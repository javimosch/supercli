# picolm Plugin

Run a 1-billion parameter LLM on a $10 board with 256MB RAM

## Commands

### General
- `picolm self version` — Print picolm version
- `picolm _ _` — Passthrough to picolm CLI

## Usage Examples
- "Run picolm"
- "Use picolm to Run a 1-billion parameter LLM on a $10 board with 256MB RAM"

## Installation

```bash
pip install picolm
```

## Key Features
- Run a 1-billion parameter LLM on a $10 board with 256MB RAM
