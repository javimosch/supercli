# pktype Plugin

CLI tool: pktype.

## Commands
- `pktype <resource> <action>` — Execute pktype commands
- `pktype self version` — Print pktype version
- `pktype _ _` — Passthrough to pktype CLI

## Usage Examples
- "pktype --help"
- "pktype self version"

## Installation
```bash
apt-get install pktype 2>/dev/null || which pktype
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
