# update-texmf-config Plugin

CLI tool: update-texmf-config.

## Commands
- `update-texmf-config <resource> <action>` — Execute update-texmf-config commands
- `update-texmf-config self version` — Print update-texmf-config version
- `update-texmf-config _ _` — Passthrough to update-texmf-config CLI

## Usage Examples
- "update-texmf-config --help"
- "update-texmf-config self version"

```bash
apt-get install update-texmf-config 2>/dev/null || which update-texmf-config
```
