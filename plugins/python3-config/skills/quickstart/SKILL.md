# python3-config Plugin

Python build configuration utility.

## Commands
- `python3-config <resource> <action>` — Execute python3-config commands
- `python3-config _ _` — Passthrough to python3-config CLI

## Usage Examples
- "python3-config --help"

## Installation
```bash
apt-get install python3-dev
```

## Key Features
- CLI-based system tool
- Scriptable and automatable
