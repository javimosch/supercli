# post-grohtml Plugin

CLI tool: post-grohtml.

## Commands
- `post-grohtml <resource> <action>` — Execute post-grohtml commands
- `post-grohtml self version` — Print post-grohtml version
- `post-grohtml _ _` — Passthrough to post-grohtml CLI

## Usage Examples
- "post-grohtml --help"
- "post-grohtml self version"

```bash
apt-get install post-grohtml 2>/dev/null || which post-grohtml
```
