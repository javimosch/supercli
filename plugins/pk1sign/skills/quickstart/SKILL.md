# pk1sign Plugin

CLI tool: pk1sign.

## Commands
- `pk1sign <resource> <action>` — Execute pk1sign commands
- `pk1sign self version` — Print pk1sign version
- `pk1sign _ _` — Passthrough to pk1sign CLI

## Usage Examples
- "pk1sign --help"
- "pk1sign self version"

## Installation
```bash
apt-get install pk1sign 2>/dev/null || which pk1sign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
