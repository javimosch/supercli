# usbip Plugin

CLI tool: usbip.

## Commands
- `usbip <resource> <action>` — Execute usbip commands
- `usbip self version` — Print usbip version
- `usbip _ _` — Passthrough to usbip CLI

## Usage Examples
- "usbip --help"
- "usbip self version"

## Installation
```bash
apt-get install usbip 2>/dev/null || which usbip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
