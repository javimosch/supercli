# gnome-session-custom-session Plugin

CLI tool: gnome-session-custom-session.

## Commands
- `gnome-session-custom-session <resource> <action>` — Execute gnome-session-custom-session commands
- `gnome-session-custom-session self version` — Print gnome-session-custom-session version
- `gnome-session-custom-session _ _` — Passthrough to gnome-session-custom-session CLI

## Usage Examples
- "gnome-session-custom-session --help"
- "gnome-session-custom-session self version"

## Installation
```bash
apt-get install gnome-session-custom-session 2>/dev/null || which gnome-session-custom-session
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
