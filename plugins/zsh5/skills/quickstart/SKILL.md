# zsh5 Plugin

CLI tool: zsh5.

## Commands
- `zsh5 <resource> <action>` — Execute zsh5 commands
- `zsh5 self version` — Print zsh5 version
- `zsh5 _ _` — Passthrough to zsh5 CLI

## Usage Examples
- "zsh5 --help"
- "zsh5 self version"

## Installation
```bash
apt-get install zsh5 2>/dev/null || which zsh5
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
