# crosspoint-reader Plugin

Firmware for the Xteink X3 and X4 e-paper display readers

## Commands

### General
- `crosspoint-reader self version` — Print crosspoint-reader version
- `crosspoint-reader _ _` — Passthrough to crosspoint-reader CLI

## Usage Examples
- "Run crosspoint-reader"
- "Use crosspoint-reader to Firmware for the Xteink X3 and X4 e-paper display readers"

## Installation

```bash
pip install crosspoint-reader
```

## Key Features
- Firmware for the Xteink X3 and X4 e-paper display readers
- CLI tool, headless and scriptable
