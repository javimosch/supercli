# rstartd Plugin

CLI tool: rstartd.

## Commands
- `rstartd <resource> <action>` — Execute rstartd commands
- `rstartd self version` — Print rstartd version
- `rstartd _ _` — Passthrough to rstartd CLI

## Usage Examples
- "rstartd --help"
- "rstartd self version"

## Installation
```bash
apt-get install rstartd 2>/dev/null || which rstartd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
