# gencnval Plugin

CLI tool: gencnval.

## Commands
- `gencnval <resource> <action>` — Execute gencnval commands
- `gencnval self version` — Print gencnval version
- `gencnval _ _` — Passthrough to gencnval CLI

## Usage Examples
- "gencnval --help"
- "gencnval self version"

## Installation
```bash
apt-get install gencnval 2>/dev/null || which gencnval
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
