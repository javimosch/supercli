# mft Plugin

CLI tool: mft.

## Commands
- `mft <resource> <action>` — Execute mft commands
- `mft self version` — Print mft version
- `mft _ _` — Passthrough to mft CLI

## Usage Examples
- "mft --help"
- "mft self version"

## Installation
```bash
apt-get install mft 2>/dev/null || which mft
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
