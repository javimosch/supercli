# ssh-proxy Plugin

SSH proxy CLI — manage SSH tunnels and port forwarding with JSON status output

## Commands
- `ssh-proxy self version` — Print version
- `ssh-proxy _ _` — Passthrough to ssh-proxy

## Installation
```bash
go install github.com/ssh-proxy/ssh-proxy@latest
```
