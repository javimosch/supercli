# gcm-viewer Plugin

CLI tool: gcm-viewer.

## Commands
- `gcm-viewer <resource> <action>` — Execute gcm-viewer commands
- `gcm-viewer self version` — Print gcm-viewer version
- `gcm-viewer _ _` — Passthrough to gcm-viewer CLI

## Usage Examples
- "gcm-viewer --help"
- "gcm-viewer self version"

## Installation
```bash
apt-get install gcm-viewer 2>/dev/null || which gcm-viewer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
