# lxc-start Plugin

CLI tool: lxc-start.

## Commands
- `lxc-start <resource> <action>` — Execute lxc-start commands
- `lxc-start self version` — Print lxc-start version
- `lxc-start _ _` — Passthrough to lxc-start CLI

## Usage Examples
- "lxc-start --help"
- "lxc-start self version"

## Installation
```bash
apt-get install lxc-start 2>/dev/null || which lxc-start
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
