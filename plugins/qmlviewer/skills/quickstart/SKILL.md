# qmlviewer Plugin

CLI tool: qmlviewer.

## Commands
- `qmlviewer <resource> <action>` — Execute qmlviewer commands
- `qmlviewer self version` — Print qmlviewer version
- `qmlviewer _ _` — Passthrough to qmlviewer CLI

## Usage Examples
- "qmlviewer --help"
- "qmlviewer self version"

## Installation
```bash
apt-get install qmlviewer 2>/dev/null || which qmlviewer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
