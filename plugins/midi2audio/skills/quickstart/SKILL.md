# midi2audio Plugin
CLI wrapper for FluidSynth to convert MIDI to audio

## Commands
- `midi2audio <resource> <action>` — Execute midi2audio commands
- `midi2audio _ _` — Passthrough to midi2audio CLI

## Usage
- `midi2audio _ _ <args>` — Run midi2audio with any arguments
