# dorso Plugin

A macOS app that blurs your screen when you slouch.

## Commands

### General
- `dorso self version` — Print dorso version
- `dorso _ _` — Passthrough to dorso CLI

## Usage Examples
- "Run dorso"
- "Use dorso to A macOS app that blurs your screen when you slouch."

## Installation

```bash
pip install dorso
```

## Key Features
- A macOS app that blurs your screen when you slouch.
- CLI tool, headless and scriptable
