# prove Plugin

CLI tool: prove.

## Commands
- `prove <resource> <action>` — Execute prove commands
- `prove self version` — Print prove version
- `prove _ _` — Passthrough to prove CLI

## Usage Examples
- "prove --help"
- "prove self version"

## Installation
```bash
apt-get install prove 2>/dev/null || which prove
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
