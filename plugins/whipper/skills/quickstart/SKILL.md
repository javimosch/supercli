# whipper Plugin

CD-DA ripper preferring accuracy in Python

## Commands

### Operations
- `whipper self version` — Print whipper version
- `whipper _ _` — Passthrough to whipper CLI

## Usage Examples
- `whipper --help`
- `whipper <args>`

## Installation

```bash
pip install whipper
```

## Examples

```bash
whipper --version
whipper --help
```
