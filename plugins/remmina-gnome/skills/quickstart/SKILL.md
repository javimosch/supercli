# remmina-gnome Plugin

CLI tool: remmina-gnome.

## Commands
- `remmina-gnome <resource> <action>` — Execute remmina-gnome commands
- `remmina-gnome self version` — Print remmina-gnome version
- `remmina-gnome _ _` — Passthrough to remmina-gnome CLI

## Usage Examples
- "remmina-gnome --help"
- "remmina-gnome self version"

## Installation
```bash
apt-get install remmina-gnome 2>/dev/null || which remmina-gnome
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
