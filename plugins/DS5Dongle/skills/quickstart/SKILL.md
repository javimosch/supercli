# DS5Dongle Plugin

Turn your Pico 2 W into a DualSense 5 dongle.

## Commands

### General
- `DS5Dongle self version` — Print DS5Dongle version
- `DS5Dongle _ _` — Passthrough to ds5dongle CLI

## Usage Examples
- "Run DS5Dongle"
- "Use ds5dongle to Turn your Pico 2 W into a DualSense 5 dongle."

## Installation

```bash
pip install ds5dongle
```

## Key Features
- Turn your Pico 2 W into a DualSense 5 dongle.
- CLI tool, headless and scriptable
