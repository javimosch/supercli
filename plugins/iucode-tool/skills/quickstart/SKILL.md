# iucode-tool Plugin

CLI tool: iucode-tool.

## Commands
- `iucode-tool <resource> <action>` — Execute iucode-tool commands
- `iucode-tool self version` — Print iucode-tool version
- `iucode-tool _ _` — Passthrough to iucode-tool CLI

## Usage Examples
- "iucode-tool --help"
- "iucode-tool self version"

## Installation
```bash
apt-get install iucode-tool 2>/dev/null || which iucode-tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
