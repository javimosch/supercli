# geeknote Plugin
Command-line client for Evernote

## Commands
- `geeknote <resource> <action>` — Execute geeknote commands
- `geeknote _ _` — Passthrough to geeknote CLI

## Usage
- `geeknote _ _ <args>` — Run geeknote with any arguments
