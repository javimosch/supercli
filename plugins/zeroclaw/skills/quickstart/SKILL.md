# zeroclaw Plugin

Fast, small, and fully autonomous AI personal assistant infrastructure, any OS, any platform — deploy anywhere, swap anything 🦀

## Commands
- `zeroclaw <resource> <action>` — Execute zeroclaw commands
- `zeroclaw self version` — Print zeroclaw version
- `zeroclaw _ _` — Passthrough to zeroclaw CLI

## Installation

```bash
pip install zeroclaw
```
