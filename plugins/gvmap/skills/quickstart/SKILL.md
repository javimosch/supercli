# gvmap Plugin

CLI tool: gvmap.

## Commands
- `gvmap <resource> <action>` — Execute gvmap commands
- `gvmap self version` — Print gvmap version
- `gvmap _ _` — Passthrough to gvmap CLI

## Usage Examples
- "gvmap --help"
- "gvmap self version"

## Installation
```bash
apt-get install gvmap 2>/dev/null || which gvmap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
