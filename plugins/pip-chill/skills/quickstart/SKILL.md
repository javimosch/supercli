# pip-chill Plugin
List Python packages not installed via pip. Shows only packages that were manually installed, not dependencies.
## Commands
- `pip self version` — Print version
- `pip _ _` — Passthrough to pip-chill
## Installation
```bash
pip install pip-chill
```
