# gtk-launch Plugin

CLI tool: gtk-launch.

## Commands
- `gtk-launch <resource> <action>` — Execute gtk-launch commands
- `gtk-launch self version` — Print gtk-launch version
- `gtk-launch _ _` — Passthrough to gtk-launch CLI

## Usage Examples
- "gtk-launch --help"
- "gtk-launch self version"

## Installation
```bash
apt-get install gtk-launch 2>/dev/null || which gtk-launch
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
