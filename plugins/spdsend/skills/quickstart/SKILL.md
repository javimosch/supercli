# spdsend Plugin

CLI tool: spdsend.

## Commands
- `spdsend <resource> <action>` — Execute spdsend commands
- `spdsend self version` — Print spdsend version
- `spdsend _ _` — Passthrough to spdsend CLI

## Usage Examples
- "spdsend --help"
- "spdsend self version"

## Installation
```bash
apt-get install spdsend 2>/dev/null || which spdsend
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
