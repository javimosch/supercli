# gcov-11 Plugin

CLI tool: gcov-11.

## Commands
- `gcov-11 <resource> <action>` — Execute gcov-11 commands
- `gcov-11 self version` — Print gcov-11 version
- `gcov-11 _ _` — Passthrough to gcov-11 CLI

## Usage Examples
- "gcov-11 --help"
- "gcov-11 self version"

## Installation
```bash
apt-get install gcov-11 2>/dev/null || which gcov-11
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
