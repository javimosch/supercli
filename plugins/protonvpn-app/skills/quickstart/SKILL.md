# protonvpn-app Plugin

CLI tool: protonvpn-app.

## Commands
- `protonvpn-app <resource> <action>` — Execute protonvpn-app commands
- `protonvpn-app self version` — Print protonvpn-app version
- `protonvpn-app _ _` — Passthrough to protonvpn-app CLI

## Usage Examples
- "protonvpn-app --help"
- "protonvpn-app self version"

## Installation
```bash
apt-get install protonvpn-app 2>/dev/null || which protonvpn-app
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
