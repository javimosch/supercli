# ntptime Plugin

CLI tool: ntptime.

## Commands
- `ntptime <resource> <action>` — Execute ntptime commands
- `ntptime self version` — Print ntptime version
- `ntptime _ _` — Passthrough to ntptime CLI

## Usage Examples
- "ntptime --help"
- "ntptime self version"

## Installation
```bash
apt-get install ntptime 2>/dev/null || which ntptime
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
