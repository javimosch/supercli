# openzl Plugin

Novel data compression framework

## Commands

### Version
`openzl self version` — Print openzl version

### Passthrough
`openzl _ _` — Passthrough to openzl CLI with all arguments forwarded.

## Usage Examples

```bash
openzl --version
openzl --help
```

## Installation

```bash
cargo install openzl
```

## Key Features
- Novel data compression framework
