# uuidd Plugin

CLI tool: uuidd.

## Commands
- `uuidd <resource> <action>` — Execute uuidd commands
- `uuidd self version` — Print uuidd version
- `uuidd _ _` — Passthrough to uuidd CLI

## Usage Examples
- "uuidd --help"
- "uuidd self version"

## Installation
```bash
apt-get install uuidd 2>/dev/null || which uuidd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
