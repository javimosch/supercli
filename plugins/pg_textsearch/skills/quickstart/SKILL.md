# pg_textsearch Plugin

PostgreSQL extension for BM25 relevance-ranked full-text search. Postgres OSS licensed.

## Commands

### General
- `pg_textsearch self version` — Print pg_textsearch version
- `pg_textsearch _ _` — Passthrough to pg-textsearch CLI
