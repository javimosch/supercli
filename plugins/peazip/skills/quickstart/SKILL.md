# peazip Plugin

peazip — cross-platform archive manager CLI supporting 200+ archive formats. Create, extract, and convert archives with AES-256 encryption, split volumes, checksum verification, and compression presets for zip, 7z, tar, gz, bz2, and many more.

## Installation

```bash
brew install peazip
Verify: peazip --version
```

## Commands

### `sc peazip self version`

Print peazip version

## Passthrough

```bash
sc peazip _ _ <args...>
```

## SuperCLI

```bash
sc peazip _ _ --help
sc plugins learn peazip
```
