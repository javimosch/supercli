# dotenv-cli Plugin
Load environment variables from dotenv files

## Commands
- `dotenv-cli <resource> <action>` — Execute dotenv-cli commands
- `dotenv-cli _ _` — Passthrough to dotenv-cli CLI

## Usage
- `dotenv-cli _ _ <args>` — Run dotenv-cli with any arguments
