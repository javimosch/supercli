# dtach
dtach — detach terminal sessions. Run programs detached from terminal, reattach later.

## Commands
- `dtach <resource> <action>` — Execute dtach commands
- `dtach dtach run` — dtach — detach terminal sessions. Run programs detached from terminal, reattach later.
