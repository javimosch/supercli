# gxditview Plugin

CLI tool: gxditview.

## Commands
- `gxditview <resource> <action>` — Execute gxditview commands
- `gxditview self version` — Print gxditview version
- `gxditview _ _` — Passthrough to gxditview CLI

## Usage Examples
- "gxditview --help"
- "gxditview self version"

## Installation
```bash
apt-get install gxditview 2>/dev/null || which gxditview
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
