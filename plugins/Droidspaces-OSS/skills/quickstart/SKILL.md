# Droidspaces-OSS Plugin

A lightweight, LXC-like container runtime for Android and Linux. Run full Linux distributions natively with zero performance penalty

## Commands

### General
- `Droidspaces-OSS self version` — Print Droidspaces-OSS version
- `Droidspaces-OSS _ _` — Passthrough to droidspaces-oss CLI
