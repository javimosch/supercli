# gettextize Plugin

CLI tool: gettextize.

## Commands
- `gettextize <resource> <action>` — Execute gettextize commands
- `gettextize self version` — Print gettextize version
- `gettextize _ _` — Passthrough to gettextize CLI

## Usage Examples
- "gettextize --help"
- "gettextize self version"

## Installation
```bash
apt-get install gettextize 2>/dev/null || which gettextize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
