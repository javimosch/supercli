# gaianet-node Plugin

Install, run and deploy your own decentralized AI agent service

## Commands

### General
- `gaianet-node self version` — Print gaianet-node version
- `gaianet-node _ _` — Passthrough to gaianet-node CLI

## Usage Examples
- "Run gaianet-node"
- "Use gaianet-node to Install, run and deploy your own decentralized AI agent serv"

## Installation

```bash
pip install gaianet-node
```

## Key Features
- Install, run and deploy your own decentralized AI agent service
- CLI tool, headless and scriptable
