# Vk-Turn-Proxy Plugin

WireGuard tunnel through VK TURN relay servers for VPN proxying

## Commands
- `vk-turn-proxy _ _` — Passthrough to vk-turn-proxy CLI

## Installation

```bash
go install github.com/cacggghp/vk-turn-proxy@latest
```

## Examples
```bash
vk-turn-proxy --help
vk-turn-proxy --version
```
