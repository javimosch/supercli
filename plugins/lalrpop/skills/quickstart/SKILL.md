# lalrpop

LALRPOP — LR parser generator for Rust

## Install

```bash
cargo install lalrpop
```

Verify installation:

```bash
which lalrpop
```

## Commands

- `lalrpop self version` — print lalrpop version
- `lalrpop cli run ...` — pass any arguments straight through to `lalrpop`
