# rust-script Plugin

rust-script — run Rust files and expressions as scripts..

## Commands

### `sc rust-script script run`
Run a Rust script file.

### `sc rust-script self version`
Print version.

## Installation

```bash
cargo install rust-script
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
