# godot-task Plugin
Automate Godot project tasks including build and export via CLI

## Commands
- `godot-task <resource> <action>` — Execute godot-task commands
- `godot-task _ _` — Passthrough to godot-task CLI

## Usage
- `godot-task _ _ <args>` — Run godot-task with any arguments
