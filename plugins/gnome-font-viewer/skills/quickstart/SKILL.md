# gnome-font-viewer Plugin

CLI tool: gnome-font-viewer.

## Commands
- `gnome-font-viewer <resource> <action>` — Execute gnome-font-viewer commands
- `gnome-font-viewer self version` — Print gnome-font-viewer version
- `gnome-font-viewer _ _` — Passthrough to gnome-font-viewer CLI

## Usage Examples
- "gnome-font-viewer --help"
- "gnome-font-viewer self version"

## Installation
```bash
apt-get install gnome-font-viewer 2>/dev/null || which gnome-font-viewer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
