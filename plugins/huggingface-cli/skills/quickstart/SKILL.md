# huggingface-cli Plugin

CLI tool: huggingface-cli.

## Commands
- `huggingface-cli <resource> <action>` — Execute huggingface-cli commands
- `huggingface-cli self version` — Print huggingface-cli version
- `huggingface-cli _ _` — Passthrough to huggingface-cli CLI

## Usage Examples
- "huggingface-cli --help"
- "huggingface-cli self version"

## Installation
```bash
apt-get install huggingface-cli 2>/dev/null || which huggingface-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
