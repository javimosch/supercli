# git-ignore Plugin
Quickly fetch gitignore templates from the CLI

## Commands
- `git-ignore <resource> <action>` — Execute git-ignore commands
- `git-ignore _ _` — Passthrough to git-ignore CLI

## Usage
- `git-ignore _ _ <args>` — Run git-ignore with any arguments
