# pico-crypt Plugin
Simple file encryption tool with strong cryptography

## Commands
- `pico-crypt <resource> <action>` — Execute pico-crypt commands
- `pico-crypt _ _` — Passthrough to pico-crypt CLI

## Usage
- `pico-crypt _ _ <args>` — Run pico-crypt with any arguments
