# gvfs-move Plugin

CLI tool: gvfs-move.

## Commands
- `gvfs-move <resource> <action>` — Execute gvfs-move commands
- `gvfs-move self version` — Print gvfs-move version
- `gvfs-move _ _` — Passthrough to gvfs-move CLI

- "gvfs-move self version"
