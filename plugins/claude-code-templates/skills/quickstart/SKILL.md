# claude-code-templates Plugin

CLI tool for configuring and monitoring Claude Code

## Commands

### General
- `claude-code-templates self version` — Print claude-code-templates version
- `claude-code-templates _ _` — Passthrough to claude-code-templates CLI

## Usage Examples
- "Run claude-code-templates"
- "Use claude-code-templates to CLI tool for configuring and monitoring Claude Code"

## Installation

```bash
pip install claude-code-templates
```

## Key Features
- CLI tool for configuring and monitoring Claude Code
- CLI tool, headless and scriptable
