# pyi-set_version Plugin

CLI tool: pyi-set_version.

## Commands
- `pyi-set_version <resource> <action>` — Execute pyi-set_version commands
- `pyi-set_version self version` — Print pyi-set_version version
- `pyi-set_version _ _` — Passthrough to pyi-set_version CLI

## Usage Examples
- "pyi-set_version --help"
- "pyi-set_version self version"

## Installation
```bash
apt-get install pyi-set_version 2>/dev/null || which pyi-set_version
```
