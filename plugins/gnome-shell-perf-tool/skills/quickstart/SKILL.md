# gnome-shell-perf-tool Plugin

CLI tool: gnome-shell-perf-tool.

## Commands
- `gnome-shell-perf-tool <resource> <action>` — Execute gnome-shell-perf-tool commands
- `gnome-shell-perf-tool self version` — Print gnome-shell-perf-tool version
- `gnome-shell-perf-tool _ _` — Passthrough to gnome-shell-perf-tool CLI

## Usage Examples
- "gnome-shell-perf-tool --help"
- "gnome-shell-perf-tool self version"

## Installation
```bash
apt-get install gnome-shell-perf-tool 2>/dev/null || which gnome-shell-perf-tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
