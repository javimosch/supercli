# xxd Plugin
Create hex dumps from binary files or convert hex back to binary.

## Commands
- `xxd <resource> <action>` — Execute xxd commands
- `xxd _ _` — Passthrough to xxd CLI

## Usage
- `xxd _ _ <file>` — Hex dump a file
