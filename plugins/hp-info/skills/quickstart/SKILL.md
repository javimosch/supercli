# hp-info Plugin

CLI tool: hp-info.

## Commands
- `hp-info <resource> <action>` — Execute hp-info commands
- `hp-info self version` — Print hp-info version
- `hp-info _ _` — Passthrough to hp-info CLI

## Usage Examples
- "hp-info --help"
- "hp-info self version"

## Installation
```bash
apt-get install hp-info 2>/dev/null || which hp-info
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
