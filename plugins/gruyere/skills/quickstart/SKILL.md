# gruyere Plugin
Tiny port viewer and killer.
## Commands
- `gruyere _ _` — Passthrough to gruyere CLI
## Installation
```bash
cargo install gruyere
```
## Key Features
- **Port viewing** — List listening ports
- **Port killing** — Free up occupied ports
- **Tiny** — Minimal utility
- **Pipeline-ready** — Automation support
