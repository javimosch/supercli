# native2ascii Plugin

CLI tool: native2ascii.

## Commands
- `native2ascii <resource> <action>` — Execute native2ascii commands
- `native2ascii self version` — Print native2ascii version
- `native2ascii _ _` — Passthrough to native2ascii CLI

## Usage Examples
- "native2ascii --help"
- "native2ascii self version"

## Installation
```bash
apt-get install native2ascii 2>/dev/null || which native2ascii
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
