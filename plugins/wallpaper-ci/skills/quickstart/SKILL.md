# wallpaper-ci Plugin
Minimalist tool for cycling desktop wallpapers from directories

## Commands
- `wallpaper-ci <resource> <action>` — Execute wallpaper-ci commands
- `wallpaper-ci _ _` — Passthrough to wallpaper-ci CLI

## Usage
- `wallpaper-ci _ _ <args>` — Run wallpaper-ci with any arguments
