# sbsign Plugin

CLI tool: sbsign.

## Commands
- `sbsign <resource> <action>` — Execute sbsign commands
- `sbsign self version` — Print sbsign version
- `sbsign _ _` — Passthrough to sbsign CLI

## Usage Examples
- "sbsign --help"
- "sbsign self version"

## Installation
```bash
apt-get install sbsign 2>/dev/null || which sbsign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
