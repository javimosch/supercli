# ppmchange Plugin

CLI tool: ppmchange.

## Commands
- `ppmchange <resource> <action>` — Execute ppmchange commands
- `ppmchange self version` — Print ppmchange version
- `ppmchange _ _` — Passthrough to ppmchange CLI

## Usage Examples
- "ppmchange --help"
- "ppmchange self version"

## Installation
```bash
apt-get install ppmchange 2>/dev/null || which ppmchange
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
