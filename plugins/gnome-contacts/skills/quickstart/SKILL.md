# gnome-contacts Plugin

CLI tool: gnome-contacts.

## Commands
- `gnome-contacts <resource> <action>` — Execute gnome-contacts commands
- `gnome-contacts self version` — Print gnome-contacts version
- `gnome-contacts _ _` — Passthrough to gnome-contacts CLI

## Usage Examples
- "gnome-contacts --help"
- "gnome-contacts self version"

## Installation
```bash
apt-get install gnome-contacts 2>/dev/null || which gnome-contacts
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
