# macptopbm Plugin

CLI tool: macptopbm.

## Commands
- `macptopbm <resource> <action>` — Execute macptopbm commands
- `macptopbm self version` — Print macptopbm version
- `macptopbm _ _` — Passthrough to macptopbm CLI

## Usage Examples
- "macptopbm --help"
- "macptopbm self version"

## Installation
```bash
apt-get install macptopbm 2>/dev/null || which macptopbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
