# bumpver Plugin
Automated calendar and semver version bumping with Git tags

## Commands
- `bumpver <resource> <action>` — Execute bumpver commands
- `bumpver _ _` — Passthrough to bumpver CLI

## Usage
- `bumpver _ _ <args>` — Run bumpver with any arguments
