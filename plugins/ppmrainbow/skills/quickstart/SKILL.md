# ppmrainbow Plugin

CLI tool: ppmrainbow.

## Commands
- `ppmrainbow <resource> <action>` — Execute ppmrainbow commands
- `ppmrainbow self version` — Print ppmrainbow version
- `ppmrainbow _ _` — Passthrough to ppmrainbow CLI

## Usage Examples
- "ppmrainbow --help"
- "ppmrainbow self version"

## Installation
```bash
apt-get install ppmrainbow 2>/dev/null || which ppmrainbow
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
