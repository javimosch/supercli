# uptftopl Plugin

CLI tool: uptftopl.

## Commands
- `uptftopl <resource> <action>` — Execute uptftopl commands
- `uptftopl self version` — Print uptftopl version
- `uptftopl _ _` — Passthrough to uptftopl CLI

## Usage Examples
- "uptftopl --help"
- "uptftopl self version"

## Installation
```bash
apt-get install uptftopl 2>/dev/null || which uptftopl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
