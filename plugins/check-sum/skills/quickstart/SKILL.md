# check-sum Plugin
Simple integrity verifier for file bundle checksums

## Commands
- `check-sum <resource> <action>` — Execute check-sum commands
- `check-sum _ _` — Passthrough to check-sum CLI

## Usage
- `check-sum _ _ <args>` — Run check-sum with any arguments
