# magic-g Plugin

CLI tool: magic-g.

## Commands
- `magic-g <resource> <action>` — Execute magic-g commands
- `magic-g self version` — Print magic-g version
- `magic-g _ _` — Passthrough to magic-g CLI

## Usage Examples
- "magic-g --help"
- "magic-g self version"

## Installation
```bash
apt-get install magic-g 2>/dev/null || which magic-g
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
