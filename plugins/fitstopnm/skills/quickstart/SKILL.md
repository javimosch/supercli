# fitstopnm Plugin

CLI tool: fitstopnm.

## Commands
- `fitstopnm <resource> <action>` — Execute fitstopnm commands
- `fitstopnm self version` — Print fitstopnm version
- `fitstopnm _ _` — Passthrough to fitstopnm CLI

## Usage Examples
- "fitstopnm --help"
- "fitstopnm self version"

```bash
apt-get install fitstopnm 2>/dev/null || which fitstopnm
```
