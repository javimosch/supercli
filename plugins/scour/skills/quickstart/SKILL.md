# scour Plugin

scour — SVG optimizer and cleaner that reduces file size without affecting quality. Removes metadata, editor cruft, unused definitions, and simplifies path data. Produces production-ready SVGs optimized for web delivery with configurable precision settings.

## Installation

```bash
pip install scour
Verify: scour --version
```

## Commands

### `sc scour self version`

Print scour version

## Passthrough

```bash
sc scour _ _ <args...>
```

## SuperCLI

```bash
sc scour _ _ --help
sc plugins learn scour
```
