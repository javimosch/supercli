# doctl

doctl — DigitalOcean CLI for managing cloud resources

## Install

```bash
brew install doctl
```

Verify installation:

```bash
which doctl
```

## Commands

- `doctl self version` — print doctl version
- `doctl cli run ...` — pass any arguments straight through to `doctl`
