# DroidDesk Plugin

DroidDesk turns your Android phone into a real Linux desktop using Termux, Termux X11, TUR, and Proot. Run VS Code, Firefox, LibreOffice, Blender, and more with X11 or VNC support for monitor setup.

## Commands

### General
- `DroidDesk self version` — Print DroidDesk version
- `DroidDesk _ _` — Passthrough to droiddesk CLI

## Usage Examples
- "Run DroidDesk"
- "Use droiddesk to DroidDesk turns your Android phone into a real Linux desktop"

## Installation

```bash
pip install droiddesk
```
