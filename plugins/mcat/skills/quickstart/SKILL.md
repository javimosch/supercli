# mcat Plugin

CLI tool: mcat.

## Commands
- `mcat <resource> <action>` — Execute mcat commands
- `mcat self version` — Print mcat version
- `mcat _ _` — Passthrough to mcat CLI

## Usage Examples
- "mcat --help"
- "mcat self version"

## Installation
```bash
apt-get install mcat 2>/dev/null || which mcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
