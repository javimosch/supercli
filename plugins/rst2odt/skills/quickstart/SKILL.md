# rst2odt Plugin

CLI tool: rst2odt.

## Commands
- `rst2odt <resource> <action>` — Execute rst2odt commands
- `rst2odt self version` — Print rst2odt version
- `rst2odt _ _` — Passthrough to rst2odt CLI

## Usage Examples
- "rst2odt --help"
- "rst2odt self version"

## Installation
```bash
apt-get install rst2odt 2>/dev/null || which rst2odt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
