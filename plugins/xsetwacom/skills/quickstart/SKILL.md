# xsetwacom Plugin

CLI tool: xsetwacom.

## Commands
- `xsetwacom <resource> <action>` — Execute xsetwacom commands
- `xsetwacom self version` — Print xsetwacom version
- `xsetwacom _ _` — Passthrough to xsetwacom CLI

## Usage Examples
- "xsetwacom --help"
- "xsetwacom self version"

## Installation
```bash
apt-get install xsetwacom 2>/dev/null || which xsetwacom
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
