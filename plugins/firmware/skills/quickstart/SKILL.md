# firmware Plugin

Predatory ESP32 Firmware

## Commands

### General
- `firmware self version` — Print firmware version
- `firmware _ _` — Passthrough to firmware CLI

## Usage Examples
- "Run firmware"
- "Use firmware to Predatory ESP32 Firmware"

## Installation

```bash
pip install firmware
```

## Key Features
- Predatory ESP32 Firmware
- CLI tool, headless and scriptable
