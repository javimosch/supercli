# jhat Plugin

CLI tool: jhat.

## Commands
- `jhat <resource> <action>` — Execute jhat commands
- `jhat self version` — Print jhat version
- `jhat _ _` — Passthrough to jhat CLI

## Usage Examples
- "jhat --help"
- "jhat self version"

## Installation
```bash
apt-get install jhat 2>/dev/null || which jhat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
