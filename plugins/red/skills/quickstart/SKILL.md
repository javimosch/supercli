# red Plugin

CLI tool: red.

## Commands
- `red <resource> <action>` — Execute red commands
- `red self version` — Print red version
- `red _ _` — Passthrough to red CLI

## Usage Examples
- "red --help"
- "red self version"

## Installation
```bash
apt-get install red 2>/dev/null || which red
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
