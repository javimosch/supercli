# lzdiff Plugin

CLI tool: lzdiff.

## Commands
- `lzdiff <resource> <action>` — Execute lzdiff commands
- `lzdiff self version` — Print lzdiff version
- `lzdiff _ _` — Passthrough to lzdiff CLI

## Usage Examples
- "lzdiff --help"
- "lzdiff self version"

## Installation
```bash
apt-get install lzdiff 2>/dev/null || which lzdiff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
