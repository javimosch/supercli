# tokentap Plugin

Intercept LLM API traffic and visualize token usage in a real-time terminal dashboard. Track costs, debug prompts, zero configuration, pip installed.

## Commands
- `tokentap self version` — Print version
- `tokentap _ _ <args>` — Passthrough to tokentap

## Usage Examples
- "Token Usage Monitor"

## Installation
```bash
pip install tokentap
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
