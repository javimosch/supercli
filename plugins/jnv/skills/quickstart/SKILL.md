# jnv
jnv — interactive JSON viewer and filter. Navigate JSON structures with jq-like filtering. Non-interactive mode with --raw.

## Commands
- `jnv <resource> <action>` — Execute jnv commands
- `jnv jnv run` — jnv — interactive JSON viewer and filter. Navigate JSON structures with jq-like filtering. Non-interactive mode with --raw.
