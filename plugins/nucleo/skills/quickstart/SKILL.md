# nucleo Plugin
High-performance Rust fuzzy matching library with CLI interface

## Commands
- `nucleo <resource> <action>` — Execute nucleo commands
- `nucleo _ _` — Passthrough to nucleo CLI

## Usage
- `nucleo _ _ <args>` — Run nucleo with any arguments
