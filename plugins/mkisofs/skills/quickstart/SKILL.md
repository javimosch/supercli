# mkisofs Plugin

CLI tool: mkisofs.

## Commands
- `mkisofs <resource> <action>` — Execute mkisofs commands
- `mkisofs self version` — Print mkisofs version
- `mkisofs _ _` — Passthrough to mkisofs CLI

## Usage Examples
- "mkisofs --help"
- "mkisofs self version"

## Installation
```bash
apt-get install mkisofs 2>/dev/null || which mkisofs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
