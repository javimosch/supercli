# p-scan Plugin
Simple asynchronous port scanner for network discovery

## Commands
- `p-scan <resource> <action>` — Execute p-scan commands
- `p-scan _ _` — Passthrough to p-scan CLI

## Usage
- `p-scan _ _ <args>` — Run p-scan with any arguments
