# yaml-to-json Plugin
Convert YAML files to JSON format via CLI

## Commands
- `yaml-to-json <resource> <action>` — Execute yaml-to-json commands
- `yaml-to-json _ _` — Passthrough to yaml-to-json CLI

## Usage
- `yaml-to-json _ _ <args>` — Run yaml-to-json with any arguments
