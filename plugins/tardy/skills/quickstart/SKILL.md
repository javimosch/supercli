# tardy Plugin

An asynchronous runtime for writing applications and services. Supports io_uring, epoll, kqueue, and poll for I/O. 

## Commands

### General
- `tardy self version` — Print tardy version
- `tardy _ _` — Passthrough to tardy CLI
