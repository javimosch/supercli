# vigr Plugin

vigr — change and administer password and group data.

## Commands
- `vigr <resource> <action>` — Execute vigr commands
- `vigr self version` — Print vigr version
- `vigr _ _` — Passthrough to vigr CLI

## Usage Examples
- "vigr --help"
- "vigr self version"

## Installation
```bash
apt-get install passwd 2>/dev/null || which vigr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
