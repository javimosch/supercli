# photon-wallpaper Plugin
Sync wallpapers with Bing and Reddit image sources

## Commands
- `photon-wallpaper <resource> <action>` — Execute photon-wallpaper commands
- `photon-wallpaper _ _` — Passthrough to photon-wallpaper CLI

## Usage
- `photon-wallpaper _ _ <args>` — Run photon-wallpaper with any arguments
