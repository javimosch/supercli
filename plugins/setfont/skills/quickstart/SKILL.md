# setfont Plugin

CLI tool: setfont.

## Commands
- `setfont <resource> <action>` — Execute setfont commands
- `setfont self version` — Print setfont version
- `setfont _ _` — Passthrough to setfont CLI

## Usage Examples
- "setfont --help"
- "setfont self version"

## Installation
```bash
apt-get install setfont 2>/dev/null || which setfont
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
