# MoneyPrinterV2 Plugin

Automate the process of making money online.

## Commands

### General
- `MoneyPrinterV2 self version` — Print MoneyPrinterV2 version
- `MoneyPrinterV2 _ _` — Passthrough to moneyprinterv2 CLI

## Usage Examples
- "Run MoneyPrinterV2"
- "Use moneyprinterv2 to Automate the process of making money online."

## Installation

```bash
pip install moneyprinterv2
```

## Key Features
- Automate the process of making money online.
- CLI tool, headless and scriptable
