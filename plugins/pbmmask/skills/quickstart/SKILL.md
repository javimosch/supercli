# pbmmask Plugin

CLI tool: pbmmask.

## Commands
- `pbmmask <resource> <action>` — Execute pbmmask commands
- `pbmmask self version` — Print pbmmask version
- `pbmmask _ _` — Passthrough to pbmmask CLI

## Usage Examples
- "pbmmask --help"
- "pbmmask self version"

## Installation
```bash
apt-get install pbmmask 2>/dev/null || which pbmmask
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
