# pstopnm Plugin

CLI tool: pstopnm.

## Commands
- `pstopnm <resource> <action>` — Execute pstopnm commands
- `pstopnm self version` — Print pstopnm version
- `pstopnm _ _` — Passthrough to pstopnm CLI

## Usage Examples
- "pstopnm --help"
- "pstopnm self version"

## Installation
```bash
apt-get install pstopnm 2>/dev/null || which pstopnm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
