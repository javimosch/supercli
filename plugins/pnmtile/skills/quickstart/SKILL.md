# pnmtile Plugin

CLI tool: pnmtile.

## Commands
- `pnmtile <resource> <action>` — Execute pnmtile commands
- `pnmtile self version` — Print pnmtile version
- `pnmtile _ _` — Passthrough to pnmtile CLI

## Usage Examples
- "pnmtile --help"
- "pnmtile self version"

## Installation
```bash
apt-get install pnmtile 2>/dev/null || which pnmtile
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
