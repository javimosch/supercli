# thermald Plugin

CLI tool: thermald.

## Commands
- `thermald <resource> <action>` — Execute thermald commands
- `thermald self version` — Print thermald version
- `thermald _ _` — Passthrough to thermald CLI

## Usage Examples
- "thermald --help"
- "thermald self version"

## Installation
```bash
apt-get install thermald 2>/dev/null || which thermald
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
