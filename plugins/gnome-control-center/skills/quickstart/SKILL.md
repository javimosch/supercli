# gnome-control-center Plugin

CLI tool: gnome-control-center.

## Commands
- `gnome-control-center <resource> <action>` — Execute gnome-control-center commands
- `gnome-control-center self version` — Print gnome-control-center version
- `gnome-control-center _ _` — Passthrough to gnome-control-center CLI

## Usage Examples
- "gnome-control-center --help"
- "gnome-control-center self version"

## Installation
```bash
apt-get install gnome-control-center 2>/dev/null || which gnome-control-center
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
