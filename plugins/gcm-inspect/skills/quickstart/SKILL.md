# gcm-inspect Plugin

CLI tool: gcm-inspect.

## Commands
- `gcm-inspect <resource> <action>` — Execute gcm-inspect commands
- `gcm-inspect self version` — Print gcm-inspect version
- `gcm-inspect _ _` — Passthrough to gcm-inspect CLI

## Usage Examples
- "gcm-inspect --help"
- "gcm-inspect self version"

## Installation
```bash
apt-get install gcm-inspect 2>/dev/null || which gcm-inspect
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
