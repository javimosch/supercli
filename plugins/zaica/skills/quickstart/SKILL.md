# zaica Plugin
Zig LLM-agent CLI.
## Commands
- `zaica _ _` — Passthrough to zaica CLI
## Installation
```bash
git clone https://github.com/neolite/zaica && cd zaica && zig build
```
## Key Features
- **LLM agent** — Tool-calling capabilities
- **Low-latency** — Fast Zig execution
- **Headless** — Non-interactive workflows
