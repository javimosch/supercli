# remindee-bot Plugin
CLI tool for remindee-bot.

## Commands
- `remindee-bot <resource> <action>` — Execute remindee-bot commands
- `remindee-bot _ _` — Passthrough to remindee-bot CLI

## Installation
```bash
cargo install remindee-bot
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
