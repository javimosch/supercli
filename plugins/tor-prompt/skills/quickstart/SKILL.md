# tor-prompt Plugin

CLI tool: tor-prompt.

## Commands
- `tor-prompt <resource> <action>` — Execute tor-prompt commands
- `tor-prompt self version` — Print tor-prompt version
- `tor-prompt _ _` — Passthrough to tor-prompt CLI

## Usage Examples
- "tor-prompt --help"
- "tor-prompt self version"

## Installation
```bash
apt-get install tor-prompt 2>/dev/null || which tor-prompt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
