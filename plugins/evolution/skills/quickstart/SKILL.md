# evolution Plugin

CLI tool: evolution.

## Commands
- `evolution <resource> <action>` — Execute evolution commands
- `evolution self version` — Print evolution version
- `evolution _ _` — Passthrough to evolution CLI

## Usage Examples
- "evolution --help"
- "evolution self version"

## Installation
```bash
apt-get install evolution 2>/dev/null || which evolution
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
