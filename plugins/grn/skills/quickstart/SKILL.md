# grn Plugin

CLI tool: grn.

## Commands
- `grn <resource> <action>` — Execute grn commands
- `grn self version` — Print grn version
- `grn _ _` — Passthrough to grn CLI

## Usage Examples
- "grn --help"
- "grn self version"

## Installation
```bash
apt-get install grn 2>/dev/null || which grn
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
