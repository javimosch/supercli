# lvmdiskscan Plugin

CLI tool: lvmdiskscan.

## Commands
- `lvmdiskscan <resource> <action>` — Execute lvmdiskscan commands
- `lvmdiskscan self version` — Print lvmdiskscan version
- `lvmdiskscan _ _` — Passthrough to lvmdiskscan CLI

## Usage Examples
- "lvmdiskscan --help"
- "lvmdiskscan self version"

## Installation
```bash
apt-get install lvmdiskscan 2>/dev/null || which lvmdiskscan
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
