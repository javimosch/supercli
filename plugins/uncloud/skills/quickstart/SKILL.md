# uncloud Plugin

A lightweight tool for deploying and managing containerised applications across a network of Docker hosts. Bridging the gap between Docker and Kubernetes ✨

## Commands
- `uncloud <resource> <action>` — Execute uncloud commands
- `uncloud self version` — Print uncloud version
- `uncloud _ _` — Passthrough to uncloud CLI

## Installation

```bash
pip install uncloud
```
