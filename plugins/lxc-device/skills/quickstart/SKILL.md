# lxc-device Plugin

CLI tool: lxc-device.

## Commands
- `lxc-device <resource> <action>` — Execute lxc-device commands
- `lxc-device self version` — Print lxc-device version
- `lxc-device _ _` — Passthrough to lxc-device CLI

## Usage Examples
- "lxc-device --help"
- "lxc-device self version"

## Installation
```bash
apt-get install lxc-device 2>/dev/null || which lxc-device
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
