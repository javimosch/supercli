# gnome-menus-blacklist Plugin

CLI tool: gnome-menus-blacklist.

## Commands
- `gnome-menus-blacklist <resource> <action>` — Execute gnome-menus-blacklist commands
- `gnome-menus-blacklist self version` — Print gnome-menus-blacklist version
- `gnome-menus-blacklist _ _` — Passthrough to gnome-menus-blacklist CLI

## Usage Examples
- "gnome-menus-blacklist --help"
- "gnome-menus-blacklist self version"

## Installation
```bash
apt-get install gnome-menus-blacklist 2>/dev/null || which gnome-menus-blacklist
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
