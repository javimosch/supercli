# projclean Plugin
CLI tool for projclean.

## Commands
- `projclean <resource> <action>` — Execute projclean commands
- `projclean _ _` — Passthrough to projclean CLI

## Installation
```bash
cargo install projclean
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
