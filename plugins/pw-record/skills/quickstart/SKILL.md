# pw-record Plugin

CLI tool: pw-record.

## Commands
- `pw-record <resource> <action>` — Execute pw-record commands
- `pw-record self version` — Print pw-record version
- `pw-record _ _` — Passthrough to pw-record CLI

## Usage Examples
- "pw-record --help"
- "pw-record self version"

## Installation
```bash
apt-get install pw-record 2>/dev/null || which pw-record
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
