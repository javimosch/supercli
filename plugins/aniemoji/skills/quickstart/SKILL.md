# aniemoji Plugin
Lightweight cross-platform emoji list fetcher and viewer

## Commands
- `aniemoji <resource> <action>` — Execute aniemoji commands
- `aniemoji _ _` — Passthrough to aniemoji CLI

## Usage
- `aniemoji _ _ <args>` — Run aniemoji with any arguments
