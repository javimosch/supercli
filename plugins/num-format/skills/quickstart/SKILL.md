# num-format Plugin

num-format — format numbers with separators

## Commands
- `num-format <resource> <action>` — Execute num-format commands
- `num-format self version` — Version

## Installation

```bash
cargo install num-format
Verify: num-format --version
```

## Commands

### `sc num-format self version`

Version


## SuperCLI

```bash
sc num-format _ _ --help
sc plugins learn num-format
```
