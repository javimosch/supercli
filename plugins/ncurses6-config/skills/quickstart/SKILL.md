# ncurses6-config Plugin

CLI tool: ncurses6-config.

## Commands
- `ncurses6-config <resource> <action>` — Execute ncurses6-config commands
- `ncurses6-config self version` — Print ncurses6-config version
- `ncurses6-config _ _` — Passthrough to ncurses6-config CLI

## Usage Examples
- "ncurses6-config --help"
- "ncurses6-config self version"

## Installation
```bash
apt-get install ncurses6-config 2>/dev/null || which ncurses6-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
