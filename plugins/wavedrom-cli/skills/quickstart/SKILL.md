# wavedrom-cli Plugin
Digital timing diagrams from JSON descriptions via CLI

## Commands
- `wavedrom-cli <resource> <action>` — Execute wavedrom-cli commands
- `wavedrom-cli _ _` — Passthrough to wavedrom-cli CLI

## Usage
- `wavedrom-cli _ _ <args>` — Run wavedrom-cli with any arguments
