# mbadblocks Plugin

CLI tool: mbadblocks.

## Commands
- `mbadblocks <resource> <action>` — Execute mbadblocks commands
- `mbadblocks self version` — Print mbadblocks version
- `mbadblocks _ _` — Passthrough to mbadblocks CLI

## Usage Examples
- "mbadblocks --help"
- "mbadblocks self version"

## Installation
```bash
apt-get install mbadblocks 2>/dev/null || which mbadblocks
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
