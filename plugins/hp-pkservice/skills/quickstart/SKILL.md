# hp-pkservice Plugin

CLI tool: hp-pkservice.

## Commands
- `hp-pkservice <resource> <action>` — Execute hp-pkservice commands
- `hp-pkservice self version` — Print hp-pkservice version
- `hp-pkservice _ _` — Passthrough to hp-pkservice CLI

## Usage Examples
- "hp-pkservice --help"
- "hp-pkservice self version"

## Installation
```bash
apt-get install hp-pkservice 2>/dev/null || which hp-pkservice
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
