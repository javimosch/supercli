# helium Plugin

Private, fast, and honest web browser

## Commands

### General
- `helium self version` — Print helium version
- `helium _ _` — Passthrough to helium CLI

## Usage Examples
- "Run helium"
- "Use helium to Private, fast, and honest web browser"

## Installation

```bash
pip install helium
```

## Key Features
- Private, fast, and honest web browser
- CLI tool, headless and scriptable
