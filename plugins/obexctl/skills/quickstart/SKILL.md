# obexctl Plugin

CLI tool: obexctl.

## Commands
- `obexctl <resource> <action>` — Execute obexctl commands
- `obexctl self version` — Print obexctl version
- `obexctl _ _` — Passthrough to obexctl CLI

## Usage Examples
- "obexctl --help"
- "obexctl self version"

## Installation
```bash
apt-get install obexctl 2>/dev/null || which obexctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
