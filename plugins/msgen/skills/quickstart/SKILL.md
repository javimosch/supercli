# msgen Plugin

CLI tool: msgen.

## Commands
- `msgen <resource> <action>` — Execute msgen commands
- `msgen self version` — Print msgen version
- `msgen _ _` — Passthrough to msgen CLI

## Usage Examples
- "msgen --help"
- "msgen self version"

## Installation
```bash
apt-get install msgen 2>/dev/null || which msgen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
