# pnminvert Plugin

CLI tool: pnminvert.

## Commands
- `pnminvert <resource> <action>` — Execute pnminvert commands
- `pnminvert self version` — Print pnminvert version
- `pnminvert _ _` — Passthrough to pnminvert CLI

## Usage Examples
- "pnminvert --help"
- "pnminvert self version"

## Installation
```bash
apt-get install pnminvert 2>/dev/null || which pnminvert
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
