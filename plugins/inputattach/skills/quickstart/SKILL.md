# inputattach Plugin

CLI tool: inputattach.

## Commands
- `inputattach <resource> <action>` — Execute inputattach commands
- `inputattach self version` — Print inputattach version
- `inputattach _ _` — Passthrough to inputattach CLI

## Usage Examples
- "inputattach --help"
- "inputattach self version"

## Installation
```bash
apt-get install inputattach 2>/dev/null || which inputattach
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
