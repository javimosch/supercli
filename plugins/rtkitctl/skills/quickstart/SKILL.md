# rtkitctl Plugin

CLI tool: rtkitctl.

## Commands
- `rtkitctl <resource> <action>` — Execute rtkitctl commands
- `rtkitctl self version` — Print rtkitctl version
- `rtkitctl _ _` — Passthrough to rtkitctl CLI

## Usage Examples
- "rtkitctl --help"
- "rtkitctl self version"

## Installation
```bash
apt-get install rtkitctl 2>/dev/null || which rtkitctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
