# wrmsr Plugin

CLI tool: wrmsr.

## Commands
- `wrmsr <resource> <action>` — Execute wrmsr commands
- `wrmsr self version` — Print wrmsr version
- `wrmsr _ _` — Passthrough to wrmsr CLI

## Usage Examples
- "wrmsr --help"
- "wrmsr self version"

## Installation
```bash
apt-get install wrmsr 2>/dev/null || which wrmsr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
