# VBox Plugin

CLI tool: VBox.

## Commands
- `VBox <resource> <action>` — Execute VBox commands
- `VBox self version` — Print VBox version
- `VBox _ _` — Passthrough to VBox CLI

## Usage Examples
- "VBox --help"
- "VBox self version"

## Installation
```bash
apt-get install VBox 2>/dev/null || which VBox
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
