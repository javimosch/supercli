# w3m
w3m — text-based web browser. Browse web pages in terminal with table and frame support.

## Commands
- `w3m <resource> <action>` — Execute w3m commands
- `w3m w3m run` — w3m — text-based web browser. Browse web pages in terminal with table and frame support.
