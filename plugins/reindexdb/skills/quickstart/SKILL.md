# reindexdb Plugin

CLI tool: reindexdb.

## Commands
- `reindexdb <resource> <action>` — Execute reindexdb commands
- `reindexdb self version` — Print reindexdb version
- `reindexdb _ _` — Passthrough to reindexdb CLI

## Usage Examples
- "reindexdb --help"
- "reindexdb self version"

## Installation
```bash
apt-get install reindexdb 2>/dev/null || which reindexdb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
