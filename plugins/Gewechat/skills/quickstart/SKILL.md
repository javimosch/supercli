# Gewechat Plugin

微信机器人框架，个人微信二次开发，最简单易用的免费二开框架,微信ipad登录（非HOOK破解桌面端）

## Commands

### General
- `Gewechat self version` — Print Gewechat version
- `Gewechat _ _` — Passthrough to gewechat CLI
