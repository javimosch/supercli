# homeshick Plugin
Git-based dotfile synchronizer in bash

## Commands
- `homeshick <resource> <action>` — Execute homeshick commands
- `homeshick _ _` — Passthrough to homeshick CLI

## Usage
- `homeshick _ _ <args>` — Run homeshick with any arguments
