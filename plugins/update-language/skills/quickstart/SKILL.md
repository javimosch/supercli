# update-language Plugin

CLI tool: update-language.

## Commands
- `update-language <resource> <action>` — Execute update-language commands
- `update-language self version` — Print update-language version
- `update-language _ _` — Passthrough to update-language CLI

## Usage Examples
- "update-language --help"
- "update-language self version"

## Installation
```bash
apt-get install update-language 2>/dev/null || which update-language
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
