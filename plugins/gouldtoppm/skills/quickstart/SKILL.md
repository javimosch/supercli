# gouldtoppm Plugin

CLI tool: gouldtoppm.

## Commands
- `gouldtoppm <resource> <action>` — Execute gouldtoppm commands
- `gouldtoppm self version` — Print gouldtoppm version
- `gouldtoppm _ _` — Passthrough to gouldtoppm CLI

## Usage Examples
- "gouldtoppm --help"
- "gouldtoppm self version"

## Installation
```bash
apt-get install gouldtoppm 2>/dev/null || which gouldtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
