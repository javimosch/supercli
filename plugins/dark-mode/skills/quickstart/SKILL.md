# dark-mode Plugin
Toggle macOS dark mode from the command line

## Commands
- `dark-mode <resource> <action>` — Execute dark-mode commands
- `dark-mode _ _` — Passthrough to dark-mode CLI

## Usage
- `dark-mode _ _ <args>` — Run dark-mode with any arguments
