# sprof Plugin

CLI tool: sprof.

## Commands
- `sprof <resource> <action>` — Execute sprof commands
- `sprof self version` — Print sprof version
- `sprof _ _` — Passthrough to sprof CLI

## Usage Examples
- "sprof --help"
- "sprof self version"

## Installation
```bash
apt-get install sprof 2>/dev/null || which sprof
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
