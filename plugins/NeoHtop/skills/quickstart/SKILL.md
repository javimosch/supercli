# NeoHtop Plugin

CLI tool: NeoHtop.

## Commands
- `NeoHtop <resource> <action>` — Execute NeoHtop commands
- `NeoHtop self version` — Print NeoHtop version
- `NeoHtop _ _` — Passthrough to NeoHtop CLI

## Usage Examples
- "NeoHtop --help"
- "NeoHtop self version"

## Installation
```bash
apt-get install NeoHtop 2>/dev/null || which NeoHtop
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
