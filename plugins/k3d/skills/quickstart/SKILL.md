# k3d
k3d — lightweight Kubernetes in Docker. Create single/multi-node k3s clusters for local development.

## Commands
- `k3d <resource> <action>` — Execute k3d commands
- `k3d k3d run` — k3d — lightweight Kubernetes in Docker. Create single/multi-node k3s clusters for local development.
