# ppmtouil Plugin

CLI tool: ppmtouil.

## Commands
- `ppmtouil <resource> <action>` — Execute ppmtouil commands
- `ppmtouil self version` — Print ppmtouil version
- `ppmtouil _ _` — Passthrough to ppmtouil CLI

## Usage Examples
- "ppmtouil --help"
- "ppmtouil self version"

## Installation
```bash
apt-get install ppmtouil 2>/dev/null || which ppmtouil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
