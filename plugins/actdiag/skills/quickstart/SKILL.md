# actdiag Plugin
Generate activity network diagrams from text descriptions

## Commands
- `actdiag <resource> <action>` — Execute actdiag commands
- `actdiag _ _` — Passthrough to actdiag CLI

## Usage
- `actdiag _ _ <args>` — Run actdiag with any arguments
