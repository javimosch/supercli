# lorem-cli Plugin
Generate Lorem Ipsum placeholder text for templates

## Commands
- `lorem-cli <resource> <action>` — Execute lorem-cli commands
- `lorem-cli _ _` — Passthrough to lorem-cli CLI

## Usage
- `lorem-cli _ _ <args>` — Run lorem-cli with any arguments
