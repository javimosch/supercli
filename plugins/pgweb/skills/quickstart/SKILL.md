# pgweb Plugin

pgweb — web-based PostgreSQL database browser written in Go..

## Commands

### `sc pgweb server start`
Start pgweb server with database URL.

### `sc pgweb self version`
Print version.

## Installation

```bash
brew install pgweb
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
