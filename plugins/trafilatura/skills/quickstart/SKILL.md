# trafilatura Plugin
Web scraping and text extraction from HTML pages

## Commands
- `trafilatura <resource> <action>` — Execute trafilatura commands
- `trafilatura _ _` — Passthrough to trafilatura CLI

## Usage
- `trafilatura _ _ <args>` — Run trafilatura with any arguments
