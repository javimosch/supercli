# psjoin Plugin

CLI tool: psjoin.

## Commands
- `psjoin <resource> <action>` — Execute psjoin commands
- `psjoin self version` — Print psjoin version
- `psjoin _ _` — Passthrough to psjoin CLI

## Usage Examples
- "psjoin --help"
- "psjoin self version"

## Installation
```bash
apt-get install psjoin 2>/dev/null || which psjoin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
