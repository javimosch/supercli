# ipmaddr Plugin

CLI tool: ipmaddr.

## Commands
- `ipmaddr <resource> <action>` — Execute ipmaddr commands
- `ipmaddr self version` — Print ipmaddr version
- `ipmaddr _ _` — Passthrough to ipmaddr CLI

## Usage Examples
- "ipmaddr --help"
- "ipmaddr self version"

## Installation
```bash
apt-get install ipmaddr 2>/dev/null || which ipmaddr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
