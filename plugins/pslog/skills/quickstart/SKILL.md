# pslog Plugin

CLI tool: pslog.

## Commands
- `pslog <resource> <action>` — Execute pslog commands
- `pslog self version` — Print pslog version
- `pslog _ _` — Passthrough to pslog CLI

## Usage Examples
- "pslog --help"
- "pslog self version"

## Installation
```bash
apt-get install pslog 2>/dev/null || which pslog
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
