# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `checkpwn <resource> <action>` — Execute checkpwn commands
- `checkpwn self version` — Print checkpwn version
- `checkpwn check account` — Check if account was compromised
- `checkpwn _ _` — Passthrough to checkpwn CLI
