# pgmslice Plugin

CLI tool: pgmslice.

## Commands
- `pgmslice <resource> <action>` — Execute pgmslice commands
- `pgmslice self version` — Print pgmslice version
- `pgmslice _ _` — Passthrough to pgmslice CLI

## Usage Examples
- "pgmslice --help"
- "pgmslice self version"

## Installation
```bash
apt-get install pgmslice 2>/dev/null || which pgmslice
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
