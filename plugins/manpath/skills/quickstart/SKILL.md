# manpath Plugin

CLI tool: manpath.

## Commands
- `manpath <resource> <action>` — Execute manpath commands
- `manpath self version` — Print manpath version
- `manpath _ _` — Passthrough to manpath CLI

## Usage Examples
- "manpath --help"
- "manpath self version"

## Installation
```bash
apt-get install manpath 2>/dev/null || which manpath
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
