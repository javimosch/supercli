# lwp-request Plugin

CLI tool: lwp-request.

## Commands
- `lwp-request <resource> <action>` — Execute lwp-request commands
- `lwp-request self version` — Print lwp-request version
- `lwp-request _ _` — Passthrough to lwp-request CLI

## Usage Examples
- "lwp-request --help"
- "lwp-request self version"

## Installation
```bash
apt-get install lwp-request 2>/dev/null || which lwp-request
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
