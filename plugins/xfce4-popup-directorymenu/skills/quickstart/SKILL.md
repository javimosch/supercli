# xfce4-popup-directorymenu Plugin

xfce4-popup-directorymenu — panel for Xfce4 desktop environment.

## Commands
- `xfce4-popup-directorymenu <resource> <action>` — Execute xfce4-popup-directorymenu commands
- `xfce4-popup-directorymenu self version` — Print xfce4-popup-directorymenu version
- `xfce4-popup-directorymenu _ _` — Passthrough to xfce4-popup-directorymenu CLI

## Usage Examples
- "xfce4-popup-directorymenu --help"
- "xfce4-popup-directorymenu self version"

## Installation
```bash
apt-get install xfce4-panel 2>/dev/null || which xfce4-popup-directorymenu
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
