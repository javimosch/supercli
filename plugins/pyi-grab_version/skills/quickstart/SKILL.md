# pyi-grab_version Plugin

CLI tool: pyi-grab_version.

## Commands
- `pyi-grab_version <resource> <action>` — Execute pyi-grab_version commands
- `pyi-grab_version self version` — Print pyi-grab_version version
- `pyi-grab_version _ _` — Passthrough to pyi-grab_version CLI

- "pyi-grab_version self version"
