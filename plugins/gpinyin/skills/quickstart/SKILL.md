# gpinyin Plugin

CLI tool: gpinyin.

## Commands
- `gpinyin <resource> <action>` — Execute gpinyin commands
- `gpinyin self version` — Print gpinyin version
- `gpinyin _ _` — Passthrough to gpinyin CLI

## Usage Examples
- "gpinyin --help"
- "gpinyin self version"

## Installation
```bash
apt-get install gpinyin 2>/dev/null || which gpinyin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
