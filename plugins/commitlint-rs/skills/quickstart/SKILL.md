# commitlint-rs Plugin
Commit message linter in Rust with config

## Commands
- `commitlint-rs <resource> <action>` — Execute commitlint-rs commands
- `commitlint-rs _ _` — Passthrough to commitlint-rs CLI

## Usage
- `commitlint-rs _ _ <args>` — Run commitlint-rs with any arguments
