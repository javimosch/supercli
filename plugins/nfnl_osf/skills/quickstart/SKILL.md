# nfnl_osf Plugin

CLI tool: nfnl_osf.

## Commands
- `nfnl_osf <resource> <action>` — Execute nfnl_osf commands
- `nfnl_osf self version` — Print nfnl_osf version
- `nfnl_osf _ _` — Passthrough to nfnl_osf CLI

## Usage Examples
- "nfnl_osf --help"
- "nfnl_osf self version"

## Installation
```bash
apt-get install nfnl_osf 2>/dev/null || which nfnl_osf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
