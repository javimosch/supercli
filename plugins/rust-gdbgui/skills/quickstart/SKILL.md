# rust-gdbgui Plugin

CLI tool: rust-gdbgui.

## Commands
- `rust-gdbgui <resource> <action>` — Execute rust-gdbgui commands
- `rust-gdbgui self version` — Print rust-gdbgui version
- `rust-gdbgui _ _` — Passthrough to rust-gdbgui CLI

## Usage Examples
- "rust-gdbgui --help"
- "rust-gdbgui self version"

## Installation
```bash
cargo install rust-gdbgui
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- rust based
