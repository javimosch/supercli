# pnmcolormap Plugin

CLI tool: pnmcolormap.

## Commands
- `pnmcolormap <resource> <action>` — Execute pnmcolormap commands
- `pnmcolormap self version` — Print pnmcolormap version
- `pnmcolormap _ _` — Passthrough to pnmcolormap CLI

## Usage Examples
- "pnmcolormap --help"
- "pnmcolormap self version"

## Installation
```bash
apt-get install pnmcolormap 2>/dev/null || which pnmcolormap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
