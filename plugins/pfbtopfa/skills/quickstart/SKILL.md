# pfbtopfa Plugin

CLI tool: pfbtopfa.

## Commands
- `pfbtopfa <resource> <action>` — Execute pfbtopfa commands
- `pfbtopfa self version` — Print pfbtopfa version
- `pfbtopfa _ _` — Passthrough to pfbtopfa CLI

## Usage Examples
- "pfbtopfa --help"
- "pfbtopfa self version"

## Installation
```bash
apt-get install pfbtopfa 2>/dev/null || which pfbtopfa
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
