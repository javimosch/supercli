# pdfmom Plugin

CLI tool: pdfmom.

## Commands
- `pdfmom <resource> <action>` — Execute pdfmom commands
- `pdfmom self version` — Print pdfmom version
- `pdfmom _ _` — Passthrough to pdfmom CLI

## Usage Examples
- "pdfmom --help"
- "pdfmom self version"

## Installation
```bash
apt-get install pdfmom 2>/dev/null || which pdfmom
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
