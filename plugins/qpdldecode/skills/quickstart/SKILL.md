# qpdldecode Plugin

CLI tool: qpdldecode.

## Commands
- `qpdldecode <resource> <action>` — Execute qpdldecode commands
- `qpdldecode self version` — Print qpdldecode version
- `qpdldecode _ _` — Passthrough to qpdldecode CLI

## Usage Examples
- "qpdldecode --help"
- "qpdldecode self version"

## Installation
```bash
apt-get install qpdldecode 2>/dev/null || which qpdldecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
