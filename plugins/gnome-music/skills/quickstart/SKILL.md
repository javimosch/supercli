# gnome-music Plugin

CLI tool: gnome-music.

## Commands
- `gnome-music <resource> <action>` — Execute gnome-music commands
- `gnome-music self version` — Print gnome-music version
- `gnome-music _ _` — Passthrough to gnome-music CLI

## Usage Examples
- "gnome-music --help"
- "gnome-music self version"

## Installation
```bash
apt-get install gnome-music 2>/dev/null || which gnome-music
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
