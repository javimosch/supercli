# zsh-4 Plugin

Zsh shell (4.x series)

## Commands
- `zsh-4 <resource> <action>` — Execute zsh-4 commands
- `zsh-4 self version` — Version

## Installation

```bash
brew install zsh-4
Verify: zsh-4 --version
```

## Commands

### `sc zsh-4 self version`

Version

sc zsh-4 _ _ --help
