# getcli Plugin

CLI package manager and bootstrap layer for AI coding agents

## Commands
- `getcli self version` — Print getcli version
- `getcli _ _` — Passthrough to getcli CLI

## Usage Examples
- `getcli self version` — Check installed version
- `getcli _ _ --help` — Show getcli help
- `getcli _ _ --json` — JSON output mode

## Installation
```bash
cargo install getcli
```

## Key Features
- cli, ai-agents, package-manager
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
