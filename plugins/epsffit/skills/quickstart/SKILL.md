# epsffit Plugin

CLI tool: epsffit.

## Commands
- `epsffit <resource> <action>` — Execute epsffit commands
- `epsffit self version` — Print epsffit version
- `epsffit _ _` — Passthrough to epsffit CLI

## Usage Examples
- "epsffit --help"
- "epsffit self version"

## Installation
```bash
apt-get install epsffit 2>/dev/null || which epsffit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
