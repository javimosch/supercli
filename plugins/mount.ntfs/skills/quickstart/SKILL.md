# mount.ntfs Plugin

CLI tool: mount.ntfs.

## Commands
- `mount.ntfs <resource> <action>` — Execute mount.ntfs commands
- `mount.ntfs self version` — Print mount.ntfs version
- `mount.ntfs _ _` — Passthrough to mount.ntfs CLI

## Usage Examples
- "mount.ntfs --help"
- "mount.ntfs self version"

## Installation
```bash
apt-get install mount.ntfs 2>/dev/null || which mount.ntfs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
