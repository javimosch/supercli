# cron-manager Plugin
Centralized cron job management using JSON configuration

## Commands
- `cron-manager <resource> <action>` — Execute cron-manager commands
- `cron-manager _ _` — Passthrough to cron-manager CLI

## Usage
- `cron-manager _ _ <args>` — Run cron-manager with any arguments
