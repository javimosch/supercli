# gsf-vba-dump Plugin

CLI tool: gsf-vba-dump.

## Commands
- `gsf-vba-dump <resource> <action>` — Execute gsf-vba-dump commands
- `gsf-vba-dump self version` — Print gsf-vba-dump version
- `gsf-vba-dump _ _` — Passthrough to gsf-vba-dump CLI

## Usage Examples
- "gsf-vba-dump --help"
- "gsf-vba-dump self version"

## Installation
```bash
apt-get install gsf-vba-dump 2>/dev/null || which gsf-vba-dump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
