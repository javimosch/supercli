# ghx Plugin

Agent-first GitHub code exploration — GraphQL batching, code maps, 92% token reduction

## Commands
- `ghx self version` — Print ghx version
- `ghx _ _` — Passthrough to ghx CLI

## Usage Examples
- `ghx self version` — Check installed version
- `ghx _ _ --help` — Show ghx help
- `ghx _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/gkoreli/ghx/v2/cmd/ghx@latest
```

## Key Features
- github, code-exploration, ai-agents, golang
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
