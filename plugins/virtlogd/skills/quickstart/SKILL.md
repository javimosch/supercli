# virtlogd Plugin

CLI tool: virtlogd.

## Commands
- `virtlogd <resource> <action>` — Execute virtlogd commands
- `virtlogd self version` — Print virtlogd version
- `virtlogd _ _` — Passthrough to virtlogd CLI

## Usage Examples
- "virtlogd --help"
- "virtlogd self version"

## Installation
```bash
apt-get install virtlogd 2>/dev/null || which virtlogd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
