# ldapexop Plugin

CLI tool: ldapexop.

## Commands
- `ldapexop <resource> <action>` — Execute ldapexop commands
- `ldapexop self version` — Print ldapexop version
- `ldapexop _ _` — Passthrough to ldapexop CLI

## Usage Examples
- "ldapexop --help"
- "ldapexop self version"

## Installation
```bash
apt-get install ldapexop 2>/dev/null || which ldapexop
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
