# xdg-open Plugin

CLI tool: xdg-open.

## Commands
- `xdg-open <resource> <action>` — Execute xdg-open commands
- `xdg-open self version` — Print xdg-open version
- `xdg-open _ _` — Passthrough to xdg-open CLI

## Usage Examples
- "xdg-open --help"
- "xdg-open self version"

## Installation
```bash
apt-get install xdg-open 2>/dev/null || which xdg-open
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
