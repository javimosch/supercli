# zio Plugin

Async I/O framework for Zig

## Commands

### General
- `zio self version` — Print zio version
- `zio _ _` — Passthrough to zio CLI

## Usage Examples
- "Run zio"
- "Use zio to Async I/O framework for Zig"

## Installation

```bash
pip install zio
```

## Key Features
- Async I/O framework for Zig
- CLI tool, headless and scriptable
