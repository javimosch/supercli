# zio Plugin

Async I/O framework for Zig

## Commands

### Version
`zio self version` — Print zio version

### Passthrough
`zio _ _` — Passthrough to zio CLI with all arguments forwarded.

## Usage Examples

```bash
zio --version
zio --help
```

## Installation

```bash
cargo install zio
```

## Key Features
- Async I/O framework for Zig
