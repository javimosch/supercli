# pptpsetup Plugin

CLI tool: pptpsetup.

## Commands
- `pptpsetup <resource> <action>` — Execute pptpsetup commands
- `pptpsetup self version` — Print pptpsetup version
- `pptpsetup _ _` — Passthrough to pptpsetup CLI

## Usage Examples
- "pptpsetup --help"
- "pptpsetup self version"

## Installation
```bash
apt-get install pptpsetup 2>/dev/null || which pptpsetup
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
