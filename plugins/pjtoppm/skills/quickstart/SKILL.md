# pjtoppm Plugin

CLI tool: pjtoppm.

## Commands
- `pjtoppm <resource> <action>` — Execute pjtoppm commands
- `pjtoppm self version` — Print pjtoppm version
- `pjtoppm _ _` — Passthrough to pjtoppm CLI

## Usage Examples
- "pjtoppm --help"
- "pjtoppm self version"

## Installation
```bash
apt-get install pjtoppm 2>/dev/null || which pjtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
