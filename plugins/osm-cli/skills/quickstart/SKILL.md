# osm-cli Plugin
Interact with the OpenStreetMap API for nodes ways and relations

## Commands
- `osm-cli <resource> <action>` — Execute osm-cli commands
- `osm-cli _ _` — Passthrough to osm-cli CLI

## Usage
- `osm-cli _ _ <args>` — Run osm-cli with any arguments
