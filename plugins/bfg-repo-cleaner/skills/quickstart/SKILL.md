# bfg-repo-cleaner Plugin
Remove large files and secrets from Git history

## Commands
- `bfg-repo-cleaner <resource> <action>` — Execute bfg-repo-cleaner commands
- `bfg-repo-cleaner _ _` — Passthrough to bfg CLI

## Usage
- `bfg-repo-cleaner _ _ <args>` — Run bfg with any arguments
