# patchright Plugin

CLI tool: patchright.

## Commands
- `patchright <resource> <action>` — Execute patchright commands
- `patchright self version` — Print patchright version
- `patchright _ _` — Passthrough to patchright CLI

## Usage Examples
- "patchright --help"
- "patchright self version"

## Installation
```bash
apt-get install patchright 2>/dev/null || which patchright
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
