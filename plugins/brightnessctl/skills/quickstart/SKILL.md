# brightnessctl Plugin

brightnessctl controls display backlight brightness.

## Usage Examples

- "get current brightness level"
- "set brightness to 50 percent"
- "increase brightness by 10 percent"
- "save current brightness for restore"

## Installation

```bash
brew install brightnessctl
```

## Key Features
- Display brightness read and set
- Percentage-based and absolute control
- Step-based adjustments (inc/dec)
- Min/max brightness querying
- Multiple device support (internal/external)
