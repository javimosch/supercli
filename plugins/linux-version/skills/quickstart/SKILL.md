# linux-version Plugin

CLI tool: linux-version.

## Commands
- `linux-version <resource> <action>` — Execute linux-version commands
- `linux-version self version` — Print linux-version version
- `linux-version _ _` — Passthrough to linux-version CLI

## Usage Examples
- "linux-version --help"
- "linux-version self version"

## Installation
```bash
apt-get install linux-version 2>/dev/null || which linux-version
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
