# Autocli Plugin

Fetch information from any website with a single command, covering 55+ sites

## Commands
- `autocli _ _` — Passthrough to autocli CLI

## Installation

```bash
cargo install autocli
```

## Examples
```bash
autocli --help
autocli --version
```
