# qemu-system-i386 Plugin

CLI tool: qemu-system-i386.

## Commands
- `qemu-system-i386 <resource> <action>` — Execute qemu-system-i386 commands
- `qemu-system-i386 self version` — Print qemu-system-i386 version
- `qemu-system-i386 _ _` — Passthrough to qemu-system-i386 CLI

## Usage Examples
- "qemu-system-i386 --help"
- "qemu-system-i386 self version"

```bash
apt-get install qemu-system-i386 2>/dev/null || which qemu-system-i386
```
