# mdsq Plugin
Query Markdown files using a SQL-like syntax

## Commands
- `mdsq <resource> <action>` — Execute mdsq commands
- `mdsq _ _` — Passthrough to mdsq CLI

## Usage
- `mdsq _ _ <args>` — Run mdsq with any arguments
