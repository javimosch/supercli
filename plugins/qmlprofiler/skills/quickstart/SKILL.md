# qmlprofiler Plugin

CLI tool: qmlprofiler.

## Commands
- `qmlprofiler <resource> <action>` — Execute qmlprofiler commands
- `qmlprofiler self version` — Print qmlprofiler version
- `qmlprofiler _ _` — Passthrough to qmlprofiler CLI

## Usage Examples
- "qmlprofiler --help"
- "qmlprofiler self version"

## Installation
```bash
apt-get install qmlprofiler 2>/dev/null || which qmlprofiler
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
