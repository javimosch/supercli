# iptunnel Plugin

CLI tool: iptunnel.

## Commands
- `iptunnel <resource> <action>` — Execute iptunnel commands
- `iptunnel self version` — Print iptunnel version
- `iptunnel _ _` — Passthrough to iptunnel CLI

## Usage Examples
- "iptunnel --help"
- "iptunnel self version"

## Installation
```bash
apt-get install iptunnel 2>/dev/null || which iptunnel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
