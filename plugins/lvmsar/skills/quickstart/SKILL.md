# lvmsar Plugin

CLI tool: lvmsar.

## Commands
- `lvmsar <resource> <action>` — Execute lvmsar commands
- `lvmsar self version` — Print lvmsar version
- `lvmsar _ _` — Passthrough to lvmsar CLI

## Usage Examples
- "lvmsar --help"
- "lvmsar self version"

## Installation
```bash
apt-get install lvmsar 2>/dev/null || which lvmsar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
