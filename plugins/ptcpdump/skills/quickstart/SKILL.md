# ptcpdump Plugin

Process-aware, eBPF-based tcpdump

## Commands

### General
- `ptcpdump self version` — Print ptcpdump version
- `ptcpdump _ _` — Passthrough to ptcpdump CLI

```bash
pip install ptcpdump
```

## Key Features
- Process-aware, eBPF-based tcpdump
- CLI tool, headless and scriptable
