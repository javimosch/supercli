# bore Quickstart

Simple CLI tool for making tunnels to localhost

## Commands
- `bore <resource> <action>` — Execute bore commands
- `bore local expose` — Expose local port to remote server
- `bore server start` — Start bore server

## Installation

```bash
cargo install bore-cli
```

## Quick Examples

```bash
# Check version
bore --version

# Get help
bore --help
```
