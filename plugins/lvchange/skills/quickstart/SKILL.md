# lvchange Plugin

CLI tool: lvchange.

## Commands
- `lvchange <resource> <action>` — Execute lvchange commands
- `lvchange self version` — Print lvchange version
- `lvchange _ _` — Passthrough to lvchange CLI

## Usage Examples
- "lvchange --help"
- "lvchange self version"

## Installation
```bash
apt-get install lvchange 2>/dev/null || which lvchange
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
