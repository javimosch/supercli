# ziex Plugin

Full-stack web framework for Zig. HTML syntax within Zig code, just like JSX but for Zig!

## Commands

### General
- `ziex self version` — Print ziex version
- `ziex _ _` — Passthrough to ziex CLI

## Usage Examples
- "Run ziex"
- "Use ziex to Full-stack web framework for Zig. HTML syntax within Zig cod"

## Installation

```bash
pip install ziex
```

## Key Features
- Full-stack web framework for Zig. HTML syntax within Zig code, just like JSX but for Zig!
- CLI tool, headless and scriptable
