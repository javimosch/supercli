# odvitype Plugin

CLI tool: odvitype.

## Commands
- `odvitype <resource> <action>` — Execute odvitype commands
- `odvitype self version` — Print odvitype version
- `odvitype _ _` — Passthrough to odvitype CLI

## Usage Examples
- "odvitype --help"
- "odvitype self version"

## Installation
```bash
apt-get install odvitype 2>/dev/null || which odvitype
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
