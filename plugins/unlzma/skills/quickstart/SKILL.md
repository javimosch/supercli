# unlzma Plugin

CLI tool: unlzma.

## Commands
- `unlzma <resource> <action>` — Execute unlzma commands
- `unlzma self version` — Print unlzma version
- `unlzma _ _` — Passthrough to unlzma CLI

## Usage Examples
- "unlzma --help"
- "unlzma self version"

## Installation
```bash
apt-get install unlzma 2>/dev/null || which unlzma
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
