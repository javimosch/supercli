# zipdetails Plugin

CLI tool: zipdetails.

## Commands
- `zipdetails <resource> <action>` — Execute zipdetails commands
- `zipdetails self version` — Print zipdetails version
- `zipdetails _ _` — Passthrough to zipdetails CLI

## Usage Examples
- "zipdetails --help"
- "zipdetails self version"

## Installation
```bash
apt-get install zipdetails 2>/dev/null || which zipdetails
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
