# word-cli Plugin
Look up word definitions from the command line

## Commands
- `word-cli <resource> <action>` — Execute word-cli commands
- `word-cli _ _` — Passthrough to word-cli CLI

## Usage
- `word-cli _ _ <args>` — Run word-cli with any arguments
