# ai-observer Plugin
Self-hosted AI tool observability.
## Commands
- `ai-observer _ _` — Passthrough to ai-observer CLI
## Installation
```bash
go install github.com/tobilg/ai-observer@latest
```
## Key Features
- **AI observability** — Monitor coding CLIs
- **Self-hosted** — Your data, your control
- **Structured output** — Telemetry data
