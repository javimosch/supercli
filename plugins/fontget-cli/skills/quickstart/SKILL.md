# fontget-cli Plugin
Tiny CLI manager to discover and install system fonts

## Commands
- `fontget-cli <resource> <action>` — Execute fontget-cli commands
- `fontget-cli _ _` — Passthrough to fontget-cli CLI

## Usage
- `fontget-cli _ _ <args>` — Run fontget-cli with any arguments
