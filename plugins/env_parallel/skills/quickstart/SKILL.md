# env_parallel Plugin

CLI tool: env_parallel.

## Commands
- `env_parallel <resource> <action>` — Execute env_parallel commands
- `env_parallel self version` — Print env_parallel version
- `env_parallel _ _` — Passthrough to env_parallel CLI

## Usage Examples
- "env_parallel --help"
- "env_parallel self version"

## Installation
```bash
apt-get install env_parallel 2>/dev/null || which env_parallel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
