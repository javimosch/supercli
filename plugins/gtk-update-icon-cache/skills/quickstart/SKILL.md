# gtk-update-icon-cache Plugin

CLI tool: gtk-update-icon-cache.

## Commands
- `gtk-update-icon-cache <resource> <action>` — Execute gtk-update-icon-cache commands
- `gtk-update-icon-cache self version` — Print gtk-update-icon-cache version
- `gtk-update-icon-cache _ _` — Passthrough to gtk-update-icon-cache CLI

## Usage Examples

- "gtk-update-icon-cache self version"

apt-get install gtk-update-icon-cache 2>/dev/null || which gtk-update-icon-cache
