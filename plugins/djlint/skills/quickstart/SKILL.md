# djlint Plugin
HTML template formatter and linter for Django/Jinja

## Commands
- `djlint <resource> <action>` — Execute djlint commands
- `djlint _ _` — Passthrough to djlint CLI

## Usage
- `djlint _ _ <args>` — Run djlint with any arguments
