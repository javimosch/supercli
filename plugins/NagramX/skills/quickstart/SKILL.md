# NagramX Plugin

A variant of Nagram with additional features.

## Commands

### General
- `NagramX self version` — Print NagramX version
- `NagramX _ _` — Passthrough to nagramx CLI

## Usage Examples
- "Run NagramX"
- "Use nagramx to A variant of Nagram with additional features."

## Installation

```bash
pip install nagramx
```

## Key Features
- A variant of Nagram with additional features.
- CLI tool, headless and scriptable
