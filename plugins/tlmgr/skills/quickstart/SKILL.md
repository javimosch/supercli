# tlmgr Plugin

CLI tool: tlmgr.

## Commands
- `tlmgr <resource> <action>` — Execute tlmgr commands
- `tlmgr self version` — Print tlmgr version
- `tlmgr _ _` — Passthrough to tlmgr CLI

## Usage Examples
- "tlmgr --help"
- "tlmgr self version"

## Installation
```bash
apt-get install tlmgr 2>/dev/null || which tlmgr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
