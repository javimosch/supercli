# sql Plugin

CLI tool: sql.

## Commands
- `sql <resource> <action>` — Execute sql commands
- `sql self version` — Print sql version
- `sql _ _` — Passthrough to sql CLI

## Usage Examples
- "sql --help"
- "sql self version"

## Installation
```bash
apt-get install sql 2>/dev/null || which sql
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
