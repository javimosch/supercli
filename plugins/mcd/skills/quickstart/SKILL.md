# mcd Plugin

CLI tool: mcd.

## Commands
- `mcd <resource> <action>` — Execute mcd commands
- `mcd self version` — Print mcd version
- `mcd _ _` — Passthrough to mcd CLI

## Usage Examples
- "mcd --help"
- "mcd self version"

## Installation
```bash
apt-get install mcd 2>/dev/null || which mcd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
