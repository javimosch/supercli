# pnm2ppa Plugin

CLI tool: pnm2ppa.

## Commands
- `pnm2ppa <resource> <action>` — Execute pnm2ppa commands
- `pnm2ppa self version` — Print pnm2ppa version
- `pnm2ppa _ _` — Passthrough to pnm2ppa CLI

## Usage Examples
- "pnm2ppa --help"
- "pnm2ppa self version"

## Installation
```bash
apt-get install pnm2ppa 2>/dev/null || which pnm2ppa
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
