# lvconvert Plugin

CLI tool: lvconvert.

## Commands
- `lvconvert <resource> <action>` — Execute lvconvert commands
- `lvconvert self version` — Print lvconvert version
- `lvconvert _ _` — Passthrough to lvconvert CLI

## Usage Examples
- "lvconvert --help"
- "lvconvert self version"

## Installation
```bash
apt-get install lvconvert 2>/dev/null || which lvconvert
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
