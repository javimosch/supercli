# jpgicc Plugin

CLI tool: jpgicc.

## Commands
- `jpgicc <resource> <action>` — Execute jpgicc commands
- `jpgicc self version` — Print jpgicc version
- `jpgicc _ _` — Passthrough to jpgicc CLI

## Usage Examples
- "jpgicc --help"
- "jpgicc self version"

## Installation
```bash
apt-get install jpgicc 2>/dev/null || which jpgicc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
