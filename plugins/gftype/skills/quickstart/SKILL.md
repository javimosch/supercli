# gftype Plugin

CLI tool: gftype.

## Commands
- `gftype <resource> <action>` — Execute gftype commands
- `gftype self version` — Print gftype version
- `gftype _ _` — Passthrough to gftype CLI

## Usage Examples
- "gftype --help"
- "gftype self version"

## Installation
```bash
apt-get install gftype 2>/dev/null || which gftype
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
