# XMLStarlet Plugin

XMLStarlet is a command-line toolkit for XML processing. Supports XPath queries, XSLT transformations, XML validation, and namespace-aware editing.

## Commands

- `xmlstarlet _ _ <args>` — Passthrough

## Usage Examples

- "query an XML file for all book titles using XPath"
- "transform an XML document using an XSLT stylesheet"
- "validate an XML file against an XSD schema"
- "edit an XML file and update an attribute value"

## Installation

```bash
brew install xmlstarlet
```

## Key Features
- XPath query support for XML document traversal
- XSLT transformation engine
- XML Schema (XSD) validation
- XML document editing (add, delete, update, rename)
- XInclude resolution
- Namespace-aware operations
- Format/pretty-print XML output
- XML canonicalization and diff
- Batch processing support for multiple files
