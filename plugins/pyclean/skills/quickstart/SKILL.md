# pyclean Plugin

CLI tool: pyclean.

## Commands
- `pyclean <resource> <action>` — Execute pyclean commands
- `pyclean self version` — Print pyclean version
- `pyclean _ _` — Passthrough to pyclean CLI

## Usage Examples
- "pyclean --help"
- "pyclean self version"

## Installation
```bash
apt-get install pyclean 2>/dev/null || which pyclean
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
