# twscrape Plugin

CLI tool: twscrape.

## Commands
- `twscrape <resource> <action>` — Execute twscrape commands
- `twscrape self version` — Print twscrape version
- `twscrape _ _` — Passthrough to twscrape CLI

## Usage Examples
- "twscrape --help"
- "twscrape self version"

## Installation
```bash
apt-get install twscrape 2>/dev/null || which twscrape
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
