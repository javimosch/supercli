# ybmtopbm Plugin

CLI tool: ybmtopbm.

## Commands
- `ybmtopbm <resource> <action>` — Execute ybmtopbm commands
- `ybmtopbm self version` — Print ybmtopbm version
- `ybmtopbm _ _` — Passthrough to ybmtopbm CLI

## Usage Examples
- "ybmtopbm --help"
- "ybmtopbm self version"

## Installation
```bash
apt-get install ybmtopbm 2>/dev/null || which ybmtopbm
```

- Pipeline-ready output
