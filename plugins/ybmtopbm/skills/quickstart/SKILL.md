# ybmtopbm Plugin

ybmtopbm — Graphics conversion tools between image formats.

## Commands
- `ybmtopbm <resource> <action>` — Execute ybmtopbm commands
- `ybmtopbm self version` — Print ybmtopbm version
- `ybmtopbm _ _` — Passthrough to ybmtopbm CLI

## Usage Examples
- "ybmtopbm --help"
- "ybmtopbm self version"

## Installation
```bash
apt-get install netpbm 2>/dev/null || which ybmtopbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
