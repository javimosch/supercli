# sntp Plugin

CLI tool: sntp.

## Commands
- `sntp <resource> <action>` — Execute sntp commands
- `sntp self version` — Print sntp version
- `sntp _ _` — Passthrough to sntp CLI

## Usage Examples
- "sntp --help"
- "sntp self version"

## Installation
```bash
apt-get install sntp 2>/dev/null || which sntp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
