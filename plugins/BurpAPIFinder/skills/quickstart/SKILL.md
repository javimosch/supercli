# BurpAPIFinder Plugin

攻防演练过程中，我们通常会用浏览器访问一些资产，但很多未授权/敏感信息/越权隐匿在已访问接口过html、JS文件等，该插件能让我们发现未授权/敏感信息/越权/登陆接口等。

## Commands

### General
- `BurpAPIFinder self version` — Print BurpAPIFinder version
- `BurpAPIFinder _ _` — Passthrough to burpapifinder CLI
