# osage Plugin

CLI tool: osage.

## Commands
- `osage <resource> <action>` — Execute osage commands
- `osage self version` — Print osage version
- `osage _ _` — Passthrough to osage CLI

## Usage Examples
- "osage --help"
- "osage self version"

## Installation
```bash
apt-get install osage 2>/dev/null || which osage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
