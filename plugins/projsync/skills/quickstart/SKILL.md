# projsync Plugin

CLI tool: projsync.

## Commands
- `projsync <resource> <action>` — Execute projsync commands
- `projsync self version` — Print projsync version
- `projsync _ _` — Passthrough to projsync CLI

## Usage Examples
- "projsync --help"
- "projsync self version"

## Installation
```bash
apt-get install projsync 2>/dev/null || which projsync
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
