# influxdb-cli
influxdb-cli — InfluxDB CLI client. Query time-series data, manage buckets, write data from command line.

## Commands
- `influxdb-cli <resource> <action>` — Execute influxdb-cli commands
- `influxdb cli run` — influxdb-cli — InfluxDB CLI client. Query time-series data, manage buckets, write data from command line.
