# skidl Plugin
Describe electronic circuits using Python code instead of schematic editors

## Commands
- `skidl <resource> <action>` — Execute skidl commands
- `skidl _ _` — Passthrough to skidl CLI

## Usage
- `skidl _ _ <args>` — Run skidl with any arguments
