# fzf-bin Plugin

fzf — command-line fuzzy finder

## Commands
- `fzf-bin <resource> <action>` — Execute fzf-bin commands
- `fzf-bin self version` — Version

## Installation

```bash
brew install fzf-bin
Verify: fzf-bin --version
```

## Commands

### `sc fzf-bin self version`

Version


## SuperCLI

```bash
sc fzf-bin _ _ --help
sc plugins learn fzf-bin
```
