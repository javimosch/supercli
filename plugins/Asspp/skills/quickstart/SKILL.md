# Asspp Plugin

The App Store for your multi-account eco system.

## Commands

### General
- `Asspp self version` — Print Asspp version
- `Asspp _ _` — Passthrough to asspp CLI

## Usage Examples
- "Run Asspp"
- "Use asspp to The App Store for your multi-account eco system."

## Installation

```bash
pip install asspp
```

- The App Store for your multi-account eco system.
