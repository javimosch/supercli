# vboxbugreport Plugin

CLI tool: vboxbugreport.

## Commands
- `vboxbugreport <resource> <action>` — Execute vboxbugreport commands
- `vboxbugreport self version` — Print vboxbugreport version
- `vboxbugreport _ _` — Passthrough to vboxbugreport CLI

## Usage Examples
- "vboxbugreport --help"
- "vboxbugreport self version"

## Installation
```bash
apt-get install vboxbugreport 2>/dev/null || which vboxbugreport
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
