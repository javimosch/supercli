# opencode-cli Plugin

CLI tool: opencode-cli.

## Commands
- `opencode-cli <resource> <action>` — Execute opencode-cli commands
- `opencode-cli self version` — Print opencode-cli version
- `opencode-cli _ _` — Passthrough to opencode-cli CLI

## Usage Examples
- "opencode-cli --help"
- "opencode-cli self version"

## Installation
```bash
apt-get install opencode-cli 2>/dev/null || which opencode-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
