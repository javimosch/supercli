# infotocap Plugin

CLI tool: infotocap.

## Commands
- `infotocap <resource> <action>` — Execute infotocap commands
- `infotocap self version` — Print infotocap version
- `infotocap _ _` — Passthrough to infotocap CLI

## Usage Examples
- "infotocap --help"
- "infotocap self version"

## Installation
```bash
apt-get install infotocap 2>/dev/null || which infotocap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
