# gtts-cli Plugin

CLI tool: gtts-cli.

## Commands
- `gtts-cli <resource> <action>` — Execute gtts-cli commands
- `gtts-cli self version` — Print gtts-cli version
- `gtts-cli _ _` — Passthrough to gtts-cli CLI

## Usage Examples
- "gtts-cli --help"
- "gtts-cli self version"

## Installation
```bash
apt-get install gtts-cli 2>/dev/null || which gtts-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
