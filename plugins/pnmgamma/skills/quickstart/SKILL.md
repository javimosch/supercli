# pnmgamma Plugin

CLI tool: pnmgamma.

## Commands
- `pnmgamma <resource> <action>` — Execute pnmgamma commands
- `pnmgamma self version` — Print pnmgamma version
- `pnmgamma _ _` — Passthrough to pnmgamma CLI

## Usage Examples
- "pnmgamma --help"
- "pnmgamma self version"

## Installation
```bash
apt-get install pnmgamma 2>/dev/null || which pnmgamma
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
