# infocmp Plugin

CLI tool: infocmp.

## Commands
- `infocmp <resource> <action>` — Execute infocmp commands
- `infocmp self version` — Print infocmp version
- `infocmp _ _` — Passthrough to infocmp CLI

## Usage Examples
- "infocmp --help"
- "infocmp self version"

## Installation
```bash
apt-get install infocmp 2>/dev/null || which infocmp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
