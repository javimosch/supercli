# xfce4-screensaver-command Plugin

CLI tool: xfce4-screensaver-command.

## Commands
- `xfce4-screensaver-command <resource> <action>` — Execute xfce4-screensaver-command commands
- `xfce4-screensaver-command self version` — Print xfce4-screensaver-command version
- `xfce4-screensaver-command _ _` — Passthrough to xfce4-screensaver-command CLI

## Usage Examples
- "xfce4-screensaver-command --help"
- "xfce4-screensaver-command self version"

## Installation
```bash
apt-get install xfce4-screensaver-command 2>/dev/null || which xfce4-screensaver-command
```
