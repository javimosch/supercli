# open-lovable Plugin

🔥 Clone and recreate any website as a modern React app in seconds

## Commands

### General
- `open-lovable self version` — Print open-lovable version
- `open-lovable _ _` — Passthrough to open-lovable CLI

## Usage Examples
- "Run open-lovable"
- "Use open-lovable to 🔥 Clone and recreate any website as a modern React app in se"

## Installation

```bash
pip install open-lovable
```

## Key Features
- 🔥 Clone and recreate any website as a modern React app in seconds
- CLI tool, headless and scriptable
