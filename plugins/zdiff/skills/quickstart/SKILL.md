# zdiff Plugin

CLI tool: zdiff.

## Commands
- `zdiff <resource> <action>` — Execute zdiff commands
- `zdiff self version` — Print zdiff version
- `zdiff _ _` — Passthrough to zdiff CLI

## Usage Examples
- "zdiff --help"
- "zdiff self version"

## Installation
```bash
apt-get install zdiff 2>/dev/null || which zdiff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
