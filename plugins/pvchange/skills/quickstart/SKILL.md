# pvchange Plugin

CLI tool: pvchange.

## Commands
- `pvchange <resource> <action>` — Execute pvchange commands
- `pvchange self version` — Print pvchange version
- `pvchange _ _` — Passthrough to pvchange CLI

## Usage Examples
- "pvchange --help"
- "pvchange self version"

## Installation
```bash
apt-get install pvchange 2>/dev/null || which pvchange
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
