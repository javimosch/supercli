# pax11publish Plugin

CLI tool: pax11publish.

## Commands
- `pax11publish <resource> <action>` — Execute pax11publish commands
- `pax11publish self version` — Print pax11publish version
- `pax11publish _ _` — Passthrough to pax11publish CLI

## Usage Examples
- "pax11publish --help"
- "pax11publish self version"

apt-get install pax11publish 2>/dev/null || which pax11publish
