# numfmt Plugin
Convert numbers to human-readable format

## Commands
- `numfmt <resource> <action>` — Execute numfmt commands
- `numfmt self version` — Print numfmt version
- `numfmt _ _` — Passthrough to numfmt CLI

## Usage
- `numfmt _ _ <args>` — Run numfmt with any arguments
