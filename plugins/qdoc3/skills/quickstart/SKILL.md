# qdoc3 Plugin

CLI tool: qdoc3.

## Commands
- `qdoc3 <resource> <action>` — Execute qdoc3 commands
- `qdoc3 self version` — Print qdoc3 version
- `qdoc3 _ _` — Passthrough to qdoc3 CLI

## Usage Examples
- "qdoc3 --help"
- "qdoc3 self version"

## Installation
```bash
apt-get install qdoc3 2>/dev/null || which qdoc3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
