# dvitodvi Plugin

CLI tool: dvitodvi.

## Commands
- `dvitodvi <resource> <action>` — Execute dvitodvi commands
- `dvitodvi self version` — Print dvitodvi version
- `dvitodvi _ _` — Passthrough to dvitodvi CLI

## Usage Examples
- "dvitodvi --help"
- "dvitodvi self version"

## Installation
```bash
apt-get install dvitodvi 2>/dev/null || which dvitodvi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
