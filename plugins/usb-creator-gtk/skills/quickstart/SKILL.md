# usb-creator-gtk Plugin

CLI tool: usb-creator-gtk.

## Commands
- `usb-creator-gtk <resource> <action>` — Execute usb-creator-gtk commands
- `usb-creator-gtk self version` — Print usb-creator-gtk version
- `usb-creator-gtk _ _` — Passthrough to usb-creator-gtk CLI

## Usage Examples
- "usb-creator-gtk --help"
- "usb-creator-gtk self version"

## Installation
```bash
apt-get install usb-creator-gtk 2>/dev/null || which usb-creator-gtk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
