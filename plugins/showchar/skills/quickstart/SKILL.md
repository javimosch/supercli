# showchar Plugin

CLI tool: showchar.

## Commands
- `showchar <resource> <action>` — Execute showchar commands
- `showchar self version` — Print showchar version
- `showchar _ _` — Passthrough to showchar CLI

## Usage Examples
- "showchar --help"
- "showchar self version"

## Installation
```bash
apt-get install showchar 2>/dev/null || which showchar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
