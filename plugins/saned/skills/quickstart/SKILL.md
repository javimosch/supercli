# saned Plugin

CLI tool: saned.

## Commands
- `saned <resource> <action>` — Execute saned commands
- `saned self version` — Print saned version
- `saned _ _` — Passthrough to saned CLI

## Usage Examples
- "saned --help"
- "saned self version"

## Installation
```bash
apt-get install saned 2>/dev/null || which saned
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
