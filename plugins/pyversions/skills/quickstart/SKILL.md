# pyversions Plugin

CLI tool: pyversions.

## Commands
- `pyversions <resource> <action>` — Execute pyversions commands
- `pyversions self version` — Print pyversions version
- `pyversions _ _` — Passthrough to pyversions CLI

## Usage Examples
- "pyversions --help"
- "pyversions self version"

## Installation
```bash
apt-get install pyversions 2>/dev/null || which pyversions
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
