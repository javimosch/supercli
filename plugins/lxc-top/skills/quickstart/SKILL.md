# lxc-top Plugin

CLI tool: lxc-top.

## Commands
- `lxc-top <resource> <action>` — Execute lxc-top commands
- `lxc-top self version` — Print lxc-top version
- `lxc-top _ _` — Passthrough to lxc-top CLI

## Usage Examples
- "lxc-top --help"
- "lxc-top self version"

## Installation
```bash
apt-get install lxc-top 2>/dev/null || which lxc-top
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
