# gfortran-8 Plugin

CLI tool: gfortran-8.

## Commands
- `gfortran-8 <resource> <action>` — Execute gfortran-8 commands
- `gfortran-8 self version` — Print gfortran-8 version
- `gfortran-8 _ _` — Passthrough to gfortran-8 CLI

## Usage Examples
- "gfortran-8 --help"
- "gfortran-8 self version"

## Installation
```bash
apt-get install gfortran-8 2>/dev/null || which gfortran-8
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
