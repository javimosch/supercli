# pbmtoptx Plugin

CLI tool: pbmtoptx.

## Commands
- `pbmtoptx <resource> <action>` — Execute pbmtoptx commands
- `pbmtoptx self version` — Print pbmtoptx version
- `pbmtoptx _ _` — Passthrough to pbmtoptx CLI

## Usage Examples
- "pbmtoptx --help"
- "pbmtoptx self version"

## Installation
```bash
apt-get install pbmtoptx 2>/dev/null || which pbmtoptx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
