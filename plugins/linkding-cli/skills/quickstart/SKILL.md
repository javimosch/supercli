# linkding-cli Plugin
CLI for linkding self-hosted bookmark manager

## Commands
- `linkding-cli <resource> <action>` — Execute linkding-cli commands
- `linkding-cli _ _` — Passthrough to linkding-cli CLI

## Usage
- `linkding-cli _ _ <args>` — Run linkding-cli with any arguments
