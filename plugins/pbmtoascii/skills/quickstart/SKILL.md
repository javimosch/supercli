# pbmtoascii Plugin

CLI tool: pbmtoascii.

## Commands
- `pbmtoascii <resource> <action>` — Execute pbmtoascii commands
- `pbmtoascii self version` — Print pbmtoascii version
- `pbmtoascii _ _` — Passthrough to pbmtoascii CLI

## Usage Examples
- "pbmtoascii --help"
- "pbmtoascii self version"

## Installation
```bash
apt-get install pbmtoascii 2>/dev/null || which pbmtoascii
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
