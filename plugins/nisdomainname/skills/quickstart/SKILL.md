# nisdomainname Plugin

CLI tool: nisdomainname.

## Commands
- `nisdomainname <resource> <action>` — Execute nisdomainname commands
- `nisdomainname self version` — Print nisdomainname version
- `nisdomainname _ _` — Passthrough to nisdomainname CLI

## Usage Examples
- "nisdomainname --help"
- "nisdomainname self version"

## Installation
```bash
apt-get install nisdomainname 2>/dev/null || which nisdomainname
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
