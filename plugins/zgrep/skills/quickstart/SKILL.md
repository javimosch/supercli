# zgrep Plugin
Fast text search through gzip-compressed files

## Commands
- `zgrep <resource> <action>` — Execute zgrep commands
- `zgrep _ _` — Passthrough to zgrep CLI

## Usage
- `zgrep _ _ <args>` — Run zgrep with any arguments
