# tapestat Plugin

CLI tool: tapestat.

## Commands
- `tapestat <resource> <action>` — Execute tapestat commands
- `tapestat self version` — Print tapestat version
- `tapestat _ _` — Passthrough to tapestat CLI

## Usage Examples
- "tapestat --help"
- "tapestat self version"

## Installation
```bash
apt-get install tapestat 2>/dev/null || which tapestat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
