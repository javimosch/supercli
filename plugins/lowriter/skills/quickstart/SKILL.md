# lowriter Plugin

CLI tool: lowriter.

## Commands
- `lowriter <resource> <action>` — Execute lowriter commands
- `lowriter self version` — Print lowriter version
- `lowriter _ _` — Passthrough to lowriter CLI

## Usage Examples
- "lowriter --help"
- "lowriter self version"

## Installation
```bash
apt-get install lowriter 2>/dev/null || which lowriter
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
