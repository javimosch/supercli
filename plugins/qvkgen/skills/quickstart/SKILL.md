# qvkgen Plugin

CLI tool: qvkgen.

## Commands
- `qvkgen <resource> <action>` — Execute qvkgen commands
- `qvkgen self version` — Print qvkgen version
- `qvkgen _ _` — Passthrough to qvkgen CLI

## Usage Examples
- "qvkgen --help"
- "qvkgen self version"

## Installation
```bash
apt-get install qvkgen 2>/dev/null || which qvkgen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
