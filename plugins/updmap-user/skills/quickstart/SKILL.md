# updmap-user Plugin

CLI tool: updmap-user.

## Commands
- `updmap-user <resource> <action>` — Execute updmap-user commands
- `updmap-user self version` — Print updmap-user version
- `updmap-user _ _` — Passthrough to updmap-user CLI

## Usage Examples
- "updmap-user --help"
- "updmap-user self version"

## Installation
```bash
apt-get install updmap-user 2>/dev/null || which updmap-user
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
