# qcollectiongenerator Plugin

CLI tool: qcollectiongenerator.

## Commands
- `qcollectiongenerator <resource> <action>` — Execute qcollectiongenerator commands
- `qcollectiongenerator self version` — Print qcollectiongenerator version
- `qcollectiongenerator _ _` — Passthrough to qcollectiongenerator CLI

## Usage Examples
- "qcollectiongenerator --help"
- "qcollectiongenerator self version"

## Installation
```bash
apt-get install qcollectiongenerator 2>/dev/null || which qcollectiongenerator
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
