# vdir Plugin

CLI tool: vdir.

## Commands
- `vdir <resource> <action>` — Execute vdir commands
- `vdir self version` — Print vdir version
- `vdir _ _` — Passthrough to vdir CLI

## Usage Examples
- "vdir --help"
- "vdir self version"

## Installation
```bash
apt-get install vdir 2>/dev/null || which vdir
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
