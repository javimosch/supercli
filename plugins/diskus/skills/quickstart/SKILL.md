# diskus Plugin
CLI tool for diskus.

## Commands
- `diskus <resource> <action>` — Execute diskus commands
- `diskus _ _` — Passthrough to diskus CLI

## Installation
```bash
cargo install diskus
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
