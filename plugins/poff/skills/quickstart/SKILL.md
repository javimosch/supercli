# poff Plugin

CLI tool: poff.

## Commands
- `poff <resource> <action>` — Execute poff commands
- `poff self version` — Print poff version
- `poff _ _` — Passthrough to poff CLI

## Usage Examples
- "poff --help"
- "poff self version"

## Installation
```bash
apt-get install poff 2>/dev/null || which poff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
