# scie-pants Plugin
Self-contained Python executable for the Pants build system

## Commands
- `scie-pants <resource> <action>` — Execute scie-pants commands
- `scie-pants _ _` — Passthrough to scie-pants CLI

## Usage
- `scie-pants _ _ <args>` — Run scie-pants with any arguments
