# BarraCUDA Plugin

Open-source CUDA, Triton and HIP compiler targeting multiple GPU architectures. 

## Commands

### General
- `BarraCUDA self version` — Print BarraCUDA version
- `BarraCUDA _ _` — Passthrough to barracuda CLI

```bash
pip install barracuda
```

## Key Features
- Open-source CUDA, Triton and HIP compiler targeting multiple GPU architectures. 
- CLI tool, headless and scriptable
