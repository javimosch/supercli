# ico Plugin

CLI tool: ico.

## Commands
- `ico <resource> <action>` — Execute ico commands
- `ico self version` — Print ico version
- `ico _ _` — Passthrough to ico CLI

## Usage Examples
- "ico --help"
- "ico self version"

## Installation
```bash
apt-get install ico 2>/dev/null || which ico
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
