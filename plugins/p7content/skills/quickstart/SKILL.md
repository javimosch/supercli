# p7content Plugin

CLI tool: p7content.

## Commands
- `p7content <resource> <action>` — Execute p7content commands
- `p7content self version` — Print p7content version
- `p7content _ _` — Passthrough to p7content CLI

## Usage Examples
- "p7content --help"
- "p7content self version"

## Installation
```bash
apt-get install p7content 2>/dev/null || which p7content
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
