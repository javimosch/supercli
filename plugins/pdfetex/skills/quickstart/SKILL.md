# pdfetex Plugin

CLI tool: pdfetex.

## Commands
- `pdfetex <resource> <action>` — Execute pdfetex commands
- `pdfetex self version` — Print pdfetex version
- `pdfetex _ _` — Passthrough to pdfetex CLI

## Usage Examples
- "pdfetex --help"
- "pdfetex self version"

## Installation
```bash
apt-get install pdfetex 2>/dev/null || which pdfetex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
