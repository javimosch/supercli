# wl-clipboard Plugin

Command-line copy/paste for Wayland in C

## Commands

### Operations
- `wl-clipboard self version` — Print wl-clipboard version
- `wl-clipboard _ _` — Passthrough to wl-clipboard CLI

## Usage Examples
- `wl-clipboard --help`
- `wl-clipboard <args>`

## Installation

```bash
brew install wl-clipboard
```

## Examples

```bash
wl-clipboard --version
wl-clipboard --help
```
