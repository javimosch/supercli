# fin-cli Plugin
Lightweight CLI for querying financial stock and ETF metrics

## Commands
- `fin-cli <resource> <action>` — Execute fin-cli commands
- `fin-cli _ _` — Passthrough to fin-cli CLI

## Usage
- `fin-cli _ _ <args>` — Run fin-cli with any arguments
