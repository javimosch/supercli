# gxl2gv Plugin

CLI tool: gxl2gv.

## Commands
- `gxl2gv <resource> <action>` — Execute gxl2gv commands
- `gxl2gv self version` — Print gxl2gv version
- `gxl2gv _ _` — Passthrough to gxl2gv CLI

## Usage Examples
- "gxl2gv --help"
- "gxl2gv self version"

## Installation
```bash
apt-get install gxl2gv 2>/dev/null || which gxl2gv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
