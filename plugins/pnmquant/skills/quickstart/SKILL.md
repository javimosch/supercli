# pnmquant Plugin

CLI tool: pnmquant.

## Commands
- `pnmquant <resource> <action>` — Execute pnmquant commands
- `pnmquant self version` — Print pnmquant version
- `pnmquant _ _` — Passthrough to pnmquant CLI

## Usage Examples
- "pnmquant --help"
- "pnmquant self version"

## Installation
```bash
apt-get install pnmquant 2>/dev/null || which pnmquant
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
