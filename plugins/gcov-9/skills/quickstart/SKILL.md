# gcov-9 Plugin

CLI tool: gcov-9.

## Commands
- `gcov-9 <resource> <action>` — Execute gcov-9 commands
- `gcov-9 self version` — Print gcov-9 version
- `gcov-9 _ _` — Passthrough to gcov-9 CLI

## Usage Examples
- "gcov-9 --help"
- "gcov-9 self version"

## Installation
```bash
apt-get install gcov-9 2>/dev/null || which gcov-9
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
