# urlhunter Plugin
Hunt and extract URLs from file sources

## Commands
- `urlhunter <resource> <action>` — Execute urlhunter commands
- `urlhunter _ _` — Passthrough to urlhunter CLI

## Usage
- `urlhunter _ _ <args>` — Run urlhunter with any arguments
