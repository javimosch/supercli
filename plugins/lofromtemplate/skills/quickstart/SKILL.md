# lofromtemplate Plugin

CLI tool: lofromtemplate.

## Commands
- `lofromtemplate <resource> <action>` — Execute lofromtemplate commands
- `lofromtemplate self version` — Print lofromtemplate version
- `lofromtemplate _ _` — Passthrough to lofromtemplate CLI

## Usage Examples
- "lofromtemplate --help"
- "lofromtemplate self version"

## Installation
```bash
apt-get install lofromtemplate 2>/dev/null || which lofromtemplate
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
