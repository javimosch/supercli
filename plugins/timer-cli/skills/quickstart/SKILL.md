# timer-cli Plugin
Simple countdown and stopwatch timer for the terminal

## Commands
- `timer-cli <resource> <action>` — Execute timer-cli commands
- `timer-cli _ _` — Passthrough to timer-cli CLI

## Usage
- `timer-cli _ _ <args>` — Run timer-cli with any arguments
