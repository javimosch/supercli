# libgcrypt-config Plugin

CLI tool: libgcrypt-config.

## Commands
- `libgcrypt-config <resource> <action>` — Execute libgcrypt-config commands
- `libgcrypt-config self version` — Print libgcrypt-config version
- `libgcrypt-config _ _` — Passthrough to libgcrypt-config CLI

## Usage Examples
- "libgcrypt-config --help"
- "libgcrypt-config self version"

## Installation
```bash
apt-get install libgcrypt-config 2>/dev/null || which libgcrypt-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
