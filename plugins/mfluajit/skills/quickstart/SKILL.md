# mfluajit Plugin

CLI tool: mfluajit.

## Commands
- `mfluajit <resource> <action>` — Execute mfluajit commands
- `mfluajit self version` — Print mfluajit version
- `mfluajit _ _` — Passthrough to mfluajit CLI

## Usage Examples
- "mfluajit --help"
- "mfluajit self version"

## Installation
```bash
apt-get install mfluajit 2>/dev/null || which mfluajit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
