# orted Plugin

CLI tool: orted.

## Commands
- `orted <resource> <action>` — Execute orted commands
- `orted self version` — Print orted version
- `orted _ _` — Passthrough to orted CLI

## Usage Examples
- "orted --help"
- "orted self version"

## Installation

```bash
apt-get install orted 2>/dev/null || which orted
```
