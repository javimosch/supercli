# extcheck Plugin

CLI tool: extcheck.

## Commands
- `extcheck <resource> <action>` — Execute extcheck commands
- `extcheck self version` — Print extcheck version
- `extcheck _ _` — Passthrough to extcheck CLI

## Usage Examples
- "extcheck --help"
- "extcheck self version"

## Installation
```bash
apt-get install extcheck 2>/dev/null || which extcheck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
