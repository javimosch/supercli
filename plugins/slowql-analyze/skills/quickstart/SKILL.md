# slowql-analyze Plugin

CLI tool: slowql-analyze.

## Commands
- `slowql-analyze <resource> <action>` — Execute slowql-analyze commands
- `slowql-analyze self version` — Print slowql-analyze version
- `slowql-analyze _ _` — Passthrough to slowql-analyze CLI

## Usage Examples
- "slowql-analyze --help"
- "slowql-analyze self version"

## Installation
```bash
apt-get install slowql-analyze 2>/dev/null || which slowql-analyze
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
