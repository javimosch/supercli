# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `graphicsmagick <resource> <action>` — Execute graphicsmagick commands
- `graphicsmagick self version` — Print GraphicsMagick version
- `graphicsmagick convert format` — Convert image format
- `graphicsmagick _ _` — Passthrough to gm CLI
