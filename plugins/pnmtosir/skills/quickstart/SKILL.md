# pnmtosir Plugin

CLI tool: pnmtosir.

## Commands
- `pnmtosir <resource> <action>` — Execute pnmtosir commands
- `pnmtosir self version` — Print pnmtosir version
- `pnmtosir _ _` — Passthrough to pnmtosir CLI

## Usage Examples
- "pnmtosir --help"
- "pnmtosir self version"

## Installation
```bash
apt-get install pnmtosir 2>/dev/null || which pnmtosir
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
