# gregorio Plugin

CLI tool: gregorio.

## Commands
- `gregorio <resource> <action>` — Execute gregorio commands
- `gregorio self version` — Print gregorio version
- `gregorio _ _` — Passthrough to gregorio CLI

## Usage Examples
- "gregorio --help"
- "gregorio self version"

## Installation
```bash
apt-get install gregorio 2>/dev/null || which gregorio
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
