# em-keyboard Plugin

CLI emoji keyboard in Python

## Commands

### Operations
- `em-keyboard self version` — Print em-keyboard version
- `em-keyboard _ _` — Passthrough to em-keyboard CLI

## Usage Examples
- `em-keyboard --help`
- `em-keyboard <args>`

## Installation

```bash
pip install em-keyboard
```

## Examples

```bash
em-keyboard --version
em-keyboard --help
```
