# hledger
hledger — plain text accounting CLI. Track finances, generate reports from ledger-compatible text files. Non-interactive, JSON output.

## Install
```bash
curl -LO https://github.com/simonmichael/hledger/releases/download/1.41/hledger-linux-x64.zip && unzip -o hledger-linux-x64.zip && sudo mv hledger /usr/local/bin/ && rm hledger-linux-x64.zip
```
