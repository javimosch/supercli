# xkbprint Plugin

CLI tool: xkbprint.

## Commands
- `xkbprint <resource> <action>` — Execute xkbprint commands
- `xkbprint self version` — Print xkbprint version
- `xkbprint _ _` — Passthrough to xkbprint CLI

## Usage Examples
- "xkbprint --help"
- "xkbprint self version"

## Installation
```bash
apt-get install xkbprint 2>/dev/null || which xkbprint
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
