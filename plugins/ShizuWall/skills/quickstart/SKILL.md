# ShizuWall Plugin

Lightweight, no vpn firewall solution for Android 11+

## Commands

### General
- `ShizuWall self version` — Print ShizuWall version
- `ShizuWall _ _` — Passthrough to shizuwall CLI

## Usage Examples
- "Run ShizuWall"
- "Use shizuwall to Lightweight, no vpn firewall solution for Android 11+"

## Installation

```bash
pip install shizuwall
```

## Key Features
- Lightweight, no vpn firewall solution for Android 11+
- CLI tool, headless and scriptable
