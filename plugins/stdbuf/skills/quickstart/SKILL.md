# stdbuf Plugin
Control buffering of standard I/O streams

## Commands
- `stdbuf <resource> <action>` — Execute stdbuf commands
- `stdbuf self version` — Print stdbuf version
- `stdbuf _ _` — Passthrough to stdbuf CLI

## Usage
- `stdbuf _ _ <args>` — Run stdbuf with any arguments
