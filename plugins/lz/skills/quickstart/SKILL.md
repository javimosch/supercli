# lz Plugin

CLI tool: lz.

## Commands
- `lz <resource> <action>` — Execute lz commands
- `lz self version` — Print lz version
- `lz _ _` — Passthrough to lz CLI

## Usage Examples
- "lz --help"
- "lz self version"

## Installation
```bash
apt-get install lz 2>/dev/null || which lz
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
