# jshell Plugin

CLI tool: jshell.

## Commands
- `jshell <resource> <action>` — Execute jshell commands
- `jshell self version` — Print jshell version
- `jshell _ _` — Passthrough to jshell CLI

## Usage Examples
- "jshell --help"
- "jshell self version"

## Installation
```bash
apt-get install jshell 2>/dev/null || which jshell
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
