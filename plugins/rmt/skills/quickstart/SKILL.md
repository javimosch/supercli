# rmt Plugin

CLI tool: rmt.

## Commands
- `rmt <resource> <action>` — Execute rmt commands
- `rmt self version` — Print rmt version
- `rmt _ _` — Passthrough to rmt CLI

## Usage Examples
- "rmt --help"
- "rmt self version"

## Installation
```bash
apt-get install rmt 2>/dev/null || which rmt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
