# whodb Plugin

A lightweight next-gen data explorer - Postgres, MySQL, SQLite, MongoDB, Redis, MariaDB, Elastic Search, and Clickhouse with Chat interface

## Commands
- `whodb <resource> <action>` — Execute whodb commands
- `whodb self version` — Print whodb version
- `whodb _ _` — Passthrough to whodb CLI

## Installation

```bash
pip install whodb
```
