# dblatex Plugin

dblatex converts DocBook to PDF via LaTeX.

## Commands
- `dblatex <resource> <action>` — Execute dblatex commands
- `dblatex self version` — Print dblatex version
- `dblatex _ _` — Passthrough to dblatex CLI

## Usage Examples

- "convert a DocBook document to PDF"
- "generate DVI output from DocBook"
- "apply custom LaTeX style"

## Installation

```bash
brew install dblatex
```

## Key Features
- DocBook XML to PDF conversion
- LaTeX-based professional typesetting
- Table of contents and index generation
- MathML equation support
- Custom LaTeX style application
- Cross-references and hyperlinks
