# mren Plugin

CLI tool: mren.

## Commands
- `mren <resource> <action>` — Execute mren commands
- `mren self version` — Print mren version
- `mren _ _` — Passthrough to mren CLI

## Usage Examples
- "mren --help"
- "mren self version"

## Installation
```bash
apt-get install mren 2>/dev/null || which mren
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
