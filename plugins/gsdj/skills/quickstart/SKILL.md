# gsdj Plugin

CLI tool: gsdj.

## Commands
- `gsdj <resource> <action>` — Execute gsdj commands
- `gsdj self version` — Print gsdj version
- `gsdj _ _` — Passthrough to gsdj CLI

## Usage Examples
- "gsdj --help"
- "gsdj self version"

## Installation
```bash
apt-get install gsdj 2>/dev/null || which gsdj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
