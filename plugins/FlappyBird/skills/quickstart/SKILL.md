# FlappyBird Plugin

Less than 100 Kilobytes. Works for Android 5.0 and above

## Commands

### General
- `FlappyBird self version` — Print FlappyBird version
- `FlappyBird _ _` — Passthrough to flappybird CLI

## Usage Examples
- "Run FlappyBird"
- "Use flappybird to Less than 100 Kilobytes. Works for Android 5.0 and above"

## Installation

```bash
pip install flappybird
```

## Key Features
- Less than 100 Kilobytes. Works for Android 5.0 and above
- CLI tool, headless and scriptable
