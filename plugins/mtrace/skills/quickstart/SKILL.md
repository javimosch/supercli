# mtrace Plugin

CLI tool: mtrace.

## Commands
- `mtrace <resource> <action>` — Execute mtrace commands
- `mtrace self version` — Print mtrace version
- `mtrace _ _` — Passthrough to mtrace CLI

## Usage Examples
- "mtrace --help"
- "mtrace self version"

## Installation
```bash
apt-get install mtrace 2>/dev/null || which mtrace
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
