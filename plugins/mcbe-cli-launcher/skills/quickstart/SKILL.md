# mcbe-cli-launcher Plugin
CLI injector for Minecraft Bedrock Edition mod development

## Commands
- `mcbe-cli-launcher <resource> <action>` — Execute mcbe-cli-launcher commands
- `mcbe-cli-launcher _ _` — Passthrough to mcbe-cli-launcher CLI

## Usage
- `mcbe-cli-launcher _ _ <args>` — Run mcbe-cli-launcher with any arguments
