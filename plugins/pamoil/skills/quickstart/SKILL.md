# pamoil Plugin

CLI tool: pamoil.

## Commands
- `pamoil <resource> <action>` — Execute pamoil commands
- `pamoil self version` — Print pamoil version
- `pamoil _ _` — Passthrough to pamoil CLI

## Usage Examples
- "pamoil --help"
- "pamoil self version"

## Installation
```bash
apt-get install pamoil 2>/dev/null || which pamoil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
