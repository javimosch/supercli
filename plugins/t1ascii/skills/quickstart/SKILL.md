# t1ascii Plugin

CLI tool: t1ascii.

## Commands
- `t1ascii <resource> <action>` — Execute t1ascii commands
- `t1ascii self version` — Print t1ascii version
- `t1ascii _ _` — Passthrough to t1ascii CLI

## Usage Examples
- "t1ascii --help"
- "t1ascii self version"

## Installation
```bash
apt-get install t1ascii 2>/dev/null || which t1ascii
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
