# scanopy Plugin

Network diagrams that update themselves

## Commands

### General
- `scanopy self version` — Print scanopy version
- `scanopy _ _` — Passthrough to scanopy CLI

```bash
pip install scanopy
```

- CLI tool, headless and scriptable
