# magic-generate Plugin

CLI tool: magic-generate.

## Commands
- `magic-generate <resource> <action>` — Execute magic-generate commands
- `magic-generate self version` — Print magic-generate version
- `magic-generate _ _` — Passthrough to magic-generate CLI

## Usage Examples
- "magic-generate --help"
- "magic-generate self version"

## Installation
```bash
apt-get install magic-generate 2>/dev/null || which magic-generate
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
