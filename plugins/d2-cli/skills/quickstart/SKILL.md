# d2-cli Plugin
Declarative diagramming language compiler and renderer

## Commands
- `d2-cli <resource> <action>` — Execute d2-cli commands
- `d2-cli _ _` — Passthrough to d2-cli CLI

## Usage
- `d2-cli _ _ <args>` — Run d2-cli with any arguments
