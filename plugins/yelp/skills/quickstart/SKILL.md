# yelp Plugin

CLI tool: yelp.

## Commands
- `yelp <resource> <action>` — Execute yelp commands
- `yelp self version` — Print yelp version
- `yelp _ _` — Passthrough to yelp CLI

## Usage Examples
- "yelp --help"
- "yelp self version"

## Installation
```bash
apt-get install yelp 2>/dev/null || which yelp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
