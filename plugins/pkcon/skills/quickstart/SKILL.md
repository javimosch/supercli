# pkcon Plugin

CLI tool: pkcon.

## Commands
- `pkcon <resource> <action>` — Execute pkcon commands
- `pkcon self version` — Print pkcon version
- `pkcon _ _` — Passthrough to pkcon CLI

## Usage Examples
- "pkcon --help"
- "pkcon self version"

## Installation
```bash
apt-get install pkcon 2>/dev/null || which pkcon
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
