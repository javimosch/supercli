# pickle Plugin

pickle — serialization format

## Commands
- `pickle <resource> <action>` — Execute pickle commands
- `pickle self version` — Version

## Installation

```bash
cargo install pickle
Verify: pickle --version
```

## Commands

### `sc pickle self version`

Version


## SuperCLI

```bash
sc pickle _ _ --help
sc plugins learn pickle
```
