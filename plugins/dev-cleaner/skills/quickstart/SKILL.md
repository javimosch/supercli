# dev-cleaner Plugin

One-click CLI utility to safely clear 50GB+ of developer cache bloat. Cleans Xcode, Flutter, npm, Android Gradle, and IDE temp files.

## Commands
- `dev-cleaner self version` — Print version
- `dev-cleaner _ _ <args>` — Passthrough to dev-cleaner

## Usage Examples
- "Cache Cleaner"

## Installation
```bash
npm install -g dev-cleaner
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
