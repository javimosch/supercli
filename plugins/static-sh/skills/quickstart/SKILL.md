# static-sh Plugin

CLI tool: static-sh.

## Commands
- `static-sh <resource> <action>` — Execute static-sh commands
- `static-sh self version` — Print static-sh version
- `static-sh _ _` — Passthrough to static-sh CLI

## Usage Examples
- "static-sh --help"
- "static-sh self version"

## Installation
```bash
apt-get install static-sh 2>/dev/null || which static-sh
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
