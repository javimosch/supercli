# lvmsadc Plugin

CLI tool: lvmsadc.

## Commands
- `lvmsadc <resource> <action>` — Execute lvmsadc commands
- `lvmsadc self version` — Print lvmsadc version
- `lvmsadc _ _` — Passthrough to lvmsadc CLI

## Usage Examples
- "lvmsadc --help"
- "lvmsadc self version"

## Installation
```bash
apt-get install lvmsadc 2>/dev/null || which lvmsadc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
