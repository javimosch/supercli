# xml2-config Plugin

CLI tool: xml2-config.

## Commands
- `xml2-config <resource> <action>` — Execute xml2-config commands
- `xml2-config self version` — Print xml2-config version
- `xml2-config _ _` — Passthrough to xml2-config CLI

## Usage Examples
- "xml2-config --help"
- "xml2-config self version"

## Installation
```bash
apt-get install xml2-config 2>/dev/null || which xml2-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
