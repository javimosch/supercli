# pnmtops Plugin

CLI tool: pnmtops.

## Commands
- `pnmtops <resource> <action>` — Execute pnmtops commands
- `pnmtops self version` — Print pnmtops version
- `pnmtops _ _` — Passthrough to pnmtops CLI

## Usage Examples
- "pnmtops --help"
- "pnmtops self version"

## Installation
```bash
apt-get install pnmtops 2>/dev/null || which pnmtops
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
