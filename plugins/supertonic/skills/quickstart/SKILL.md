# supertonic Plugin

CLI tool: supertonic.

## Commands
- `supertonic <resource> <action>` — Execute supertonic commands
- `supertonic self version` — Print supertonic version
- `supertonic _ _` — Passthrough to supertonic CLI

## Usage Examples
- "supertonic --help"
- "supertonic self version"

## Installation
```bash
apt-get install supertonic 2>/dev/null || which supertonic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
