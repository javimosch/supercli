# translate-c Plugin

A Zig package for translating C code into Zig code.

## Commands

### General
- `translate-c self version` — Print translate-c version
- `translate-c _ _` — Passthrough to translate-c CLI

## Usage Examples
- "Run translate-c"
- "Use translate-c to A Zig package for translating C code into Zig code."

## Installation

```bash
pip install translate-c
```

## Key Features
- A Zig package for translating C code into Zig code.
- CLI tool, headless and scriptable
