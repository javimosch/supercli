# pnmindex Plugin

CLI tool: pnmindex.

## Commands
- `pnmindex <resource> <action>` — Execute pnmindex commands
- `pnmindex self version` — Print pnmindex version
- `pnmindex _ _` — Passthrough to pnmindex CLI

## Usage Examples
- "pnmindex --help"
- "pnmindex self version"

## Installation
```bash
apt-get install pnmindex 2>/dev/null || which pnmindex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
