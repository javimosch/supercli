# zzdoc Plugin
scdoc-compatible manpage compiler.
## Commands
- `zzdoc _ _` — Passthrough to zzdoc CLI
## Installation
```bash
git clone https://github.com/rockorager/zzdoc && cd zzdoc && zig build
```
## Key Features
- **Manpage compiler** — scdoc compatible
- **Fast** — Written in Zig
- **CI/CD ready** — Pipeline integration
