# m365_comp Plugin

CLI tool: m365_comp.

## Commands
- `m365_comp <resource> <action>` — Execute m365_comp commands
- `m365_comp self version` — Print m365_comp version
- `m365_comp _ _` — Passthrough to m365_comp CLI

## Usage Examples
- "m365_comp --help"
- "m365_comp self version"

## Installation
```bash
apt-get install m365_comp 2>/dev/null || which m365_comp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
