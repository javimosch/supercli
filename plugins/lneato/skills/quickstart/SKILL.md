# lneato Plugin

CLI tool: lneato.

## Commands
- `lneato <resource> <action>` — Execute lneato commands
- `lneato self version` — Print lneato version
- `lneato _ _` — Passthrough to lneato CLI

## Usage Examples
- "lneato --help"
- "lneato self version"

## Installation
```bash
apt-get install lneato 2>/dev/null || which lneato
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
