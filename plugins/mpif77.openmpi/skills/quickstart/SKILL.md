# mpif77.openmpi Plugin

CLI tool: mpif77.openmpi.

## Commands
- `mpif77.openmpi <resource> <action>` — Execute mpif77.openmpi commands
- `mpif77.openmpi self version` — Print mpif77.openmpi version
- `mpif77.openmpi _ _` — Passthrough to mpif77.openmpi CLI

## Usage Examples
- "mpif77.openmpi --help"
- "mpif77.openmpi self version"

## Installation
```bash
apt-get install mpif77.openmpi 2>/dev/null || which mpif77.openmpi
```
