# ps2ps2 Plugin

CLI tool: ps2ps2.

## Commands
- `ps2ps2 <resource> <action>` — Execute ps2ps2 commands
- `ps2ps2 self version` — Print ps2ps2 version
- `ps2ps2 _ _` — Passthrough to ps2ps2 CLI

## Usage Examples
- "ps2ps2 --help"
- "ps2ps2 self version"

## Installation
```bash
apt-get install ps2ps2 2>/dev/null || which ps2ps2
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
