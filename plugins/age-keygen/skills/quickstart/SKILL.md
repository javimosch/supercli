# age-keygen Plugin

Generate age key pairs.

## Commands
- `age-keygen <resource> <action>` — Execute age-keygen commands
- `age-keygen self version` — Print age-keygen version
- `age-keygen _ _` — Passthrough to age-keygen CLI

## Usage Examples
- "age-keygen --help"
- "age-keygen self version"

## Installation
```bash
go install filippo.io/age/cmd/age-keygen@latest
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- go based
