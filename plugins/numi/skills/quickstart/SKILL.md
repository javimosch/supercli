# numi Plugin

Beautiful calculator app for macOS/Linux/Windows in JavaScript

## Commands

### Operations
- `numi self version` — Print numi version
- `numi _ _` — Passthrough to numi CLI

## Usage Examples
- `numi --help`
- `numi <args>`

## Installation

```bash
npm install -g numi
```

## Examples

```bash
numi --version
numi --help
```
