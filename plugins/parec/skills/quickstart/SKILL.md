# parec Plugin

CLI tool: parec.

## Commands
- `parec <resource> <action>` — Execute parec commands
- `parec self version` — Print parec version
- `parec _ _` — Passthrough to parec CLI

## Usage Examples
- "parec --help"
- "parec self version"

## Installation
```bash
apt-get install parec 2>/dev/null || which parec
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
