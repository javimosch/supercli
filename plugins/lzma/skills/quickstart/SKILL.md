# lzma Plugin

CLI tool: lzma.

## Commands
- `lzma <resource> <action>` — Execute lzma commands
- `lzma self version` — Print lzma version
- `lzma _ _` — Passthrough to lzma CLI

## Usage Examples
- "lzma --help"
- "lzma self version"

## Installation
```bash
apt-get install lzma 2>/dev/null || which lzma
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
