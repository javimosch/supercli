# xdriinfo Plugin

CLI tool: xdriinfo.

## Commands
- `xdriinfo <resource> <action>` — Execute xdriinfo commands
- `xdriinfo self version` — Print xdriinfo version
- `xdriinfo _ _` — Passthrough to xdriinfo CLI

## Usage Examples
- "xdriinfo --help"
- "xdriinfo self version"

## Installation
```bash
apt-get install xdriinfo 2>/dev/null || which xdriinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
