# kazam Plugin

CLI tool: kazam.

## Commands
- `kazam <resource> <action>` — Execute kazam commands
- `kazam self version` — Print kazam version
- `kazam _ _` — Passthrough to kazam CLI

## Usage Examples
- "kazam --help"
- "kazam self version"

## Installation
```bash
apt-get install kazam 2>/dev/null || which kazam
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
