# ten-vad Plugin

Voice Activity Detector low-latency

## Commands

### Version
`ten-vad self version` — Print ten-vad version

### Passthrough
`ten-vad _ _` — Passthrough to ten-vad CLI with all arguments forwarded.

## Usage Examples

```bash
ten-vad --version
ten-vad --help
```

## Installation

```bash
cargo install ten-vad
```

## Key Features
- Voice Activity Detector low-latency
