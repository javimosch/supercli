# raw Plugin

CLI tool: raw.

## Commands
- `raw <resource> <action>` — Execute raw commands
- `raw self version` — Print raw version
- `raw _ _` — Passthrough to raw CLI

## Usage Examples
- "raw --help"
- "raw self version"

## Installation

```bash
apt-get install raw 2>/dev/null || which raw
```
