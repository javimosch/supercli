# slxdecode Plugin

CLI tool: slxdecode.

## Commands
- `slxdecode <resource> <action>` — Execute slxdecode commands
- `slxdecode self version` — Print slxdecode version
- `slxdecode _ _` — Passthrough to slxdecode CLI

## Usage Examples
- "slxdecode --help"
- "slxdecode self version"

## Installation
```bash
apt-get install slxdecode 2>/dev/null || which slxdecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
