# what-url Plugin
Identify and classify URLs from command line

## Commands
- `what-url <resource> <action>` — Execute what-url commands
- `what-url _ _` — Passthrough to what-url CLI

## Usage
- `what-url _ _ <args>` — Run what-url with any arguments
