# kube-linter Plugin
Kubernetes YAML linter. Checks for best practices and security issues.

## Commands
- `kube-linter <resource> <action>` — Execute kube-linter commands
- `kube-linter self version` — Print kube-linter version
- `kube-linter _ _` — Passthrough to kube-linter CLI
