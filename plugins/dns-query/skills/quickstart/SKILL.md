# dns-query Plugin
Advanced DNS lookup tool with DNS-over-HTTPS support

## Commands
- `dns-query <resource> <action>` — Execute dns-query commands
- `dns-query _ _` — Passthrough to dns-query CLI

## Usage
- `dns-query _ _ <args>` — Run dns-query with any arguments
