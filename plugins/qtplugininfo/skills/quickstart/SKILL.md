# qtplugininfo Plugin

CLI tool: qtplugininfo.

## Commands
- `qtplugininfo <resource> <action>` — Execute qtplugininfo commands
- `qtplugininfo self version` — Print qtplugininfo version
- `qtplugininfo _ _` — Passthrough to qtplugininfo CLI

## Usage Examples
- "qtplugininfo --help"
- "qtplugininfo self version"

## Installation
```bash
apt-get install qtplugininfo 2>/dev/null || which qtplugininfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
