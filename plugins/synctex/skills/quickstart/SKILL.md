# synctex Plugin

CLI tool: synctex.

## Commands
- `synctex <resource> <action>` — Execute synctex commands
- `synctex self version` — Print synctex version
- `synctex _ _` — Passthrough to synctex CLI

## Usage Examples
- "synctex --help"
- "synctex self version"

## Installation
```bash
apt-get install synctex 2>/dev/null || which synctex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
