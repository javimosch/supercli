# vstp Plugin

CLI tool: vstp.

## Commands
- `vstp <resource> <action>` — Execute vstp commands
- `vstp self version` — Print vstp version
- `vstp _ _` — Passthrough to vstp CLI

## Usage Examples
- "vstp --help"
- "vstp self version"

## Installation
```bash
apt-get install vstp 2>/dev/null || which vstp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
