# textql
textql — execute SQL queries against structured text (CSV/TSV). No database needed, works directly on text files.

## Commands
- `textql <resource> <action>` — Execute textql commands
- `textql textql run` — textql — execute SQL queries against structured text (CSV/TSV). No database needed, works directly on text files.
