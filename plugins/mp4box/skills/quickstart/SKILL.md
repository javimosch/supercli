# mp4box
mp4box — GPAC multimedia packager. Multiplex, demux, fragment, and analyze MP4 files. Essential for DASH/HLS packaging.

## Commands
- `mp4box <resource> <action>` — Execute mp4box commands
- `mp4box mp4box run` — mp4box — GPAC multimedia packager. Multiplex, demux, fragment, and analyze MP4 files. Essential for DASH/HLS packaging.
