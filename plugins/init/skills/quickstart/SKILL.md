# init Plugin

CLI tool: init.

## Commands
- `init <resource> <action>` — Execute init commands
- `init self version` — Print init version
- `init _ _` — Passthrough to init CLI

## Usage Examples
- "init --help"
- "init self version"

## Installation
```bash
apt-get install init 2>/dev/null || which init
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
