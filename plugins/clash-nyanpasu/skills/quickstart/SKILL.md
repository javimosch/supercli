# clash-nyanpasu Plugin

Clash Nyanpasu～(∠・ω< )⌒☆​

## Commands
- `clash-nyanpasu <resource> <action>` — Execute clash-nyanpasu commands
- `clash-nyanpasu self version` — Print clash-nyanpasu version
- `clash-nyanpasu _ _` — Passthrough to clash-nyanpasu CLI

## Installation

```bash
pip install clash-nyanpasu
```
