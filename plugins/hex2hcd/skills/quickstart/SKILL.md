# hex2hcd Plugin

CLI tool: hex2hcd.

## Commands
- `hex2hcd <resource> <action>` — Execute hex2hcd commands
- `hex2hcd self version` — Print hex2hcd version
- `hex2hcd _ _` — Passthrough to hex2hcd CLI

## Usage Examples
- "hex2hcd --help"
- "hex2hcd self version"

## Installation
```bash
apt-get install hex2hcd 2>/dev/null || which hex2hcd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
