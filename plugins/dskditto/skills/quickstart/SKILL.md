# dskditto Plugin
Ultra-fast duplicate file finder.
## Commands
- `dskditto _ _` — Passthrough to dskditto CLI
## Installation
```bash
cargo install dskditto
```
## Key Features
- **Duplicate detection** — Find redundant files
- **Disk reclamation** — Free up space
- **Fast** — Ultra-fast scanning
- **Pipeline-ready** — JSON output
