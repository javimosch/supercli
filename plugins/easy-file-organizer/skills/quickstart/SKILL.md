# easy-file-organizer Plugin

CLI tool: easy-file-organizer.

## Commands
- `easy-file-organizer <resource> <action>` — Execute easy-file-organizer commands
- `easy-file-organizer self version` — Print easy-file-organizer version
- `easy-file-organizer _ _` — Passthrough to easy-file-organizer CLI

## Usage Examples
- "easy-file-organizer --help"
- "easy-file-organizer self version"

## Installation
```bash
apt-get install easy-file-organizer 2>/dev/null || which easy-file-organizer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
