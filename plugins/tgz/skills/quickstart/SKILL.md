# tgz Plugin

CLI tool: tgz.

## Commands
- `tgz <resource> <action>` — Execute tgz commands
- `tgz self version` — Print tgz version
- `tgz _ _` — Passthrough to tgz CLI

## Usage Examples
- "tgz --help"
- "tgz self version"

## Installation
```bash
apt-get install tgz 2>/dev/null || which tgz
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
