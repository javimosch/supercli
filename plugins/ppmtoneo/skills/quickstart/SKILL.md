# ppmtoneo Plugin

CLI tool: ppmtoneo.

## Commands
- `ppmtoneo <resource> <action>` — Execute ppmtoneo commands
- `ppmtoneo self version` — Print ppmtoneo version
- `ppmtoneo _ _` — Passthrough to ppmtoneo CLI

## Usage Examples
- "ppmtoneo --help"
- "ppmtoneo self version"

## Installation
```bash
apt-get install ppmtoneo 2>/dev/null || which ppmtoneo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
