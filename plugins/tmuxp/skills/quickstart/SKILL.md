# tmuxp Plugin

tmuxp — tmux session manager. Create, manage, and attach to tmux sessions via YAML/JSON configs..

## Commands

### `sc tmuxp session load`
Load a tmux session from config file.

### `sc tmuxp session list`
List tmux sessions.

### `sc tmuxp session freeze`
Freeze a tmux session to config.

### `sc tmuxp self version`
Print version.

## Installation

```bash
pip install tmuxp
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
