# proptest Plugin

proptest — property-based testing framework for Rust

## Commands
- `proptest <resource> <action>` — Execute proptest commands
- `proptest self version` — Version

## Installation

```bash
cargo install proptest
Verify: proptest --version
```

## Commands

### `sc proptest self version`

Version


## SuperCLI

```bash
sc proptest _ _ --help
sc plugins learn proptest
```
