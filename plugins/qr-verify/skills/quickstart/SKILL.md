# qr-verify Plugin

Verify scannable QR Code in batch in TypeScript

## Commands

### Operations
- `qr-verify self version` — Print qr-verify version
- `qr-verify _ _` — Passthrough to qr-verify CLI

## Usage Examples
- `qr-verify --help`
- `qr-verify <args>`

## Installation

```bash
npm install -g qr-verify
```

## Examples

```bash
qr-verify --version
qr-verify --help
```
