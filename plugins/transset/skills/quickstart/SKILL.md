# transset Plugin

CLI tool: transset.

## Commands
- `transset <resource> <action>` — Execute transset commands
- `transset self version` — Print transset version
- `transset _ _` — Passthrough to transset CLI

## Usage Examples
- "transset --help"
- "transset self version"

## Installation
```bash
apt-get install transset 2>/dev/null || which transset
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
