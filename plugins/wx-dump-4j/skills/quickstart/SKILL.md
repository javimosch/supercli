# wx-dump-4j Plugin

一款基于Java开发的微信数据分析工具。

## Commands

### General
- `wx-dump-4j self version` — Print wx-dump-4j version
- `wx-dump-4j _ _` — Passthrough to wx-dump-4j CLI
