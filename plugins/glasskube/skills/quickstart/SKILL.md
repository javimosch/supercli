# glasskube Plugin

The next generation Package Manager for Kubernetes. Dependency aware, GitOps ready, automatic updates. Go CLI.

## Commands
- `glasskube self version` — Print version
- `glasskube _ _ <args>` — Passthrough to glasskube

## Usage Examples
- "K8s Package Manager"

## Installation
```bash
brew install glasskube
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
