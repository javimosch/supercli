# htdbm Plugin

CLI tool: htdbm.

## Commands
- `htdbm <resource> <action>` — Execute htdbm commands
- `htdbm self version` — Print htdbm version
- `htdbm _ _` — Passthrough to htdbm CLI

## Usage Examples
- "htdbm --help"
- "htdbm self version"

## Installation
```bash
apt-get install htdbm 2>/dev/null || which htdbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
