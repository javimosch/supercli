# mpost Plugin

CLI tool: mpost.

## Commands
- `mpost <resource> <action>` — Execute mpost commands
- `mpost self version` — Print mpost version
- `mpost _ _` — Passthrough to mpost CLI

## Usage Examples
- "mpost --help"
- "mpost self version"

## Installation
```bash
apt-get install mpost 2>/dev/null || which mpost
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
