# spice-vdagent Plugin

CLI tool: spice-vdagent.

## Commands
- `spice-vdagent <resource> <action>` — Execute spice-vdagent commands
- `spice-vdagent self version` — Print spice-vdagent version
- `spice-vdagent _ _` — Passthrough to spice-vdagent CLI

## Usage Examples
- "spice-vdagent --help"
- "spice-vdagent self version"

## Installation
```bash
apt-get install spice-vdagent 2>/dev/null || which spice-vdagent
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
