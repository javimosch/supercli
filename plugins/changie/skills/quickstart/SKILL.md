# changie
changie — changelog automation CLI. Structured changelog management with release notes generation. Non-interactive.

## Install
```bash
curl -LO https://github.com/miniscruff/changie/releases/download/v1.24.0/changie_1.24.0_linux_amd64.tar.gz && tar xzf changie_1.24.0_linux_amd64.tar.gz && sudo mv changie /usr/local/bin/ && rm changie_1.24.0_linux_amd64.tar.gz
```
