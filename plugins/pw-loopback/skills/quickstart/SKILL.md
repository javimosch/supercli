# pw-loopback Plugin

CLI tool: pw-loopback.

## Commands
- `pw-loopback <resource> <action>` — Execute pw-loopback commands
- `pw-loopback self version` — Print pw-loopback version
- `pw-loopback _ _` — Passthrough to pw-loopback CLI

## Usage Examples
- "pw-loopback --help"
- "pw-loopback self version"

## Installation
```bash
apt-get install pw-loopback 2>/dev/null || which pw-loopback
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
