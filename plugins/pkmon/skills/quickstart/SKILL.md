# pkmon Plugin

CLI tool: pkmon.

## Commands
- `pkmon <resource> <action>` — Execute pkmon commands
- `pkmon self version` — Print pkmon version
- `pkmon _ _` — Passthrough to pkmon CLI

## Usage Examples
- "pkmon --help"
- "pkmon self version"

## Installation
```bash
apt-get install pkmon 2>/dev/null || which pkmon
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
