# dvilj2p Plugin

dvilj2p — Binaries for TeX Live.

## Commands
- `dvilj2p <resource> <action>` — Execute dvilj2p commands
- `dvilj2p self version` — Print dvilj2p version
- `dvilj2p _ _` — Passthrough to dvilj2p CLI

## Usage Examples
- "dvilj2p --help"
- "dvilj2p self version"

## Installation
```bash
apt-get install texlive-binaries 2>/dev/null || which dvilj2p
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
