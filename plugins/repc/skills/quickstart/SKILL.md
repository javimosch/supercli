# repc Plugin

CLI tool: repc.

## Commands
- `repc <resource> <action>` — Execute repc commands
- `repc self version` — Print repc version
- `repc _ _` — Passthrough to repc CLI

## Usage Examples
- "repc --help"
- "repc self version"

## Installation
```bash
apt-get install repc 2>/dev/null || which repc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
