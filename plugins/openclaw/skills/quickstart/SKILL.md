# openclaw Plugin

Your own personal AI assistant. Any OS. Any Platform. The lobster way. 🦞 

## Commands
- `openclaw <resource> <action>` — Execute openclaw commands
- `openclaw self version` — Print openclaw version
- `openclaw _ _` — Passthrough to openclaw CLI

## Installation

```bash
pip install openclaw
```
