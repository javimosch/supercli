# filelight Plugin

filelight shows disk usage as a radial map.

## Commands
- `filelight <resource> <action>` — Execute filelight commands
- `filelight self version` — Print filelight version
- `filelight _ _` — Passthrough to filelight CLI

## Usage Examples

- "analyze disk usage in the current directory"
- "find large files in home directory"
- "visualize storage distribution"

## Installation

```bash
brew install filelight
```

## Key Features
- Visual radial map of disk usage
- Interactive directory scanning
- Large file identification
- Storage distribution visualization
- Directory size comparison
