# progress Plugin

progress — view progress of running coreutils commands (cp, mv, dd, tar, cat, rsync, grep, find, sort)..

## Commands

### `sc progress process monitor`
Show progress of running coreutils commands.

### `sc progress process watch`
Watch progress continuously.

### `sc progress self version`
Print progress version.

## Installation

```bash
sudo apt-get install progress
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
