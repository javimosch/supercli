# qp Plugin
Multi-ecosystem package query tool.
## Commands
- `qp self version` — Print version
- `qp _ _` — Passthrough to qp CLI
## Installation
```bash
cargo install qp
```
## Key Features
- **Multi-ecosystem** — npm, flatpak, brew
- **Boolean queries** — Advanced search logic
- **JSON output** — Structured results
- **Pipeline-ready** — Automation support
