# mpifort.openmpi Plugin

CLI tool: mpifort.openmpi.

## Commands
- `mpifort.openmpi <resource> <action>` — Execute mpifort.openmpi commands
- `mpifort.openmpi self version` — Print mpifort.openmpi version
- `mpifort.openmpi _ _` — Passthrough to mpifort.openmpi CLI

## Usage Examples
- "mpifort.openmpi --help"
- "mpifort.openmpi self version"

## Installation
```bash
apt-get install mpifort.openmpi 2>/dev/null || which mpifort.openmpi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
