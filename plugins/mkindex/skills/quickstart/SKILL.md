# mkindex Plugin

CLI tool: mkindex.

## Commands
- `mkindex <resource> <action>` — Execute mkindex commands
- `mkindex self version` — Print mkindex version
- `mkindex _ _` — Passthrough to mkindex CLI

## Usage Examples
- "mkindex --help"
- "mkindex self version"

## Installation
```bash
apt-get install mkindex 2>/dev/null || which mkindex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
