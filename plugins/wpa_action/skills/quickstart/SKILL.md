# wpa_action Plugin

CLI tool: wpa_action.

## Commands
- `wpa_action <resource> <action>` — Execute wpa_action commands
- `wpa_action self version` — Print wpa_action version
- `wpa_action _ _` — Passthrough to wpa_action CLI

## Usage Examples
- "wpa_action --help"
- "wpa_action self version"

## Installation
```bash
apt-get install wpa_action 2>/dev/null || which wpa_action
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
