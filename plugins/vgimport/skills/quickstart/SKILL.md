# vgimport Plugin

CLI tool: vgimport.

## Commands
- `vgimport <resource> <action>` — Execute vgimport commands
- `vgimport self version` — Print vgimport version
- `vgimport _ _` — Passthrough to vgimport CLI

## Usage Examples
- "vgimport --help"
- "vgimport self version"

## Installation
```bash
apt-get install vgimport 2>/dev/null || which vgimport
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
