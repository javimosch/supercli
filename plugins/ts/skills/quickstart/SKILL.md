# ts Plugin

CLI tool: ts.

## Commands
- `ts <resource> <action>` — Execute ts commands
- `ts self version` — Print ts version
- `ts _ _` — Passthrough to ts CLI

## Usage Examples
- "ts --help"
- "ts self version"

## Installation
```bash
apt-get install ts 2>/dev/null || which ts
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
