# AiToEarn Plugin

Let's use AI to Earn!

## Commands
- `AiToEarn <resource> <action>` — Execute AiToEarn commands
- `AiToEarn self version` — Print AiToEarn version
- `AiToEarn _ _` — Passthrough to aitoearn CLI

## Installation

```bash
pip install aitoearn
```
