# zig-dotenv Plugin
Fast .env file parser and manager.
## Commands
- `zig-dotenv _ _` — Passthrough to zig-dotenv CLI
## Installation
```bash
git clone https://github.com/xcaeser/zig-dotenv && cd zig-dotenv && zig build
```
## Key Features
- **.env parsing** — Read and manage env files
- **Fast** — Zig-powered performance
- **Pipeline-ready** — stdin/stdout support
