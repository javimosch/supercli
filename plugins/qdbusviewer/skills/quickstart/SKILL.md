# qdbusviewer Plugin

CLI tool: qdbusviewer.

## Commands
- `qdbusviewer <resource> <action>` — Execute qdbusviewer commands
- `qdbusviewer self version` — Print qdbusviewer version
- `qdbusviewer _ _` — Passthrough to qdbusviewer CLI

## Usage Examples
- "qdbusviewer --help"
- "qdbusviewer self version"

## Installation
```bash
apt-get install qdbusviewer 2>/dev/null || which qdbusviewer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
