# tika-cli Plugin
Extract text and metadata from various file formats

## Commands
- `tika-cli <resource> <action>` — Execute tika-cli commands
- `tika-cli _ _` — Passthrough to tika-cli CLI

## Usage
- `tika-cli _ _ <args>` — Run tika-cli with any arguments
