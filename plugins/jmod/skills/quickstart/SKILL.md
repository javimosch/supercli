# jmod Plugin

CLI tool: jmod.

## Commands
- `jmod <resource> <action>` — Execute jmod commands
- `jmod self version` — Print jmod version
- `jmod _ _` — Passthrough to jmod CLI

## Usage Examples
- "jmod --help"
- "jmod self version"

## Installation
```bash
apt-get install jmod 2>/dev/null || which jmod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
