# gdiffmk Plugin

CLI tool: gdiffmk.

## Commands
- `gdiffmk <resource> <action>` — Execute gdiffmk commands
- `gdiffmk self version` — Print gdiffmk version
- `gdiffmk _ _` — Passthrough to gdiffmk CLI

## Usage Examples
- "gdiffmk --help"
- "gdiffmk self version"

## Installation
```bash
apt-get install gdiffmk 2>/dev/null || which gdiffmk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
