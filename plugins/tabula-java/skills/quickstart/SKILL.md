# tabula-java Plugin
Extract tables from PDFs into CSV using Java CLI

## Commands
- `tabula-java <resource> <action>` — Execute tabula-java commands
- `tabula-java _ _` — Passthrough to tabula-java CLI

## Usage
- `tabula-java _ _ <args>` — Run tabula-java with any arguments
