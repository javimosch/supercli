# mdatopbm Plugin

CLI tool: mdatopbm.

## Commands
- `mdatopbm <resource> <action>` — Execute mdatopbm commands
- `mdatopbm self version` — Print mdatopbm version
- `mdatopbm _ _` — Passthrough to mdatopbm CLI

## Usage Examples
- "mdatopbm --help"
- "mdatopbm self version"

## Installation
```bash
apt-get install mdatopbm 2>/dev/null || which mdatopbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
