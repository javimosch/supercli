# l2test Plugin

CLI tool: l2test.

## Commands
- `l2test <resource> <action>` — Execute l2test commands
- `l2test self version` — Print l2test version
- `l2test _ _` — Passthrough to l2test CLI

## Usage Examples
- "l2test --help"
- "l2test self version"

## Installation
```bash
apt-get install l2test 2>/dev/null || which l2test
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
