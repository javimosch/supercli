# grog Plugin

CLI tool: grog.

## Commands
- `grog <resource> <action>` — Execute grog commands
- `grog self version` — Print grog version
- `grog _ _` — Passthrough to grog CLI

## Usage Examples
- "grog --help"
- "grog self version"

## Installation
```bash
apt-get install grog 2>/dev/null || which grog
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
