# esac Plugin

CLI tool: esac.

## Commands
- `esac <resource> <action>` — Execute esac commands
- `esac self version` — Print esac version
- `esac _ _` — Passthrough to esac CLI

## Usage Examples
- "esac --help"
- "esac self version"

## Installation
```bash
apt-get install esac 2>/dev/null || which esac
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
