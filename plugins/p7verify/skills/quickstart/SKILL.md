# p7verify Plugin

CLI tool: p7verify.

## Commands
- `p7verify <resource> <action>` — Execute p7verify commands
- `p7verify self version` — Print p7verify version
- `p7verify _ _` — Passthrough to p7verify CLI

## Usage Examples
- "p7verify --help"
- "p7verify self version"

## Installation
```bash
apt-get install p7verify 2>/dev/null || which p7verify
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
