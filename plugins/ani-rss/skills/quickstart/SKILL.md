# ani-rss Plugin

基于RSS自动追番、订阅、下载、刮削、洗版

## Commands

### General
- `ani-rss self version` — Print ani-rss version
- `ani-rss _ _` — Passthrough to ani-rss CLI

## Installation

```bash
pip install ani-rss
```

- 基于RSS自动追番、订阅、下载、刮削、洗版
