# svgbob_cli Plugin

CLI tool: svgbob_cli.

## Commands
- `svgbob_cli <resource> <action>` — Execute svgbob_cli commands
- `svgbob_cli self version` — Print svgbob_cli version
- `svgbob_cli _ _` — Passthrough to svgbob_cli CLI

## Usage Examples
- "svgbob_cli --help"
- "svgbob_cli self version"

## Installation
```bash
apt-get install svgbob_cli 2>/dev/null || which svgbob_cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
