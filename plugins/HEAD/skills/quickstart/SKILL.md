# HEAD Plugin

CLI tool: HEAD.

## Commands
- `HEAD <resource> <action>` — Execute HEAD commands
- `HEAD self version` — Print HEAD version
- `HEAD _ _` — Passthrough to HEAD CLI

## Usage Examples
- "HEAD --help"
- "HEAD self version"

## Installation
```bash
apt-get install HEAD 2>/dev/null || which HEAD
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
