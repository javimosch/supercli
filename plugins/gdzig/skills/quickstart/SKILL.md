# gdzig Plugin

Zig bindings for Godot 4

## Commands

### General
- `gdzig self version` — Print gdzig version
- `gdzig _ _` — Passthrough to gdzig CLI

## Usage Examples
- "Run gdzig"
- "Use gdzig to Zig bindings for Godot 4"

## Installation

```bash
pip install gdzig
```

## Key Features
- Zig bindings for Godot 4
- CLI tool, headless and scriptable
