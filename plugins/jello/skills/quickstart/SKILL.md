# jello Plugin

jello — jq alternative in Python. Query JSON with Python syntax..

## Commands

### `sc jello json query`
Query JSON with Python syntax.

### `sc jello self version`
Print version.

## Installation

```bash
pip install jello
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
