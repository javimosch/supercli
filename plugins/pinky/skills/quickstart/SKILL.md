# pinky Plugin

CLI tool: pinky.

## Commands
- `pinky <resource> <action>` — Execute pinky commands
- `pinky self version` — Print pinky version
- `pinky _ _` — Passthrough to pinky CLI

## Usage Examples
- "pinky --help"
- "pinky self version"

## Installation
```bash
apt-get install pinky 2>/dev/null || which pinky
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
