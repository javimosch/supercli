# lvrename Plugin

CLI tool: lvrename.

## Commands
- `lvrename <resource> <action>` — Execute lvrename commands
- `lvrename self version` — Print lvrename version
- `lvrename _ _` — Passthrough to lvrename CLI

## Usage Examples
- "lvrename --help"
- "lvrename self version"

## Installation
```bash
apt-get install lvrename 2>/dev/null || which lvrename
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
