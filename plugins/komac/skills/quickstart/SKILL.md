# komac Plugin
CLI tool for komac.

## Commands
- `komac <resource> <action>` — Execute komac commands
- `komac _ _` — Passthrough to komac CLI

## Installation
```bash
cargo install komac
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
