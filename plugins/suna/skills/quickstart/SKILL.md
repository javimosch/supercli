# suna Plugin

The Company AI Command Center

## Commands

### General
- `suna self version` — Print suna version
- `suna _ _` — Passthrough to suna CLI

- "Run suna"
- "Use suna to The Company AI Command Center"

## Installation

```bash
pip install suna
```
