# Hashsigs-Ts Plugin

Hash-based signatures (WOTS+) implementation in TypeScript

## Commands
- `hashsigs-ts _ _` — Passthrough to hashsigs-ts CLI

## Installation

```bash
npm install -g hashsigs-ts
```

## Examples
```bash
hashsigs-ts --help
hashsigs-ts --version
```
