# gendict Plugin

CLI tool: gendict.

## Commands
- `gendict <resource> <action>` — Execute gendict commands
- `gendict self version` — Print gendict version
- `gendict _ _` — Passthrough to gendict CLI

## Usage Examples
- "gendict --help"
- "gendict self version"

## Installation
```bash
apt-get install gendict 2>/dev/null || which gendict
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
