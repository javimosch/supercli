# dotty Plugin

CLI tool: dotty.

## Commands
- `dotty <resource> <action>` — Execute dotty commands
- `dotty self version` — Print dotty version
- `dotty _ _` — Passthrough to dotty CLI

## Usage Examples
- "dotty --help"
- "dotty self version"

## Installation
```bash
apt-get install dotty 2>/dev/null || which dotty
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
