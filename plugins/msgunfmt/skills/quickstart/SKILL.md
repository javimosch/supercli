# msgunfmt Plugin

CLI tool: msgunfmt.

## Commands
- `msgunfmt <resource> <action>` — Execute msgunfmt commands
- `msgunfmt self version` — Print msgunfmt version
- `msgunfmt _ _` — Passthrough to msgunfmt CLI

## Usage Examples
- "msgunfmt --help"
- "msgunfmt self version"

## Installation
```bash
apt-get install msgunfmt 2>/dev/null || which msgunfmt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
