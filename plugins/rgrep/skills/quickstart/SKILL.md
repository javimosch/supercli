# rgrep Plugin

CLI tool: rgrep.

## Commands
- `rgrep <resource> <action>` — Execute rgrep commands
- `rgrep self version` — Print rgrep version
- `rgrep _ _` — Passthrough to rgrep CLI

## Usage Examples
- "rgrep --help"
- "rgrep self version"

## Installation
```bash
apt-get install rgrep 2>/dev/null || which rgrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
