# vphone-aio Plugin

1 script run the vphone

## Commands

### General
- `vphone-aio self version` — Print vphone-aio version
- `vphone-aio _ _` — Passthrough to vphone-aio CLI

## Usage Examples
- "Run vphone-aio"
- "Use vphone-aio to 1 script run the vphone"

## Installation

```bash
pip install vphone-aio
```

## Key Features
- 1 script run the vphone
- CLI tool, headless and scriptable
