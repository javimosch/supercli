# lessecho Plugin

CLI tool: lessecho.

## Commands
- `lessecho <resource> <action>` — Execute lessecho commands
- `lessecho self version` — Print lessecho version
- `lessecho _ _` — Passthrough to lessecho CLI

## Usage Examples
- "lessecho --help"
- "lessecho self version"

## Installation
```bash
apt-get install lessecho 2>/dev/null || which lessecho
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
