# dbmigrate Plugin
Rust-based CLI for simple Up/Down SQL migration files

## Commands
- `dbmigrate <resource> <action>` — Execute dbmigrate commands
- `dbmigrate _ _` — Passthrough to dbmigrate CLI

## Usage
- `dbmigrate _ _ <args>` — Run dbmigrate with any arguments
