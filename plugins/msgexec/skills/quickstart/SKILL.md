# msgexec Plugin

CLI tool: msgexec.

## Commands
- `msgexec <resource> <action>` — Execute msgexec commands
- `msgexec self version` — Print msgexec version
- `msgexec _ _` — Passthrough to msgexec CLI

## Usage Examples
- "msgexec --help"
- "msgexec self version"

## Installation
```bash
apt-get install msgexec 2>/dev/null || which msgexec
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
