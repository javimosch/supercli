# litestream Plugin
Streaming SQLite replication to S3 for disaster recovery

## Commands
- `litestream <resource> <action>` — Execute litestream commands
- `litestream _ _` — Passthrough to litestream CLI

## Usage
- `litestream _ _ <args>` — Run litestream with any arguments
