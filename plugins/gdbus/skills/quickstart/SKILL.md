# gdbus Plugin

CLI tool: gdbus.

## Commands
- `gdbus <resource> <action>` — Execute gdbus commands
- `gdbus self version` — Print gdbus version
- `gdbus _ _` — Passthrough to gdbus CLI

## Usage Examples
- "gdbus --help"
- "gdbus self version"

## Installation
```bash
apt-get install gdbus 2>/dev/null || which gdbus
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
