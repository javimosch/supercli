# gnome-session-properties Plugin

CLI tool: gnome-session-properties.

## Commands
- `gnome-session-properties <resource> <action>` — Execute gnome-session-properties commands
- `gnome-session-properties self version` — Print gnome-session-properties version
- `gnome-session-properties _ _` — Passthrough to gnome-session-properties CLI

## Usage Examples
- "gnome-session-properties --help"
- "gnome-session-properties self version"

## Installation
```bash
apt-get install gnome-session-properties 2>/dev/null || which gnome-session-properties
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
