# JxrDecApp Plugin

CLI tool: JxrDecApp.

## Commands
- `JxrDecApp <resource> <action>` — Execute JxrDecApp commands
- `JxrDecApp self version` — Print JxrDecApp version
- `JxrDecApp _ _` — Passthrough to JxrDecApp CLI

## Usage Examples
- "JxrDecApp --help"
- "JxrDecApp self version"

## Installation
```bash
apt-get install JxrDecApp 2>/dev/null || which JxrDecApp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
