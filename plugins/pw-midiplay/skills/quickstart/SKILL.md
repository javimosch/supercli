# pw-midiplay Plugin

CLI tool: pw-midiplay.

## Commands
- `pw-midiplay <resource> <action>` — Execute pw-midiplay commands
- `pw-midiplay self version` — Print pw-midiplay version
- `pw-midiplay _ _` — Passthrough to pw-midiplay CLI

## Usage Examples
- "pw-midiplay --help"
- "pw-midiplay self version"

## Installation
```bash
apt-get install pw-midiplay 2>/dev/null || which pw-midiplay
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
