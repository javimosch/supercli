# identify-cli Plugin

CLI tool: identify-cli.

## Commands
- `identify-cli <resource> <action>` — Execute identify-cli commands
- `identify-cli self version` — Print identify-cli version
- `identify-cli _ _` — Passthrough to identify-cli CLI

## Usage Examples
- "identify-cli --help"
- "identify-cli self version"

## Installation
```bash
apt-get install identify-cli 2>/dev/null || which identify-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
