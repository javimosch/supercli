# uz Plugin

CLI tool: uz.

## Commands
- `uz <resource> <action>` — Execute uz commands
- `uz self version` — Print uz version
- `uz _ _` — Passthrough to uz CLI

## Usage Examples
- "uz --help"
- "uz self version"

## Installation
```bash
apt-get install uz 2>/dev/null || which uz
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
