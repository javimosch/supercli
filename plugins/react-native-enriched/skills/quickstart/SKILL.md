# react-native-enriched Plugin

Rich Text Editor for React Native

## Commands

### General
- `react-native-enriched self version` — Print react-native-enriched version
- `react-native-enriched _ _` — Passthrough to react-native-enriched CLI

## Usage Examples
- "Run react-native-enriched"
- "Use react-native-enriched to Rich Text Editor for React Native"

## Installation

```bash
pip install react-native-enriched
```

## Key Features
- Rich Text Editor for React Native
- CLI tool, headless and scriptable
