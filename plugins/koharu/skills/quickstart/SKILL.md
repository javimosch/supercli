# koharu Plugin

ML-powered manga translator, written in Rust.

## Commands

### General
- `koharu self version` — Print koharu version
- `koharu _ _` — Passthrough to koharu CLI

## Usage Examples
- "Run koharu"
- "Use koharu to ML-powered manga translator, written in Rust."

## Installation

```bash
pip install koharu
```

## Key Features
- ML-powered manga translator, written in Rust.
- CLI tool, headless and scriptable
