# simpdftex Plugin

CLI tool: simpdftex.

## Commands
- `simpdftex <resource> <action>` — Execute simpdftex commands
- `simpdftex self version` — Print simpdftex version
- `simpdftex _ _` — Passthrough to simpdftex CLI

## Usage Examples
- "simpdftex --help"
- "simpdftex self version"

## Installation
```bash
apt-get install simpdftex 2>/dev/null || which simpdftex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
