# nss-addbuiltin Plugin

CLI tool: nss-addbuiltin.

## Commands
- `nss-addbuiltin <resource> <action>` — Execute nss-addbuiltin commands
- `nss-addbuiltin self version` — Print nss-addbuiltin version
- `nss-addbuiltin _ _` — Passthrough to nss-addbuiltin CLI

## Usage Examples
- "nss-addbuiltin --help"
- "nss-addbuiltin self version"

## Installation
```bash
apt-get install nss-addbuiltin 2>/dev/null || which nss-addbuiltin
```
