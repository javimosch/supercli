# semver-diff-cli Plugin
CLI tool for semver-diff-cli.

## Commands
- `semver-diff-cli <resource> <action>` — Execute semver-diff-cli commands
- `semver-diff-cli _ _` — Passthrough to semver-diff-cli CLI

## Installation
```bash
cargo install semver-diff-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
