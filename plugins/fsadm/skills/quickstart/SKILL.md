# fsadm Plugin

CLI tool: fsadm.

## Commands
- `fsadm <resource> <action>` — Execute fsadm commands
- `fsadm self version` — Print fsadm version
- `fsadm _ _` — Passthrough to fsadm CLI

## Usage Examples
- "fsadm --help"
- "fsadm self version"

## Installation
```bash
apt-get install fsadm 2>/dev/null || which fsadm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
