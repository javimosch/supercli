# ngettext Plugin

CLI tool: ngettext.

## Commands
- `ngettext <resource> <action>` — Execute ngettext commands
- `ngettext self version` — Print ngettext version
- `ngettext _ _` — Passthrough to ngettext CLI

## Usage Examples
- "ngettext --help"
- "ngettext self version"

## Installation
```bash
apt-get install ngettext 2>/dev/null || which ngettext
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
