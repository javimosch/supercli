# cups.cancel Plugin

CLI tool: cups.cancel.

## Commands
- `cups.cancel <resource> <action>` — Execute cups.cancel commands
- `cups.cancel self version` — Print cups.cancel version
- `cups.cancel _ _` — Passthrough to cups.cancel CLI

## Usage Examples
- "cups.cancel --help"
- "cups.cancel self version"

## Installation
```bash
apt-get install cups.cancel 2>/dev/null || which cups.cancel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
