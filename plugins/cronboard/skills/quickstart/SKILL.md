# cronboard Plugin

A terminal-based dashboard for managing cron jobs locally and on servers. Python/pip installable, no auth required.

## Commands
- `cronboard self version` — Print version
- `cronboard _ _ <args>` — Passthrough to cronboard

## Usage Examples
- "Cron Dashboard"

## Installation
```bash
pip install cronboard
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
