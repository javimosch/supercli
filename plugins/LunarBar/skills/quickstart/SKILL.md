# LunarBar Plugin

A compact lunar calendar for your macOS menu bar.

## Commands

### General
- `LunarBar self version` — Print LunarBar version
- `LunarBar _ _` — Passthrough to lunarbar CLI

## Usage Examples
- "Run LunarBar"
- "Use lunarbar to A compact lunar calendar for your macOS menu bar."

## Installation

```bash
pip install lunarbar
```

## Key Features
- A compact lunar calendar for your macOS menu bar.
- CLI tool, headless and scriptable
