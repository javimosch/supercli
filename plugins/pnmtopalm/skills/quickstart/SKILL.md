# pnmtopalm Plugin

CLI tool: pnmtopalm.

## Commands
- `pnmtopalm <resource> <action>` — Execute pnmtopalm commands
- `pnmtopalm self version` — Print pnmtopalm version
- `pnmtopalm _ _` — Passthrough to pnmtopalm CLI

## Usage Examples
- "pnmtopalm --help"
- "pnmtopalm self version"

## Installation
```bash
apt-get install pnmtopalm 2>/dev/null || which pnmtopalm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
