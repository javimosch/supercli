# nvidia-detector Plugin

CLI tool: nvidia-detector.

## Commands
- `nvidia-detector <resource> <action>` — Execute nvidia-detector commands
- `nvidia-detector self version` — Print nvidia-detector version
- `nvidia-detector _ _` — Passthrough to nvidia-detector CLI

## Usage Examples
- "nvidia-detector --help"
- "nvidia-detector self version"

## Installation
```bash
apt-get install nvidia-detector 2>/dev/null || which nvidia-detector
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
