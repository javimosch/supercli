# xclip-pastefile Plugin

CLI tool: xclip-pastefile.

## Commands
- `xclip-pastefile <resource> <action>` — Execute xclip-pastefile commands
- `xclip-pastefile self version` — Print xclip-pastefile version
- `xclip-pastefile _ _` — Passthrough to xclip-pastefile CLI

## Usage Examples
- "xclip-pastefile --help"
- "xclip-pastefile self version"

## Installation
```bash
apt-get install xclip-pastefile 2>/dev/null || which xclip-pastefile
```
