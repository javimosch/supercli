# gnome-power-statistics Plugin

CLI tool: gnome-power-statistics.

## Commands
- `gnome-power-statistics <resource> <action>` — Execute gnome-power-statistics commands
- `gnome-power-statistics self version` — Print gnome-power-statistics version
- `gnome-power-statistics _ _` — Passthrough to gnome-power-statistics CLI

## Usage Examples
- "gnome-power-statistics --help"
- "gnome-power-statistics self version"

## Installation
```bash
apt-get install gnome-power-statistics 2>/dev/null || which gnome-power-statistics
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
