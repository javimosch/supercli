# cargo-deny-config Plugin
Configuration and advisory database for cargo-deny

## Commands
- `cargo-deny-config <resource> <action>` — Execute cargo-deny-config commands
- `cargo-deny-config _ _` — Passthrough to cargo-deny-config CLI

## Usage
- `cargo-deny-config _ _ <args>` — Run cargo-deny-config with any arguments
