# cargo-about Plugin
Generate license and dependency reports for Rust crates

## Commands
- `cargo-about <resource> <action>` — Execute cargo-about commands
- `cargo-about _ _` — Passthrough to cargo-about CLI

## Usage
- `cargo-about _ _ <args>` — Run cargo-about with any arguments
