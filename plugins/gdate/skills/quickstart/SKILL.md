# gdate Plugin
GNU date for advanced date formatting

## Commands
- `gdate <resource> <action>` — Execute gdate commands
- `gdate self version` — Print gdate version
- `gdate _ _` — Passthrough to gdate CLI

## Usage
- `gdate _ _ <args>` — Run gdate with any arguments
