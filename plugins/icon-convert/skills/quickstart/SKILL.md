# icon-convert Plugin
Convert images to ICO and other icon formats

## Commands
- `icon-convert <resource> <action>` — Execute icon-convert commands
- `icon-convert _ _` — Passthrough to icon-convert CLI

## Usage
- `icon-convert _ _ <args>` — Run icon-convert with any arguments
