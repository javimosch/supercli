# ip-geo-cli Plugin
Fetch geolocation data for IP addresses via CLI

## Commands
- `ip-geo-cli <resource> <action>` — Execute ip-geo-cli commands
- `ip-geo-cli _ _` — Passthrough to ip-geo-cli CLI

## Usage
- `ip-geo-cli _ _ <args>` — Run ip-geo-cli with any arguments
