# mdproof Plugin
Standalone Rust-powered Markdown to PDF converter

## Commands
- `mdproof <resource> <action>` — Execute mdproof commands
- `mdproof _ _` — Passthrough to mdproof CLI

## Usage
- `mdproof _ _ <args>` — Run mdproof with any arguments
