# serde.zig Plugin

Universal serialization for Zig

## Commands

### Version
`serde.zig self version` — Print serde.zig version

### Passthrough
`serde.zig _ _` — Passthrough to serde CLI with all arguments forwarded.

## Usage Examples

```bash
serde --version
serde --help
```

## Installation

```bash
cargo install serde-zig
```

## Key Features
- Universal serialization for Zig
