# tgatoppm Plugin

CLI tool: tgatoppm.

## Commands
- `tgatoppm <resource> <action>` — Execute tgatoppm commands
- `tgatoppm self version` — Print tgatoppm version
- `tgatoppm _ _` — Passthrough to tgatoppm CLI

## Usage Examples
- "tgatoppm --help"
- "tgatoppm self version"

## Installation
```bash
apt-get install tgatoppm 2>/dev/null || which tgatoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
