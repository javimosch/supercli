# turborepo Plugin
High-performance build system for monorepos

## Commands
- `turborepo <resource> <action>` — Execute turborepo commands
- `turborepo _ _` — Passthrough to turborepo CLI

## Usage
- `turborepo _ _ <args>` — Run turborepo with any arguments
