# WuKongIM Plugin

More than just IM 不只是即时通讯(IM)

## Commands
- `WuKongIM <resource> <action>` — Execute WuKongIM commands
- `WuKongIM self version` — Print WuKongIM version
- `WuKongIM _ _` — Passthrough to wukongim CLI

## Installation

```bash
pip install wukongim
```
