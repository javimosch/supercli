# sdptool Plugin

CLI tool: sdptool.

## Commands
- `sdptool <resource> <action>` — Execute sdptool commands
- `sdptool self version` — Print sdptool version
- `sdptool _ _` — Passthrough to sdptool CLI

## Usage Examples
- "sdptool --help"
- "sdptool self version"

## Installation
```bash
apt-get install sdptool 2>/dev/null || which sdptool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
