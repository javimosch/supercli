# pnmtopng Plugin

CLI tool: pnmtopng.

## Commands
- `pnmtopng <resource> <action>` — Execute pnmtopng commands
- `pnmtopng self version` — Print pnmtopng version
- `pnmtopng _ _` — Passthrough to pnmtopng CLI

## Usage Examples
- "pnmtopng --help"
- "pnmtopng self version"

## Installation
```bash
apt-get install pnmtopng 2>/dev/null || which pnmtopng
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
