# tred Plugin

CLI tool: tred.

## Commands
- `tred <resource> <action>` — Execute tred commands
- `tred self version` — Print tred version
- `tred _ _` — Passthrough to tred CLI

## Usage Examples
- "tred --help"
- "tred self version"

## Installation
```bash
apt-get install tred 2>/dev/null || which tred
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
