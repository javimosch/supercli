# precat Plugin

CLI tool: precat.

## Commands
- `precat <resource> <action>` — Execute precat commands
- `precat self version` — Print precat version
- `precat _ _` — Passthrough to precat CLI

## Usage Examples
- "precat --help"
- "precat self version"

## Installation
```bash
apt-get install precat 2>/dev/null || which precat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
