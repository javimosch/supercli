# pbmtoepsi Plugin

CLI tool: pbmtoepsi.

## Commands
- `pbmtoepsi <resource> <action>` — Execute pbmtoepsi commands
- `pbmtoepsi self version` — Print pbmtoepsi version
- `pbmtoepsi _ _` — Passthrough to pbmtoepsi CLI

## Usage Examples
- "pbmtoepsi --help"
- "pbmtoepsi self version"

## Installation
```bash
apt-get install pbmtoepsi 2>/dev/null || which pbmtoepsi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
