# groupmod Plugin

CLI tool: groupmod.

## Commands
- `groupmod <resource> <action>` — Execute groupmod commands
- `groupmod self version` — Print groupmod version
- `groupmod _ _` — Passthrough to groupmod CLI

## Usage Examples
- "groupmod --help"
- "groupmod self version"

## Installation
```bash
apt-get install groupmod 2>/dev/null || which groupmod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
