# nwdiag Plugin
Generate network topology diagrams from text descriptions

## Commands
- `nwdiag <resource> <action>` — Execute nwdiag commands
- `nwdiag _ _` — Passthrough to nwdiag CLI

## Usage
- `nwdiag _ _ <args>` — Run nwdiag with any arguments
