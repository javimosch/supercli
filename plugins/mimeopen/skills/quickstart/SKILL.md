# mimeopen Plugin

CLI tool: mimeopen.

## Commands
- `mimeopen <resource> <action>` — Execute mimeopen commands
- `mimeopen self version` — Print mimeopen version
- `mimeopen _ _` — Passthrough to mimeopen CLI

## Usage Examples
- "mimeopen --help"
- "mimeopen self version"

## Installation
```bash
apt-get install mimeopen 2>/dev/null || which mimeopen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
