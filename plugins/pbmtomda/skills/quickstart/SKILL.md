# pbmtomda Plugin

CLI tool: pbmtomda.

## Commands
- `pbmtomda <resource> <action>` — Execute pbmtomda commands
- `pbmtomda self version` — Print pbmtomda version
- `pbmtomda _ _` — Passthrough to pbmtomda CLI

## Usage Examples
- "pbmtomda --help"
- "pbmtomda self version"

## Installation
```bash
apt-get install pbmtomda 2>/dev/null || which pbmtomda
```
