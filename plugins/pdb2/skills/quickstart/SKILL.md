# pdb2 Plugin

CLI tool: pdb2.

## Commands
- `pdb2 <resource> <action>` — Execute pdb2 commands
- `pdb2 self version` — Print pdb2 version
- `pdb2 _ _` — Passthrough to pdb2 CLI

## Usage Examples
- "pdb2 --help"
- "pdb2 self version"

## Installation
```bash
apt-get install pdb2 2>/dev/null || which pdb2
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
