# pg_duckdb Plugin

DuckDB-powered Postgres for high performance apps & analytics.

## Commands

### General
- `pg_duckdb self version` — Print pg_duckdb version
- `pg_duckdb _ _` — Passthrough to pg-duckdb CLI

- "Run pg_duckdb"

```bash
pip install pg-duckdb
```
