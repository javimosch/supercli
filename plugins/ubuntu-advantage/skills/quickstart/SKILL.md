# ubuntu-advantage Plugin

CLI tool: ubuntu-advantage.

## Commands
- `ubuntu-advantage <resource> <action>` — Execute ubuntu-advantage commands
- `ubuntu-advantage self version` — Print ubuntu-advantage version
- `ubuntu-advantage _ _` — Passthrough to ubuntu-advantage CLI

## Usage Examples
- "ubuntu-advantage --help"
- "ubuntu-advantage self version"

## Installation
```bash
apt-get install ubuntu-advantage 2>/dev/null || which ubuntu-advantage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
