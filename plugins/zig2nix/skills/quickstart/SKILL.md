# zig2nix Plugin

Flake for packaging, building and running Zig projects.

## Commands

### General
- `zig2nix self version` — Print zig2nix version
- `zig2nix _ _` — Passthrough to zig2nix CLI

## Usage Examples
- "Run zig2nix"
- "Use zig2nix to Flake for packaging, building and running Zig projects."

## Installation

```bash
pip install zig2nix
```

## Key Features
- Flake for packaging, building and running Zig projects.
- CLI tool, headless and scriptable
