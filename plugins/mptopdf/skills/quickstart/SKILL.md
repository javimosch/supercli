# mptopdf Plugin

CLI tool: mptopdf.

## Commands
- `mptopdf <resource> <action>` — Execute mptopdf commands
- `mptopdf self version` — Print mptopdf version
- `mptopdf _ _` — Passthrough to mptopdf CLI

## Usage Examples
- "mptopdf --help"
- "mptopdf self version"

## Installation
```bash
apt-get install mptopdf 2>/dev/null || which mptopdf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
