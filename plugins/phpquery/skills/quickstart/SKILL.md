# phpquery Plugin

CLI tool: phpquery.

## Commands
- `phpquery <resource> <action>` — Execute phpquery commands
- `phpquery self version` — Print phpquery version
- `phpquery _ _` — Passthrough to phpquery CLI

## Usage Examples
- "phpquery --help"
- "phpquery self version"

## Installation
```bash
apt-get install phpquery 2>/dev/null || which phpquery
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
