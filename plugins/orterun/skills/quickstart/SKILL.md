# orterun Plugin

CLI tool: orterun.

## Commands
- `orterun <resource> <action>` — Execute orterun commands
- `orterun self version` — Print orterun version
- `orterun _ _` — Passthrough to orterun CLI

## Usage Examples
- "orterun --help"
- "orterun self version"

## Installation
```bash
apt-get install orterun 2>/dev/null || which orterun
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
