# fmtutil Plugin

CLI tool: fmtutil.

## Commands
- `fmtutil <resource> <action>` — Execute fmtutil commands
- `fmtutil self version` — Print fmtutil version
- `fmtutil _ _` — Passthrough to fmtutil CLI

## Usage Examples
- "fmtutil --help"
- "fmtutil self version"

## Installation
```bash
apt-get install fmtutil 2>/dev/null || which fmtutil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
