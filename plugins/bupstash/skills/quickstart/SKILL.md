# bupstash Plugin
Encrypted efficient deduplicated backup tool in Rust

## Commands
- `bupstash <resource> <action>` — Execute bupstash commands
- `bupstash _ _` — Passthrough to bupstash CLI

## Usage
- `bupstash _ _ <args>` — Run bupstash with any arguments
