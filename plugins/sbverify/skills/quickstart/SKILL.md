# sbverify Plugin

CLI tool: sbverify.

## Commands
- `sbverify <resource> <action>` — Execute sbverify commands
- `sbverify self version` — Print sbverify version
- `sbverify _ _` — Passthrough to sbverify CLI

## Usage Examples
- "sbverify --help"
- "sbverify self version"

## Installation
```bash
apt-get install sbverify 2>/dev/null || which sbverify
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
