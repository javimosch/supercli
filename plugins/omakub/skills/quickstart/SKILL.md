# omakub Plugin

Opinionated Ubuntu Setup

## Commands

### General
- `omakub self version` — Print omakub version
- `omakub _ _` — Passthrough to omakub CLI

## Usage Examples

## Installation

```bash
pip install omakub
```

- Opinionated Ubuntu Setup
