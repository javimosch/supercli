# safety-db Plugin
Curated database of insecure Python packages

## Commands
- `safety-db <resource> <action>` — Execute safety-db commands
- `safety-db _ _` — Passthrough to safety-db CLI

## Usage
- `safety-db _ _ <args>` — Run safety-db with any arguments
