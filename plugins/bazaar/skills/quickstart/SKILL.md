# bazaar Plugin

New App Store for GNOME

## Commands

### General
- `bazaar self version` — Print bazaar version
- `bazaar _ _` — Passthrough to bazaar CLI

## Usage Examples
- "Run bazaar"
- "Use bazaar to New App Store for GNOME"

## Installation

```bash
pip install bazaar
```

## Key Features
- New App Store for GNOME
- CLI tool, headless and scriptable
