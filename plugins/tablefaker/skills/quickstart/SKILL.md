# tablefaker Plugin
Generate realistic synthetic table data from YAML schema definitions

## Commands
- `tablefaker <resource> <action>` — Execute tablefaker commands
- `tablefaker _ _` — Passthrough to tablefaker CLI

## Usage
- `tablefaker _ _ <args>` — Run tablefaker with any arguments
