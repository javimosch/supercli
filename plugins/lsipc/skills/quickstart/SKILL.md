# lsipc Plugin

CLI tool: lsipc.

## Commands
- `lsipc <resource> <action>` — Execute lsipc commands
- `lsipc self version` — Print lsipc version
- `lsipc _ _` — Passthrough to lsipc CLI

## Usage Examples
- "lsipc --help"
- "lsipc self version"

## Installation
```bash
apt-get install lsipc 2>/dev/null || which lsipc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
