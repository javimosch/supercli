# morse-cli Plugin
Translate text to and from Morse code in the terminal

## Commands
- `morse-cli <resource> <action>` — Execute morse-cli commands
- `morse-cli _ _` — Passthrough to morse-cli CLI

## Usage
- `morse-cli _ _ <args>` — Run morse-cli with any arguments
