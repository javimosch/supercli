# ps Plugin
Report a snapshot of current processes

## Commands
- `ps <resource> <action>` — Execute ps commands
- `ps self version` — Print ps version
- `ps _ _` — Passthrough to ps CLI

## Usage
- `ps _ _ <args>` — Run ps with any arguments
- `ps self version` — Print ps version
