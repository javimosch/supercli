# ppmshift Plugin

CLI tool: ppmshift.

## Commands
- `ppmshift <resource> <action>` — Execute ppmshift commands
- `ppmshift self version` — Print ppmshift version
- `ppmshift _ _` — Passthrough to ppmshift CLI

## Usage Examples
- "ppmshift --help"
- "ppmshift self version"

## Installation
```bash
apt-get install ppmshift 2>/dev/null || which ppmshift
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
