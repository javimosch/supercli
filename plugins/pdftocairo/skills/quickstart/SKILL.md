# pdftocairo Plugin

CLI tool: pdftocairo.

## Commands
- `pdftocairo <resource> <action>` — Execute pdftocairo commands
- `pdftocairo self version` — Print pdftocairo version
- `pdftocairo _ _` — Passthrough to pdftocairo CLI

## Usage Examples
- "pdftocairo --help"
- "pdftocairo self version"

## Installation
```bash
apt-get install pdftocairo 2>/dev/null || which pdftocairo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
