# pdfparanoia Plugin
Remove watermarks from academic PDF papers

## Commands
- `pdfparanoia <resource> <action>` — Execute pdfparanoia commands
- `pdfparanoia _ _` — Passthrough to pdfparanoia CLI

## Usage
- `pdfparanoia _ _ <args>` — Run pdfparanoia with any arguments
