# rst2html5 Plugin

CLI tool: rst2html5.

## Commands
- `rst2html5 <resource> <action>` — Execute rst2html5 commands
- `rst2html5 self version` — Print rst2html5 version
- `rst2html5 _ _` — Passthrough to rst2html5 CLI

## Usage Examples
- "rst2html5 --help"
- "rst2html5 self version"

## Installation
```bash
apt-get install rst2html5 2>/dev/null || which rst2html5
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
