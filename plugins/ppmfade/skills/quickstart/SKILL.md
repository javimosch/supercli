# ppmfade Plugin

CLI tool: ppmfade.

## Commands
- `ppmfade <resource> <action>` — Execute ppmfade commands
- `ppmfade self version` — Print ppmfade version
- `ppmfade _ _` — Passthrough to ppmfade CLI

## Usage Examples
- "ppmfade --help"
- "ppmfade self version"

## Installation
```bash
apt-get install ppmfade 2>/dev/null || which ppmfade
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
