# whoopsie Plugin

CLI tool: whoopsie.

## Commands
- `whoopsie <resource> <action>` — Execute whoopsie commands
- `whoopsie self version` — Print whoopsie version
- `whoopsie _ _` — Passthrough to whoopsie CLI

## Usage Examples
- "whoopsie --help"
- "whoopsie self version"

## Installation
```bash
apt-get install whoopsie 2>/dev/null || which whoopsie
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
