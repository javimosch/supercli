# seq-utils Plugin
Lightweight collection of fasta/fastq sequence manipulation utilities

## Commands
- `seq-utils <resource> <action>` — Execute seq-utils commands
- `seq-utils _ _` — Passthrough to seq-utils CLI

## Usage
- `seq-utils _ _ <args>` — Run seq-utils with any arguments
