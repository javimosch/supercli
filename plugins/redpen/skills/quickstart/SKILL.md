# redpen Plugin

redpen — document validation tool for writing quality. Checks HTML, LaTeX, Markdown, and plain text documents for readability, sentencelength, paragraph structure, double negatives, and banned words. Supports custom validation rules via configuration files.

## Installation

```bash
npm install -g redpen
Verify: redpen --version
```

## Commands

### `sc redpen self version`

Print redpen version

## Passthrough

```bash
sc redpen _ _ <args...>
```

## SuperCLI

```bash
sc redpen _ _ --help
sc plugins learn redpen
```
