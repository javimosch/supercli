# tracker3 Plugin

CLI tool: tracker3.

## Commands
- `tracker3 <resource> <action>` — Execute tracker3 commands
- `tracker3 self version` — Print tracker3 version
- `tracker3 _ _` — Passthrough to tracker3 CLI

## Usage Examples
- "tracker3 --help"
- "tracker3 self version"

## Installation
```bash
apt-get install tracker3 2>/dev/null || which tracker3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
