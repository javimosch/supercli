# era_restore Plugin

CLI tool: era_restore.

## Commands
- `era_restore <resource> <action>` — Execute era_restore commands
- `era_restore self version` — Print era_restore version
- `era_restore _ _` — Passthrough to era_restore CLI

## Usage Examples
- "era_restore --help"
- "era_restore self version"

## Installation
```bash
apt-get install era_restore 2>/dev/null || which era_restore
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
