# microsoft365 Plugin

CLI tool: microsoft365.

## Commands
- `microsoft365 <resource> <action>` — Execute microsoft365 commands
- `microsoft365 self version` — Print microsoft365 version
- `microsoft365 _ _` — Passthrough to microsoft365 CLI

## Usage Examples
- "microsoft365 --help"
- "microsoft365 self version"

## Installation
```bash
apt-get install microsoft365 2>/dev/null || which microsoft365
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
