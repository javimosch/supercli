# dviconcat Plugin

CLI tool: dviconcat.

## Commands
- `dviconcat <resource> <action>` — Execute dviconcat commands
- `dviconcat self version` — Print dviconcat version
- `dviconcat _ _` — Passthrough to dviconcat CLI

## Usage Examples
- "dviconcat --help"
- "dviconcat self version"

## Installation
```bash
apt-get install dviconcat 2>/dev/null || which dviconcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
