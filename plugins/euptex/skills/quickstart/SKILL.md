# euptex Plugin

CLI tool: euptex.

## Commands
- `euptex <resource> <action>` — Execute euptex commands
- `euptex self version` — Print euptex version
- `euptex _ _` — Passthrough to euptex CLI

## Usage Examples
- "euptex --help"
- "euptex self version"

## Installation
```bash
apt-get install euptex 2>/dev/null || which euptex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
