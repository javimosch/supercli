# mcomp Plugin

CLI tool: mcomp.

## Commands
- `mcomp <resource> <action>` — Execute mcomp commands
- `mcomp self version` — Print mcomp version
- `mcomp _ _` — Passthrough to mcomp CLI

## Usage Examples
- "mcomp --help"
- "mcomp self version"

## Installation
```bash
apt-get install mcomp 2>/dev/null || which mcomp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
