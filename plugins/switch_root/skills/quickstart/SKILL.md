# switch_root Plugin

CLI tool: switch_root.

## Commands
- `switch_root <resource> <action>` — Execute switch_root commands
- `switch_root self version` — Print switch_root version
- `switch_root _ _` — Passthrough to switch_root CLI

## Usage Examples
- "switch_root --help"
- "switch_root self version"

## Installation
```bash
apt-get install switch_root 2>/dev/null || which switch_root
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
