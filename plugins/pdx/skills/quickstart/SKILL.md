# pdx Plugin

CLI tool: pdx.

## Commands
- `pdx <resource> <action>` — Execute pdx commands
- `pdx self version` — Print pdx version
- `pdx _ _` — Passthrough to pdx CLI

## Usage Examples
- "pdx --help"
- "pdx self version"

## Installation
```bash
apt-get install pdx 2>/dev/null || which pdx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
