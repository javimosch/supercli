# xtables-monitor Plugin

CLI tool: xtables-monitor.

## Commands
- `xtables-monitor <resource> <action>` — Execute xtables-monitor commands
- `xtables-monitor self version` — Print xtables-monitor version
- `xtables-monitor _ _` — Passthrough to xtables-monitor CLI

## Usage Examples
- "xtables-monitor --help"
- "xtables-monitor self version"

## Installation
```bash
apt-get install xtables-monitor 2>/dev/null || which xtables-monitor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
