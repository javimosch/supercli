# gnome-terminal Plugin

CLI tool: gnome-terminal.

## Commands
- `gnome-terminal <resource> <action>` — Execute gnome-terminal commands
- `gnome-terminal self version` — Print gnome-terminal version
- `gnome-terminal _ _` — Passthrough to gnome-terminal CLI

## Usage Examples
- "gnome-terminal --help"
- "gnome-terminal self version"

## Installation
```bash
apt-get install gnome-terminal 2>/dev/null || which gnome-terminal
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
