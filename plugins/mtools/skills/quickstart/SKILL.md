# mtools Plugin

CLI tool: mtools.

## Commands
- `mtools <resource> <action>` — Execute mtools commands
- `mtools self version` — Print mtools version
- `mtools _ _` — Passthrough to mtools CLI

## Usage Examples
- "mtools --help"
- "mtools self version"

## Installation
```bash
apt-get install mtools 2>/dev/null || which mtools
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
