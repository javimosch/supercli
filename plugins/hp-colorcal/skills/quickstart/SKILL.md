# hp-colorcal Plugin

CLI tool: hp-colorcal.

## Commands
- `hp-colorcal <resource> <action>` — Execute hp-colorcal commands
- `hp-colorcal self version` — Print hp-colorcal version
- `hp-colorcal _ _` — Passthrough to hp-colorcal CLI

## Usage Examples
- "hp-colorcal --help"
- "hp-colorcal self version"

## Installation
```bash
apt-get install hp-colorcal 2>/dev/null || which hp-colorcal
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
