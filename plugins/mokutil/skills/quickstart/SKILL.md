# mokutil Plugin

CLI tool: mokutil.

## Commands
- `mokutil <resource> <action>` — Execute mokutil commands
- `mokutil self version` — Print mokutil version
- `mokutil _ _` — Passthrough to mokutil CLI

## Usage Examples
- "mokutil --help"
- "mokutil self version"

## Installation
```bash
apt-get install mokutil 2>/dev/null || which mokutil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
