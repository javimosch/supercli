# load-tester Plugin
Lightweight HTTP load testing tool for performance

## Commands
- `load-tester <resource> <action>` — Execute load-tester commands
- `load-tester _ _` — Passthrough to load-tester CLI

## Usage
- `load-tester _ _ <args>` — Run load-tester with any arguments
