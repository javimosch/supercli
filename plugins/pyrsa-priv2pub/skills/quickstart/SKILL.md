# pyrsa-priv2pub Plugin

CLI tool: pyrsa-priv2pub.

## Commands
- `pyrsa-priv2pub <resource> <action>` — Execute pyrsa-priv2pub commands
- `pyrsa-priv2pub self version` — Print pyrsa-priv2pub version
- `pyrsa-priv2pub _ _` — Passthrough to pyrsa-priv2pub CLI

## Usage Examples
- "pyrsa-priv2pub --help"
- "pyrsa-priv2pub self version"

## Installation
```bash
apt-get install pyrsa-priv2pub 2>/dev/null || which pyrsa-priv2pub
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
