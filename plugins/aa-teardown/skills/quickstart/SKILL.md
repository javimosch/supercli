# aa-teardown Plugin

CLI tool: aa-teardown.

## Commands
- `aa-teardown <resource> <action>` — Execute aa-teardown commands
- `aa-teardown self version` — Print aa-teardown version
- `aa-teardown _ _` — Passthrough to aa-teardown CLI

## Usage Examples
- "aa-teardown --help"
- "aa-teardown self version"

## Installation
```bash
apt-get install aa-teardown 2>/dev/null || which aa-teardown
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
