# gpt-load Plugin

Multi-channel AI proxy with intelligent key rotation. 智能密钥轮询的多渠道 AI 代理。

## Commands

### General
- `gpt-load self version` — Print gpt-load version
- `gpt-load _ _` — Passthrough to gpt-load CLI
