# Rybbit Plugin

Open-source and privacy-friendly alternative to Google Analytics, 10x more intuitive

## Commands
- `rybbit _ _` — Passthrough to rybbit CLI

## Installation

```bash
npm install -g rybbit
```

## Examples
```bash
rybbit --help
rybbit --version
```
