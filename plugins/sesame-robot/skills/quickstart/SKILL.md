# sesame-robot Plugin

An open and affordable mini quadruped robot based on ESP32.

## Commands

### General
- `sesame-robot self version` — Print sesame-robot version
- `sesame-robot _ _` — Passthrough to sesame-robot CLI

## Usage Examples
- "Run sesame-robot"
- "Use sesame-robot to An open and affordable mini quadruped robot based on ESP32."

## Installation

```bash
pip install sesame-robot
```

## Key Features
- An open and affordable mini quadruped robot based on ESP32.
- CLI tool, headless and scriptable
