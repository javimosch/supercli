# dexter Plugin

An autonomous agent for deep financial research

## Commands
- `dexter <resource> <action>` — Execute dexter commands
- `dexter self version` — Print dexter version
- `dexter _ _` — Passthrough to dexter CLI

## Installation

```bash
pip install dexter
```
