# a2dismod Plugin

CLI tool: a2dismod.

## Commands
- `a2dismod <resource> <action>` — Execute a2dismod commands
- `a2dismod self version` — Print a2dismod version
- `a2dismod _ _` — Passthrough to a2dismod CLI

## Usage Examples
- "a2dismod --help"
- "a2dismod self version"

## Installation
```bash
apt-get install a2dismod 2>/dev/null || which a2dismod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
