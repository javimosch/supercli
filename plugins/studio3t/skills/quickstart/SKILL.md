# studio3t Plugin

CLI tool: studio3t.

## Commands
- `studio3t <resource> <action>` — Execute studio3t commands
- `studio3t self version` — Print studio3t version
- `studio3t _ _` — Passthrough to studio3t CLI

## Usage Examples
- "studio3t --help"
- "studio3t self version"

## Installation
```bash
apt-get install studio3t 2>/dev/null || which studio3t
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
