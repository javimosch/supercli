# mslex-split Plugin

CLI tool: mslex-split.

## Commands
- `mslex-split <resource> <action>` — Execute mslex-split commands
- `mslex-split self version` — Print mslex-split version
- `mslex-split _ _` — Passthrough to mslex-split CLI

## Usage Examples
- "mslex-split --help"
- "mslex-split self version"

## Installation
```bash
apt-get install mslex-split 2>/dev/null || which mslex-split
```
