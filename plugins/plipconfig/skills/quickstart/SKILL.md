# plipconfig Plugin

CLI tool: plipconfig.

## Commands
- `plipconfig <resource> <action>` — Execute plipconfig commands
- `plipconfig self version` — Print plipconfig version
- `plipconfig _ _` — Passthrough to plipconfig CLI

## Usage Examples
- "plipconfig --help"
- "plipconfig self version"

## Installation
```bash
apt-get install plipconfig 2>/dev/null || which plipconfig
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
