# Zygisk-Assistant Plugin

A Zygisk module to hide root for KernelSU, Magisk and APatch, designed to work on Android 5.0 and above.

## Commands

### General
- `Zygisk-Assistant self version` — Print Zygisk-Assistant version
- `Zygisk-Assistant _ _` — Passthrough to zygisk-assistant CLI
