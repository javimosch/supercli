# soelim Plugin

CLI tool: soelim.

## Commands
- `soelim <resource> <action>` — Execute soelim commands
- `soelim self version` — Print soelim version
- `soelim _ _` — Passthrough to soelim CLI

## Usage Examples
- "soelim --help"
- "soelim self version"

## Installation
```bash
apt-get install soelim 2>/dev/null || which soelim
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
