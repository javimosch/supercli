# sqlite-data Plugin

A fast, lightweight replacement for SwiftData, powered by SQL and supporting CloudKit synchronization.

## Commands

### General
- `sqlite-data self version` — Print sqlite-data version
- `sqlite-data _ _` — Passthrough to sqlite-data CLI
