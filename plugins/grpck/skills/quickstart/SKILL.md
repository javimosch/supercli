# grpck Plugin

CLI tool: grpck.

## Commands
- `grpck <resource> <action>` — Execute grpck commands
- `grpck self version` — Print grpck version
- `grpck _ _` — Passthrough to grpck CLI

## Usage Examples
- "grpck --help"
- "grpck self version"

## Installation
```bash
apt-get install grpck 2>/dev/null || which grpck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
