# VBoxBalloonCtrl Plugin

CLI tool: VBoxBalloonCtrl.

## Commands
- `VBoxBalloonCtrl <resource> <action>` — Execute VBoxBalloonCtrl commands
- `VBoxBalloonCtrl self version` — Print VBoxBalloonCtrl version
- `VBoxBalloonCtrl _ _` — Passthrough to VBoxBalloonCtrl CLI

## Usage Examples
- "VBoxBalloonCtrl --help"
- "VBoxBalloonCtrl self version"

## Installation
```bash
apt-get install VBoxBalloonCtrl 2>/dev/null || which VBoxBalloonCtrl
```
