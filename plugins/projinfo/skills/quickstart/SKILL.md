# projinfo Plugin

CLI tool: projinfo.

## Commands
- `projinfo <resource> <action>` — Execute projinfo commands
- `projinfo self version` — Print projinfo version
- `projinfo _ _` — Passthrough to projinfo CLI

## Usage Examples
- "projinfo --help"
- "projinfo self version"

## Installation
```bash
apt-get install projinfo 2>/dev/null || which projinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
