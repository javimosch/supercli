# ps2pk Plugin

CLI tool: ps2pk.

## Commands
- `ps2pk <resource> <action>` — Execute ps2pk commands
- `ps2pk self version` — Print ps2pk version
- `ps2pk _ _` — Passthrough to ps2pk CLI

## Usage Examples
- "ps2pk --help"
- "ps2pk self version"

## Installation
```bash
apt-get install ps2pk 2>/dev/null || which ps2pk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
