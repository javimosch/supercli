# RKNHardering Plugin

Обнаружние VPN конфигураторов на пользовательских устройствах с дальнейшей целью защиты от обнаружения

## Commands

### General
- `RKNHardering self version` — Print RKNHardering version
- `RKNHardering _ _` — Passthrough to rknhardering CLI

## Usage Examples
- "Run RKNHardering"
- "Use rknhardering to Обнаружние VPN конфигураторов на пользовательских устройства"

## Installation

```bash
pip install rknhardering
```

## Key Features
- Обнаружние VPN конфигураторов на пользовательских устройствах с дальнейшей целью защиты от обнаружен
- CLI tool, headless and scriptable
