# t1mac Plugin

CLI tool: t1mac.

## Commands
- `t1mac <resource> <action>` — Execute t1mac commands
- `t1mac self version` — Print t1mac version
- `t1mac _ _` — Passthrough to t1mac CLI

## Usage Examples
- "t1mac --help"
- "t1mac self version"

## Installation
```bash
apt-get install t1mac 2>/dev/null || which t1mac
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
