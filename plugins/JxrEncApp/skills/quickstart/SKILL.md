# JxrEncApp Plugin

CLI tool: JxrEncApp.

## Commands
- `JxrEncApp <resource> <action>` — Execute JxrEncApp commands
- `JxrEncApp self version` — Print JxrEncApp version
- `JxrEncApp _ _` — Passthrough to JxrEncApp CLI

## Usage Examples
- "JxrEncApp --help"
- "JxrEncApp self version"

## Installation
```bash
apt-get install JxrEncApp 2>/dev/null || which JxrEncApp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
