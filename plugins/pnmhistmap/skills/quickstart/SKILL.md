# pnmhistmap Plugin

CLI tool: pnmhistmap.

## Commands
- `pnmhistmap <resource> <action>` — Execute pnmhistmap commands
- `pnmhistmap self version` — Print pnmhistmap version
- `pnmhistmap _ _` — Passthrough to pnmhistmap CLI

## Usage Examples
- "pnmhistmap --help"
- "pnmhistmap self version"

```bash
apt-get install pnmhistmap 2>/dev/null || which pnmhistmap
```
