# unlink Plugin
Remove files via unlink syscall

## Commands
- `unlink <resource> <action>` — Execute unlink commands
- `unlink self version` — Print unlink version
- `unlink _ _` — Passthrough to unlink CLI

## Usage
- `unlink _ _ <args>` — Run unlink with any arguments
