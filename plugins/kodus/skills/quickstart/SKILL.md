# kodus Plugin
AI code review CLI that integrates with IDE agents for change review

## Commands
- `kodus <resource> <action>` — Execute kodus commands
- `kodus _ _` — Passthrough to kodus CLI

## Usage
- `kodus _ _ <args>` — Run kodus with any arguments
