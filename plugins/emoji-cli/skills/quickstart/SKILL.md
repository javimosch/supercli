# emoji-cli Plugin

Emoji completion on command line in Shell

## Commands

### Operations
- `emoji-cli self version` — Print emoji-cli version
- `emoji-cli _ _` — Passthrough to emoji-cli CLI

## Usage Examples
- `emoji-cli --help`
- `emoji-cli <args>`

## Installation

```bash
npm install -g emoji-cli
```

## Examples

```bash
emoji-cli --version
emoji-cli --help
```
