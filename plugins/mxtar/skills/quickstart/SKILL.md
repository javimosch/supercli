# mxtar Plugin

CLI tool: mxtar.

## Commands
- `mxtar <resource> <action>` — Execute mxtar commands
- `mxtar self version` — Print mxtar version
- `mxtar _ _` — Passthrough to mxtar CLI

## Usage Examples
- "mxtar --help"
- "mxtar self version"

## Installation
```bash
apt-get install mxtar 2>/dev/null || which mxtar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
