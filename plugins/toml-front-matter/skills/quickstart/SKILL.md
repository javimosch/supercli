# toml-front-matter Plugin
TOML front-matter parser for markdown files

## Commands
- `toml-front-matter <resource> <action>` — Execute toml-front-matter commands
- `toml-front-matter _ _` — Passthrough to toml-front-matter CLI

## Usage
- `toml-front-matter _ _ <args>` — Run toml-front-matter with any arguments
