# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `miniserve <resource> <action>` — Execute miniserve commands
- `miniserve self version` — Print miniserve version
- `miniserve serve directory` — Serve directory over HTTP
- `miniserve _ _` — Passthrough to miniserve CLI
