# msvcup Plugin

Hermetic install of MSVC/SDK from the CLI

## Commands

### General
- `msvcup self version` — Print msvcup version
- `msvcup _ _` — Passthrough to msvcup CLI

## Usage Examples
- "Run msvcup"
- "Use msvcup to Hermetic install of MSVC/SDK from the CLI"

## Installation

```bash
pip install msvcup
```

## Key Features
- Hermetic install of MSVC/SDK from the CLI
- CLI tool, headless and scriptable
