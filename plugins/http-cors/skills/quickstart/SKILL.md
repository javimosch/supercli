# http-cors
http-cors — test CORS configuration for a URL. Sends OPTIONS preflight and GET requests, reports Access-Control headers, origin and credential support.

## Commands
- `http-cors <resource> <action>` — Execute http-cors commands
- `http cors run` — http-cors — test CORS configuration for a URL. Sends OPTIONS preflight and GET requests, reports Access-Control headers, origin and credential support.
