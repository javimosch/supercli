# pygrep Plugin
Grep for Python code patterns using AST matching

## Commands
- `pygrep <resource> <action>` — Execute pygrep commands
- `pygrep _ _` — Passthrough to pygrep CLI

## Usage
- `pygrep _ _ <args>` — Run pygrep with any arguments
