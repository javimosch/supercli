# icuexportdata Plugin

CLI tool: icuexportdata.

## Commands
- `icuexportdata <resource> <action>` — Execute icuexportdata commands
- `icuexportdata self version` — Print icuexportdata version
- `icuexportdata _ _` — Passthrough to icuexportdata CLI

## Usage Examples
- "icuexportdata --help"
- "icuexportdata self version"

apt-get install icuexportdata 2>/dev/null || which icuexportdata
