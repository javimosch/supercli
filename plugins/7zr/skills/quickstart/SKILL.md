# 7zr Plugin

CLI tool: 7zr.

## Commands
- `7zr <resource> <action>` — Execute 7zr commands
- `7zr self version` — Print 7zr version
- `7zr _ _` — Passthrough to 7zr CLI

## Usage Examples
- "7zr --help"
- "7zr self version"

## Installation
```bash
apt-get install 7zr 2>/dev/null || which 7zr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
