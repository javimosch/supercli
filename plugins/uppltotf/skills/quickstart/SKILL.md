# uppltotf Plugin

CLI tool: uppltotf.

## Commands
- `uppltotf <resource> <action>` — Execute uppltotf commands
- `uppltotf self version` — Print uppltotf version
- `uppltotf _ _` — Passthrough to uppltotf CLI

## Usage Examples
- "uppltotf --help"
- "uppltotf self version"

## Installation
```bash
apt-get install uppltotf 2>/dev/null || which uppltotf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
