# pathy Plugin

CLI tool: pathy.

## Commands
- `pathy <resource> <action>` — Execute pathy commands
- `pathy self version` — Print pathy version
- `pathy _ _` — Passthrough to pathy CLI

## Usage Examples
- "pathy --help"
- "pathy self version"

## Installation
```bash
apt-get install pathy 2>/dev/null || which pathy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
