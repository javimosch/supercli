# Archon Plugin

The first open-source harness builder for AI coding. Make AI coding deterministic and repeatable.

## Commands
- `Archon <resource> <action>` — Execute Archon commands
- `Archon self version` — Print Archon version
- `Archon _ _` — Passthrough to archon CLI

## Installation

```bash
pip install archon
```
