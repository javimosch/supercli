# phpenmod Plugin

CLI tool: phpenmod.

## Commands
- `phpenmod <resource> <action>` — Execute phpenmod commands
- `phpenmod self version` — Print phpenmod version
- `phpenmod _ _` — Passthrough to phpenmod CLI

## Usage Examples
- "phpenmod --help"
- "phpenmod self version"

## Installation
```bash
apt-get install phpenmod 2>/dev/null || which phpenmod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
