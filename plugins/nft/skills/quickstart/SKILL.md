# nft Plugin

CLI tool: nft.

## Commands
- `nft <resource> <action>` — Execute nft commands
- `nft self version` — Print nft version
- `nft _ _` — Passthrough to nft CLI

## Usage Examples
- "nft --help"
- "nft self version"

## Installation
```bash
apt-get install nft 2>/dev/null || which nft
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
