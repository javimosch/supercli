# pw-profiler Plugin

CLI tool: pw-profiler.

## Commands
- `pw-profiler <resource> <action>` — Execute pw-profiler commands
- `pw-profiler self version` — Print pw-profiler version
- `pw-profiler _ _` — Passthrough to pw-profiler CLI

## Usage Examples
- "pw-profiler --help"
- "pw-profiler self version"

## Installation
```bash
apt-get install pw-profiler 2>/dev/null || which pw-profiler
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
