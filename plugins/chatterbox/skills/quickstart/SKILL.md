# Chatterbox Plugin

SoTA open-source text-to-speech model

## Commands
- `chatterbox _ _` — Passthrough to chatterbox CLI

## Installation

```bash
pip install chatterbox-tts
```

## Examples
```bash
chatterbox --help
chatterbox --version
```
