# gowitness Plugin

Headless website screenshot CLI — captures screenshots and generates reports

## Commands
- `gowitness self version` — Print gowitness version
- `gowitness _ _` — Passthrough to gowitness CLI

## Usage Examples
- `gowitness self version` — Check installed version
- `gowitness _ _ --help` — Show gowitness help
- `gowitness _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/sensepost/gowitness@latest
```

## Key Features
- security, screenshot, golang, recon
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
