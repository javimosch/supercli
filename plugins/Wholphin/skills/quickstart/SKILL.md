# Wholphin Plugin

An OSS Android TV client for Jellyfin

## Commands

### General
- `Wholphin self version` — Print Wholphin version
- `Wholphin _ _` — Passthrough to wholphin CLI

## Usage Examples
- "Run Wholphin"
- "Use wholphin to An OSS Android TV client for Jellyfin"

## Installation

```bash
pip install wholphin
```

## Key Features
- An OSS Android TV client for Jellyfin
- CLI tool, headless and scriptable
