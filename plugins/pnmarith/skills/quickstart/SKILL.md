# pnmarith Plugin

CLI tool: pnmarith.

## Commands
- `pnmarith <resource> <action>` — Execute pnmarith commands
- `pnmarith self version` — Print pnmarith version
- `pnmarith _ _` — Passthrough to pnmarith CLI

## Usage Examples
- "pnmarith --help"
- "pnmarith self version"

## Installation
```bash
apt-get install pnmarith 2>/dev/null || which pnmarith
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
