# snipt Plugin
Text snippet expansion tool.
## Commands
- `snipt _ _` — Passthrough to snipt CLI
## Installation
```bash
cargo install snipt
```
## Key Features
- **Snippet expansion** — Fast text templates
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line workflow
