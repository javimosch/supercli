# xcmsdb Plugin

CLI tool: xcmsdb.

## Commands
- `xcmsdb <resource> <action>` — Execute xcmsdb commands
- `xcmsdb self version` — Print xcmsdb version
- `xcmsdb _ _` — Passthrough to xcmsdb CLI

## Usage Examples
- "xcmsdb --help"
- "xcmsdb self version"

## Installation
```bash
apt-get install xcmsdb 2>/dev/null || which xcmsdb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
