# adler-cli Plugin
CLI tool for adler-cli.

## Commands
- `adler-cli <resource> <action>` — Execute adler-cli commands
- `adler-cli _ _` — Passthrough to adler-cli CLI

## Installation
```bash
cargo install adler-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
