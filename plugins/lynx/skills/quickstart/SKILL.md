# Quickstart

Comprehensive documentation available in the repository.

## Commands
- `lynx <resource> <action>` — Execute lynx commands
- `lynx self version` — Print lynx version
- `lynx fetch page` — Fetch and display webpage as text
- `lynx _ _` — Passthrough to lynx CLI
