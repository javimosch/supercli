# rdiffdir Plugin

CLI tool: rdiffdir.

## Commands
- `rdiffdir <resource> <action>` — Execute rdiffdir commands
- `rdiffdir self version` — Print rdiffdir version
- `rdiffdir _ _` — Passthrough to rdiffdir CLI

## Usage Examples
- "rdiffdir --help"
- "rdiffdir self version"

## Installation
```bash
apt-get install rdiffdir 2>/dev/null || which rdiffdir
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
