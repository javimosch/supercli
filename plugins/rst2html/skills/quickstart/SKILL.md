# rst2html Plugin

CLI tool: rst2html.

## Commands
- `rst2html <resource> <action>` — Execute rst2html commands
- `rst2html self version` — Print rst2html version
- `rst2html _ _` — Passthrough to rst2html CLI

## Usage Examples
- "rst2html --help"
- "rst2html self version"

## Installation
```bash
apt-get install rst2html 2>/dev/null || which rst2html
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
