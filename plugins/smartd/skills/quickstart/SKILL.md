# smartd Plugin

CLI tool: smartd.

## Commands
- `smartd <resource> <action>` — Execute smartd commands
- `smartd self version` — Print smartd version
- `smartd _ _` — Passthrough to smartd CLI

## Usage Examples
- "smartd --help"
- "smartd self version"

## Installation
```bash
apt-get install smartd 2>/dev/null || which smartd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
