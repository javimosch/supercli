# tuckr-dotfiles Plugin
Organize dotfiles with declarative symlink management

## Commands
- `tuckr-dotfiles <resource> <action>` — Execute tuckr-dotfiles commands
- `tuckr-dotfiles _ _` — Passthrough to tuckr-dotfiles CLI

## Usage
- `tuckr-dotfiles _ _ <args>` — Run tuckr-dotfiles with any arguments
