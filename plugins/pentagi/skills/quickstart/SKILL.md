# pentagi Plugin

Fully autonomous AI Agents system capable of performing complex penetration testing tasks

## Commands
- `pentagi <resource> <action>` — Execute pentagi commands
- `pentagi self version` — Print pentagi version
- `pentagi _ _` — Passthrough to pentagi CLI

## Installation

```bash
pip install pentagi
```
