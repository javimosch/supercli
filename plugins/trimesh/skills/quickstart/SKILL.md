# trimesh Plugin

CLI tool: trimesh.

## Commands
- `trimesh <resource> <action>` — Execute trimesh commands
- `trimesh self version` — Print trimesh version
- `trimesh _ _` — Passthrough to trimesh CLI

## Usage Examples
- "trimesh --help"
- "trimesh self version"

## Installation
```bash
apt-get install trimesh 2>/dev/null || which trimesh
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
