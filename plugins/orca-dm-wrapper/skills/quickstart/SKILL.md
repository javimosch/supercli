# orca-dm-wrapper Plugin

CLI tool: orca-dm-wrapper.

## Commands
- `orca-dm-wrapper <resource> <action>` — Execute orca-dm-wrapper commands
- `orca-dm-wrapper self version` — Print orca-dm-wrapper version
- `orca-dm-wrapper _ _` — Passthrough to orca-dm-wrapper CLI

## Usage Examples
- "orca-dm-wrapper --help"
- "orca-dm-wrapper self version"

## Installation
```bash
apt-get install orca-dm-wrapper 2>/dev/null || which orca-dm-wrapper
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
