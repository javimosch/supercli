# glow-ext Plugin
Render markdown in the terminal with style

## Commands
- `glow-ext <resource> <action>` — Execute glow-ext commands
- `glow-ext _ _` — Passthrough to glow CLI

## Usage
- `glow-ext _ _ <args>` — Run glow with any arguments
