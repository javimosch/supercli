# pnmenlarge Plugin

CLI tool: pnmenlarge.

## Commands
- `pnmenlarge <resource> <action>` — Execute pnmenlarge commands
- `pnmenlarge self version` — Print pnmenlarge version
- `pnmenlarge _ _` — Passthrough to pnmenlarge CLI

## Usage Examples
- "pnmenlarge --help"
- "pnmenlarge self version"

## Installation
```bash
apt-get install pnmenlarge 2>/dev/null || which pnmenlarge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
