# pppoe-discovery Plugin

CLI tool: pppoe-discovery.

## Commands
- `pppoe-discovery <resource> <action>` — Execute pppoe-discovery commands
- `pppoe-discovery self version` — Print pppoe-discovery version
- `pppoe-discovery _ _` — Passthrough to pppoe-discovery CLI

## Usage Examples
- "pppoe-discovery --help"
- "pppoe-discovery self version"

## Installation
```bash
apt-get install pppoe-discovery 2>/dev/null || which pppoe-discovery
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
