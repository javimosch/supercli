# iwspy Plugin

CLI tool: iwspy.

## Commands
- `iwspy <resource> <action>` — Execute iwspy commands
- `iwspy self version` — Print iwspy version
- `iwspy _ _` — Passthrough to iwspy CLI

## Usage Examples
- "iwspy --help"
- "iwspy self version"

## Installation
```bash
apt-get install iwspy 2>/dev/null || which iwspy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
