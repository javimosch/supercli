# textblob-cli Plugin
Lightweight text processing CLI for NLP tasks

## Commands
- `textblob-cli <resource> <action>` — Execute textblob-cli commands
- `textblob-cli _ _` — Passthrough to textblob-cli CLI

## Usage
- `textblob-cli _ _ <args>` — Run textblob-cli with any arguments
