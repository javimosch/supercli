# ccat Plugin
Colorize cat output with syntax highlighting. Display source files with language-aware coloring directly in the terminal.
## Commands
- `ccat self version` — Print version
- `ccat _ _` — Passthrough to ccat
## Installation
```bash
brew install ccat
```
