# update-locale Plugin

CLI tool: update-locale.

## Commands
- `update-locale <resource> <action>` — Execute update-locale commands
- `update-locale self version` — Print update-locale version
- `update-locale _ _` — Passthrough to update-locale CLI

## Usage Examples
- "update-locale --help"
- "update-locale self version"

## Installation
```bash
apt-get install update-locale 2>/dev/null || which update-locale
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
