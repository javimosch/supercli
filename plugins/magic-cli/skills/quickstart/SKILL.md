# magic-cli Plugin

Command line utility to make you a magician in the terminal. Productivity boosting CLI. curl or brew install.

## Commands
- `magic-cli self version` — Print version
- `magic-cli _ _ <args>` — Passthrough to magic-cli

## Usage Examples
- "Terminal Magic"

## Installation
```bash
curl -LsSf https://github.com/guywaldman/magic-cli/releases/download/0.0.6/magic-cli-installer.sh | sh
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
