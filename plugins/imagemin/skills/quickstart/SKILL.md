# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `imagemin <resource> <action>` — Execute imagemin commands
- `imagemin self version` — Print imagemin version
- `imagemin compress image` — Minify image file
- `imagemin _ _` — Passthrough to imagemin CLI
