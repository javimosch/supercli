# tstclnt Plugin

CLI tool: tstclnt.

## Commands
- `tstclnt <resource> <action>` — Execute tstclnt commands
- `tstclnt self version` — Print tstclnt version
- `tstclnt _ _` — Passthrough to tstclnt CLI

## Usage Examples
- "tstclnt --help"
- "tstclnt self version"

## Installation
```bash
apt-get install tstclnt 2>/dev/null || which tstclnt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
