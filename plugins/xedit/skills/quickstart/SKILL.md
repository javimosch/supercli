# xedit Plugin

CLI tool: xedit.

## Commands
- `xedit <resource> <action>` — Execute xedit commands
- `xedit self version` — Print xedit version
- `xedit _ _` — Passthrough to xedit CLI

## Usage Examples
- "xedit --help"
- "xedit self version"

## Installation
```bash
apt-get install xedit 2>/dev/null || which xedit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
