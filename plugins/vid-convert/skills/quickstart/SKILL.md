# vid-convert Plugin
Convert video files between formats using FFmpeg wrapper

## Commands
- `vid-convert <resource> <action>` — Execute vid-convert commands
- `vid-convert _ _` — Passthrough to vid-convert CLI

## Usage
- `vid-convert _ _ <args>` — Run vid-convert with any arguments
