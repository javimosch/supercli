# browsertap-cli Plugin
CLI for browser automation with WebDriver BiDi and WASM plugins

## Commands
- `browsertap-cli <resource> <action>` — Execute browsertap-cli commands
- `browsertap-cli _ _` — Passthrough to browsertap-cli CLI

## Usage
- `browsertap-cli _ _ <args>` — Run browsertap-cli with any arguments
