# mimetype Plugin

CLI tool: mimetype.

## Commands
- `mimetype <resource> <action>` — Execute mimetype commands
- `mimetype self version` — Print mimetype version
- `mimetype _ _` — Passthrough to mimetype CLI

## Usage Examples
- "mimetype --help"
- "mimetype self version"

## Installation
```bash
apt-get install mimetype 2>/dev/null || which mimetype
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
