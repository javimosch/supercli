# fusermount Plugin

CLI tool: fusermount.

## Commands
- `fusermount <resource> <action>` — Execute fusermount commands
- `fusermount self version` — Print fusermount version
- `fusermount _ _` — Passthrough to fusermount CLI

## Usage Examples
- "fusermount --help"
- "fusermount self version"

## Installation
```bash
apt-get install fusermount 2>/dev/null || which fusermount
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
