# isoprod Plugin

CLI tool: isoprod.

## Commands
- `isoprod <resource> <action>` — Execute isoprod commands
- `isoprod self version` — Print isoprod version
- `isoprod _ _` — Passthrough to isoprod CLI

## Usage Examples
- "isoprod --help"
- "isoprod self version"

## Installation
```bash
apt-get install isoprod 2>/dev/null || which isoprod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
