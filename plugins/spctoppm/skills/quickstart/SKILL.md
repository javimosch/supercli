# spctoppm Plugin

CLI tool: spctoppm.

## Commands
- `spctoppm <resource> <action>` — Execute spctoppm commands
- `spctoppm self version` — Print spctoppm version
- `spctoppm _ _` — Passthrough to spctoppm CLI

## Usage Examples
- "spctoppm --help"
- "spctoppm self version"

## Installation
```bash
apt-get install spctoppm 2>/dev/null || which spctoppm
```
