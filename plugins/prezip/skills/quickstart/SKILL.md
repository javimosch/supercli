# prezip Plugin

CLI tool: prezip.

## Commands
- `prezip <resource> <action>` — Execute prezip commands
- `prezip self version` — Print prezip version
- `prezip _ _` — Passthrough to prezip CLI

## Usage Examples
- "prezip --help"
- "prezip self version"

## Installation
```bash
apt-get install prezip 2>/dev/null || which prezip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
