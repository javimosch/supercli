# hbpldecode Plugin

CLI tool: hbpldecode.

## Commands
- `hbpldecode <resource> <action>` — Execute hbpldecode commands
- `hbpldecode self version` — Print hbpldecode version
- `hbpldecode _ _` — Passthrough to hbpldecode CLI

## Usage Examples
- "hbpldecode --help"
- "hbpldecode self version"

## Installation
```bash
apt-get install hbpldecode 2>/dev/null || which hbpldecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
