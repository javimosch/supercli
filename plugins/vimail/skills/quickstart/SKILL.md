# vimail Plugin
Terminal email client with Vim-style keybindings written in Go

## Commands
- `vimail <resource> <action>` — Execute vimail commands
- `vimail _ _` — Passthrough to vimail CLI

## Usage
- `vimail _ _ <args>` — Run vimail with any arguments
