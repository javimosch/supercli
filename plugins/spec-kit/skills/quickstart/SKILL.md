# spec-kit Plugin

💫 Toolkit to help you get started with Spec-Driven Development

## Commands
- `spec-kit <resource> <action>` — Execute spec-kit commands
- `spec-kit self version` — Print spec-kit version
- `spec-kit _ _` — Passthrough to spec-kit CLI

## Installation

```bash
pip install spec-kit
```
