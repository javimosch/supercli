# GuitarPedal Plugin

Linus learns analog circuits

## Commands

### General
- `GuitarPedal self version` — Print GuitarPedal version
- `GuitarPedal _ _` — Passthrough to guitarpedal CLI

## Usage Examples
- "Run GuitarPedal"
- "Use guitarpedal to Linus learns analog circuits"

## Installation

```bash
pip install guitarpedal
```

## Key Features
- Linus learns analog circuits
- CLI tool, headless and scriptable
