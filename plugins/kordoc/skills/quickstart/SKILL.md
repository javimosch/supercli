# Kordoc Plugin

Parse Korean documents (HWP, HWPX, PDF, Office) to Markdown with CLI and MCP Server

## Commands
- `kordoc _ _` — Passthrough to kordoc CLI

## Installation

```bash
npm install -g kordoc
```

## Examples
```bash
kordoc --help
kordoc --version
```
