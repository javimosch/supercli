# errno Plugin

CLI tool: errno.

## Commands
- `errno <resource> <action>` — Execute errno commands
- `errno self version` — Print errno version
- `errno _ _` — Passthrough to errno CLI

## Usage Examples
- "errno --help"
- "errno self version"

## Installation
```bash
apt-get install errno 2>/dev/null || which errno
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
