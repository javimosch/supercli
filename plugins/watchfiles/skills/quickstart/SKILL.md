# watchfiles Plugin

CLI tool: watchfiles.

## Commands
- `watchfiles <resource> <action>` — Execute watchfiles commands
- `watchfiles self version` — Print watchfiles version
- `watchfiles _ _` — Passthrough to watchfiles CLI

## Usage Examples
- "watchfiles --help"
- "watchfiles self version"

## Installation
```bash
apt-get install watchfiles 2>/dev/null || which watchfiles
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
