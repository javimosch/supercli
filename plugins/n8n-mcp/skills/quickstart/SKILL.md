# n8n-mcp Plugin

A MCP for Claude Desktop / Claude Code / Windsurf / Cursor to build n8n workflows for you 

## Commands

### General
- `n8n-mcp self version` — Print n8n-mcp version
- `n8n-mcp _ _` — Passthrough to n8n-mcp CLI
