# mdbook-toc Plugin
Auto-generate table of contents for mdBook projects

## Commands
- `mdbook-toc <resource> <action>` — Execute mdbook-toc commands
- `mdbook-toc _ _` — Passthrough to mdbook-toc CLI

## Usage
- `mdbook-toc _ _ <args>` — Run mdbook-toc with any arguments
