# ocsinventory-agent Plugin

CLI tool: ocsinventory-agent.

## Commands
- `ocsinventory-agent <resource> <action>` — Execute ocsinventory-agent commands
- `ocsinventory-agent self version` — Print ocsinventory-agent version
- `ocsinventory-agent _ _` — Passthrough to ocsinventory-agent CLI

## Usage Examples
- "ocsinventory-agent --help"
- "ocsinventory-agent self version"

## Installation
```bash
apt-get install ocsinventory-agent 2>/dev/null || which ocsinventory-agent
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
