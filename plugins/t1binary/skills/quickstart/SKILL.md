# t1binary Plugin

CLI tool: t1binary.

## Commands
- `t1binary <resource> <action>` — Execute t1binary commands
- `t1binary self version` — Print t1binary version
- `t1binary _ _` — Passthrough to t1binary CLI

## Usage Examples
- "t1binary --help"
- "t1binary self version"

## Installation
```bash
apt-get install t1binary 2>/dev/null || which t1binary
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
