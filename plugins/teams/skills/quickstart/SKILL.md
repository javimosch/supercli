# teams Plugin

CLI tool: teams.

## Commands
- `teams <resource> <action>` — Execute teams commands
- `teams self version` — Print teams version
- `teams _ _` — Passthrough to teams CLI

## Usage Examples
- "teams --help"
- "teams self version"

## Installation
```bash
apt-get install teams 2>/dev/null || which teams
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
