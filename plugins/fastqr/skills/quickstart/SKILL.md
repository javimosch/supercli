# fastqr Plugin
High-performance C++ QR code generator for batch usage

## Commands
- `fastqr <resource> <action>` — Execute fastqr commands
- `fastqr _ _` — Passthrough to fastqr CLI

## Usage
- `fastqr _ _ <args>` — Run fastqr with any arguments
