# k8sgpt Plugin

Giving Kubernetes Superpowers to everyone

## Commands
- `k8sgpt <resource> <action>` — Execute k8sgpt commands
- `k8sgpt self version` — Print k8sgpt version
- `k8sgpt _ _` — Passthrough to k8sgpt CLI

## Installation

```bash
pip install k8sgpt
```
