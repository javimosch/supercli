# g3topbm Plugin

CLI tool: g3topbm.

## Commands
- `g3topbm <resource> <action>` — Execute g3topbm commands
- `g3topbm self version` — Print g3topbm version
- `g3topbm _ _` — Passthrough to g3topbm CLI

## Usage Examples
- "g3topbm --help"
- "g3topbm self version"

## Installation
```bash
apt-get install g3topbm 2>/dev/null || which g3topbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
