# select-editor Plugin

CLI tool: select-editor.

## Commands
- `select-editor <resource> <action>` — Execute select-editor commands
- `select-editor self version` — Print select-editor version
- `select-editor _ _` — Passthrough to select-editor CLI

## Usage Examples
- "select-editor --help"
- "select-editor self version"

## Installation
```bash
apt-get install select-editor 2>/dev/null || which select-editor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
