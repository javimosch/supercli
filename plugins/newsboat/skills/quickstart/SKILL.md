# newsboat Plugin

newsboat — terminal RSS/Atom feed reader with OPML support, podcast integration, and extensible configuration

## Installation

```bash
brew install newsboat
Verify: newsboat --version
```

## Passthrough

```bash
sc newsboat _ _ <args...>
```

## SuperCLI

```bash
sc newsboat _ _ --help
sc plugins learn newsboat
```
