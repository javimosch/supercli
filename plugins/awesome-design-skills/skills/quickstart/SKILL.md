# Awesome Design Skills

67+ DESIGN.md and SKILL.md design files for AI design tools. Curated collection covering UI/UX systems, visual styles, component libraries, brand guidelines, and design tokens.

## Installation
```bash
git clone https://github.com/bergside/awesome-design-skills.git
sc skills teach awesome-design-skills:quickstart
```

## What's Included
- **DESIGN.md files** — Design system specifications and style guides
- **SKILL.md files** — Reusable design skills for AI agents
- Coverage: Claude Design, Google Stitch, Codex, Cursor, and other AI tools

## Usage
- Browse the collection to find a design skill that matches your project
- Use `sc skills search --query design` to find design-related skills
- Reference DESIGN.md files when asking the agent to generate UI components

## Key Areas
- UI/UX design systems, visual style guides, component libraries
- Brand guidelines, design tokens, color palettes, typography
- Accessibility standards, responsive design patterns
- Animation and interaction design specifications
