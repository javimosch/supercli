# lomath Plugin

CLI tool: lomath.

## Commands
- `lomath <resource> <action>` — Execute lomath commands
- `lomath self version` — Print lomath version
- `lomath _ _` — Passthrough to lomath CLI

## Usage Examples
- "lomath --help"
- "lomath self version"

## Installation
```bash
apt-get install lomath 2>/dev/null || which lomath
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
