# mmroff Plugin

CLI tool: mmroff.

## Commands
- `mmroff <resource> <action>` — Execute mmroff commands
- `mmroff self version` — Print mmroff version
- `mmroff _ _` — Passthrough to mmroff CLI

## Usage Examples
- "mmroff --help"
- "mmroff self version"

## Installation
```bash
apt-get install mmroff 2>/dev/null || which mmroff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
