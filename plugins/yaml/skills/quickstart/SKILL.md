# yaml Plugin

YAML — human-friendly data serialization format

## Commands
- `yaml <resource> <action>` — Execute yaml commands
- `yaml self version` — Version

## Installation

```bash
cargo install yaml
Verify: yaml --version
```

### `sc yaml self version`
