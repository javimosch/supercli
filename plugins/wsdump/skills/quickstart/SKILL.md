# wsdump Plugin

wsdump — WebSocket client library - Python 3.x.

## Commands
- `wsdump <resource> <action>` — Execute wsdump commands
- `wsdump self version` — Print wsdump version
- `wsdump _ _` — Passthrough to wsdump CLI

## Usage Examples
- "wsdump --help"
- "wsdump self version"

## Installation
```bash
apt-get install python3-websocket 2>/dev/null || which wsdump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
