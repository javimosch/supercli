# hp-align Plugin

CLI tool: hp-align.

## Commands
- `hp-align <resource> <action>` — Execute hp-align commands
- `hp-align self version` — Print hp-align version
- `hp-align _ _` — Passthrough to hp-align CLI

## Usage Examples
- "hp-align --help"
- "hp-align self version"

## Installation
```bash
apt-get install hp-align 2>/dev/null || which hp-align
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
