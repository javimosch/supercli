# mlabel Plugin

CLI tool: mlabel.

## Commands
- `mlabel <resource> <action>` — Execute mlabel commands
- `mlabel self version` — Print mlabel version
- `mlabel _ _` — Passthrough to mlabel CLI

## Usage Examples
- "mlabel --help"
- "mlabel self version"

## Installation
```bash
apt-get install mlabel 2>/dev/null || which mlabel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
