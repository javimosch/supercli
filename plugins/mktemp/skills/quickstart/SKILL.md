# mktemp Plugin
Create temporary files and directories

## Commands
- `mktemp <resource> <action>` — Execute mktemp commands
- `mktemp self version` — Print mktemp version
- `mktemp _ _` — Passthrough to mktemp CLI

## Usage
- `mktemp _ _ <args>` — Run mktemp with any arguments
