# xcp Plugin

xcp — an extended cp with progress bars, parallel copies (Rust)..

## Commands

### `sc xcp file copy`
Copy files with progress.

### `sc xcp self version`
Print version.

## Installation

```bash
cargo install xcp
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
