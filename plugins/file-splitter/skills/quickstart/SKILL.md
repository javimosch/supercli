# file-splitter Plugin
Split massive files into smaller chunks from CLI

## Commands
- `file-splitter <resource> <action>` — Execute file-splitter commands
- `file-splitter _ _` — Passthrough to file-splitter CLI

## Usage
- `file-splitter _ _ <args>` — Run file-splitter with any arguments
