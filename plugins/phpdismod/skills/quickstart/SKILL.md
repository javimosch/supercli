# phpdismod Plugin

CLI tool: phpdismod.

## Commands
- `phpdismod <resource> <action>` — Execute phpdismod commands
- `phpdismod self version` — Print phpdismod version
- `phpdismod _ _` — Passthrough to phpdismod CLI

## Usage Examples
- "phpdismod --help"
- "phpdismod self version"

## Installation
```bash
apt-get install phpdismod 2>/dev/null || which phpdismod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
