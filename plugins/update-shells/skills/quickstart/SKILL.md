# update-shells Plugin

CLI tool: update-shells.

## Commands
- `update-shells <resource> <action>` — Execute update-shells commands
- `update-shells self version` — Print update-shells version
- `update-shells _ _` — Passthrough to update-shells CLI

## Usage Examples
- "update-shells --help"
- "update-shells self version"

## Installation
```bash
apt-get install update-shells 2>/dev/null || which update-shells
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
