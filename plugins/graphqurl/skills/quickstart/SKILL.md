# graphqurl Plugin
Curl-like CLI tool for making GraphQL queries and mutations

## Commands
- `graphqurl <resource> <action>` — Execute graphqurl commands
- `graphqurl _ _` — Passthrough to graphqurl CLI

## Usage
- `graphqurl _ _ <args>` — Run graphqurl with any arguments
