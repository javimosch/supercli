# shtab Plugin

CLI tool: shtab.

## Commands
- `shtab <resource> <action>` — Execute shtab commands
- `shtab self version` — Print shtab version
- `shtab _ _` — Passthrough to shtab CLI

## Usage Examples
- "shtab --help"
- "shtab self version"

## Installation
```bash
apt-get install shtab 2>/dev/null || which shtab
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
