# routef Plugin

CLI tool: routef.

## Commands
- `routef <resource> <action>` — Execute routef commands
- `routef self version` — Print routef version
- `routef _ _` — Passthrough to routef CLI

## Usage Examples
- "routef --help"
- "routef self version"

## Installation
```bash
apt-get install routef 2>/dev/null || which routef
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
