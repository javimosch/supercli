# amfora Plugin

A fancy terminal browser for the Gemini protocol.

## Commands
- `amfora <resource> <action>` — Execute amfora commands
- `amfora self version` — Print amfora version
- `amfora _ _` — Passthrough to amfora CLI

## Usage Examples
- "amfora --help"
- "amfora self version"

## Installation
```bash
go install github.com/makeworld-the-better-one/amfora@latest
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- go based
