# startx Plugin

CLI tool: startx.

## Commands
- `startx <resource> <action>` — Execute startx commands
- `startx self version` — Print startx version
- `startx _ _` — Passthrough to startx CLI

## Usage Examples
- "startx --help"
- "startx self version"

## Installation
```bash
apt-get install startx 2>/dev/null || which startx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
