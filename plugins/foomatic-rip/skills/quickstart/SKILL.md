# foomatic-rip Plugin

CLI tool: foomatic-rip.

## Commands
- `foomatic-rip <resource> <action>` — Execute foomatic-rip commands
- `foomatic-rip self version` — Print foomatic-rip version
- `foomatic-rip _ _` — Passthrough to foomatic-rip CLI

## Usage Examples
- "foomatic-rip --help"
- "foomatic-rip self version"

## Installation
```bash
apt-get install foomatic-rip 2>/dev/null || which foomatic-rip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
