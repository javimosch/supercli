# sudoreplay Plugin

CLI tool: sudoreplay.

## Commands
- `sudoreplay <resource> <action>` — Execute sudoreplay commands
- `sudoreplay self version` — Print sudoreplay version
- `sudoreplay _ _` — Passthrough to sudoreplay CLI

## Usage Examples
- "sudoreplay --help"
- "sudoreplay self version"

## Installation
```bash
apt-get install sudoreplay 2>/dev/null || which sudoreplay
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
