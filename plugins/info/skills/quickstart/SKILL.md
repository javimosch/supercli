# info Plugin

CLI tool: info.

## Commands
- `info <resource> <action>` — Execute info commands
- `info self version` — Print info version
- `info _ _` — Passthrough to info CLI

## Usage Examples
- "info --help"
- "info self version"

## Installation
```bash
apt-get install info 2>/dev/null || which info
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
