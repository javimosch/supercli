# ttf2afm Plugin

CLI tool: ttf2afm.

## Commands
- `ttf2afm <resource> <action>` — Execute ttf2afm commands
- `ttf2afm self version` — Print ttf2afm version
- `ttf2afm _ _` — Passthrough to ttf2afm CLI

## Usage Examples
- "ttf2afm --help"
- "ttf2afm self version"

## Installation
```bash
apt-get install ttf2afm 2>/dev/null || which ttf2afm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
