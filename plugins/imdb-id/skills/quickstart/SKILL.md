# imdb-id Plugin
CLI tool for imdb-id.

## Commands
- `imdb-id <resource> <action>` — Execute imdb-id commands
- `imdb-id _ _` — Passthrough to imdb-id CLI

## Installation
```bash
cargo install imdb-id
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
