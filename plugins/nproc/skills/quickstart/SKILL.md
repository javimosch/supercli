# nproc Plugin

CLI tool: nproc.

## Commands
- `nproc <resource> <action>` — Execute nproc commands
- `nproc self version` — Print nproc version
- `nproc _ _` — Passthrough to nproc CLI

## Usage Examples
- "nproc --help"
- "nproc self version"

## Installation
```bash
apt-get install nproc 2>/dev/null || which nproc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
