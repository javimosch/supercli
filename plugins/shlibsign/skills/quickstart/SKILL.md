# shlibsign Plugin

CLI tool: shlibsign.

## Commands
- `shlibsign <resource> <action>` — Execute shlibsign commands
- `shlibsign self version` — Print shlibsign version
- `shlibsign _ _` — Passthrough to shlibsign CLI

## Usage Examples
- "shlibsign --help"
- "shlibsign self version"

## Installation
```bash
apt-get install shlibsign 2>/dev/null || which shlibsign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
