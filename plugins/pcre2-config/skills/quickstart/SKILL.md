# pcre2-config Plugin

CLI tool: pcre2-config.

## Commands
- `pcre2-config <resource> <action>` — Execute pcre2-config commands
- `pcre2-config self version` — Print pcre2-config version
- `pcre2-config _ _` — Passthrough to pcre2-config CLI

## Usage Examples
- "pcre2-config --help"
- "pcre2-config self version"

## Installation
```bash
apt-get install pcre2-config 2>/dev/null || which pcre2-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
