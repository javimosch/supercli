# du-dust Plugin

du-dust (dust) — a more intuitive version of du in Rust..

## Commands

### `sc du-dust disk usage`
Show disk usage for directory.

### `sc du-dust self version`
Print version.

## Installation

```bash
cargo install du-dust
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
