# pw-midirecord Plugin

CLI tool: pw-midirecord.

## Commands
- `pw-midirecord <resource> <action>` — Execute pw-midirecord commands
- `pw-midirecord self version` — Print pw-midirecord version
- `pw-midirecord _ _` — Passthrough to pw-midirecord CLI

## Usage Examples
- "pw-midirecord --help"
- "pw-midirecord self version"

## Installation
```bash
apt-get install pw-midirecord 2>/dev/null || which pw-midirecord
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
