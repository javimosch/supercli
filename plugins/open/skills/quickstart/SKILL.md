# open Plugin

CLI tool: open.

## Commands
- `open <resource> <action>` — Execute open commands
- `open self version` — Print open version
- `open _ _` — Passthrough to open CLI

## Usage Examples
- "open --help"
- "open self version"

## Installation
```bash
apt-get install open 2>/dev/null || which open
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
