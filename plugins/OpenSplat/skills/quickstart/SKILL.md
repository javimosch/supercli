# OpenSplat Plugin

Production-grade 3D gaussian splatting with CPU/GPU support for Windows, Mac and Linux 🚀

## Commands

### General
- `OpenSplat self version` — Print OpenSplat version
- `OpenSplat _ _` — Passthrough to opensplat CLI

## Usage Examples
- "Run OpenSplat"
- "Use opensplat to Production-grade 3D gaussian splatting with CPU/GPU support "

## Installation

```bash
pip install opensplat
```

## Key Features
- Production-grade 3D gaussian splatting with CPU/GPU support for Windows, Mac and Linux 🚀
- CLI tool, headless and scriptable
