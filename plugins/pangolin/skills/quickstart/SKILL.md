# pangolin Plugin

Identity-aware VPN and tunneled reverse proxy for remote access based on WireGuard®.

## Commands
- `pangolin <resource> <action>` — Execute pangolin commands
- `pangolin self version` — Print pangolin version
- `pangolin _ _` — Passthrough to pangolin CLI

## Installation

```bash
pip install pangolin
```
