# wizer Plugin

WASM pre-initializer CLI — pre-run WASM modules to snapshot state for fast cold starts

## Commands
- `wizer self version` — Print wizer version
- `wizer _ _` — Passthrough to wizer CLI

## Usage Examples
- `wizer self version` — Check installed version
- `wizer _ _ --help` — Show wizer help
- `wizer _ _ --json` — JSON output mode

## Installation
```bash
cargo install wizer
```

## Key Features
- wasm, pre-init, rust, cli
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
