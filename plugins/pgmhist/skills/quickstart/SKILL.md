# pgmhist Plugin

CLI tool: pgmhist.

## Commands
- `pgmhist <resource> <action>` — Execute pgmhist commands
- `pgmhist self version` — Print pgmhist version
- `pgmhist _ _` — Passthrough to pgmhist CLI

## Usage Examples
- "pgmhist --help"
- "pgmhist self version"

## Installation
```bash
apt-get install pgmhist 2>/dev/null || which pgmhist
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
