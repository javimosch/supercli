# spyql Plugin

CLI tool: spyql.

## Commands
- `spyql <resource> <action>` — Execute spyql commands
- `spyql self version` — Print spyql version
- `spyql _ _` — Passthrough to spyql CLI

## Usage Examples
- "spyql --help"
- "spyql self version"

## Installation
```bash
apt-get install spyql 2>/dev/null || which spyql
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
