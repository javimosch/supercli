# uniq Plugin
Report or omit repeated lines

## Commands
- `uniq <resource> <action>` — Execute uniq commands
- `uniq self version` — Print uniq version
- `uniq _ _` — Passthrough to uniq CLI

## Usage
- `uniq _ _ <args>` — Run uniq with any arguments
