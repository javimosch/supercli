# msexpand Plugin

CLI tool: msexpand.

## Commands
- `msexpand <resource> <action>` — Execute msexpand commands
- `msexpand self version` — Print msexpand version
- `msexpand _ _` — Passthrough to msexpand CLI

## Usage Examples
- "msexpand --help"
- "msexpand self version"

## Installation
```bash
apt-get install msexpand 2>/dev/null || which msexpand
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
