# wifiqr Plugin

wifiqr — create a QR code with your Wi-Fi login details..

## Commands

### `sc wifiqr wifi generate`
Generate WiFi QR code.

### `sc wifiqr self version`
Print version.

## Installation

```bash
go install github.com/reclaimingmytime/wifiqr@latest
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
