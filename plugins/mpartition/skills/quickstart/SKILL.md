# mpartition Plugin

CLI tool: mpartition.

## Commands
- `mpartition <resource> <action>` — Execute mpartition commands
- `mpartition self version` — Print mpartition version
- `mpartition _ _` — Passthrough to mpartition CLI

## Usage Examples
- "mpartition --help"
- "mpartition self version"

## Installation
```bash
apt-get install mpartition 2>/dev/null || which mpartition
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
