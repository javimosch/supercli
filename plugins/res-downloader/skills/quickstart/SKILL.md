# res-downloader Plugin

视频号、小程序、抖音、快手、小红书、直播流、m3u8、酷狗、QQ音乐等常见网络资源下载!

## Commands
- `res-downloader <resource> <action>` — Execute res-downloader commands
- `res-downloader self version` — Print res-downloader version
- `res-downloader _ _` — Passthrough to res-downloader CLI

## Installation

```bash
pip install res-downloader
```
