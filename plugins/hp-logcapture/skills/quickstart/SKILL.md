# hp-logcapture Plugin

CLI tool: hp-logcapture.

## Commands
- `hp-logcapture <resource> <action>` — Execute hp-logcapture commands
- `hp-logcapture self version` — Print hp-logcapture version
- `hp-logcapture _ _` — Passthrough to hp-logcapture CLI

## Usage Examples
- "hp-logcapture --help"
- "hp-logcapture self version"

## Installation
```bash
apt-get install hp-logcapture 2>/dev/null || which hp-logcapture
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
