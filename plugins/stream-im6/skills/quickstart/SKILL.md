# stream-im6 Plugin

CLI tool: stream-im6.

## Commands
- `stream-im6 <resource> <action>` — Execute stream-im6 commands
- `stream-im6 self version` — Print stream-im6 version
- `stream-im6 _ _` — Passthrough to stream-im6 CLI

## Usage Examples
- "stream-im6 --help"
- "stream-im6 self version"

## Installation
```bash
apt-get install stream-im6 2>/dev/null || which stream-im6
```
