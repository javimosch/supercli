# icuinfo Plugin

CLI tool: icuinfo.

## Commands
- `icuinfo <resource> <action>` — Execute icuinfo commands
- `icuinfo self version` — Print icuinfo version
- `icuinfo _ _` — Passthrough to icuinfo CLI

## Usage Examples
- "icuinfo --help"
- "icuinfo self version"

## Installation
```bash
apt-get install icuinfo 2>/dev/null || which icuinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
