# gif-maker Plugin
Create animated GIFs from video files and image sequences

## Commands
- `gif-maker <resource> <action>` — Execute gif-maker commands
- `gif-maker _ _` — Passthrough to gif-maker CLI

## Usage
- `gif-maker _ _ <args>` — Run gif-maker with any arguments
