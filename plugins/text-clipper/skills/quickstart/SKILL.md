# text-clipper Plugin
Clip text to specified lengths.
## Commands
- `text-clipper _ _` — Passthrough to text-clipper CLI
## Installation
```bash
cargo install text-clipper
```
## Key Features
- **Text clipping** — Truncate to length
- **LLM-ready** — Context window preparation
- **Pipeline-ready** — stdin/stdout
