# mmount Plugin

CLI tool: mmount.

## Commands
- `mmount <resource> <action>` — Execute mmount commands
- `mmount self version` — Print mmount version
- `mmount _ _` — Passthrough to mmount CLI

## Usage Examples
- "mmount --help"
- "mmount self version"

## Installation
```bash
apt-get install mmount 2>/dev/null || which mmount
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
