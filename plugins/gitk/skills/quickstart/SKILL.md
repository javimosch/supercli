# gitk Plugin

CLI tool: gitk.

## Commands
- `gitk <resource> <action>` — Execute gitk commands
- `gitk self version` — Print gitk version
- `gitk _ _` — Passthrough to gitk CLI

## Usage Examples
- "gitk --help"
- "gitk self version"

## Installation
```bash
apt-get install gitk 2>/dev/null || which gitk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
