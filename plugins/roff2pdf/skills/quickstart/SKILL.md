# roff2pdf Plugin

CLI tool: roff2pdf.

## Commands
- `roff2pdf <resource> <action>` — Execute roff2pdf commands
- `roff2pdf self version` — Print roff2pdf version
- `roff2pdf _ _` — Passthrough to roff2pdf CLI

## Usage Examples
- "roff2pdf --help"
- "roff2pdf self version"

## Installation
```bash
apt-get install roff2pdf 2>/dev/null || which roff2pdf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
