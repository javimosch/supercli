# port-available-cli Plugin
CLI tool for port-available-cli.

- `port-available-cli _ _` — Passthrough to port-available-cli CLI

## Installation
```bash
cargo install port-available-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
