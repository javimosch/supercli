# texluac Plugin

CLI tool: texluac.

## Commands
- `texluac <resource> <action>` — Execute texluac commands
- `texluac self version` — Print texluac version
- `texluac _ _` — Passthrough to texluac CLI

## Usage Examples
- "texluac --help"
- "texluac self version"

## Installation
```bash
apt-get install texluac 2>/dev/null || which texluac
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
