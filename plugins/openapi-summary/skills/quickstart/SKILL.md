# openapi-summary
openapi-summary — parse OpenAPI/Swagger specs into flattened summaries. Shows endpoints, methods, summaries, servers. Agents can understand any REST API from its spec.

## Commands
- `openapi-summary <resource> <action>` — Execute openapi-summary commands
- `openapi summary run` — openapi-summary — parse OpenAPI/Swagger specs into flattened summaries. Shows endpoints, methods, summaries, servers. Agents can understand any REST API from its spec.
