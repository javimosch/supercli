# neuron Plugin
Future-proof Zettelkasten note-taking system

- `neuron <resource> <action>` — Execute neuron commands
- `neuron _ _` — Passthrough to neuron CLI

## Usage
- `neuron _ _ <args>` — Run neuron with any arguments
