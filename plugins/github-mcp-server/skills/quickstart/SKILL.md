# github-mcp-server Plugin

GitHub's official MCP Server

## Commands

### General
- `github-mcp-server self version` — Print github-mcp-server version
- `github-mcp-server _ _` — Passthrough to github-mcp-server CLI

## Usage Examples
- "Run github-mcp-server"
- "Use github-mcp-server to GitHub's official MCP Server"

## Installation

```bash
pip install github-mcp-server
```

## Key Features
- GitHub's official MCP Server
- CLI tool, headless and scriptable
