# rls Plugin

CLI tool: rls.

## Commands
- `rls <resource> <action>` — Execute rls commands
- `rls self version` — Print rls version
- `rls _ _` — Passthrough to rls CLI

## Usage Examples
- "rls --help"
- "rls self version"

## Installation
```bash
apt-get install rls 2>/dev/null || which rls
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
