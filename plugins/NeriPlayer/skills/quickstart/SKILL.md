# NeriPlayer Plugin

A unified Android player for streaming music and videos from multiple online platforms. / ✨ 简易多平台音视频聚合流媒体播放器 🎵

## Commands

### General
- `NeriPlayer self version` — Print NeriPlayer version
- `NeriPlayer _ _` — Passthrough to neriplayer CLI
