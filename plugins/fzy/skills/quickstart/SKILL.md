# fzy Plugin

fzy — a fast, simple fuzzy text selector for the terminal..

## Commands

### `sc fzy search run`
Fuzzy filter stdin lines.

### `sc fzy self version`
Print version.

## Installation

```bash
brew install fzy
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
