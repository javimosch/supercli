# grub-script-check Plugin

CLI tool: grub-script-check.

## Commands
- `grub-script-check <resource> <action>` — Execute grub-script-check commands
- `grub-script-check self version` — Print grub-script-check version
- `grub-script-check _ _` — Passthrough to grub-script-check CLI

## Usage Examples
- "grub-script-check --help"
- "grub-script-check self version"

## Installation
```bash
apt-get install grub-script-check 2>/dev/null || which grub-script-check
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
