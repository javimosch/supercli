# mdir Plugin

CLI tool: mdir.

## Commands
- `mdir <resource> <action>` — Execute mdir commands
- `mdir self version` — Print mdir version
- `mdir _ _` — Passthrough to mdir CLI

## Usage Examples
- "mdir --help"
- "mdir self version"

## Installation
```bash
apt-get install mdir 2>/dev/null || which mdir
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
