# iio-sensor-proxy Plugin

CLI tool: iio-sensor-proxy.

## Commands
- `iio-sensor-proxy <resource> <action>` — Execute iio-sensor-proxy commands
- `iio-sensor-proxy self version` — Print iio-sensor-proxy version
- `iio-sensor-proxy _ _` — Passthrough to iio-sensor-proxy CLI

## Usage Examples
- "iio-sensor-proxy --help"
- "iio-sensor-proxy self version"

## Installation
```bash
apt-get install iio-sensor-proxy 2>/dev/null || which iio-sensor-proxy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
