# niri Plugin

A scrollable-tiling Wayland compositor.

## Commands
- `niri <resource> <action>` — Execute niri commands
- `niri self version` — Print niri version
- `niri _ _` — Passthrough to niri CLI

## Installation

```bash
pip install niri
```
