# matugen Plugin
CLI tool for matugen.

## Commands
- `matugen <resource> <action>` — Execute matugen commands
- `matugen _ _` — Passthrough to matugen CLI

## Installation
```bash
cargo install matugen
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
