# Langextract Plugin

Extract structured information from unstructured text using LLMs with source grounding

## Commands
- `langextract _ _` — Passthrough to langextract CLI

## Installation

```bash
pip install langextract
```

## Examples
```bash
langextract --help
langextract --version
```
