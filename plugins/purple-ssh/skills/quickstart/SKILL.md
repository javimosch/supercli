# purple-ssh Plugin
Ratatui-powered terminal SSH client with modern UI

## Commands
- `purple-ssh <resource> <action>` — Execute purple-ssh commands
- `purple-ssh _ _` — Passthrough to purple-ssh CLI

## Usage
- `purple-ssh _ _ <args>` — Run purple-ssh with any arguments
