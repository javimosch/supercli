# newusers Plugin

CLI tool: newusers.

## Commands
- `newusers <resource> <action>` — Execute newusers commands
- `newusers self version` — Print newusers version
- `newusers _ _` — Passthrough to newusers CLI

## Usage Examples
- "newusers --help"
- "newusers self version"

## Installation
```bash
apt-get install newusers 2>/dev/null || which newusers
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
