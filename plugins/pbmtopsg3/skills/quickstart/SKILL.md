# pbmtopsg3 Plugin

CLI tool: pbmtopsg3.

- `pbmtopsg3 <resource> <action>` — Execute pbmtopsg3 commands
- `pbmtopsg3 self version` — Print pbmtopsg3 version
- `pbmtopsg3 _ _` — Passthrough to pbmtopsg3 CLI
