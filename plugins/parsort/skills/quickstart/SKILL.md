# parsort Plugin

CLI tool: parsort.

## Commands
- `parsort <resource> <action>` — Execute parsort commands
- `parsort self version` — Print parsort version
- `parsort _ _` — Passthrough to parsort CLI

## Usage Examples
- "parsort --help"
- "parsort self version"

## Installation
```bash
apt-get install parsort 2>/dev/null || which parsort
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
