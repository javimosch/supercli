# pbmtopi3 Plugin

CLI tool: pbmtopi3.

## Commands
- `pbmtopi3 <resource> <action>` — Execute pbmtopi3 commands
- `pbmtopi3 self version` — Print pbmtopi3 version
- `pbmtopi3 _ _` — Passthrough to pbmtopi3 CLI

## Usage Examples
- "pbmtopi3 --help"
- "pbmtopi3 self version"

## Installation
```bash
apt-get install pbmtopi3 2>/dev/null || which pbmtopi3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
