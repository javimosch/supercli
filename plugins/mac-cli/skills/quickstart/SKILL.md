# mac-cli Plugin
Automation suite for common macOS system tasks

## Commands
- `mac-cli <resource> <action>` — Execute mac-cli commands
- `mac-cli _ _` — Passthrough to mac-cli CLI

## Usage
- `mac-cli _ _ <args>` — Run mac-cli with any arguments
