# pnmpad Plugin

CLI tool: pnmpad.

## Commands
- `pnmpad <resource> <action>` — Execute pnmpad commands
- `pnmpad self version` — Print pnmpad version
- `pnmpad _ _` — Passthrough to pnmpad CLI

## Usage Examples
- "pnmpad --help"
- "pnmpad self version"

## Installation
```bash
apt-get install pnmpad 2>/dev/null || which pnmpad
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
