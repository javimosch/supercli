# lessfile Plugin

CLI tool: lessfile.

## Commands
- `lessfile <resource> <action>` — Execute lessfile commands
- `lessfile self version` — Print lessfile version
- `lessfile _ _` — Passthrough to lessfile CLI

## Usage Examples
- "lessfile --help"
- "lessfile self version"

## Installation
```bash
apt-get install lessfile 2>/dev/null || which lessfile
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
