# httpserv Plugin

CLI tool: httpserv.

## Commands
- `httpserv <resource> <action>` — Execute httpserv commands
- `httpserv self version` — Print httpserv version
- `httpserv _ _` — Passthrough to httpserv CLI

## Usage Examples
- "httpserv --help"
- "httpserv self version"

## Installation
```bash
apt-get install httpserv 2>/dev/null || which httpserv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
