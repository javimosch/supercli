# anyzig Plugin

One zig to rule them all

## Commands

### Version
`anyzig self version` — Print anyzig version

### Passthrough
`anyzig _ _` — Passthrough to anyzig CLI with all arguments forwarded.

## Usage Examples

```bash
anyzig --version
anyzig --help
```

## Installation

```bash
cargo install anyzig
```
