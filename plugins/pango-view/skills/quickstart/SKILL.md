# pango-view Plugin

CLI tool: pango-view.

## Commands
- `pango-view <resource> <action>` — Execute pango-view commands
- `pango-view self version` — Print pango-view version
- `pango-view _ _` — Passthrough to pango-view CLI

## Usage Examples
- "pango-view --help"
- "pango-view self version"

## Installation
```bash
apt-get install pango-view 2>/dev/null || which pango-view
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
