# termpair Plugin
Share your terminal sessions with end-to-end encryption

## Commands
- `termpair <resource> <action>` — Execute termpair commands
- `termpair _ _` — Passthrough to termpair CLI

## Usage
- `termpair _ _ <args>` — Run termpair with any arguments
