# gpt-cli Plugin
Command-line interface to ChatGPT models

## Commands
- `gpt-cli <resource> <action>` — Execute gpt-cli commands
- `gpt-cli _ _` — Passthrough to gpt-cli CLI

## Usage
- `gpt-cli _ _ <args>` — Run gpt-cli with any arguments
