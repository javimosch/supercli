# pamfile Plugin

CLI tool: pamfile.

## Commands
- `pamfile <resource> <action>` — Execute pamfile commands
- `pamfile self version` — Print pamfile version
- `pamfile _ _` — Passthrough to pamfile CLI

## Usage Examples
- "pamfile --help"
- "pamfile self version"

## Installation
```bash
apt-get install pamfile 2>/dev/null || which pamfile
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
