# Venice.ai Skills — AI API Agent Skills

Agent Skills for the Venice.ai API. SKILL.md files for AI agent runtimes covering Venice.ai's capabilities.

## Installation
```bash
git clone https://github.com/veniceai/skills.git
sc skills teach veniceai-skills:quickstart
```

## What's Included
- **Image Generation** — Skills for generating images via Venice.ai API
- **Model Access** — Skills for LLM and model interactions
- **API Integration** — Skills for Venice.ai API endpoints and usage patterns

## Requirements
- Some capabilities require a Venice.ai API key
- Works with Cursor, Claude Code, Codex, and other SKILL.md-compatible runtimes
