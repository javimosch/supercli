# harmony Plugin

Renderer for the harmony response format to be used with gpt-oss

## Commands

### General
- `harmony self version` — Print harmony version
- `harmony _ _` — Passthrough to harmony CLI

## Usage Examples
- "Run harmony"
- "Use harmony to Renderer for the harmony response format to be used with gpt"

## Installation

```bash
pip install harmony
```

## Key Features
- Renderer for the harmony response format to be used with gpt-oss
- CLI tool, headless and scriptable
