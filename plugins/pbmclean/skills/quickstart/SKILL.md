# pbmclean Plugin

CLI tool: pbmclean.

## Commands
- `pbmclean <resource> <action>` — Execute pbmclean commands
- `pbmclean self version` — Print pbmclean version
- `pbmclean _ _` — Passthrough to pbmclean CLI

## Usage Examples
- "pbmclean --help"
- "pbmclean self version"

## Installation
```bash
apt-get install pbmclean 2>/dev/null || which pbmclean
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
