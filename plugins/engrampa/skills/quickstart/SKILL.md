# engrampa Plugin

engrampa manages compressed archives.

## Usage Examples

- "extract a ZIP archive"
- "create a compressed TAR archive"
- "list contents of an archive file"

## Installation

```bash
brew install engrampa
```

## Key Features
- Multiple archive format support
- Archive creation and extraction
- Encrypted archive handling
- Split archive management
- Automatic format detection
- Batch archive operations
