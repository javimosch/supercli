# gcm-import Plugin

CLI tool: gcm-import.

## Commands
- `gcm-import <resource> <action>` — Execute gcm-import commands
- `gcm-import self version` — Print gcm-import version
- `gcm-import _ _` — Passthrough to gcm-import CLI

## Usage Examples
- "gcm-import --help"
- "gcm-import self version"

## Installation
```bash
apt-get install gcm-import 2>/dev/null || which gcm-import
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
