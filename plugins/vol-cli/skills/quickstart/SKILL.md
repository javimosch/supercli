# vol-cli Plugin
Simple ALSA/Pulse audio volume control from scripts

## Commands
- `vol-cli <resource> <action>` — Execute vol-cli commands
- `vol-cli _ _` — Passthrough to vol-cli CLI

## Usage
- `vol-cli _ _ <args>` — Run vol-cli with any arguments
