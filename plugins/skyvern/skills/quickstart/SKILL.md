# skyvern Plugin

Automate browser based workflows with AI

## Commands
- `skyvern <resource> <action>` — Execute skyvern commands
- `skyvern self version` — Print skyvern version
- `skyvern _ _` — Passthrough to skyvern CLI

## Installation

```bash
pip install skyvern
```
