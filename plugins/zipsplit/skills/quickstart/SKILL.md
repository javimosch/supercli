# zipsplit Plugin

CLI tool: zipsplit.

## Commands
- `zipsplit <resource> <action>` — Execute zipsplit commands
- `zipsplit self version` — Print zipsplit version
- `zipsplit _ _` — Passthrough to zipsplit CLI

## Usage Examples
- "zipsplit --help"
- "zipsplit self version"

## Installation
```bash
apt-get install zipsplit 2>/dev/null || which zipsplit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
