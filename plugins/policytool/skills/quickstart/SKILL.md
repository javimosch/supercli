# policytool Plugin

CLI tool: policytool.

## Commands
- `policytool <resource> <action>` — Execute policytool commands
- `policytool self version` — Print policytool version
- `policytool _ _` — Passthrough to policytool CLI

## Usage Examples
- "policytool --help"
- "policytool self version"

## Installation
```bash
apt-get install policytool 2>/dev/null || which policytool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
