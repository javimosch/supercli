# makejvf Plugin

CLI tool: makejvf.

## Commands
- `makejvf <resource> <action>` — Execute makejvf commands
- `makejvf self version` — Print makejvf version
- `makejvf _ _` — Passthrough to makejvf CLI

## Usage Examples
- "makejvf --help"
- "makejvf self version"

## Installation
```bash
apt-get install makejvf 2>/dev/null || which makejvf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
