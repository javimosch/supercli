# isort-identify-imports Plugin

CLI tool: isort-identify-imports.

## Commands
- `isort-identify-imports <resource> <action>` — Execute isort-identify-imports commands
- `isort-identify-imports self version` — Print isort-identify-imports version
- `isort-identify-imports _ _` — Passthrough to isort-identify-imports CLI

## Usage Examples
- "isort-identify-imports --help"
- "isort-identify-imports self version"
