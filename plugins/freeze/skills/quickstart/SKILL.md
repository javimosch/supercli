# freeze Plugin

Generate images of code and terminal output 📸

## Commands

### General
- `freeze self version` — Print freeze version
- `freeze _ _` — Passthrough to freeze CLI

## Usage Examples
- "Run freeze"
- "Use freeze to Generate images of code and terminal output 📸"

## Installation

```bash
pip install freeze
```

## Key Features
- Generate images of code and terminal output 📸
- CLI tool, headless and scriptable
