# vale Quickstart

Markup-aware linter for prose

## Commands
- `vale <resource> <action>` — Execute vale commands
- `vale self version` — Print vale version
- `vale _ _` — Passthrough to vale CLI

## Installation

```bash
brew install vale
```

## Quick Examples

```bash
# Check version
vale --version

# Get help
vale --help
```
