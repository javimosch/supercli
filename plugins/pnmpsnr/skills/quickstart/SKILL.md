# pnmpsnr Plugin

CLI tool: pnmpsnr.

## Commands
- `pnmpsnr <resource> <action>` — Execute pnmpsnr commands
- `pnmpsnr self version` — Print pnmpsnr version
- `pnmpsnr _ _` — Passthrough to pnmpsnr CLI

## Usage Examples
- "pnmpsnr --help"
- "pnmpsnr self version"

## Installation
```bash
apt-get install pnmpsnr 2>/dev/null || which pnmpsnr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
