# localc Plugin

CLI tool: localc.

## Commands
- `localc <resource> <action>` — Execute localc commands
- `localc self version` — Print localc version
- `localc _ _` — Passthrough to localc CLI

## Usage Examples
- "localc --help"
- "localc self version"

## Installation
```bash
apt-get install localc 2>/dev/null || which localc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
