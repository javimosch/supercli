# ovh-cli Plugin

OVHcloud CLI for managing cloud resources

## Commands
- `ovh-cli self version` — Print version
- `ovh-cli _ _` — Passthrough to ovh

## Installation
```bash
npm install -g @ovh-api/cli
```
