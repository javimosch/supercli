# mm2gv Plugin

CLI tool: mm2gv.

## Commands
- `mm2gv <resource> <action>` — Execute mm2gv commands
- `mm2gv self version` — Print mm2gv version
- `mm2gv _ _` — Passthrough to mm2gv CLI

## Usage Examples
- "mm2gv --help"
- "mm2gv self version"

## Installation
```bash
apt-get install mm2gv 2>/dev/null || which mm2gv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
