# portfwd Plugin

Port forwarding CLI — manage local and remote port forwards with JSON config

## Commands
- `portfwd self version` — Print version
- `portfwd _ _` — Passthrough to portfwd

## Installation
```bash
go install github.com/portfwd/portfwd@latest
```
