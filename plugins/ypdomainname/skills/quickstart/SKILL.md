# ypdomainname Plugin

CLI tool: ypdomainname.

## Commands
- `ypdomainname <resource> <action>` — Execute ypdomainname commands
- `ypdomainname self version` — Print ypdomainname version
- `ypdomainname _ _` — Passthrough to ypdomainname CLI

## Usage Examples
- "ypdomainname --help"
- "ypdomainname self version"

## Installation
```bash
apt-get install ypdomainname 2>/dev/null || which ypdomainname
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
