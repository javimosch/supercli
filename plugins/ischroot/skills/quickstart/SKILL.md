# ischroot Plugin

CLI tool: ischroot.

## Commands
- `ischroot <resource> <action>` — Execute ischroot commands
- `ischroot self version` — Print ischroot version
- `ischroot _ _` — Passthrough to ischroot CLI

## Usage Examples
- "ischroot --help"
- "ischroot self version"

## Installation
```bash
apt-get install ischroot 2>/dev/null || which ischroot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
