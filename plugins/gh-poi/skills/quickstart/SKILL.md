# gh-poi Plugin

Delete merged GitHub branches with CLI — JSON output supported

## Commands
- `gh-poi self version` — Print gh-poi version
- `gh-poi _ _` — Passthrough to gh-poi CLI

## Usage Examples
- `gh-poi self version` — Check installed version
- `gh-poi _ _ --help` — Show gh-poi help
- `gh-poi _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/seachicken/gh-poi@latest
```

## Key Features
- github, branches, golang, cli
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
