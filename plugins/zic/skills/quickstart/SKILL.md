# zic Plugin

CLI tool: zic.

## Commands
- `zic <resource> <action>` — Execute zic commands
- `zic self version` — Print zic version
- `zic _ _` — Passthrough to zic CLI

## Usage Examples
- "zic --help"
- "zic self version"

## Installation
```bash
apt-get install zic 2>/dev/null || which zic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
