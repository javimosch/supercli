# webp-pixbuf-loader
webp-pixbuf-loader — WebP GDK pixbuf loader. Enable WebP support in GTK applications.

## Commands
- `webp-pixbuf-loader <resource> <action>` — Execute webp-pixbuf-loader commands
- `webp pixbuf-loader run` — webp-pixbuf-loader — WebP GDK pixbuf loader. Enable WebP support in GTK applications.
