# pbmtozinc Plugin

CLI tool: pbmtozinc.

## Commands
- `pbmtozinc <resource> <action>` — Execute pbmtozinc commands
- `pbmtozinc self version` — Print pbmtozinc version
- `pbmtozinc _ _` — Passthrough to pbmtozinc CLI

## Usage Examples
- "pbmtozinc --help"
- "pbmtozinc self version"

## Installation
```bash
apt-get install pbmtozinc 2>/dev/null || which pbmtozinc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
