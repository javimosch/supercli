# ps2ascii Plugin

CLI tool: ps2ascii.

## Commands
- `ps2ascii <resource> <action>` — Execute ps2ascii commands
- `ps2ascii self version` — Print ps2ascii version
- `ps2ascii _ _` — Passthrough to ps2ascii CLI

## Usage Examples
- "ps2ascii --help"
- "ps2ascii self version"

## Installation
```bash
apt-get install ps2ascii 2>/dev/null || which ps2ascii
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
