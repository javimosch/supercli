# view Plugin

CLI tool: view.

## Commands
- `view <resource> <action>` — Execute view commands
- `view self version` — Print view version
- `view _ _` — Passthrough to view CLI

## Usage Examples
- "view --help"
- "view self version"

## Installation
```bash
apt-get install view 2>/dev/null || which view
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
