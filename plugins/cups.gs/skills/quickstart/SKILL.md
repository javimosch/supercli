# cups.gs Plugin

CLI tool: cups.gs.

## Commands
- `cups.gs <resource> <action>` — Execute cups.gs commands
- `cups.gs self version` — Print cups.gs version
- `cups.gs _ _` — Passthrough to cups.gs CLI

## Usage Examples
- "cups.gs --help"
- "cups.gs self version"

## Installation
```bash
apt-get install cups.gs 2>/dev/null || which cups.gs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
