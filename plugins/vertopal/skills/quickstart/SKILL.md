# vertopal Plugin

CLI tool: vertopal.

## Commands
- `vertopal <resource> <action>` — Execute vertopal commands
- `vertopal self version` — Print vertopal version
- `vertopal _ _` — Passthrough to vertopal CLI

## Usage Examples
- "vertopal --help"
- "vertopal self version"

## Installation
```bash
apt-get install vertopal 2>/dev/null || which vertopal
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
