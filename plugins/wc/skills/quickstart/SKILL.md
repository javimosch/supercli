# wc Plugin
Count lines, words, and characters

## Commands
- `wc <resource> <action>` — Execute wc commands
- `wc self version` — Print wc version
- `wc _ _` — Passthrough to wc CLI

## Usage
- `wc _ _ <args>` — Run wc with any arguments
