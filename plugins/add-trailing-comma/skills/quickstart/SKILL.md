# add-trailing-comma Plugin
Add trailing commas to Python calls and literals

## Commands
- `add-trailing-comma <resource> <action>` — Execute add-trailing-comma commands
- `add-trailing-comma _ _` — Passthrough to add-trailing-comma CLI

## Usage
- `add-trailing-comma _ _ <args>` — Run add-trailing-comma with any arguments
