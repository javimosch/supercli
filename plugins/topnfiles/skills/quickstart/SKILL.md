# topnfiles Plugin
CLI tool for topnfiles.

## Commands
- `topnfiles <resource> <action>` — Execute topnfiles commands
- `topnfiles _ _` — Passthrough to topnfiles CLI

## Installation
```bash
cargo install topnfiles
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
