# setleds Plugin

CLI tool: setleds.

## Commands
- `setleds <resource> <action>` — Execute setleds commands
- `setleds self version` — Print setleds version
- `setleds _ _` — Passthrough to setleds CLI

## Usage Examples
- "setleds --help"
- "setleds self version"

## Installation
```bash
apt-get install setleds 2>/dev/null || which setleds
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
