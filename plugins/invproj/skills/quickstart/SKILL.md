# invproj Plugin

CLI tool: invproj.

## Commands
- `invproj <resource> <action>` — Execute invproj commands
- `invproj self version` — Print invproj version
- `invproj _ _` — Passthrough to invproj CLI

## Usage Examples
- "invproj --help"
- "invproj self version"

## Installation
```bash
apt-get install invproj 2>/dev/null || which invproj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
