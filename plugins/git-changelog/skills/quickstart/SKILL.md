# git-changelog
git-changelog — structured changelog from git history. Outputs JSON array of commits with hash, author, date, subject.

## Commands
- `git-changelog <resource> <action>` — Execute git-changelog commands
- `git changelog run` — git-changelog — structured changelog from git history. Outputs JSON array of commits with hash, author, date, subject.
