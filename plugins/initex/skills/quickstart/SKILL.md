# initex Plugin

CLI tool: initex.

## Commands
- `initex <resource> <action>` — Execute initex commands
- `initex self version` — Print initex version
- `initex _ _` — Passthrough to initex CLI

## Usage Examples
- "initex --help"
- "initex self version"

## Installation
```bash
apt-get install initex 2>/dev/null || which initex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
