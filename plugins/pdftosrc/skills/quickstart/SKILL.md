# pdftosrc Plugin

CLI tool: pdftosrc.

## Commands
- `pdftosrc <resource> <action>` — Execute pdftosrc commands
- `pdftosrc self version` — Print pdftosrc version
- `pdftosrc _ _` — Passthrough to pdftosrc CLI

## Usage Examples
- "pdftosrc --help"
- "pdftosrc self version"

## Installation
```bash
apt-get install pdftosrc 2>/dev/null || which pdftosrc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
