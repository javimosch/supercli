# roff2x Plugin

CLI tool: roff2x.

## Commands
- `roff2x <resource> <action>` — Execute roff2x commands
- `roff2x self version` — Print roff2x version
- `roff2x _ _` — Passthrough to roff2x CLI

## Usage Examples
- "roff2x --help"
- "roff2x self version"

## Installation
```bash
apt-get install roff2x 2>/dev/null || which roff2x
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
