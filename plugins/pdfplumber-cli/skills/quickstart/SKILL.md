# pdfplumber-cli Plugin
Extract tables and text from PDFs with precise layout

## Commands
- `pdfplumber-cli <resource> <action>` — Execute pdfplumber-cli commands
- `pdfplumber-cli _ _` — Passthrough to pdfplumber-cli CLI

## Usage
- `pdfplumber-cli _ _ <args>` — Run pdfplumber-cli with any arguments
