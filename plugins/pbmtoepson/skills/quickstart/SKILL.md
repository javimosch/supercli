# pbmtoepson Plugin

CLI tool: pbmtoepson.

## Commands
- `pbmtoepson <resource> <action>` — Execute pbmtoepson commands
- `pbmtoepson self version` — Print pbmtoepson version
- `pbmtoepson _ _` — Passthrough to pbmtoepson CLI
