# pdf-merge Plugin
Merge multiple PDF files into a single document via CLI

## Commands
- `pdf-merge <resource> <action>` — Execute pdf-merge commands
- `pdf-merge _ _` — Passthrough to pdf-merge CLI

## Usage
- `pdf-merge _ _ <args>` — Run pdf-merge with any arguments
