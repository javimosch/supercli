# genisoimage Plugin

CLI tool: genisoimage.

## Commands
- `genisoimage <resource> <action>` — Execute genisoimage commands
- `genisoimage self version` — Print genisoimage version
- `genisoimage _ _` — Passthrough to genisoimage CLI

## Usage Examples
- "genisoimage --help"
- "genisoimage self version"

## Installation
```bash
apt-get install genisoimage 2>/dev/null || which genisoimage
```
