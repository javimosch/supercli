# streamzip Plugin

CLI tool: streamzip.

## Commands
- `streamzip <resource> <action>` — Execute streamzip commands
- `streamzip self version` — Print streamzip version
- `streamzip _ _` — Passthrough to streamzip CLI

## Usage Examples
- "streamzip --help"
- "streamzip self version"

## Installation
```bash
apt-get install streamzip 2>/dev/null || which streamzip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
