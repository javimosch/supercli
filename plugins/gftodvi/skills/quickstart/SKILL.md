# gftodvi Plugin

CLI tool: gftodvi.

## Commands
- `gftodvi <resource> <action>` — Execute gftodvi commands
- `gftodvi self version` — Print gftodvi version
- `gftodvi _ _` — Passthrough to gftodvi CLI

## Usage Examples
- "gftodvi --help"
- "gftodvi self version"

## Installation
```bash
apt-get install gftodvi 2>/dev/null || which gftodvi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
