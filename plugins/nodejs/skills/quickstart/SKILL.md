# nodejs Plugin

CLI tool: nodejs.

## Commands
- `nodejs <resource> <action>` — Execute nodejs commands
- `nodejs self version` — Print nodejs version
- `nodejs _ _` — Passthrough to nodejs CLI

## Usage Examples
- "nodejs --help"
- "nodejs self version"

## Installation
```bash
apt-get install nodejs 2>/dev/null || which nodejs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
