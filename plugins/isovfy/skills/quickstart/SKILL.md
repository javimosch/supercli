# isovfy Plugin

CLI tool: isovfy.

## Commands
- `isovfy <resource> <action>` — Execute isovfy commands
- `isovfy self version` — Print isovfy version
- `isovfy _ _` — Passthrough to isovfy CLI

## Usage Examples
- "isovfy --help"
- "isovfy self version"

## Installation
```bash
apt-get install isovfy 2>/dev/null || which isovfy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
