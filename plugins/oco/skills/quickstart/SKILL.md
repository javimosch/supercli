# oco Plugin

CLI tool: oco.

## Commands
- `oco <resource> <action>` — Execute oco commands
- `oco self version` — Print oco version
- `oco _ _` — Passthrough to oco CLI

## Usage Examples
- "oco --help"
- "oco self version"

## Installation
```bash
apt-get install oco 2>/dev/null || which oco
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
