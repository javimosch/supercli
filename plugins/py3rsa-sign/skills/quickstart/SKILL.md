# py3rsa-sign Plugin

CLI tool: py3rsa-sign.

## Commands
- `py3rsa-sign <resource> <action>` — Execute py3rsa-sign commands
- `py3rsa-sign self version` — Print py3rsa-sign version
- `py3rsa-sign _ _` — Passthrough to py3rsa-sign CLI

## Usage Examples
- "py3rsa-sign --help"
- "py3rsa-sign self version"

## Installation
```bash
apt-get install py3rsa-sign 2>/dev/null || which py3rsa-sign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
