# lsns Plugin

CLI tool: lsns.

## Commands
- `lsns <resource> <action>` — Execute lsns commands
- `lsns self version` — Print lsns version
- `lsns _ _` — Passthrough to lsns CLI

## Usage Examples
- "lsns --help"
- "lsns self version"

## Installation
```bash
apt-get install lsns 2>/dev/null || which lsns
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
