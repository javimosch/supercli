# spellchecker-cli Plugin
Fast spellchecker CLI using SymSpell algorithm

## Commands
- `spellchecker-cli <resource> <action>` — Execute spellchecker-cli commands
- `spellchecker-cli _ _` — Passthrough to spellchecker-cli CLI

## Usage
- `spellchecker-cli _ _ <args>` — Run spellchecker-cli with any arguments
