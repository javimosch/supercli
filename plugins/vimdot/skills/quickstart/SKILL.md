# vimdot Plugin

CLI tool: vimdot.

## Commands
- `vimdot <resource> <action>` — Execute vimdot commands
- `vimdot self version` — Print vimdot version
- `vimdot _ _` — Passthrough to vimdot CLI

## Usage Examples
- "vimdot --help"
- "vimdot self version"

## Installation
```bash
apt-get install vimdot 2>/dev/null || which vimdot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
