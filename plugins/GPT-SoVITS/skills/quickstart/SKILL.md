# GPT-SoVITS Plugin

1 min voice data can also be used to train a good TTS model! (few shot voice cloning)

## Commands

### General
- `GPT-SoVITS self version` — Print GPT-SoVITS version
- `GPT-SoVITS _ _` — Passthrough to gpt-sovits CLI

## Usage Examples
- "Run GPT-SoVITS"
- "Use gpt-sovits to 1 min voice data can also be used to train a good TTS model!"

## Installation

```bash
pip install gpt-sovits
```

## Key Features
- 1 min voice data can also be used to train a good TTS model! (few shot voice cloning)
- CLI tool, headless and scriptable
