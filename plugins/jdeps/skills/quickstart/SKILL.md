# jdeps Plugin

CLI tool: jdeps.

## Commands
- `jdeps <resource> <action>` — Execute jdeps commands
- `jdeps self version` — Print jdeps version
- `jdeps _ _` — Passthrough to jdeps CLI

## Usage Examples
- "jdeps --help"
- "jdeps self version"

## Installation
```bash
apt-get install jdeps 2>/dev/null || which jdeps
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
