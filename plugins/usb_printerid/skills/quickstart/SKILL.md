# usb_printerid Plugin

CLI tool: usb_printerid.

## Commands
- `usb_printerid <resource> <action>` — Execute usb_printerid commands
- `usb_printerid self version` — Print usb_printerid version
- `usb_printerid _ _` — Passthrough to usb_printerid CLI

## Usage Examples
- "usb_printerid --help"
- "usb_printerid self version"

## Installation
```bash
apt-get install usb_printerid 2>/dev/null || which usb_printerid
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
