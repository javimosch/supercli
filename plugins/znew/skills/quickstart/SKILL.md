# znew Plugin

CLI tool: znew.

## Commands
- `znew <resource> <action>` — Execute znew commands
- `znew self version` — Print znew version
- `znew _ _` — Passthrough to znew CLI

## Usage Examples
- "znew --help"
- "znew self version"

## Installation
```bash
apt-get install znew 2>/dev/null || which znew
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
