# json-merge
json-merge — deep merge multiple JSON objects from stdin. Later objects override earlier ones recursively.

## Commands
- `json-merge <resource> <action>` — Execute json-merge commands
- `json merge run` — json-merge — deep merge multiple JSON objects from stdin. Later objects override earlier ones recursively.
