# myloader Plugin

CLI tool: myloader.

## Commands
- `myloader <resource> <action>` — Execute myloader commands
- `myloader self version` — Print myloader version
- `myloader _ _` — Passthrough to myloader CLI

## Usage Examples
- "myloader --help"
- "myloader self version"

## Installation
```bash
apt-get install myloader 2>/dev/null || which myloader
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
