# sccmap Plugin

CLI tool: sccmap.

## Commands
- `sccmap <resource> <action>` — Execute sccmap commands
- `sccmap self version` — Print sccmap version
- `sccmap _ _` — Passthrough to sccmap CLI

## Usage Examples
- "sccmap --help"
- "sccmap self version"

## Installation
```bash
apt-get install sccmap 2>/dev/null || which sccmap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
