# seqdiag Plugin
Generate sequence diagrams from simple text descriptions

## Commands
- `seqdiag <resource> <action>` — Execute seqdiag commands
- `seqdiag _ _` — Passthrough to seqdiag CLI

## Usage
- `seqdiag _ _ <args>` — Run seqdiag with any arguments
