# pbmtoybm Plugin

CLI tool: pbmtoybm.

## Commands
- `pbmtoybm <resource> <action>` — Execute pbmtoybm commands
- `pbmtoybm self version` — Print pbmtoybm version
- `pbmtoybm _ _` — Passthrough to pbmtoybm CLI

## Usage Examples
- "pbmtoybm --help"
- "pbmtoybm self version"

## Installation
```bash
apt-get install pbmtoybm 2>/dev/null || which pbmtoybm
```
