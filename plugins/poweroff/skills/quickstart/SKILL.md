# poweroff Plugin

CLI tool: poweroff.

## Commands
- `poweroff <resource> <action>` — Execute poweroff commands
- `poweroff self version` — Print poweroff version
- `poweroff _ _` — Passthrough to poweroff CLI

## Usage Examples
- "poweroff --help"
- "poweroff self version"

## Installation
```bash
apt-get install poweroff 2>/dev/null || which poweroff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
