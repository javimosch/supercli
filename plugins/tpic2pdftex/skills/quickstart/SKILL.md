# tpic2pdftex Plugin

CLI tool: tpic2pdftex.

## Commands
- `tpic2pdftex <resource> <action>` — Execute tpic2pdftex commands
- `tpic2pdftex self version` — Print tpic2pdftex version
- `tpic2pdftex _ _` — Passthrough to tpic2pdftex CLI

## Usage Examples
- "tpic2pdftex --help"
- "tpic2pdftex self version"

## Installation
```bash
apt-get install tpic2pdftex 2>/dev/null || which tpic2pdftex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
