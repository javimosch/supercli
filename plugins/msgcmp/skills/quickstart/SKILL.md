# msgcmp Plugin

CLI tool: msgcmp.

## Commands
- `msgcmp <resource> <action>` — Execute msgcmp commands
- `msgcmp self version` — Print msgcmp version
- `msgcmp _ _` — Passthrough to msgcmp CLI

## Usage Examples
- "msgcmp --help"
- "msgcmp self version"

## Installation
```bash
apt-get install msgcmp 2>/dev/null || which msgcmp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
