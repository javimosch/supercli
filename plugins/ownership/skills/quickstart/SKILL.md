# ownership Plugin

CLI tool: ownership.

## Commands
- `ownership <resource> <action>` — Execute ownership commands
- `ownership self version` — Print ownership version
- `ownership _ _` — Passthrough to ownership CLI

## Usage Examples
- "ownership --help"
- "ownership self version"

## Installation
```bash
apt-get install ownership 2>/dev/null || which ownership
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
