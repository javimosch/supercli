# gtester-report Plugin

CLI tool: gtester-report.

## Commands
- `gtester-report <resource> <action>` — Execute gtester-report commands
- `gtester-report self version` — Print gtester-report version
- `gtester-report _ _` — Passthrough to gtester-report CLI

## Usage Examples
- "gtester-report --help"
- "gtester-report self version"

## Installation
```bash
apt-get install gtester-report 2>/dev/null || which gtester-report
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
