# gcloud-sdk

Google Cloud SDK — command-line tools for Google Cloud Platform

## Install

```bash
brew install --cask google-cloud-sdk
```

Verify installation:

```bash
which gcloud
```

## Commands

- `gcloud-sdk self version` — print gcloud version
- `gcloud-sdk cli run ...` — pass any arguments straight through to `gcloud`
