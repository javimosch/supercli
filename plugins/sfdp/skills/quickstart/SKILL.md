# sfdp Plugin

CLI tool: sfdp.

## Commands
- `sfdp <resource> <action>` — Execute sfdp commands
- `sfdp self version` — Print sfdp version
- `sfdp _ _` — Passthrough to sfdp CLI

## Usage Examples
- "sfdp --help"
- "sfdp self version"

## Installation
```bash
apt-get install sfdp 2>/dev/null || which sfdp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
