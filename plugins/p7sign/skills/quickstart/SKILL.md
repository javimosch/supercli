# p7sign Plugin

CLI tool: p7sign.

## Commands
- `p7sign <resource> <action>` — Execute p7sign commands
- `p7sign self version` — Print p7sign version
- `p7sign _ _` — Passthrough to p7sign CLI

## Usage Examples
- "p7sign --help"
- "p7sign self version"

## Installation
```bash
apt-get install p7sign 2>/dev/null || which p7sign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
