# ppmtoicr Plugin

CLI tool: ppmtoicr.

## Commands
- `ppmtoicr <resource> <action>` — Execute ppmtoicr commands
- `ppmtoicr self version` — Print ppmtoicr version
- `ppmtoicr _ _` — Passthrough to ppmtoicr CLI

## Usage Examples
- "ppmtoicr --help"
- "ppmtoicr self version"

## Installation
```bash
apt-get install ppmtoicr 2>/dev/null || which ppmtoicr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
