# getafm Plugin

CLI tool: getafm.

## Commands
- `getafm <resource> <action>` — Execute getafm commands
- `getafm self version` — Print getafm version
- `getafm _ _` — Passthrough to getafm CLI

## Usage Examples
- "getafm --help"
- "getafm self version"

## Installation
```bash
apt-get install getafm 2>/dev/null || which getafm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
