# hp-plugin Plugin

CLI tool: hp-plugin.

## Commands
- `hp-plugin <resource> <action>` — Execute hp-plugin commands
- `hp-plugin self version` — Print hp-plugin version
- `hp-plugin _ _` — Passthrough to hp-plugin CLI

## Usage Examples
- "hp-plugin --help"
- "hp-plugin self version"

## Installation
```bash
apt-get install hp-plugin 2>/dev/null || which hp-plugin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
