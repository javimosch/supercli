# DreamServer Plugin

Turn your PC, Mac, or Linux box into an AI server.  LLM inference, chat UI, voice, agents, workflows, RAG, and image generation.

## Commands

### General
- `DreamServer self version` — Print DreamServer version
- `DreamServer _ _` — Passthrough to dreamserver CLI

```bash
pip install dreamserver
```
