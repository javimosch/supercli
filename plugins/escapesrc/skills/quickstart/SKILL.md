# escapesrc Plugin

CLI tool: escapesrc.

## Commands
- `escapesrc <resource> <action>` — Execute escapesrc commands
- `escapesrc self version` — Print escapesrc version
- `escapesrc _ _` — Passthrough to escapesrc CLI

## Usage Examples
- "escapesrc --help"
- "escapesrc self version"

## Installation
```bash
apt-get install escapesrc 2>/dev/null || which escapesrc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
