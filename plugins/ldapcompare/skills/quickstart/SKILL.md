# ldapcompare Plugin

CLI tool: ldapcompare.

## Commands
- `ldapcompare <resource> <action>` — Execute ldapcompare commands
- `ldapcompare self version` — Print ldapcompare version
- `ldapcompare _ _` — Passthrough to ldapcompare CLI

## Usage Examples
- "ldapcompare --help"
- "ldapcompare self version"

## Installation
```bash
apt-get install ldapcompare 2>/dev/null || which ldapcompare
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
