# openvt Plugin

CLI tool: openvt.

## Commands
- `openvt <resource> <action>` — Execute openvt commands
- `openvt self version` — Print openvt version
- `openvt _ _` — Passthrough to openvt CLI

## Usage Examples
- "openvt --help"
- "openvt self version"

## Installation
```bash
apt-get install openvt 2>/dev/null || which openvt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
