# pgmcrater Plugin

CLI tool: pgmcrater.

## Commands
- `pgmcrater <resource> <action>` — Execute pgmcrater commands
- `pgmcrater self version` — Print pgmcrater version
- `pgmcrater _ _` — Passthrough to pgmcrater CLI

## Usage Examples
- "pgmcrater --help"
- "pgmcrater self version"

## Installation
```bash
apt-get install pgmcrater 2>/dev/null || which pgmcrater
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
