# ld-musl-config Plugin

CLI tool: ld-musl-config.

## Commands
- `ld-musl-config <resource> <action>` — Execute ld-musl-config commands
- `ld-musl-config self version` — Print ld-musl-config version
- `ld-musl-config _ _` — Passthrough to ld-musl-config CLI

## Usage Examples
- "ld-musl-config --help"
- "ld-musl-config self version"

## Installation
```bash
apt-get install ld-musl-config 2>/dev/null || which ld-musl-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
