# pnmtojpeg Plugin

CLI tool: pnmtojpeg.

## Commands
- `pnmtojpeg <resource> <action>` — Execute pnmtojpeg commands
- `pnmtojpeg self version` — Print pnmtojpeg version
- `pnmtojpeg _ _` — Passthrough to pnmtojpeg CLI

## Usage Examples
- "pnmtojpeg --help"
- "pnmtojpeg self version"

## Installation
```bash
apt-get install pnmtojpeg 2>/dev/null || which pnmtojpeg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
