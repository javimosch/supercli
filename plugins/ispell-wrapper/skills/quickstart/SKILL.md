# ispell-wrapper Plugin

CLI tool: ispell-wrapper.

## Commands
- `ispell-wrapper <resource> <action>` — Execute ispell-wrapper commands
- `ispell-wrapper self version` — Print ispell-wrapper version
- `ispell-wrapper _ _` — Passthrough to ispell-wrapper CLI

## Usage Examples
- "ispell-wrapper --help"
- "ispell-wrapper self version"

## Installation
```bash
apt-get install ispell-wrapper 2>/dev/null || which ispell-wrapper
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
