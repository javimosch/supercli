# pycontractions Plugin
Expand English contractions in text

## Commands
- `pycontractions <resource> <action>` — Execute pycontractions commands
- `pycontractions _ _` — Passthrough to pycontractions CLI

## Usage
- `pycontractions _ _ <args>` — Run pycontractions with any arguments
