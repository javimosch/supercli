# forever Quickstart

Ensure scripts run continuously

## Commands
- `forever <resource> <action>` — Execute forever commands
- `forever script start` — Start script continuously
- `forever processes list` — List running processes
- `forever process stop` — Stop a process

## Installation

```bash
npm install -g forever
```

## Quick Examples

```bash
# Check version
forever --version

# Get help
forever --help
```
