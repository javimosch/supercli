# ppmcolormask Plugin

CLI tool: ppmcolormask.

## Commands
- `ppmcolormask <resource> <action>` — Execute ppmcolormask commands
- `ppmcolormask self version` — Print ppmcolormask version
- `ppmcolormask _ _` — Passthrough to ppmcolormask CLI

## Usage Examples
- "ppmcolormask --help"
- "ppmcolormask self version"

## Installation
```bash
apt-get install ppmcolormask 2>/dev/null || which ppmcolormask
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
