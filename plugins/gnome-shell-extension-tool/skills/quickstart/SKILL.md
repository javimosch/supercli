# gnome-shell-extension-tool Plugin

CLI tool: gnome-shell-extension-tool.

## Commands
- `gnome-shell-extension-tool <resource> <action>` — Execute gnome-shell-extension-tool commands
- `gnome-shell-extension-tool self version` — Print gnome-shell-extension-tool version
- `gnome-shell-extension-tool _ _` — Passthrough to gnome-shell-extension-tool CLI

## Usage Examples
- "gnome-shell-extension-tool --help"
- "gnome-shell-extension-tool self version"

## Installation
```bash
apt-get install gnome-shell-extension-tool 2>/dev/null || which gnome-shell-extension-tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
