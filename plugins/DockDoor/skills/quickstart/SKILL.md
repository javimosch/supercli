# DockDoor Plugin

Window peeking, alt-tab and other enhancements for macOS

## Commands

### General
- `DockDoor self version` — Print DockDoor version
- `DockDoor _ _` — Passthrough to dockdoor CLI

## Usage Examples
- "Run DockDoor"
- "Use dockdoor to Window peeking, alt-tab and other enhancements for macOS"

## Installation

```bash
pip install dockdoor
```

## Key Features
- Window peeking, alt-tab and other enhancements for macOS
- CLI tool, headless and scriptable
