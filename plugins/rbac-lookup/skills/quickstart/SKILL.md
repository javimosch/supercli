# rbac-lookup Plugin
Reverse lookup Kubernetes RBAC permissions

## Commands
- `rbac-lookup <resource> <action>` — Execute rbac-lookup commands
- `rbac-lookup _ _` — Passthrough to rbac-lookup CLI

## Usage
- `rbac-lookup _ _ <args>` — Run rbac-lookup with any arguments
