# exo Plugin

Run frontier AI locally.

## Commands

### General
- `exo self version` — Print exo version
- `exo _ _` — Passthrough to exo CLI

## Usage Examples
- "Run exo"
- "Use exo to Run frontier AI locally."

## Installation

```bash
pip install exo
```

## Key Features
- Run frontier AI locally.
- CLI tool, headless and scriptable
