# term-progress Plugin
Simple progress bar for shell scripts in Go

## Commands
- `term-progress <resource> <action>` — Execute term-progress commands
- `term-progress _ _` — Passthrough to term-progress CLI

## Usage
- `term-progress _ _ <args>` — Run term-progress with any arguments
