# file2brl Plugin

CLI tool: file2brl.

## Commands
- `file2brl <resource> <action>` — Execute file2brl commands
- `file2brl self version` — Print file2brl version
- `file2brl _ _` — Passthrough to file2brl CLI

## Usage Examples
- "file2brl --help"
- "file2brl self version"

## Installation
```bash
apt-get install file2brl 2>/dev/null || which file2brl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
