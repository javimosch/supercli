# fullmoon-ios Plugin

chat with private and local large language models

## Commands

### General
- `fullmoon-ios self version` — Print fullmoon-ios version
- `fullmoon-ios _ _` — Passthrough to fullmoon-ios CLI

## Usage Examples
- "Run fullmoon-ios"
- "Use fullmoon-ios to chat with private and local large language models"

## Installation

```bash
pip install fullmoon-ios
```

## Key Features
- chat with private and local large language models
- CLI tool, headless and scriptable
