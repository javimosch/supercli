# cups.ippfind Plugin

CLI tool: cups.ippfind.

## Commands
- `cups.ippfind <resource> <action>` — Execute cups.ippfind commands
- `cups.ippfind self version` — Print cups.ippfind version
- `cups.ippfind _ _` — Passthrough to cups.ippfind CLI

## Usage Examples
- "cups.ippfind --help"
- "cups.ippfind self version"

## Installation
```bash
apt-get install cups.ippfind 2>/dev/null || which cups.ippfind
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
