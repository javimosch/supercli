# pivot_root Plugin

CLI tool: pivot_root.

## Commands
- `pivot_root <resource> <action>` — Execute pivot_root commands
- `pivot_root self version` — Print pivot_root version
- `pivot_root _ _` — Passthrough to pivot_root CLI

## Usage Examples
- "pivot_root --help"
- "pivot_root self version"

## Installation
```bash
apt-get install pivot_root 2>/dev/null || which pivot_root
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
