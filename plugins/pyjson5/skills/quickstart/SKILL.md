# pyjson5 Plugin

CLI tool: pyjson5.

## Commands
- `pyjson5 <resource> <action>` — Execute pyjson5 commands
- `pyjson5 self version` — Print pyjson5 version
- `pyjson5 _ _` — Passthrough to pyjson5 CLI

## Usage Examples
- "pyjson5 --help"
- "pyjson5 self version"

## Installation
```bash
apt-get install pyjson5 2>/dev/null || which pyjson5
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
