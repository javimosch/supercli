# ppmcie Plugin

CLI tool: ppmcie.

## Commands
- `ppmcie <resource> <action>` — Execute ppmcie commands
- `ppmcie self version` — Print ppmcie version
- `ppmcie _ _` — Passthrough to ppmcie CLI

## Usage Examples
- "ppmcie --help"
- "ppmcie self version"

## Installation
```bash
apt-get install ppmcie 2>/dev/null || which ppmcie
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
