# junie Plugin

CLI tool: junie.

## Commands
- `junie <resource> <action>` — Execute junie commands
- `junie self version` — Print junie version
- `junie _ _` — Passthrough to junie CLI

## Usage Examples
- "junie --help"
- "junie self version"

## Installation
```bash
apt-get install junie 2>/dev/null || which junie
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
