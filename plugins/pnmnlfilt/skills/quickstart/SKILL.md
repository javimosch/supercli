# pnmnlfilt Plugin

CLI tool: pnmnlfilt.

## Commands
- `pnmnlfilt <resource> <action>` — Execute pnmnlfilt commands
- `pnmnlfilt self version` — Print pnmnlfilt version
- `pnmnlfilt _ _` — Passthrough to pnmnlfilt CLI

## Usage Examples
- "pnmnlfilt --help"
- "pnmnlfilt self version"

## Installation
```bash
apt-get install pnmnlfilt 2>/dev/null || which pnmnlfilt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
