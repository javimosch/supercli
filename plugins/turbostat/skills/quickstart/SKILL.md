# turbostat Plugin

CLI tool: turbostat.

## Commands
- `turbostat <resource> <action>` — Execute turbostat commands
- `turbostat self version` — Print turbostat version
- `turbostat _ _` — Passthrough to turbostat CLI

## Usage Examples
- "turbostat --help"
- "turbostat self version"

## Installation
```bash
apt-get install turbostat 2>/dev/null || which turbostat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
