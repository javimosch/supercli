# niceload Plugin

CLI tool: niceload.

## Commands
- `niceload <resource> <action>` — Execute niceload commands
- `niceload self version` — Print niceload version
- `niceload _ _` — Passthrough to niceload CLI

## Usage Examples
- "niceload --help"
- "niceload self version"

## Installation
```bash
apt-get install niceload 2>/dev/null || which niceload
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
