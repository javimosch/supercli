# f2fs_io Plugin

CLI tool: f2fs_io.

## Commands
- `f2fs_io <resource> <action>` — Execute f2fs_io commands
- `f2fs_io self version` — Print f2fs_io version
- `f2fs_io _ _` — Passthrough to f2fs_io CLI

## Usage Examples
