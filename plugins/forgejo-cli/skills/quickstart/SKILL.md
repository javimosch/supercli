# forgejo-cli Plugin
Forgejo CLI for repository management

## Commands
- `forgejo-cli <resource> <action>` — Execute forgejo-cli commands
- `forgejo-cli _ _` — Passthrough to forgejo-cli CLI

## Usage
- `forgejo-cli _ _ <args>` — Run forgejo-cli with any arguments
