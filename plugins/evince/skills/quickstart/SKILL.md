# evince Plugin

CLI tool: evince.

## Commands
- `evince <resource> <action>` — Execute evince commands
- `evince self version` — Print evince version
- `evince _ _` — Passthrough to evince CLI

## Usage Examples
- "evince --help"
- "evince self version"

## Installation
```bash
apt-get install evince 2>/dev/null || which evince
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
