# gtf Plugin

CLI tool: gtf.

## Commands
- `gtf <resource> <action>` — Execute gtf commands
- `gtf self version` — Print gtf version
- `gtf _ _` — Passthrough to gtf CLI

## Usage Examples
- "gtf --help"
- "gtf self version"

## Installation
```bash
apt-get install gtf 2>/dev/null || which gtf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
