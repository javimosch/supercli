# bVisor Plugin

Embedded bash sandbox for agents, inspired by gVisor

## Commands

### General
- `bVisor self version` — Print bVisor version
- `bVisor _ _` — Passthrough to bvisor CLI

## Usage Examples
- "Run bVisor"
- "Use bvisor to Embedded bash sandbox for agents, inspired by gVisor"

## Installation

```bash
pip install bvisor
```

## Key Features
- Embedded bash sandbox for agents, inspired by gVisor
- CLI tool, headless and scriptable
