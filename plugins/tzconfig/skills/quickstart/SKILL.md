# tzconfig Plugin

CLI tool: tzconfig.

## Commands
- `tzconfig <resource> <action>` — Execute tzconfig commands
- `tzconfig self version` — Print tzconfig version
- `tzconfig _ _` — Passthrough to tzconfig CLI

## Usage Examples
- "tzconfig --help"
- "tzconfig self version"

## Installation
```bash
apt-get install tzconfig 2>/dev/null || which tzconfig
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
