# sbattach Plugin

CLI tool: sbattach.

## Commands
- `sbattach <resource> <action>` — Execute sbattach commands
- `sbattach self version` — Print sbattach version
- `sbattach _ _` — Passthrough to sbattach CLI

## Usage Examples
- "sbattach --help"
- "sbattach self version"

## Installation
```bash
apt-get install sbattach 2>/dev/null || which sbattach
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
