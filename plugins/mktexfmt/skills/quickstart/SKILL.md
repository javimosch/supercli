# mktexfmt Plugin

CLI tool: mktexfmt.

## Commands
- `mktexfmt <resource> <action>` — Execute mktexfmt commands
- `mktexfmt self version` — Print mktexfmt version
- `mktexfmt _ _` — Passthrough to mktexfmt CLI

## Usage Examples
- "mktexfmt --help"
- "mktexfmt self version"

## Installation
```bash
apt-get install mktexfmt 2>/dev/null || which mktexfmt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
