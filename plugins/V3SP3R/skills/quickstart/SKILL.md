# V3SP3R Plugin

AI Flipper control

## Commands

### General
- `V3SP3R self version` — Print V3SP3R version
- `V3SP3R _ _` — Passthrough to v3sp3r CLI

## Usage Examples
- "Run V3SP3R"

```bash
pip install v3sp3r
```

## Key Features
- AI Flipper control
- CLI tool, headless and scriptable
