# git-sweep Plugin
Clean up merged git branches from your local repo

## Commands
- `git-sweep <resource> <action>` — Execute git-sweep commands
- `git-sweep _ _` — Passthrough to git-sweep CLI

## Usage
- `git-sweep _ _ <args>` — Run git-sweep with any arguments
