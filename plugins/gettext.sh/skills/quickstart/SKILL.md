# gettext.sh Plugin

CLI tool: gettext.sh.

## Commands
- `gettext.sh <resource> <action>` — Execute gettext.sh commands
- `gettext.sh self version` — Print gettext.sh version
- `gettext.sh _ _` — Passthrough to gettext.sh CLI

## Usage Examples
- "gettext.sh --help"
- "gettext.sh self version"

## Installation
```bash
apt-get install gettext.sh 2>/dev/null || which gettext.sh
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
