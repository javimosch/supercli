# texluajit Plugin

CLI tool: texluajit.

## Commands
- `texluajit <resource> <action>` — Execute texluajit commands
- `texluajit self version` — Print texluajit version
- `texluajit _ _` — Passthrough to texluajit CLI

## Usage Examples
- "texluajit --help"
- "texluajit self version"

## Installation
```bash
apt-get install texluajit 2>/dev/null || which texluajit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
