# pyupgrade Plugin
Upgrade Python syntax to newer version equivalents

## Commands
- `pyupgrade <resource> <action>` — Execute pyupgrade commands
- `pyupgrade _ _` — Passthrough to pyupgrade CLI

## Usage
- `pyupgrade _ _ <args>` — Run pyupgrade with any arguments
