# gorilla-cli Plugin
LLM-powered CLI for generating commands

## Commands
- `gorilla-cli <resource> <action>` — Execute gorilla-cli commands
- `gorilla-cli _ _` — Passthrough to gorilla-cli CLI

## Usage
- `gorilla-cli _ _ <args>` — Run gorilla-cli with any arguments
