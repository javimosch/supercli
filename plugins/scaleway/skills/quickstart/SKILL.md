# scaleway

Scaleway CLI — command-line tool for Scaleway cloud

## Install

```bash
brew install scw
```

Verify installation:

```bash
which scw
```

## Commands

- `scaleway self version` — print scw version
- `scaleway cli run ...` — pass any arguments straight through to `scw`
