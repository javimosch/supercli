# rtmux Plugin

CLI tool: rtmux.

## Commands
- `rtmux <resource> <action>` — Execute rtmux commands
- `rtmux self version` — Print rtmux version
- `rtmux _ _` — Passthrough to rtmux CLI

## Usage Examples
- "rtmux --help"
- "rtmux self version"

## Installation
```bash
apt-get install rtmux 2>/dev/null || which rtmux
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
