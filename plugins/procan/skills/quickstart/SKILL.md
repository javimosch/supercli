# procan Plugin

CLI tool: procan.

## Commands
- `procan <resource> <action>` — Execute procan commands
- `procan self version` — Print procan version
- `procan _ _` — Passthrough to procan CLI

## Usage Examples
- "procan --help"
- "procan self version"

## Installation
```bash
apt-get install procan 2>/dev/null || which procan
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
