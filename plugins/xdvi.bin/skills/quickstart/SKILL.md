# xdvi.bin Plugin

CLI tool: xdvi.bin.

## Commands
- `xdvi.bin <resource> <action>` — Execute xdvi.bin commands
- `xdvi.bin self version` — Print xdvi.bin version
- `xdvi.bin _ _` — Passthrough to xdvi.bin CLI

## Usage Examples
- "xdvi.bin --help"
- "xdvi.bin self version"

## Installation
```bash
apt-get install xdvi.bin 2>/dev/null || which xdvi.bin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
