# git-trim Plugin
Automatically prune merged and stray git branches

## Commands
- `git-trim <resource> <action>` — Execute git-trim commands
- `git-trim _ _` — Passthrough to git-trim CLI

## Usage
- `git-trim _ _ <args>` — Run git-trim with any arguments
