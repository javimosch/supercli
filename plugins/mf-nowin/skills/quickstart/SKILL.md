# mf-nowin Plugin

CLI tool: mf-nowin.

## Commands
- `mf-nowin <resource> <action>` — Execute mf-nowin commands
- `mf-nowin self version` — Print mf-nowin version
- `mf-nowin _ _` — Passthrough to mf-nowin CLI

## Usage Examples
- "mf-nowin --help"
- "mf-nowin self version"

## Installation
```bash
apt-get install mf-nowin 2>/dev/null || which mf-nowin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
