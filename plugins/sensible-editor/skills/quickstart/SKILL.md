# sensible-editor Plugin

CLI tool: sensible-editor.

## Commands
- `sensible-editor <resource> <action>` — Execute sensible-editor commands
- `sensible-editor self version` — Print sensible-editor version
- `sensible-editor _ _` — Passthrough to sensible-editor CLI

## Usage Examples
- "sensible-editor --help"
- "sensible-editor self version"

## Installation
```bash
apt-get install sensible-editor 2>/dev/null || which sensible-editor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
