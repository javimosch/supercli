# crnch Plugin
Lightning-fast tool to compress PNGs JPGs and PDFs to exact target sizes

## Commands
- `crnch <resource> <action>` — Execute crnch commands
- `crnch _ _` — Passthrough to crnch CLI

## Usage
- `crnch _ _ <args>` — Run crnch with any arguments
