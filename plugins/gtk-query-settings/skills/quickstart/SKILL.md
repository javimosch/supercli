# gtk-query-settings Plugin

CLI tool: gtk-query-settings.

## Commands
- `gtk-query-settings <resource> <action>` — Execute gtk-query-settings commands
- `gtk-query-settings self version` — Print gtk-query-settings version
- `gtk-query-settings _ _` — Passthrough to gtk-query-settings CLI

## Usage Examples
- "gtk-query-settings --help"
- "gtk-query-settings self version"

## Installation
```bash
apt-get install gtk-query-settings 2>/dev/null || which gtk-query-settings
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
