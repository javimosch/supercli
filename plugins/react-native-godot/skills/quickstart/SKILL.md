# react-native-godot Plugin

React Native Godot - Embed Godot Engine in React Native apps

## Commands

### General
- `react-native-godot self version` — Print react-native-godot version
- `react-native-godot _ _` — Passthrough to react-native-godot CLI

## Usage Examples
- "Run react-native-godot"
- "Use react-native-godot to React Native Godot - Embed Godot Engine in React Native apps"

## Installation

```bash
pip install react-native-godot
```

## Key Features
- React Native Godot - Embed Godot Engine in React Native apps
- CLI tool, headless and scriptable
