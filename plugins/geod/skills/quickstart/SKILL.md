# geod Plugin

CLI tool: geod.

## Commands
- `geod <resource> <action>` — Execute geod commands
- `geod self version` — Print geod version
- `geod _ _` — Passthrough to geod CLI

## Usage Examples
- "geod --help"
- "geod self version"

## Installation
```bash
apt-get install geod 2>/dev/null || which geod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
