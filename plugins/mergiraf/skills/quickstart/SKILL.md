# mergiraf Plugin
Syntax-aware git merge conflict resolver.
## Commands
- `mergiraf self version` — Print version
- `mergiraf _ _` — Passthrough to mergiraf CLI
## Installation
```bash
cargo install mergiraf
```
## Key Features
- **Syntax-aware** — Understands code structure
- **Smart merging** — Better conflict resolution
- **Pipeline-ready** — Automation support
