# lspcmcia Plugin

CLI tool: lspcmcia.

## Commands
- `lspcmcia <resource> <action>` — Execute lspcmcia commands
- `lspcmcia self version` — Print lspcmcia version
- `lspcmcia _ _` — Passthrough to lspcmcia CLI

## Usage Examples
- "lspcmcia --help"
- "lspcmcia self version"

## Installation
```bash
apt-get install lspcmcia 2>/dev/null || which lspcmcia
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
