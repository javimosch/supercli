# cups.lpinfo Plugin

CLI tool: cups.lpinfo.

## Commands
- `cups.lpinfo <resource> <action>` — Execute cups.lpinfo commands
- `cups.lpinfo self version` — Print cups.lpinfo version
- `cups.lpinfo _ _` — Passthrough to cups.lpinfo CLI

## Usage Examples
- "cups.lpinfo --help"
- "cups.lpinfo self version"

## Installation
```bash
apt-get install cups.lpinfo 2>/dev/null || which cups.lpinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
