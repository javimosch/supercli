# tshark Plugin

## Commands
- `tshark <resource> <action>` — Execute tshark commands
- `tshark capture list-interfaces` — List available network interfaces for capture
- `tshark capture live` — Capture live packets (use timeout or count to limit)
- `tshark read file` — Read and analyze a packet capture file with JSON output
- `tshark _ _` — Passthrough to tshark CLI for any command
