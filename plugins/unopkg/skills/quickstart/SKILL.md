# unopkg Plugin

CLI tool: unopkg.

## Commands
- `unopkg <resource> <action>` — Execute unopkg commands
- `unopkg self version` — Print unopkg version
- `unopkg _ _` — Passthrough to unopkg CLI

## Usage Examples
- "unopkg --help"
- "unopkg self version"

## Installation
```bash
apt-get install unopkg 2>/dev/null || which unopkg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
