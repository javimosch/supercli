# tifftopnm Plugin

CLI tool: tifftopnm.

## Commands
- `tifftopnm <resource> <action>` — Execute tifftopnm commands
- `tifftopnm self version` — Print tifftopnm version
- `tifftopnm _ _` — Passthrough to tifftopnm CLI

## Usage Examples
- "tifftopnm --help"
- "tifftopnm self version"

```bash
apt-get install tifftopnm 2>/dev/null || which tifftopnm
```
