# GET Plugin

GET — simple and consistent interface to the world-wide web.

## Commands
- `GET <resource> <action>` — Execute GET commands
- `GET self version` — Print GET version
- `GET _ _` — Passthrough to GET CLI

## Usage Examples
- "GET --help"
- "GET self version"

## Installation
```bash
apt-get install libwww-perl 2>/dev/null || which GET
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
