# thunar-settings Plugin

CLI tool: thunar-settings.

## Commands
- `thunar-settings <resource> <action>` — Execute thunar-settings commands
- `thunar-settings self version` — Print thunar-settings version
- `thunar-settings _ _` — Passthrough to thunar-settings CLI

## Usage Examples
- "thunar-settings --help"
- "thunar-settings self version"

## Installation
```bash
apt-get install thunar-settings 2>/dev/null || which thunar-settings
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
