# pk12util Plugin

CLI tool: pk12util.

## Commands
- `pk12util <resource> <action>` — Execute pk12util commands
- `pk12util self version` — Print pk12util version
- `pk12util _ _` — Passthrough to pk12util CLI

## Usage Examples
- "pk12util --help"
- "pk12util self version"

## Installation
```bash
apt-get install pk12util 2>/dev/null || which pk12util
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
