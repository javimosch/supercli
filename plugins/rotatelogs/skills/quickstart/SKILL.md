# rotatelogs Plugin

CLI tool: rotatelogs.

## Commands
- `rotatelogs <resource> <action>` — Execute rotatelogs commands
- `rotatelogs self version` — Print rotatelogs version
- `rotatelogs _ _` — Passthrough to rotatelogs CLI

## Usage Examples
- "rotatelogs --help"
- "rotatelogs self version"

## Installation
```bash
apt-get install rotatelogs 2>/dev/null || which rotatelogs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
