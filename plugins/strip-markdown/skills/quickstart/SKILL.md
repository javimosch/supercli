# strip-markdown Plugin
Convert HTML/Markdown to plain text.
## Commands
- `strip-markdown _ _` — Passthrough to strip-markdown CLI
## Installation
```bash
pipx install strip-markdown
```
## Key Features
- **HTML to text** — Strip HTML tags
- **Markdown to text** — Remove formatting
- **LLM-ready** — Clean text for AI input
- **Pipeline-ready** — stdin/stdout support
