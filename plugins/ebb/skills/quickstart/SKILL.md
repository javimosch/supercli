# ebb Plugin

CLI tool: ebb.

## Commands
- `ebb <resource> <action>` — Execute ebb commands
- `ebb self version` — Print ebb version
- `ebb _ _` — Passthrough to ebb CLI

## Usage Examples
- "ebb --help"
- "ebb self version"

## Installation
```bash
apt-get install ebb 2>/dev/null || which ebb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
