# prime-rs Plugin
Find prime numbers up to a specified limit

## Commands
- `prime-rs <resource> <action>` — Execute prime-rs commands
- `prime-rs _ _` — Passthrough to prime-rs CLI

## Usage
- `prime-rs _ _ <args>` — Run prime-rs with any arguments
