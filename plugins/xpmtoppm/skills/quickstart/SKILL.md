# xpmtoppm Plugin

CLI tool: xpmtoppm.

## Commands
- `xpmtoppm <resource> <action>` — Execute xpmtoppm commands
- `xpmtoppm self version` — Print xpmtoppm version
- `xpmtoppm _ _` — Passthrough to xpmtoppm CLI

## Usage Examples
- "xpmtoppm --help"
- "xpmtoppm self version"

## Installation
```bash
apt-get install xpmtoppm 2>/dev/null || which xpmtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
