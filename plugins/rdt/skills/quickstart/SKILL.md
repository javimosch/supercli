# rdt Plugin

CLI tool: rdt.

## Commands
- `rdt <resource> <action>` — Execute rdt commands
- `rdt self version` — Print rdt version
- `rdt _ _` — Passthrough to rdt CLI

## Usage Examples
- "rdt --help"
- "rdt self version"

## Installation
```bash
apt-get install rdt 2>/dev/null || which rdt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
