# gdbus-codegen Plugin

CLI tool: gdbus-codegen.

## Commands
- `gdbus-codegen <resource> <action>` — Execute gdbus-codegen commands
- `gdbus-codegen self version` — Print gdbus-codegen version
- `gdbus-codegen _ _` — Passthrough to gdbus-codegen CLI

## Usage Examples
- "gdbus-codegen --help"
- "gdbus-codegen self version"

## Installation
```bash
apt-get install gdbus-codegen 2>/dev/null || which gdbus-codegen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
