# rctest Plugin

CLI tool: rctest.

## Commands
- `rctest <resource> <action>` — Execute rctest commands
- `rctest self version` — Print rctest version
- `rctest _ _` — Passthrough to rctest CLI

## Usage Examples
- "rctest --help"
- "rctest self version"

## Installation
```bash
apt-get install rctest 2>/dev/null || which rctest
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
