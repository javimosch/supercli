# javah Plugin

CLI tool: javah.

## Commands
- `javah <resource> <action>` — Execute javah commands
- `javah self version` — Print javah version
- `javah _ _` — Passthrough to javah CLI

## Usage Examples
- "javah --help"
- "javah self version"

## Installation
```bash
apt-get install javah 2>/dev/null || which javah
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
