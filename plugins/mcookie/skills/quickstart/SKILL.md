# mcookie Plugin

CLI tool: mcookie.

## Commands
- `mcookie <resource> <action>` — Execute mcookie commands
- `mcookie self version` — Print mcookie version
- `mcookie _ _` — Passthrough to mcookie CLI

## Usage Examples
- "mcookie --help"
- "mcookie self version"

## Installation
```bash
apt-get install mcookie 2>/dev/null || which mcookie
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
