# bookmarker Plugin
CLI bookmark management with tagging and search

## Commands
- `bookmarker <resource> <action>` — Execute bookmarker commands
- `bookmarker _ _` — Passthrough to bookmarker CLI

## Usage
- `bookmarker _ _ <args>` — Run bookmarker with any arguments
