# pnmdepth Plugin

CLI tool: pnmdepth.

## Commands
- `pnmdepth <resource> <action>` — Execute pnmdepth commands
- `pnmdepth self version` — Print pnmdepth version
- `pnmdepth _ _` — Passthrough to pnmdepth CLI

## Usage Examples
- "pnmdepth --help"
- "pnmdepth self version"

## Installation
```bash
apt-get install pnmdepth 2>/dev/null || which pnmdepth
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
