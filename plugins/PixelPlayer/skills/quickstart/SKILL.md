# PixelPlayer Plugin

privacy-first Android music player built with Material 3 Expressive. Play offline, sync lyrics, fine-tune with equalizer presets, and cast to your devices.

## Commands

### General
- `PixelPlayer self version` — Print PixelPlayer version
- `PixelPlayer _ _` — Passthrough to pixelplayer CLI

```bash
pip install pixelplayer
```
