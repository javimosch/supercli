# dua

dua (Disk Usage Analyzer) — a tool to conveniently learn about the usage of disk space of files.

## Commands
- `sc dua disk usage` — Show disk usage for a directory
- `sc dua self version` — Print version

## Installation
```
cargo install dua-cli
```
