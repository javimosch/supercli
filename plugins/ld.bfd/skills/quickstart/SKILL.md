# ld.bfd Plugin

CLI tool: ld.bfd.

## Commands
- `ld.bfd <resource> <action>` — Execute ld.bfd commands
- `ld.bfd self version` — Print ld.bfd version
- `ld.bfd _ _` — Passthrough to ld.bfd CLI

## Usage Examples
- "ld.bfd --help"
- "ld.bfd self version"

## Installation
```bash
apt-get install ld.bfd 2>/dev/null || which ld.bfd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
