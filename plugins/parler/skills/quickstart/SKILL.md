# parler Plugin

CLI tool: parler.

## Commands
- `parler <resource> <action>` — Execute parler commands
- `parler self version` — Print parler version
- `parler _ _` — Passthrough to parler CLI

## Usage Examples
- "parler --help"
- "parler self version"

## Installation
```bash
apt-get install parler 2>/dev/null || which parler
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
