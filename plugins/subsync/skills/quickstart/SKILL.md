# subsync Plugin
CLI tool to synchronize srt/ssa subtitles with audio

## Commands
- `subsync <resource> <action>` — Execute subsync commands
- `subsync _ _` — Passthrough to subsync CLI

## Usage
- `subsync _ _ <args>` — Run subsync with any arguments
