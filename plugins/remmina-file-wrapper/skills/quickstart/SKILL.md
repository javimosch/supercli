# remmina-file-wrapper Plugin

CLI tool: remmina-file-wrapper.

## Commands
- `remmina-file-wrapper <resource> <action>` — Execute remmina-file-wrapper commands
- `remmina-file-wrapper self version` — Print remmina-file-wrapper version
- `remmina-file-wrapper _ _` — Passthrough to remmina-file-wrapper CLI

## Usage Examples
- "remmina-file-wrapper --help"
- "remmina-file-wrapper self version"

## Installation
```bash
apt-get install remmina-file-wrapper 2>/dev/null || which remmina-file-wrapper
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
