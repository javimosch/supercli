# bentoml Plugin
CLI for packaging ML models for production deployment

## Commands
- `bentoml <resource> <action>` — Execute bentoml commands
- `bentoml _ _` — Passthrough to bentoml CLI

## Usage
- `bentoml _ _ <args>` — Run bentoml with any arguments
