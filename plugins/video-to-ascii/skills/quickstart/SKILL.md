# video-to-ascii Plugin
Play videos as ASCII art in the terminal

## Commands
- `video-to-ascii <resource> <action>` — Execute video-to-ascii commands
- `video-to-ascii _ _` — Passthrough to video-to-ascii CLI

## Usage
- `video-to-ascii _ _ <args>` — Run video-to-ascii with any arguments
