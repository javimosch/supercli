# m365_chili Plugin

CLI tool: m365_chili.

## Commands
- `m365_chili <resource> <action>` — Execute m365_chili commands
- `m365_chili self version` — Print m365_chili version
- `m365_chili _ _` — Passthrough to m365_chili CLI

## Usage Examples
- "m365_chili --help"
- "m365_chili self version"

## Installation
```bash
apt-get install m365_chili 2>/dev/null || which m365_chili
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
