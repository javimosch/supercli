# e2label Plugin

CLI tool: e2label.

## Commands
- `e2label <resource> <action>` — Execute e2label commands
- `e2label self version` — Print e2label version
- `e2label _ _` — Passthrough to e2label CLI

## Usage Examples
- "e2label --help"
- "e2label self version"

## Installation
```bash
apt-get install e2label 2>/dev/null || which e2label
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
