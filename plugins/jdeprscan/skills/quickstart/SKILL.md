# jdeprscan Plugin

CLI tool: jdeprscan.

## Commands
- `jdeprscan <resource> <action>` — Execute jdeprscan commands
- `jdeprscan self version` — Print jdeprscan version
- `jdeprscan _ _` — Passthrough to jdeprscan CLI

## Usage Examples
- "jdeprscan --help"
- "jdeprscan self version"

## Installation
```bash
apt-get install jdeprscan 2>/dev/null || which jdeprscan
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
