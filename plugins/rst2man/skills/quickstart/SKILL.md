# rst2man Plugin

CLI tool: rst2man.

## Commands
- `rst2man <resource> <action>` — Execute rst2man commands
- `rst2man self version` — Print rst2man version
- `rst2man _ _` — Passthrough to rst2man CLI

## Usage Examples
- "rst2man --help"
- "rst2man self version"

## Installation
```bash
apt-get install rst2man 2>/dev/null || which rst2man
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
