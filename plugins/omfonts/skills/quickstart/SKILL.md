# omfonts Plugin

CLI tool: omfonts.

## Commands
- `omfonts <resource> <action>` — Execute omfonts commands
- `omfonts self version` — Print omfonts version
- `omfonts _ _` — Passthrough to omfonts CLI

## Usage Examples
- "omfonts --help"
- "omfonts self version"

## Installation
```bash
apt-get install omfonts 2>/dev/null || which omfonts
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
