# qtdiag Plugin

CLI tool: qtdiag.

## Commands
- `qtdiag <resource> <action>` — Execute qtdiag commands
- `qtdiag self version` — Print qtdiag version
- `qtdiag _ _` — Passthrough to qtdiag CLI

## Usage Examples
- "qtdiag --help"
- "qtdiag self version"

## Installation
```bash
apt-get install qtdiag 2>/dev/null || which qtdiag
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
