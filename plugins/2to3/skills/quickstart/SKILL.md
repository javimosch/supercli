# 2to3 Plugin

CLI tool: 2to3.

## Commands
- `2to3 <resource> <action>` — Execute 2to3 commands
- `2to3 self version` — Print 2to3 version
- `2to3 _ _` — Passthrough to 2to3 CLI

## Usage Examples
- "2to3 --help"
- "2to3 self version"

## Installation
```bash
apt-get install 2to3 2>/dev/null || which 2to3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
