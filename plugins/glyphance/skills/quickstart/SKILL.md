# glyphance Plugin
Generate font subsets based on specific Unicode ranges

## Commands
- `glyphance <resource> <action>` — Execute glyphance commands
- `glyphance _ _` — Passthrough to glyphance CLI

## Usage
- `glyphance _ _ <args>` — Run glyphance with any arguments
