# gnome-system-monitor Plugin

CLI tool: gnome-system-monitor.

## Commands
- `gnome-system-monitor <resource> <action>` — Execute gnome-system-monitor commands
- `gnome-system-monitor self version` — Print gnome-system-monitor version
- `gnome-system-monitor _ _` — Passthrough to gnome-system-monitor CLI

## Usage Examples
- "gnome-system-monitor --help"
- "gnome-system-monitor self version"

## Installation
```bash
apt-get install gnome-system-monitor 2>/dev/null || which gnome-system-monitor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
