# zless Plugin

CLI tool: zless.

## Commands
- `zless <resource> <action>` — Execute zless commands
- `zless self version` — Print zless version
- `zless _ _` — Passthrough to zless CLI

## Usage Examples
- "zless --help"
- "zless self version"

## Installation
```bash
apt-get install zless 2>/dev/null || which zless
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
