# uuid-cli Plugin
Generate one or more UUID v4 identifiers.

## Commands
- `uuid-cli <resource> <action>` — Execute uuid-cli commands
- `uuid self generate` — Generate one or more UUID v4 identifiers

## Usage
- `uuid self generate` — Generate one UUID
- `uuid self generate 5` — Generate 5 UUIDs
