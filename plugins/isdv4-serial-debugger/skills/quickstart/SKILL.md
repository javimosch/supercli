# isdv4-serial-debugger Plugin

CLI tool: isdv4-serial-debugger.

## Commands
- `isdv4-serial-debugger <resource> <action>` — Execute isdv4-serial-debugger commands
- `isdv4-serial-debugger self version` — Print isdv4-serial-debugger version
- `isdv4-serial-debugger _ _` — Passthrough to isdv4-serial-debugger CLI

## Usage Examples
- "isdv4-serial-debugger --help"
- "isdv4-serial-debugger self version"

## Installation
```bash
apt-get install isdv4-serial-debugger 2>/dev/null || which isdv4-serial-debugger
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
