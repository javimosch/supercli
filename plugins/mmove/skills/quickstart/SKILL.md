# mmove Plugin

CLI tool: mmove.

## Commands
- `mmove <resource> <action>` — Execute mmove commands
- `mmove self version` — Print mmove version
- `mmove _ _` — Passthrough to mmove CLI

## Usage Examples
- "mmove --help"
- "mmove self version"

## Installation
```bash
apt-get install mmove 2>/dev/null || which mmove
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
