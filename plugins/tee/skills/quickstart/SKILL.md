# tee Plugin
Read from stdin and write to stdout/files

## Commands
- `tee <resource> <action>` — Execute tee commands
- `tee self version` — Print tee version
- `tee _ _` — Passthrough to tee CLI

## Usage
- `tee _ _ <args>` — Run tee with any arguments
