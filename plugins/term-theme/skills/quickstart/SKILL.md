# term-theme Plugin
Sync terminal color schemes with your system theme

## Commands
- `term-theme <resource> <action>` — Execute term-theme commands
- `term-theme _ _` — Passthrough to term-theme CLI

## Usage
- `term-theme _ _ <args>` — Run term-theme with any arguments
