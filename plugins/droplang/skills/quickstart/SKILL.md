# droplang Plugin

CLI tool: droplang.

## Commands
- `droplang <resource> <action>` — Execute droplang commands
- `droplang self version` — Print droplang version
- `droplang _ _` — Passthrough to droplang CLI

## Usage Examples
- "droplang --help"
- "droplang self version"

## Installation
```bash
apt-get install droplang 2>/dev/null || which droplang
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
