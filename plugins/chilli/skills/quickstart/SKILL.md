# chilli Plugin
Minimal Zig CLI framework.
## Commands
- `chilli _ _` — Passthrough
## Installation
```bash
git clone https://github.com/CogitatorTech/chilli && cd chilli && zig build
```
## Key Features
- **Minimal** — Simple API
- **Fast** — Zig-powered
- **CLI building** — Framework for Zig tools
