# mpicxx.openmpi Plugin

CLI tool: mpicxx.openmpi.

## Commands
- `mpicxx.openmpi <resource> <action>` — Execute mpicxx.openmpi commands
- `mpicxx.openmpi self version` — Print mpicxx.openmpi version
- `mpicxx.openmpi _ _` — Passthrough to mpicxx.openmpi CLI

## Usage Examples
- "mpicxx.openmpi --help"
- "mpicxx.openmpi self version"

## Installation
```bash
apt-get install mpicxx.openmpi 2>/dev/null || which mpicxx.openmpi
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
