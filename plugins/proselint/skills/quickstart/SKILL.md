# proselint
proselint — linter for English prose. Checks for jargon, redundancy, weasel words, and stylistic issues in text.

## Commands
- `proselint <resource> <action>` — Execute proselint commands
- `proselint self version` — Print proselint version
- `proselint _ _` — Passthrough to proselint CLI
