# packrinth Plugin
Create and manage Minecraft modpacks using Modrinth

## Commands
- `packrinth <resource> <action>` — Execute packrinth commands
- `packrinth _ _` — Passthrough to packrinth CLI

## Usage
- `packrinth _ _ <args>` — Run packrinth with any arguments
