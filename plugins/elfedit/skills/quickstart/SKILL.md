# elfedit Plugin

CLI tool: elfedit.

## Commands
- `elfedit <resource> <action>` — Execute elfedit commands
- `elfedit self version` — Print elfedit version
- `elfedit _ _` — Passthrough to elfedit CLI

## Usage Examples
- "elfedit --help"
- "elfedit self version"

## Installation
```bash
apt-get install elfedit 2>/dev/null || which elfedit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
