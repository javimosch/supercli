# jsa-ast Plugin

CLI tool: jsa-ast.

## Commands
- `jsa-ast <resource> <action>` — Execute jsa-ast commands
- `jsa-ast self version` — Print jsa-ast version
- `jsa-ast _ _` — Passthrough to jsa-ast CLI

## Usage Examples
- "jsa-ast --help"
- "jsa-ast self version"

## Installation
```bash
apt-get install jsa-ast 2>/dev/null || which jsa-ast
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
