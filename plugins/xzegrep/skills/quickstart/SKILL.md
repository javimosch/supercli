# xzegrep Plugin

CLI tool: xzegrep.

## Commands
- `xzegrep <resource> <action>` — Execute xzegrep commands
- `xzegrep self version` — Print xzegrep version
- `xzegrep _ _` — Passthrough to xzegrep CLI

## Usage Examples
- "xzegrep --help"
- "xzegrep self version"

## Installation
```bash
apt-get install xzegrep 2>/dev/null || which xzegrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
