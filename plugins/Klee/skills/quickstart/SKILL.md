# Klee Plugin

A native macOS AI chat app powered by MLX. 100% local inference on Apple Silicon, no cloud required. Built with ShipSwift.

## Commands

### General
- `Klee self version` — Print Klee version
- `Klee _ _` — Passthrough to klee CLI
