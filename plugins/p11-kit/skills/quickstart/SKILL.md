# p11-kit Plugin

CLI tool: p11-kit.

## Commands
- `p11-kit <resource> <action>` — Execute p11-kit commands
- `p11-kit self version` — Print p11-kit version
- `p11-kit _ _` — Passthrough to p11-kit CLI

## Usage Examples
- "p11-kit --help"
- "p11-kit self version"

## Installation
```bash
apt-get install p11-kit 2>/dev/null || which p11-kit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
