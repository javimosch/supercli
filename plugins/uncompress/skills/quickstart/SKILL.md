# uncompress Plugin

CLI tool: uncompress.

## Commands
- `uncompress <resource> <action>` — Execute uncompress commands
- `uncompress self version` — Print uncompress version
- `uncompress _ _` — Passthrough to uncompress CLI

## Usage Examples
- "uncompress --help"
- "uncompress self version"

## Installation
```bash
apt-get install uncompress 2>/dev/null || which uncompress
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
