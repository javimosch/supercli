# CCTV_Viewer Plugin

电视浏览器，一款简易电视视频收看软件，用于方便的在机顶盒上收看网页视频

## Commands

### General
- `CCTV_Viewer self version` — Print CCTV_Viewer version
- `CCTV_Viewer _ _` — Passthrough to cctv-viewer CLI

## Usage Examples
- "Run CCTV_Viewer"
- "Use cctv-viewer to 电视浏览器，一款简易电视视频收看软件，用于方便的在机顶盒上收看网页视频"

## Installation

```bash
pip install cctv-viewer
```
