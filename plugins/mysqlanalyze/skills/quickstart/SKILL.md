# mysqlanalyze Plugin

CLI tool: mysqlanalyze.

## Commands
- `mysqlanalyze <resource> <action>` — Execute mysqlanalyze commands
- `mysqlanalyze self version` — Print mysqlanalyze version
- `mysqlanalyze _ _` — Passthrough to mysqlanalyze CLI

## Usage Examples
- "mysqlanalyze --help"
- "mysqlanalyze self version"

## Installation
```bash
apt-get install mysqlanalyze 2>/dev/null || which mysqlanalyze
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
