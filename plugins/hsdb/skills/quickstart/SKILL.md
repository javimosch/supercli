# hsdb Plugin

CLI tool: hsdb.

## Commands
- `hsdb <resource> <action>` — Execute hsdb commands
- `hsdb self version` — Print hsdb version
- `hsdb _ _` — Passthrough to hsdb CLI

## Usage Examples
- "hsdb --help"
- "hsdb self version"

## Installation
```bash
apt-get install hsdb 2>/dev/null || which hsdb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
