# LlamaBarn Plugin

A cosy home for your LLMs.

## Commands

### General
- `LlamaBarn self version` — Print LlamaBarn version
- `LlamaBarn _ _` — Passthrough to llamabarn CLI

## Usage Examples
- "Run LlamaBarn"
- "Use llamabarn to A cosy home for your LLMs."

## Installation

```bash
pip install llamabarn
```

## Key Features
- A cosy home for your LLMs.
- CLI tool, headless and scriptable
