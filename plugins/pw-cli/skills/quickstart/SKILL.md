# pw-cli Plugin

CLI tool: pw-cli.

## Commands
- `pw-cli <resource> <action>` — Execute pw-cli commands
- `pw-cli self version` — Print pw-cli version
- `pw-cli _ _` — Passthrough to pw-cli CLI

## Usage Examples
- "pw-cli --help"
- "pw-cli self version"

## Installation
```bash
apt-get install pw-cli 2>/dev/null || which pw-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
