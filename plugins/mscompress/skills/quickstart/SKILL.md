# mscompress Plugin

CLI tool: mscompress.

## Commands
- `mscompress <resource> <action>` — Execute mscompress commands
- `mscompress self version` — Print mscompress version
- `mscompress _ _` — Passthrough to mscompress CLI

## Usage Examples
- "mscompress --help"
- "mscompress self version"

## Installation
```bash
apt-get install mscompress 2>/dev/null || which mscompress
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
