# psresize Plugin

CLI tool: psresize.

## Commands
- `psresize <resource> <action>` — Execute psresize commands
- `psresize self version` — Print psresize version
- `psresize _ _` — Passthrough to psresize CLI

## Usage Examples
- "psresize --help"
- "psresize self version"

## Installation
```bash
apt-get install psresize 2>/dev/null || which psresize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
