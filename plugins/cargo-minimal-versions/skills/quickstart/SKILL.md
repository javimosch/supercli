# cargo-minimal-versions Plugin
Test Rust crates with minimum dependency versions

## Commands
- `cargo-minimal-versions <resource> <action>` — Execute cargo-minimal-versions commands
- `cargo-minimal-versions _ _` — Passthrough to cargo-minimal-versions CLI

## Usage
- `cargo-minimal-versions _ _ <args>` — Run cargo-minimal-versions with any arguments
