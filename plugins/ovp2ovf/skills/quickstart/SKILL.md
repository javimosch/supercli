# ovp2ovf Plugin

CLI tool: ovp2ovf.

## Commands
- `ovp2ovf <resource> <action>` — Execute ovp2ovf commands
- `ovp2ovf self version` — Print ovp2ovf version
- `ovp2ovf _ _` — Passthrough to ovp2ovf CLI

## Usage Examples
- "ovp2ovf --help"
- "ovp2ovf self version"

## Installation
```bash
apt-get install ovp2ovf 2>/dev/null || which ovp2ovf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
