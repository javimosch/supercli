# cups.lpc Plugin

CLI tool: cups.lpc.

## Commands
- `cups.lpc <resource> <action>` — Execute cups.lpc commands
- `cups.lpc self version` — Print cups.lpc version
- `cups.lpc _ _` — Passthrough to cups.lpc CLI

## Usage Examples
- "cups.lpc --help"
- "cups.lpc self version"

## Installation
```bash
apt-get install cups.lpc 2>/dev/null || which cups.lpc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
