# reorder-python-imports Plugin
Reformat and reorder Python imports

## Commands
- `reorder-python-imports <resource> <action>` — Execute reorder-python-imports commands
- `reorder-python-imports _ _` — Passthrough to reorder-python-imports CLI

## Usage
- `reorder-python-imports _ _ <args>` — Run reorder-python-imports with any arguments
