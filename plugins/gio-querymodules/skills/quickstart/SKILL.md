# gio-querymodules Plugin

CLI tool: gio-querymodules.

## Commands
- `gio-querymodules <resource> <action>` — Execute gio-querymodules commands
- `gio-querymodules self version` — Print gio-querymodules version
- `gio-querymodules _ _` — Passthrough to gio-querymodules CLI

## Usage Examples
- "gio-querymodules --help"
- "gio-querymodules self version"

## Installation
```bash
apt-get install gio-querymodules 2>/dev/null || which gio-querymodules
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
