# pnmtosgi Plugin

CLI tool: pnmtosgi.

## Commands
- `pnmtosgi <resource> <action>` — Execute pnmtosgi commands
- `pnmtosgi self version` — Print pnmtosgi version
- `pnmtosgi _ _` — Passthrough to pnmtosgi CLI

## Usage Examples
- "pnmtosgi --help"
- "pnmtosgi self version"

## Installation
```bash
apt-get install pnmtosgi 2>/dev/null || which pnmtosgi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
