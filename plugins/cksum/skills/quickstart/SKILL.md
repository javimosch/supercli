# cksum Plugin
CRC checksum computation

## Commands
- `cksum <resource> <action>` — Execute cksum commands
- `cksum self version` — Print cksum version
- `cksum _ _` — Passthrough to cksum CLI

## Usage
- `cksum _ _ <args>` — Run cksum with any arguments
