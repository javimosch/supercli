# ucs2any Plugin

CLI tool: ucs2any.

## Commands
- `ucs2any <resource> <action>` — Execute ucs2any commands
- `ucs2any self version` — Print ucs2any version
- `ucs2any _ _` — Passthrough to ucs2any CLI

## Usage Examples
- "ucs2any --help"
- "ucs2any self version"

## Installation
```bash
apt-get install ucs2any 2>/dev/null || which ucs2any
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
