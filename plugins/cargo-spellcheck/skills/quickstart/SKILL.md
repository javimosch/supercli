# cargo-spellcheck Plugin
Spellcheck Rust documentation and comments

## Commands
- `cargo-spellcheck <resource> <action>` — Execute cargo-spellcheck commands
- `cargo-spellcheck _ _` — Passthrough to cargo-spellcheck CLI

## Usage
- `cargo-spellcheck _ _ <args>` — Run cargo-spellcheck with any arguments
