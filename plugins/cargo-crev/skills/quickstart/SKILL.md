# cargo-crev Plugin
Distributed code review system for Rust crates

## Commands
- `cargo-crev <resource> <action>` — Execute cargo-crev commands
- `cargo-crev _ _` — Passthrough to cargo-crev CLI

## Usage
- `cargo-crev _ _ <args>` — Run cargo-crev with any arguments
