# yaml-front-matter Plugin
Parse YAML front matter from any text file

## Commands
- `yaml-front-matter <resource> <action>` — Execute yaml-front-matter commands
- `yaml-front-matter _ _` — Passthrough to yaml-front-matter CLI

## Usage
- `yaml-front-matter _ _ <args>` — Run yaml-front-matter with any arguments
