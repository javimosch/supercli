# xfce4-settings-manager Plugin

CLI tool: xfce4-settings-manager.

## Commands
- `xfce4-settings-manager <resource> <action>` — Execute xfce4-settings-manager commands
- `xfce4-settings-manager self version` — Print xfce4-settings-manager version
- `xfce4-settings-manager _ _` — Passthrough to xfce4-settings-manager CLI

## Usage Examples
- "xfce4-settings-manager --help"
- "xfce4-settings-manager self version"

## Installation
```bash
apt-get install xfce4-settings-manager 2>/dev/null || which xfce4-settings-manager
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
