# MasterPassword Plugin

Stateless password management

## Commands

### Version
`MasterPassword self version` — Print MasterPassword version

### Passthrough
`MasterPassword _ _` — Passthrough to mpw CLI with all arguments forwarded.

## Usage Examples

```bash
mpw --version
mpw --help
```

## Installation

```bash
brew install masterpassword
```

## Key Features
- Stateless password management
