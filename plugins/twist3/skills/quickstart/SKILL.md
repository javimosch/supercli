# twist3 Plugin

CLI tool: twist3.

## Commands
- `twist3 <resource> <action>` — Execute twist3 commands
- `twist3 self version` — Print twist3 version
- `twist3 _ _` — Passthrough to twist3 CLI

## Usage Examples
- "twist3 --help"
- "twist3 self version"

## Installation
```bash
apt-get install twist3 2>/dev/null || which twist3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
