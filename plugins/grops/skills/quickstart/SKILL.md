# grops Plugin

CLI tool: grops.

## Commands
- `grops <resource> <action>` — Execute grops commands
- `grops self version` — Print grops version
- `grops _ _` — Passthrough to grops CLI

## Usage Examples
- "grops --help"
- "grops self version"

## Installation
```bash
apt-get install grops 2>/dev/null || which grops
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
