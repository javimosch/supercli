# lpmove Plugin

CLI tool: lpmove.

## Commands
- `lpmove <resource> <action>` — Execute lpmove commands
- `lpmove self version` — Print lpmove version
- `lpmove _ _` — Passthrough to lpmove CLI

## Usage Examples
- "lpmove --help"
- "lpmove self version"

## Installation
```bash
apt-get install lpmove 2>/dev/null || which lpmove
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
