# py2rs Plugin
Convert Python code to Rust with type inference

## Commands
- `py2rs <resource> <action>` — Execute py2rs commands
- `py2rs _ _` — Passthrough to py2rs CLI

## Usage
- `py2rs _ _ <args>` — Run py2rs with any arguments
