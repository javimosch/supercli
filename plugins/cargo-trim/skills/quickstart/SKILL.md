# cargo-trim Plugin
CLI tool for cargo-trim.

## Commands
- `cargo-trim <resource> <action>` — Execute cargo-trim commands
- `cargo-trim _ _` — Passthrough to cargo-trim CLI

## Installation
```bash
cargo install cargo-trim
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
