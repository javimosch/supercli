# realpath Plugin
Resolve absolute path for file or symlink

## Commands
- `realpath <resource> <action>` — Execute realpath commands
- `realpath self version` — Print realpath version
- `realpath _ _` — Passthrough to realpath CLI

## Usage
- `realpath _ _ <args>` — Run realpath with any arguments
