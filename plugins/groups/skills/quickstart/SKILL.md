# groups Plugin

CLI tool: groups.

## Commands
- `groups <resource> <action>` — Execute groups commands
- `groups self version` — Print groups version
- `groups _ _` — Passthrough to groups CLI

## Usage Examples
- "groups --help"
- "groups self version"

## Installation
```bash
apt-get install groups 2>/dev/null || which groups
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
