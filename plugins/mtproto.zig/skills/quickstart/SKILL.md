# mtproto.zig Plugin

High-performance Telegram proxy

## Commands

### Version
`mtproto.zig self version` — Print mtproto.zig version

### Passthrough
`mtproto.zig _ _` — Passthrough to mtproto CLI with all arguments forwarded.

## Usage Examples

```bash
mtproto --version
mtproto --help
```

## Installation

```bash
cargo install mtproto-zig
```

## Key Features
- High-performance Telegram proxy
