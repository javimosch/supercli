# kwm Plugin

A window manager based on River Wayland compositor

## Commands

### General
- `kwm self version` — Print kwm version
- `kwm _ _` — Passthrough to kwm CLI

## Usage Examples
- "Run kwm"
- "Use kwm to A window manager based on River Wayland compositor"

## Installation

```bash
pip install kwm
```

## Key Features
- A window manager based on River Wayland compositor
- CLI tool, headless and scriptable
