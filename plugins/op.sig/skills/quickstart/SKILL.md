# op.sig Plugin

CLI tool: op.sig.

## Commands
- `op.sig <resource> <action>` — Execute op.sig commands
- `op.sig self version` — Print op.sig version
- `op.sig _ _` — Passthrough to op.sig CLI

## Usage Examples
- "op.sig --help"
- "op.sig self version"

## Installation
```bash
apt-get install op.sig 2>/dev/null || which op.sig
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
