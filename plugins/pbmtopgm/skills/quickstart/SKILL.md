# pbmtopgm Plugin

CLI tool: pbmtopgm.

## Commands
- `pbmtopgm <resource> <action>` — Execute pbmtopgm commands
- `pbmtopgm self version` — Print pbmtopgm version
- `pbmtopgm _ _` — Passthrough to pbmtopgm CLI

## Usage Examples
- "pbmtopgm --help"
- "pbmtopgm self version"

## Installation
```bash
apt-get install pbmtopgm 2>/dev/null || which pbmtopgm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
