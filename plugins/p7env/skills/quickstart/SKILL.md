# p7env Plugin

CLI tool: p7env.

## Commands
- `p7env <resource> <action>` — Execute p7env commands
- `p7env self version` — Print p7env version
- `p7env _ _` — Passthrough to p7env CLI

## Usage Examples
- "p7env --help"
- "p7env self version"

## Installation
```bash
apt-get install p7env 2>/dev/null || which p7env
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
