# xf Plugin
Ultra-fast local X/Twitter archive search.
## Commands
- `xf self version` — Print version
- `xf _ _` — Passthrough to xf CLI
## Installation
```bash
cargo install xf
```
## Key Features
- **Local-first** — All data on disk
- **Vector search** — Semantic search
- **JSON output** — Pipeline-ready
- **Sub-millisecond** — Ultra-fast
