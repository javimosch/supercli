# rst-buildhtml Plugin

CLI tool: rst-buildhtml.

## Commands
- `rst-buildhtml <resource> <action>` — Execute rst-buildhtml commands
- `rst-buildhtml self version` — Print rst-buildhtml version
- `rst-buildhtml _ _` — Passthrough to rst-buildhtml CLI

## Usage Examples
- "rst-buildhtml --help"
- "rst-buildhtml self version"

## Installation
```bash
apt-get install rst-buildhtml 2>/dev/null || which rst-buildhtml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
