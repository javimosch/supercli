# pyrite64 Plugin

N64 Game-Engine and Editor using libdragon & tiny3d

## Commands

### General
- `pyrite64 self version` — Print pyrite64 version
- `pyrite64 _ _` — Passthrough to pyrite64 CLI

## Usage Examples
- "Run pyrite64"
- "Use pyrite64 to N64 Game-Engine and Editor using libdragon & tiny3d"

## Installation

```bash
pip install pyrite64
```

## Key Features
- N64 Game-Engine and Editor using libdragon & tiny3d
- CLI tool, headless and scriptable
