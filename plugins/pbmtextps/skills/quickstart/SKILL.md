# pbmtextps Plugin

CLI tool: pbmtextps.

## Commands
- `pbmtextps <resource> <action>` — Execute pbmtextps commands
- `pbmtextps self version` — Print pbmtextps version
- `pbmtextps _ _` — Passthrough to pbmtextps CLI

## Usage Examples
- "pbmtextps --help"
- "pbmtextps self version"

## Installation
```bash
apt-get install pbmtextps 2>/dev/null || which pbmtextps
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
