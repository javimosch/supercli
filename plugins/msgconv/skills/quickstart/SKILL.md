# msgconv Plugin

CLI tool: msgconv.

## Commands
- `msgconv <resource> <action>` — Execute msgconv commands
- `msgconv self version` — Print msgconv version
- `msgconv _ _` — Passthrough to msgconv CLI

## Usage Examples
- "msgconv --help"
- "msgconv self version"

## Installation
```bash
apt-get install msgconv 2>/dev/null || which msgconv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
