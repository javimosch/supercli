# devmoji Plugin

Emojify conventional commits in TypeScript

## Commands

### Operations
- `devmoji self version` — Print devmoji version
- `devmoji _ _` — Passthrough to devmoji CLI

## Usage Examples
- `devmoji --help`
- `devmoji <args>`

## Installation

```bash
npm install -g devmoji
```

## Examples

```bash
devmoji --version
devmoji --help
```
