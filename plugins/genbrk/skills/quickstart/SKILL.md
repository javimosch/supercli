# genbrk Plugin

CLI tool: genbrk.

## Commands
- `genbrk <resource> <action>` — Execute genbrk commands
- `genbrk self version` — Print genbrk version
- `genbrk _ _` — Passthrough to genbrk CLI

## Usage Examples
- "genbrk --help"
- "genbrk self version"

## Installation
```bash
apt-get install genbrk 2>/dev/null || which genbrk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
