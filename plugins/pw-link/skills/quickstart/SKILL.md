# pw-link Plugin

CLI tool: pw-link.

## Commands
- `pw-link <resource> <action>` — Execute pw-link commands
- `pw-link self version` — Print pw-link version
- `pw-link _ _` — Passthrough to pw-link CLI

## Usage Examples
- "pw-link --help"
- "pw-link self version"

## Installation
```bash
apt-get install pw-link 2>/dev/null || which pw-link
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
