# mkinitramfs Plugin

CLI tool: mkinitramfs.

## Commands
- `mkinitramfs <resource> <action>` — Execute mkinitramfs commands
- `mkinitramfs self version` — Print mkinitramfs version
- `mkinitramfs _ _` — Passthrough to mkinitramfs CLI

## Usage Examples
- "mkinitramfs --help"
- "mkinitramfs self version"

## Installation
```bash
apt-get install mkinitramfs 2>/dev/null || which mkinitramfs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
