# microsoft-edge Plugin

CLI tool: microsoft-edge.

## Commands
- `microsoft-edge <resource> <action>` — Execute microsoft-edge commands
- `microsoft-edge self version` — Print microsoft-edge version
- `microsoft-edge _ _` — Passthrough to microsoft-edge CLI

## Usage Examples
- "microsoft-edge --help"
- "microsoft-edge self version"

## Installation
```bash
apt-get install microsoft-edge 2>/dev/null || which microsoft-edge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
