# img2ansi Plugin
High-performance image to ANSI terminal art converter

## Commands
- `img2ansi <resource> <action>` — Execute img2ansi commands
- `img2ansi _ _` — Passthrough to img2ansi CLI

## Usage
- `img2ansi _ _ <args>` — Run img2ansi with any arguments
