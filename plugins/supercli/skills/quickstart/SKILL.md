# supercli Plugin

CLI tool: supercli.

## Commands
- `supercli <resource> <action>` — Execute supercli commands
- `supercli self version` — Print supercli version
- `supercli _ _` — Passthrough to supercli CLI

## Usage Examples
- "supercli --help"
- "supercli self version"

## Installation
```bash
apt-get install supercli 2>/dev/null || which supercli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
