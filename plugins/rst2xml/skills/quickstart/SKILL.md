# rst2xml Plugin

CLI tool: rst2xml.

## Commands
- `rst2xml <resource> <action>` — Execute rst2xml commands
- `rst2xml self version` — Print rst2xml version
- `rst2xml _ _` — Passthrough to rst2xml CLI

## Usage Examples
- "rst2xml --help"
- "rst2xml self version"

## Installation
```bash
apt-get install rst2xml 2>/dev/null || which rst2xml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
