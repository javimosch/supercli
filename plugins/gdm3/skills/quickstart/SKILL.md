# gdm3 Plugin

CLI tool: gdm3.

## Commands
- `gdm3 <resource> <action>` — Execute gdm3 commands
- `gdm3 self version` — Print gdm3 version
- `gdm3 _ _` — Passthrough to gdm3 CLI

## Usage Examples
- "gdm3 --help"
- "gdm3 self version"

## Installation
```bash
apt-get install gdm3 2>/dev/null || which gdm3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
