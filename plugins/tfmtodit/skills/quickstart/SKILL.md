# tfmtodit Plugin

CLI tool: tfmtodit.

## Commands
- `tfmtodit <resource> <action>` — Execute tfmtodit commands
- `tfmtodit self version` — Print tfmtodit version
- `tfmtodit _ _` — Passthrough to tfmtodit CLI

## Usage Examples
- "tfmtodit --help"
- "tfmtodit self version"

## Installation
```bash
apt-get install tfmtodit 2>/dev/null || which tfmtodit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
