# gvfs-tree Plugin

CLI tool: gvfs-tree.

## Commands
- `gvfs-tree <resource> <action>` — Execute gvfs-tree commands
- `gvfs-tree self version` — Print gvfs-tree version
- `gvfs-tree _ _` — Passthrough to gvfs-tree CLI

## Usage Examples
- "gvfs-tree --help"
- "gvfs-tree self version"

## Installation
```bash
apt-get install gvfs-tree 2>/dev/null || which gvfs-tree
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
