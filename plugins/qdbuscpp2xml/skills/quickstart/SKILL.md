# qdbuscpp2xml Plugin

CLI tool: qdbuscpp2xml.

## Commands
- `qdbuscpp2xml <resource> <action>` — Execute qdbuscpp2xml commands
- `qdbuscpp2xml self version` — Print qdbuscpp2xml version
- `qdbuscpp2xml _ _` — Passthrough to qdbuscpp2xml CLI

## Usage Examples
- "qdbuscpp2xml --help"
- "qdbuscpp2xml self version"

## Installation
```bash
apt-get install qdbuscpp2xml 2>/dev/null || which qdbuscpp2xml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
