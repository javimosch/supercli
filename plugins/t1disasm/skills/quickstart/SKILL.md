# t1disasm Plugin

CLI tool: t1disasm.

## Commands
- `t1disasm <resource> <action>` — Execute t1disasm commands
- `t1disasm self version` — Print t1disasm version
- `t1disasm _ _` — Passthrough to t1disasm CLI

## Usage Examples
- "t1disasm --help"
- "t1disasm self version"

## Installation
```bash
apt-get install t1disasm 2>/dev/null || which t1disasm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
