# androidify Plugin

Sample app for Androidify

## Commands

### General
- `androidify self version` — Print androidify version
- `androidify _ _` — Passthrough to androidify CLI

## Usage Examples
- "Run androidify"
- "Use androidify to Sample app for Androidify"

## Installation

```bash
pip install androidify
```

## Key Features
- Sample app for Androidify
- CLI tool, headless and scriptable
