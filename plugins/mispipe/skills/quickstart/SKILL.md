# mispipe Plugin

CLI tool: mispipe.

## Commands
- `mispipe <resource> <action>` — Execute mispipe commands
- `mispipe self version` — Print mispipe version
- `mispipe _ _` — Passthrough to mispipe CLI

## Usage Examples
- "mispipe --help"
- "mispipe self version"

## Installation
```bash
apt-get install mispipe 2>/dev/null || which mispipe
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
