# qsvplite Plugin

CLI tool: qsvplite.

## Commands
- `qsvplite <resource> <action>` — Execute qsvplite commands
- `qsvplite self version` — Print qsvplite version
- `qsvplite _ _` — Passthrough to qsvplite CLI

## Usage Examples
- "qsvplite --help"
- "qsvplite self version"

## Installation
```bash
apt-get install qsvplite 2>/dev/null || which qsvplite
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
