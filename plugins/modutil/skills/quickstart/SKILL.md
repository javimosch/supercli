# modutil Plugin

CLI tool: modutil.

## Commands
- `modutil <resource> <action>` — Execute modutil commands
- `modutil self version` — Print modutil version
- `modutil _ _` — Passthrough to modutil CLI

## Usage Examples
- "modutil --help"
- "modutil self version"

## Installation
```bash
apt-get install modutil 2>/dev/null || which modutil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
