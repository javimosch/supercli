# frankenmermaid Plugin
Rust-based engine for rendering Mermaid diagrams

## Commands
- `frankenmermaid <resource> <action>` — Execute frankenmermaid commands
- `frankenmermaid _ _` — Passthrough to frankenmermaid CLI

## Usage
- `frankenmermaid _ _ <args>` — Run frankenmermaid with any arguments
