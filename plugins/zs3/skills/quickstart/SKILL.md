# zs3 Plugin

S3-compatible storage in Zig. Zero dependencies.

## Commands

### General
- `zs3 self version` — Print zs3 version
- `zs3 _ _` — Passthrough to zs3 CLI

## Usage Examples
- "Run zs3"
- "Use zs3 to S3-compatible storage in Zig. Zero dependencies."

## Installation

```bash
pip install zs3
```

## Key Features
- S3-compatible storage in Zig. Zero dependencies.
- CLI tool, headless and scriptable
