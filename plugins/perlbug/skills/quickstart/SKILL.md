# perlbug Plugin

CLI tool: perlbug.

## Commands
- `perlbug <resource> <action>` — Execute perlbug commands
- `perlbug self version` — Print perlbug version
- `perlbug _ _` — Passthrough to perlbug CLI

## Usage Examples
- "perlbug --help"
- "perlbug self version"

## Installation
```bash
apt-get install perlbug 2>/dev/null || which perlbug
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
