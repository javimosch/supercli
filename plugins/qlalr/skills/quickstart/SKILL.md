# qlalr Plugin

CLI tool: qlalr.

## Commands
- `qlalr <resource> <action>` — Execute qlalr commands
- `qlalr self version` — Print qlalr version
- `qlalr _ _` — Passthrough to qlalr CLI

## Usage Examples
- "qlalr --help"
- "qlalr self version"

## Installation
```bash
apt-get install qlalr 2>/dev/null || which qlalr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
