# tuckr Plugin
Simple dotfile manager focusing on symlink management

## Commands
- `tuckr <resource> <action>` — Execute tuckr commands
- `tuckr _ _` — Passthrough to tuckr CLI

## Usage
- `tuckr _ _ <args>` — Run tuckr with any arguments
