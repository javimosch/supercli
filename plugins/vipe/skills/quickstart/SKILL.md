# vipe Plugin

CLI tool: vipe.

## Commands
- `vipe <resource> <action>` — Execute vipe commands
- `vipe self version` — Print vipe version
- `vipe _ _` — Passthrough to vipe CLI

## Usage Examples
- "vipe --help"
- "vipe self version"

## Installation
```bash
apt-get install vipe 2>/dev/null || which vipe
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
