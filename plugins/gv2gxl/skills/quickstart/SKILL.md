# gv2gxl Plugin

CLI tool: gv2gxl.

## Commands
- `gv2gxl <resource> <action>` — Execute gv2gxl commands
- `gv2gxl self version` — Print gv2gxl version
- `gv2gxl _ _` — Passthrough to gv2gxl CLI

## Usage Examples
- "gv2gxl --help"
- "gv2gxl self version"

## Installation
```bash
apt-get install gv2gxl 2>/dev/null || which gv2gxl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
