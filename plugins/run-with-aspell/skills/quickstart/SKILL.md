# run-with-aspell Plugin

CLI tool: run-with-aspell.

## Commands
- `run-with-aspell <resource> <action>` — Execute run-with-aspell commands
- `run-with-aspell self version` — Print run-with-aspell version
- `run-with-aspell _ _` — Passthrough to run-with-aspell CLI

## Usage Examples
- "run-with-aspell --help"
- "run-with-aspell self version"

## Installation
```bash
apt-get install run-with-aspell 2>/dev/null || which run-with-aspell
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
