# gts2stl Plugin

CLI tool: gts2stl.

## Commands
- `gts2stl <resource> <action>` — Execute gts2stl commands
- `gts2stl self version` — Print gts2stl version
- `gts2stl _ _` — Passthrough to gts2stl CLI

## Usage Examples
- "gts2stl --help"
- "gts2stl self version"

## Installation
```bash
apt-get install gts2stl 2>/dev/null || which gts2stl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
