# Impactor Plugin

Feature-rich iOS/tvOS sideloading application written in Rust

## Commands
- `impactor _ _` — Passthrough to impactor CLI

## Installation

```bash
cargo install impactor
```

## Examples
```bash
impactor --help
impactor --version
```
