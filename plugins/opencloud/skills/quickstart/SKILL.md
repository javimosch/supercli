# Opencloud Plugin

Open source platform for file management, sharing and collaboration

## Commands
- `opencloud _ _` — Passthrough to opencloud CLI

## Installation

```bash
go install github.com/opencloud-eu/opencloud@latest
```

## Examples
```bash
opencloud --help
opencloud --version
```
