# ytsub Plugin
CLI tool for ytsub.

## Commands
- `ytsub <resource> <action>` — Execute ytsub commands
- `ytsub _ _` — Passthrough to ytsub CLI

## Installation
```bash
cargo install ytsub
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
