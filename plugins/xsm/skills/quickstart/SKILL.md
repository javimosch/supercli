# xsm Plugin

CLI tool: xsm.

## Commands
- `xsm <resource> <action>` — Execute xsm commands
- `xsm self version` — Print xsm version
- `xsm _ _` — Passthrough to xsm CLI

## Usage Examples
- "xsm --help"
- "xsm self version"

## Installation
```bash
apt-get install xsm 2>/dev/null || which xsm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
