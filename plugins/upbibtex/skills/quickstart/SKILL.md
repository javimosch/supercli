# upbibtex Plugin

CLI tool: upbibtex.

## Commands
- `upbibtex <resource> <action>` — Execute upbibtex commands
- `upbibtex self version` — Print upbibtex version
- `upbibtex _ _` — Passthrough to upbibtex CLI

## Usage Examples
- "upbibtex --help"
- "upbibtex self version"

## Installation
```bash
apt-get install upbibtex 2>/dev/null || which upbibtex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
