# volname Plugin

CLI tool: volname.

## Commands
- `volname <resource> <action>` — Execute volname commands
- `volname self version` — Print volname version
- `volname _ _` — Passthrough to volname CLI

## Usage Examples
- "volname --help"
- "volname self version"

## Installation
```bash
apt-get install volname 2>/dev/null || which volname
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
