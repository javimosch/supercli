# install-clever-completion Plugin

CLI tool: install-clever-completion.

## Commands
- `install-clever-completion <resource> <action>` — Execute install-clever-completion commands
- `install-clever-completion self version` — Print install-clever-completion version
- `install-clever-completion _ _` — Passthrough to install-clever-completion CLI

## Usage Examples
- "install-clever-completion --help"
- "install-clever-completion self version"

## Installation
```bash
apt-get install install-clever-completion 2>/dev/null || which install-clever-completion
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
