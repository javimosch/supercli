# pbmtoxbm Plugin

CLI tool: pbmtoxbm.

## Commands
- `pbmtoxbm <resource> <action>` — Execute pbmtoxbm commands
- `pbmtoxbm self version` — Print pbmtoxbm version
- `pbmtoxbm _ _` — Passthrough to pbmtoxbm CLI

## Usage Examples
- "pbmtoxbm --help"
- "pbmtoxbm self version"

## Installation
```bash
apt-get install pbmtoxbm 2>/dev/null || which pbmtoxbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
