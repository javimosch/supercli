# foundrytools-cli Plugin
Manipulate font metadata and convert font formats

## Commands
- `foundrytools-cli <resource> <action>` — Execute foundrytools-cli commands
- `foundrytools-cli _ _` — Passthrough to foundrytools-cli CLI

## Usage
- `foundrytools-cli _ _ <args>` — Run foundrytools-cli with any arguments
