# vector Quickstart

vector processes and routes logs and events with minimal overhead.

## Installation

```bash
brew install vector
```

## Basic Usage

### Validate config
```bash
vector validate vector.toml
```

### Run pipeline
```bash
vector --config vector.toml
```
