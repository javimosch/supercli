# tensor.h Plugin

creating a tiny tensor library in raw C

## Commands

### General
- `tensor.h self version` — Print tensor.h version
- `tensor.h _ _` — Passthrough to tensor.h CLI

## Usage Examples
- "Run tensor.h"
- "Use tensor.h to creating a tiny tensor library in raw C"

## Installation

```bash
pip install tensor.h
```

## Key Features
- creating a tiny tensor library in raw C
- CLI tool, headless and scriptable
