# fdp Plugin

CLI tool: fdp.

## Commands
- `fdp <resource> <action>` — Execute fdp commands
- `fdp self version` — Print fdp version
- `fdp _ _` — Passthrough to fdp CLI

## Usage Examples
- "fdp --help"
- "fdp self version"

## Installation
```bash
apt-get install fdp 2>/dev/null || which fdp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
