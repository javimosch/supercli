# mtype Plugin

CLI tool: mtype.

## Commands
- `mtype <resource> <action>` — Execute mtype commands
- `mtype self version` — Print mtype version
- `mtype _ _` — Passthrough to mtype CLI

## Usage Examples
- "mtype --help"
- "mtype self version"

## Installation
```bash
apt-get install mtype 2>/dev/null || which mtype
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
