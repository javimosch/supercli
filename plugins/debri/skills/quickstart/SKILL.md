# debri Plugin

CLI tool: debri.

## Commands
- `debri <resource> <action>` — Execute debri commands
- `debri self version` — Print debri version
- `debri _ _` — Passthrough to debri CLI

## Usage Examples
- "debri --help"
- "debri self version"

## Installation
```bash
apt-get install debri 2>/dev/null || which debri
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
