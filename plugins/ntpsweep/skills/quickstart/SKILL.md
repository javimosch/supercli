# ntpsweep Plugin

CLI tool: ntpsweep.

## Commands
- `ntpsweep <resource> <action>` — Execute ntpsweep commands
- `ntpsweep self version` — Print ntpsweep version
- `ntpsweep _ _` — Passthrough to ntpsweep CLI

## Usage Examples
- "ntpsweep --help"
- "ntpsweep self version"

## Installation
```bash
apt-get install ntpsweep 2>/dev/null || which ntpsweep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
