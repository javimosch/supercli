# tificc Plugin

CLI tool: tificc.

## Commands
- `tificc <resource> <action>` — Execute tificc commands
- `tificc self version` — Print tificc version
- `tificc _ _` — Passthrough to tificc CLI

## Usage Examples
- "tificc --help"
- "tificc self version"

## Installation
```bash
apt-get install tificc 2>/dev/null || which tificc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
