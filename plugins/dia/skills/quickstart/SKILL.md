# dia Plugin

TTS model for ultra-realistic dialogue generation

## Commands

### Version
`dia self version` — Print dia version

### Passthrough
`dia _ _` — Passthrough to dia CLI with all arguments forwarded.

## Usage Examples

```bash
dia --version
dia --help
```

## Installation

```bash
pip install dia
```

## Key Features
- TTS model for ultra-realistic dialogue generation
