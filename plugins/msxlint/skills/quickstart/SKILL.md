# msxlint Plugin

CLI tool: msxlint.

## Commands
- `msxlint <resource> <action>` — Execute msxlint commands
- `msxlint self version` — Print msxlint version
- `msxlint _ _` — Passthrough to msxlint CLI

## Usage Examples
- "msxlint --help"
- "msxlint self version"

## Installation
```bash
apt-get install msxlint 2>/dev/null || which msxlint
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
