# bssh Plugin
CLI tool for bssh.

## Commands
- `bssh <resource> <action>` — Execute bssh commands
- `bssh _ _` — Passthrough to bssh CLI

## Installation
```bash
cargo install bssh
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
