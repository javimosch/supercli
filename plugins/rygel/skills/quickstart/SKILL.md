# rygel Plugin

CLI tool: rygel.

## Commands
- `rygel <resource> <action>` — Execute rygel commands
- `rygel self version` — Print rygel version
- `rygel _ _` — Passthrough to rygel CLI

## Usage Examples
- "rygel --help"
- "rygel self version"

## Installation
```bash
apt-get install rygel 2>/dev/null || which rygel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
