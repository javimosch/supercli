# xfdesktop Plugin

CLI tool: xfdesktop.

## Commands
- `xfdesktop <resource> <action>` — Execute xfdesktop commands
- `xfdesktop self version` — Print xfdesktop version
- `xfdesktop _ _` — Passthrough to xfdesktop CLI

## Usage Examples
- "xfdesktop --help"
- "xfdesktop self version"

## Installation
```bash
apt-get install xfdesktop 2>/dev/null || which xfdesktop
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
