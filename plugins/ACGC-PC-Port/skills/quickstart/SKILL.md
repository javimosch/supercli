# ACGC-PC-Port Plugin

Unofficial PC Port of Animal Crossing Gamecube

## Commands

### General
- `ACGC-PC-Port self version` — Print ACGC-PC-Port version
- `ACGC-PC-Port _ _` — Passthrough to acgc-pc-port CLI

## Usage Examples
- "Run ACGC-PC-Port"
- "Use acgc-pc-port to Unofficial PC Port of Animal Crossing Gamecube"

## Installation

```bash
pip install acgc-pc-port
```

## Key Features
- Unofficial PC Port of Animal Crossing Gamecube
- CLI tool, headless and scriptable
