# ifnames Plugin

CLI tool: ifnames.

## Commands
- `ifnames <resource> <action>` — Execute ifnames commands
- `ifnames self version` — Print ifnames version
- `ifnames _ _` — Passthrough to ifnames CLI

## Usage Examples
- "ifnames --help"
- "ifnames self version"

## Installation
```bash
apt-get install ifnames 2>/dev/null || which ifnames
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
