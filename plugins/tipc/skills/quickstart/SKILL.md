# tipc Plugin

CLI tool: tipc.

## Commands
- `tipc <resource> <action>` — Execute tipc commands
- `tipc self version` — Print tipc version
- `tipc _ _` — Passthrough to tipc CLI

## Usage Examples
- "tipc --help"
- "tipc self version"

## Installation
```bash
apt-get install tipc 2>/dev/null || which tipc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
