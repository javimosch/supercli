# nping Plugin

CLI tool: nping.

## Commands
- `nping <resource> <action>` — Execute nping commands
- `nping self version` — Print nping version
- `nping _ _` — Passthrough to nping CLI

## Usage Examples
- "nping --help"
- "nping self version"

## Installation
```bash
apt-get install nping 2>/dev/null || which nping
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
