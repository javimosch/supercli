# pnmtofits Plugin

CLI tool: pnmtofits.

## Commands
- `pnmtofits <resource> <action>` — Execute pnmtofits commands
- `pnmtofits self version` — Print pnmtofits version
- `pnmtofits _ _` — Passthrough to pnmtofits CLI

## Usage Examples
- "pnmtofits --help"
- "pnmtofits self version"

## Installation
```bash
apt-get install pnmtofits 2>/dev/null || which pnmtofits
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
