# Understand-Anything Plugin

Graphs that teach > graphs that impress. Turn any code into an interactive knowledge graph you can explore, search, and ask questions about. Works with Claude Code, Codex, Cursor, Copilot, Gemini CLI, and more.

## Commands
- `Understand-Anything <resource> <action>` — Execute Understand-Anything commands
- `Understand-Anything self version` — Print Understand-Anything version
- `Understand-Anything _ _` — Passthrough to understand-anything CLI

## Installation

```bash
pip install understand-anything
```
