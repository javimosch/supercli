# pw-cat Plugin

CLI tool: pw-cat.

## Commands
- `pw-cat <resource> <action>` — Execute pw-cat commands
- `pw-cat self version` — Print pw-cat version
- `pw-cat _ _` — Passthrough to pw-cat CLI

## Usage Examples
- "pw-cat --help"
- "pw-cat self version"

## Installation
```bash
apt-get install pw-cat 2>/dev/null || which pw-cat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
