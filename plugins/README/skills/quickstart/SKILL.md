# README Plugin

CLI tool: README.

## Commands
- `README <resource> <action>` — Execute README commands
- `README self version` — Print README version
- `README _ _` — Passthrough to README CLI

## Usage Examples
- "README --help"
- "README self version"

## Installation
```bash
apt-get install README 2>/dev/null || which README
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
