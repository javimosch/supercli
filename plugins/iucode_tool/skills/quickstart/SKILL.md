# iucode_tool Plugin

CLI tool: iucode_tool.

## Commands
- `iucode_tool <resource> <action>` — Execute iucode_tool commands
- `iucode_tool self version` — Print iucode_tool version
- `iucode_tool _ _` — Passthrough to iucode_tool CLI

## Usage Examples
- "iucode_tool --help"
- "iucode_tool self version"

## Installation
```bash
apt-get install iucode_tool 2>/dev/null || which iucode_tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
