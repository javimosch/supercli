# geteltorito Plugin

CLI tool: geteltorito.

## Commands
- `geteltorito <resource> <action>` — Execute geteltorito commands
- `geteltorito self version` — Print geteltorito version
- `geteltorito _ _` — Passthrough to geteltorito CLI

## Usage Examples
- "geteltorito --help"
- "geteltorito self version"

## Installation
```bash
apt-get install geteltorito 2>/dev/null || which geteltorito
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
