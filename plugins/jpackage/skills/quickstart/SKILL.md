# jpackage Plugin

CLI tool: jpackage.

## Commands
- `jpackage <resource> <action>` — Execute jpackage commands
- `jpackage self version` — Print jpackage version
- `jpackage _ _` — Passthrough to jpackage CLI

## Usage Examples
- "jpackage --help"
- "jpackage self version"

## Installation
```bash
apt-get install jpackage 2>/dev/null || which jpackage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
