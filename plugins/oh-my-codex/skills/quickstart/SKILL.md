# oh-my-codex Plugin

OmX - Oh My codeX: Your codex is not alone. Add hooks, agent teams, HUDs, and so much more.

## Commands
- `oh-my-codex <resource> <action>` — Execute oh-my-codex commands
- `oh-my-codex self version` — Print oh-my-codex version
- `oh-my-codex _ _` — Passthrough to oh-my-codex CLI

## Installation

```bash
pip install oh-my-codex
```
