# gvpr Plugin

CLI tool: gvpr.

## Commands
- `gvpr <resource> <action>` — Execute gvpr commands
- `gvpr self version` — Print gvpr version
- `gvpr _ _` — Passthrough to gvpr CLI

## Usage Examples
- "gvpr --help"
- "gvpr self version"

## Installation
```bash
apt-get install gvpr 2>/dev/null || which gvpr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
