# cups.lp Plugin

CLI tool: cups.lp.

## Commands
- `cups.lp <resource> <action>` — Execute cups.lp commands
- `cups.lp self version` — Print cups.lp version
- `cups.lp _ _` — Passthrough to cups.lp CLI

## Usage Examples
- "cups.lp --help"
- "cups.lp self version"

## Installation
```bash
apt-get install cups.lp 2>/dev/null || which cups.lp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
