# fmtutil-sys Plugin

CLI tool: fmtutil-sys.

## Commands
- `fmtutil-sys <resource> <action>` — Execute fmtutil-sys commands
- `fmtutil-sys self version` — Print fmtutil-sys version
- `fmtutil-sys _ _` — Passthrough to fmtutil-sys CLI

## Usage Examples
- "fmtutil-sys --help"
- "fmtutil-sys self version"

## Installation
```bash
apt-get install fmtutil-sys 2>/dev/null || which fmtutil-sys
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
