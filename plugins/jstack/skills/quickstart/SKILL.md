# jstack Plugin

CLI tool: jstack.

## Commands
- `jstack <resource> <action>` — Execute jstack commands
- `jstack self version` — Print jstack version
- `jstack _ _` — Passthrough to jstack CLI

## Usage Examples
- "jstack --help"
- "jstack self version"

## Installation
```bash
apt-get install jstack 2>/dev/null || which jstack
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
