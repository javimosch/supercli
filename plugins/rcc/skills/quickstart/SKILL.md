# rcc Plugin

CLI tool: rcc.

## Commands
- `rcc <resource> <action>` — Execute rcc commands
- `rcc self version` — Print rcc version
- `rcc _ _` — Passthrough to rcc CLI

## Usage Examples
- "rcc --help"
- "rcc self version"

## Installation
```bash
apt-get install rcc 2>/dev/null || which rcc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
