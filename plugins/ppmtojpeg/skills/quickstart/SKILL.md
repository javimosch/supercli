# ppmtojpeg Plugin

CLI tool: ppmtojpeg.

## Commands
- `ppmtojpeg <resource> <action>` — Execute ppmtojpeg commands
- `ppmtojpeg self version` — Print ppmtojpeg version
- `ppmtojpeg _ _` — Passthrough to ppmtojpeg CLI

## Usage Examples
- "ppmtojpeg --help"
- "ppmtojpeg self version"

```bash
apt-get install ppmtojpeg 2>/dev/null || which ppmtojpeg
```
