# poetry2setup Plugin
Convert Poetry pyproject toml to setup py

## Commands
- `poetry2setup <resource> <action>` — Execute poetry2setup commands
- `poetry2setup _ _` — Passthrough to poetry2setup CLI

## Usage
- `poetry2setup _ _ <args>` — Run poetry2setup with any arguments
