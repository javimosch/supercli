# xlsatoms Plugin

CLI tool: xlsatoms.

## Commands
- `xlsatoms <resource> <action>` — Execute xlsatoms commands
- `xlsatoms self version` — Print xlsatoms version
- `xlsatoms _ _` — Passthrough to xlsatoms CLI

## Usage Examples
- "xlsatoms --help"
- "xlsatoms self version"

## Installation
```bash
apt-get install xlsatoms 2>/dev/null || which xlsatoms
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
