# ntpdc Plugin

CLI tool: ntpdc.

## Commands
- `ntpdc <resource> <action>` — Execute ntpdc commands
- `ntpdc self version` — Print ntpdc version
- `ntpdc _ _` — Passthrough to ntpdc CLI

## Usage Examples
- "ntpdc --help"
- "ntpdc self version"

## Installation
```bash
apt-get install ntpdc 2>/dev/null || which ntpdc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
