# mdu Plugin

CLI tool: mdu.

## Commands
- `mdu <resource> <action>` — Execute mdu commands
- `mdu self version` — Print mdu version
- `mdu _ _` — Passthrough to mdu CLI

## Usage Examples
- "mdu --help"
- "mdu self version"

## Installation
```bash
apt-get install mdu 2>/dev/null || which mdu
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
