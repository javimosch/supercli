# md5sum.textutils Plugin

CLI tool: md5sum.textutils.

## Commands
- `md5sum.textutils <resource> <action>` — Execute md5sum.textutils commands
- `md5sum.textutils self version` — Print md5sum.textutils version
- `md5sum.textutils _ _` — Passthrough to md5sum.textutils CLI

## Usage Examples
- "md5sum.textutils --help"
- "md5sum.textutils self version"

## Installation
```bash
apt-get install md5sum.textutils 2>/dev/null || which md5sum.textutils
```
