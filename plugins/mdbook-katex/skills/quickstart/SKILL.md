# mdbook-katex Plugin
Math typesetting with KaTeX preprocessor for mdBook

## Commands
- `mdbook-katex <resource> <action>` — Execute mdbook-katex commands
- `mdbook-katex _ _` — Passthrough to mdbook-katex CLI

## Usage
- `mdbook-katex _ _ <args>` — Run mdbook-katex with any arguments
