# Hunyuan3D Plugin

High-resolution 3D assets generation with Hunyuan3D diffusion models by Tencent

## Commands
- `hunyuan3d _ _` — Passthrough to hunyuan3d CLI

## Installation

```bash
pip install hunyuan3d
```

## Examples
```bash
hunyuan3d --help
hunyuan3d --version
```
