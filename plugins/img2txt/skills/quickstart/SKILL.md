# img2txt Plugin
Convert images to colored text with ANSI codes

## Commands
- `img2txt <resource> <action>` — Execute img2txt commands
- `img2txt _ _` — Passthrough to img2txt CLI

## Usage
- `img2txt _ _ <args>` — Run img2txt with any arguments
