# llmfit Plugin

Hundreds of models & providers. One command to find what runs on your hardware.

## Commands

### General
- `llmfit self version` — Print llmfit version
- `llmfit _ _` — Passthrough to llmfit CLI

## Installation

```bash
pip install llmfit
```

## Key Features
- Hundreds of models & providers. One command to find what runs on your hardware.
