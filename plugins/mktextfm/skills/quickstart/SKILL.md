# mktextfm Plugin

CLI tool: mktextfm.

## Commands
- `mktextfm <resource> <action>` — Execute mktextfm commands
- `mktextfm self version` — Print mktextfm version
- `mktextfm _ _` — Passthrough to mktextfm CLI

## Usage Examples
- "mktextfm --help"
- "mktextfm self version"

## Installation
```bash
apt-get install mktextfm 2>/dev/null || which mktextfm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
