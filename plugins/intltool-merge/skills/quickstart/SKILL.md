# intltool-merge Plugin

CLI tool: intltool-merge.

## Commands
- `intltool-merge <resource> <action>` — Execute intltool-merge commands
- `intltool-merge self version` — Print intltool-merge version
- `intltool-merge _ _` — Passthrough to intltool-merge CLI

## Usage Examples
- "intltool-merge --help"
- "intltool-merge self version"

## Installation
```bash
apt-get install intltool-merge 2>/dev/null || which intltool-merge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
