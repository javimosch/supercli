# yuku Plugin

High-performance JavaScript/TypeScript compiler toolchain in Zig.

## Commands

### General
- `yuku self version` — Print yuku version
- `yuku _ _` — Passthrough to yuku CLI

```bash
pip install yuku
```

- High-performance JavaScript/TypeScript compiler toolchain in Zig.
- CLI tool, headless and scriptable
