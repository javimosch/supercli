# diff-so-fancy Plugin
Human-readable diff output formatter. Transforms unified diffs into easier-to-read, colorized output.
## Commands
- `diff self version` — Print version
- `diff _ _` — Passthrough to diff-so-fancy
## Installation
```bash
brew install diff-so-fancy
```
