# gmp-cli Plugin
Google Marketing Platform CLI.
## Commands
- `gmp-cli _ _` — Passthrough to gmp-cli CLI
## Installation
```bash
npm install -g @lucianfialho/gmp-cli
```
## Key Features
- **GA4 access** — Google Analytics 4
- **Search Console** — SEO data
- **JSON output** — jq pipeline support
- **AI-ready** — Built for agent consumption
