# recipe-ui Plugin

CLI tool: recipe-ui.

## Commands
- `recipe-ui <resource> <action>` — Execute recipe-ui commands
- `recipe-ui self version` — Print recipe-ui version
- `recipe-ui _ _` — Passthrough to recipe-ui CLI

## Usage Examples
- "recipe-ui --help"
- "recipe-ui self version"

## Installation
```bash
apt-get install recipe-ui 2>/dev/null || which recipe-ui
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
