# pf2afm Plugin

CLI tool: pf2afm.

## Commands
- `pf2afm <resource> <action>` — Execute pf2afm commands
- `pf2afm self version` — Print pf2afm version
- `pf2afm _ _` — Passthrough to pf2afm CLI

## Usage Examples
- "pf2afm --help"
- "pf2afm self version"

## Installation
```bash
apt-get install pf2afm 2>/dev/null || which pf2afm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
