# mpvEx Plugin

A beautiful media player for android, based on mpv-android and built with Jetpack Compose. Forked from mpvKt

## Commands

### General
- `mpvEx self version` — Print mpvEx version
- `mpvEx _ _` — Passthrough to mpvex CLI
