# mrd Plugin

CLI tool: mrd.

## Commands
- `mrd <resource> <action>` — Execute mrd commands
- `mrd self version` — Print mrd version
- `mrd _ _` — Passthrough to mrd CLI

## Usage Examples
- "mrd --help"
- "mrd self version"

## Installation
```bash
apt-get install mrd 2>/dev/null || which mrd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
