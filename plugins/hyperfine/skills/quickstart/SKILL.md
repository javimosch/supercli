# hyperfine Plugin

Hyperfine — command benchmarking tool for performance testing

## Commands
- `hyperfine <resource> <action>` — Execute hyperfine commands
- `hyperfine self version` — Version

## Installation

```bash
cargo install hyperfine
Verify: hyperfine --version
```

## Commands

### `sc hyperfine self version`

Version


## SuperCLI

```bash
sc hyperfine _ _ --help
sc plugins learn hyperfine
```
