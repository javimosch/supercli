# xfce4-appfinder Plugin

CLI tool: xfce4-appfinder.

## Commands
- `xfce4-appfinder <resource> <action>` — Execute xfce4-appfinder commands
- `xfce4-appfinder self version` — Print xfce4-appfinder version
- `xfce4-appfinder _ _` — Passthrough to xfce4-appfinder CLI

## Usage Examples
- "xfce4-appfinder --help"
- "xfce4-appfinder self version"

## Installation
```bash
apt-get install xfce4-appfinder 2>/dev/null || which xfce4-appfinder
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
