# ubnexlnx Plugin

CLI tool: ubnexlnx.

## Commands
- `ubnexlnx <resource> <action>` — Execute ubnexlnx commands
- `ubnexlnx self version` — Print ubnexlnx version
- `ubnexlnx _ _` — Passthrough to ubnexlnx CLI

## Usage Examples
- "ubnexlnx --help"
- "ubnexlnx self version"

## Installation
```bash
apt-get install ubnexlnx 2>/dev/null || which ubnexlnx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
