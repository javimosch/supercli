# midi2audio-cli Plugin
CLI wrapper for converting MIDI files to audio formats

## Commands
- `midi2audio-cli <resource> <action>` — Execute midi2audio-cli commands
- `midi2audio-cli _ _` — Passthrough to midi2audio-cli CLI

## Usage
- `midi2audio-cli _ _ <args>` — Run midi2audio-cli with any arguments
