# SwitchAI Plugin

Easily select and manage your preferred AI digital assistants on Android.

## Commands

### General
- `SwitchAI self version` — Print SwitchAI version
- `SwitchAI _ _` — Passthrough to switchai CLI

## Usage Examples
- "Run SwitchAI"
- "Use switchai to Easily select and manage your preferred AI digital assistant"

## Installation

```bash
pip install switchai
```

## Key Features
- Easily select and manage your preferred AI digital assistants on Android.
- CLI tool, headless and scriptable
