# pbmtog3 Plugin

CLI tool: pbmtog3.

## Commands
- `pbmtog3 <resource> <action>` — Execute pbmtog3 commands
- `pbmtog3 self version` — Print pbmtog3 version
- `pbmtog3 _ _` — Passthrough to pbmtog3 CLI

## Usage Examples
- "pbmtog3 --help"
- "pbmtog3 self version"

## Installation
```bash
apt-get install pbmtog3 2>/dev/null || which pbmtog3
```
