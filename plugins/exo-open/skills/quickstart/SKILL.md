# exo-open Plugin

CLI tool: exo-open.

## Commands
- `exo-open <resource> <action>` — Execute exo-open commands
- `exo-open self version` — Print exo-open version
- `exo-open _ _` — Passthrough to exo-open CLI

## Usage Examples
- "exo-open --help"
- "exo-open self version"

## Installation
```bash
apt-get install exo-open 2>/dev/null || which exo-open
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
