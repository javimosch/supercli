# compose-stability-analyzer Plugin

🦄 Real-time analysis of Jetpack Compose composable functions' stability directly within Android Studio or IntelliJ.

## Commands

### General
- `compose-stability-analyzer self version` — Print compose-stability-analyzer version
- `compose-stability-analyzer _ _` — Passthrough to compose-stability-analyzer CLI
