# gamemoded Plugin

CLI tool: gamemoded.

## Commands
- `gamemoded <resource> <action>` — Execute gamemoded commands
- `gamemoded self version` — Print gamemoded version
- `gamemoded _ _` — Passthrough to gamemoded CLI

## Usage Examples
- "gamemoded --help"
- "gamemoded self version"

## Installation
```bash
apt-get install gamemoded 2>/dev/null || which gamemoded
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
