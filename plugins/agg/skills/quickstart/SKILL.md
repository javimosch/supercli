# agg
agg — asciicast to GIF converter. Convert terminal recordings (asciicast v2) to animated GIFs. Non-interactive.

## Commands
- `agg <resource> <action>` — Execute agg commands
- `agg self version` — Print agg version
- `agg _ _` — Passthrough to agg CLI
