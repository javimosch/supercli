# cups.cupsenable Plugin

CLI tool: cups.cupsenable.

## Commands
- `cups.cupsenable <resource> <action>` — Execute cups.cupsenable commands
- `cups.cupsenable self version` — Print cups.cupsenable version
- `cups.cupsenable _ _` — Passthrough to cups.cupsenable CLI

## Usage Examples
- "cups.cupsenable --help"
- "cups.cupsenable self version"

## Installation
```bash
apt-get install cups.cupsenable 2>/dev/null || which cups.cupsenable
```
