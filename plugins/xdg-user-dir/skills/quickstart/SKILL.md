# xdg-user-dir Plugin

CLI tool: xdg-user-dir.

## Commands
- `xdg-user-dir <resource> <action>` — Execute xdg-user-dir commands
- `xdg-user-dir self version` — Print xdg-user-dir version
- `xdg-user-dir _ _` — Passthrough to xdg-user-dir CLI

## Usage Examples
- "xdg-user-dir --help"
- "xdg-user-dir self version"

## Installation
```bash
apt-get install xdg-user-dir 2>/dev/null || which xdg-user-dir
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
