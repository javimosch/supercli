# antfly Plugin

Terminal file manager

## Commands

### Version
`antfly self version` — Print antfly version

### Passthrough
`antfly _ _` — Passthrough to antfly CLI with all arguments forwarded.

## Usage Examples

```bash
antfly --version
antfly --help
```

## Installation

```bash
cargo install antfly
```

## Key Features
- Terminal file manager
