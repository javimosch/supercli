# gitmoji-changelog Plugin

Changelog generator with gitmoji in JavaScript

## Commands
- `gitmoji-changelog self version` — Print version
- `gitmoji-changelog _ _` — Passthrough to gitmoji-changelog

## Installation
```bash
npm install -g gitmoji-changelog
```
