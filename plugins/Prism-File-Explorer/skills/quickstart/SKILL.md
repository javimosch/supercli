# Prism-File-Explorer Plugin

A modern, feature-rich, and lightweight file manager for Android, built entirely with Kotlin and Jetpack Compose.

## Commands

### General
- `Prism-File-Explorer self version` — Print Prism-File-Explorer version
- `Prism-File-Explorer _ _` — Passthrough to prism-file-explorer CLI
