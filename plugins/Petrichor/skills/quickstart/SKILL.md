# Petrichor Plugin

An offline macOS music player

## Commands

### General
- `Petrichor self version` — Print Petrichor version
- `Petrichor _ _` — Passthrough to petrichor CLI

## Usage Examples
- "Run Petrichor"
- "Use petrichor to An offline macOS music player"

## Installation

```bash
pip install petrichor
```

## Key Features
- An offline macOS music player
- CLI tool, headless and scriptable
