# loweb Plugin

CLI tool: loweb.

## Commands
- `loweb <resource> <action>` — Execute loweb commands
- `loweb self version` — Print loweb version
- `loweb _ _` — Passthrough to loweb CLI

## Usage Examples
- "loweb --help"
- "loweb self version"

## Installation
```bash
apt-get install loweb 2>/dev/null || which loweb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
