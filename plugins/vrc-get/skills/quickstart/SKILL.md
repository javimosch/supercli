# vrc-get Plugin
CLI tool for vrc-get.

## Commands
- `vrc-get <resource> <action>` — Execute vrc-get commands
- `vrc-get _ _` — Passthrough to vrc-get CLI

## Installation
```bash
cargo install vrc-get
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
