# giftopnm Plugin

CLI tool: giftopnm.

## Commands
- `giftopnm <resource> <action>` — Execute giftopnm commands
- `giftopnm self version` — Print giftopnm version
- `giftopnm _ _` — Passthrough to giftopnm CLI

## Usage Examples
- "giftopnm --help"
- "giftopnm self version"

## Installation
```bash
apt-get install giftopnm 2>/dev/null || which giftopnm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
