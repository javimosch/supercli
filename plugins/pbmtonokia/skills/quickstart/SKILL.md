# pbmtonokia Plugin

CLI tool: pbmtonokia.

## Commands
- `pbmtonokia <resource> <action>` — Execute pbmtonokia commands
- `pbmtonokia self version` — Print pbmtonokia version
- `pbmtonokia _ _` — Passthrough to pbmtonokia CLI

## Usage Examples
- "pbmtonokia --help"
- "pbmtonokia self version"

## Installation
```bash
apt-get install pbmtonokia 2>/dev/null || which pbmtonokia
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
