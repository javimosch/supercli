# gh-hype-scout Plugin

Terminal-first scout for discovering fast-rising GitHub repos with JSON export

## Commands
- `gh-hype-scout self version` — Print gh-hype-scout version
- `gh-hype-scout _ _` — Passthrough to gh-hype-scout CLI

## Usage Examples
- `gh-hype-scout self version` — Check installed version
- `gh-hype-scout _ _ --help` — Show gh-hype-scout help
- `gh-hype-scout _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/agent19710101/gh-hype-scout@latest
```

## Key Features
- github, discovery, trending, golang
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
