# termux-desktop Plugin

Install a full Linux desktop environment on your Android device with Termux X11 ( VNC optional) and also enable hardware acceleration

## Commands

### General
- `termux-desktop self version` — Print termux-desktop version
- `termux-desktop _ _` — Passthrough to termux-desktop CLI

## Usage Examples
- "Run termux-desktop"
- "Use termux-desktop to Install a full Linux desktop environment on your Android dev"

## Installation

```bash
pip install termux-desktop
```

## Key Features
- Install a full Linux desktop environment on your Android device with Termux X11 ( VNC optional) and 
- CLI tool, headless and scriptable
