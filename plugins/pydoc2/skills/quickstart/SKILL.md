# pydoc2 Plugin

CLI tool: pydoc2.

## Commands
- `pydoc2 <resource> <action>` — Execute pydoc2 commands
- `pydoc2 self version` — Print pydoc2 version
- `pydoc2 _ _` — Passthrough to pydoc2 CLI

## Usage Examples
- "pydoc2 --help"
- "pydoc2 self version"

## Installation
```bash
apt-get install pydoc2 2>/dev/null || which pydoc2
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
