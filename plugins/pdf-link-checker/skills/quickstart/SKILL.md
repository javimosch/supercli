# pdf-link-checker Plugin
Automated verification of broken links within PDF files

## Commands
- `pdf-link-checker <resource> <action>` — Execute pdf-link-checker commands
- `pdf-link-checker _ _` — Passthrough to pdf-link-checker CLI

## Usage
- `pdf-link-checker _ _ <args>` — Run pdf-link-checker with any arguments
