# zero-native Plugin

Build desktop + mobile apps with Zig and web UI

## Commands

### General
- `zero-native self version` — Print zero-native version
- `zero-native _ _` — Passthrough to zero-native CLI

## Usage Examples
- "Run zero-native"
- "Use zero-native to Build desktop + mobile apps with Zig and web UI"

## Installation

```bash
pip install zero-native
```

## Key Features
- Build desktop + mobile apps with Zig and web UI
- CLI tool, headless and scriptable
