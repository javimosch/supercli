# qmlplugindump Plugin

CLI tool: qmlplugindump.

## Commands
- `qmlplugindump <resource> <action>` — Execute qmlplugindump commands
- `qmlplugindump self version` — Print qmlplugindump version
- `qmlplugindump _ _` — Passthrough to qmlplugindump CLI

## Usage Examples
- "qmlplugindump --help"
- "qmlplugindump self version"

## Installation
```bash
apt-get install qmlplugindump 2>/dev/null || which qmlplugindump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
