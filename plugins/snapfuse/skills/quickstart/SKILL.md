# snapfuse Plugin

CLI tool: snapfuse.

## Commands
- `snapfuse <resource> <action>` — Execute snapfuse commands
- `snapfuse self version` — Print snapfuse version
- `snapfuse _ _` — Passthrough to snapfuse CLI

## Usage Examples
- "snapfuse --help"
- "snapfuse self version"

## Installation
```bash
apt-get install snapfuse 2>/dev/null || which snapfuse
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
