# idlj Plugin

CLI tool: idlj.

## Commands
- `idlj <resource> <action>` — Execute idlj commands
- `idlj self version` — Print idlj version
- `idlj _ _` — Passthrough to idlj CLI

## Usage Examples
- "idlj --help"
- "idlj self version"

## Installation
```bash
apt-get install idlj 2>/dev/null || which idlj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
