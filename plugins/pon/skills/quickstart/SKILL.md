# pon Plugin

CLI tool: pon.

## Commands
- `pon <resource> <action>` — Execute pon commands
- `pon self version` — Print pon version
- `pon _ _` — Passthrough to pon CLI

## Usage Examples
- "pon --help"
- "pon self version"

## Installation
```bash
apt-get install pon 2>/dev/null || which pon
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
