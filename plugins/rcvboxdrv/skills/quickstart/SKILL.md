# rcvboxdrv Plugin

CLI tool: rcvboxdrv.

## Commands
- `rcvboxdrv <resource> <action>` — Execute rcvboxdrv commands
- `rcvboxdrv self version` — Print rcvboxdrv version
- `rcvboxdrv _ _` — Passthrough to rcvboxdrv CLI

## Usage Examples
- "rcvboxdrv --help"
- "rcvboxdrv self version"

## Installation
```bash
apt-get install rcvboxdrv 2>/dev/null || which rcvboxdrv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
