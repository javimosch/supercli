# keepassxc-proxy Plugin

CLI tool: keepassxc-proxy.

## Commands
- `keepassxc-proxy <resource> <action>` — Execute keepassxc-proxy commands
- `keepassxc-proxy self version` — Print keepassxc-proxy version
- `keepassxc-proxy _ _` — Passthrough to keepassxc-proxy CLI

## Usage Examples
- "keepassxc-proxy --help"
- "keepassxc-proxy self version"

## Installation
```bash
apt-get install keepassxc-proxy 2>/dev/null || which keepassxc-proxy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
