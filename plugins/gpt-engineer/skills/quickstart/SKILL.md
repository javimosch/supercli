# gpt-engineer Plugin
Generate codebases from natural language specs with AI

## Commands
- `gpt-engineer <resource> <action>` — Execute gpt-engineer commands
- `gpt-engineer _ _` — Passthrough to gpt-engineer CLI

## Usage
- `gpt-engineer _ _ <args>` — Run gpt-engineer with any arguments
