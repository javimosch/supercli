# printafm Plugin

CLI tool: printafm.

## Commands
- `printafm <resource> <action>` — Execute printafm commands
- `printafm self version` — Print printafm version
- `printafm _ _` — Passthrough to printafm CLI

## Usage Examples
- "printafm --help"
- "printafm self version"

## Installation
```bash
apt-get install printafm 2>/dev/null || which printafm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
