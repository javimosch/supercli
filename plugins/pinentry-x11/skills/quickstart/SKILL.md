# pinentry-x11 Plugin

CLI tool: pinentry-x11.

## Commands
- `pinentry-x11 <resource> <action>` — Execute pinentry-x11 commands
- `pinentry-x11 self version` — Print pinentry-x11 version
- `pinentry-x11 _ _` — Passthrough to pinentry-x11 CLI

## Usage Examples

- "pinentry-x11 self version"
