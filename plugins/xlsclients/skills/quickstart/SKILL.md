# xlsclients Plugin

CLI tool: xlsclients.

## Commands
- `xlsclients <resource> <action>` — Execute xlsclients commands
- `xlsclients self version` — Print xlsclients version
- `xlsclients _ _` — Passthrough to xlsclients CLI

## Usage Examples
- "xlsclients --help"
- "xlsclients self version"

## Installation
```bash
apt-get install xlsclients 2>/dev/null || which xlsclients
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
