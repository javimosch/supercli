# xditview Plugin

CLI tool: xditview.

## Commands
- `xditview <resource> <action>` — Execute xditview commands
- `xditview self version` — Print xditview version
- `xditview _ _` — Passthrough to xditview CLI

## Usage Examples
- "xditview --help"
- "xditview self version"

## Installation
```bash
apt-get install xditview 2>/dev/null || which xditview
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
