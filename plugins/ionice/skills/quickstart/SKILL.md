# ionice Plugin

CLI tool: ionice.

## Commands
- `ionice <resource> <action>` — Execute ionice commands
- `ionice self version` — Print ionice version
- `ionice _ _` — Passthrough to ionice CLI

## Usage Examples
- "ionice --help"
- "ionice self version"

## Installation
```bash
apt-get install ionice 2>/dev/null || which ionice
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
