# roff2ps Plugin

CLI tool: roff2ps.

## Commands
- `roff2ps <resource> <action>` — Execute roff2ps commands
- `roff2ps self version` — Print roff2ps version
- `roff2ps _ _` — Passthrough to roff2ps CLI

## Usage Examples
- "roff2ps --help"
- "roff2ps self version"

## Installation
```bash
apt-get install roff2ps 2>/dev/null || which roff2ps
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
