# Trustunnel Plugin

VPN tunnel protocol implementation in Rust

## Commands
- `trustunnel _ _` — Passthrough to trustunnel CLI

## Installation

```bash
cargo install trustunnel
```

## Examples
```bash
trustunnel --help
trustunnel --version
```
