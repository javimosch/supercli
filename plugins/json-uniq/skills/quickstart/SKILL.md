# json-uniq
json-uniq — remove duplicate objects from a JSON array using SHA256 content hashing. Deduplicates by full object equality.

## Commands
- `json-uniq <resource> <action>` — Execute json-uniq commands
- `json uniq run` — json-uniq — remove duplicate objects from a JSON array using SHA256 content hashing. Deduplicates by full object equality.
