# asciicam Plugin
Record your terminal as ASCII art video

## Commands
- `asciicam <resource> <action>` — Execute asciicam commands
- `asciicam _ _` — Passthrough to asciicam CLI

## Usage
- `asciicam _ _ <args>` — Run asciicam with any arguments
