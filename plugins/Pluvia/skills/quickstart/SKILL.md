# Pluvia Plugin

Lightweight unofficial Steam client for Android

## Commands

### General
- `Pluvia self version` — Print Pluvia version
- `Pluvia _ _` — Passthrough to pluvia CLI

## Usage Examples
- "Run Pluvia"
- "Use pluvia to Lightweight unofficial Steam client for Android"

## Installation

```bash
pip install pluvia
```

## Key Features
- Lightweight unofficial Steam client for Android
- CLI tool, headless and scriptable
