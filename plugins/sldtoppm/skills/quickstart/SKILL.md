# sldtoppm Plugin

CLI tool: sldtoppm.

## Commands
- `sldtoppm <resource> <action>` — Execute sldtoppm commands
- `sldtoppm self version` — Print sldtoppm version
- `sldtoppm _ _` — Passthrough to sldtoppm CLI

## Usage Examples
- "sldtoppm --help"
- "sldtoppm self version"

## Installation
```bash
apt-get install sldtoppm 2>/dev/null || which sldtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
