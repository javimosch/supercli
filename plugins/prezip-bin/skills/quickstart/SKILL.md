# prezip-bin Plugin

CLI tool: prezip-bin.

## Commands
- `prezip-bin <resource> <action>` — Execute prezip-bin commands
- `prezip-bin self version` — Print prezip-bin version
- `prezip-bin _ _` — Passthrough to prezip-bin CLI

## Usage Examples
- "prezip-bin --help"
- "prezip-bin self version"

## Installation
```bash
apt-get install prezip-bin 2>/dev/null || which prezip-bin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
