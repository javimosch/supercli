# ua Plugin

CLI tool: ua.

## Commands
- `ua <resource> <action>` — Execute ua commands
- `ua self version` — Print ua version
- `ua _ _` — Passthrough to ua CLI

## Usage Examples
- "ua --help"
- "ua self version"

## Installation
```bash
apt-get install ua 2>/dev/null || which ua
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
