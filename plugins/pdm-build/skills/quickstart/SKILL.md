# pdm-build Plugin
PEP 517 build backend for PDM Python projects

## Commands
- `pdm-build <resource> <action>` — Execute pdm-build commands
- `pdm-build _ _` — Passthrough to pdm-build CLI

## Usage
- `pdm-build _ _ <args>` — Run pdm-build with any arguments
