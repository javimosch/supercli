# wheel Plugin

CLI tool: wheel.

## Commands
- `wheel <resource> <action>` — Execute wheel commands
- `wheel self version` — Print wheel version
- `wheel _ _` — Passthrough to wheel CLI

## Usage Examples
- "wheel --help"
- "wheel self version"

## Installation
```bash
apt-get install wheel 2>/dev/null || which wheel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
