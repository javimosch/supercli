# dRonin Plugin

The dRonin flight controller software.

## Commands

### General
- `dRonin self version` — Print dRonin version
- `dRonin _ _` — Passthrough to dronin CLI

## Usage Examples
- "Run dRonin"
- "Use dronin to The dRonin flight controller software."

## Installation

```bash
pip install dronin
```

## Key Features
- The dRonin flight controller software.
- CLI tool, headless and scriptable
