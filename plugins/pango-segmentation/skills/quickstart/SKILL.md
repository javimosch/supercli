# pango-segmentation Plugin

CLI tool: pango-segmentation.

## Commands
- `pango-segmentation <resource> <action>` — Execute pango-segmentation commands
- `pango-segmentation self version` — Print pango-segmentation version
- `pango-segmentation _ _` — Passthrough to pango-segmentation CLI

## Usage Examples
- "pango-segmentation --help"
- "pango-segmentation self version"

## Installation
```bash
apt-get install pango-segmentation 2>/dev/null || which pango-segmentation
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
