# weather-cli Plugin
Minimalist Go-based weather data fetcher

## Commands
- `weather-cli <resource> <action>` — Execute weather-cli commands
- `weather-cli _ _` — Passthrough to weather-cli CLI

## Usage
- `weather-cli _ _ <args>` — Run weather-cli with any arguments
