# fmtutil-user Plugin

CLI tool: fmtutil-user.

## Commands
- `fmtutil-user <resource> <action>` — Execute fmtutil-user commands
- `fmtutil-user self version` — Print fmtutil-user version
- `fmtutil-user _ _` — Passthrough to fmtutil-user CLI

## Usage Examples
- "fmtutil-user --help"
- "fmtutil-user self version"

## Installation
```bash
apt-get install fmtutil-user 2>/dev/null || which fmtutil-user
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
