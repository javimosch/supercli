# svg2sixel Plugin
Render SVG images as SIXEL graphics in terminals

## Commands
- `svg2sixel <resource> <action>` — Execute svg2sixel commands
- `svg2sixel _ _` — Passthrough to svg2sixel CLI

## Usage
- `svg2sixel _ _ <args>` — Run svg2sixel with any arguments
