# gsf Plugin

CLI tool: gsf.

## Commands
- `gsf <resource> <action>` — Execute gsf commands
- `gsf self version` — Print gsf version
- `gsf _ _` — Passthrough to gsf CLI

## Usage Examples
- "gsf --help"
- "gsf self version"

## Installation
```bash
apt-get install gsf 2>/dev/null || which gsf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
