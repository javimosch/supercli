# pgmramp Plugin

CLI tool: pgmramp.

## Commands
- `pgmramp <resource> <action>` — Execute pgmramp commands
- `pgmramp self version` — Print pgmramp version
- `pgmramp _ _` — Passthrough to pgmramp CLI

## Usage Examples
- "pgmramp --help"
- "pgmramp self version"

## Installation
```bash
apt-get install pgmramp 2>/dev/null || which pgmramp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
