# windows-arm Plugin

Windows for ARM in a Docker container.

## Commands

### General
- `windows-arm self version` — Print windows-arm version
- `windows-arm _ _` — Passthrough to windows-arm CLI

## Usage Examples
- "Run windows-arm"
- "Use windows-arm to Windows for ARM in a Docker container."

## Installation

```bash
pip install windows-arm
```

## Key Features
- Windows for ARM in a Docker container.
- CLI tool, headless and scriptable
