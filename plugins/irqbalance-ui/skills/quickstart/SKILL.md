# irqbalance-ui Plugin

CLI tool: irqbalance-ui.

## Commands
- `irqbalance-ui <resource> <action>` — Execute irqbalance-ui commands
- `irqbalance-ui self version` — Print irqbalance-ui version
- `irqbalance-ui _ _` — Passthrough to irqbalance-ui CLI

## Usage Examples
- "irqbalance-ui --help"
- "irqbalance-ui self version"

## Installation
```bash
apt-get install irqbalance-ui 2>/dev/null || which irqbalance-ui
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
