# line-sequencer Plugin
Micro-sequencer language for live coding MIDI music

## Commands
- `line-sequencer <resource> <action>` — Execute line-sequencer commands
- `line-sequencer _ _` — Passthrough to line-sequencer CLI

## Usage
- `line-sequencer _ _ <args>` — Run line-sequencer with any arguments
