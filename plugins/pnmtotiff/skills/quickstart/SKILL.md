# pnmtotiff Plugin

CLI tool: pnmtotiff.

## Commands
- `pnmtotiff <resource> <action>` — Execute pnmtotiff commands
- `pnmtotiff self version` — Print pnmtotiff version
- `pnmtotiff _ _` — Passthrough to pnmtotiff CLI

## Usage Examples
- "pnmtotiff --help"
- "pnmtotiff self version"

## Installation
```bash
apt-get install pnmtotiff 2>/dev/null || which pnmtotiff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
