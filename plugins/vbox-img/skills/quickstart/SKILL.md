# vbox-img Plugin

CLI tool: vbox-img.

## Commands
- `vbox-img <resource> <action>` — Execute vbox-img commands
- `vbox-img self version` — Print vbox-img version
- `vbox-img _ _` — Passthrough to vbox-img CLI

## Usage Examples
- "vbox-img --help"
- "vbox-img self version"

## Installation
```bash
apt-get install vbox-img 2>/dev/null || which vbox-img
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
