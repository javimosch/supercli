# h2ph Plugin

CLI tool: h2ph.

## Commands
- `h2ph <resource> <action>` — Execute h2ph commands
- `h2ph self version` — Print h2ph version
- `h2ph _ _` — Passthrough to h2ph CLI

## Usage Examples
- "h2ph --help"
- "h2ph self version"

## Installation
```bash
apt-get install h2ph 2>/dev/null || which h2ph
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
