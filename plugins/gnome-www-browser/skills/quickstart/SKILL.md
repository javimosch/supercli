# gnome-www-browser Plugin

CLI tool: gnome-www-browser.

## Commands
- `gnome-www-browser <resource> <action>` — Execute gnome-www-browser commands
- `gnome-www-browser self version` — Print gnome-www-browser version
- `gnome-www-browser _ _` — Passthrough to gnome-www-browser CLI

## Usage Examples
- "gnome-www-browser --help"
- "gnome-www-browser self version"

## Installation
```bash
apt-get install gnome-www-browser 2>/dev/null || which gnome-www-browser
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
