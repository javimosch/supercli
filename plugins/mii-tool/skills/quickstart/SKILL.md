# mii-tool Plugin

CLI tool: mii-tool.

## Commands
- `mii-tool <resource> <action>` — Execute mii-tool commands
- `mii-tool self version` — Print mii-tool version
- `mii-tool _ _` — Passthrough to mii-tool CLI

## Usage Examples
- "mii-tool --help"
- "mii-tool self version"

## Installation
```bash
apt-get install mii-tool 2>/dev/null || which mii-tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
