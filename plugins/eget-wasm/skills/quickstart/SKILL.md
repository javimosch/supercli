# eget-wasm Plugin
WASI-compiled binary downloader for sandboxed environments

## Commands
- `eget-wasm <resource> <action>` — Execute eget-wasm commands
- `eget-wasm _ _` — Passthrough to eget-wasm CLI

## Usage
- `eget-wasm _ _ <args>` — Run eget-wasm with any arguments
