# gedcom-cli Plugin
Search and display GEDCOM genealogy file contents

## Commands
- `gedcom-cli <resource> <action>` — Execute gedcom-cli commands
- `gedcom-cli _ _` — Passthrough to gedcom-cli CLI

## Usage
- `gedcom-cli _ _ <args>` — Run gedcom-cli with any arguments
