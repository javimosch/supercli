# gensprep Plugin

CLI tool: gensprep.

## Commands
- `gensprep <resource> <action>` — Execute gensprep commands
- `gensprep self version` — Print gensprep version
- `gensprep _ _` — Passthrough to gensprep CLI

## Usage Examples
- "gensprep --help"
- "gensprep self version"

## Installation
```bash
apt-get install gensprep 2>/dev/null || which gensprep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
