# docx2txt Plugin

CLI tool: docx2txt.

## Commands
- `docx2txt <resource> <action>` — Execute docx2txt commands
- `docx2txt self version` — Print docx2txt version
- `docx2txt _ _` — Passthrough to docx2txt CLI

## Usage Examples
- "docx2txt --help"
- "docx2txt self version"

## Installation
```bash
apt-get install docx2txt 2>/dev/null || which docx2txt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
