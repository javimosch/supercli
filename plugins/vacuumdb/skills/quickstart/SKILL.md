# vacuumdb Plugin

CLI tool: vacuumdb.

## Commands
- `vacuumdb <resource> <action>` — Execute vacuumdb commands
- `vacuumdb self version` — Print vacuumdb version
- `vacuumdb _ _` — Passthrough to vacuumdb CLI

## Usage Examples
- "vacuumdb --help"
- "vacuumdb self version"

## Installation
```bash
apt-get install vacuumdb 2>/dev/null || which vacuumdb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
