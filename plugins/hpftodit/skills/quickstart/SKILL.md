# hpftodit Plugin

CLI tool: hpftodit.

## Commands
- `hpftodit <resource> <action>` — Execute hpftodit commands
- `hpftodit self version` — Print hpftodit version
- `hpftodit _ _` — Passthrough to hpftodit CLI

## Usage Examples
- "hpftodit --help"
- "hpftodit self version"

## Installation
```bash
apt-get install hpftodit 2>/dev/null || which hpftodit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
