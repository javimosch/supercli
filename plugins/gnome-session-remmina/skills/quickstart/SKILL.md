# gnome-session-remmina Plugin

CLI tool: gnome-session-remmina.

## Commands
- `gnome-session-remmina <resource> <action>` — Execute gnome-session-remmina commands
- `gnome-session-remmina self version` — Print gnome-session-remmina version
- `gnome-session-remmina _ _` — Passthrough to gnome-session-remmina CLI

## Usage Examples
- "gnome-session-remmina --help"
- "gnome-session-remmina self version"

## Installation
```bash
apt-get install gnome-session-remmina 2>/dev/null || which gnome-session-remmina
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
