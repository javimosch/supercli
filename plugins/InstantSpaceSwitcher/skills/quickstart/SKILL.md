# InstantSpaceSwitcher Plugin

Native space switching on macOS with no animation

## Commands

### General
- `InstantSpaceSwitcher self version` — Print InstantSpaceSwitcher version
- `InstantSpaceSwitcher _ _` — Passthrough to instantspaceswitcher CLI

## Usage Examples
- "Run InstantSpaceSwitcher"
- "Use instantspaceswitcher to Native space switching on macOS with no animation"

## Installation

```bash
pip install instantspaceswitcher
```

## Key Features
- Native space switching on macOS with no animation
- CLI tool, headless and scriptable
