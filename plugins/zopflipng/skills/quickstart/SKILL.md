# zopflipng Plugin
Optimize PNG using Zopfli compression

## Commands
- `zopflipng <resource> <action>` — Execute zopflipng commands
- `zopflipng _ _` — Passthrough to zopflipng CLI

## Usage
- `zopflipng _ _ <args>` — Run zopflipng with any arguments
