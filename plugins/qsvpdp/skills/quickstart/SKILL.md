# qsvpdp Plugin

CLI tool: qsvpdp.

## Commands
- `qsvpdp <resource> <action>` — Execute qsvpdp commands
- `qsvpdp self version` — Print qsvpdp version
- `qsvpdp _ _` — Passthrough to qsvpdp CLI

## Usage Examples
- "qsvpdp --help"
- "qsvpdp self version"

## Installation
```bash
apt-get install qsvpdp 2>/dev/null || which qsvpdp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
