# twistd3 Plugin

CLI tool: twistd3.

## Commands
- `twistd3 <resource> <action>` — Execute twistd3 commands
- `twistd3 self version` — Print twistd3 version
- `twistd3 _ _` — Passthrough to twistd3 CLI

## Usage Examples
- "twistd3 --help"
- "twistd3 self version"

## Installation
```bash
apt-get install twistd3 2>/dev/null || which twistd3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
