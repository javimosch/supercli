# rustysd Plugin
Minimalist service manager compatible with systemd units

## Commands
- `rustysd <resource> <action>` — Execute rustysd commands
- `rustysd _ _` — Passthrough to rustysd CLI

## Usage
- `rustysd _ _ <args>` — Run rustysd with any arguments
