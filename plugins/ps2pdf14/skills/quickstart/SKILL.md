# ps2pdf14 Plugin

CLI tool: ps2pdf14.

## Commands
- `ps2pdf14 <resource> <action>` — Execute ps2pdf14 commands
- `ps2pdf14 self version` — Print ps2pdf14 version
- `ps2pdf14 _ _` — Passthrough to ps2pdf14 CLI

## Usage Examples
- "ps2pdf14 --help"
- "ps2pdf14 self version"

## Installation
```bash
apt-get install ps2pdf14 2>/dev/null || which ps2pdf14
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
