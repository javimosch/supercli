# markitdown Plugin

Convert files and documents to Markdown

## Commands

### Version
`markitdown self version` — Print markitdown version

### Passthrough
`markitdown _ _` — Passthrough to markitdown CLI with all arguments forwarded.

## Usage Examples

```bash
markitdown --version
markitdown --help
```

## Installation

```bash
pip install markitdown
```

## Key Features
- Convert files and documents to Markdown
