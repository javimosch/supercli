# serv00-play Plugin

serv00/hostuno 上的一些应用，包括argo+vmess/vmess+ws/hy2/socks5/mtproto/alist/哪吒探针|面板 等, 自动化部署、批量保号、进程防杀、消息推送

## Commands

### General
- `serv00-play self version` — Print serv00-play version
- `serv00-play _ _` — Passthrough to serv00-play CLI

## Usage Examples
- "Run serv00-play"
- "Use serv00-play to serv00/hostuno 上的一些应用，包括argo+vmess/vmess+ws/hy2/socks5/mtpro"

## Installation

```bash
pip install serv00-play
```

## Key Features
- serv00/hostuno 上的一些应用，包括argo+vmess/vmess+ws/hy2/socks5/mtproto/alist/哪吒探针|面板 等, 自动化部署、批量保号、进程防杀、消息推送
- CLI tool, headless and scriptable
