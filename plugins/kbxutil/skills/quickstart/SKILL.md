# kbxutil Plugin

CLI tool: kbxutil.

## Commands
- `kbxutil <resource> <action>` — Execute kbxutil commands
- `kbxutil self version` — Print kbxutil version
- `kbxutil _ _` — Passthrough to kbxutil CLI

## Usage Examples
- "kbxutil --help"
- "kbxutil self version"

## Installation
```bash
apt-get install kbxutil 2>/dev/null || which kbxutil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
