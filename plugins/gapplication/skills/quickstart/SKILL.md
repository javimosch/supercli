# gapplication Plugin

CLI tool: gapplication.

## Commands
- `gapplication <resource> <action>` — Execute gapplication commands
- `gapplication self version` — Print gapplication version
- `gapplication _ _` — Passthrough to gapplication CLI

## Usage Examples
- "gapplication --help"
- "gapplication self version"

## Installation
```bash
apt-get install gapplication 2>/dev/null || which gapplication
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
