# termscp Plugin
Terminal file transfer client with SCP and SFTP

## Commands
- `termscp <resource> <action>` — Execute termscp commands
- `termscp self version` — Print termscp version
- `termscp file upload` — Upload a file via SCP/SFTP
- `termscp _ _` — Passthrough to termscp CLI

## Usage
- `termscp _ _ <args>` — Run termscp with any arguments
