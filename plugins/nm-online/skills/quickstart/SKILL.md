# nm-online Plugin

CLI tool: nm-online.

## Commands
- `nm-online <resource> <action>` — Execute nm-online commands
- `nm-online self version` — Print nm-online version
- `nm-online _ _` — Passthrough to nm-online CLI

## Usage Examples
- "nm-online --help"
- "nm-online self version"

## Installation
```bash
apt-get install nm-online 2>/dev/null || which nm-online
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
