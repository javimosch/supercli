# gnome-calendar Plugin

CLI tool: gnome-calendar.

## Commands
- `gnome-calendar <resource> <action>` — Execute gnome-calendar commands
- `gnome-calendar self version` — Print gnome-calendar version
- `gnome-calendar _ _` — Passthrough to gnome-calendar CLI

## Usage Examples
- "gnome-calendar --help"
- "gnome-calendar self version"

## Installation
```bash
apt-get install gnome-calendar 2>/dev/null || which gnome-calendar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
