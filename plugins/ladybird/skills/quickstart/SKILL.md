# ladybird Plugin

Truly independent web browser

## Commands

### General
- `ladybird self version` — Print ladybird version
- `ladybird _ _` — Passthrough to ladybird CLI

## Usage Examples
- "Run ladybird"
- "Use ladybird to Truly independent web browser"

## Installation

```bash
pip install ladybird
```

## Key Features
- Truly independent web browser
- CLI tool, headless and scriptable
