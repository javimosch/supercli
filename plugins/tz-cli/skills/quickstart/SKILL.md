# tz-cli Plugin
Simple CLI for converting between timezones

## Commands
- `tz-cli <resource> <action>` — Execute tz-cli commands
- `tz-cli _ _` — Passthrough to tz-cli CLI

## Usage
- `tz-cli _ _ <args>` — Run tz-cli with any arguments
