# trans Plugin

CLI tool: trans.

## Commands
- `trans <resource> <action>` — Execute trans commands
- `trans self version` — Print trans version
- `trans _ _` — Passthrough to trans CLI

## Usage Examples
- "trans --help"
- "trans self version"

## Installation
```bash
apt-get install trans 2>/dev/null || which trans
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
