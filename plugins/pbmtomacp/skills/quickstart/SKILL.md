# pbmtomacp Plugin

CLI tool: pbmtomacp.

## Commands
- `pbmtomacp <resource> <action>` — Execute pbmtomacp commands
- `pbmtomacp self version` — Print pbmtomacp version
- `pbmtomacp _ _` — Passthrough to pbmtomacp CLI

## Usage Examples
- "pbmtomacp --help"
- "pbmtomacp self version"

## Installation
```bash
apt-get install pbmtomacp 2>/dev/null || which pbmtomacp
```
