# grim Plugin

Grab images from Wayland compositor in C

## Commands

### Operations
- `grim self version` — Print grim version
- `grim _ _` — Passthrough to grim CLI

## Usage Examples
- `grim --help`
- `grim <args>`

## Installation

```bash
brew install grim
```

## Examples

```bash
grim --version
grim --help
```
