# pnmshear Plugin

CLI tool: pnmshear.

## Commands
- `pnmshear <resource> <action>` — Execute pnmshear commands
- `pnmshear self version` — Print pnmshear version
- `pnmshear _ _` — Passthrough to pnmshear CLI

## Usage Examples
- "pnmshear --help"
- "pnmshear self version"

## Installation
```bash
apt-get install pnmshear 2>/dev/null || which pnmshear
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
