# lzegrep Plugin

CLI tool: lzegrep.

## Commands
- `lzegrep <resource> <action>` — Execute lzegrep commands
- `lzegrep self version` — Print lzegrep version
- `lzegrep _ _` — Passthrough to lzegrep CLI

## Usage Examples
- "lzegrep --help"
- "lzegrep self version"

## Installation
```bash
apt-get install lzegrep 2>/dev/null || which lzegrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
