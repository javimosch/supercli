# dot2gxl Plugin

CLI tool: dot2gxl.

## Commands
- `dot2gxl <resource> <action>` — Execute dot2gxl commands
- `dot2gxl self version` — Print dot2gxl version
- `dot2gxl _ _` — Passthrough to dot2gxl CLI

## Usage Examples
- "dot2gxl --help"
- "dot2gxl self version"

## Installation
```bash
apt-get install dot2gxl 2>/dev/null || which dot2gxl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
