# qtpaths Plugin

CLI tool: qtpaths.

## Commands
- `qtpaths <resource> <action>` — Execute qtpaths commands
- `qtpaths self version` — Print qtpaths version
- `qtpaths _ _` — Passthrough to qtpaths CLI

## Usage Examples
- "qtpaths --help"
- "qtpaths self version"

## Installation
```bash
apt-get install qtpaths 2>/dev/null || which qtpaths
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
