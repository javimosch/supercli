# stream Plugin

CLI tool: stream.

## Commands
- `stream <resource> <action>` — Execute stream commands
- `stream self version` — Print stream version
- `stream _ _` — Passthrough to stream CLI

## Usage Examples
- "stream --help"
- "stream self version"

## Installation
```bash
apt-get install stream 2>/dev/null || which stream
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
