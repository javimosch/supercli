# updmap Plugin

CLI tool: updmap.

## Commands
- `updmap <resource> <action>` — Execute updmap commands
- `updmap self version` — Print updmap version
- `updmap _ _` — Passthrough to updmap CLI

## Usage Examples
- "updmap --help"
- "updmap self version"

## Installation
```bash
apt-get install updmap 2>/dev/null || which updmap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
