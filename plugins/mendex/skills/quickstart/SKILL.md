# mendex Plugin

CLI tool: mendex.

## Commands
- `mendex <resource> <action>` — Execute mendex commands
- `mendex self version` — Print mendex version
- `mendex _ _` — Passthrough to mendex CLI

## Usage Examples
- "mendex --help"
- "mendex self version"

## Installation
```bash
apt-get install mendex 2>/dev/null || which mendex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
