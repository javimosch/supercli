# xflock4 Plugin

CLI tool: xflock4.

## Commands
- `xflock4 <resource> <action>` — Execute xflock4 commands
- `xflock4 self version` — Print xflock4 version
- `xflock4 _ _` — Passthrough to xflock4 CLI

## Usage Examples
- "xflock4 --help"
- "xflock4 self version"

## Installation
```bash
apt-get install xflock4 2>/dev/null || which xflock4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
