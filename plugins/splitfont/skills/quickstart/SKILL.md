# splitfont Plugin

CLI tool: splitfont.

## Commands
- `splitfont <resource> <action>` — Execute splitfont commands
- `splitfont self version` — Print splitfont version
- `splitfont _ _` — Passthrough to splitfont CLI

## Usage Examples
- "splitfont --help"
- "splitfont self version"

## Installation
```bash
apt-get install splitfont 2>/dev/null || which splitfont
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
