# drgns Plugin
Python static analysis for code complexity hotspot detection

## Commands
- `drgns <resource> <action>` — Execute drgns commands
- `drgns _ _` — Passthrough to drgns CLI

## Usage
- `drgns _ _ <args>` — Run drgns with any arguments
