# zfgrep Plugin

CLI tool: zfgrep.

## Commands
- `zfgrep <resource> <action>` — Execute zfgrep commands
- `zfgrep self version` — Print zfgrep version
- `zfgrep _ _` — Passthrough to zfgrep CLI

## Usage Examples
- "zfgrep --help"
- "zfgrep self version"

## Installation
```bash
apt-get install zfgrep 2>/dev/null || which zfgrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
