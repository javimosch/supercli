# usermod Plugin

CLI tool: usermod.

## Commands
- `usermod <resource> <action>` — Execute usermod commands
- `usermod self version` — Print usermod version
- `usermod _ _` — Passthrough to usermod CLI

## Usage Examples
- "usermod --help"
- "usermod self version"

## Installation
```bash
apt-get install usermod 2>/dev/null || which usermod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
