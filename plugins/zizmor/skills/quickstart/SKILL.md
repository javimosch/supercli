# zizmor Plugin

Static analysis for GitHub Actions

## Commands
- `zizmor <resource> <action>` — Execute zizmor commands
- `zizmor self version` — Print zizmor version
- `zizmor _ _` — Passthrough to zizmor CLI

## Installation

```bash
pip install zizmor
```
