# vmwarectrl Plugin

CLI tool: vmwarectrl.

## Commands
- `vmwarectrl <resource> <action>` — Execute vmwarectrl commands
- `vmwarectrl self version` — Print vmwarectrl version
- `vmwarectrl _ _` — Passthrough to vmwarectrl CLI

## Usage Examples
- "vmwarectrl --help"
- "vmwarectrl self version"

## Installation
```bash
apt-get install vmwarectrl 2>/dev/null || which vmwarectrl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
