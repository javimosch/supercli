# orca Plugin

CLI tool: orca.

## Commands
- `orca <resource> <action>` — Execute orca commands
- `orca self version` — Print orca version
- `orca _ _` — Passthrough to orca CLI

## Usage Examples
- "orca --help"
- "orca self version"

## Installation
```bash
apt-get install orca 2>/dev/null || which orca
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
