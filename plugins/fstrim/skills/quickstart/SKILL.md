# fstrim Plugin

CLI tool: fstrim.

## Commands
- `fstrim <resource> <action>` — Execute fstrim commands
- `fstrim self version` — Print fstrim version
- `fstrim _ _` — Passthrough to fstrim CLI

## Usage Examples
- "fstrim --help"
- "fstrim self version"

## Installation
```bash
apt-get install fstrim 2>/dev/null || which fstrim
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
