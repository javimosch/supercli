# open-r1 Plugin

Fully open reproduction of DeepSeek-R1

## Commands

### General
- `open-r1 self version` — Print open-r1 version
- `open-r1 _ _` — Passthrough to open-r1 CLI

## Usage Examples
- "Run open-r1"
- "Use open-r1 to Fully open reproduction of DeepSeek-R1"

## Installation

```bash
pip install open-r1
```

## Key Features
- Fully open reproduction of DeepSeek-R1
- CLI tool, headless and scriptable
