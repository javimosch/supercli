# aud-convert Plugin
Batch convert audio files between formats via CLI

## Commands
- `aud-convert <resource> <action>` — Execute aud-convert commands
- `aud-convert _ _` — Passthrough to aud-convert CLI

## Usage
- `aud-convert _ _ <args>` — Run aud-convert with any arguments
