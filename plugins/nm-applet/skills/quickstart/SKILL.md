# nm-applet Plugin

CLI tool: nm-applet.

## Commands
- `nm-applet <resource> <action>` — Execute nm-applet commands
- `nm-applet self version` — Print nm-applet version
- `nm-applet _ _` — Passthrough to nm-applet CLI

## Usage Examples
- "nm-applet --help"
- "nm-applet self version"

## Installation
```bash
apt-get install nm-applet 2>/dev/null || which nm-applet
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
