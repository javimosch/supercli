# gdialog Plugin

CLI tool: gdialog.

## Commands
- `gdialog <resource> <action>` — Execute gdialog commands
- `gdialog self version` — Print gdialog version
- `gdialog _ _` — Passthrough to gdialog CLI

## Usage Examples
- "gdialog --help"
- "gdialog self version"

## Installation
```bash
apt-get install gdialog 2>/dev/null || which gdialog
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
