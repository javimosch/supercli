# ocspclnt Plugin

CLI tool: ocspclnt.

## Commands
- `ocspclnt <resource> <action>` — Execute ocspclnt commands
- `ocspclnt self version` — Print ocspclnt version
- `ocspclnt _ _` — Passthrough to ocspclnt CLI

## Usage Examples
- "ocspclnt --help"
- "ocspclnt self version"

## Installation
```bash
apt-get install ocspclnt 2>/dev/null || which ocspclnt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
