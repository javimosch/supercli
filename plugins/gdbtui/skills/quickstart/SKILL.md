# gdbtui Plugin

CLI tool: gdbtui.

## Commands
- `gdbtui <resource> <action>` — Execute gdbtui commands
- `gdbtui self version` — Print gdbtui version
- `gdbtui _ _` — Passthrough to gdbtui CLI

## Usage Examples
- "gdbtui --help"
- "gdbtui self version"

## Installation
```bash
apt-get install gdbtui 2>/dev/null || which gdbtui
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
