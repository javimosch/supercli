# libnetcfg Plugin

CLI tool: libnetcfg.

## Commands
- `libnetcfg <resource> <action>` — Execute libnetcfg commands
- `libnetcfg self version` — Print libnetcfg version
- `libnetcfg _ _` — Passthrough to libnetcfg CLI

## Usage Examples
- "libnetcfg --help"
- "libnetcfg self version"

## Installation
```bash
apt-get install libnetcfg 2>/dev/null || which libnetcfg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
