# scriptlive Plugin

CLI tool: scriptlive.

## Commands
- `scriptlive <resource> <action>` — Execute scriptlive commands
- `scriptlive self version` — Print scriptlive version
- `scriptlive _ _` — Passthrough to scriptlive CLI

## Usage Examples
- "scriptlive --help"
- "scriptlive self version"

## Installation
```bash
apt-get install scriptlive 2>/dev/null || which scriptlive
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
