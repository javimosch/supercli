# gooey Plugin

Gooey is a hybrid immediate/retained mode UI framework designed for building fast, GPU-rendered applications on macOS/Metal, WebAssembly/WebGPU, and Wayland/Vulkan

## Commands

### General

- `gooey _ _` — Passthrough to gooey CLI
