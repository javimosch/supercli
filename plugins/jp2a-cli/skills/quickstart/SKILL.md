# jp2a-cli Plugin
Convert JPEG images to colored ASCII art in terminal

## Commands
- `jp2a-cli <resource> <action>` — Execute jp2a-cli commands
- `jp2a-cli _ _` — Passthrough to jp2a-cli CLI

## Usage
- `jp2a-cli _ _ <args>` — Run jp2a-cli with any arguments
