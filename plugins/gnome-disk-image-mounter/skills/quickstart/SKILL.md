# gnome-disk-image-mounter Plugin

CLI tool: gnome-disk-image-mounter.

## Commands
- `gnome-disk-image-mounter <resource> <action>` — Execute gnome-disk-image-mounter commands
- `gnome-disk-image-mounter self version` — Print gnome-disk-image-mounter version
- `gnome-disk-image-mounter _ _` — Passthrough to gnome-disk-image-mounter CLI

## Usage Examples
- "gnome-disk-image-mounter --help"
- "gnome-disk-image-mounter self version"

## Installation
```bash
apt-get install gnome-disk-image-mounter 2>/dev/null || which gnome-disk-image-mounter
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
