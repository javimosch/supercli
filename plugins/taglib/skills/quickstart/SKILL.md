taglib — audio metadata library CLI. Read/write ID3v1, ID3v2, APE, Xiph comments in audio files.

## Commands
- `taglib <resource> <action>` — Execute taglib commands
- `taglib taglib run` — taglib — audio metadata library CLI. Read/write ID3v1, ID3v2, APE, Xiph comments in audio files.
