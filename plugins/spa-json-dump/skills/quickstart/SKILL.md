# spa-json-dump Plugin

CLI tool: spa-json-dump.

## Commands
- `spa-json-dump <resource> <action>` — Execute spa-json-dump commands
- `spa-json-dump self version` — Print spa-json-dump version
- `spa-json-dump _ _` — Passthrough to spa-json-dump CLI

## Usage Examples
- "spa-json-dump --help"
- "spa-json-dump self version"

## Installation
```bash
apt-get install spa-json-dump 2>/dev/null || which spa-json-dump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
