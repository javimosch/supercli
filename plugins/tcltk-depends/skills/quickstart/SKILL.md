# tcltk-depends Plugin

CLI tool: tcltk-depends.

## Commands
- `tcltk-depends <resource> <action>` — Execute tcltk-depends commands
- `tcltk-depends self version` — Print tcltk-depends version
- `tcltk-depends _ _` — Passthrough to tcltk-depends CLI

## Usage Examples
- "tcltk-depends --help"
- "tcltk-depends self version"

## Installation

```bash
apt-get install tcltk-depends 2>/dev/null || which tcltk-depends
```
