# minipostiz Plugin

CLI tool: minipostiz.

## Commands
- `minipostiz <resource> <action>` — Execute minipostiz commands
- `minipostiz self version` — Print minipostiz version
- `minipostiz _ _` — Passthrough to minipostiz CLI

## Usage Examples
- "minipostiz --help"
- "minipostiz self version"

## Installation
```bash
apt-get install minipostiz 2>/dev/null || which minipostiz
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
