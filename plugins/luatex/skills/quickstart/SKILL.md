# luatex Plugin

CLI tool: luatex.

## Commands
- `luatex <resource> <action>` — Execute luatex commands
- `luatex self version` — Print luatex version
- `luatex _ _` — Passthrough to luatex CLI

## Usage Examples
- "luatex --help"
- "luatex self version"

## Installation
```bash
apt-get install luatex 2>/dev/null || which luatex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
