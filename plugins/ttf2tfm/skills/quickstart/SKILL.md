# ttf2tfm Plugin

CLI tool: ttf2tfm.

## Commands
- `ttf2tfm <resource> <action>` — Execute ttf2tfm commands
- `ttf2tfm self version` — Print ttf2tfm version
- `ttf2tfm _ _` — Passthrough to ttf2tfm CLI

## Usage Examples
- "ttf2tfm --help"
- "ttf2tfm self version"

## Installation
```bash
apt-get install ttf2tfm 2>/dev/null || which ttf2tfm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
