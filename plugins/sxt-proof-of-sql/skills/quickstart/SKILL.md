# sxt-proof-of-sql Plugin

Space and Time | Proof of SQL

## Commands
- `sxt-proof-of-sql <resource> <action>` — Execute sxt-proof-of-sql commands
- `sxt-proof-of-sql self version` — Print sxt-proof-of-sql version
- `sxt-proof-of-sql _ _` — Passthrough to sxt-proof-of-sql CLI

## Installation

```bash
pip install sxt-proof-of-sql
```
