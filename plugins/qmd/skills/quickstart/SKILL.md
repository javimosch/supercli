# qmd Plugin

mini cli search engine for your docs, knowledge bases, meeting notes, whatever. Tracking current sota approaches while being all local

## Commands

### General
- `qmd self version` — Print qmd version
- `qmd _ _` — Passthrough to qmd CLI

## Usage Examples
- "Run qmd"
- "Use qmd to mini cli search engine for your docs, knowledge bases, meeti"

## Installation

```bash
pip install qmd
```

## Key Features
- mini cli search engine for your docs, knowledge bases, meeting notes, whatever. Tracking current sot
- CLI tool, headless and scriptable
