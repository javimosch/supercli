# mdbook-mermaid Plugin
Mermaid diagram preprocessor for mdBook projects

## Commands
- `mdbook-mermaid <resource> <action>` — Execute mdbook-mermaid commands
- `mdbook-mermaid _ _` — Passthrough to mdbook-mermaid CLI

## Usage
- `mdbook-mermaid _ _ <args>` — Run mdbook-mermaid with any arguments
