# Sports Skills — Live Sports Data & Prediction Markets

Open-source agent skills for live sports data and prediction markets. Zero API keys needed.

## Installation
```bash
git clone https://github.com/machina-sports/sports-skills.git
sc skills teach sports-skills:quickstart
```

## What's Included
- **Football** — Live match data, standings, fixtures, player stats
- **F1** — Race results, driver standings, constructor standings, calendar
- **Kalshi** — Prediction market queries and event data
- **Polymarket** — Prediction market data and outcomes

## Usage Prompts
- "What are today's football fixtures in the Premier League?"
- "Show me the current F1 driver standings"
- "What's the probability of the Fed cutting rates in September on Kalshi?"
- "Check Polymarket for the US election prediction"
