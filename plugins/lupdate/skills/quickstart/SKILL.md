# lupdate Plugin

CLI tool: lupdate.

## Commands
- `lupdate <resource> <action>` — Execute lupdate commands
- `lupdate self version` — Print lupdate version
- `lupdate _ _` — Passthrough to lupdate CLI

## Usage Examples
- "lupdate --help"
- "lupdate self version"

## Installation
```bash
apt-get install lupdate 2>/dev/null || which lupdate
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
