# expiry Plugin

CLI tool: expiry.

## Commands
- `expiry <resource> <action>` — Execute expiry commands
- `expiry self version` — Print expiry version
- `expiry _ _` — Passthrough to expiry CLI

## Usage Examples
- "expiry --help"
- "expiry self version"

## Installation
```bash
apt-get install expiry 2>/dev/null || which expiry
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
