# tokio Plugin

Tokio — async runtime for Rust applications

## Commands
- `tokio <resource> <action>` — Execute tokio commands
- `tokio self version` — Version

## Installation

```bash
cargo install tokio
Verify: tokio --version
```

## Commands

### `sc tokio self version`

Version


## SuperCLI

```bash
sc tokio _ _ --help
sc plugins learn tokio
```
