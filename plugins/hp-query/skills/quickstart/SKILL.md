# hp-query Plugin

CLI tool: hp-query.

## Commands
- `hp-query <resource> <action>` — Execute hp-query commands
- `hp-query self version` — Print hp-query version
- `hp-query _ _` — Passthrough to hp-query CLI

## Usage Examples
- "hp-query --help"
- "hp-query self version"

## Installation
```bash
apt-get install hp-query 2>/dev/null || which hp-query
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
