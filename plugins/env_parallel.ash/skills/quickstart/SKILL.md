# env_parallel.ash Plugin

CLI tool: env_parallel.ash.

## Commands
- `env_parallel.ash <resource> <action>` — Execute env_parallel.ash commands
- `env_parallel.ash self version` — Print env_parallel.ash version
- `env_parallel.ash _ _` — Passthrough to env_parallel.ash CLI

## Usage Examples
- "env_parallel.ash --help"
- "env_parallel.ash self version"

