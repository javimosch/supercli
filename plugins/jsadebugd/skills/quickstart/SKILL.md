# jsadebugd Plugin

CLI tool: jsadebugd.

## Commands
- `jsadebugd <resource> <action>` — Execute jsadebugd commands
- `jsadebugd self version` — Print jsadebugd version
- `jsadebugd _ _` — Passthrough to jsadebugd CLI

## Usage Examples
- "jsadebugd --help"
- "jsadebugd self version"

## Installation
```bash
apt-get install jsadebugd 2>/dev/null || which jsadebugd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
