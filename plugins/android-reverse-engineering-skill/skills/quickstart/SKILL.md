# android-reverse-engineering-skill Plugin

Claude Code skill to support Android app's reverse engineering

## Commands

### General
- `android-reverse-engineering-skill self version` — Print android-reverse-engineering-skill version
- `android-reverse-engineering-skill _ _` — Passthrough to android-reverse-engineering-skill CLI
