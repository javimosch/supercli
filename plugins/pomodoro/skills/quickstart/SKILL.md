# pomodoro Plugin

ESP32-based focus timer with an epaper display and rotary dial

## Commands

### General
- `pomodoro self version` — Print pomodoro version
- `pomodoro _ _` — Passthrough to pomodoro CLI

## Installation

```bash
pip install pomodoro
```

## Key Features
- ESP32-based focus timer with an epaper display and rotary dial
- CLI tool, headless and scriptable
