# mpicc Plugin

CLI tool: mpicc.

## Commands
- `mpicc <resource> <action>` — Execute mpicc commands
- `mpicc self version` — Print mpicc version
- `mpicc _ _` — Passthrough to mpicc CLI

## Usage Examples
- "mpicc --help"
- "mpicc self version"

## Installation
```bash
apt-get install mpicc 2>/dev/null || which mpicc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
