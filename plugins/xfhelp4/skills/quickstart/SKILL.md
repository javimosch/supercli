# xfhelp4 Plugin

CLI tool: xfhelp4.

## Commands
- `xfhelp4 <resource> <action>` — Execute xfhelp4 commands
- `xfhelp4 self version` — Print xfhelp4 version
- `xfhelp4 _ _` — Passthrough to xfhelp4 CLI

## Usage Examples
- "xfhelp4 --help"
- "xfhelp4 self version"

## Installation
```bash
apt-get install xfhelp4 2>/dev/null || which xfhelp4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
