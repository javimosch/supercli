# pi3topbm Plugin

CLI tool: pi3topbm.

## Commands
- `pi3topbm <resource> <action>` — Execute pi3topbm commands
- `pi3topbm self version` — Print pi3topbm version
- `pi3topbm _ _` — Passthrough to pi3topbm CLI

## Usage Examples
- "pi3topbm --help"
- "pi3topbm self version"

## Installation
```bash
apt-get install pi3topbm 2>/dev/null || which pi3topbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
