# RustTraining Plugin

Beginner, advanced, expert level Rust training material

## Commands

### General
- `RustTraining self version` — Print RustTraining version
- `RustTraining _ _` — Passthrough to rusttraining CLI

## Usage Examples
- "Run RustTraining"
- "Use rusttraining to Beginner, advanced, expert level Rust training material"

## Installation

```bash
pip install rusttraining
```

## Key Features
- Beginner, advanced, expert level Rust training material
- CLI tool, headless and scriptable
