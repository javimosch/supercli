# paradedb Plugin

Simple, Elastic-quality search for Postgres

## Commands
- `paradedb <resource> <action>` — Execute paradedb commands
- `paradedb self version` — Print paradedb version
- `paradedb _ _` — Passthrough to paradedb CLI

## Installation

```bash
pip install paradedb
```
