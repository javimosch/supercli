# e2scrub Plugin

CLI tool: e2scrub.

## Commands
- `e2scrub <resource> <action>` — Execute e2scrub commands
- `e2scrub self version` — Print e2scrub version
- `e2scrub _ _` — Passthrough to e2scrub CLI

## Usage Examples
- "e2scrub --help"
- "e2scrub self version"

## Installation
```bash
apt-get install e2scrub 2>/dev/null || which e2scrub
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
