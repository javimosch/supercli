# grub-mklayout Plugin

CLI tool: grub-mklayout.

## Commands
- `grub-mklayout <resource> <action>` — Execute grub-mklayout commands
- `grub-mklayout self version` — Print grub-mklayout version
- `grub-mklayout _ _` — Passthrough to grub-mklayout CLI

## Usage Examples
- "grub-mklayout --help"
- "grub-mklayout self version"

## Installation
```bash
apt-get install grub-mklayout 2>/dev/null || which grub-mklayout
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
