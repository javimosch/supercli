# iceauth Plugin

CLI tool: iceauth.

## Commands
- `iceauth <resource> <action>` — Execute iceauth commands
- `iceauth self version` — Print iceauth version
- `iceauth _ _` — Passthrough to iceauth CLI

## Usage Examples
- "iceauth --help"
- "iceauth self version"

## Installation
```bash
apt-get install iceauth 2>/dev/null || which iceauth
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
