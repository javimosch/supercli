# tload Plugin

CLI tool: tload.

## Commands
- `tload <resource> <action>` — Execute tload commands
- `tload self version` — Print tload version
- `tload _ _` — Passthrough to tload CLI

## Usage Examples
- "tload --help"
- "tload self version"

## Installation
```bash
apt-get install tload 2>/dev/null || which tload
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
