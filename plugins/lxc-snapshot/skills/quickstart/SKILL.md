# lxc-snapshot Plugin

CLI tool: lxc-snapshot.

## Commands
- `lxc-snapshot <resource> <action>` — Execute lxc-snapshot commands
- `lxc-snapshot self version` — Print lxc-snapshot version
- `lxc-snapshot _ _` — Passthrough to lxc-snapshot CLI

## Usage Examples
- "lxc-snapshot --help"
- "lxc-snapshot self version"

## Installation
```bash
apt-get install lxc-snapshot 2>/dev/null || which lxc-snapshot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
