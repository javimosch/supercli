# ppmtv Plugin

CLI tool: ppmtv.

## Commands
- `ppmtv <resource> <action>` — Execute ppmtv commands
- `ppmtv self version` — Print ppmtv version
- `ppmtv _ _` — Passthrough to ppmtv CLI

## Usage Examples
- "ppmtv --help"
- "ppmtv self version"

## Installation
```bash
apt-get install ppmtv 2>/dev/null || which ppmtv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
