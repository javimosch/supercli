# Launcher Plugin

Firmware Launcher for ESP32 boards like: M5Stack, Lilygo, Marauder and CYD devices.

## Commands

### General
- `Launcher self version` — Print Launcher version
- `Launcher _ _` — Passthrough to launcher CLI
