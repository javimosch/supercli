# ahasend-cli Plugin
Domain and email management CLI.
## Commands
- `ahasend-cli _ _` — Passthrough to ahasend-cli CLI
## Installation
```bash
npm install -g ahasend-cli
```
## Examples
```bash
ahasend-cli --json
```
## Key Features
- **Domain management** — CLI domain operations
- **JSON output** — Structured data export
- **Pipeline-ready** — Automation-friendly
