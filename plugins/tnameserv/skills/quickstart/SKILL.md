# tnameserv Plugin

CLI tool: tnameserv.

## Commands
- `tnameserv <resource> <action>` — Execute tnameserv commands
- `tnameserv self version` — Print tnameserv version
- `tnameserv _ _` — Passthrough to tnameserv CLI

## Usage Examples
- "tnameserv --help"
- "tnameserv self version"

## Installation
```bash
apt-get install tnameserv 2>/dev/null || which tnameserv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
