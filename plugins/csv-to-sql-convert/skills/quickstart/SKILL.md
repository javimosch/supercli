# csv-to-sql-convert Plugin
Simple script for piping CSV files into SQL INSERT statements

## Commands
- `csv-to-sql-convert <resource> <action>` — Execute csv-to-sql-convert commands
- `csv-to-sql-convert _ _` — Passthrough to csv-to-sql-convert CLI

## Usage
- `csv-to-sql-convert _ _ <args>` — Run csv-to-sql-convert with any arguments
