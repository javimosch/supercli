# MicroManipulatorStepper Plugin

A sub-micrometer 3D motion control plattform.

- `MicroManipulatorStepper self version` — Print MicroManipulatorStepper version
- `MicroManipulatorStepper _ _` — Passthrough to micromanipulatorstepper CLI
