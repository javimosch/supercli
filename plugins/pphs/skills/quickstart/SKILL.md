# pphs Plugin

CLI tool: pphs.

## Commands
- `pphs <resource> <action>` — Execute pphs commands
- `pphs self version` — Print pphs version
- `pphs _ _` — Passthrough to pphs CLI

## Usage Examples
- "pphs --help"
- "pphs self version"

## Installation
```bash
apt-get install pphs 2>/dev/null || which pphs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
