# espeak-ng Plugin

Open-source speech synthesizer command-line tool.

## Commands
- `espeak-ng <resource> <action>` — Execute espeak-ng commands
- `espeak-ng _ _` — Passthrough to espeak-ng CLI

## Usage Examples
- "espeak-ng --help"

## Installation
```bash
apt-get install espeak-ng
```

## Key Features
- CLI-based system tool
- Scriptable and automatable
