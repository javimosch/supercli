# zsh-bench Plugin
Benchmark your ZSH configuration performance

## Commands
- `zsh-bench <resource> <action>` — Execute zsh-bench commands
- `zsh-bench _ _` — Passthrough to zsh-bench CLI

## Usage
- `zsh-bench _ _ <args>` — Run zsh-bench with any arguments
