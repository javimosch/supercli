# Agent Skills MD — Awesome Agent Skills Directory

Curated awesome list of reusable SKILL.md files for AI coding assistants. Find skills organized by category for Codex, Claude Code, Cursor, and other platforms.

## Installation
```bash
git clone https://github.com/futantan/agent-skills.md.git
sc skills teach agent-skills-md:quickstart
```

## Categories
- Frontend, Backend, Fullstack development
- DevOps, Infrastructure, Deployment
- Database, Data Engineering
- Testing, QA, CI/CD
- Security, Authentication
- API Development, Design
- Performance Optimization
- And more...

## Usage
Browse the collection to find the right skill for your current task. Each entry links to the original SKILL.md file that you can load into your AI agent.
