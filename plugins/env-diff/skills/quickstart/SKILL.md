# env-diff Plugin

CLI tool: env-diff.

## Commands
- `env-diff <resource> <action>` — Execute env-diff commands
- `env-diff self version` — Print env-diff version
- `env-diff _ _` — Passthrough to env-diff CLI

## Usage Examples
- "env-diff --help"
- "env-diff self version"

## Installation
```bash
apt-get install env-diff 2>/dev/null || which env-diff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
