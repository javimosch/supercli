# rungs Plugin

CLI tool: rungs.

## Commands
- `rungs <resource> <action>` — Execute rungs commands
- `rungs self version` — Print rungs version
- `rungs _ _` — Passthrough to rungs CLI

## Usage Examples
- "rungs --help"
- "rungs self version"

## Installation
```bash
apt-get install rungs 2>/dev/null || which rungs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
