# xfce4-notifyd-config Plugin

CLI tool: xfce4-notifyd-config.

## Commands
- `xfce4-notifyd-config <resource> <action>` — Execute xfce4-notifyd-config commands
- `xfce4-notifyd-config self version` — Print xfce4-notifyd-config version
- `xfce4-notifyd-config _ _` — Passthrough to xfce4-notifyd-config CLI

## Usage Examples
- "xfce4-notifyd-config --help"
- "xfce4-notifyd-config self version"

apt-get install xfce4-notifyd-config 2>/dev/null || which xfce4-notifyd-config
