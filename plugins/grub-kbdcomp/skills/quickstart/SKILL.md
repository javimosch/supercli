# grub-kbdcomp Plugin

CLI tool: grub-kbdcomp.

## Commands
- `grub-kbdcomp <resource> <action>` — Execute grub-kbdcomp commands
- `grub-kbdcomp self version` — Print grub-kbdcomp version
- `grub-kbdcomp _ _` — Passthrough to grub-kbdcomp CLI

## Usage Examples
- "grub-kbdcomp --help"
- "grub-kbdcomp self version"

## Installation
```bash
apt-get install grub-kbdcomp 2>/dev/null || which grub-kbdcomp
```
