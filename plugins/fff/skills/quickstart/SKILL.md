# fff Plugin

The fastest and the most accurate file search toolkit for AI agents, Neovim, Rust, C, and NodeJS

## Commands
- `fff <resource> <action>` — Execute fff commands
- `fff self version` — Print fff version
- `fff _ _` — Passthrough to fff CLI

## Installation

```bash
pip install fff
```
