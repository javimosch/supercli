# temp-conv Plugin
Multi-unit temperature converter for Kelvin Celsius Fahrenheit

## Commands
- `temp-conv <resource> <action>` — Execute temp-conv commands
- `temp-conv _ _` — Passthrough to temp-conv CLI

## Usage
- `temp-conv _ _ <args>` — Run temp-conv with any arguments
