# tomlq Plugin
Process TOML files with jq-like query syntax

## Commands
- `tomlq <resource> <action>` — Execute tomlq commands
- `tomlq _ _` — Passthrough to tomlq CLI

## Usage
- `tomlq _ _ <args>` — Run tomlq with any arguments
