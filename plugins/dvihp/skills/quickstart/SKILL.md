# dvihp Plugin

CLI tool: dvihp.

## Commands
- `dvihp <resource> <action>` — Execute dvihp commands
- `dvihp self version` — Print dvihp version
- `dvihp _ _` — Passthrough to dvihp CLI

## Usage Examples
- "dvihp --help"
- "dvihp self version"

## Installation
```bash
apt-get install dvihp 2>/dev/null || which dvihp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
