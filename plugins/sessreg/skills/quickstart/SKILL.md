# sessreg Plugin

CLI tool: sessreg.

## Commands
- `sessreg <resource> <action>` — Execute sessreg commands
- `sessreg self version` — Print sessreg version
- `sessreg _ _` — Passthrough to sessreg CLI

## Usage Examples
- "sessreg --help"
- "sessreg self version"

## Installation
```bash
apt-get install sessreg 2>/dev/null || which sessreg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
