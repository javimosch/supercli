# scli Plugin

CLI tool: scli.

## Commands
- `scli <resource> <action>` — Execute scli commands
- `scli self version` — Print scli version
- `scli _ _` — Passthrough to scli CLI

## Usage Examples
- "scli --help"
- "scli self version"

## Installation
```bash
apt-get install scli 2>/dev/null || which scli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
