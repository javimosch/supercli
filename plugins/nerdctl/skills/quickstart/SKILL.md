# nerdctl
nerdctl — Docker-compatible CLI for containerd. Same interface as docker but for containerd.

## Commands
- `nerdctl <resource> <action>` — Execute nerdctl commands
- `nerdctl _ _` — Passthrough to nerdctl CLI
