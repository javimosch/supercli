# preconv Plugin

CLI tool: preconv.

## Commands
- `preconv <resource> <action>` — Execute preconv commands
- `preconv self version` — Print preconv version
- `preconv _ _` — Passthrough to preconv CLI

## Usage Examples
- "preconv --help"
- "preconv self version"

## Installation
```bash
apt-get install preconv 2>/dev/null || which preconv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
