# xeokit-convert Plugin
Convert various 3D and BIM formats including IFC GLB STL to XKT

## Commands
- `xeokit-convert <resource> <action>` — Execute xeokit-convert commands
- `xeokit-convert _ _` — Passthrough to xeokit-convert CLI

## Usage
- `xeokit-convert _ _ <args>` — Run xeokit-convert with any arguments
