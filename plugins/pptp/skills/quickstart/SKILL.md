# pptp Plugin

CLI tool: pptp.

## Commands
- `pptp <resource> <action>` — Execute pptp commands
- `pptp self version` — Print pptp version
- `pptp _ _` — Passthrough to pptp CLI

## Usage Examples
- "pptp --help"
- "pptp self version"

## Installation
```bash
apt-get install pptp 2>/dev/null || which pptp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
