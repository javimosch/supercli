# pnminterp Plugin

CLI tool: pnminterp.

## Commands
- `pnminterp <resource> <action>` — Execute pnminterp commands
- `pnminterp self version` — Print pnminterp version
- `pnminterp _ _` — Passthrough to pnminterp CLI

## Usage Examples
- "pnminterp --help"
- "pnminterp self version"

## Installation
```bash
apt-get install pnminterp 2>/dev/null || which pnminterp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
