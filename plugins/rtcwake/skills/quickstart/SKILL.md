# rtcwake Plugin

CLI tool: rtcwake.

## Commands
- `rtcwake <resource> <action>` — Execute rtcwake commands
- `rtcwake self version` — Print rtcwake version
- `rtcwake _ _` — Passthrough to rtcwake CLI

## Usage Examples
- "rtcwake --help"
- "rtcwake self version"

## Installation
```bash
apt-get install rtcwake 2>/dev/null || which rtcwake
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
