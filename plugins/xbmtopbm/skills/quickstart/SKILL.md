# xbmtopbm Plugin

CLI tool: xbmtopbm.

## Commands
- `xbmtopbm <resource> <action>` — Execute xbmtopbm commands
- `xbmtopbm self version` — Print xbmtopbm version
- `xbmtopbm _ _` — Passthrough to xbmtopbm CLI

## Usage Examples
- "xbmtopbm --help"
- "xbmtopbm self version"

```bash
apt-get install xbmtopbm 2>/dev/null || which xbmtopbm
```
