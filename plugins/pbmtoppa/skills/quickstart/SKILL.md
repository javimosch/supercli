# pbmtoppa Plugin

CLI tool: pbmtoppa.

## Commands
- `pbmtoppa <resource> <action>` — Execute pbmtoppa commands
- `pbmtoppa self version` — Print pbmtoppa version
- `pbmtoppa _ _` — Passthrough to pbmtoppa CLI

## Usage Examples
- "pbmtoppa --help"
- "pbmtoppa self version"

## Installation
```bash
apt-get install pbmtoppa 2>/dev/null || which pbmtoppa
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
