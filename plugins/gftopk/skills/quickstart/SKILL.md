# gftopk Plugin

CLI tool: gftopk.

## Commands
- `gftopk <resource> <action>` — Execute gftopk commands
- `gftopk self version` — Print gftopk version
- `gftopk _ _` — Passthrough to gftopk CLI

## Usage Examples
- "gftopk --help"
- "gftopk self version"

## Installation
```bash
apt-get install gftopk 2>/dev/null || which gftopk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
