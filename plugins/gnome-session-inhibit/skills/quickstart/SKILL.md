# gnome-session-inhibit Plugin

CLI tool: gnome-session-inhibit.

## Commands
- `gnome-session-inhibit <resource> <action>` — Execute gnome-session-inhibit commands
- `gnome-session-inhibit self version` — Print gnome-session-inhibit version
- `gnome-session-inhibit _ _` — Passthrough to gnome-session-inhibit CLI

## Usage Examples
- "gnome-session-inhibit --help"
- "gnome-session-inhibit self version"

```bash
apt-get install gnome-session-inhibit 2>/dev/null || which gnome-session-inhibit
```
