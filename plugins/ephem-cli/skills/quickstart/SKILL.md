# ephem-cli Plugin
Calculate planetary positions and rise/set times

## Commands
- `ephem-cli <resource> <action>` — Execute ephem-cli commands
- `ephem-cli _ _` — Passthrough to ephem-cli CLI

## Usage
- `ephem-cli _ _ <args>` — Run ephem-cli with any arguments
