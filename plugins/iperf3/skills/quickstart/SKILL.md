# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `iperf3 <resource> <action>` — Execute iperf3 commands
- `iperf3 self version` — Print iperf3 version
- `iperf3 measure server` — Start iperf3 server
- `iperf3 measure client` — Run bandwidth test (client)
- `iperf3 _ _` — Passthrough to iperf3 CLI
