# ulockmgr_server Plugin

CLI tool: ulockmgr_server.

- `ulockmgr_server <resource> <action>` — Execute ulockmgr_server commands
- `ulockmgr_server self version` — Print ulockmgr_server version
- `ulockmgr_server _ _` — Passthrough to ulockmgr_server CLI
