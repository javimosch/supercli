# astroterm Plugin
Real-time celestial planetarium for the terminal

## Commands
- `astroterm <resource> <action>` — Execute astroterm commands
- `astroterm _ _` — Passthrough to astroterm CLI

## Usage
- `astroterm _ _ <args>` — Run astroterm with any arguments
