# img2sixel Plugin
Convert images to DEC SIXEL graphics format

## Commands
- `img2sixel <resource> <action>` — Execute img2sixel commands
- `img2sixel _ _` — Passthrough to img2sixel CLI

## Usage
- `img2sixel _ _ <args>` — Run img2sixel with any arguments
