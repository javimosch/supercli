# NuvioMobile Plugin

Official Nuvio Mobile Repository

## Commands

### General
- `NuvioMobile self version` — Print NuvioMobile version
- `NuvioMobile _ _` — Passthrough to nuviomobile CLI

## Usage Examples
- "Run NuvioMobile"
- "Use nuviomobile to Official Nuvio Mobile Repository"

## Installation

```bash
pip install nuviomobile
```

## Key Features
- Official Nuvio Mobile Repository
- CLI tool, headless and scriptable
