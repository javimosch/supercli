# graphql-cli Plugin
Generate Markdown docs from GraphQL schemas

## Commands
- `graphql-cli <resource> <action>` — Execute graphql-cli commands
- `graphql-cli _ _` — Passthrough to graphql-cli CLI

## Usage
- `graphql-cli _ _ <args>` — Run graphql-markdown with any arguments
