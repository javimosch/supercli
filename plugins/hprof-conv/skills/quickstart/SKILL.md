# hprof-conv Plugin

CLI tool: hprof-conv.

## Commands
- `hprof-conv <resource> <action>` — Execute hprof-conv commands
- `hprof-conv self version` — Print hprof-conv version
- `hprof-conv _ _` — Passthrough to hprof-conv CLI

## Usage Examples
- "hprof-conv --help"
- "hprof-conv self version"

## Installation
```bash
apt-get install hprof-conv 2>/dev/null || which hprof-conv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
