# vim.tiny Plugin

CLI tool: vim.tiny.

## Commands
- `vim.tiny <resource> <action>` — Execute vim.tiny commands
- `vim.tiny self version` — Print vim.tiny version
- `vim.tiny _ _` — Passthrough to vim.tiny CLI

## Usage Examples
- "vim.tiny --help"
- "vim.tiny self version"

## Installation
```bash
apt-get install vim.tiny 2>/dev/null || which vim.tiny
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
