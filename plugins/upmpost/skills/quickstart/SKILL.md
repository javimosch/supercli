# upmpost Plugin

CLI tool: upmpost.

## Commands
- `upmpost <resource> <action>` — Execute upmpost commands
- `upmpost self version` — Print upmpost version
- `upmpost _ _` — Passthrough to upmpost CLI

## Usage Examples
- "upmpost --help"
- "upmpost self version"

## Installation
```bash
apt-get install upmpost 2>/dev/null || which upmpost
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
