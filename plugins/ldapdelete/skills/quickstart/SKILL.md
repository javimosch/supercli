# ldapdelete Plugin

CLI tool: ldapdelete.

## Commands
- `ldapdelete <resource> <action>` — Execute ldapdelete commands
- `ldapdelete self version` — Print ldapdelete version
- `ldapdelete _ _` — Passthrough to ldapdelete CLI

## Usage Examples
- "ldapdelete --help"
- "ldapdelete self version"

## Installation
```bash
apt-get install ldapdelete 2>/dev/null || which ldapdelete
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
