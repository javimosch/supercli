# paperclip Plugin

The open-source app everyone uses to manage agents at work

## Commands
- `paperclip <resource> <action>` — Execute paperclip commands
- `paperclip self version` — Print paperclip version
- `paperclip _ _` — Passthrough to paperclip CLI

## Installation

```bash
pip install paperclip
```
