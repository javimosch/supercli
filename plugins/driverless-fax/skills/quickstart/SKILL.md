# driverless-fax Plugin

CLI tool: driverless-fax.

## Commands
- `driverless-fax <resource> <action>` — Execute driverless-fax commands
- `driverless-fax self version` — Print driverless-fax version
- `driverless-fax _ _` — Passthrough to driverless-fax CLI

## Usage Examples
- "driverless-fax --help"
- "driverless-fax self version"

## Installation
```bash
apt-get install driverless-fax 2>/dev/null || which driverless-fax
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
