# x86_64-linux-gnu-pkg-config Plugin

x86_64-linux-gnu-pkg-config — manage compile and link flags for libraries.

## Commands
- `x86_64-linux-gnu-pkg-config <resource> <action>` — Execute x86_64-linux-gnu-pkg-config commands
- `x86_64-linux-gnu-pkg-config self version` — Print x86_64-linux-gnu-pkg-config version
- `x86_64-linux-gnu-pkg-config _ _` — Passthrough to x86_64-linux-gnu-pkg-config CLI

## Usage Examples
- "x86_64-linux-gnu-pkg-config --help"
- "x86_64-linux-gnu-pkg-config self version"

## Installation
```bash
apt-get install pkgconf 2>/dev/null || which x86_64-linux-gnu-pkg-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
