# ppmlabel Plugin

CLI tool: ppmlabel.

## Commands
- `ppmlabel <resource> <action>` — Execute ppmlabel commands
- `ppmlabel self version` — Print ppmlabel version
- `ppmlabel _ _` — Passthrough to ppmlabel CLI

## Usage Examples
- "ppmlabel --help"
- "ppmlabel self version"

## Installation
```bash
apt-get install ppmlabel 2>/dev/null || which ppmlabel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
