# xslt-config Plugin

CLI tool: xslt-config.

## Commands
- `xslt-config <resource> <action>` — Execute xslt-config commands
- `xslt-config self version` — Print xslt-config version
- `xslt-config _ _` — Passthrough to xslt-config CLI

## Usage Examples
- "xslt-config --help"
- "xslt-config self version"

## Installation
```bash
apt-get install xslt-config 2>/dev/null || which xslt-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
