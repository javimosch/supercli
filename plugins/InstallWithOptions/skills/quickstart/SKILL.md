# InstallWithOptions Plugin

Simple-ish app using Shizuku to install APKs on-device with advanced options

## Commands

### General
- `InstallWithOptions self version` — Print InstallWithOptions version
- `InstallWithOptions _ _` — Passthrough to installwithoptions CLI
