# parcat Plugin

CLI tool: parcat.

## Commands
- `parcat <resource> <action>` — Execute parcat commands
- `parcat self version` — Print parcat version
- `parcat _ _` — Passthrough to parcat CLI

## Usage Examples
- "parcat --help"
- "parcat self version"

## Installation
```bash
apt-get install parcat 2>/dev/null || which parcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
