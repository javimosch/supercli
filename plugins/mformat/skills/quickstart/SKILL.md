# mformat Plugin

CLI tool: mformat.

## Commands
- `mformat <resource> <action>` — Execute mformat commands
- `mformat self version` — Print mformat version
- `mformat _ _` — Passthrough to mformat CLI

## Usage Examples
- "mformat --help"
- "mformat self version"

## Installation
```bash
apt-get install mformat 2>/dev/null || which mformat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
