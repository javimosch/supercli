# xzmore Plugin

CLI tool: xzmore.

## Commands
- `xzmore <resource> <action>` — Execute xzmore commands
- `xzmore self version` — Print xzmore version
- `xzmore _ _` — Passthrough to xzmore CLI

## Usage Examples
- "xzmore --help"
- "xzmore self version"

## Installation
```bash
apt-get install xzmore 2>/dev/null || which xzmore
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
