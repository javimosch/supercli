# FileKit Plugin

Pick and save Files, Medias and Folder for Kotlin Multiplatform / KMP and Compose Multiplatform / CMP

## Commands

### General
- `FileKit self version` — Print FileKit version
- `FileKit _ _` — Passthrough to filekit CLI


- Pick and save Files, Medias and Folder for Kotlin Multiplatform / KMP and Compose Multiplatform / CM
