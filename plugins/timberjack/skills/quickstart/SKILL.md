# timberjack Plugin
Fast Rust-based log analyzer for pattern extraction

## Commands
- `timberjack <resource> <action>` — Execute timberjack commands
- `timberjack _ _` — Passthrough to timberjack CLI

## Usage
- `timberjack _ _ <args>` — Run timberjack with any arguments
