# gtk-builder-tool Plugin

CLI tool: gtk-builder-tool.

## Commands
- `gtk-builder-tool <resource> <action>` — Execute gtk-builder-tool commands
- `gtk-builder-tool self version` — Print gtk-builder-tool version
- `gtk-builder-tool _ _` — Passthrough to gtk-builder-tool CLI

## Usage Examples
- "gtk-builder-tool --help"
- "gtk-builder-tool self version"

## Installation
```bash
apt-get install gtk-builder-tool 2>/dev/null || which gtk-builder-tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
