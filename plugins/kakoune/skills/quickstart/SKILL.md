# kakoune Plugin
Modal code editor with selection-oriented paradigm

## Commands
- `kakoune <resource> <action>` — Execute kakoune commands
- `kakoune _ _` — Passthrough to kak CLI

## Usage
- `kakoune _ _ <args>` — Run kak with any arguments
