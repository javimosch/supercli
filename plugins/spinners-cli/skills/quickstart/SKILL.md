# spinners-cli Plugin
Display various terminal spinners with colors

## Commands
- `spinners-cli <resource> <action>` — Execute spinners-cli commands
- `spinners-cli _ _` — Passthrough to spinners-cli CLI

## Usage
- `spinners-cli _ _ <args>` — Run spinners-cli with any arguments
