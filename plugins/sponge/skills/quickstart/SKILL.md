# sponge Plugin

CLI tool: sponge.

## Commands
- `sponge <resource> <action>` — Execute sponge commands
- `sponge self version` — Print sponge version
- `sponge _ _` — Passthrough to sponge CLI

## Usage Examples
- "sponge --help"
- "sponge self version"

## Installation
```bash
apt-get install sponge 2>/dev/null || which sponge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
