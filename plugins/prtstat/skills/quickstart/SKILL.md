# prtstat Plugin

CLI tool: prtstat.

## Commands
- `prtstat <resource> <action>` — Execute prtstat commands
- `prtstat self version` — Print prtstat version
- `prtstat _ _` — Passthrough to prtstat CLI

## Usage Examples
- "prtstat --help"
- "prtstat self version"

## Installation
```bash
apt-get install prtstat 2>/dev/null || which prtstat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
