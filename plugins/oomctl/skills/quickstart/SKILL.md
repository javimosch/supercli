# oomctl Plugin

CLI tool: oomctl.

## Commands
- `oomctl <resource> <action>` — Execute oomctl commands
- `oomctl self version` — Print oomctl version
- `oomctl _ _` — Passthrough to oomctl CLI

## Usage Examples
- "oomctl --help"
- "oomctl self version"

## Installation
```bash
apt-get install oomctl 2>/dev/null || which oomctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
