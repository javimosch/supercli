# mdtable Plugin
Generate and format Markdown tables from CLI input

## Commands
- `mdtable <resource> <action>` — Execute mdtable commands
- `mdtable _ _` — Passthrough to mdtable CLI

## Usage
- `mdtable _ _ <args>` — Run mdtable with any arguments
