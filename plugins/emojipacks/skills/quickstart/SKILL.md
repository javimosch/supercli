# emojipacks Plugin

Bulk upload emojis to Slack in JavaScript

## Commands

### Operations
- `emojipacks self version` — Print emojipacks version
- `emojipacks _ _` — Passthrough to emojipacks CLI

## Usage Examples
- `emojipacks --help`
- `emojipacks <args>`

## Installation

```bash
npm install -g emojipacks
```

## Examples

```bash
emojipacks --version
emojipacks --help
```
