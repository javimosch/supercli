# psbook Plugin

CLI tool: psbook.

## Commands
- `psbook <resource> <action>` — Execute psbook commands
- `psbook self version` — Print psbook version
- `psbook _ _` — Passthrough to psbook CLI

## Usage Examples
- "psbook --help"
- "psbook self version"

## Installation
```bash
apt-get install psbook 2>/dev/null || which psbook
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
