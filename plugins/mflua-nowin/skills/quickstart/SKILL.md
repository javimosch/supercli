# mflua-nowin Plugin

CLI tool: mflua-nowin.

## Commands
- `mflua-nowin <resource> <action>` — Execute mflua-nowin commands
- `mflua-nowin self version` — Print mflua-nowin version
- `mflua-nowin _ _` — Passthrough to mflua-nowin CLI

## Usage Examples
- "mflua-nowin --help"
- "mflua-nowin self version"

## Installation
```bash
apt-get install mflua-nowin 2>/dev/null || which mflua-nowin
```
