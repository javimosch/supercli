# sqllineage Plugin

sqllineage — SQL lineage analysis tool. Track column-level dependencies in SQL queries..

## Commands

### `sc sqllineage sql analyze`
Analyze SQL query lineage.

### `sc sqllineage self version`
Print version.

## Installation

```bash
pip install sqllineage
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
