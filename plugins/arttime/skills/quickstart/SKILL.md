# arttime Plugin

CLI app blending ASCII art with timekeeping

## Commands

### Version
`arttime self version` — Print arttime version

### Passthrough
`arttime _ _` — Passthrough to arttime CLI with all arguments forwarded.

## Usage Examples

```bash
arttime --version
arttime --help
```

## Installation

```bash
brew install arttime
```

## Key Features
- CLI app blending ASCII art with timekeeping
