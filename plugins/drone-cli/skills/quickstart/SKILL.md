# drone-cli
drone-cli — Drone CI command line interface. Trigger builds, view logs, manage pipelines. Interact with Drone CI server.

## Commands
- `drone-cli <resource> <action>` — Execute drone-cli commands
- `drone cli run` — drone-cli — Drone CI command line interface. Trigger builds, view logs, manage pipelines. Interact with Drone CI server.
