# ps2txt Plugin

CLI tool: ps2txt.

## Commands
- `ps2txt <resource> <action>` — Execute ps2txt commands
- `ps2txt self version` — Print ps2txt version
- `ps2txt _ _` — Passthrough to ps2txt CLI

## Usage Examples
- "ps2txt --help"
- "ps2txt self version"

## Installation
```bash
apt-get install ps2txt 2>/dev/null || which ps2txt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
