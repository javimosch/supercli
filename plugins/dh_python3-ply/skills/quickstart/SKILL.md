# dh_python3-ply Plugin

CLI tool: dh_python3-ply.

## Commands
- `dh_python3-ply <resource> <action>` — Execute dh_python3-ply commands
- `dh_python3-ply self version` — Print dh_python3-ply version
- `dh_python3-ply _ _` — Passthrough to dh_python3-ply CLI

## Usage Examples
- "dh_python3-ply --help"
- "dh_python3-ply self version"

## Installation
```bash
apt-get install dh_python3-ply 2>/dev/null || which dh_python3-ply
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
