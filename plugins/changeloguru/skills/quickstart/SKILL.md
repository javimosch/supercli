# changeloguru Plugin

Generate changelog from conventional commits — JSON output supported

## Commands
- `changeloguru self version` — Print changeloguru version
- `changeloguru _ _` — Passthrough to changeloguru CLI

## Usage Examples
- `changeloguru self version` — Check installed version
- `changeloguru _ _ --help` — Show changeloguru help
- `changeloguru _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/changeloguru/changeloguru@latest
```

## Key Features
- changelog, git, golang, cli
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
