# patgen Plugin

CLI tool: patgen.

## Commands
- `patgen <resource> <action>` — Execute patgen commands
- `patgen self version` — Print patgen version
- `patgen _ _` — Passthrough to patgen CLI

## Usage Examples
- "patgen --help"
- "patgen self version"

## Installation
```bash
apt-get install patgen 2>/dev/null || which patgen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
