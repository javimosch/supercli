# termpix Plugin
Display images in the terminal using half blocks

## Commands
- `termpix <resource> <action>` — Execute termpix commands
- `termpix _ _` — Passthrough to termpix CLI

## Usage
- `termpix _ _ <args>` — Run termpix with any arguments
