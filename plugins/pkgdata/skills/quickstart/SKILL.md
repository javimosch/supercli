# pkgdata Plugin

CLI tool: pkgdata.

## Commands
- `pkgdata <resource> <action>` — Execute pkgdata commands
- `pkgdata self version` — Print pkgdata version
- `pkgdata _ _` — Passthrough to pkgdata CLI

## Usage Examples
- "pkgdata --help"
- "pkgdata self version"

## Installation
```bash
apt-get install pkgdata 2>/dev/null || which pkgdata
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
