# nologin Plugin

CLI tool: nologin.

## Commands
- `nologin <resource> <action>` — Execute nologin commands
- `nologin self version` — Print nologin version
- `nologin _ _` — Passthrough to nologin CLI

## Usage Examples
- "nologin --help"
- "nologin self version"

## Installation
```bash
apt-get install nologin 2>/dev/null || which nologin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
