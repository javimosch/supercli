# rletopnm Plugin

CLI tool: rletopnm.

## Commands
- `rletopnm <resource> <action>` — Execute rletopnm commands
- `rletopnm self version` — Print rletopnm version
- `rletopnm _ _` — Passthrough to rletopnm CLI

## Usage Examples
- "rletopnm --help"
- "rletopnm self version"

## Installation
```bash
apt-get install rletopnm 2>/dev/null || which rletopnm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
