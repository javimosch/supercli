# cups.reject Plugin

CLI tool: cups.reject.

## Commands
- `cups.reject <resource> <action>` — Execute cups.reject commands
- `cups.reject self version` — Print cups.reject version
- `cups.reject _ _` — Passthrough to cups.reject CLI

## Usage Examples
- "cups.reject --help"
- "cups.reject self version"

## Installation
```bash
apt-get install cups.reject 2>/dev/null || which cups.reject
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
