# jconsole Plugin

CLI tool: jconsole.

## Commands
- `jconsole <resource> <action>` — Execute jconsole commands
- `jconsole self version` — Print jconsole version
- `jconsole _ _` — Passthrough to jconsole CLI

## Usage Examples
- "jconsole --help"
- "jconsole self version"

## Installation
```bash
apt-get install jconsole 2>/dev/null || which jconsole
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
