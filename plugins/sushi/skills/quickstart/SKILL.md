# sushi Plugin

CLI tool: sushi.

## Commands
- `sushi <resource> <action>` — Execute sushi commands
- `sushi self version` — Print sushi version
- `sushi _ _` — Passthrough to sushi CLI

## Usage Examples
- "sushi --help"
- "sushi self version"

## Installation
```bash
apt-get install sushi 2>/dev/null || which sushi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
