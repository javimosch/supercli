# nmtui-edit Plugin

CLI tool: nmtui-edit.

## Commands
- `nmtui-edit <resource> <action>` — Execute nmtui-edit commands
- `nmtui-edit self version` — Print nmtui-edit version
- `nmtui-edit _ _` — Passthrough to nmtui-edit CLI

## Usage Examples
- "nmtui-edit --help"
- "nmtui-edit self version"

## Installation
```bash
apt-get install nmtui-edit 2>/dev/null || which nmtui-edit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
