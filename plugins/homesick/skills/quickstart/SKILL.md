# homesick Plugin
Your home directory is your castle for dotfiles

## Commands
- `homesick <resource> <action>` — Execute homesick commands
- `homesick _ _` — Passthrough to homesick CLI

## Usage
- `homesick _ _ <args>` — Run homesick with any arguments
