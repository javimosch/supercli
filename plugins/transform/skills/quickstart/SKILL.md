# transform Plugin

CLI tool: transform.

## Commands
- `transform <resource> <action>` — Execute transform commands
- `transform self version` — Print transform version
- `transform _ _` — Passthrough to transform CLI

## Usage Examples
- "transform --help"
- "transform self version"

## Installation
```bash
apt-get install transform 2>/dev/null || which transform
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
