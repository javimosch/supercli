# ssl-tls-verify Plugin
Verify SSL/TLS connections and inspect certificate chains

## Commands
- `ssl-tls-verify <resource> <action>` — Execute ssl-tls-verify commands
- `ssl-tls-verify _ _` — Passthrough to ssl-tls-verify CLI

## Usage
- `ssl-tls-verify _ _ <args>` — Run ssl-tls-verify with any arguments
