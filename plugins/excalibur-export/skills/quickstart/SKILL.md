# excalibur-export Plugin
Export Excalidraw diagrams to PNG SVG and PDF

## Commands
- `excalibur-export <resource> <action>` — Execute excalibur-export commands
- `excalibur-export _ _` — Passthrough to excalibur-export CLI

## Usage
- `excalibur-export _ _ <args>` — Run excalibur-export with any arguments
