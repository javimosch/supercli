# dvipdfmx Plugin

CLI tool: dvipdfmx.

## Commands
- `dvipdfmx <resource> <action>` — Execute dvipdfmx commands
- `dvipdfmx self version` — Print dvipdfmx version
- `dvipdfmx _ _` — Passthrough to dvipdfmx CLI

## Usage Examples
- "dvipdfmx --help"
- "dvipdfmx self version"

## Installation
```bash
apt-get install dvipdfmx 2>/dev/null || which dvipdfmx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
