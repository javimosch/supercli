# vite-plus Plugin

Vite+ is the unified toolchain and entry point for web development. It manages your runtime, package manager, and frontend toolchain in one place.

## Commands
- `vite-plus <resource> <action>` — Execute vite-plus commands
- `vite-plus self version` — Print vite-plus version
- `vite-plus _ _` — Passthrough to vite-plus CLI

## Installation

```bash
pip install vite-plus
```
