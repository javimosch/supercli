# rstpep2html Plugin

CLI tool: rstpep2html.

## Commands
- `rstpep2html <resource> <action>` — Execute rstpep2html commands
- `rstpep2html self version` — Print rstpep2html version
- `rstpep2html _ _` — Passthrough to rstpep2html CLI

## Usage Examples
- "rstpep2html --help"
- "rstpep2html self version"

## Installation
```bash
apt-get install rstpep2html 2>/dev/null || which rstpep2html
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
