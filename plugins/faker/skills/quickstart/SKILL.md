# faker Plugin

CLI tool: faker.

## Commands
- `faker <resource> <action>` — Execute faker commands
- `faker self version` — Print faker version
- `faker _ _` — Passthrough to faker CLI

## Usage Examples
- "faker --help"
- "faker self version"

## Installation
```bash
apt-get install faker 2>/dev/null || which faker
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
