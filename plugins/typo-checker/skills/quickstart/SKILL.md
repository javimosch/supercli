# typo-checker Plugin
Fast spell checker for code and documentation.
## Commands
- `typo-checker _ _` — Passthrough to typo-checker CLI
## Installation
```bash
cargo install typo-checker
```
## Key Features
- **Code-aware** — Spell check source code
- **JSON output** — CI/CD integration
- **Fast** — Written in Rust
