# icdiff Plugin
Improved colored side-by-side diff tool. Better than diff with enhanced readability and color highlighting.
## Commands
- `icdiff self version` — Print version
- `icdiff _ _` — Passthrough to icdiff
## Installation
```bash
brew install icdiff
```
