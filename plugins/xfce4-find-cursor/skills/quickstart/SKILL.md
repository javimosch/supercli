# xfce4-find-cursor Plugin

CLI tool: xfce4-find-cursor.

## Commands
- `xfce4-find-cursor <resource> <action>` — Execute xfce4-find-cursor commands
- `xfce4-find-cursor self version` — Print xfce4-find-cursor version
- `xfce4-find-cursor _ _` — Passthrough to xfce4-find-cursor CLI

## Usage Examples
- "xfce4-find-cursor --help"
- "xfce4-find-cursor self version"

## Installation

```bash
apt-get install xfce4-find-cursor 2>/dev/null || which xfce4-find-cursor
```
