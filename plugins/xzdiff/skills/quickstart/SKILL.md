# xzdiff Plugin

CLI tool: xzdiff.

## Commands
- `xzdiff <resource> <action>` — Execute xzdiff commands
- `xzdiff self version` — Print xzdiff version
- `xzdiff _ _` — Passthrough to xzdiff CLI

## Usage Examples
- "xzdiff --help"
- "xzdiff self version"

## Installation
```bash
apt-get install xzdiff 2>/dev/null || which xzdiff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
