# UnleashedRecomp Plugin

An unofficial PC port of the Xbox 360 version of Sonic Unleashed created through the process of static recompilation.

## Commands

### General
- `UnleashedRecomp self version` — Print UnleashedRecomp version
- `UnleashedRecomp _ _` — Passthrough to unleashedrecomp CLI
