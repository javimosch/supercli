# ppmpat Plugin

CLI tool: ppmpat.

## Commands
- `ppmpat <resource> <action>` — Execute ppmpat commands
- `ppmpat self version` — Print ppmpat version
- `ppmpat _ _` — Passthrough to ppmpat CLI

## Usage Examples
- "ppmpat --help"
- "ppmpat self version"

## Installation
```bash
apt-get install ppmpat 2>/dev/null || which ppmpat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
