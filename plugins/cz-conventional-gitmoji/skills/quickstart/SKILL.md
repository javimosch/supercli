# cz-conventional-gitmoji Plugin
Commitizen adapter for conventional gitmoji

## Commands
- `cz-conventional-gitmoji <resource> <action>` — Execute cz-conventional-gitmoji commands
- `cz-conventional-gitmoji _ _` — Passthrough to cz-conventional-gitmoji CLI

## Usage
- `cz-conventional-gitmoji _ _ <args>` — Run cz-conventional-gitmoji with any arguments
