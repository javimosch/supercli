# nmtui-connect Plugin

CLI tool: nmtui-connect.

## Commands
- `nmtui-connect <resource> <action>` — Execute nmtui-connect commands
- `nmtui-connect self version` — Print nmtui-connect version
- `nmtui-connect _ _` — Passthrough to nmtui-connect CLI

## Usage Examples
- "nmtui-connect --help"
- "nmtui-connect self version"

## Installation
```bash
apt-get install nmtui-connect 2>/dev/null || which nmtui-connect
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
