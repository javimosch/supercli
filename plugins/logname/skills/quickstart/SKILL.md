# logname Plugin
Display the login name of current user

## Commands
- `logname <resource> <action>` — Execute logname commands
- `logname self version` — Print logname version
- `logname _ _` — Passthrough to logname CLI

## Usage
- `logname _ _ <args>` — Run logname with any arguments
