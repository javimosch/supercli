# Telemt Plugin

MTProxy for Telegram on Rust + Tokio

## Commands
- `telemt _ _` — Passthrough to telemt CLI

## Installation

```bash
cargo install telemt
```

## Examples
```bash
telemt --help
telemt --version
```
