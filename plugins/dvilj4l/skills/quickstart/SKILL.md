# dvilj4l Plugin

CLI tool: dvilj4l.

## Commands
- `dvilj4l <resource> <action>` — Execute dvilj4l commands
- `dvilj4l self version` — Print dvilj4l version
- `dvilj4l _ _` — Passthrough to dvilj4l CLI

## Usage Examples
- "dvilj4l --help"
- "dvilj4l self version"

## Installation
```bash
apt-get install dvilj4l 2>/dev/null || which dvilj4l
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
