# pnmcat Plugin

CLI tool: pnmcat.

## Commands
- `pnmcat <resource> <action>` — Execute pnmcat commands
- `pnmcat self version` — Print pnmcat version
- `pnmcat _ _` — Passthrough to pnmcat CLI

## Usage Examples
- "pnmcat --help"
- "pnmcat self version"

## Installation
```bash
apt-get install pnmcat 2>/dev/null || which pnmcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
