# ipp-usb Plugin

CLI tool: ipp-usb.

## Commands
- `ipp-usb <resource> <action>` — Execute ipp-usb commands
- `ipp-usb self version` — Print ipp-usb version
- `ipp-usb _ _` — Passthrough to ipp-usb CLI

## Usage Examples
- "ipp-usb --help"
- "ipp-usb self version"

## Installation
```bash
apt-get install ipp-usb 2>/dev/null || which ipp-usb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
