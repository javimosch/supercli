# oblivion Plugin

Unofficial warp client for android

## Commands

### General
- `oblivion self version` — Print oblivion version
- `oblivion _ _` — Passthrough to oblivion CLI

## Usage Examples
- "Run oblivion"
- "Use oblivion to Unofficial warp client for android"

## Installation

```bash
pip install oblivion
```

## Key Features
- Unofficial warp client for android
- CLI tool, headless and scriptable
