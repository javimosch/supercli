# qml Plugin

CLI tool: qml.

## Commands
- `qml <resource> <action>` — Execute qml commands
- `qml self version` — Print qml version
- `qml _ _` — Passthrough to qml CLI

## Usage Examples
- "qml --help"
- "qml self version"

## Installation
```bash
apt-get install qml 2>/dev/null || which qml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
