# updvitomp Plugin

CLI tool: updvitomp.

## Commands
- `updvitomp <resource> <action>` — Execute updvitomp commands
- `updvitomp self version` — Print updvitomp version
- `updvitomp _ _` — Passthrough to updvitomp CLI

## Usage Examples
- "updvitomp --help"
- "updvitomp self version"

## Installation
```bash
apt-get install updvitomp 2>/dev/null || which updvitomp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
