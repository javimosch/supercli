# catimg Plugin

catimg renders images in the terminal.

## Usage Examples

- "preview an image in terminal"
- "show a thumbnail of a large image"
- "display image with sixel graphics"

## Installation

```bash
brew install catimg
```

## Key Features
- Terminal image rendering
- ANSI color and Unicode block output
- Sixel graphics support
- Image resize and thumbnail
- Alignment and positioning
- Multiple color depth options
