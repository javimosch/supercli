# keepassxc-cli Plugin

CLI tool: keepassxc-cli.

## Commands
- `keepassxc-cli <resource> <action>` — Execute keepassxc-cli commands
- `keepassxc-cli self version` — Print keepassxc-cli version
- `keepassxc-cli _ _` — Passthrough to keepassxc-cli CLI

## Usage Examples
- "keepassxc-cli --help"
- "keepassxc-cli self version"

## Installation
```bash
apt-get install keepassxc-cli 2>/dev/null || which keepassxc-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
