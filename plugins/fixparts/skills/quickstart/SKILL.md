# fixparts Plugin

CLI tool: fixparts.

## Commands
- `fixparts <resource> <action>` — Execute fixparts commands
- `fixparts self version` — Print fixparts version
- `fixparts _ _` — Passthrough to fixparts CLI

## Usage Examples
- "fixparts --help"
- "fixparts self version"

## Installation
```bash
apt-get install fixparts 2>/dev/null || which fixparts
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
