# pic Plugin

CLI tool: pic.

## Commands
- `pic <resource> <action>` — Execute pic commands
- `pic self version` — Print pic version
- `pic _ _` — Passthrough to pic CLI

## Usage Examples
- "pic --help"
- "pic self version"

## Installation
```bash
apt-get install pic 2>/dev/null || which pic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
