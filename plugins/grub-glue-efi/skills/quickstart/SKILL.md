# grub-glue-efi Plugin

CLI tool: grub-glue-efi.

## Commands
- `grub-glue-efi <resource> <action>` — Execute grub-glue-efi commands
- `grub-glue-efi self version` — Print grub-glue-efi version
- `grub-glue-efi _ _` — Passthrough to grub-glue-efi CLI

## Usage Examples
- "grub-glue-efi --help"
- "grub-glue-efi self version"

## Installation
```bash
apt-get install grub-glue-efi 2>/dev/null || which grub-glue-efi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
