# lavadecode Plugin

CLI tool: lavadecode.

## Commands
- `lavadecode <resource> <action>` — Execute lavadecode commands
- `lavadecode self version` — Print lavadecode version
- `lavadecode _ _` — Passthrough to lavadecode CLI

## Usage Examples
- "lavadecode --help"
- "lavadecode self version"

## Installation
```bash
apt-get install lavadecode 2>/dev/null || which lavadecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
