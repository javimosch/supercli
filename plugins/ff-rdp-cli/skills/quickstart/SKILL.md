# ff-rdp-cli Plugin
CLI tool for ff-rdp-cli.

## Commands
- `ff-rdp-cli <resource> <action>` — Execute ff-rdp-cli commands
- `ff-rdp-cli _ _` — Passthrough to ff-rdp-cli CLI

## Installation
```bash
cargo install ff-rdp-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
