# TrickyStoreOSS Plugin

Open source alternative to proprietary Tricky Store module

## Commands

### General
- `TrickyStoreOSS self version` — Print TrickyStoreOSS version
- `TrickyStoreOSS _ _` — Passthrough to trickystoreoss CLI

## Usage Examples
- "Run TrickyStoreOSS"
- "Use trickystoreoss to Open source alternative to proprietary Tricky Store module"

## Installation

```bash
pip install trickystoreoss
```

## Key Features
- Open source alternative to proprietary Tricky Store module
- CLI tool, headless and scriptable
