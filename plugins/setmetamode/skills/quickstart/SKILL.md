# setmetamode Plugin

CLI tool: setmetamode.

## Commands
- `setmetamode <resource> <action>` — Execute setmetamode commands
- `setmetamode self version` — Print setmetamode version
- `setmetamode _ _` — Passthrough to setmetamode CLI

## Usage Examples
- "setmetamode --help"
- "setmetamode self version"

## Installation
```bash
apt-get install setmetamode 2>/dev/null || which setmetamode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
