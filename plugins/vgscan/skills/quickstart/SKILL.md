# vgscan Plugin

CLI tool: vgscan.

## Commands
- `vgscan <resource> <action>` — Execute vgscan commands
- `vgscan self version` — Print vgscan version
- `vgscan _ _` — Passthrough to vgscan CLI

## Usage Examples
- "vgscan --help"
- "vgscan self version"

## Installation
```bash
apt-get install vgscan 2>/dev/null || which vgscan
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
