# encguess Plugin

CLI tool: encguess.

## Commands
- `encguess <resource> <action>` — Execute encguess commands
- `encguess self version` — Print encguess version
- `encguess _ _` — Passthrough to encguess CLI

## Usage Examples
- "encguess --help"
- "encguess self version"

## Installation
```bash
apt-get install encguess 2>/dev/null || which encguess
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
