# stopwatch-cli Plugin
Precision stopwatch with lap timing from the command line

## Commands
- `stopwatch-cli <resource> <action>` — Execute stopwatch-cli commands
- `stopwatch-cli _ _` — Passthrough to stopwatch-cli CLI

## Usage
- `stopwatch-cli _ _ <args>` — Run stopwatch-cli with any arguments
