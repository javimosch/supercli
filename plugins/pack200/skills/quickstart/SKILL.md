# pack200 Plugin

CLI tool: pack200.

## Commands
- `pack200 <resource> <action>` — Execute pack200 commands
- `pack200 self version` — Print pack200 version
- `pack200 _ _` — Passthrough to pack200 CLI

## Usage Examples
- "pack200 --help"
- "pack200 self version"

## Installation
```bash
apt-get install pack200 2>/dev/null || which pack200
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
