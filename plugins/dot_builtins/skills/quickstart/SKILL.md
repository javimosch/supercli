# dot_builtins Plugin

CLI tool: dot_builtins.

## Commands
- `dot_builtins <resource> <action>` — Execute dot_builtins commands
- `dot_builtins self version` — Print dot_builtins version
- `dot_builtins _ _` — Passthrough to dot_builtins CLI

## Usage Examples
- "dot_builtins --help"
- "dot_builtins self version"

## Installation
```bash
apt-get install dot_builtins 2>/dev/null || which dot_builtins
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
