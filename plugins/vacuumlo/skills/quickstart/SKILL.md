# vacuumlo Plugin

CLI tool: vacuumlo.

## Commands
- `vacuumlo <resource> <action>` — Execute vacuumlo commands
- `vacuumlo self version` — Print vacuumlo version
- `vacuumlo _ _` — Passthrough to vacuumlo CLI

## Usage Examples
- "vacuumlo --help"
- "vacuumlo self version"

## Installation
```bash
apt-get install vacuumlo 2>/dev/null || which vacuumlo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
