# hostid Plugin

CLI tool: hostid.

## Commands
- `hostid <resource> <action>` — Execute hostid commands
- `hostid self version` — Print hostid version
- `hostid _ _` — Passthrough to hostid CLI

## Usage Examples
- "hostid --help"
- "hostid self version"

## Installation
```bash
apt-get install hostid 2>/dev/null || which hostid
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
