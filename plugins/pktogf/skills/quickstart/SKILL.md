# pktogf Plugin

CLI tool: pktogf.

## Commands
- `pktogf <resource> <action>` — Execute pktogf commands
- `pktogf self version` — Print pktogf version
- `pktogf _ _` — Passthrough to pktogf CLI

## Usage Examples
- "pktogf --help"
- "pktogf self version"

## Installation
```bash
apt-get install pktogf 2>/dev/null || which pktogf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
