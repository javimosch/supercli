# man-recode Plugin

CLI tool: man-recode.

## Commands
- `man-recode <resource> <action>` — Execute man-recode commands
- `man-recode self version` — Print man-recode version
- `man-recode _ _` — Passthrough to man-recode CLI

## Usage Examples
- "man-recode --help"
- "man-recode self version"

## Installation
```bash
apt-get install man-recode 2>/dev/null || which man-recode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
