# bunchee Plugin
Zero-config bundler for Bun libraries

## Commands
- `bunchee <resource> <action>` — Execute bunchee commands
- `bunchee _ _` — Passthrough to bunchee CLI

## Usage
- `bunchee _ _ <args>` — Run bunchee with any arguments
