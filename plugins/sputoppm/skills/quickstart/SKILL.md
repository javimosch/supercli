# sputoppm Plugin

CLI tool: sputoppm.

## Commands
- `sputoppm <resource> <action>` — Execute sputoppm commands
- `sputoppm self version` — Print sputoppm version
- `sputoppm _ _` — Passthrough to sputoppm CLI

## Usage Examples
- "sputoppm --help"
- "sputoppm self version"

## Installation
```bash
apt-get install sputoppm 2>/dev/null || which sputoppm
```

## Key Features

- Scriptable and automatable
- Pipeline-ready output
