# TrackWeight Plugin

Use your Mac trackpad as a weighing scale

## Commands

### General
- `TrackWeight self version` — Print TrackWeight version
- `TrackWeight _ _` — Passthrough to trackweight CLI

## Usage Examples
- "Run TrackWeight"
- "Use trackweight to Use your Mac trackpad as a weighing scale"

## Installation

```bash
pip install trackweight
```

## Key Features
- Use your Mac trackpad as a weighing scale
- CLI tool, headless and scriptable
