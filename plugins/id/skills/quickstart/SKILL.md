# id Plugin
Print user and group identity information

## Commands
- `id <resource> <action>` — Execute id commands
- `id self version` — Print id version
- `id _ _` — Passthrough to id CLI

## Usage
- `id _ _ <args>` — Run id with any arguments
- `id self version` — Print id version
