# linux32 Plugin

CLI tool: linux32.

## Commands
- `linux32 <resource> <action>` — Execute linux32 commands
- `linux32 self version` — Print linux32 version
- `linux32 _ _` — Passthrough to linux32 CLI

## Usage Examples
- "linux32 --help"
- "linux32 self version"

## Installation
```bash
apt-get install linux32 2>/dev/null || which linux32
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
