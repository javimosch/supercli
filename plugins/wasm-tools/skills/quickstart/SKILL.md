# wasm-tools
wasm-tools — WebAssembly toolchain CLI. Parse, validate, demangle, and convert WASM binaries. Includes wasm2wat, wat2wasm, wasm-validate.

## Commands
- `wasm-tools <resource> <action>` — Execute wasm-tools commands
- `wasm tools run` — wasm-tools — WebAssembly toolchain CLI. Parse, validate, demangle, and convert WASM binaries. Includes wasm2wat, wat2wasm, wasm-validate.
