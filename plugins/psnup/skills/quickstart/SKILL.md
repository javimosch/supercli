# psnup Plugin

CLI tool: psnup.

## Commands
- `psnup <resource> <action>` — Execute psnup commands
- `psnup self version` — Print psnup version
- `psnup _ _` — Passthrough to psnup CLI

## Usage Examples
- "psnup --help"
- "psnup self version"

## Installation
```bash
apt-get install psnup 2>/dev/null || which psnup
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
