# kspider Plugin

Kspider 是一个爬虫平台，以图形化方式定义爬虫流程，无需代码即可实现一个爬虫流程，Kspider不仅限爬虫，也可用于WEB自动化测试，更多功能等你探索。

## Commands

### General
- `kspider self version` — Print kspider version
- `kspider _ _` — Passthrough to kspider CLI
