# ElaWidgetTools Plugin

Fluent-UI For QT-Widget

## Commands

### General
- `ElaWidgetTools self version` — Print ElaWidgetTools version
- `ElaWidgetTools _ _` — Passthrough to elawidgettools CLI

