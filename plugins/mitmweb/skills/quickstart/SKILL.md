# mitmweb Plugin

CLI tool: mitmweb.

## Commands
- `mitmweb <resource> <action>` — Execute mitmweb commands
- `mitmweb self version` — Print mitmweb version
- `mitmweb _ _` — Passthrough to mitmweb CLI

## Usage Examples
- "mitmweb --help"
- "mitmweb self version"

## Installation
```bash
apt-get install mitmweb 2>/dev/null || which mitmweb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
