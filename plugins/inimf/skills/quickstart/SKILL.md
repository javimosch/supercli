# inimf Plugin

CLI tool: inimf.

## Commands
- `inimf <resource> <action>` — Execute inimf commands
- `inimf self version` — Print inimf version
- `inimf _ _` — Passthrough to inimf CLI

## Usage Examples
- "inimf --help"
- "inimf self version"

## Installation
```bash
apt-get install inimf 2>/dev/null || which inimf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
