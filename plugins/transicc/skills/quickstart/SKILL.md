# transicc Plugin

CLI tool: transicc.

## Commands
- `transicc <resource> <action>` — Execute transicc commands
- `transicc self version` — Print transicc version
- `transicc _ _` — Passthrough to transicc CLI

## Usage Examples
- "transicc --help"
- "transicc self version"

## Installation
```bash
apt-get install transicc 2>/dev/null || which transicc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
