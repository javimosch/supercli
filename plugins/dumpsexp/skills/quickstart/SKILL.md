# dumpsexp Plugin

CLI tool: dumpsexp.

## Commands
- `dumpsexp <resource> <action>` — Execute dumpsexp commands
- `dumpsexp self version` — Print dumpsexp version
- `dumpsexp _ _` — Passthrough to dumpsexp CLI

## Usage Examples
- "dumpsexp --help"
- "dumpsexp self version"

## Installation
```bash
apt-get install dumpsexp 2>/dev/null || which dumpsexp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
