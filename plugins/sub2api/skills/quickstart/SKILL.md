# sub2api Plugin

Sub2API 一站式开源中转服务，让 Claude、Openai 、Gemini、Antigravity订阅统一接入，支持拼车共享，更高效分摊成本，原生工具无缝使用。

## Commands

### General
- `sub2api self version` — Print sub2api version
- `sub2api _ _` — Passthrough to sub2api CLI

- "Run sub2api"

```bash
pip install sub2api
```
