# pinecone Plugin

CLI tool: pinecone.

## Commands
- `pinecone <resource> <action>` — Execute pinecone commands
- `pinecone self version` — Print pinecone version
- `pinecone _ _` — Passthrough to pinecone CLI

## Usage Examples
- "pinecone --help"
- "pinecone self version"

## Installation
```bash
apt-get install pinecone 2>/dev/null || which pinecone
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
