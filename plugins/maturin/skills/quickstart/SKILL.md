# maturin Plugin
Build and publish Rust crates as Python packages

## Commands
- `maturin <resource> <action>` — Execute maturin commands
- `maturin _ _` — Passthrough to maturin CLI

## Usage
- `maturin _ _ <args>` — Run maturin with any arguments
