# ssltap Plugin

CLI tool: ssltap.

## Commands
- `ssltap <resource> <action>` — Execute ssltap commands
- `ssltap self version` — Print ssltap version
- `ssltap _ _` — Passthrough to ssltap CLI

## Usage Examples
- "ssltap --help"
- "ssltap self version"

## Installation
```bash
apt-get install ssltap 2>/dev/null || which ssltap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
