# psfgettable Plugin

CLI tool: psfgettable.

## Commands
- `psfgettable <resource> <action>` — Execute psfgettable commands
- `psfgettable self version` — Print psfgettable version
- `psfgettable _ _` — Passthrough to psfgettable CLI

## Usage Examples
- "psfgettable --help"
- "psfgettable self version"

## Installation
```bash
apt-get install psfgettable 2>/dev/null || which psfgettable
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
