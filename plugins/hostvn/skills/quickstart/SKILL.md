# hostvn

HostVN CLI — Vietnam hosting provider interface

## Install

```bash
curl -sO https://scripts.hostvn.net/install && chmod +x install && ./install
```

Verify installation:

```bash
which hostvn
```

## Commands

- `hostvn self version` — print hostvn version
- `hostvn cli run ...` — pass any arguments straight through to `hostvn`
