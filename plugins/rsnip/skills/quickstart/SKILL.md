# rsnip Plugin
Powerful Rust-based code snippet manager

## Commands
- `rsnip <resource> <action>` — Execute rsnip commands
- `rsnip _ _` — Passthrough to rsnip CLI

## Usage
- `rsnip _ _ <args>` — Run rsnip with any arguments
