# rsbkb Plugin
CLI tool for rsbkb.

## Commands
- `rsbkb <resource> <action>` — Execute rsbkb commands
- `rsbkb _ _` — Passthrough to rsbkb CLI

## Installation
```bash
cargo install rsbkb
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
