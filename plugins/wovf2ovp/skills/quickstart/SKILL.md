# wovf2ovp Plugin

CLI tool: wovf2ovp.

## Commands
- `wovf2ovp <resource> <action>` — Execute wovf2ovp commands
- `wovf2ovp self version` — Print wovf2ovp version
- `wovf2ovp _ _` — Passthrough to wovf2ovp CLI

## Usage Examples
- "wovf2ovp --help"
- "wovf2ovp self version"

## Installation
```bash
apt-get install wovf2ovp 2>/dev/null || which wovf2ovp
```

- Pipeline-ready output
