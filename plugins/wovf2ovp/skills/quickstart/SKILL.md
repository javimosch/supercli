# wovf2ovp Plugin

wovf2ovp — Binaries for TeX Live.

## Commands
- `wovf2ovp <resource> <action>` — Execute wovf2ovp commands
- `wovf2ovp self version` — Print wovf2ovp version
- `wovf2ovp _ _` — Passthrough to wovf2ovp CLI

## Usage Examples
- "wovf2ovp --help"
- "wovf2ovp self version"

## Installation
```bash
apt-get install texlive-binaries 2>/dev/null || which wovf2ovp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
