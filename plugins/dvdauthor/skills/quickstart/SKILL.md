# dvdauthor Plugin

dvdauthor creates DVD-Video structures from MPEG files.

## Usage Examples

- "create a simple DVD from an MPEG file"
- "author a DVD with chapter points"
- "add subtitles to a DVD title"

## Installation

```bash
brew install dvdauthor
```

## Key Features
- DVD-Video compliant file creation
- MPEG to VOB conversion
- Chapter point support
- Subtitle and audio track management
- Multi-angle video support
- Menu generation capability
