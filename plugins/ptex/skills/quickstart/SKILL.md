# ptex Plugin

CLI tool: ptex.

## Commands
- `ptex <resource> <action>` — Execute ptex commands
- `ptex self version` — Print ptex version
- `ptex _ _` — Passthrough to ptex CLI

## Usage Examples
- "ptex --help"
- "ptex self version"

## Installation
```bash
apt-get install ptex 2>/dev/null || which ptex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
