# pbmtoicon Plugin

CLI tool: pbmtoicon.

## Commands
- `pbmtoicon <resource> <action>` — Execute pbmtoicon commands
- `pbmtoicon self version` — Print pbmtoicon version
- `pbmtoicon _ _` — Passthrough to pbmtoicon CLI

## Usage Examples
- "pbmtoicon --help"
- "pbmtoicon self version"

## Installation
```bash
apt-get install pbmtoicon 2>/dev/null || which pbmtoicon
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
