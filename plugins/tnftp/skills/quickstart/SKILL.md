# tnftp Plugin

CLI tool: tnftp.

## Commands
- `tnftp <resource> <action>` — Execute tnftp commands
- `tnftp self version` — Print tnftp version
- `tnftp _ _` — Passthrough to tnftp CLI

## Usage Examples
- "tnftp --help"
- "tnftp self version"

## Installation
```bash
apt-get install tnftp 2>/dev/null || which tnftp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
