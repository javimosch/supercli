# ppltotf Plugin

CLI tool: ppltotf.

## Commands
- `ppltotf <resource> <action>` — Execute ppltotf commands
- `ppltotf self version` — Print ppltotf version
- `ppltotf _ _` — Passthrough to ppltotf CLI

## Usage Examples
- "ppltotf --help"
- "ppltotf self version"

## Installation
```bash
apt-get install ppltotf 2>/dev/null || which ppltotf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
