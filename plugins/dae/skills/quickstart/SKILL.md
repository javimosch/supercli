# dae Plugin

eBPF-based Linux high-performance transparent proxy solution.

## Commands
- `dae <resource> <action>` — Execute dae commands
- `dae self version` — Print dae version
- `dae _ _` — Passthrough to dae CLI

## Installation

```bash
pip install dae
```
