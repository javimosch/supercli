# ppmdist Plugin

CLI tool: ppmdist.

## Commands
- `ppmdist <resource> <action>` — Execute ppmdist commands
- `ppmdist self version` — Print ppmdist version
- `ppmdist _ _` — Passthrough to ppmdist CLI

## Usage Examples
- "ppmdist --help"
- "ppmdist self version"

## Installation
```bash
apt-get install ppmdist 2>/dev/null || which ppmdist
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
