# powerlevel10k Plugin

Fast zsh theme with instant prompt — CLI configuration and status export

## Commands
- `powerlevel10k self version` — Print powerlevel10k version
- `powerlevel10k _ _` — Passthrough to powerlevel10k CLI

## Usage Examples
- `powerlevel10k self version` — Check installed version
- `powerlevel10k _ _ --help` — Show powerlevel10k help
- `powerlevel10k _ _ --json` — JSON output mode

## Installation
```bash
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ~/powerlevel10k
```

## Key Features
- zsh, theme, cli
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
