# ig Plugin

Instant grep — token-efficient CLI search for AI agents, mmap index, JSON output

## Commands
- `ig self version` — Print ig version
- `ig _ _` — Passthrough to ig CLI

## Usage Examples
- `ig self version` — Check installed version
- `ig _ _ --help` — Show ig help
- `ig _ _ --json` — JSON output mode

## Installation
```bash
curl -fsSL https://raw.githubusercontent.com/MakFly/instant-grep/main/install.sh | bash
```

## Key Features
- search, grep, ai-agents, rust
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
