# tflint Plugin
Pluggable Terraform linter with deep checking

## Commands
- `tflint <resource> <action>` — Execute tflint commands
- `tflint _ _` — Passthrough to tflint CLI

## Usage
- `tflint _ _ <args>` — Run tflint with any arguments
