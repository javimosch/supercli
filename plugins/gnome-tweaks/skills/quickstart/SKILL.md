# gnome-tweaks Plugin

CLI tool: gnome-tweaks.

## Commands
- `gnome-tweaks <resource> <action>` — Execute gnome-tweaks commands
- `gnome-tweaks self version` — Print gnome-tweaks version
- `gnome-tweaks _ _` — Passthrough to gnome-tweaks CLI

## Usage Examples
- "gnome-tweaks --help"
- "gnome-tweaks self version"

## Installation
```bash
apt-get install gnome-tweaks 2>/dev/null || which gnome-tweaks
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
