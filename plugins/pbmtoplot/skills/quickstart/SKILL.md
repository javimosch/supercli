# pbmtoplot Plugin

CLI tool: pbmtoplot.

## Commands
- `pbmtoplot <resource> <action>` — Execute pbmtoplot commands
- `pbmtoplot self version` — Print pbmtoplot version
- `pbmtoplot _ _` — Passthrough to pbmtoplot CLI

## Usage Examples
- "pbmtoplot --help"
- "pbmtoplot self version"

## Installation
```bash
apt-get install pbmtoplot 2>/dev/null || which pbmtoplot
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
