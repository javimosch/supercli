# gslp Plugin

CLI tool: gslp.

## Commands
- `gslp <resource> <action>` — Execute gslp commands
- `gslp self version` — Print gslp version
- `gslp _ _` — Passthrough to gslp CLI

## Usage Examples
- "gslp --help"
- "gslp self version"

## Installation
```bash
apt-get install gslp 2>/dev/null || which gslp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
