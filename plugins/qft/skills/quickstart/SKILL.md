# qft Plugin
CLI tool for qft.

## Commands
- `qft <resource> <action>` — Execute qft commands
- `qft _ _` — Passthrough to qft CLI

## Installation
```bash
cargo install qft
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
