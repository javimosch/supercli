# crypt-fs Plugin
Simple encrypted filesystem layer for directories

## Commands
- `crypt-fs <resource> <action>` — Execute crypt-fs commands
- `crypt-fs _ _` — Passthrough to crypt-fs CLI

## Usage
- `crypt-fs _ _ <args>` — Run crypt-fs with any arguments
