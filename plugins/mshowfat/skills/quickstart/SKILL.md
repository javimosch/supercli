# mshowfat Plugin

CLI tool: mshowfat.

## Commands
- `mshowfat <resource> <action>` — Execute mshowfat commands
- `mshowfat self version` — Print mshowfat version
- `mshowfat _ _` — Passthrough to mshowfat CLI

## Usage Examples
- "mshowfat --help"
- "mshowfat self version"

## Installation
```bash
apt-get install mshowfat 2>/dev/null || which mshowfat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
