# lzgrep Plugin

CLI tool: lzgrep.

## Commands
- `lzgrep <resource> <action>` — Execute lzgrep commands
- `lzgrep self version` — Print lzgrep version
- `lzgrep _ _` — Passthrough to lzgrep CLI

## Usage Examples
- "lzgrep --help"
- "lzgrep self version"

## Installation
```bash
apt-get install lzgrep 2>/dev/null || which lzgrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
