# rq Plugin
Converter for Avro CBOR Protobuf YAML and multiple data formats

## Commands
- `rq <resource> <action>` — Execute rq commands
- `rq _ _` — Passthrough to rq CLI

## Usage
- `rq _ _ <args>` — Run rq with any arguments
