# batt Plugin

Batteries for the terminal.

## Commands
- `batt <resource> <action>` — Execute batt commands
- `batt self version` — Print batt version
- `batt _ _` — Passthrough to batt CLI

## Usage Examples
- "batt --help"
- "batt self version"
