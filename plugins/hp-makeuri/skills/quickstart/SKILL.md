# hp-makeuri Plugin

CLI tool: hp-makeuri.

## Commands
- `hp-makeuri <resource> <action>` — Execute hp-makeuri commands
- `hp-makeuri self version` — Print hp-makeuri version
- `hp-makeuri _ _` — Passthrough to hp-makeuri CLI

## Usage Examples
- "hp-makeuri --help"
- "hp-makeuri self version"

## Installation
```bash
apt-get install hp-makeuri 2>/dev/null || which hp-makeuri
```
