# lexgrog Plugin

CLI tool: lexgrog.

## Commands
- `lexgrog <resource> <action>` — Execute lexgrog commands
- `lexgrog self version` — Print lexgrog version
- `lexgrog _ _` — Passthrough to lexgrog CLI

## Usage Examples
- "lexgrog --help"
- "lexgrog self version"

## Installation
```bash
apt-get install lexgrog 2>/dev/null || which lexgrog
```
