# hatchling Plugin
Build backend for Hatch Python project manager

## Commands
- `hatchling <resource> <action>` — Execute hatchling commands
- `hatchling _ _` — Passthrough to hatchling CLI

## Usage
- `hatchling _ _ <args>` — Run hatchling with any arguments
