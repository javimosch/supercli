# gnome-language-selector Plugin

CLI tool: gnome-language-selector.

## Commands
- `gnome-language-selector <resource> <action>` — Execute gnome-language-selector commands
- `gnome-language-selector self version` — Print gnome-language-selector version
- `gnome-language-selector _ _` — Passthrough to gnome-language-selector CLI

## Usage Examples
- "gnome-language-selector --help"
- "gnome-language-selector self version"

## Installation
```bash
apt-get install gnome-language-selector 2>/dev/null || which gnome-language-selector
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
