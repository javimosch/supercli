# fierce
fierce — DNS subdomain scanner. Locate non-contiguous IP space and hostnames using DNS.

## Commands
- `fierce <resource> <action>` — Execute fierce commands
- `fierce self version` — Print fierce version
- `fierce _ _` — Passthrough to fierce CLI
