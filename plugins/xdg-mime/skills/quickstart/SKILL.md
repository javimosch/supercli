# xdg-mime Plugin

CLI tool: xdg-mime.

## Commands
- `xdg-mime <resource> <action>` — Execute xdg-mime commands
- `xdg-mime self version` — Print xdg-mime version
- `xdg-mime _ _` — Passthrough to xdg-mime CLI

## Usage Examples
- "xdg-mime --help"
- "xdg-mime self version"

## Installation
```bash
apt-get install xdg-mime 2>/dev/null || which xdg-mime
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
