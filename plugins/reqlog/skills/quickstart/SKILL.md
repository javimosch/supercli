# reqlog Plugin
HTTP request tracer for distributed systems.
## Commands
- `reqlog _ _` — Passthrough to reqlog CLI
## Installation
```bash
go install github.com/chmouel/reqlog@latest
```
## Key Features
- **HTTP tracing** — Track request flows
- **Filtering** — Advanced request filtering
- **Pipeline-ready** — Structured output
