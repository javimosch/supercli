# luahbtex Plugin

CLI tool: luahbtex.

## Commands
- `luahbtex <resource> <action>` — Execute luahbtex commands
- `luahbtex self version` — Print luahbtex version
- `luahbtex _ _` — Passthrough to luahbtex CLI

## Usage Examples
- "luahbtex --help"
- "luahbtex self version"

## Installation
```bash
apt-get install luahbtex 2>/dev/null || which luahbtex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
