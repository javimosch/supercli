# isodump Plugin

CLI tool: isodump.

## Commands
- `isodump <resource> <action>` — Execute isodump commands
- `isodump self version` — Print isodump version
- `isodump _ _` — Passthrough to isodump CLI

## Usage Examples
- "isodump --help"
- "isodump self version"

## Installation
```bash
apt-get install isodump 2>/dev/null || which isodump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
