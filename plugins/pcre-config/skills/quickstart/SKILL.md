# pcre-config Plugin

CLI tool: pcre-config.

## Commands
- `pcre-config <resource> <action>` — Execute pcre-config commands
- `pcre-config self version` — Print pcre-config version
- `pcre-config _ _` — Passthrough to pcre-config CLI

## Usage Examples
- "pcre-config --help"
- "pcre-config self version"

## Installation
```bash
apt-get install pcre-config 2>/dev/null || which pcre-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
