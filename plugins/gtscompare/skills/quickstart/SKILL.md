# gtscompare Plugin

CLI tool: gtscompare.

## Commands
- `gtscompare <resource> <action>` — Execute gtscompare commands
- `gtscompare self version` — Print gtscompare version
- `gtscompare _ _` — Passthrough to gtscompare CLI

## Usage Examples
- "gtscompare --help"
- "gtscompare self version"

## Installation
```bash
apt-get install gtscompare 2>/dev/null || which gtscompare
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
