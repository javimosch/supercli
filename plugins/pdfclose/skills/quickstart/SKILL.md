# pdfclose Plugin

CLI tool: pdfclose.

## Commands
- `pdfclose <resource> <action>` — Execute pdfclose commands
- `pdfclose self version` — Print pdfclose version
- `pdfclose _ _` — Passthrough to pdfclose CLI

## Usage Examples
- "pdfclose --help"
- "pdfclose self version"

## Installation
```bash
apt-get install pdfclose 2>/dev/null || which pdfclose
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
