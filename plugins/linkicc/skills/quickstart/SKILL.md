# linkicc Plugin

CLI tool: linkicc.

## Commands
- `linkicc <resource> <action>` — Execute linkicc commands
- `linkicc self version` — Print linkicc version
- `linkicc _ _` — Passthrough to linkicc CLI

## Usage Examples
- "linkicc --help"
- "linkicc self version"

## Installation
```bash
apt-get install linkicc 2>/dev/null || which linkicc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
