# Pdfx Plugin

React PDF component library with pre-built components and CLI for PDF creation

## Commands
- `pdfx _ _` — Passthrough to pdfx CLI

## Installation

```bash
npm install -g pdfx
```

## Examples
```bash
pdfx --help
pdfx --version
```
