# TrollFools Plugin

In-place tweak injection with insert_dylib and ChOma.

## Commands

### General
- `TrollFools self version` — Print TrollFools version
- `TrollFools _ _` — Passthrough to trollfools CLI

## Usage Examples
- "Run TrollFools"
- "Use trollfools to In-place tweak injection with insert_dylib and ChOma."

## Installation

```bash
pip install trollfools
```

## Key Features
- In-place tweak injection with insert_dylib and ChOma.
- CLI tool, headless and scriptable
