# fzputtygen Plugin

CLI tool: fzputtygen.

## Commands
- `fzputtygen <resource> <action>` — Execute fzputtygen commands
- `fzputtygen self version` — Print fzputtygen version
- `fzputtygen _ _` — Passthrough to fzputtygen CLI

## Usage Examples
- "fzputtygen --help"
- "fzputtygen self version"

## Installation
```bash
apt-get install fzputtygen 2>/dev/null || which fzputtygen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
