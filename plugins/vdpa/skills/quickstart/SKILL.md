# vdpa Plugin

CLI tool: vdpa.

## Commands
- `vdpa <resource> <action>` — Execute vdpa commands
- `vdpa self version` — Print vdpa version
- `vdpa _ _` — Passthrough to vdpa CLI

## Usage Examples
- "vdpa --help"
- "vdpa self version"

## Installation
```bash
apt-get install vdpa 2>/dev/null || which vdpa
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
