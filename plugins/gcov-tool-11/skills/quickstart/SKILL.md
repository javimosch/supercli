# gcov-tool-11 Plugin

CLI tool: gcov-tool-11.

## Commands
- `gcov-tool-11 <resource> <action>` — Execute gcov-tool-11 commands
- `gcov-tool-11 self version` — Print gcov-tool-11 version
- `gcov-tool-11 _ _` — Passthrough to gcov-tool-11 CLI

## Usage Examples
- "gcov-tool-11 --help"
- "gcov-tool-11 self version"

## Installation
```bash
apt-get install gcov-tool-11 2>/dev/null || which gcov-tool-11
```
