# ptftopl Plugin

CLI tool: ptftopl.

## Commands
- `ptftopl <resource> <action>` — Execute ptftopl commands
- `ptftopl self version` — Print ptftopl version
- `ptftopl _ _` — Passthrough to ptftopl CLI

## Usage Examples
- "ptftopl --help"
- "ptftopl self version"

## Installation
```bash
apt-get install ptftopl 2>/dev/null || which ptftopl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
