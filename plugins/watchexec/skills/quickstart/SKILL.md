# watchexec Plugin

Execute commands in response to file modifications

## Installation

```bash
brew install watchexec
Verify: watchexec --version
```

## Commands

### `sc watchexec self version`

Version


## Passthrough

```bash
sc watchexec _ _ <args...>
```

## SuperCLI

```bash
sc watchexec _ _ --help
sc plugins learn watchexec
```
