# repo-radar-cli Plugin

GitHub repo monitoring CLI — track stars, issues, and releases with JSON export

## Commands
- `repo-radar-cli self version` — Print repo-radar-cli version
- `repo-radar-cli _ _` — Passthrough to repo-radar CLI

## Usage Examples
- `repo-radar-cli self version` — Check installed version
- `repo-radar-cli _ _ --help` — Show repo-radar-cli help
- `repo-radar-cli _ _ --json` — JSON output mode

## Installation
```bash
cargo install repo-radar-cli
```

## Key Features
- github, monitoring, rust, cli
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
