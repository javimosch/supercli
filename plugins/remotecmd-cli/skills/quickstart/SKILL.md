# remotecmd-cli Plugin

CLI tool: remotecmd-cli.

## Commands
- `remotecmd-cli <resource> <action>` — Execute remotecmd-cli commands
- `remotecmd-cli self version` — Print remotecmd-cli version
- `remotecmd-cli _ _` — Passthrough to remotecmd-cli CLI

## Usage Examples
- "remotecmd-cli --help"
- "remotecmd-cli self version"

## Installation
```bash
apt-get install remotecmd-cli 2>/dev/null || which remotecmd-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
