# wamp Plugin

CLI tool: wamp.

## Commands
- `wamp <resource> <action>` — Execute wamp commands
- `wamp self version` — Print wamp version
- `wamp _ _` — Passthrough to wamp CLI

## Usage Examples
- "wamp --help"
- "wamp self version"

## Installation
```bash
apt-get install wamp 2>/dev/null || which wamp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
