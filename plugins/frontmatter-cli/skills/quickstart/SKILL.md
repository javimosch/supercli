# frontmatter-cli Plugin
Extract and parse frontmatter from markdown files

## Commands
- `frontmatter-cli <resource> <action>` — Execute frontmatter-cli commands
- `frontmatter-cli _ _` — Passthrough to frontmatter-cli CLI

## Usage
- `frontmatter-cli _ _ <args>` — Run frontmatter-cli with any arguments
