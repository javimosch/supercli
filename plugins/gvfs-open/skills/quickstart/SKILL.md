# gvfs-open Plugin

CLI tool: gvfs-open.

## Commands
- `gvfs-open <resource> <action>` — Execute gvfs-open commands
- `gvfs-open self version` — Print gvfs-open version
- `gvfs-open _ _` — Passthrough to gvfs-open CLI

## Usage Examples
- "gvfs-open --help"
- "gvfs-open self version"

## Installation
```bash
apt-get install gvfs-open 2>/dev/null || which gvfs-open
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
