# mcopy Plugin

CLI tool: mcopy.

## Commands
- `mcopy <resource> <action>` — Execute mcopy commands
- `mcopy self version` — Print mcopy version
- `mcopy _ _` — Passthrough to mcopy CLI

## Usage Examples
- "mcopy --help"
- "mcopy self version"

## Installation
```bash
apt-get install mcopy 2>/dev/null || which mcopy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
