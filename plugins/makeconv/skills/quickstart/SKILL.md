# makeconv Plugin

CLI tool: makeconv.

## Commands
- `makeconv <resource> <action>` — Execute makeconv commands
- `makeconv self version` — Print makeconv version
- `makeconv _ _` — Passthrough to makeconv CLI

## Usage Examples
- "makeconv --help"
- "makeconv self version"

## Installation
```bash
apt-get install makeconv 2>/dev/null || which makeconv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
