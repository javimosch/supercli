# pacmd Plugin

CLI tool: pacmd.

## Commands
- `pacmd <resource> <action>` — Execute pacmd commands
- `pacmd self version` — Print pacmd version
- `pacmd _ _` — Passthrough to pacmd CLI

## Usage Examples
- "pacmd --help"
- "pacmd self version"

## Installation
```bash
apt-get install pacmd 2>/dev/null || which pacmd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
