# xzless Plugin

CLI tool: xzless.

## Commands
- `xzless <resource> <action>` — Execute xzless commands
- `xzless self version` — Print xzless version
- `xzless _ _` — Passthrough to xzless CLI

## Usage Examples
- "xzless --help"
- "xzless self version"

## Installation
```bash
apt-get install xzless 2>/dev/null || which xzless
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
