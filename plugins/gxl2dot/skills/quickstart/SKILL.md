# gxl2dot Plugin

CLI tool: gxl2dot.

## Commands
- `gxl2dot <resource> <action>` — Execute gxl2dot commands
- `gxl2dot self version` — Print gxl2dot version
- `gxl2dot _ _` — Passthrough to gxl2dot CLI

## Usage Examples
- "gxl2dot --help"
- "gxl2dot self version"

## Installation
```bash
apt-get install gxl2dot 2>/dev/null || which gxl2dot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
