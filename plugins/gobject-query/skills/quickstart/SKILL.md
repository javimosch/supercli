# gobject-query Plugin

CLI tool: gobject-query.

## Commands
- `gobject-query <resource> <action>` — Execute gobject-query commands
- `gobject-query self version` — Print gobject-query version
- `gobject-query _ _` — Passthrough to gobject-query CLI

## Usage Examples
- "gobject-query --help"
- "gobject-query self version"

## Installation
```bash
apt-get install gobject-query 2>/dev/null || which gobject-query
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
