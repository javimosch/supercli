# lightning-lm Plugin

Lidar Localization and Mapping

## Commands

### General
- `lightning-lm self version` — Print lightning-lm version
- `lightning-lm _ _` — Passthrough to lightning-lm CLI

## Usage Examples
- "Run lightning-lm"

## Installation

```bash
pip install lightning-lm
```

## Key Features
- Lidar Localization and Mapping
- CLI tool, headless and scriptable
