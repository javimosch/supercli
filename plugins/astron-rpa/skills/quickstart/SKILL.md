# astron-rpa Plugin

Agent-ready RPA suite with out-of-the-box automation tools. Built for individuals and enterprises.

## Commands

### General
- `astron-rpa self version` — Print astron-rpa version
- `astron-rpa _ _` — Passthrough to astron-rpa CLI
