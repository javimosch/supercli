# lxc-create Plugin

CLI tool: lxc-create.

## Commands
- `lxc-create <resource> <action>` — Execute lxc-create commands
- `lxc-create self version` — Print lxc-create version
- `lxc-create _ _` — Passthrough to lxc-create CLI

## Usage Examples
- "lxc-create --help"
- "lxc-create self version"

## Installation
```bash
apt-get install lxc-create 2>/dev/null || which lxc-create
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
