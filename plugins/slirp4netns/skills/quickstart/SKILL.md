# slirp4netns Plugin

CLI tool: slirp4netns.

## Commands
- `slirp4netns <resource> <action>` — Execute slirp4netns commands
- `slirp4netns self version` — Print slirp4netns version
- `slirp4netns _ _` — Passthrough to slirp4netns CLI

## Usage Examples
- "slirp4netns --help"
- "slirp4netns self version"

## Installation
```bash
apt-get install slirp4netns 2>/dev/null || which slirp4netns
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
