# gts-config Plugin

CLI tool: gts-config.

## Commands
- `gts-config <resource> <action>` — Execute gts-config commands
- `gts-config self version` — Print gts-config version
- `gts-config _ _` — Passthrough to gts-config CLI

## Usage Examples
- "gts-config --help"
- "gts-config self version"

## Installation
```bash
apt-get install gts-config 2>/dev/null || which gts-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
