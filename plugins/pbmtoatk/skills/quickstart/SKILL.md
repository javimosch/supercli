# pbmtoatk Plugin

CLI tool: pbmtoatk.

## Commands
- `pbmtoatk <resource> <action>` — Execute pbmtoatk commands
- `pbmtoatk self version` — Print pbmtoatk version
- `pbmtoatk _ _` — Passthrough to pbmtoatk CLI

## Usage Examples
- "pbmtoatk --help"
- "pbmtoatk self version"

## Installation
```bash
apt-get install pbmtoatk 2>/dev/null || which pbmtoatk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
