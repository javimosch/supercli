# burp-ai-agent Plugin

Burp Suite extension that adds built-in MCP tooling, AI-assisted analysis, privacy controls, passive and active scanning and more

## Commands

### General
- `burp-ai-agent self version` — Print burp-ai-agent version
- `burp-ai-agent _ _` — Passthrough to burp-ai-agent CLI

## Installation

```bash
pip install burp-ai-agent
```

## Key Features
- Burp Suite extension that adds built-in MCP tooling, AI-assisted analysis, privacy controls, passive
