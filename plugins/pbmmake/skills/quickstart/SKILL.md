# pbmmake Plugin

CLI tool: pbmmake.

## Commands
- `pbmmake <resource> <action>` — Execute pbmmake commands
- `pbmmake self version` — Print pbmmake version
- `pbmmake _ _` — Passthrough to pbmmake CLI

## Usage Examples
- "pbmmake --help"
- "pbmmake self version"

## Installation
```bash
apt-get install pbmmake 2>/dev/null || which pbmmake
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
