# usbmuxd Plugin

CLI tool: usbmuxd.

## Commands
- `usbmuxd <resource> <action>` — Execute usbmuxd commands
- `usbmuxd self version` — Print usbmuxd version
- `usbmuxd _ _` — Passthrough to usbmuxd CLI

## Usage Examples
- "usbmuxd --help"
- "usbmuxd self version"

## Installation
```bash
apt-get install usbmuxd 2>/dev/null || which usbmuxd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
