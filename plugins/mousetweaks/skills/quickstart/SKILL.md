# mousetweaks Plugin

CLI tool: mousetweaks.

## Commands
- `mousetweaks <resource> <action>` — Execute mousetweaks commands
- `mousetweaks self version` — Print mousetweaks version
- `mousetweaks _ _` — Passthrough to mousetweaks CLI

## Usage Examples
- "mousetweaks --help"
- "mousetweaks self version"

## Installation
```bash
apt-get install mousetweaks 2>/dev/null || which mousetweaks
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
