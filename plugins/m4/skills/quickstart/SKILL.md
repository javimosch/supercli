# m4 Plugin

CLI tool: m4.

## Commands
- `m4 <resource> <action>` — Execute m4 commands
- `m4 self version` — Print m4 version
- `m4 _ _` — Passthrough to m4 CLI

## Usage Examples
- "m4 --help"
- "m4 self version"

## Installation
```bash
apt-get install m4 2>/dev/null || which m4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
