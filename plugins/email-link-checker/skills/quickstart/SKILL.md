# email-link-checker Plugin
Detect dead links in HTML email files from CLI

## Commands
- `email-link-checker <resource> <action>` — Execute email-link-checker commands
- `email-link-checker _ _` — Passthrough to email-link-checker CLI

## Usage
- `email-link-checker _ _ <args>` — Run email-link-checker with any arguments
