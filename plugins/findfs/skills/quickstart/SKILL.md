# findfs Plugin

CLI tool: findfs.

## Commands
- `findfs <resource> <action>` — Execute findfs commands
- `findfs self version` — Print findfs version
- `findfs _ _` — Passthrough to findfs CLI

## Usage Examples
- "findfs --help"
- "findfs self version"

## Installation
```bash
apt-get install findfs 2>/dev/null || which findfs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
