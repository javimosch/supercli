# unflatten Plugin

CLI tool: unflatten.

## Commands
- `unflatten <resource> <action>` — Execute unflatten commands
- `unflatten self version` — Print unflatten version
- `unflatten _ _` — Passthrough to unflatten CLI

## Usage Examples
- "unflatten --help"
- "unflatten self version"

## Installation
```bash
apt-get install unflatten 2>/dev/null || which unflatten
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
