# commitmsgfmt Plugin
Format git commit messages to conventional style

## Commands
- `commitmsgfmt <resource> <action>` — Execute commitmsgfmt commands
- `commitmsgfmt _ _` — Passthrough to commitmsgfmt CLI

## Usage
- `commitmsgfmt _ _ <args>` — Run commitmsgfmt with any arguments
