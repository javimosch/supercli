# nodeenv Plugin

CLI tool: nodeenv.

## Commands
- `nodeenv <resource> <action>` — Execute nodeenv commands
- `nodeenv self version` — Print nodeenv version
- `nodeenv _ _` — Passthrough to nodeenv CLI

## Usage Examples
- "nodeenv --help"
- "nodeenv self version"

## Installation
```bash
apt-get install nodeenv 2>/dev/null || which nodeenv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
