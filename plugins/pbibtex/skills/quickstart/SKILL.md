# pbibtex Plugin

CLI tool: pbibtex.

## Commands
- `pbibtex <resource> <action>` — Execute pbibtex commands
- `pbibtex self version` — Print pbibtex version
- `pbibtex _ _` — Passthrough to pbibtex CLI

## Usage Examples
- "pbibtex --help"
- "pbibtex self version"

## Installation
```bash
apt-get install pbibtex 2>/dev/null || which pbibtex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
