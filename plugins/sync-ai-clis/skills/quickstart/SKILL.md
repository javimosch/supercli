# sync-ai-clis Plugin

Detect, install, update, and verify AI coding CLIs across platforms

## Commands
- `sync-ai-clis self version` — Print sync-ai-clis version
- `sync-ai-clis _ _` — Passthrough to sync-ai-clis CLI

## Usage Examples
- `sync-ai-clis self version` — Check installed version
- `sync-ai-clis _ _ --help` — Show sync-ai-clis help
- `sync-ai-clis _ _ --json` — JSON output mode

## Installation
```bash
cargo install sync-ai-clis
```

## Key Features
- ai, cli, installer, rust
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
