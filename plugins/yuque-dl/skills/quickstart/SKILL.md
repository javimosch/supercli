# Yuque-Dl Plugin

Download Yuque knowledge base documents and export to local storage

## Commands
- `yuque-dl _ _` — Passthrough to yuque-dl CLI

## Installation

```bash
npm install -g yuque-dl
```

## Examples
```bash
yuque-dl --help
yuque-dl --version
```
