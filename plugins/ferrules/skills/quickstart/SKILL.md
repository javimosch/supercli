# ferrules Plugin

Modern fast document parser in Rust — generates LLM-ready documents from PDFs

## Commands
- `ferrules self version` — Print ferrules version
- `ferrules _ _` — Passthrough to ferrules CLI

## Usage Examples
- `ferrules self version` — Check installed version
- `ferrules _ _ --help` — Show ferrules help
- `ferrules _ _ --json` — JSON output mode

## Installation
```bash
cargo install ferrules
```

## Key Features
- pdf, document, rust, llm
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
