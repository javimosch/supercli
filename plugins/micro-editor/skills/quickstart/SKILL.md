# micro-editor Plugin
Modern and intuitive terminal-based text editor

## Commands
- `micro-editor <resource> <action>` — Execute micro-editor commands
- `micro-editor _ _` — Passthrough to micro-editor CLI

## Usage
- `micro-editor _ _ <args>` — Run micro-editor with any arguments
