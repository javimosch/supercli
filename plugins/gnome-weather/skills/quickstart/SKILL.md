# gnome-weather Plugin

CLI tool: gnome-weather.

## Commands
- `gnome-weather <resource> <action>` — Execute gnome-weather commands
- `gnome-weather self version` — Print gnome-weather version
- `gnome-weather _ _` — Passthrough to gnome-weather CLI

## Usage Examples
- "gnome-weather --help"
- "gnome-weather self version"

## Installation
```bash
apt-get install gnome-weather 2>/dev/null || which gnome-weather
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
