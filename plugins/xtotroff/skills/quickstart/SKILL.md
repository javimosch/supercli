# xtotroff Plugin

CLI tool: xtotroff.

## Commands
- `xtotroff <resource> <action>` — Execute xtotroff commands
- `xtotroff self version` — Print xtotroff version
- `xtotroff _ _` — Passthrough to xtotroff CLI

## Usage Examples
- "xtotroff --help"
- "xtotroff self version"

## Installation
```bash
apt-get install xtotroff 2>/dev/null || which xtotroff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
