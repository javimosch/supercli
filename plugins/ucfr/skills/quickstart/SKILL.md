# ucfr Plugin

CLI tool: ucfr.

## Commands
- `ucfr <resource> <action>` — Execute ucfr commands
- `ucfr self version` — Print ucfr version
- `ucfr _ _` — Passthrough to ucfr CLI

## Usage Examples
- "ucfr --help"
- "ucfr self version"

## Installation
```bash
apt-get install ucfr 2>/dev/null || which ucfr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
