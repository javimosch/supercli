# gtk4-builder-tool Plugin

CLI tool: gtk4-builder-tool.

## Commands
- `gtk4-builder-tool <resource> <action>` — Execute gtk4-builder-tool commands
- `gtk4-builder-tool self version` — Print gtk4-builder-tool version
- `gtk4-builder-tool _ _` — Passthrough to gtk4-builder-tool CLI

## Usage Examples
- "gtk4-builder-tool --help"
- "gtk4-builder-tool self version"

## Installation
```bash
apt-get install gtk4-builder-tool 2>/dev/null || which gtk4-builder-tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
