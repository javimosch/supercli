# cups.accept Plugin

CLI tool: cups.accept.

## Commands
- `cups.accept <resource> <action>` — Execute cups.accept commands
- `cups.accept self version` — Print cups.accept version
- `cups.accept _ _` — Passthrough to cups.accept CLI

## Usage Examples
- "cups.accept --help"
- "cups.accept self version"

## Installation
```bash
apt-get install cups.accept 2>/dev/null || which cups.accept
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
