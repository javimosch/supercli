# yazap Plugin
Zig CLI argument parsing tool.
## Commands
- `yazap _ _` — Passthrough to yazap CLI
## Installation
```bash
git clone https://github.com/PrajwalCH/yazap && cd yazap && zig build
```
## Key Features
- **Type-safe** — Zig-native argument parsing
- **Fast** — Minimal overhead
- **CLI building** — Argument handling
