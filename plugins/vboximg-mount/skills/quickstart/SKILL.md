# vboximg-mount Plugin

CLI tool: vboximg-mount.

## Commands
- `vboximg-mount <resource> <action>` — Execute vboximg-mount commands
- `vboximg-mount self version` — Print vboximg-mount version
- `vboximg-mount _ _` — Passthrough to vboximg-mount CLI

## Usage Examples
- "vboximg-mount --help"
- "vboximg-mount self version"

## Installation
```bash
apt-get install vboximg-mount 2>/dev/null || which vboximg-mount
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
