# gnome-extensions-app Plugin

CLI tool: gnome-extensions-app.

## Commands
- `gnome-extensions-app <resource> <action>` — Execute gnome-extensions-app commands
- `gnome-extensions-app self version` — Print gnome-extensions-app version
- `gnome-extensions-app _ _` — Passthrough to gnome-extensions-app CLI

## Usage Examples
- "gnome-extensions-app --help"
- "gnome-extensions-app self version"

## Installation
```bash
apt-get install gnome-extensions-app 2>/dev/null || which gnome-extensions-app
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
