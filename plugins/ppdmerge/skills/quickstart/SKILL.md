# ppdmerge Plugin

CLI tool: ppdmerge.

## Commands
- `ppdmerge <resource> <action>` — Execute ppdmerge commands
- `ppdmerge self version` — Print ppdmerge version
- `ppdmerge _ _` — Passthrough to ppdmerge CLI

## Usage Examples
- "ppdmerge --help"
- "ppdmerge self version"

## Installation
```bash
apt-get install ppdmerge 2>/dev/null || which ppdmerge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
