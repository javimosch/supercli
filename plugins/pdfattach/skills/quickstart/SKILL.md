# pdfattach Plugin

CLI tool: pdfattach.

## Commands
- `pdfattach <resource> <action>` — Execute pdfattach commands
- `pdfattach self version` — Print pdfattach version
- `pdfattach _ _` — Passthrough to pdfattach CLI

## Usage Examples
- "pdfattach --help"
- "pdfattach self version"

## Installation
```bash
apt-get install pdfattach 2>/dev/null || which pdfattach
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
