# google Plugin

CLI tool: google.

## Commands
- `google <resource> <action>` — Execute google commands
- `google self version` — Print google version
- `google _ _` — Passthrough to google CLI

## Usage Examples
- "google --help"
- "google self version"

## Installation
```bash
apt-get install google 2>/dev/null || which google
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
