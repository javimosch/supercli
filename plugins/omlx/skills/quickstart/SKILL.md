# Omlx Plugin

LLM inference server with continuous batching and SSD caching for Apple Silicon

## Commands
- `omlx _ _` — Passthrough to omlx CLI

## Installation

```bash
pip install omlx
```

## Examples
```bash
omlx --help
omlx --version
```
