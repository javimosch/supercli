# xfce4-panel Plugin

CLI tool: xfce4-panel.

## Commands
- `xfce4-panel <resource> <action>` — Execute xfce4-panel commands
- `xfce4-panel self version` — Print xfce4-panel version
- `xfce4-panel _ _` — Passthrough to xfce4-panel CLI

## Usage Examples
- "xfce4-panel --help"
- "xfce4-panel self version"

## Installation
```bash
apt-get install xfce4-panel 2>/dev/null || which xfce4-panel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
