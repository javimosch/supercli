# qmlscene Plugin

CLI tool: qmlscene.

## Commands
- `qmlscene <resource> <action>` — Execute qmlscene commands
- `qmlscene self version` — Print qmlscene version
- `qmlscene _ _` — Passthrough to qmlscene CLI

## Usage Examples
- "qmlscene --help"
- "qmlscene self version"

## Installation
```bash
apt-get install qmlscene 2>/dev/null || which qmlscene
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
