# limactl Plugin
Linux virtual machines on macOS with Lima

## Commands
- `limactl <resource> <action>` — Execute limactl commands
- `limactl _ _` — Passthrough to limactl CLI

## Usage
- `limactl _ _ <args>` — Run limactl with any arguments
