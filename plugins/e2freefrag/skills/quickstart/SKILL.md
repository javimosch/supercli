# e2freefrag Plugin

CLI tool: e2freefrag.

## Commands
- `e2freefrag <resource> <action>` — Execute e2freefrag commands
- `e2freefrag self version` — Print e2freefrag version
- `e2freefrag _ _` — Passthrough to e2freefrag CLI

## Usage Examples
- "e2freefrag --help"
- "e2freefrag self version"

## Installation
```bash
apt-get install e2freefrag 2>/dev/null || which e2freefrag
```
