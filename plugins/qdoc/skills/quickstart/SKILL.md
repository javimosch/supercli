# qdoc Plugin

CLI tool: qdoc.

## Commands
- `qdoc <resource> <action>` — Execute qdoc commands
- `qdoc self version` — Print qdoc version
- `qdoc _ _` — Passthrough to qdoc CLI

## Usage Examples
- "qdoc --help"
- "qdoc self version"

## Installation
```bash
apt-get install qdoc 2>/dev/null || which qdoc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
