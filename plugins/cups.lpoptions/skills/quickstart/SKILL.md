# cups.lpoptions Plugin

CLI tool: cups.lpoptions.

## Commands
- `cups.lpoptions <resource> <action>` — Execute cups.lpoptions commands
- `cups.lpoptions self version` — Print cups.lpoptions version
- `cups.lpoptions _ _` — Passthrough to cups.lpoptions CLI

## Usage Examples
- "cups.lpoptions --help"
- "cups.lpoptions self version"

## Installation
```bash
apt-get install cups.lpoptions 2>/dev/null || which cups.lpoptions
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
