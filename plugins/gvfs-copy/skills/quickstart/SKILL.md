# gvfs-copy Plugin

CLI tool: gvfs-copy.

## Commands
- `gvfs-copy <resource> <action>` — Execute gvfs-copy commands
- `gvfs-copy self version` — Print gvfs-copy version
- `gvfs-copy _ _` — Passthrough to gvfs-copy CLI

## Usage Examples
- "gvfs-copy --help"
- "gvfs-copy self version"

## Installation
```bash
apt-get install gvfs-copy 2>/dev/null || which gvfs-copy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
