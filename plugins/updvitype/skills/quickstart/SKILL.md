# updvitype Plugin

CLI tool: updvitype.

## Commands
- `updvitype <resource> <action>` — Execute updvitype commands
- `updvitype self version` — Print updvitype version
- `updvitype _ _` — Passthrough to updvitype CLI

## Usage Examples
- "updvitype --help"
- "updvitype self version"

## Installation
```bash
apt-get install updvitype 2>/dev/null || which updvitype
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
