# lefty Plugin

CLI tool: lefty.

## Commands
- `lefty <resource> <action>` — Execute lefty commands
- `lefty self version` — Print lefty version
- `lefty _ _` — Passthrough to lefty CLI

## Usage Examples
- "lefty --help"
- "lefty self version"

## Installation
```bash
apt-get install lefty 2>/dev/null || which lefty
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
