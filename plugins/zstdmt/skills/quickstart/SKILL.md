# zstdmt Plugin

CLI tool: zstdmt.

## Commands
- `zstdmt <resource> <action>` — Execute zstdmt commands
- `zstdmt self version` — Print zstdmt version
- `zstdmt _ _` — Passthrough to zstdmt CLI

## Usage Examples
- "zstdmt --help"
- "zstdmt self version"

## Installation
```bash
apt-get install zstdmt 2>/dev/null || which zstdmt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
