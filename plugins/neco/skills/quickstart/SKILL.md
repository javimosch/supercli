# neco Plugin

Concurrency library for C (coroutines)

## Commands

### General
- `neco self version` — Print neco version
- `neco _ _` — Passthrough to neco CLI

```bash
pip install neco
```

- Concurrency library for C (coroutines)
- CLI tool, headless and scriptable
