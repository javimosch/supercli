# import-im6 Plugin

CLI tool: import-im6.

## Commands
- `import-im6 <resource> <action>` — Execute import-im6 commands
- `import-im6 self version` — Print import-im6 version
- `import-im6 _ _` — Passthrough to import-im6 CLI
