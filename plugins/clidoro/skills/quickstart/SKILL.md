# clidoro Plugin
Terminal Pomodoro timer with task tracking integration

## Commands
- `clidoro <resource> <action>` — Execute clidoro commands
- `clidoro _ _` — Passthrough to clidoro CLI

## Usage
- `clidoro _ _ <args>` — Run clidoro with any arguments
