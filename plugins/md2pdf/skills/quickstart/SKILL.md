# md2pdf Plugin
Simple Go-based Markdown to PDF converter

## Commands
- `md2pdf <resource> <action>` — Execute md2pdf commands
- `md2pdf _ _` — Passthrough to md2pdf CLI

## Usage
- `md2pdf _ _ <args>` — Run md2pdf with any arguments
