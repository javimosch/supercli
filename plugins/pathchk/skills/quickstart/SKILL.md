# pathchk Plugin
Check filename portability

## Commands
- `pathchk <resource> <action>` — Execute pathchk commands
- `pathchk self version` — Print pathchk version
- `pathchk _ _` — Passthrough to pathchk CLI

## Usage
- `pathchk _ _ <args>` — Run pathchk with any arguments
