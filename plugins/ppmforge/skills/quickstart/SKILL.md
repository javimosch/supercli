# ppmforge Plugin

CLI tool: ppmforge.

## Commands
- `ppmforge <resource> <action>` — Execute ppmforge commands
- `ppmforge self version` — Print ppmforge version
- `ppmforge _ _` — Passthrough to ppmforge CLI

## Usage Examples
- "ppmforge --help"
- "ppmforge self version"

## Installation
```bash
apt-get install ppmforge 2>/dev/null || which ppmforge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
