# jjs Plugin

CLI tool: jjs.

## Commands
- `jjs <resource> <action>` — Execute jjs commands
- `jjs self version` — Print jjs version
- `jjs _ _` — Passthrough to jjs CLI

## Usage Examples
- "jjs --help"
- "jjs self version"

## Installation
```bash
apt-get install jjs 2>/dev/null || which jjs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
