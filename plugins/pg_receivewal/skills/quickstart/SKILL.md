# pg_receivewal Plugin

CLI tool: pg_receivewal.

## Commands
- `pg_receivewal <resource> <action>` — Execute pg_receivewal commands
- `pg_receivewal self version` — Print pg_receivewal version
- `pg_receivewal _ _` — Passthrough to pg_receivewal CLI

```bash
apt-get install pg_receivewal 2>/dev/null || which pg_receivewal
```
