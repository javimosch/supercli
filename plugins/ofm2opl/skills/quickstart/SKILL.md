# ofm2opl Plugin

CLI tool: ofm2opl.

## Commands
- `ofm2opl <resource> <action>` — Execute ofm2opl commands
- `ofm2opl self version` — Print ofm2opl version
- `ofm2opl _ _` — Passthrough to ofm2opl CLI

## Usage Examples
- "ofm2opl --help"
- "ofm2opl self version"

## Installation
```bash
apt-get install ofm2opl 2>/dev/null || which ofm2opl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
