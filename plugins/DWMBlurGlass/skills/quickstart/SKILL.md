# DWMBlurGlass Plugin

Add custom effect to global system title bar, support win10 and win11.

## Commands

### General
- `DWMBlurGlass self version` — Print DWMBlurGlass version
- `DWMBlurGlass _ _` — Passthrough to dwmblurglass CLI

## Usage Examples
- "Run DWMBlurGlass"
- "Use dwmblurglass to Add custom effect to global system title bar, support win10 "

## Installation

```bash
pip install dwmblurglass
```

## Key Features
- Add custom effect to global system title bar, support win10 and win11.
- CLI tool, headless and scriptable
