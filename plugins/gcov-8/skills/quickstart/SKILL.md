# gcov-8 Plugin

CLI tool: gcov-8.

## Commands
- `gcov-8 <resource> <action>` — Execute gcov-8 commands
- `gcov-8 self version` — Print gcov-8 version
- `gcov-8 _ _` — Passthrough to gcov-8 CLI

## Usage Examples
- "gcov-8 --help"
- "gcov-8 self version"

## Installation
```bash
apt-get install gcov-8 2>/dev/null || which gcov-8
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
