# OpenCode Plugin

CLI tool: OpenCode.

## Commands
- `OpenCode <resource> <action>` — Execute OpenCode commands
- `OpenCode self version` — Print OpenCode version
- `OpenCode _ _` — Passthrough to OpenCode CLI

## Usage Examples
- "OpenCode --help"
- "OpenCode self version"

## Installation
```bash
apt-get install OpenCode 2>/dev/null || which OpenCode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
