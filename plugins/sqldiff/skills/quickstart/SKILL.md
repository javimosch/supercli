# sqldiff Plugin

CLI tool: sqldiff.

## Commands
- `sqldiff <resource> <action>` — Execute sqldiff commands
- `sqldiff self version` — Print sqldiff version
- `sqldiff _ _` — Passthrough to sqldiff CLI

## Usage Examples
- "sqldiff --help"
- "sqldiff self version"

## Installation
```bash
apt-get install sqldiff 2>/dev/null || which sqldiff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
