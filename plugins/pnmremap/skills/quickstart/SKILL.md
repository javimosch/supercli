# pnmremap Plugin

CLI tool: pnmremap.

## Commands
- `pnmremap <resource> <action>` — Execute pnmremap commands
- `pnmremap self version` — Print pnmremap version
- `pnmremap _ _` — Passthrough to pnmremap CLI

## Usage Examples
- "pnmremap --help"
- "pnmremap self version"

## Installation
```bash
apt-get install pnmremap 2>/dev/null || which pnmremap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
