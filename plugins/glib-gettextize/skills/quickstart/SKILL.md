# glib-gettextize Plugin

CLI tool: glib-gettextize.

## Commands
- `glib-gettextize <resource> <action>` — Execute glib-gettextize commands
- `glib-gettextize self version` — Print glib-gettextize version
- `glib-gettextize _ _` — Passthrough to glib-gettextize CLI

## Usage Examples
- "glib-gettextize --help"
- "glib-gettextize self version"

## Installation
```bash
apt-get install glib-gettextize 2>/dev/null || which glib-gettextize
```
