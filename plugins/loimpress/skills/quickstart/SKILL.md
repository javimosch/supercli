# loimpress Plugin

CLI tool: loimpress.

## Commands
- `loimpress <resource> <action>` — Execute loimpress commands
- `loimpress self version` — Print loimpress version
- `loimpress _ _` — Passthrough to loimpress CLI

## Usage Examples
- "loimpress --help"
- "loimpress self version"

## Installation
```bash
apt-get install loimpress 2>/dev/null || which loimpress
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
