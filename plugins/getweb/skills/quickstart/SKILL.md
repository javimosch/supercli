# getweb Plugin

CLI tool: getweb.

## Commands
- `getweb <resource> <action>` — Execute getweb commands
- `getweb self version` — Print getweb version
- `getweb _ _` — Passthrough to getweb CLI

## Usage Examples
- "getweb --help"
- "getweb self version"

## Installation
```bash
apt-get install getweb 2>/dev/null || which getweb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
