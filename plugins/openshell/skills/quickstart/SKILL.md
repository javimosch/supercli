# openshell Plugin

CLI tool: openshell.

## Commands
- `openshell <resource> <action>` — Execute openshell commands
- `openshell self version` — Print openshell version
- `openshell _ _` — Passthrough to openshell CLI

## Usage Examples
- "openshell --help"
- "openshell self version"

## Installation
```bash
apt-get install openshell 2>/dev/null || which openshell
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
