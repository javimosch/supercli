# gv2gml Plugin

CLI tool: gv2gml.

## Commands
- `gv2gml <resource> <action>` — Execute gv2gml commands
- `gv2gml self version` — Print gv2gml version
- `gv2gml _ _` — Passthrough to gv2gml CLI

## Usage Examples
- "gv2gml --help"
- "gv2gml self version"

## Installation
```bash
apt-get install gv2gml 2>/dev/null || which gv2gml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
