# doc-convert Plugin
Convert between document formats using Pandoc wrapper

## Commands
- `doc-convert <resource> <action>` — Execute doc-convert commands
- `doc-convert _ _` — Passthrough to doc-convert CLI

## Usage
- `doc-convert _ _ <args>` — Run doc-convert with any arguments
