# structurizr-cli Plugin
Software architecture modeling as code with C4 model

## Commands
- `structurizr-cli <resource> <action>` — Execute structurizr-cli commands
- `structurizr-cli _ _` — Passthrough to structurizr-cli CLI

## Usage
- `structurizr-cli _ _ <args>` — Run structurizr-cli with any arguments
