# pasteurize Plugin

CLI tool: pasteurize.

## Commands
- `pasteurize <resource> <action>` — Execute pasteurize commands
- `pasteurize self version` — Print pasteurize version
- `pasteurize _ _` — Passthrough to pasteurize CLI

## Usage Examples
- "pasteurize --help"
- "pasteurize self version"

## Installation
```bash
apt-get install pasteurize 2>/dev/null || which pasteurize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
