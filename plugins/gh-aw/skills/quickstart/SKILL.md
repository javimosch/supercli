# gh-aw Plugin

GitHub Agentic Workflows

## Commands

### General
- `gh-aw self version` — Print gh-aw version
- `gh-aw _ _` — Passthrough to gh-aw CLI

## Usage Examples
- "Run gh-aw"

## Installation

```bash
pip install gh-aw
```

- GitHub Agentic Workflows
- CLI tool, headless and scriptable
