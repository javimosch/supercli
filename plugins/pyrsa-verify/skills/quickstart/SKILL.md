# pyrsa-verify Plugin

CLI tool: pyrsa-verify.

## Commands
- `pyrsa-verify <resource> <action>` — Execute pyrsa-verify commands
- `pyrsa-verify self version` — Print pyrsa-verify version
- `pyrsa-verify _ _` — Passthrough to pyrsa-verify CLI

## Usage Examples
- "pyrsa-verify --help"
- "pyrsa-verify self version"

## Installation
```bash
apt-get install pyrsa-verify 2>/dev/null || which pyrsa-verify
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
