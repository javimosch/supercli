# genccode Plugin

CLI tool: genccode.

## Commands
- `genccode <resource> <action>` — Execute genccode commands
- `genccode self version` — Print genccode version
- `genccode _ _` — Passthrough to genccode CLI

## Usage Examples
- "genccode --help"
- "genccode self version"

## Installation
```bash
apt-get install genccode 2>/dev/null || which genccode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
