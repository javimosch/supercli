# url-short-cli Plugin
Minimalist URL shortener utility for the command line

## Commands
- `url-short-cli <resource> <action>` — Execute url-short-cli commands
- `url-short-cli _ _` — Passthrough to url-short-cli CLI

## Usage
- `url-short-cli _ _ <args>` — Run url-short-cli with any arguments
