# diatom Plugin
Text editor with the spirit of Acme and Sam

## Commands
- `diatom <resource> <action>` — Execute diatom commands
- `diatom _ _` — Passthrough to diatom CLI

## Usage
- `diatom _ _ <args>` — Run diatom with any arguments
