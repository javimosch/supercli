# pee Plugin

CLI tool: pee.

## Commands
- `pee <resource> <action>` — Execute pee commands
- `pee self version` — Print pee version
- `pee _ _` — Passthrough to pee CLI

## Usage Examples
- "pee --help"
- "pee self version"

## Installation
```bash
apt-get install pee 2>/dev/null || which pee
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
