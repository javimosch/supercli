# sqlitebrowser Plugin

CLI tool: sqlitebrowser.

## Commands
- `sqlitebrowser <resource> <action>` — Execute sqlitebrowser commands
- `sqlitebrowser self version` — Print sqlitebrowser version
- `sqlitebrowser _ _` — Passthrough to sqlitebrowser CLI

## Usage Examples
- "sqlitebrowser --help"
- "sqlitebrowser self version"

## Installation
```bash
apt-get install sqlitebrowser 2>/dev/null || which sqlitebrowser
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
