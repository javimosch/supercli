# zrun Plugin

CLI tool: zrun.

## Commands
- `zrun <resource> <action>` — Execute zrun commands
- `zrun self version` — Print zrun version
- `zrun _ _` — Passthrough to zrun CLI

## Usage Examples
- "zrun --help"
- "zrun self version"

## Installation
```bash
apt-get install zrun 2>/dev/null || which zrun
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
