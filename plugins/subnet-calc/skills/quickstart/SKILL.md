# subnet-calc Plugin
CIDR range and subnet calculator for network planning

## Commands
- `subnet-calc <resource> <action>` — Execute subnet-calc commands
- `subnet-calc _ _` — Passthrough to subnet-calc CLI

## Usage
- `subnet-calc _ _ <args>` — Run subnet-calc with any arguments
