# gcm-picker Plugin

CLI tool: gcm-picker.

## Commands
- `gcm-picker <resource> <action>` — Execute gcm-picker commands
- `gcm-picker self version` — Print gcm-picker version
- `gcm-picker _ _` — Passthrough to gcm-picker CLI

## Usage Examples
- "gcm-picker --help"
- "gcm-picker self version"

## Installation
```bash
apt-get install gcm-picker 2>/dev/null || which gcm-picker
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
