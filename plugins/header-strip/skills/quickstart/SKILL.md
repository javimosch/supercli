# header-strip Plugin
Remove YAML frontmatter from markdown files

## Commands
- `header-strip <resource> <action>` — Execute header-strip commands
- `header-strip _ _` — Passthrough to header-strip CLI

## Usage
- `header-strip _ _ <args>` — Run header-strip with any arguments
