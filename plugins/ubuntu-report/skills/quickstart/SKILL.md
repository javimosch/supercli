# ubuntu-report Plugin

CLI tool: ubuntu-report.

## Commands
- `ubuntu-report <resource> <action>` — Execute ubuntu-report commands
- `ubuntu-report self version` — Print ubuntu-report version
- `ubuntu-report _ _` — Passthrough to ubuntu-report CLI

## Usage Examples
- "ubuntu-report --help"
- "ubuntu-report self version"

## Installation
```bash
apt-get install ubuntu-report 2>/dev/null || which ubuntu-report
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
