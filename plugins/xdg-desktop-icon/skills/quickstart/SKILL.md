# xdg-desktop-icon Plugin

CLI tool: xdg-desktop-icon.

## Commands
- `xdg-desktop-icon <resource> <action>` — Execute xdg-desktop-icon commands
- `xdg-desktop-icon self version` — Print xdg-desktop-icon version
- `xdg-desktop-icon _ _` — Passthrough to xdg-desktop-icon CLI

## Usage Examples
- "xdg-desktop-icon --help"
- "xdg-desktop-icon self version"

## Installation
```bash
apt-get install xdg-desktop-icon 2>/dev/null || which xdg-desktop-icon
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
