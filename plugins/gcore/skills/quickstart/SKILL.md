# gcore Plugin

CLI tool: gcore.

## Commands
- `gcore <resource> <action>` — Execute gcore commands
- `gcore self version` — Print gcore version
- `gcore _ _` — Passthrough to gcore CLI

## Usage Examples
- "gcore --help"
- "gcore self version"

## Installation
```bash
apt-get install gcore 2>/dev/null || which gcore
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
