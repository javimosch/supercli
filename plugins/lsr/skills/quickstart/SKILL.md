# lsr Plugin
Fast ls alternative in Zig.
## Commands
- `lsr _ _` — Passthrough to lsr CLI
## Installation
```bash
git clone https://github.com/rockorager/lsr && cd lsr && zig build
```
## Key Features
- **Fast** — Zig performance
- **Colorized** — Readable output
- **Pipeline-ready** — stdin/stdout support
