# gresource Plugin

CLI tool: gresource.

## Commands
- `gresource <resource> <action>` — Execute gresource commands
- `gresource self version` — Print gresource version
- `gresource _ _` — Passthrough to gresource CLI

## Usage Examples
- "gresource --help"
- "gresource self version"

## Installation
```bash
apt-get install gresource 2>/dev/null || which gresource
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
