# xdg-desktop-menu Plugin

CLI tool: xdg-desktop-menu.

## Commands
- `xdg-desktop-menu <resource> <action>` — Execute xdg-desktop-menu commands
- `xdg-desktop-menu self version` — Print xdg-desktop-menu version
- `xdg-desktop-menu _ _` — Passthrough to xdg-desktop-menu CLI

## Usage Examples
- "xdg-desktop-menu --help"
- "xdg-desktop-menu self version"

## Installation
```bash
apt-get install xdg-desktop-menu 2>/dev/null || which xdg-desktop-menu
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
