# selfserv Plugin

CLI tool: selfserv.

## Commands
- `selfserv <resource> <action>` — Execute selfserv commands
- `selfserv self version` — Print selfserv version
- `selfserv _ _` — Passthrough to selfserv CLI

## Usage Examples
- "selfserv --help"
- "selfserv self version"

## Installation
```bash
apt-get install selfserv 2>/dev/null || which selfserv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
