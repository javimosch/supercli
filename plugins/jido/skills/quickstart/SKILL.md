# jido Plugin
File navigation and management utility.
## Commands
- `jido _ _` — Passthrough to jido CLI
## Installation
```bash
git clone https://github.com/BrookJeynes/jido && cd jido && zig build
```
## Key Features
- **File navigation** — Fast directory browsing
- **Pipeline-ready** — File system operations
- **Fast** — Written in Zig
