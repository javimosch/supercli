# wsgen Plugin

CLI tool: wsgen.

## Commands
- `wsgen <resource> <action>` — Execute wsgen commands
- `wsgen self version` — Print wsgen version
- `wsgen _ _` — Passthrough to wsgen CLI

## Usage Examples
- "wsgen --help"
- "wsgen self version"

## Installation
```bash
apt-get install wsgen 2>/dev/null || which wsgen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
