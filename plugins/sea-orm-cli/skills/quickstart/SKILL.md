# sea-orm-cli Plugin
CLI for the SeaORM Rust asynchronous ORM framework

## Commands
- `sea-orm-cli <resource> <action>` — Execute sea-orm-cli commands
- `sea-orm-cli _ _` — Passthrough to sea-orm-cli CLI

## Usage
- `sea-orm-cli _ _ <args>` — Run sea-orm-cli with any arguments
