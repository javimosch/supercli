# printer-profile Plugin

CLI tool: printer-profile.

## Commands
- `printer-profile <resource> <action>` — Execute printer-profile commands
- `printer-profile self version` — Print printer-profile version
- `printer-profile _ _` — Passthrough to printer-profile CLI

## Usage Examples
- "printer-profile --help"
- "printer-profile self version"

## Installation
```bash
apt-get install printer-profile 2>/dev/null || which printer-profile
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
