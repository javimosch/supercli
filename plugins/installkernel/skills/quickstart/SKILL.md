# installkernel Plugin

CLI tool: installkernel.

## Commands
- `installkernel <resource> <action>` — Execute installkernel commands
- `installkernel self version` — Print installkernel version
- `installkernel _ _` — Passthrough to installkernel CLI

## Usage Examples
- "installkernel --help"
- "installkernel self version"

## Installation
```bash
apt-get install installkernel 2>/dev/null || which installkernel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
