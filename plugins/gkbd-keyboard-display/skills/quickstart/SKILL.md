# gkbd-keyboard-display Plugin

CLI tool: gkbd-keyboard-display.

## Commands
- `gkbd-keyboard-display <resource> <action>` — Execute gkbd-keyboard-display commands
- `gkbd-keyboard-display self version` — Print gkbd-keyboard-display version
- `gkbd-keyboard-display _ _` — Passthrough to gkbd-keyboard-display CLI

## Usage Examples
- "gkbd-keyboard-display --help"
- "gkbd-keyboard-display self version"

## Installation
```bash
apt-get install gkbd-keyboard-display 2>/dev/null || which gkbd-keyboard-display
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
