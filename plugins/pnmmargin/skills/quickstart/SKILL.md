# pnmmargin Plugin

CLI tool: pnmmargin.

## Commands
- `pnmmargin <resource> <action>` — Execute pnmmargin commands
- `pnmmargin self version` — Print pnmmargin version
- `pnmmargin _ _` — Passthrough to pnmmargin CLI

## Usage Examples
- "pnmmargin --help"
- "pnmmargin self version"

## Installation
```bash
apt-get install pnmmargin 2>/dev/null || which pnmmargin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
