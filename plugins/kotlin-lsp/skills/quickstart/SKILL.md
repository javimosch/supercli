# kotlin-lsp Plugin

Kotlin Language Server and plugin for Visual Studio Code

## Commands

### General
- `kotlin-lsp self version` — Print kotlin-lsp version
- `kotlin-lsp _ _` — Passthrough to kotlin-lsp CLI

## Usage Examples
- "Run kotlin-lsp"
- "Use kotlin-lsp to Kotlin Language Server and plugin for Visual Studio Code"

## Installation

```bash
pip install kotlin-lsp
```

## Key Features
- Kotlin Language Server and plugin for Visual Studio Code
- CLI tool, headless and scriptable
