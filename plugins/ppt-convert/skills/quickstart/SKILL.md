# ppt-convert Plugin
Convert PowerPoint presentations between formats

## Commands
- `ppt-convert <resource> <action>` — Execute ppt-convert commands
- `ppt-convert _ _` — Passthrough to ppt-convert CLI

## Usage
- `ppt-convert _ _ <args>` — Run ppt-convert with any arguments
