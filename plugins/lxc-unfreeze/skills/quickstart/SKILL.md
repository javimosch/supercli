# lxc-unfreeze Plugin

CLI tool: lxc-unfreeze.

## Commands
- `lxc-unfreeze <resource> <action>` — Execute lxc-unfreeze commands
- `lxc-unfreeze self version` — Print lxc-unfreeze version
- `lxc-unfreeze _ _` — Passthrough to lxc-unfreeze CLI

## Usage Examples
- "lxc-unfreeze --help"
- "lxc-unfreeze self version"

## Installation
```bash
apt-get install lxc-unfreeze 2>/dev/null || which lxc-unfreeze
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
