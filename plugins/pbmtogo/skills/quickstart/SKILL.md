# pbmtogo Plugin

CLI tool: pbmtogo.

## Commands
- `pbmtogo <resource> <action>` — Execute pbmtogo commands
- `pbmtogo self version` — Print pbmtogo version
- `pbmtogo _ _` — Passthrough to pbmtogo CLI

## Usage Examples
- "pbmtogo --help"
- "pbmtogo self version"

## Installation
```bash
apt-get install pbmtogo 2>/dev/null || which pbmtogo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
