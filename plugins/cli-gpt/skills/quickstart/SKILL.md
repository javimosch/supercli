# cli-gpt Plugin
Simple ChatGPT in your terminal with markdown

## Commands
- `cli-gpt <resource> <action>` — Execute cli-gpt commands
- `cli-gpt _ _` — Passthrough to cli-gpt CLI

## Usage
- `cli-gpt _ _ <args>` — Run cli-gpt with any arguments
