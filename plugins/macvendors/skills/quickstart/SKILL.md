# macvendors Plugin

macvendors — lookup MAC address vendor information..

## Commands

### `sc macvendors mac lookup`
Lookup MAC address vendor.

### `sc macvendors self version`
Print version.

## Installation

```bash
npm install -g macvendors
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
