# gpsbabel Plugin

CLI tool: gpsbabel.

## Commands
- `gpsbabel <resource> <action>` — Execute gpsbabel commands
- `gpsbabel self version` — Print gpsbabel version
- `gpsbabel _ _` — Passthrough to gpsbabel CLI

## Usage Examples
- "gpsbabel --help"
- "gpsbabel self version"

## Installation
```bash
apt-get install gpsbabel 2>/dev/null || which gpsbabel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
