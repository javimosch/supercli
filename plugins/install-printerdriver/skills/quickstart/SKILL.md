# install-printerdriver Plugin

CLI tool: install-printerdriver.

## Commands
- `install-printerdriver <resource> <action>` — Execute install-printerdriver commands
- `install-printerdriver self version` — Print install-printerdriver version
- `install-printerdriver _ _` — Passthrough to install-printerdriver CLI

## Usage Examples
- "install-printerdriver --help"
- "install-printerdriver self version"

## Installation
```bash
apt-get install install-printerdriver 2>/dev/null || which install-printerdriver
```
