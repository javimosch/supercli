# grolbp Plugin

CLI tool: grolbp.

## Commands
- `grolbp <resource> <action>` — Execute grolbp commands
- `grolbp self version` — Print grolbp version
- `grolbp _ _` — Passthrough to grolbp CLI

## Usage Examples
- "grolbp --help"
- "grolbp self version"

## Installation
```bash
apt-get install grolbp 2>/dev/null || which grolbp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
