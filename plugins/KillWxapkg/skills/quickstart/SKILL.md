# KillWxapkg Plugin

自动化反编译微信小程序，小程序安全评估工具，发现小程序安全问题，自动解密，解包，可还原工程目录，支持Hook，小程序修改

## Commands

### General
- `KillWxapkg self version` — Print KillWxapkg version
- `KillWxapkg _ _` — Passthrough to killwxapkg CLI
