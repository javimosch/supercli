# dvisvgm Plugin

CLI tool: dvisvgm.

## Commands
- `dvisvgm <resource> <action>` — Execute dvisvgm commands
- `dvisvgm self version` — Print dvisvgm version
- `dvisvgm _ _` — Passthrough to dvisvgm CLI

## Usage Examples
- "dvisvgm --help"
- "dvisvgm self version"

## Installation
```bash
apt-get install dvisvgm 2>/dev/null || which dvisvgm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
