# screendump Plugin

CLI tool: screendump.

## Commands
- `screendump <resource> <action>` — Execute screendump commands
- `screendump self version` — Print screendump version
- `screendump _ _` — Passthrough to screendump CLI

## Usage Examples
- "screendump --help"
- "screendump self version"

## Installation
```bash
apt-get install screendump 2>/dev/null || which screendump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
