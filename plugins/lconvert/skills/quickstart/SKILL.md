# lconvert Plugin

CLI tool: lconvert.

## Commands
- `lconvert <resource> <action>` — Execute lconvert commands
- `lconvert self version` — Print lconvert version
- `lconvert _ _` — Passthrough to lconvert CLI

## Usage Examples
- "lconvert --help"
- "lconvert self version"

## Installation
```bash
apt-get install lconvert 2>/dev/null || which lconvert
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
