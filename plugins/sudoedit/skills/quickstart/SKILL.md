# sudoedit Plugin

CLI tool: sudoedit.

## Commands
- `sudoedit <resource> <action>` — Execute sudoedit commands
- `sudoedit self version` — Print sudoedit version
- `sudoedit _ _` — Passthrough to sudoedit CLI

## Usage Examples
- "sudoedit --help"
- "sudoedit self version"

## Installation
```bash
apt-get install sudoedit 2>/dev/null || which sudoedit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
