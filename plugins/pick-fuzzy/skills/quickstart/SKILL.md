# pick-fuzzy Plugin
Simple command-line fuzzy file and text picker in C

## Commands
- `pick-fuzzy <resource> <action>` — Execute pick-fuzzy commands
- `pick-fuzzy _ _` — Passthrough to pick-fuzzy CLI

## Usage
- `pick-fuzzy _ _ <args>` — Run pick-fuzzy with any arguments
