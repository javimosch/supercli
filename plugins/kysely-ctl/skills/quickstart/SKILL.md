# kysely-ctl Plugin

Command-line tool for Kysely ORM. Migrations, seeding, introspection. Knex-compatible, works in Node/Deno/Bun. npm install.

## Commands
- `kysely-ctl self version` — Print version
- `kysely-ctl _ _ <args>` — Passthrough to kysely-ctl

## Usage Examples
- "Kysely CLI"

## Installation
```bash
npm install -g kysely-ctl
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
