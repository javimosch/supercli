# spa-acp-tool Plugin

CLI tool: spa-acp-tool.

## Commands
- `spa-acp-tool <resource> <action>` — Execute spa-acp-tool commands
- `spa-acp-tool self version` — Print spa-acp-tool version
- `spa-acp-tool _ _` — Passthrough to spa-acp-tool CLI

## Usage Examples
- "spa-acp-tool --help"
- "spa-acp-tool self version"

## Installation
```bash
apt-get install spa-acp-tool 2>/dev/null || which spa-acp-tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
