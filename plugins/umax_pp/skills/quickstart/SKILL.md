# umax_pp Plugin

CLI tool: umax_pp.

## Commands
- `umax_pp <resource> <action>` — Execute umax_pp commands
- `umax_pp self version` — Print umax_pp version
- `umax_pp _ _` — Passthrough to umax_pp CLI

## Usage Examples
- "umax_pp --help"
- "umax_pp self version"

## Installation
```bash
apt-get install umax_pp 2>/dev/null || which umax_pp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
