# cargo-hack Plugin
Check and test Rust crates with feature combinations

## Commands
- `cargo-hack <resource> <action>` — Execute cargo-hack commands
- `cargo-hack _ _` — Passthrough to cargo-hack CLI

## Usage
- `cargo-hack _ _ <args>` — Run cargo-hack with any arguments
