# xmlpatternsvalidator Plugin

xmlpatternsvalidator — Wrapper to select between Qt development binary versions.

## Commands
- `xmlpatternsvalidator <resource> <action>` — Execute xmlpatternsvalidator commands
- `xmlpatternsvalidator self version` — Print xmlpatternsvalidator version
- `xmlpatternsvalidator _ _` — Passthrough to xmlpatternsvalidator CLI

## Usage Examples
- "xmlpatternsvalidator --help"
- "xmlpatternsvalidator self version"

## Installation
```bash
apt-get install qtchooser 2>/dev/null || which xmlpatternsvalidator
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
