# xfdesktop-settings Plugin

CLI tool: xfdesktop-settings.

## Commands
- `xfdesktop-settings <resource> <action>` — Execute xfdesktop-settings commands
- `xfdesktop-settings self version` — Print xfdesktop-settings version
- `xfdesktop-settings _ _` — Passthrough to xfdesktop-settings CLI

## Usage Examples
- "xfdesktop-settings --help"
- "xfdesktop-settings self version"

## Installation
```bash
apt-get install xfdesktop-settings 2>/dev/null || which xfdesktop-settings
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
