# newsnow Plugin

Elegant reading of real-time and hottest news

## Commands

### General
- `newsnow self version` — Print newsnow version
- `newsnow _ _` — Passthrough to newsnow CLI

## Usage Examples
- "Run newsnow"
- "Use newsnow to Elegant reading of real-time and hottest news"

## Installation

```bash
pip install newsnow
```

## Key Features
- Elegant reading of real-time and hottest news
- CLI tool, headless and scriptable
