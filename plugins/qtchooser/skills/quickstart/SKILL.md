# qtchooser Plugin

CLI tool: qtchooser.

## Commands
- `qtchooser <resource> <action>` — Execute qtchooser commands
- `qtchooser self version` — Print qtchooser version
- `qtchooser _ _` — Passthrough to qtchooser CLI

## Usage Examples
- "qtchooser --help"
- "qtchooser self version"

## Installation
```bash
apt-get install qtchooser 2>/dev/null || which qtchooser
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
