# nmtui-hostname Plugin

CLI tool: nmtui-hostname.

## Commands
- `nmtui-hostname <resource> <action>` — Execute nmtui-hostname commands
- `nmtui-hostname self version` — Print nmtui-hostname version
- `nmtui-hostname _ _` — Passthrough to nmtui-hostname CLI

## Usage Examples
- "nmtui-hostname --help"
- "nmtui-hostname self version"

## Installation
```bash
apt-get install nmtui-hostname 2>/dev/null || which nmtui-hostname
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
