# Go-Kata Plugin

Daily coding challenges to master idiomatic Go through deliberate practice

## Commands
- `go-kata _ _` — Passthrough to go-kata CLI

## Installation

```bash
go install github.com/MedUnes/go-kata@latest
```

## Examples
```bash
go-kata --help
go-kata --version
```
