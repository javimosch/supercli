# pamcut Plugin

CLI tool: pamcut.

## Commands
- `pamcut <resource> <action>` — Execute pamcut commands
- `pamcut self version` — Print pamcut version
- `pamcut _ _` — Passthrough to pamcut CLI

## Usage Examples
- "pamcut --help"
- "pamcut self version"

## Installation
```bash
apt-get install pamcut 2>/dev/null || which pamcut
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
