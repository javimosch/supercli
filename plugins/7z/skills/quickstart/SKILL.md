# 7z Plugin

CLI tool: 7z.

## Commands
- `7z <resource> <action>` — Execute 7z commands
- `7z self version` — Print 7z version
- `7z _ _` — Passthrough to 7z CLI

## Usage Examples
- "7z --help"
- "7z self version"

## Installation
```bash
apt-get install 7z 2>/dev/null || which 7z
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
