# cargo-diet Plugin
Minimize Rust crate size by finding large dependencies

## Commands
- `cargo-diet <resource> <action>` — Execute cargo-diet commands
- `cargo-diet _ _` — Passthrough to cargo-diet CLI

## Usage
- `cargo-diet _ _ <args>` — Run cargo-diet with any arguments
