# rusty-hook Plugin
Fast git hook manager.
## Commands
- `rusty-hook _ _` — Passthrough to rusty-hook CLI
## Installation
```bash
cargo install rusty-hook
```
## Key Features
- **Git hooks** — Pre-commit, pre-push management
- **Fast** — Rust-powered performance
- **Pipeline-ready** — CI/CD integration
