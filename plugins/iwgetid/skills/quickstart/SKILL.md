# iwgetid Plugin

CLI tool: iwgetid.

## Commands
- `iwgetid <resource> <action>` — Execute iwgetid commands
- `iwgetid self version` — Print iwgetid version
- `iwgetid _ _` — Passthrough to iwgetid CLI

## Usage Examples
- "iwgetid --help"
- "iwgetid self version"

## Installation
```bash
apt-get install iwgetid 2>/dev/null || which iwgetid
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
