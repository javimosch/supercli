# loffice Plugin

CLI tool: loffice.

## Commands
- `loffice <resource> <action>` — Execute loffice commands
- `loffice self version` — Print loffice version
- `loffice _ _` — Passthrough to loffice CLI

## Usage Examples
- "loffice --help"
- "loffice self version"

## Installation
```bash
apt-get install loffice 2>/dev/null || which loffice
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
