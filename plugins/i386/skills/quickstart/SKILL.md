# i386 Plugin

CLI tool: i386.

## Commands
- `i386 <resource> <action>` — Execute i386 commands
- `i386 self version` — Print i386 version
- `i386 _ _` — Passthrough to i386 CLI

## Usage Examples
- "i386 --help"
- "i386 self version"

## Installation
```bash
apt-get install i386 2>/dev/null || which i386
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
