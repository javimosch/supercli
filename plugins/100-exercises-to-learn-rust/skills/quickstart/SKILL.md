# 100-exercises-to-learn-rust Plugin

A self-paced course to learn Rust, one exercise at a time.

## Commands
- `100-exercises-to-learn-rust <resource> <action>` — Execute 100-exercises-to-learn-rust commands
- `100-exercises-to-learn-rust self version` — Print 100-exercises-to-learn-rust version
- `100-exercises-to-learn-rust _ _` — Passthrough to 100-exercises-to-learn-rust CLI

## Installation

```bash
pip install 100-exercises-to-learn-rust
```
