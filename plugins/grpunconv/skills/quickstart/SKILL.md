# grpunconv Plugin

CLI tool: grpunconv.

## Commands
- `grpunconv <resource> <action>` — Execute grpunconv commands
- `grpunconv self version` — Print grpunconv version
- `grpunconv _ _` — Passthrough to grpunconv CLI

## Usage Examples
- "grpunconv --help"
- "grpunconv self version"

## Installation
```bash
apt-get install grpunconv 2>/dev/null || which grpunconv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
