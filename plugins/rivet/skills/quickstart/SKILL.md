# rivet Plugin

Rivet Actors are the primitive for stateful workloads. Built for AI agents, collaborative apps, and durable execution.

## Commands
- `rivet <resource> <action>` — Execute rivet commands
- `rivet self version` — Print rivet version
- `rivet _ _` — Passthrough to rivet CLI

## Installation

```bash
pip install rivet
```
