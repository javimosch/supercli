# pnmcut Plugin

CLI tool: pnmcut.

## Commands
- `pnmcut <resource> <action>` — Execute pnmcut commands
- `pnmcut self version` — Print pnmcut version
- `pnmcut _ _` — Passthrough to pnmcut CLI

## Usage Examples
- "pnmcut --help"
- "pnmcut self version"

## Installation
```bash
apt-get install pnmcut 2>/dev/null || which pnmcut
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
