# ministats Plugin

CLI tool: ministats.

## Commands
- `ministats <resource> <action>` — Execute ministats commands
- `ministats self version` — Print ministats version
- `ministats _ _` — Passthrough to ministats CLI

## Usage Examples
- "ministats --help"
- "ministats self version"

## Installation
```bash
apt-get install ministats 2>/dev/null || which ministats
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
