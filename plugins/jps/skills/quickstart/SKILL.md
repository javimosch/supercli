# jps Plugin

CLI tool: jps.

## Commands
- `jps <resource> <action>` — Execute jps commands
- `jps self version` — Print jps version
- `jps _ _` — Passthrough to jps CLI

## Usage Examples
- "jps --help"
- "jps self version"

## Installation
```bash
apt-get install jps 2>/dev/null || which jps
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
