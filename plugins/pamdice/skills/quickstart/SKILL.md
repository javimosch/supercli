# pamdice Plugin

CLI tool: pamdice.

## Commands
- `pamdice <resource> <action>` — Execute pamdice commands
- `pamdice self version` — Print pamdice version
- `pamdice _ _` — Passthrough to pamdice CLI

## Usage Examples
- "pamdice --help"
- "pamdice self version"

## Installation
```bash
apt-get install pamdice 2>/dev/null || which pamdice
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
