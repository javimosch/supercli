# sotruss Plugin

CLI tool: sotruss.

## Commands
- `sotruss <resource> <action>` — Execute sotruss commands
- `sotruss self version` — Print sotruss version
- `sotruss _ _` — Passthrough to sotruss CLI

## Usage Examples
- "sotruss --help"
- "sotruss self version"

## Installation
```bash
apt-get install sotruss 2>/dev/null || which sotruss
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
