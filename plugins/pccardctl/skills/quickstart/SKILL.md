# pccardctl Plugin

CLI tool: pccardctl.

## Commands
- `pccardctl <resource> <action>` — Execute pccardctl commands
- `pccardctl self version` — Print pccardctl version
- `pccardctl _ _` — Passthrough to pccardctl CLI

## Usage Examples
- "pccardctl --help"
- "pccardctl self version"

## Installation
```bash
apt-get install pccardctl 2>/dev/null || which pccardctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
