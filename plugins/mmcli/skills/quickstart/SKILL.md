# mmcli Plugin

CLI tool: mmcli.

## Commands
- `mmcli <resource> <action>` — Execute mmcli commands
- `mmcli self version` — Print mmcli version
- `mmcli _ _` — Passthrough to mmcli CLI

## Usage Examples
- "mmcli --help"
- "mmcli self version"

## Installation
```bash
apt-get install mmcli 2>/dev/null || which mmcli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
