# nspr-config Plugin

CLI tool: nspr-config.

## Commands
- `nspr-config <resource> <action>` — Execute nspr-config commands
- `nspr-config self version` — Print nspr-config version
- `nspr-config _ _` — Passthrough to nspr-config CLI

## Usage Examples
- "nspr-config --help"
- "nspr-config self version"

## Installation
```bash
apt-get install nspr-config 2>/dev/null || which nspr-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
