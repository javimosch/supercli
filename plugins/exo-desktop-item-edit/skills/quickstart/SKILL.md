# exo-desktop-item-edit Plugin

CLI tool: exo-desktop-item-edit.

## Commands
- `exo-desktop-item-edit <resource> <action>` — Execute exo-desktop-item-edit commands
- `exo-desktop-item-edit self version` — Print exo-desktop-item-edit version
- `exo-desktop-item-edit _ _` — Passthrough to exo-desktop-item-edit CLI

## Usage Examples
- "exo-desktop-item-edit --help"
- "exo-desktop-item-edit self version"

apt-get install exo-desktop-item-edit 2>/dev/null || which exo-desktop-item-edit
