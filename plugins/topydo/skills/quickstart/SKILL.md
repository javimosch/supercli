# topydo Plugin

Powerful todo list for console in Python

## Commands

### Operations
- `topydo self version` — Print topydo version
- `topydo _ _` — Passthrough to topydo CLI

## Usage Examples
- `topydo --help`
- `topydo <args>`

## Installation

```bash
pip install topydo
```

## Examples

```bash
topydo --version
topydo --help
```
