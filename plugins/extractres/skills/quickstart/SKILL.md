# extractres Plugin

CLI tool: extractres.

## Commands
- `extractres <resource> <action>` — Execute extractres commands
- `extractres self version` — Print extractres version
- `extractres _ _` — Passthrough to extractres CLI

## Usage Examples
- "extractres --help"
- "extractres self version"

## Installation
```bash
apt-get install extractres 2>/dev/null || which extractres
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
