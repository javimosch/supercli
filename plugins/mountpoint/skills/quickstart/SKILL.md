# mountpoint Plugin

CLI tool: mountpoint.

## Commands
- `mountpoint <resource> <action>` — Execute mountpoint commands
- `mountpoint self version` — Print mountpoint version
- `mountpoint _ _` — Passthrough to mountpoint CLI

## Usage Examples
- "mountpoint --help"
- "mountpoint self version"

## Installation
```bash
apt-get install mountpoint 2>/dev/null || which mountpoint
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
