# tex4ht Plugin

CLI tool: tex4ht.

## Commands
- `tex4ht <resource> <action>` — Execute tex4ht commands
- `tex4ht self version` — Print tex4ht version
- `tex4ht _ _` — Passthrough to tex4ht CLI

## Usage Examples
- "tex4ht --help"
- "tex4ht self version"

## Installation
```bash
apt-get install tex4ht 2>/dev/null || which tex4ht
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
