# parset Plugin

CLI tool: parset.

## Commands
- `parset <resource> <action>` — Execute parset commands
- `parset self version` — Print parset version
- `parset _ _` — Passthrough to parset CLI

## Usage Examples
- "parset --help"
- "parset self version"

## Installation
```bash
apt-get install parset 2>/dev/null || which parset
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
