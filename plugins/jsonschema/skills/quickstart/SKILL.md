# jsonschema Plugin

CLI tool: jsonschema.

## Commands
- `jsonschema <resource> <action>` — Execute jsonschema commands
- `jsonschema self version` — Print jsonschema version
- `jsonschema _ _` — Passthrough to jsonschema CLI

## Usage Examples
- "jsonschema --help"
- "jsonschema self version"

## Installation
```bash
apt-get install jsonschema 2>/dev/null || which jsonschema
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
