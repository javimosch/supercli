# remmina Plugin

CLI tool: remmina.

## Commands
- `remmina <resource> <action>` — Execute remmina commands
- `remmina self version` — Print remmina version
- `remmina _ _` — Passthrough to remmina CLI

## Usage Examples
- "remmina --help"
- "remmina self version"

## Installation
```bash
apt-get install remmina 2>/dev/null || which remmina
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
