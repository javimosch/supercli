# ReZygisk Plugin

Transparent implementation of Zygisk.

## Commands

### General
- `ReZygisk self version` — Print ReZygisk version
- `ReZygisk _ _` — Passthrough to rezygisk CLI

## Usage Examples
- "Run ReZygisk"
- "Use rezygisk to Transparent implementation of Zygisk."

## Installation

```bash
pip install rezygisk
```

## Key Features
- Transparent implementation of Zygisk.
- CLI tool, headless and scriptable
