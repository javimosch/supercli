# showconsolefont Plugin

CLI tool: showconsolefont.

## Commands
- `showconsolefont <resource> <action>` — Execute showconsolefont commands
- `showconsolefont self version` — Print showconsolefont version
- `showconsolefont _ _` — Passthrough to showconsolefont CLI

## Usage Examples
- "showconsolefont --help"
- "showconsolefont self version"

## Installation
```bash
apt-get install showconsolefont 2>/dev/null || which showconsolefont
```
