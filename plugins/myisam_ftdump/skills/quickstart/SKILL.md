# myisam_ftdump Plugin

CLI tool: myisam_ftdump.

## Commands
- `myisam_ftdump <resource> <action>` — Execute myisam_ftdump commands
- `myisam_ftdump self version` — Print myisam_ftdump version
- `myisam_ftdump _ _` — Passthrough to myisam_ftdump CLI

## Usage Examples
- "myisam_ftdump --help"
- "myisam_ftdump self version"

## Installation
```bash
apt-get install myisam_ftdump 2>/dev/null || which myisam_ftdump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
