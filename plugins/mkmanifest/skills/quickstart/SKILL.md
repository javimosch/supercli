# mkmanifest Plugin

CLI tool: mkmanifest.

## Commands
- `mkmanifest <resource> <action>` — Execute mkmanifest commands
- `mkmanifest self version` — Print mkmanifest version
- `mkmanifest _ _` — Passthrough to mkmanifest CLI

## Usage Examples
- "mkmanifest --help"
- "mkmanifest self version"

## Installation
```bash
apt-get install mkmanifest 2>/dev/null || which mkmanifest
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
