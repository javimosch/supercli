# m2300w-wrapper Plugin

CLI tool: m2300w-wrapper.

## Commands
- `m2300w-wrapper <resource> <action>` — Execute m2300w-wrapper commands
- `m2300w-wrapper self version` — Print m2300w-wrapper version
- `m2300w-wrapper _ _` — Passthrough to m2300w-wrapper CLI

## Usage Examples
- "m2300w-wrapper --help"
- "m2300w-wrapper self version"

## Installation
```bash
apt-get install m2300w-wrapper 2>/dev/null || which m2300w-wrapper
```
