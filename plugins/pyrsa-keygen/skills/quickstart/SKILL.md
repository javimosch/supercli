# pyrsa-keygen Plugin

CLI tool: pyrsa-keygen.

## Commands
- `pyrsa-keygen <resource> <action>` — Execute pyrsa-keygen commands
- `pyrsa-keygen self version` — Print pyrsa-keygen version
- `pyrsa-keygen _ _` — Passthrough to pyrsa-keygen CLI

## Usage Examples
- "pyrsa-keygen --help"
- "pyrsa-keygen self version"

## Installation
```bash
apt-get install pyrsa-keygen 2>/dev/null || which pyrsa-keygen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
