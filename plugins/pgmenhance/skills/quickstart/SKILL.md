# pgmenhance Plugin

CLI tool: pgmenhance.

## Commands
- `pgmenhance <resource> <action>` — Execute pgmenhance commands
- `pgmenhance self version` — Print pgmenhance version
- `pgmenhance _ _` — Passthrough to pgmenhance CLI

## Usage Examples
- "pgmenhance --help"
- "pgmenhance self version"

## Installation
```bash
apt-get install pgmenhance 2>/dev/null || which pgmenhance
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
