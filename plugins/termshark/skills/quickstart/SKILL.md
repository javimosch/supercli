# termshark

termshark — a terminal UI for tshark, inspired by Wireshark.

## Commands
- `sc termshark capture run` — Capture and analyze network traffic
- `sc termshark self version` — Print version

## Installation
```
go install github.com/gcla/termshark@latest
```
