# py-spy Plugin
Sampling profiler for Python programs. Generate flame graphs, speedscope, and raw JSON output. Non-interactive, scriptable.
## Commands
- `py self version` — Print version
- `py _ _` — Passthrough to py-spy
## Installation
```bash
brew install py-spy
```
