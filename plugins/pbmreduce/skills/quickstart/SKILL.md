# pbmreduce Plugin

CLI tool: pbmreduce.

## Commands
- `pbmreduce <resource> <action>` — Execute pbmreduce commands
- `pbmreduce self version` — Print pbmreduce version
- `pbmreduce _ _` — Passthrough to pbmreduce CLI

## Usage Examples
- "pbmreduce --help"
- "pbmreduce self version"

## Installation
```bash
apt-get install pbmreduce 2>/dev/null || which pbmreduce
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
