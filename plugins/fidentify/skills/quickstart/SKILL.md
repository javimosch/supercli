# fidentify Plugin

CLI tool: fidentify.

## Commands
- `fidentify <resource> <action>` — Execute fidentify commands
- `fidentify self version` — Print fidentify version
- `fidentify _ _` — Passthrough to fidentify CLI

## Usage Examples
- "fidentify --help"
- "fidentify self version"

## Installation
```bash
apt-get install fidentify 2>/dev/null || which fidentify
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
