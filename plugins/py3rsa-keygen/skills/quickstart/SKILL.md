# py3rsa-keygen Plugin

CLI tool: py3rsa-keygen.

## Commands
- `py3rsa-keygen <resource> <action>` — Execute py3rsa-keygen commands
- `py3rsa-keygen self version` — Print py3rsa-keygen version
- `py3rsa-keygen _ _` — Passthrough to py3rsa-keygen CLI

## Usage Examples
- "py3rsa-keygen --help"
- "py3rsa-keygen self version"

## Installation
```bash
apt-get install py3rsa-keygen 2>/dev/null || which py3rsa-keygen
```
