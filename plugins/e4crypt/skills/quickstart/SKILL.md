# e4crypt Plugin

CLI tool: e4crypt.

## Commands
- `e4crypt <resource> <action>` — Execute e4crypt commands
- `e4crypt self version` — Print e4crypt version
- `e4crypt _ _` — Passthrough to e4crypt CLI

## Usage Examples
- "e4crypt --help"
- "e4crypt self version"

## Installation
```bash
apt-get install e4crypt 2>/dev/null || which e4crypt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
