# smproxy Plugin

CLI tool: smproxy.

## Commands
- `smproxy <resource> <action>` — Execute smproxy commands
- `smproxy self version` — Print smproxy version
- `smproxy _ _` — Passthrough to smproxy CLI

## Usage Examples
- "smproxy --help"
- "smproxy self version"

## Installation
```bash
apt-get install smproxy 2>/dev/null || which smproxy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
