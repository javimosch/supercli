# qhelpconverter Plugin

CLI tool: qhelpconverter.

## Commands
- `qhelpconverter <resource> <action>` — Execute qhelpconverter commands
- `qhelpconverter self version` — Print qhelpconverter version
- `qhelpconverter _ _` — Passthrough to qhelpconverter CLI

## Usage Examples
- "qhelpconverter --help"
- "qhelpconverter self version"

## Installation
```bash
apt-get install qhelpconverter 2>/dev/null || which qhelpconverter
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
