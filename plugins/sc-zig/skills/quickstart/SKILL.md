# sc-zig Plugin

CLI tool: sc-zig.

## Commands
- `sc-zig <resource> <action>` — Execute sc-zig commands
- `sc-zig self version` — Print sc-zig version
- `sc-zig _ _` — Passthrough to sc-zig CLI

## Usage Examples
- "sc-zig --help"
- "sc-zig self version"

## Installation
```bash
apt-get install sc-zig 2>/dev/null || which sc-zig
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
