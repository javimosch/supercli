# ink-kit Plugin

React component library for onchain applications - See README for modern alternatives

## Commands

### General
- `ink-kit self version` — Print ink-kit version
- `ink-kit _ _` — Passthrough to ink-kit CLI

```bash
pip install ink-kit
```
