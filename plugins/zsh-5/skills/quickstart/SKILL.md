# zsh-5 Plugin

Zsh shell (5.x series)

## Commands
- `zsh-5 <resource> <action>` — Execute zsh-5 commands
- `zsh-5 self version` — Version

## Installation

```bash
brew install zsh-5
Verify: zsh-5 --version
```

## Commands

### `sc zsh-5 self version`

Version


## SuperCLI

```bash
sc zsh-5 _ _ --help
sc plugins learn zsh-5
```
