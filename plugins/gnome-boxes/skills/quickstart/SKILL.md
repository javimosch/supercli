# gnome-boxes Plugin

CLI tool: gnome-boxes.

## Commands
- `gnome-boxes <resource> <action>` — Execute gnome-boxes commands
- `gnome-boxes self version` — Print gnome-boxes version
- `gnome-boxes _ _` — Passthrough to gnome-boxes CLI

## Usage Examples
- "gnome-boxes --help"
- "gnome-boxes self version"

## Installation
```bash
apt-get install gnome-boxes 2>/dev/null || which gnome-boxes
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
