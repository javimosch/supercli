# azure-cli

Azure CLI — command-line interface for Microsoft Azure services

## Install

```bash
brew install azure-cli
```

Verify installation:

```bash
which az
```

## Commands

- `azure-cli self version` — print az version
- `azure-cli cli run ...` — pass any arguments straight through to `az`
