# supermemory Plugin

Memory engine and app that is extremely fast, scalable. The Memory API for the AI era.

## Commands
- `supermemory <resource> <action>` — Execute supermemory commands
- `supermemory self version` — Print supermemory version
- `supermemory _ _` — Passthrough to supermemory CLI

## Installation

```bash
pip install supermemory
```
