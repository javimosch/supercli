# mime-type Plugin
Get the MIME type for any file extension.

## Commands
- `mime-type <resource> <action>` — Execute mime-type commands
- `mime detect type` — Detect MIME type from a filename

## Usage
- `mime detect type image.png` → image/png
- `mime detect type document.pdf` → application/pdf
