# enchant-2 Plugin

CLI tool: enchant-2.

## Commands
- `enchant-2 <resource> <action>` — Execute enchant-2 commands
- `enchant-2 self version` — Print enchant-2 version
- `enchant-2 _ _` — Passthrough to enchant-2 CLI

## Usage Examples
- "enchant-2 --help"
- "enchant-2 self version"

## Installation
```bash
apt-get install enchant-2 2>/dev/null || which enchant-2
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
