# ppmquant Plugin

CLI tool: ppmquant.

## Commands
- `ppmquant <resource> <action>` — Execute ppmquant commands
- `ppmquant self version` — Print ppmquant version
- `ppmquant _ _` — Passthrough to ppmquant CLI

## Usage Examples
- "ppmquant --help"
- "ppmquant self version"

## Installation
```bash
apt-get install ppmquant 2>/dev/null || which ppmquant
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
