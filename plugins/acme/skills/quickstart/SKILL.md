# acme Plugin
Plan 9 text editor and window system from Bell Labs

## Commands
- `acme <resource> <action>` — Execute acme commands
- `acme _ _` — Passthrough to acme CLI

## Usage
- `acme _ _ <args>` — Run acme with any arguments
