# intltoolize Plugin

CLI tool: intltoolize.

## Commands
- `intltoolize <resource> <action>` — Execute intltoolize commands
- `intltoolize self version` — Print intltoolize version
- `intltoolize _ _` — Passthrough to intltoolize CLI

## Usage Examples
- "intltoolize --help"
- "intltoolize self version"

## Installation
```bash
apt-get install intltoolize 2>/dev/null || which intltoolize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
