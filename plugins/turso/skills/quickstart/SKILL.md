# turso Plugin

Turso is an in-process SQL database, compatible with SQLite.

## Commands
- `turso <resource> <action>` — Execute turso commands
- `turso self version` — Print turso version
- `turso _ _` — Passthrough to turso CLI

## Installation

```bash
pip install turso
```
