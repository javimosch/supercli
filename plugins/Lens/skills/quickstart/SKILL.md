# Lens Plugin

CLI tool: Lens.

## Commands
- `Lens <resource> <action>` — Execute Lens commands
- `Lens self version` — Print Lens version
- `Lens _ _` — Passthrough to Lens CLI

## Usage Examples
- "Lens --help"
- "Lens self version"

## Installation
```bash
apt-get install Lens 2>/dev/null || which Lens
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
