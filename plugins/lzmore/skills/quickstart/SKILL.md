# lzmore Plugin

CLI tool: lzmore.

## Commands
- `lzmore <resource> <action>` — Execute lzmore commands
- `lzmore self version` — Print lzmore version
- `lzmore _ _` — Passthrough to lzmore CLI

## Usage Examples
- "lzmore --help"
- "lzmore self version"

## Installation
```bash
apt-get install lzmore 2>/dev/null || which lzmore
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
