# ocrmac Plugin
macOS native OCR using Vision framework from CLI

## Commands
- `ocrmac <resource> <action>` — Execute ocrmac commands
- `ocrmac _ _` — Passthrough to ocrmac CLI

## Usage
- `ocrmac _ _ <args>` — Run ocrmac with any arguments
