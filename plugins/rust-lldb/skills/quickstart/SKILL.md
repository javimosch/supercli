# rust-lldb Plugin

CLI tool: rust-lldb.

## Commands
- `rust-lldb <resource> <action>` — Execute rust-lldb commands
- `rust-lldb self version` — Print rust-lldb version
- `rust-lldb _ _` — Passthrough to rust-lldb CLI

## Usage Examples
- "rust-lldb --help"
- "rust-lldb self version"

## Installation
```bash
cargo install rust-lldb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- rust based
