# Xed-Editor Plugin

Advanced Text Editor for Android 

## Commands

### General
- `Xed-Editor self version` — Print Xed-Editor version
- `Xed-Editor _ _` — Passthrough to xed-editor CLI

## Usage Examples
- "Run Xed-Editor"
- "Use xed-editor to Advanced Text Editor for Android "

## Installation

```bash
pip install xed-editor
```

## Key Features
- Advanced Text Editor for Android 
- CLI tool, headless and scriptable
