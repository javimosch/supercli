# roff2html Plugin

CLI tool: roff2html.

## Commands
- `roff2html <resource> <action>` — Execute roff2html commands
- `roff2html self version` — Print roff2html version
- `roff2html _ _` — Passthrough to roff2html CLI

## Usage Examples
- "roff2html --help"
- "roff2html self version"

## Installation
```bash
apt-get install roff2html 2>/dev/null || which roff2html
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
