# hf Plugin

CLI tool: hf.

## Commands
- `hf <resource> <action>` — Execute hf commands
- `hf self version` — Print hf version
- `hf _ _` — Passthrough to hf CLI

## Usage Examples
- "hf --help"
- "hf self version"

## Installation
```bash
apt-get install hf 2>/dev/null || which hf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
