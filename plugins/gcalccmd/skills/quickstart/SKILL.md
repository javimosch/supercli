# gcalccmd Plugin

CLI tool: gcalccmd.

## Commands
- `gcalccmd <resource> <action>` — Execute gcalccmd commands
- `gcalccmd self version` — Print gcalccmd version
- `gcalccmd _ _` — Passthrough to gcalccmd CLI

## Usage Examples
- "gcalccmd --help"
- "gcalccmd self version"

## Installation
```bash
apt-get install gcalccmd 2>/dev/null || which gcalccmd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
