# mktexmf Plugin

CLI tool: mktexmf.

## Commands
- `mktexmf <resource> <action>` — Execute mktexmf commands
- `mktexmf self version` — Print mktexmf version
- `mktexmf _ _` — Passthrough to mktexmf CLI

## Usage Examples
- "mktexmf --help"
- "mktexmf self version"

## Installation
```bash
apt-get install mktexmf 2>/dev/null || which mktexmf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
