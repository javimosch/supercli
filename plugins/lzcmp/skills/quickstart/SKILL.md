# lzcmp Plugin

CLI tool: lzcmp.

## Commands
- `lzcmp <resource> <action>` — Execute lzcmp commands
- `lzcmp self version` — Print lzcmp version
- `lzcmp _ _` — Passthrough to lzcmp CLI

## Usage Examples
- "lzcmp --help"
- "lzcmp self version"

## Installation
```bash
apt-get install lzcmp 2>/dev/null || which lzcmp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
