# oxwm Plugin

Minimalist window manager

## Commands

### Version
`oxwm self version` — Print oxwm version

### Passthrough
`oxwm _ _` — Passthrough to oxwm CLI with all arguments forwarded.

## Usage Examples

```bash
oxwm --version
oxwm --help
```

## Installation

```bash
cargo install oxwm
```

## Key Features
- Minimalist window manager
