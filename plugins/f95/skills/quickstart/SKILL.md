# f95 Plugin

CLI tool: f95.

## Commands
- `f95 <resource> <action>` — Execute f95 commands
- `f95 self version` — Print f95 version
- `f95 _ _` — Passthrough to f95 CLI

## Usage Examples
- "f95 --help"
- "f95 self version"

## Installation
```bash
apt-get install f95 2>/dev/null || which f95
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
