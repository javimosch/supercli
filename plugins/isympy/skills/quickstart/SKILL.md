# isympy Plugin

CLI tool: isympy.

## Commands
- `isympy <resource> <action>` — Execute isympy commands
- `isympy self version` — Print isympy version
- `isympy _ _` — Passthrough to isympy CLI

## Usage Examples
- "isympy --help"
- "isympy self version"

## Installation
```bash
apt-get install isympy 2>/dev/null || which isympy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
