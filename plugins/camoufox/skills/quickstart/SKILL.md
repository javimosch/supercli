# camoufox Plugin

🦊 Anti-detect browser

## Commands

### General
- `camoufox self version` — Print camoufox version
- `camoufox _ _` — Passthrough to camoufox CLI

## Usage Examples
- "Run camoufox"
- "Use camoufox to 🦊 Anti-detect browser"

## Installation

```bash
pip install camoufox
```

## Key Features
- 🦊 Anti-detect browser
- CLI tool, headless and scriptable
