# oakdecode Plugin

CLI tool: oakdecode.

## Commands
- `oakdecode <resource> <action>` — Execute oakdecode commands
- `oakdecode self version` — Print oakdecode version
- `oakdecode _ _` — Passthrough to oakdecode CLI

## Usage Examples
- "oakdecode --help"
- "oakdecode self version"

## Installation
```bash
apt-get install oakdecode 2>/dev/null || which oakdecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
