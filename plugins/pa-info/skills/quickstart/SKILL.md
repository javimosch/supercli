# pa-info Plugin

CLI tool: pa-info.

## Commands
- `pa-info <resource> <action>` — Execute pa-info commands
- `pa-info self version` — Print pa-info version
- `pa-info _ _` — Passthrough to pa-info CLI

## Usage Examples
- "pa-info --help"
- "pa-info self version"

## Installation
```bash
apt-get install pa-info 2>/dev/null || which pa-info
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
