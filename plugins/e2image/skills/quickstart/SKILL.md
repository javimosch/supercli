# e2image Plugin

CLI tool: e2image.

## Commands
- `e2image <resource> <action>` — Execute e2image commands
- `e2image self version` — Print e2image version
- `e2image _ _` — Passthrough to e2image CLI

## Usage Examples
- "e2image --help"
- "e2image self version"

## Installation
```bash
apt-get install e2image 2>/dev/null || which e2image
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
