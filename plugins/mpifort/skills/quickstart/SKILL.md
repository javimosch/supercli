# mpifort Plugin

CLI tool: mpifort.

## Commands
- `mpifort <resource> <action>` — Execute mpifort commands
- `mpifort self version` — Print mpifort version
- `mpifort _ _` — Passthrough to mpifort CLI

## Usage Examples
- "mpifort --help"
- "mpifort self version"

## Installation
```bash
apt-get install mpifort 2>/dev/null || which mpifort
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
