# gvcolor Plugin

CLI tool: gvcolor.

## Commands
- `gvcolor <resource> <action>` — Execute gvcolor commands
- `gvcolor self version` — Print gvcolor version
- `gvcolor _ _` — Passthrough to gvcolor CLI

## Usage Examples
- "gvcolor --help"
- "gvcolor self version"

## Installation
```bash
apt-get install gvcolor 2>/dev/null || which gvcolor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
