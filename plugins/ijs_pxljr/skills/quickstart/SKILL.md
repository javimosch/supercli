# ijs_pxljr Plugin

CLI tool: ijs_pxljr.

## Commands
- `ijs_pxljr <resource> <action>` — Execute ijs_pxljr commands
- `ijs_pxljr self version` — Print ijs_pxljr version
- `ijs_pxljr _ _` — Passthrough to ijs_pxljr CLI

- "ijs_pxljr self version"
