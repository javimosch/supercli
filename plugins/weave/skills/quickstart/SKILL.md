# weave Plugin

CLI tool: weave.

## Commands
- `weave <resource> <action>` — Execute weave commands
- `weave self version` — Print weave version
- `weave _ _` — Passthrough to weave CLI

## Usage Examples
- "weave --help"
- "weave self version"

## Installation
```bash
apt-get install weave 2>/dev/null || which weave
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
