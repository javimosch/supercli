# credstash Plugin
Use AWS KMS to manage credentials securely

## Commands
- `credstash <resource> <action>` — Execute credstash commands
- `credstash _ _` — Passthrough to credstash CLI

## Usage
- `credstash _ _ <args>` — Run credstash with any arguments
