# cups.ipptool Plugin

CLI tool: cups.ipptool.

## Commands
- `cups.ipptool <resource> <action>` — Execute cups.ipptool commands
- `cups.ipptool self version` — Print cups.ipptool version
- `cups.ipptool _ _` — Passthrough to cups.ipptool CLI

## Usage Examples
- "cups.ipptool --help"
- "cups.ipptool self version"

## Installation
```bash
apt-get install cups.ipptool 2>/dev/null || which cups.ipptool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
