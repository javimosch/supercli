# lzless Plugin

CLI tool: lzless.

## Commands
- `lzless <resource> <action>` — Execute lzless commands
- `lzless self version` — Print lzless version
- `lzless _ _` — Passthrough to lzless CLI

## Usage Examples
- "lzless --help"
- "lzless self version"

## Installation
```bash
apt-get install lzless 2>/dev/null || which lzless
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
