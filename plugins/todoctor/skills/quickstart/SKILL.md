# todoctor Plugin

Analyze and report TODO comments in JS/TS in Svelte

## Commands

### Operations
- `todoctor self version` — Print todoctor version
- `todoctor _ _` — Passthrough to todoctor CLI

## Usage Examples
- `todoctor --help`
- `todoctor <args>`

## Installation

```bash
npm install -g todoctor
```

## Examples

```bash
todoctor --version
todoctor --help
```
