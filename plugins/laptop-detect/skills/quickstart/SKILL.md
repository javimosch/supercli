# laptop-detect Plugin

CLI tool: laptop-detect.

## Commands
- `laptop-detect <resource> <action>` — Execute laptop-detect commands
- `laptop-detect self version` — Print laptop-detect version
- `laptop-detect _ _` — Passthrough to laptop-detect CLI

## Usage Examples
- "laptop-detect --help"
- "laptop-detect self version"

## Installation
```bash
apt-get install laptop-detect 2>/dev/null || which laptop-detect
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
