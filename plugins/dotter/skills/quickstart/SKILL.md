# dotter Plugin
Rust-based templating dotfile manager with handlebars support

## Commands
- `dotter <resource> <action>` — Execute dotter commands
- `dotter _ _` — Passthrough to dotter CLI

## Usage
- `dotter _ _ <args>` — Run dotter with any arguments
