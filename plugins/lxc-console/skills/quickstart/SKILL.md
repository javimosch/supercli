# lxc-console Plugin

CLI tool: lxc-console.

## Commands
- `lxc-console <resource> <action>` — Execute lxc-console commands
- `lxc-console self version` — Print lxc-console version
- `lxc-console _ _` — Passthrough to lxc-console CLI

## Usage Examples
- "lxc-console --help"
- "lxc-console self version"

## Installation
```bash
apt-get install lxc-console 2>/dev/null || which lxc-console
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
