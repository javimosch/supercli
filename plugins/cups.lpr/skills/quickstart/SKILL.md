# cups.lpr Plugin

CLI tool: cups.lpr.

## Commands
- `cups.lpr <resource> <action>` — Execute cups.lpr commands
- `cups.lpr self version` — Print cups.lpr version
- `cups.lpr _ _` — Passthrough to cups.lpr CLI

## Usage Examples
- "cups.lpr --help"
- "cups.lpr self version"

## Installation
```bash
apt-get install cups.lpr 2>/dev/null || which cups.lpr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
