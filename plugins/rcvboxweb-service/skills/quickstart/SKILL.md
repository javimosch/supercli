# rcvboxweb-service Plugin

CLI tool: rcvboxweb-service.

## Commands
- `rcvboxweb-service <resource> <action>` — Execute rcvboxweb-service commands
- `rcvboxweb-service self version` — Print rcvboxweb-service version
- `rcvboxweb-service _ _` — Passthrough to rcvboxweb-service CLI

## Usage Examples
- "rcvboxweb-service --help"
- "rcvboxweb-service self version"

## Installation
```bash
apt-get install rcvboxweb-service 2>/dev/null || which rcvboxweb-service
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
