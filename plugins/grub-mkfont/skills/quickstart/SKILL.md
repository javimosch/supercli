# grub-mkfont Plugin

CLI tool: grub-mkfont.

## Commands
- `grub-mkfont <resource> <action>` — Execute grub-mkfont commands
- `grub-mkfont self version` — Print grub-mkfont version
- `grub-mkfont _ _` — Passthrough to grub-mkfont CLI

## Usage Examples
- "grub-mkfont --help"
- "grub-mkfont self version"

## Installation
```bash
apt-get install grub-mkfont 2>/dev/null || which grub-mkfont
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
