# ps2ps Plugin

CLI tool: ps2ps.

## Commands
- `ps2ps <resource> <action>` — Execute ps2ps commands
- `ps2ps self version` — Print ps2ps version
- `ps2ps _ _` — Passthrough to ps2ps CLI

## Usage Examples
- "ps2ps --help"
- "ps2ps self version"

## Installation
```bash
apt-get install ps2ps 2>/dev/null || which ps2ps
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
