# sload.f2fs Plugin

CLI tool: sload.f2fs.

- `sload.f2fs <resource> <action>` — Execute sload.f2fs commands
- `sload.f2fs self version` — Print sload.f2fs version
- `sload.f2fs _ _` — Passthrough to sload.f2fs CLI
