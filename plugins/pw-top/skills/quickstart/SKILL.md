# pw-top Plugin

CLI tool: pw-top.

## Commands
- `pw-top <resource> <action>` — Execute pw-top commands
- `pw-top self version` — Print pw-top version
- `pw-top _ _` — Passthrough to pw-top CLI

## Usage Examples
- "pw-top --help"
- "pw-top self version"

## Installation
```bash
apt-get install pw-top 2>/dev/null || which pw-top
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
