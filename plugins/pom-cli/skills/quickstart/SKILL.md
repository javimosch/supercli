# pom-cli Plugin
Minimal Pomodoro timer with desktop notifications

## Commands
- `pom-cli <resource> <action>` — Execute pom-cli commands
- `pom-cli _ _` — Passthrough to pom-cli CLI

## Usage
- `pom-cli _ _ <args>` — Run pom-cli with any arguments
