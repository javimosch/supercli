# intltool-prepare Plugin

CLI tool: intltool-prepare.

## Commands
- `intltool-prepare <resource> <action>` — Execute intltool-prepare commands
- `intltool-prepare self version` — Print intltool-prepare version
- `intltool-prepare _ _` — Passthrough to intltool-prepare CLI

## Usage Examples
- "intltool-prepare --help"
- "intltool-prepare self version"

## Installation
```bash
apt-get install intltool-prepare 2>/dev/null || which intltool-prepare
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
