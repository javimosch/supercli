# pnmfile Plugin

CLI tool: pnmfile.

## Commands
- `pnmfile <resource> <action>` — Execute pnmfile commands
- `pnmfile self version` — Print pnmfile version
- `pnmfile _ _` — Passthrough to pnmfile CLI

## Usage Examples
- "pnmfile --help"
- "pnmfile self version"

## Installation
```bash
apt-get install pnmfile 2>/dev/null || which pnmfile
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
