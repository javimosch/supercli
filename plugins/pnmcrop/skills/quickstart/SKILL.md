# pnmcrop Plugin

CLI tool: pnmcrop.

## Commands
- `pnmcrop <resource> <action>` — Execute pnmcrop commands
- `pnmcrop self version` — Print pnmcrop version
- `pnmcrop _ _` — Passthrough to pnmcrop CLI

## Usage Examples
- "pnmcrop --help"
- "pnmcrop self version"

## Installation
```bash
apt-get install pnmcrop 2>/dev/null || which pnmcrop
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
