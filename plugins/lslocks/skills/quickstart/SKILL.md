# lslocks Plugin

CLI tool: lslocks.

## Commands
- `lslocks <resource> <action>` — Execute lslocks commands
- `lslocks self version` — Print lslocks version
- `lslocks _ _` — Passthrough to lslocks CLI

## Usage Examples
- "lslocks --help"
- "lslocks self version"

## Installation
```bash
apt-get install lslocks 2>/dev/null || which lslocks
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
