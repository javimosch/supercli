# h-m-m Plugin

Simple fast keyboard-centric terminal mind map tool — file-based, non-interactive mode

## Commands
- `h-m-m self version` — Print h-m-m version
- `h-m-m _ _` — Passthrough to h-m-m CLI

## Usage Examples
- `h-m-m self version` — Check installed version
- `h-m-m _ _ --help` — Show h-m-m help
- `h-m-m _ _ --json` — JSON output mode

## Installation
```bash
npm install -g h-m-m
```

## Key Features
- mindmap, productivity, cli
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
