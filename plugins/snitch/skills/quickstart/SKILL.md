# snitch Plugin

a prettier way to inspect network connections

## Commands

### General
- `snitch self version` — Print snitch version
- `snitch _ _` — Passthrough to snitch CLI

## Usage Examples
- "Run snitch"
- "Use snitch to a prettier way to inspect network connections"

## Installation

```bash
pip install snitch
```

## Key Features
- a prettier way to inspect network connections
- CLI tool, headless and scriptable
