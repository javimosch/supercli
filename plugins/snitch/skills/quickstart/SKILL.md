# snitch Plugin
Modern network connection inspector.
## Commands
- `snitch _ _` — Passthrough to snitch CLI
## Installation
```bash
cargo install snitch
```
## Key Features
- **Network inspection** — View all connections
- **Readable output** — Human-focused display
- **Pipeline-ready** — Structured data export
