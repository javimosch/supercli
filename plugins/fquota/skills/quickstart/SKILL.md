# fquota Plugin
Disk usage alert and analysis tool for filesystems

## Commands
- `fquota <resource> <action>` — Execute fquota commands
- `fquota _ _` — Passthrough to fquota CLI

## Usage
- `fquota _ _ <args>` — Run fquota with any arguments
