# pdvitomp Plugin

CLI tool: pdvitomp.

## Commands
- `pdvitomp <resource> <action>` — Execute pdvitomp commands
- `pdvitomp self version` — Print pdvitomp version
- `pdvitomp _ _` — Passthrough to pdvitomp CLI

## Usage Examples
- "pdvitomp --help"
- "pdvitomp self version"

## Installation
```bash
apt-get install pdvitomp 2>/dev/null || which pdvitomp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
