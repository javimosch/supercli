# hd Plugin

CLI tool: hd.

## Commands
- `hd <resource> <action>` — Execute hd commands
- `hd self version` — Print hd version
- `hd _ _` — Passthrough to hd CLI

## Usage Examples
- "hd --help"
- "hd self version"

## Installation
```bash
apt-get install hd 2>/dev/null || which hd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
