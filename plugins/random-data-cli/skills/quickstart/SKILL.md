# random-data-cli Plugin
Generate random mock datasets from the command line

## Commands
- `random-data-cli <resource> <action>` — Execute random-data-cli commands
- `random-data-cli _ _` — Passthrough to random-data-cli CLI

## Usage
- `random-data-cli _ _ <args>` — Run random-data-cli with any arguments
