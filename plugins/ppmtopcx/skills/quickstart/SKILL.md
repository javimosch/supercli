# ppmtopcx Plugin

CLI tool: ppmtopcx.

## Commands
- `ppmtopcx <resource> <action>` — Execute ppmtopcx commands
- `ppmtopcx self version` — Print ppmtopcx version
- `ppmtopcx _ _` — Passthrough to ppmtopcx CLI

## Usage Examples
- "ppmtopcx --help"
- "ppmtopcx self version"

## Installation
```bash
apt-get install ppmtopcx 2>/dev/null || which ppmtopcx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
