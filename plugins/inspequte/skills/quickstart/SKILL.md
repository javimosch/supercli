# inspequte Plugin
CLI tool for inspequte.

## Commands
- `inspequte <resource> <action>` — Execute inspequte commands
- `inspequte _ _` — Passthrough to inspequte CLI

## Installation
```bash
cargo install inspequte
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
