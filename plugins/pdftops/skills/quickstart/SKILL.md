# pdftops Plugin

CLI tool: pdftops.

## Commands
- `pdftops <resource> <action>` — Execute pdftops commands
- `pdftops self version` — Print pdftops version
- `pdftops _ _` — Passthrough to pdftops CLI

## Usage Examples
- "pdftops --help"
- "pdftops self version"

## Installation
```bash
apt-get install pdftops 2>/dev/null || which pdftops
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
