# lookbib Plugin

CLI tool: lookbib.

## Commands
- `lookbib <resource> <action>` — Execute lookbib commands
- `lookbib self version` — Print lookbib version
- `lookbib _ _` — Passthrough to lookbib CLI

## Usage Examples
- "lookbib --help"
- "lookbib self version"

## Installation
```bash
apt-get install lookbib 2>/dev/null || which lookbib
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
