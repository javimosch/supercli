# waylandcraft Plugin

Wayland Compositor in Minecraft

## Commands

### General
- `waylandcraft self version` — Print waylandcraft version
- `waylandcraft _ _` — Passthrough to waylandcraft CLI

## Usage Examples
- "Run waylandcraft"
- "Use waylandcraft to Wayland Compositor in Minecraft"

## Installation

```bash
pip install waylandcraft
```

## Key Features
- Wayland Compositor in Minecraft
- CLI tool, headless and scriptable
