# futurize Plugin

CLI tool: futurize.

## Commands
- `futurize <resource> <action>` — Execute futurize commands
- `futurize self version` — Print futurize version
- `futurize _ _` — Passthrough to futurize CLI

## Usage Examples
- "futurize --help"
- "futurize self version"

## Installation
```bash
apt-get install futurize 2>/dev/null || which futurize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
