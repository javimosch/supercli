# openbao Plugin

OpenBao is a software solution to manage, store, and distribute sensitive data including secrets, certificates, and keys.

## Commands
- `openbao <resource> <action>` — Execute openbao commands
- `openbao self version` — Print openbao version
- `openbao _ _` — Passthrough to openbao CLI

## Installation

```bash
pip install openbao
```
