# uic3 Plugin

CLI tool: uic3.

## Commands
- `uic3 <resource> <action>` — Execute uic3 commands
- `uic3 self version` — Print uic3 version
- `uic3 _ _` — Passthrough to uic3 CLI

## Usage Examples
- "uic3 --help"
- "uic3 self version"

## Installation
```bash
apt-get install uic3 2>/dev/null || which uic3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
