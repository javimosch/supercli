# digger Plugin

Digger is an open source IaC orchestration tool. Digger allows you to run IaC in your existing CI pipeline ⚡️  

## Commands
- `digger <resource> <action>` — Execute digger commands
- `digger self version` — Print digger version
- `digger _ _` — Passthrough to digger CLI

## Installation

```bash
pip install digger
```
