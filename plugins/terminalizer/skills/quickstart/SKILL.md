# terminalizer Plugin
Record your terminal and generate animated GIFs

## Commands
- `terminalizer <resource> <action>` — Execute terminalizer commands
- `terminalizer _ _` — Passthrough to terminalizer CLI

## Usage
- `terminalizer _ _ <args>` — Run terminalizer with any arguments
