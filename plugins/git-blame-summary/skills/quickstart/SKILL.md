# git-blame-summary
git-blame-summary — aggregate git blame statistics per author. Shows lines of code, file count, and percentage per contributor.

## Commands
- `git-blame-summary <resource> <action>` — Execute git-blame-summary commands
- `git blame-summary run` — git-blame-summary — aggregate git blame statistics per author. Shows lines of code, file count, and percentage per contributor.
