# sbkeysync Plugin

CLI tool: sbkeysync.

## Commands
- `sbkeysync <resource> <action>` — Execute sbkeysync commands
- `sbkeysync self version` — Print sbkeysync version
- `sbkeysync _ _` — Passthrough to sbkeysync CLI

## Usage Examples
- "sbkeysync --help"
- "sbkeysync self version"

## Installation
```bash
apt-get install sbkeysync 2>/dev/null || which sbkeysync
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
