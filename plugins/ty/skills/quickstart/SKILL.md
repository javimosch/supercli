# ty Plugin

Extremely fast Python type checker

## Commands

### Version
`ty self version` — Print ty version

### Passthrough
`ty _ _` — Passthrough to ty CLI with all arguments forwarded.

## Usage Examples

```bash
ty --version
ty --help
```

## Installation

```bash
pip install ty
```

## Key Features
- Extremely fast Python type checker
