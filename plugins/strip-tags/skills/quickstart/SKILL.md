# strip-tags Plugin
Strip HTML tags from text for LLM processing

## Commands
- `strip-tags <resource> <action>` — Execute strip-tags commands
- `strip-tags _ _` — Passthrough to strip-tags CLI

## Usage
- `strip-tags _ _ <args>` — Run strip-tags with any arguments
