# evince-previewer Plugin

CLI tool: evince-previewer.

## Commands
- `evince-previewer <resource> <action>` — Execute evince-previewer commands
- `evince-previewer self version` — Print evince-previewer version
- `evince-previewer _ _` — Passthrough to evince-previewer CLI

## Usage Examples
- "evince-previewer --help"
- "evince-previewer self version"

## Installation
```bash
apt-get install evince-previewer 2>/dev/null || which evince-previewer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
