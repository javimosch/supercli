# pre-grohtml Plugin

CLI tool: pre-grohtml.

## Commands
- `pre-grohtml <resource> <action>` — Execute pre-grohtml commands
- `pre-grohtml self version` — Print pre-grohtml version
- `pre-grohtml _ _` — Passthrough to pre-grohtml CLI

## Usage Examples
- "pre-grohtml --help"
- "pre-grohtml self version"

## Installation
```bash
apt-get install pre-grohtml 2>/dev/null || which pre-grohtml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
