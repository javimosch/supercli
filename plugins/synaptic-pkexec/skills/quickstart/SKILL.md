# synaptic-pkexec Plugin

CLI tool: synaptic-pkexec.

## Commands
- `synaptic-pkexec <resource> <action>` — Execute synaptic-pkexec commands
- `synaptic-pkexec self version` — Print synaptic-pkexec version
- `synaptic-pkexec _ _` — Passthrough to synaptic-pkexec CLI

## Usage Examples
- "synaptic-pkexec --help"
- "synaptic-pkexec self version"

## Installation
```bash
apt-get install synaptic-pkexec 2>/dev/null || which synaptic-pkexec
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
