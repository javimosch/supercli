# cli-emoji Plugin
Display large-format emojis directly in the terminal

## Commands
- `cli-emoji <resource> <action>` — Execute cli-emoji commands
- `cli-emoji _ _` — Passthrough to cli-emoji CLI

## Usage
- `cli-emoji _ _ <args>` — Run cli-emoji with any arguments
