# gtscheck Plugin

CLI tool: gtscheck.

## Commands
- `gtscheck <resource> <action>` — Execute gtscheck commands
- `gtscheck self version` — Print gtscheck version
- `gtscheck _ _` — Passthrough to gtscheck CLI

## Usage Examples
- "gtscheck --help"
- "gtscheck self version"

## Installation
```bash
apt-get install gtscheck 2>/dev/null || which gtscheck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
