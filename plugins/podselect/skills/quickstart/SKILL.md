# podselect Plugin

CLI tool: podselect.

## Commands
- `podselect <resource> <action>` — Execute podselect commands
- `podselect self version` — Print podselect version
- `podselect _ _` — Passthrough to podselect CLI

## Usage Examples
- "podselect --help"
- "podselect self version"

## Installation
```bash
apt-get install podselect 2>/dev/null || which podselect
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
