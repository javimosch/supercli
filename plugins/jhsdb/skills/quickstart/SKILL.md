# jhsdb Plugin

CLI tool: jhsdb.

## Commands
- `jhsdb <resource> <action>` — Execute jhsdb commands
- `jhsdb self version` — Print jhsdb version
- `jhsdb _ _` — Passthrough to jhsdb CLI

## Usage Examples
- "jhsdb --help"
- "jhsdb self version"

## Installation
```bash
apt-get install jhsdb 2>/dev/null || which jhsdb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
