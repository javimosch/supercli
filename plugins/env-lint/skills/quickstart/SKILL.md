# env-lint Plugin
Validate .env file format from stdin. Checks for proper KEY=VALUE syntax.

## Commands
- `env-lint <resource> <action>` — Execute env-lint commands
- `env lint run` — env-lint utility

## Usage
- `env lint run < .env`
