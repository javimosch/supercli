# oem-getlogs Plugin

CLI tool: oem-getlogs.

## Commands
- `oem-getlogs <resource> <action>` — Execute oem-getlogs commands
- `oem-getlogs self version` — Print oem-getlogs version
- `oem-getlogs _ _` — Passthrough to oem-getlogs CLI

## Usage Examples
- "oem-getlogs --help"
- "oem-getlogs self version"

## Installation
```bash
apt-get install oem-getlogs 2>/dev/null || which oem-getlogs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
