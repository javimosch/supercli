# cookcli Plugin
CLI for parsing planning and managing Cooklang recipes

## Commands
- `cookcli <resource> <action>` — Execute cookcli commands
- `cookcli _ _` — Passthrough to cookcli CLI

## Usage
- `cookcli _ _ <args>` — Run cookcli with any arguments
