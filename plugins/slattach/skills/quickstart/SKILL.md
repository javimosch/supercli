# slattach Plugin

CLI tool: slattach.

## Commands
- `slattach <resource> <action>` — Execute slattach commands
- `slattach self version` — Print slattach version
- `slattach _ _` — Passthrough to slattach CLI

## Usage Examples
- "slattach --help"
- "slattach self version"

## Installation
```bash
apt-get install slattach 2>/dev/null || which slattach
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
