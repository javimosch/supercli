# qmake Plugin

CLI tool: qmake.

## Commands
- `qmake <resource> <action>` — Execute qmake commands
- `qmake self version` — Print qmake version
- `qmake _ _` — Passthrough to qmake CLI

## Usage Examples
- "qmake --help"
- "qmake self version"

## Installation
```bash
apt-get install qmake 2>/dev/null || which qmake
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
