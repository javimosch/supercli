# f2fstat Plugin

CLI tool: f2fstat.

## Commands
- `f2fstat <resource> <action>` — Execute f2fstat commands
- `f2fstat self version` — Print f2fstat version
- `f2fstat _ _` — Passthrough to f2fstat CLI

## Usage Examples
- "f2fstat --help"
- "f2fstat self version"

## Installation
```bash
apt-get install f2fstat 2>/dev/null || which f2fstat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
