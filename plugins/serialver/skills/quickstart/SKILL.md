# serialver Plugin

CLI tool: serialver.

## Commands
- `serialver <resource> <action>` — Execute serialver commands
- `serialver self version` — Print serialver version
- `serialver _ _` — Passthrough to serialver CLI

## Usage Examples
- "serialver --help"
- "serialver self version"

## Installation
```bash
apt-get install serialver 2>/dev/null || which serialver
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
