# opcode Plugin

CLI tool: opcode.

## Commands
- `opcode <resource> <action>` — Execute opcode commands
- `opcode self version` — Print opcode version
- `opcode _ _` — Passthrough to opcode CLI

## Usage Examples
- "opcode --help"
- "opcode self version"

## Installation
```bash
apt-get install opcode 2>/dev/null || which opcode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
