# cups.lpq Plugin

CLI tool: cups.lpq.

## Commands
- `cups.lpq <resource> <action>` — Execute cups.lpq commands
- `cups.lpq self version` — Print cups.lpq version
- `cups.lpq _ _` — Passthrough to cups.lpq CLI

## Usage Examples
- "cups.lpq --help"
- "cups.lpq self version"

## Installation
```bash
apt-get install cups.lpq 2>/dev/null || which cups.lpq
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
