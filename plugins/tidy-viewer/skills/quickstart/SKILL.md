# tidy-viewer Plugin
CLI tool for tidy-viewer.

## Commands
- `tidy-viewer <resource> <action>` — Execute tidy-viewer commands
- `tidy-viewer _ _` — Passthrough to tidy-viewer CLI

## Installation
```bash
cargo install tidy-viewer
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
