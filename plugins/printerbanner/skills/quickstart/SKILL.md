# printerbanner Plugin

CLI tool: printerbanner.

## Commands
- `printerbanner <resource> <action>` — Execute printerbanner commands
- `printerbanner self version` — Print printerbanner version
- `printerbanner _ _` — Passthrough to printerbanner CLI

## Usage Examples
- "printerbanner --help"
- "printerbanner self version"

## Installation
```bash
apt-get install printerbanner 2>/dev/null || which printerbanner
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
