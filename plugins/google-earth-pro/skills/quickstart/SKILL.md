# google-earth-pro Plugin

CLI tool: google-earth-pro.

## Commands
- `google-earth-pro <resource> <action>` — Execute google-earth-pro commands
- `google-earth-pro self version` — Print google-earth-pro version
- `google-earth-pro _ _` — Passthrough to google-earth-pro CLI

## Usage Examples
- "google-earth-pro --help"
- "google-earth-pro self version"

## Installation
```bash
apt-get install google-earth-pro 2>/dev/null || which google-earth-pro
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
