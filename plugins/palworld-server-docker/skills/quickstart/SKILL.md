# palworld-server-docker Plugin

A Docker Container to easily run a Palworld dedicated server.

## Commands

### General
- `palworld-server-docker self version` — Print palworld-server-docker version
- `palworld-server-docker _ _` — Passthrough to palworld-server-docker CLI

## Usage Examples
- "Run palworld-server-docker"
- "Use palworld-server-docker to A Docker Container to easily run a Palworld dedicated server"

## Installation

```bash
pip install palworld-server-docker
```

## Key Features
- A Docker Container to easily run a Palworld dedicated server.
- CLI tool, headless and scriptable
