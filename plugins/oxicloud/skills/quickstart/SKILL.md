# Oxicloud Plugin

Ultra-fast, secure and lightweight self-hosted cloud storage built in Rust

## Commands
- `oxicloud _ _` — Passthrough to oxicloud CLI

## Installation

```bash
cargo install oxicloud
```

## Examples
```bash
oxicloud --help
oxicloud --version
```
