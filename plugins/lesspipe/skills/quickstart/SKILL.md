# lesspipe Plugin

CLI tool: lesspipe.

## Commands
- `lesspipe <resource> <action>` — Execute lesspipe commands
- `lesspipe self version` — Print lesspipe version
- `lesspipe _ _` — Passthrough to lesspipe CLI

## Usage Examples
- "lesspipe --help"
- "lesspipe self version"

## Installation
```bash
apt-get install lesspipe 2>/dev/null || which lesspipe
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
