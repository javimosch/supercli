# kubefwd
kubefwd — Kubernetes service port-forwarding. Forward multiple services to local machine for development.

## Commands
- `kubefwd <resource> <action>` — Execute kubefwd commands
- `kubefwd _ _` — Passthrough to kubefwd CLI
