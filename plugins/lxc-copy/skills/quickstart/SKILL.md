# lxc-copy Plugin

CLI tool: lxc-copy.

## Commands
- `lxc-copy <resource> <action>` — Execute lxc-copy commands
- `lxc-copy self version` — Print lxc-copy version
- `lxc-copy _ _` — Passthrough to lxc-copy CLI

## Usage Examples
- "lxc-copy --help"
- "lxc-copy self version"

## Installation
```bash
apt-get install lxc-copy 2>/dev/null || which lxc-copy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
