# neqn Plugin

CLI tool: neqn.

## Commands
- `neqn <resource> <action>` — Execute neqn commands
- `neqn self version` — Print neqn version
- `neqn _ _` — Passthrough to neqn CLI

## Usage Examples
- "neqn --help"
- "neqn self version"

## Installation
```bash
apt-get install neqn 2>/dev/null || which neqn
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
