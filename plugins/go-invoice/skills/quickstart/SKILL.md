# go-invoice Plugin
CLI with MCP support for billing and invoice generation

## Commands
- `go-invoice <resource> <action>` — Execute go-invoice commands
- `go-invoice _ _` — Passthrough to go-invoice CLI

## Usage
- `go-invoice _ _ <args>` — Run go-invoice with any arguments
