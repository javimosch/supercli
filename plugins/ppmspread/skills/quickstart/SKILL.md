# ppmspread Plugin

CLI tool: ppmspread.

## Commands
- `ppmspread <resource> <action>` — Execute ppmspread commands
- `ppmspread self version` — Print ppmspread version
- `ppmspread _ _` — Passthrough to ppmspread CLI

## Usage Examples
- "ppmspread --help"
- "ppmspread self version"

## Installation
```bash
apt-get install ppmspread 2>/dev/null || which ppmspread
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
