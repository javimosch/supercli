# im-launch Plugin

CLI tool: im-launch.

## Commands
- `im-launch <resource> <action>` — Execute im-launch commands
- `im-launch self version` — Print im-launch version
- `im-launch _ _` — Passthrough to im-launch CLI

## Usage Examples
- "im-launch --help"
- "im-launch self version"

## Installation
```bash
apt-get install im-launch 2>/dev/null || which im-launch
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
