# dice-roller-cli Plugin
Command-line interface for RPG dice rolling logic

## Commands
- `dice-roller-cli <resource> <action>` — Execute dice-roller-cli commands
- `dice-roller-cli _ _` — Passthrough to dice-roller-cli CLI

## Usage
- `dice-roller-cli _ _ <args>` — Run dice-roller-cli with any arguments
