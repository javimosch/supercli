# xfconf-query Plugin

CLI tool: xfconf-query.

## Commands
- `xfconf-query <resource> <action>` — Execute xfconf-query commands
- `xfconf-query self version` — Print xfconf-query version
- `xfconf-query _ _` — Passthrough to xfconf-query CLI

## Usage Examples
- "xfconf-query --help"
- "xfconf-query self version"

## Installation
```bash
apt-get install xfconf-query 2>/dev/null || which xfconf-query
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
