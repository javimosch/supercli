# ppt-master Plugin

AI generates a real, editable PowerPoint from any document — native shapes & animations, speaker notes voiced as audio narration, and the option to follow your own .pptx template, not slide images · by Hugo He

## Commands

### General
- `ppt-master self version` — Print ppt-master version
- `ppt-master _ _` — Passthrough to ppt-master CLI

## Usage Examples
- "Run ppt-master"
- "Use ppt-master to AI generates a real, editable PowerPoint from any document —"

## Installation

```bash
pip install ppt-master
```

## Key Features
- AI generates a real, editable PowerPoint from any document — native shapes & animations, speaker not
- CLI tool, headless and scriptable
