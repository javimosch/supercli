# gnome-maps Plugin

CLI tool: gnome-maps.

## Commands
- `gnome-maps <resource> <action>` — Execute gnome-maps commands
- `gnome-maps self version` — Print gnome-maps version
- `gnome-maps _ _` — Passthrough to gnome-maps CLI

## Usage Examples
- "gnome-maps --help"
- "gnome-maps self version"

## Installation
```bash
apt-get install gnome-maps 2>/dev/null || which gnome-maps
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
