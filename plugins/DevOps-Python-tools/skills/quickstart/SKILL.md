# DevOps-Python-tools Plugin

use DevOps and cloud management tools

## Commands
- `DevOps-Python-tools self version` — Print DevOps-Python-tools version
- `DevOps-Python-tools _ _` — Passthrough to devops-python-tools CLI

## Usage Examples
- "Check AWS resources"
- "Manage Kubernetes cluster"
- "Monitor Docker containers"

## Installation

```bash
pip install devops-python-tools
```

## Examples
```bash
devops-aws s3 ls
devops-k8s get pods
devops-docker stats
```

## Key Features
- 80+ DevOps CLI tools
- AWS, GCP, Azure support
- Kubernetes management
- Docker operations
