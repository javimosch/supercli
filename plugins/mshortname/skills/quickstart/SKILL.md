# mshortname Plugin

CLI tool: mshortname.

## Commands
- `mshortname <resource> <action>` — Execute mshortname commands
- `mshortname self version` — Print mshortname version
- `mshortname _ _` — Passthrough to mshortname CLI

## Usage Examples
- "mshortname --help"
- "mshortname self version"

## Installation
```bash
apt-get install mshortname 2>/dev/null || which mshortname
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
