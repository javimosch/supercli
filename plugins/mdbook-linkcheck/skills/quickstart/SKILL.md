# mdbook-linkcheck
mdbook-linkcheck — link checker plugin for mdbook. Validates all internal and external links in mdbook projects.

## Commands
- `mdbook-linkcheck <resource> <action>` — Execute mdbook-linkcheck commands
- `mdbook linkcheck run` — mdbook-linkcheck — link checker plugin for mdbook. Validates all internal and external links in mdbook projects.
