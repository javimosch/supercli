# intltool-update Plugin

CLI tool: intltool-update.

## Commands
- `intltool-update <resource> <action>` — Execute intltool-update commands
- `intltool-update self version` — Print intltool-update version
- `intltool-update _ _` — Passthrough to intltool-update CLI

## Usage Examples
- "intltool-update --help"
- "intltool-update self version"

## Installation
```bash
apt-get install intltool-update 2>/dev/null || which intltool-update
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
