# grolj4 Plugin

CLI tool: grolj4.

## Commands
- `grolj4 <resource> <action>` — Execute grolj4 commands
- `grolj4 self version` — Print grolj4 version
- `grolj4 _ _` — Passthrough to grolj4 CLI

## Usage Examples
- "grolj4 --help"
- "grolj4 self version"

## Installation
```bash
apt-get install grolj4 2>/dev/null || which grolj4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
