# usr Plugin

CLI tool: usr.

## Commands
- `usr <resource> <action>` — Execute usr commands
- `usr self version` — Print usr version
- `usr _ _` — Passthrough to usr CLI

## Usage Examples
- "usr --help"
- "usr self version"

## Installation
```bash
apt-get install usr 2>/dev/null || which usr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
