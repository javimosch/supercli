# zcmp Plugin

CLI tool: zcmp.

## Commands
- `zcmp <resource> <action>` — Execute zcmp commands
- `zcmp self version` — Print zcmp version
- `zcmp _ _` — Passthrough to zcmp CLI

## Usage Examples
- "zcmp --help"
- "zcmp self version"

## Installation
```bash
apt-get install zcmp 2>/dev/null || which zcmp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
