# bartib Plugin

Simple timetracking for the command line.

## Commands
- `bartib <resource> <action>` — Execute bartib commands
- `bartib self version` — Print bartib version
- `bartib _ _` — Passthrough to bartib CLI

## Usage Examples
- "bartib --help"
- "bartib self version"

## Installation
```bash
cargo install bartib
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- rust based
