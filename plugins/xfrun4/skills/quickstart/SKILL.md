# xfrun4 Plugin

CLI tool: xfrun4.

## Commands
- `xfrun4 <resource> <action>` — Execute xfrun4 commands
- `xfrun4 self version` — Print xfrun4 version
- `xfrun4 _ _` — Passthrough to xfrun4 CLI

## Usage Examples
- "xfrun4 --help"
- "xfrun4 self version"

## Installation
```bash
apt-get install xfrun4 2>/dev/null || which xfrun4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
