# gotenberg Plugin

Developer-friendly API for document conversion

## Commands

### Version
`gotenberg self version` — Print gotenberg version

### Passthrough
`gotenberg _ _` — Passthrough to gotenberg CLI with all arguments forwarded.

## Usage Examples

```bash
gotenberg --version
gotenberg --help
```

## Installation

```bash
docker pull gotenberg/gotenberg
```
