# gsftopk Plugin

CLI tool: gsftopk.

## Commands
- `gsftopk <resource> <action>` — Execute gsftopk commands
- `gsftopk self version` — Print gsftopk version
- `gsftopk _ _` — Passthrough to gsftopk CLI

## Usage Examples
- "gsftopk --help"
- "gsftopk self version"

## Installation
```bash
apt-get install gsftopk 2>/dev/null || which gsftopk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
