# bun-plugin-dts Plugin
Bun TypeScript declaration bundler

## Commands
- `bun-plugin-dts <resource> <action>` — Execute bun-plugin-dts commands
- `bun-plugin-dts _ _` — Passthrough to bun-plugin-dts CLI

## Usage
- `bun-plugin-dts _ _ <args>` — Run bun-plugin-dts with any arguments
