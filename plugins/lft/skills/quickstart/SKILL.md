# lft Plugin

CLI tool: lft.

## Commands
- `lft <resource> <action>` — Execute lft commands
- `lft self version` — Print lft version
- `lft _ _` — Passthrough to lft CLI

## Usage Examples
- "lft --help"
- "lft self version"

## Installation
```bash
apt-get install lft 2>/dev/null || which lft
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
