# wish Plugin

CLI tool: wish.

## Commands
- `wish <resource> <action>` — Execute wish commands
- `wish self version` — Print wish version
- `wish _ _` — Passthrough to wish CLI

## Usage Examples
- "wish --help"
- "wish self version"

## Installation
```bash
apt-get install wish 2>/dev/null || which wish
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
