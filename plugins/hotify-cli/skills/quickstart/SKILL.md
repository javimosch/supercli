# hotify-cli Plugin

CLI tool: hotify-cli.

## Commands
- `hotify-cli <resource> <action>` — Execute hotify-cli commands
- `hotify-cli self version` — Print hotify-cli version
- `hotify-cli _ _` — Passthrough to hotify-cli CLI

## Usage Examples
- "hotify-cli --help"
- "hotify-cli self version"

## Installation
```bash
apt-get install hotify-cli 2>/dev/null || which hotify-cli
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
