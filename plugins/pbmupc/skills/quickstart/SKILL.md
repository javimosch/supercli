# pbmupc Plugin

CLI tool: pbmupc.

## Commands
- `pbmupc <resource> <action>` — Execute pbmupc commands
- `pbmupc self version` — Print pbmupc version
- `pbmupc _ _` — Passthrough to pbmupc CLI

## Usage Examples
- "pbmupc --help"
- "pbmupc self version"

## Installation
```bash
apt-get install pbmupc 2>/dev/null || which pbmupc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
