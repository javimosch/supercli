# mingle Plugin

CLI tool: mingle.

## Commands
- `mingle <resource> <action>` — Execute mingle commands
- `mingle self version` — Print mingle version
- `mingle _ _` — Passthrough to mingle CLI

## Usage Examples
- "mingle --help"
- "mingle self version"

## Installation
```bash
apt-get install mingle 2>/dev/null || which mingle
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
