# vgck Plugin

CLI tool: vgck.

## Commands
- `vgck <resource> <action>` — Execute vgck commands
- `vgck self version` — Print vgck version
- `vgck _ _` — Passthrough to vgck CLI

## Usage Examples
- "vgck --help"
- "vgck self version"

## Installation
```bash
apt-get install vgck 2>/dev/null || which vgck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
