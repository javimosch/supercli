# dyad Plugin

Local, open-source AI app builder for power users ✨ v0 / Lovable / Replit / Bolt alternative 🌟 Star if you like it!

## Commands
- `dyad <resource> <action>` — Execute dyad commands
- `dyad self version` — Print dyad version
- `dyad _ _` — Passthrough to dyad CLI

## Installation

```bash
pip install dyad
```
