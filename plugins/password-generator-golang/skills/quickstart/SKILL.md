# password-generator-golang Plugin
Simple Go-based random password string generator

## Commands
- `password-generator-golang <resource> <action>` — Execute password-generator-golang commands
- `password-generator-golang _ _` — Passthrough to password-generator-golang CLI

## Usage
- `password-generator-golang _ _ <args>` — Run password-generator-golang with any arguments
