# pnmcomp Plugin

CLI tool: pnmcomp.

## Commands
- `pnmcomp <resource> <action>` — Execute pnmcomp commands
- `pnmcomp self version` — Print pnmcomp version
- `pnmcomp _ _` — Passthrough to pnmcomp CLI

## Usage Examples
- "pnmcomp --help"
- "pnmcomp self version"

## Installation
```bash
apt-get install pnmcomp 2>/dev/null || which pnmcomp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
