# zipcloak Plugin

CLI tool: zipcloak.

## Commands
- `zipcloak <resource> <action>` — Execute zipcloak commands
- `zipcloak self version` — Print zipcloak version
- `zipcloak _ _` — Passthrough to zipcloak CLI

## Usage Examples
- "zipcloak --help"
- "zipcloak self version"

## Installation
```bash
apt-get install zipcloak 2>/dev/null || which zipcloak
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
