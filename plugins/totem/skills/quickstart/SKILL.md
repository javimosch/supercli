# totem Plugin

CLI tool: totem.

## Commands
- `totem <resource> <action>` — Execute totem commands
- `totem self version` — Print totem version
- `totem _ _` — Passthrough to totem CLI

## Usage Examples
- "totem --help"
- "totem self version"

## Installation
```bash
apt-get install totem 2>/dev/null || which totem
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
