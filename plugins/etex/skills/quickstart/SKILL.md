# etex Plugin

CLI tool: etex.

## Commands
- `etex <resource> <action>` — Execute etex commands
- `etex self version` — Print etex version
- `etex _ _` — Passthrough to etex CLI

## Usage Examples
- "etex --help"
- "etex self version"

## Installation
```bash
apt-get install etex 2>/dev/null || which etex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
