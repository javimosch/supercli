# VibeOS Plugin

A completely vibecoded operating system targeting Aarch64

## Commands

### General
- `VibeOS self version` — Print VibeOS version
- `VibeOS _ _` — Passthrough to vibeos CLI

## Usage Examples
- "Run VibeOS"
- "Use vibeos to A completely vibecoded operating system targeting Aarch64"

## Installation

```bash
pip install vibeos
```

## Key Features
- A completely vibecoded operating system targeting Aarch64
- CLI tool, headless and scriptable
