# hextazy Plugin
CLI tool for hextazy.

## Commands
- `hextazy <resource> <action>` — Execute hextazy commands
- `hextazy _ _` — Passthrough to hextazy CLI

## Installation
```bash
cargo install hextazy
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
