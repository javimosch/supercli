# upmendex Plugin

CLI tool: upmendex.

## Commands
- `upmendex <resource> <action>` — Execute upmendex commands
- `upmendex self version` — Print upmendex version
- `upmendex _ _` — Passthrough to upmendex CLI

## Usage Examples
- "upmendex --help"
- "upmendex self version"

## Installation
```bash
apt-get install upmendex 2>/dev/null || which upmendex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
