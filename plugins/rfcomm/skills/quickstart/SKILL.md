# rfcomm Plugin

CLI tool: rfcomm.

## Commands
- `rfcomm <resource> <action>` — Execute rfcomm commands
- `rfcomm self version` — Print rfcomm version
- `rfcomm _ _` — Passthrough to rfcomm CLI

## Usage Examples
- "rfcomm --help"
- "rfcomm self version"

## Installation
```bash
apt-get install rfcomm 2>/dev/null || which rfcomm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
