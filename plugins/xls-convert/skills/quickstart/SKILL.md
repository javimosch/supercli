# xls-convert Plugin
Convert Excel and spreadsheet files between formats

## Commands
- `xls-convert <resource> <action>` — Execute xls-convert commands
- `xls-convert _ _` — Passthrough to xls-convert CLI

## Usage
- `xls-convert _ _ <args>` — Run xls-convert with any arguments
