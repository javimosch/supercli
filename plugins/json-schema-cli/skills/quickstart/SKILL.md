# json-schema-cli Plugin
Validate JSON files against a JSON Schema definition

## Commands
- `json-schema-cli <resource> <action>` — Execute json-schema-cli commands
- `json-schema-cli _ _` — Passthrough to json-schema-cli CLI

## Usage
- `json-schema-cli _ _ <args>` — Run json-schema-cli with any arguments
