# pycompile Plugin

CLI tool: pycompile.

## Commands
- `pycompile <resource> <action>` — Execute pycompile commands
- `pycompile self version` — Print pycompile version
- `pycompile _ _` — Passthrough to pycompile CLI

## Usage Examples
- "pycompile --help"
- "pycompile self version"

## Installation
```bash
apt-get install pycompile 2>/dev/null || which pycompile
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
