# traceproto Plugin

CLI tool: traceproto.

## Commands
- `traceproto <resource> <action>` — Execute traceproto commands
- `traceproto self version` — Print traceproto version
- `traceproto _ _` — Passthrough to traceproto CLI

## Usage Examples
- "traceproto --help"
- "traceproto self version"

## Installation
```bash
apt-get install traceproto 2>/dev/null || which traceproto
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
