# gsdj500 Plugin

CLI tool: gsdj500.

## Commands
- `gsdj500 <resource> <action>` — Execute gsdj500 commands
- `gsdj500 self version` — Print gsdj500 version
- `gsdj500 _ _` — Passthrough to gsdj500 CLI

## Usage Examples
- "gsdj500 --help"
- "gsdj500 self version"

## Installation
```bash
apt-get install gsdj500 2>/dev/null || which gsdj500
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
