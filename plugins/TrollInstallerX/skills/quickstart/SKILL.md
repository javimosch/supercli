# TrollInstallerX Plugin

A TrollStore installer for iOS 14.0 - 16.6.1

## Commands

### General
- `TrollInstallerX self version` — Print TrollInstallerX version
- `TrollInstallerX _ _` — Passthrough to trollinstallerx CLI

## Usage Examples
- "Run TrollInstallerX"
- "Use trollinstallerx to A TrollStore installer for iOS 14.0 - 16.6.1"

## Installation

```bash
pip install trollinstallerx
```

## Key Features
- A TrollStore installer for iOS 14.0 - 16.6.1
- CLI tool, headless and scriptable
