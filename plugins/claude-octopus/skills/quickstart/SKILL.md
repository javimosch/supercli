# claude-octopus Plugin

Surface AI blindspots before you ship. Put up to 8 AI models on every research, design or coding task.

## Commands

### General
- `claude-octopus self version` — Print claude-octopus version
- `claude-octopus _ _` — Passthrough to claude-octopus CLI

## Usage Examples
- "Run claude-octopus"
- "Use claude-octopus to Surface AI blindspots before you ship. Put up to 8 AI models"

## Installation

```bash
pip install claude-octopus
```

- Surface AI blindspots before you ship. Put up to 8 AI models on every research, design or coding tas
