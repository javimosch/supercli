# Quickstart

Comprehensive documentation available in the repository.

## Commands
- `sqlite3 <resource> <action>` — Execute sqlite3 commands
- `sqlite3 self version` — Print sqlite3 version
- `sqlite3 database open` — Open SQLite database
- `sqlite3 _ _` — Passthrough to sqlite3 CLI
