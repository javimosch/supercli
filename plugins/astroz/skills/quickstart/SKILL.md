# astroz Plugin

Astrodynamics and Spacecraft Toolkit. Features fast orbit prop, celestial precession, CCSDS parsing, RF parsing, fits image parsing, and more!

## Commands

### General
- `astroz self version` — Print astroz version
- `astroz _ _` — Passthrough to astroz CLI

## Usage Examples
- "Run astroz"

```bash
pip install astroz
```
