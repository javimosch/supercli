# symkeyutil Plugin

CLI tool: symkeyutil.

## Commands
- `symkeyutil <resource> <action>` — Execute symkeyutil commands
- `symkeyutil self version` — Print symkeyutil version
- `symkeyutil _ _` — Passthrough to symkeyutil CLI

## Usage Examples
- "symkeyutil --help"
- "symkeyutil self version"

## Installation
```bash
apt-get install symkeyutil 2>/dev/null || which symkeyutil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
