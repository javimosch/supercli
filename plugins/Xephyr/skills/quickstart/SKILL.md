# Xephyr Plugin

CLI tool: Xephyr.

## Commands
- `Xephyr <resource> <action>` — Execute Xephyr commands
- `Xephyr self version` — Print Xephyr version
- `Xephyr _ _` — Passthrough to Xephyr CLI

## Usage Examples
- "Xephyr --help"
- "Xephyr self version"

## Installation
```bash
apt-get install Xephyr 2>/dev/null || which Xephyr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
