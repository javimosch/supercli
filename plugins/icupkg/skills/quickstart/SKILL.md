# icupkg Plugin

CLI tool: icupkg.

## Commands
- `icupkg <resource> <action>` — Execute icupkg commands
- `icupkg self version` — Print icupkg version
- `icupkg _ _` — Passthrough to icupkg CLI

## Usage Examples
- "icupkg --help"
- "icupkg self version"

## Installation
```bash
apt-get install icupkg 2>/dev/null || which icupkg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
