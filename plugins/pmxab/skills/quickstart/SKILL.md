# pmxab Plugin

CLI tool: pmxab.

## Commands
- `pmxab <resource> <action>` — Execute pmxab commands
- `pmxab self version` — Print pmxab version
- `pmxab _ _` — Passthrough to pmxab CLI

## Usage Examples
- "pmxab --help"
- "pmxab self version"

## Installation
```bash
apt-get install pmxab 2>/dev/null || which pmxab
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
