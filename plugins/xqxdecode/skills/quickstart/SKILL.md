# xqxdecode Plugin

CLI tool: xqxdecode.

## Commands
- `xqxdecode <resource> <action>` — Execute xqxdecode commands
- `xqxdecode self version` — Print xqxdecode version
- `xqxdecode _ _` — Passthrough to xqxdecode CLI

## Usage Examples
- "xqxdecode --help"
- "xqxdecode self version"

## Installation
```bash
apt-get install xqxdecode 2>/dev/null || which xqxdecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
