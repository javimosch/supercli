# focus Plugin

CLI tool: focus.

## Commands
- `focus <resource> <action>` — Execute focus commands
- `focus self version` — Print focus version
- `focus _ _` — Passthrough to focus CLI

## Usage Examples
- "focus --help"
- "focus self version"

## Installation
```bash
apt-get install focus 2>/dev/null || which focus
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
