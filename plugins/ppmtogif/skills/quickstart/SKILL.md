# ppmtogif Plugin

CLI tool: ppmtogif.

## Commands
- `ppmtogif <resource> <action>` — Execute ppmtogif commands
- `ppmtogif self version` — Print ppmtogif version
- `ppmtogif _ _` — Passthrough to ppmtogif CLI

## Usage Examples
- "ppmtogif --help"
- "ppmtogif self version"

```bash
apt-get install ppmtogif 2>/dev/null || which ppmtogif
```
