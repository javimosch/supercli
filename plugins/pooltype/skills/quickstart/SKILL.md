# pooltype Plugin

CLI tool: pooltype.

## Commands
- `pooltype <resource> <action>` — Execute pooltype commands
- `pooltype self version` — Print pooltype version
- `pooltype _ _` — Passthrough to pooltype CLI

## Usage Examples
- "pooltype --help"
- "pooltype self version"

apt-get install pooltype 2>/dev/null || which pooltype
