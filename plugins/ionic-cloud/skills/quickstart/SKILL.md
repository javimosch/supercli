# ionic-cloud Plugin

CLI tool: ionic-cloud.

## Commands
- `ionic-cloud <resource> <action>` — Execute ionic-cloud commands
- `ionic-cloud self version` — Print ionic-cloud version
- `ionic-cloud _ _` — Passthrough to ionic-cloud CLI

## Usage Examples
- "ionic-cloud --help"
- "ionic-cloud self version"

## Installation
```bash
apt-get install ionic-cloud 2>/dev/null || which ionic-cloud
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
