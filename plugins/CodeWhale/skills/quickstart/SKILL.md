# CodeWhale Plugin

DeepSeek + MiMo coding agent in terminal

## Commands

### General
- `CodeWhale self version` — Print CodeWhale version
- `CodeWhale _ _` — Passthrough to codewhale CLI

## Usage Examples
- "Run CodeWhale"
- "Use codewhale to DeepSeek + MiMo coding agent in terminal"

## Installation

```bash
pip install codewhale
```

## Key Features
- DeepSeek + MiMo coding agent in terminal
- CLI tool, headless and scriptable
