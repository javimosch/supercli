# lpc Plugin

CLI tool: lpc.

## Commands
- `lpc <resource> <action>` — Execute lpc commands
- `lpc self version` — Print lpc version
- `lpc _ _` — Passthrough to lpc CLI

## Usage Examples
- "lpc --help"
- "lpc self version"

## Installation
```bash
apt-get install lpc 2>/dev/null || which lpc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
