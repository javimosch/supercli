# pre-commit-hooks Plugin
Collection of pre-commit hooks for various tools

## Commands
- `pre-commit-hooks <resource> <action>` — Execute pre-commit-hooks commands
- `pre-commit-hooks _ _` — Passthrough to pre-commit-hooks CLI

## Usage
- `pre-commit-hooks _ _ <args>` — Run pre-commit-hooks with any arguments
