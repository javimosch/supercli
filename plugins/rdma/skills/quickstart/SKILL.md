# rdma Plugin

CLI tool: rdma.

## Commands
- `rdma <resource> <action>` — Execute rdma commands
- `rdma self version` — Print rdma version
- `rdma _ _` — Passthrough to rdma CLI

## Usage Examples
- "rdma --help"
- "rdma self version"

## Installation
```bash
apt-get install rdma 2>/dev/null || which rdma
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
