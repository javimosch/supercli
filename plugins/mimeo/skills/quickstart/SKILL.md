# Mimeo — Expert to SKILL.md Converter

Mimeograph an expert into a SKILL.md or AGENTS.md. Convert structured or unstructured expertise into reusable, composable skill files for AI agents.

## Installation
```bash
git clone https://github.com/K-Dense-AI/mimeo.git
sc skills teach mimeo:quickstart
```

## What It Does
- Takes expert knowledge (interviews, docs, conversations)
- Produces structured SKILL.md or AGENTS.md files
- Compatible with Claude Code, Codex, Cursor, and all SKILL.md runtimes
- Makes domain expertise reusable by AI agents

## Usage Prompts
- "Convert this documentation into a SKILL.md for my AI agent"
- "Create an AGENTS.md file capturing our deployment best practices"
- "Mimeograph my expertise on Kubernetes networking into a skill file"
