# sane-find-scanner Plugin

CLI tool: sane-find-scanner.

## Commands
- `sane-find-scanner <resource> <action>` — Execute sane-find-scanner commands
- `sane-find-scanner self version` — Print sane-find-scanner version
- `sane-find-scanner _ _` — Passthrough to sane-find-scanner CLI

- "sane-find-scanner self version"
