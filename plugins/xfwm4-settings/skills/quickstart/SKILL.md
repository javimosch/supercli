# xfwm4-settings Plugin

xfwm4-settings — window manager of the Xfce project.

## Commands
- `xfwm4-settings <resource> <action>` — Execute xfwm4-settings commands
- `xfwm4-settings self version` — Print xfwm4-settings version
- `xfwm4-settings _ _` — Passthrough to xfwm4-settings CLI

## Usage Examples
- "xfwm4-settings --help"
- "xfwm4-settings self version"

## Installation
```bash
apt-get install xfwm4 2>/dev/null || which xfwm4-settings
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
