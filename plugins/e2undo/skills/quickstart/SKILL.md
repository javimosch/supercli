# e2undo Plugin

CLI tool: e2undo.

## Commands
- `e2undo <resource> <action>` — Execute e2undo commands
- `e2undo self version` — Print e2undo version
- `e2undo _ _` — Passthrough to e2undo CLI

## Usage Examples
- "e2undo --help"
- "e2undo self version"

## Installation
```bash
apt-get install e2undo 2>/dev/null || which e2undo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
