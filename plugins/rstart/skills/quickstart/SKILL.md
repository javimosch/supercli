# rstart Plugin

CLI tool: rstart.

## Commands
- `rstart <resource> <action>` — Execute rstart commands
- `rstart self version` — Print rstart version
- `rstart _ _` — Passthrough to rstart CLI

## Usage Examples
- "rstart --help"
- "rstart self version"

## Installation
```bash
apt-get install rstart 2>/dev/null || which rstart
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
