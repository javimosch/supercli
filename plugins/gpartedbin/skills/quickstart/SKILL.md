# gpartedbin Plugin

CLI tool: gpartedbin.

## Commands
- `gpartedbin <resource> <action>` — Execute gpartedbin commands
- `gpartedbin self version` — Print gpartedbin version
- `gpartedbin _ _` — Passthrough to gpartedbin CLI

## Usage Examples
- "gpartedbin --help"
- "gpartedbin self version"

## Installation
```bash
apt-get install gpartedbin 2>/dev/null || which gpartedbin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
