# jarsigner Plugin

CLI tool: jarsigner.

## Commands
- `jarsigner <resource> <action>` — Execute jarsigner commands
- `jarsigner self version` — Print jarsigner version
- `jarsigner _ _` — Passthrough to jarsigner CLI

## Usage Examples
- "jarsigner --help"
- "jarsigner self version"

## Installation
```bash
apt-get install jarsigner 2>/dev/null || which jarsigner
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
