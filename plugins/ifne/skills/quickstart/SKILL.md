# ifne Plugin

CLI tool: ifne.

## Commands
- `ifne <resource> <action>` — Execute ifne commands
- `ifne self version` — Print ifne version
- `ifne _ _` — Passthrough to ifne CLI

## Usage Examples
- "ifne --help"
- "ifne self version"

## Installation
```bash
apt-get install ifne 2>/dev/null || which ifne
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
