# soft-serve Plugin
Self-hosted Git server for the command line

## Commands
- `soft-serve <resource> <action>` — Execute soft-serve commands
- `soft-serve _ _` — Passthrough to soft-serve CLI

## Usage
- `soft-serve _ _ <args>` — Run soft-serve with any arguments
