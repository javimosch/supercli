# rolldown Plugin

Fast Rust bundler for JavaScript/TypeScript with Rollup-compatible API.

## Commands
- `rolldown <resource> <action>` — Execute rolldown commands
- `rolldown self version` — Print rolldown version
- `rolldown _ _` — Passthrough to rolldown CLI

## Installation

```bash
pip install rolldown
```
