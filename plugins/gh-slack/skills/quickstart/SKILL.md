# gh-slack Plugin
Structured JSON Slack agent for AI tool integration

## Commands
- `gh-slack <resource> <action>` — Execute gh-slack commands
- `gh-slack _ _` — Passthrough to gh-slack CLI

## Usage
- `gh-slack _ _ <args>` — Run gh-slack with any arguments
