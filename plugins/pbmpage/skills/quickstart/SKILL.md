# pbmpage Plugin

CLI tool: pbmpage.

## Commands
- `pbmpage <resource> <action>` — Execute pbmpage commands
- `pbmpage self version` — Print pbmpage version
- `pbmpage _ _` — Passthrough to pbmpage CLI

## Usage Examples
- "pbmpage --help"
- "pbmpage self version"

## Installation
```bash
apt-get install pbmpage 2>/dev/null || which pbmpage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
