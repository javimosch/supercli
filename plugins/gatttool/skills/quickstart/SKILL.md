# gatttool Plugin

CLI tool: gatttool.

## Commands
- `gatttool <resource> <action>` — Execute gatttool commands
- `gatttool self version` — Print gatttool version
- `gatttool _ _` — Passthrough to gatttool CLI

## Usage Examples
- "gatttool --help"
- "gatttool self version"

## Installation
```bash
apt-get install gatttool 2>/dev/null || which gatttool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
