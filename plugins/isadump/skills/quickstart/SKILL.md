# isadump Plugin

CLI tool: isadump.

## Commands
- `isadump <resource> <action>` — Execute isadump commands
- `isadump self version` — Print isadump version
- `isadump _ _` — Passthrough to isadump CLI

## Usage Examples
- "isadump --help"
- "isadump self version"

## Installation
```bash
apt-get install isadump 2>/dev/null || which isadump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
