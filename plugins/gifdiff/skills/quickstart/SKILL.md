# gifdiff Plugin

CLI tool: gifdiff.

## Commands
- `gifdiff <resource> <action>` — Execute gifdiff commands
- `gifdiff self version` — Print gifdiff version
- `gifdiff _ _` — Passthrough to gifdiff CLI

## Usage Examples
- "gifdiff --help"
- "gifdiff self version"

## Installation
```bash
apt-get install gifdiff 2>/dev/null || which gifdiff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
