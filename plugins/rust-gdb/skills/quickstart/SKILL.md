# rust-gdb Plugin

CLI tool: rust-gdb.

## Commands
- `rust-gdb <resource> <action>` — Execute rust-gdb commands
- `rust-gdb self version` — Print rust-gdb version
- `rust-gdb _ _` — Passthrough to rust-gdb CLI

## Usage Examples
- "rust-gdb --help"
- "rust-gdb self version"

## Installation
```bash
cargo install rust-gdb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- rust based
