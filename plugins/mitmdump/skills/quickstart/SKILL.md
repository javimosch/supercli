# mitmdump Plugin

CLI tool: mitmdump.

## Commands
- `mitmdump <resource> <action>` — Execute mitmdump commands
- `mitmdump self version` — Print mitmdump version
- `mitmdump _ _` — Passthrough to mitmdump CLI

## Usage Examples
- "mitmdump --help"
- "mitmdump self version"

## Installation
```bash
apt-get install mitmdump 2>/dev/null || which mitmdump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
