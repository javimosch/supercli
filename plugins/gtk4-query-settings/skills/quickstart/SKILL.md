# gtk4-query-settings Plugin

CLI tool: gtk4-query-settings.

## Commands
- `gtk4-query-settings <resource> <action>` — Execute gtk4-query-settings commands
- `gtk4-query-settings self version` — Print gtk4-query-settings version
- `gtk4-query-settings _ _` — Passthrough to gtk4-query-settings CLI

## Usage Examples
- "gtk4-query-settings --help"
- "gtk4-query-settings self version"

## Installation
```bash
apt-get install gtk4-query-settings 2>/dev/null || which gtk4-query-settings
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
