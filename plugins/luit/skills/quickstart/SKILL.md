# luit Plugin

CLI tool: luit.

## Commands
- `luit <resource> <action>` — Execute luit commands
- `luit self version` — Print luit version
- `luit _ _` — Passthrough to luit CLI

## Usage Examples
- "luit --help"
- "luit self version"

## Installation
```bash
apt-get install luit 2>/dev/null || which luit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
