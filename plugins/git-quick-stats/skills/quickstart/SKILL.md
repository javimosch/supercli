# git-quick-stats Plugin
Quick statistics for git repositories. Shows commit stats, contributor activity, changelogs, and more.
## Commands
- `git self version` — Print version
- `git _ _` — Passthrough to git-quick-stats
## Installation
```bash
brew install git-quick-stats
```
