# clibrowser Plugin

Zero-dependency CLI browser for AI agents — single Rust binary, 23 commands, JSON output

## Commands
- `clibrowser self version` — Print clibrowser version
- `clibrowser _ _` — Passthrough to clibrowser CLI

## Usage Examples
- `clibrowser self version` — Check installed version
- `clibrowser _ _ --help` — Show clibrowser help
- `clibrowser _ _ --json` — JSON output mode

## Installation
```bash
cargo install clibrowser
```

## Key Features
- browser, ai-agents, rust, web
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
