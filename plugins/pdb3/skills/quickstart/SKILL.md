# pdb3 Plugin

CLI tool: pdb3.

## Commands
- `pdb3 <resource> <action>` — Execute pdb3 commands
- `pdb3 self version` — Print pdb3 version
- `pdb3 _ _` — Passthrough to pdb3 CLI

## Usage Examples
- "pdb3 --help"
- "pdb3 self version"

## Installation
```bash
apt-get install pdb3 2>/dev/null || which pdb3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
