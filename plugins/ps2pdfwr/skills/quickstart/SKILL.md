# ps2pdfwr Plugin

CLI tool: ps2pdfwr.

## Commands
- `ps2pdfwr <resource> <action>` — Execute ps2pdfwr commands
- `ps2pdfwr self version` — Print ps2pdfwr version
- `ps2pdfwr _ _` — Passthrough to ps2pdfwr CLI

## Usage Examples
- "ps2pdfwr --help"
- "ps2pdfwr self version"

## Installation
```bash
apt-get install ps2pdfwr 2>/dev/null || which ps2pdfwr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
