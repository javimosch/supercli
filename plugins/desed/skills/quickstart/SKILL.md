# desed Plugin
Debugger for sed scripts with step-by-step execution and visualization

## Commands
- `desed <resource> <action>` — Execute desed commands
- `desed _ _` — Passthrough to desed CLI

## Usage
- `desed _ _ <args>` — Run desed with any arguments
