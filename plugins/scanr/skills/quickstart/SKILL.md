# scanr Plugin
CLI tool for scanr.

## Commands
- `scanr <resource> <action>` — Execute scanr commands
- `scanr _ _` — Passthrough to scanr CLI

## Installation
```bash
cargo install scanr
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
