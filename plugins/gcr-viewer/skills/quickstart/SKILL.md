# gcr-viewer Plugin

CLI tool: gcr-viewer.

## Commands
- `gcr-viewer <resource> <action>` — Execute gcr-viewer commands
- `gcr-viewer self version` — Print gcr-viewer version
- `gcr-viewer _ _` — Passthrough to gcr-viewer CLI

## Usage Examples
- "gcr-viewer --help"
- "gcr-viewer self version"

## Installation
```bash
apt-get install gcr-viewer 2>/dev/null || which gcr-viewer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
