# zev Plugin

Remember terminal commands via natural language. Ask 'how do I...' and get the right command. Brew/pipx install, no auth, pipeline-ready.

## Commands
- `zev self version` — Print version
- `zev _ _ <args>` — Passthrough to zev

## Usage Examples
- "Command Memory CLI"

## Installation
```bash
pipx install zev
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
