# harper Plugin

Offline, privacy-first grammar checker. Fast, open-source, Rust-powered

## Commands
- `harper <resource> <action>` — Execute harper commands
- `harper self version` — Print harper version
- `harper _ _` — Passthrough to harper CLI

## Installation

```bash
pip install harper
```
