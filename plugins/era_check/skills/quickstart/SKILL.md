# era_check Plugin

CLI tool: era_check.

## Commands
- `era_check <resource> <action>` — Execute era_check commands
- `era_check self version` — Print era_check version
- `era_check _ _` — Passthrough to era_check CLI

## Usage Examples
- "era_check --help"
- "era_check self version"

## Installation
```bash
apt-get install era_check 2>/dev/null || which era_check
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
