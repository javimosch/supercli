# Go-Interview-Practice Plugin

Interactive Go interview platform with 30+ coding challenges and AI simulation

## Commands
- `go-interview-practice _ _` — Passthrough to go-interview-practice CLI

## Installation

```bash
go install github.com/RezaSi/go-interview-practice@latest
```

## Examples
```bash
go-interview-practice --help
go-interview-practice --version
```
