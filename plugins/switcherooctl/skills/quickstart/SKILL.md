# switcherooctl Plugin

CLI tool: switcherooctl.

## Commands
- `switcherooctl <resource> <action>` — Execute switcherooctl commands
- `switcherooctl self version` — Print switcherooctl version
- `switcherooctl _ _` — Passthrough to switcherooctl CLI

## Usage Examples
- "switcherooctl --help"
- "switcherooctl self version"

## Installation
```bash
apt-get install switcherooctl 2>/dev/null || which switcherooctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
