# gtstemplate Plugin

CLI tool: gtstemplate.

## Commands
- `gtstemplate <resource> <action>` — Execute gtstemplate commands
- `gtstemplate self version` — Print gtstemplate version
- `gtstemplate _ _` — Passthrough to gtstemplate CLI

## Usage Examples
- "gtstemplate --help"
- "gtstemplate self version"

## Installation
```bash
apt-get install gtstemplate 2>/dev/null || which gtstemplate
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
