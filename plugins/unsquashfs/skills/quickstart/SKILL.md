# unsquashfs Plugin

CLI tool: unsquashfs.

## Commands
- `unsquashfs <resource> <action>` — Execute unsquashfs commands
- `unsquashfs self version` — Print unsquashfs version
- `unsquashfs _ _` — Passthrough to unsquashfs CLI

## Usage Examples
- "unsquashfs --help"
- "unsquashfs self version"

## Installation
```bash
apt-get install unsquashfs 2>/dev/null || which unsquashfs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
