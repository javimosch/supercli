# xtool Plugin

Cross-platform Xcode replacement. Build and deploy iOS apps with SwiftPM on Linux, Windows, macOS.

## Commands

### General
- `xtool self version` — Print xtool version
- `xtool _ _` — Passthrough to xtool CLI

## Usage Examples
- "Run xtool"
- "Use xtool to Cross-platform Xcode replacement. Build and deploy iOS apps "

## Installation

```bash
pip install xtool
```

## Key Features
- Cross-platform Xcode replacement. Build and deploy iOS apps with SwiftPM on Linux, Windows, macOS.
- CLI tool, headless and scriptable
