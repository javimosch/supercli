# spellcaster Plugin
AI-powered grammar and spelling checker for documents

## Commands
- `spellcaster <resource> <action>` — Execute spellcaster commands
- `spellcaster _ _` — Passthrough to spellcaster CLI

## Usage
- `spellcaster _ _ <args>` — Run spellcaster with any arguments
