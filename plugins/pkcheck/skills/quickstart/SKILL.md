# pkcheck Plugin

CLI tool: pkcheck.

## Commands
- `pkcheck <resource> <action>` — Execute pkcheck commands
- `pkcheck self version` — Print pkcheck version
- `pkcheck _ _` — Passthrough to pkcheck CLI

## Usage Examples
- "pkcheck --help"
- "pkcheck self version"

## Installation
```bash
apt-get install pkcheck 2>/dev/null || which pkcheck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
