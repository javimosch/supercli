# xml2pmx Plugin

CLI tool: xml2pmx.

## Commands
- `xml2pmx <resource> <action>` — Execute xml2pmx commands
- `xml2pmx self version` — Print xml2pmx version
- `xml2pmx _ _` — Passthrough to xml2pmx CLI

## Usage Examples
- "xml2pmx --help"
- "xml2pmx self version"

## Installation
```bash
apt-get install xml2pmx 2>/dev/null || which xml2pmx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
