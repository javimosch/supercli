# go-tictactoe Plugin
Simple terminal tic-tac-toe game in Go

## Commands
- `go-tictactoe <resource> <action>` — Execute go-tictactoe commands
- `go-tictactoe _ _` — Passthrough to go-tictactoe CLI

## Usage
- `go-tictactoe _ _ <args>` — Run go-tictactoe with any arguments
