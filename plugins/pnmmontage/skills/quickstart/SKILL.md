# pnmmontage Plugin

CLI tool: pnmmontage.

## Commands
- `pnmmontage <resource> <action>` — Execute pnmmontage commands
- `pnmmontage self version` — Print pnmmontage version
- `pnmmontage _ _` — Passthrough to pnmmontage CLI

## Usage Examples
- "pnmmontage --help"
- "pnmmontage self version"

## Installation
```bash
apt-get install pnmmontage 2>/dev/null || which pnmmontage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
