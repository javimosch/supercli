# lkbib Plugin

CLI tool: lkbib.

## Commands
- `lkbib <resource> <action>` — Execute lkbib commands
- `lkbib self version` — Print lkbib version
- `lkbib _ _` — Passthrough to lkbib CLI

## Usage Examples
- "lkbib --help"
- "lkbib self version"

## Installation
```bash
apt-get install lkbib 2>/dev/null || which lkbib
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
