# invgeod Plugin

CLI tool: invgeod.

## Commands
- `invgeod <resource> <action>` — Execute invgeod commands
- `invgeod self version` — Print invgeod version
- `invgeod _ _` — Passthrough to invgeod CLI

## Usage Examples
- "invgeod --help"
- "invgeod self version"

## Installation
```bash
apt-get install invgeod 2>/dev/null || which invgeod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
