# slides
slides — terminal-based presentation tool. Create and present markdown slideshows in the terminal. Non-interactive rendering.

## Commands
- `slides <resource> <action>` — Execute slides commands
- `slides self version` — Print slides version
- `slides _ _` — Passthrough to slides CLI
