# pgmkernel Plugin

CLI tool: pgmkernel.

## Commands
- `pgmkernel <resource> <action>` — Execute pgmkernel commands
- `pgmkernel self version` — Print pgmkernel version
- `pgmkernel _ _` — Passthrough to pgmkernel CLI

## Usage Examples
- "pgmkernel --help"
- "pgmkernel self version"

## Installation
```bash
apt-get install pgmkernel 2>/dev/null || which pgmkernel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
