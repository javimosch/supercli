# Quarto

Open-source scientific and technical publishing system built on Pandoc.

## Features

- Author documents using Markdown
- Embed code and output from Python, R, Julia, and JavaScript
- Create websites, books, and presentations
- Cross-references, sub-figures, layout panels
- Hoverable citations and footnotes

## Usage

```bash
# Render a document
quarto render document.qmd

# Preview with live reload
quarto preview document.qmd

# Create a new project
quarto create project website mysite

# Convert document format
quarto convert document.ipynb
```
