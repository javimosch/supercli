# whereis Plugin
Locate binary/source/man pages

## Commands
- `whereis <resource> <action>` — Execute whereis commands
- `whereis self version` — Print whereis version
- `whereis _ _` — Passthrough to whereis CLI

## Usage
- `whereis _ _ <args>` — Run whereis with any arguments
