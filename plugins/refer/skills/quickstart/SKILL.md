# refer Plugin

CLI tool: refer.

## Commands
- `refer <resource> <action>` — Execute refer commands
- `refer self version` — Print refer version
- `refer _ _` — Passthrough to refer CLI

## Usage Examples
- "refer --help"
- "refer self version"

## Installation
```bash
apt-get install refer 2>/dev/null || which refer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
