# rsaperf Plugin

CLI tool: rsaperf.

## Commands
- `rsaperf <resource> <action>` — Execute rsaperf commands
- `rsaperf self version` — Print rsaperf version
- `rsaperf _ _` — Passthrough to rsaperf CLI

## Usage Examples
- "rsaperf --help"
- "rsaperf self version"

## Installation
```bash
apt-get install rsaperf 2>/dev/null || which rsaperf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
