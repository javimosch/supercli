# tabulate Plugin

CLI tool: tabulate.

## Commands
- `tabulate <resource> <action>` — Execute tabulate commands
- `tabulate self version` — Print tabulate version
- `tabulate _ _` — Passthrough to tabulate CLI

## Usage Examples
- "tabulate --help"
- "tabulate self version"

## Installation
```bash
apt-get install tabulate 2>/dev/null || which tabulate
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
