# unzipsfx Plugin

CLI tool: unzipsfx.

## Commands
- `unzipsfx <resource> <action>` — Execute unzipsfx commands
- `unzipsfx self version` — Print unzipsfx version
- `unzipsfx _ _` — Passthrough to unzipsfx CLI

## Usage Examples
- "unzipsfx --help"
- "unzipsfx self version"

## Installation
```bash
apt-get install unzipsfx 2>/dev/null || which unzipsfx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
