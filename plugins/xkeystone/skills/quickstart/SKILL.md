# xkeystone Plugin

CLI tool: xkeystone.

## Commands
- `xkeystone <resource> <action>` — Execute xkeystone commands
- `xkeystone self version` — Print xkeystone version
- `xkeystone _ _` — Passthrough to xkeystone CLI

## Usage Examples
- "xkeystone --help"
- "xkeystone self version"

## Installation
```bash
apt-get install xkeystone 2>/dev/null || which xkeystone
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
