# pvck Plugin

CLI tool: pvck.

## Commands
- `pvck <resource> <action>` — Execute pvck commands
- `pvck self version` — Print pvck version
- `pvck _ _` — Passthrough to pvck CLI

## Usage Examples
- "pvck --help"
- "pvck self version"

## Installation
```bash
apt-get install pvck 2>/dev/null || which pvck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
