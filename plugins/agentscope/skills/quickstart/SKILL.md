# agentscope Plugin

Build and run agents you can see, understand and trust.

## Commands
- `agentscope <resource> <action>` — Execute agentscope commands
- `agentscope self version` — Print agentscope version
- `agentscope _ _` — Passthrough to agentscope CLI

## Installation

```bash
pip install agentscope
```
