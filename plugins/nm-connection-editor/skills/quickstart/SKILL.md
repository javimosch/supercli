# nm-connection-editor Plugin

CLI tool: nm-connection-editor.

## Commands
- `nm-connection-editor <resource> <action>` — Execute nm-connection-editor commands
- `nm-connection-editor self version` — Print nm-connection-editor version
- `nm-connection-editor _ _` — Passthrough to nm-connection-editor CLI

## Usage Examples
- "nm-connection-editor --help"
- "nm-connection-editor self version"

## Installation
```bash
apt-get install nm-connection-editor 2>/dev/null || which nm-connection-editor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
