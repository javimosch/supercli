# StikDebug Plugin

An on-device debugger/JIT enabler for iOS versions 17.4+, powered by idevice.

## Commands

### General
- `StikDebug self version` — Print StikDebug version
- `StikDebug _ _` — Passthrough to stikdebug CLI
