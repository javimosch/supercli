# zli Plugin
High-performance Zig CLI framework.
## Commands
- `zli _ _` — Passthrough to zli CLI
## Installation
```bash
git clone https://github.com/xcaeser/zli && cd zli && zig build
```
## Key Features
- **Cobra-like** — Familiar API
- **Zero-cost** — No runtime overhead
- **Fast** — Zig performance
