# zli Plugin

Build ergonomic CLI tools in Zig

## Commands

### Version
`zli self version` — Print zli version

### Passthrough
`zli _ _` — Passthrough to zli CLI with all arguments forwarded.

## Usage Examples

```bash
zli --version
zli --help
```

## Installation

```bash
cargo install zli
```

## Key Features
- Build ergonomic CLI tools in Zig
