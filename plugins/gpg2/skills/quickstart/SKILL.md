# gpg2 Plugin

CLI tool: gpg2.

## Commands
- `gpg2 <resource> <action>` — Execute gpg2 commands
- `gpg2 self version` — Print gpg2 version
- `gpg2 _ _` — Passthrough to gpg2 CLI

## Usage Examples
- "gpg2 --help"
- "gpg2 self version"

## Installation
```bash
apt-get install gpg2 2>/dev/null || which gpg2
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
