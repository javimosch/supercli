# nanobot Plugin

Lightweight, open-source AI agent for your tools, chats, and workflows.

## Commands
- `nanobot <resource> <action>` — Execute nanobot commands
- `nanobot self version` — Print nanobot version
- `nanobot _ _` — Passthrough to nanobot CLI

## Installation

```bash
pip install nanobot
```
