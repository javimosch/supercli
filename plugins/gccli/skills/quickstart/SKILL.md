# gccli Plugin
Garmin Connect CLI with JSON export.
## Commands
- `gccli _ _` — Passthrough to gccli CLI
## Installation
```bash
pipx install gccli
```
## Key Features
- **Garmin access** — Download fitness data
- **JSON export** — Structured data output
- **Pipeline-ready** — Automation support
