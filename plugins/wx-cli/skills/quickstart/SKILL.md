# Wx-Cli Plugin

WeChat local data CLI with daemon architecture

## Commands
- `wx-cli _ _` — Passthrough to wx-cli CLI

## Installation

```bash
cargo install wx-cli
```

## Examples
```bash
wx-cli --help
wx-cli --version
```
