# gjs Plugin

CLI tool: gjs.

## Commands
- `gjs <resource> <action>` — Execute gjs commands
- `gjs self version` — Print gjs version
- `gjs _ _` — Passthrough to gjs CLI

## Usage Examples
- "gjs --help"
- "gjs self version"

## Installation
```bash
apt-get install gjs 2>/dev/null || which gjs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
