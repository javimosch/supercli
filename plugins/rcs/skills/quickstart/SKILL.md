# rcs Plugin

CLI tool: rcs.

## Commands
- `rcs <resource> <action>` — Execute rcs commands
- `rcs self version` — Print rcs version
- `rcs _ _` — Passthrough to rcs CLI

## Usage Examples
- "rcs --help"
- "rcs self version"

## Installation
```bash
apt-get install rcs 2>/dev/null || which rcs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
