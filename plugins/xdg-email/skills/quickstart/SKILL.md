# xdg-email Plugin

xdg-email — desktop integration utilities from freedesktop.org.

## Commands
- `xdg-email <resource> <action>` — Execute xdg-email commands
- `xdg-email self version` — Print xdg-email version
- `xdg-email _ _` — Passthrough to xdg-email CLI

## Usage Examples
- "xdg-email --help"
- "xdg-email self version"

## Installation
```bash
apt-get install xdg-utils 2>/dev/null || which xdg-email
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
