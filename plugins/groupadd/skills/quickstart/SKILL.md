# groupadd Plugin

CLI tool: groupadd.

## Commands
- `groupadd <resource> <action>` — Execute groupadd commands
- `groupadd self version` — Print groupadd version
- `groupadd _ _` — Passthrough to groupadd CLI

## Usage Examples
- "groupadd --help"
- "groupadd self version"

## Installation
```bash
apt-get install groupadd 2>/dev/null || which groupadd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
