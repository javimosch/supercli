# files-to-prompt Plugin
Concatenate files into a single prompt

## Commands
- `files-to-prompt <resource> <action>` — Execute files-to-prompt commands
- `files-to-prompt _ _` — Passthrough to files-to-prompt CLI

## Usage
- `files-to-prompt _ _ <args>` — Run files-to-prompt with any arguments
