# hp-setup Plugin

CLI tool: hp-setup.

## Commands
- `hp-setup <resource> <action>` — Execute hp-setup commands
- `hp-setup self version` — Print hp-setup version
- `hp-setup _ _` — Passthrough to hp-setup CLI

## Usage Examples
- "hp-setup --help"
- "hp-setup self version"

## Installation
```bash
apt-get install hp-setup 2>/dev/null || which hp-setup
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
