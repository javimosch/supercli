# spa-inspect Plugin

CLI tool: spa-inspect.

## Commands
- `spa-inspect <resource> <action>` — Execute spa-inspect commands
- `spa-inspect self version` — Print spa-inspect version
- `spa-inspect _ _` — Passthrough to spa-inspect CLI

## Usage Examples
- "spa-inspect --help"
- "spa-inspect self version"

## Installation
```bash
apt-get install spa-inspect 2>/dev/null || which spa-inspect
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
