# pipenv-graph Plugin
Visualize pipenv dependency graphs

## Commands
- `pipenv-graph <resource> <action>` — Execute pipenv-graph commands
- `pipenv-graph _ _` — Passthrough to pipenv-graph CLI

## Usage
- `pipenv-graph _ _ <args>` — Run pipenv-graph with any arguments
