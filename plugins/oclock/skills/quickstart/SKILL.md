# oclock Plugin

CLI tool: oclock.

## Commands
- `oclock <resource> <action>` — Execute oclock commands
- `oclock self version` — Print oclock version
- `oclock _ _` — Passthrough to oclock CLI

## Usage Examples
- "oclock --help"
- "oclock self version"

## Installation
```bash
apt-get install oclock 2>/dev/null || which oclock
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
