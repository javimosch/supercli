# write.ul Plugin

CLI tool: write.ul.

## Commands
- `write.ul <resource> <action>` — Execute write.ul commands
- `write.ul self version` — Print write.ul version
- `write.ul _ _` — Passthrough to write.ul CLI

## Usage Examples
- "write.ul --help"
- "write.ul self version"

## Installation
```bash
apt-get install write.ul 2>/dev/null || which write.ul
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
