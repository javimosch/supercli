# ppmdither Plugin

CLI tool: ppmdither.

## Commands
- `ppmdither <resource> <action>` — Execute ppmdither commands
- `ppmdither self version` — Print ppmdither version
- `ppmdither _ _` — Passthrough to ppmdither CLI

## Usage Examples
- "ppmdither --help"
- "ppmdither self version"

## Installation
```bash
apt-get install ppmdither 2>/dev/null || which ppmdither
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
