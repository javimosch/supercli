# grdctl Plugin

CLI tool: grdctl.

## Commands
- `grdctl <resource> <action>` — Execute grdctl commands
- `grdctl self version` — Print grdctl version
- `grdctl _ _` — Passthrough to grdctl CLI

## Usage Examples
- "grdctl --help"
- "grdctl self version"

## Installation
```bash
apt-get install grdctl 2>/dev/null || which grdctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
