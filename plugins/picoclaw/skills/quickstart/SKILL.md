# picoclaw Plugin

Tiny, Fast, and Deployable anywhere — automate the mundane, unleash your creativity

## Commands
- `picoclaw <resource> <action>` — Execute picoclaw commands
- `picoclaw self version` — Print picoclaw version
- `picoclaw _ _` — Passthrough to picoclaw CLI

## Installation

```bash
pip install picoclaw
```
