# gnome-session-quit Plugin

CLI tool: gnome-session-quit.

## Commands
- `gnome-session-quit <resource> <action>` — Execute gnome-session-quit commands
- `gnome-session-quit self version` — Print gnome-session-quit version
- `gnome-session-quit _ _` — Passthrough to gnome-session-quit CLI

## Usage Examples
- "gnome-session-quit --help"
- "gnome-session-quit self version"

## Installation
```bash
apt-get install gnome-session-quit 2>/dev/null || which gnome-session-quit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
