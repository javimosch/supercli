# lzfgrep Plugin

CLI tool: lzfgrep.

## Commands
- `lzfgrep <resource> <action>` — Execute lzfgrep commands
- `lzfgrep self version` — Print lzfgrep version
- `lzfgrep _ _` — Passthrough to lzfgrep CLI

## Usage Examples
- "lzfgrep --help"
- "lzfgrep self version"

## Installation
```bash
apt-get install lzfgrep 2>/dev/null || which lzfgrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
