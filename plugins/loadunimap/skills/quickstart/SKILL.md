# loadunimap Plugin

CLI tool: loadunimap.

## Commands
- `loadunimap <resource> <action>` — Execute loadunimap commands
- `loadunimap self version` — Print loadunimap version
- `loadunimap _ _` — Passthrough to loadunimap CLI

## Usage Examples
- "loadunimap --help"
- "loadunimap self version"

## Installation
```bash
apt-get install loadunimap 2>/dev/null || which loadunimap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
