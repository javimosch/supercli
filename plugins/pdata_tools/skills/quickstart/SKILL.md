# pdata_tools Plugin

CLI tool: pdata_tools.

## Commands
- `pdata_tools <resource> <action>` — Execute pdata_tools commands
- `pdata_tools self version` — Print pdata_tools version
- `pdata_tools _ _` — Passthrough to pdata_tools CLI

## Usage Examples
- "pdata_tools --help"
- "pdata_tools self version"

## Installation
```bash
apt-get install pdata_tools 2>/dev/null || which pdata_tools
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
