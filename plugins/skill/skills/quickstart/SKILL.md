# skill Plugin

CLI tool: skill.

## Commands
- `skill <resource> <action>` — Execute skill commands
- `skill self version` — Print skill version
- `skill _ _` — Passthrough to skill CLI

## Usage Examples
- "skill --help"
- "skill self version"

## Installation
```bash
apt-get install skill 2>/dev/null || which skill
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
