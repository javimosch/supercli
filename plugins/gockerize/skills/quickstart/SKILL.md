# gockerize Plugin
Package Go applications into minimal containers without Dockerfiles

## Commands
- `gockerize <resource> <action>` — Execute gockerize commands
- `gockerize _ _` — Passthrough to gockerize CLI

## Usage
- `gockerize _ _ <args>` — Run gockerize with any arguments
