# pstops Plugin

CLI tool: pstops.

## Commands
- `pstops <resource> <action>` — Execute pstops commands
- `pstops self version` — Print pstops version
- `pstops _ _` — Passthrough to pstops CLI

## Usage Examples
- "pstops --help"
- "pstops self version"

## Installation
```bash
apt-get install pstops 2>/dev/null || which pstops
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
