# libgvc6-config-update Plugin

CLI tool: libgvc6-config-update.

## Commands
- `libgvc6-config-update <resource> <action>` — Execute libgvc6-config-update commands
- `libgvc6-config-update self version` — Print libgvc6-config-update version
- `libgvc6-config-update _ _` — Passthrough to libgvc6-config-update CLI

## Usage Examples
- "libgvc6-config-update --help"
- "libgvc6-config-update self version"

## Installation
```bash
apt-get install libgvc6-config-update 2>/dev/null || which libgvc6-config-update
```
