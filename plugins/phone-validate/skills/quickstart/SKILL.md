# phone-validate Plugin
CLI wrapper for parsing and validating phone formats

## Commands
- `phone-validate <resource> <action>` — Execute phone-validate commands
- `phone-validate _ _` — Passthrough to phone-validate CLI

## Usage
- `phone-validate _ _ <args>` — Run phone-validate with any arguments
