# databasus Plugin

PostgreSQL backup tool with Point-In-Time-Recovery and restore verification

## Commands

### General
- `databasus self version` — Print databasus version
- `databasus _ _` — Passthrough to databasus CLI

```bash
pip install databasus
```

- PostgreSQL backup tool with Point-In-Time-Recovery and restore verification
- CLI tool, headless and scriptable
