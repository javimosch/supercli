# t4ht Plugin

CLI tool: t4ht.

## Commands
- `t4ht <resource> <action>` — Execute t4ht commands
- `t4ht self version` — Print t4ht version
- `t4ht _ _` — Passthrough to t4ht CLI

## Usage Examples
- "t4ht --help"
- "t4ht self version"

## Installation
```bash
apt-get install t4ht 2>/dev/null || which t4ht
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
