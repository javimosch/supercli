# pwdecrypt Plugin

CLI tool: pwdecrypt.

## Commands
- `pwdecrypt <resource> <action>` — Execute pwdecrypt commands
- `pwdecrypt self version` — Print pwdecrypt version
- `pwdecrypt _ _` — Passthrough to pwdecrypt CLI

## Usage Examples
- "pwdecrypt --help"
- "pwdecrypt self version"

## Installation
```bash
apt-get install pwdecrypt 2>/dev/null || which pwdecrypt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
