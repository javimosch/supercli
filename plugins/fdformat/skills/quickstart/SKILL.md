# fdformat Plugin

CLI tool: fdformat.

## Commands
- `fdformat <resource> <action>` — Execute fdformat commands
- `fdformat self version` — Print fdformat version
- `fdformat _ _` — Passthrough to fdformat CLI

## Usage Examples
- "fdformat --help"
- "fdformat self version"

## Installation
```bash
apt-get install fdformat 2>/dev/null || which fdformat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
