# grpc-client-cli Plugin
Generic gRPC CLI client with server reflection support

## Commands
- `grpc-client-cli <resource> <action>` — Execute grpc-client-cli commands
- `grpc-client-cli _ _` — Passthrough to grpc-client-cli CLI

## Usage
- `grpc-client-cli _ _ <args>` — Run grpc-client-cli with any arguments
