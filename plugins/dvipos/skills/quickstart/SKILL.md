# dvipos Plugin

CLI tool: dvipos.

## Commands
- `dvipos <resource> <action>` — Execute dvipos commands
- `dvipos self version` — Print dvipos version
- `dvipos _ _` — Passthrough to dvipos CLI

## Usage Examples
- "dvipos --help"
- "dvipos self version"

## Installation
```bash
apt-get install dvipos 2>/dev/null || which dvipos
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
