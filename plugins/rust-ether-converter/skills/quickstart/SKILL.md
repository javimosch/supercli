# rust-ether-converter Plugin

Ether unit converter CLI in Rust

## Commands
- `rust-ether-converter self version` — Print version
- `rust-ether-converter _ _` — Passthrough to rust-ether-converter

## Installation
```bash
cargo install rust-ether-converter
```
