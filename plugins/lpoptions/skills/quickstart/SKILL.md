# lpoptions Plugin

CLI tool: lpoptions.

## Commands
- `lpoptions <resource> <action>` — Execute lpoptions commands
- `lpoptions self version` — Print lpoptions version
- `lpoptions _ _` — Passthrough to lpoptions CLI

## Usage Examples
- "lpoptions --help"
- "lpoptions self version"

## Installation
```bash
apt-get install lpoptions 2>/dev/null || which lpoptions
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
