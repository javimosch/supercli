# sirtopnm Plugin

CLI tool: sirtopnm.

## Commands
- `sirtopnm <resource> <action>` — Execute sirtopnm commands
- `sirtopnm self version` — Print sirtopnm version
- `sirtopnm _ _` — Passthrough to sirtopnm CLI

## Usage Examples
- "sirtopnm --help"
- "sirtopnm self version"

## Installation
```bash
apt-get install sirtopnm 2>/dev/null || which sirtopnm
```
