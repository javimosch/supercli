# cargo-edit Plugin

cargo-edit — Cargo extension for adding and removing crate dependencies

## Commands
- `cargo-edit <resource> <action>` — Execute cargo-edit commands
- `cargo-edit self version` — Version

## Installation

```bash
cargo install cargo-edit
Verify: cargo-edit --version
```

## Commands

### `sc cargo-edit self version`

Version


## SuperCLI

```bash
sc cargo-edit _ _ --help
sc plugins learn cargo-edit
```
