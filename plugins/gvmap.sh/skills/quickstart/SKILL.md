# gvmap.sh Plugin

CLI tool: gvmap.sh.

## Commands
- `gvmap.sh <resource> <action>` — Execute gvmap.sh commands
- `gvmap.sh self version` — Print gvmap.sh version
- `gvmap.sh _ _` — Passthrough to gvmap.sh CLI

## Usage Examples
- "gvmap.sh --help"
- "gvmap.sh self version"

## Installation
```bash
apt-get install gvmap.sh 2>/dev/null || which gvmap.sh
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
