# slowql Plugin

SQL static analyzer for performance, security, compliance and cost. 272 rules. Completely offline. Works in CI pipelines pipx install.

## Commands
- `slowql self version` — Print version
- `slowql _ _ <args>` — Passthrough to slowql

## Usage Examples
- "SQL Analyzer"

## Installation
```bash
pipx install slowql
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
