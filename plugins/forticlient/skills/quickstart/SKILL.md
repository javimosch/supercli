# forticlient Plugin

CLI tool: forticlient.

## Commands
- `forticlient <resource> <action>` — Execute forticlient commands
- `forticlient self version` — Print forticlient version
- `forticlient _ _` — Passthrough to forticlient CLI

## Usage Examples
- "forticlient --help"
- "forticlient self version"

## Installation
```bash
apt-get install forticlient 2>/dev/null || which forticlient
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
