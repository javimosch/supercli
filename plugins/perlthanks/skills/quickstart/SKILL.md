# perlthanks Plugin

CLI tool: perlthanks.

## Commands
- `perlthanks <resource> <action>` — Execute perlthanks commands
- `perlthanks self version` — Print perlthanks version
- `perlthanks _ _` — Passthrough to perlthanks CLI

## Usage Examples
- "perlthanks --help"
- "perlthanks self version"

## Installation
```bash
apt-get install perlthanks 2>/dev/null || which perlthanks
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
