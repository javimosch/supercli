# fcgistarter Plugin

CLI tool: fcgistarter.

## Commands
- `fcgistarter <resource> <action>` — Execute fcgistarter commands
- `fcgistarter self version` — Print fcgistarter version
- `fcgistarter _ _` — Passthrough to fcgistarter CLI

## Usage Examples
- "fcgistarter --help"
- "fcgistarter self version"

## Installation
```bash
apt-get install fcgistarter 2>/dev/null || which fcgistarter
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
