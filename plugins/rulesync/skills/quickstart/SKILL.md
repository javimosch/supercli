# rulesync Plugin

A Utility CLI for AI Coding Agents. Sync rules across projects. npm install -g rulesync or brew install rulesync.

## Commands
- `rulesync self version` — Print version
- `rulesync _ _ <args>` — Passthrough to rulesync

## Usage Examples
- "Rules Sync CLI"

## Installation
```bash
npm install -g rulesync
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
