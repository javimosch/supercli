# mongodb-compass Plugin

CLI tool: mongodb-compass.

## Commands
- `mongodb-compass <resource> <action>` — Execute mongodb-compass commands
- `mongodb-compass self version` — Print mongodb-compass version
- `mongodb-compass _ _` — Passthrough to mongodb-compass CLI

## Usage Examples
- "mongodb-compass --help"
- "mongodb-compass self version"

## Installation
```bash
apt-get install mongodb-compass 2>/dev/null || which mongodb-compass
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
