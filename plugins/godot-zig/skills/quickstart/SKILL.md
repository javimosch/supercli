# godot-zig Plugin

Zig bindings for Godot 4

## Commands

### General
- `godot-zig self version` — Print godot-zig version
- `godot-zig _ _` — Passthrough to godot-zig CLI

## Usage Examples
- "Run godot-zig"
- "Use godot-zig to Zig bindings for Godot 4"

## Installation

```bash
pip install godot-zig
```

## Key Features
- Zig bindings for Godot 4
- CLI tool, headless and scriptable
