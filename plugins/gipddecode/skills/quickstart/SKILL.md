# gipddecode Plugin

CLI tool: gipddecode.

## Commands
- `gipddecode <resource> <action>` — Execute gipddecode commands
- `gipddecode self version` — Print gipddecode version
- `gipddecode _ _` — Passthrough to gipddecode CLI

## Usage Examples
- "gipddecode --help"
- "gipddecode self version"

## Installation
```bash
apt-get install gipddecode 2>/dev/null || which gipddecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
