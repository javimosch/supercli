# update-inetd Plugin

CLI tool: update-inetd.

## Commands
- `update-inetd <resource> <action>` — Execute update-inetd commands
- `update-inetd self version` — Print update-inetd version
- `update-inetd _ _` — Passthrough to update-inetd CLI

## Usage Examples
- "update-inetd --help"
- "update-inetd self version"

## Installation
```bash
apt-get install update-inetd 2>/dev/null || which update-inetd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
