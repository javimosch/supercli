# segment-geospatial Plugin
CLI harness for geospatial imagery segmentation with SAM

## Commands
- `segment-geospatial <resource> <action>` — Execute segment-geospatial commands
- `segment-geospatial _ _` — Passthrough to segment-geospatial CLI

## Usage
- `segment-geospatial _ _ <args>` — Run segment-geospatial with any arguments
