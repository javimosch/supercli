# zig-time-sharing-kernel Plugin

Minimal implementation of a time-sharing kernel on RISC-V, implemented in Zig, on top of OpenSBI

## Commands

### General
- `zig-time-sharing-kernel self version` — Print zig-time-sharing-kernel version
- `zig-time-sharing-kernel _ _` — Passthrough to zig-time-sharing-kernel CLI
