# instmodsh Plugin

CLI tool: instmodsh.

## Commands
- `instmodsh <resource> <action>` — Execute instmodsh commands
- `instmodsh self version` — Print instmodsh version
- `instmodsh _ _` — Passthrough to instmodsh CLI

## Usage Examples
- "instmodsh --help"
- "instmodsh self version"

## Installation
```bash
apt-get install instmodsh 2>/dev/null || which instmodsh
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
