# maildown Plugin

Super simple CLI for sending emails in Python

## Commands

### Operations
- `maildown self version` — Print maildown version
- `maildown _ _` — Passthrough to maildown CLI

## Usage Examples
- `maildown --help`
- `maildown <args>`

## Installation

```bash
pip install maildown
```

## Examples

```bash
maildown --version
maildown --help
```
