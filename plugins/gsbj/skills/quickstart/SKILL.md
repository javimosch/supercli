# gsbj Plugin

CLI tool: gsbj.

## Commands
- `gsbj <resource> <action>` — Execute gsbj commands
- `gsbj self version` — Print gsbj version
- `gsbj _ _` — Passthrough to gsbj CLI

## Usage Examples
- "gsbj --help"
- "gsbj self version"

## Installation
```bash
apt-get install gsbj 2>/dev/null || which gsbj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
