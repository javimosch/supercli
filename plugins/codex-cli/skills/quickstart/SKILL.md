# codex-cli Plugin
OpenAI Codex CLI for generating code

## Commands
- `codex-cli <resource> <action>` — Execute codex-cli commands
- `codex-cli _ _` — Passthrough to codex-cli CLI

## Usage
- `codex-cli _ _ <args>` — Run codex-cli with any arguments
