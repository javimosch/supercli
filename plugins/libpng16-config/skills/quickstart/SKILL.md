# libpng16-config Plugin

CLI tool: libpng16-config.

## Commands
- `libpng16-config <resource> <action>` — Execute libpng16-config commands
- `libpng16-config self version` — Print libpng16-config version
- `libpng16-config _ _` — Passthrough to libpng16-config CLI

## Usage Examples
- "libpng16-config --help"
- "libpng16-config self version"

## Installation
```bash
apt-get install libpng16-config 2>/dev/null || which libpng16-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
