# cfn-diagram Plugin

Visualize CloudFormation/SAM/CDK stacks in JavaScript

## Commands

### Operations
- `cfn-diagram self version` — Print cfn-diagram version
- `cfn-diagram _ _` — Passthrough to cfn-diagram CLI

## Usage Examples
- `cfn-diagram --help`
- `cfn-diagram <args>`

## Installation

```bash
npm install -g cfn-diagram
```

## Examples

```bash
cfn-diagram --version
cfn-diagram --help
```
