# sncli Plugin
Simplenote command-line client with sync

## Commands
- `sncli <resource> <action>` — Execute sncli commands
- `sncli _ _` — Passthrough to sncli CLI

## Usage
- `sncli _ _ <args>` — Run sncli with any arguments
