# pw-v4l2 Plugin

CLI tool: pw-v4l2.

## Commands
- `pw-v4l2 <resource> <action>` — Execute pw-v4l2 commands
- `pw-v4l2 self version` — Print pw-v4l2 version
- `pw-v4l2 _ _` — Passthrough to pw-v4l2 CLI

## Usage Examples
- "pw-v4l2 --help"
- "pw-v4l2 self version"

## Installation
```bash
apt-get install pw-v4l2 2>/dev/null || which pw-v4l2
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
