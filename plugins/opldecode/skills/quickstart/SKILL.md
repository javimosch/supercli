# opldecode Plugin

CLI tool: opldecode.

## Commands
- `opldecode <resource> <action>` — Execute opldecode commands
- `opldecode self version` — Print opldecode version
- `opldecode _ _` — Passthrough to opldecode CLI

## Usage Examples
- "opldecode --help"
- "opldecode self version"

## Installation
```bash
apt-get install opldecode 2>/dev/null || which opldecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
