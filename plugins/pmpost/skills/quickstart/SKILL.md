# pmpost Plugin

CLI tool: pmpost.

## Commands
- `pmpost <resource> <action>` — Execute pmpost commands
- `pmpost self version` — Print pmpost version
- `pmpost _ _` — Passthrough to pmpost CLI

## Usage Examples
- "pmpost --help"
- "pmpost self version"

## Installation
```bash
apt-get install pmpost 2>/dev/null || which pmpost
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
