# unicode_stop Plugin

CLI tool: unicode_stop.

## Commands
- `unicode_stop <resource> <action>` — Execute unicode_stop commands
- `unicode_stop self version` — Print unicode_stop version
- `unicode_stop _ _` — Passthrough to unicode_stop CLI

## Usage Examples
- "unicode_stop --help"
- "unicode_stop self version"

## Installation
```bash
apt-get install unicode_stop 2>/dev/null || which unicode_stop
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
