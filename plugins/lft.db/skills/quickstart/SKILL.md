# lft.db Plugin

CLI tool: lft.db.

## Commands
- `lft.db <resource> <action>` — Execute lft.db commands
- `lft.db self version` — Print lft.db version
- `lft.db _ _` — Passthrough to lft.db CLI

## Usage Examples
- "lft.db --help"
- "lft.db self version"

## Installation
```bash
apt-get install lft.db 2>/dev/null || which lft.db
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
