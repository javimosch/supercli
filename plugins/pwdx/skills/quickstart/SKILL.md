# pwdx Plugin

CLI tool: pwdx.

## Commands
- `pwdx <resource> <action>` — Execute pwdx commands
- `pwdx self version` — Print pwdx version
- `pwdx _ _` — Passthrough to pwdx CLI

## Usage Examples
- "pwdx --help"
- "pwdx self version"

## Installation
```bash
apt-get install pwdx 2>/dev/null || which pwdx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
