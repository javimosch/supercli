# pw-metadata Plugin

CLI tool: pw-metadata.

## Commands
- `pw-metadata <resource> <action>` — Execute pw-metadata commands
- `pw-metadata self version` — Print pw-metadata version
- `pw-metadata _ _` — Passthrough to pw-metadata CLI

## Usage Examples
- "pw-metadata --help"
- "pw-metadata self version"

## Installation
```bash
apt-get install pw-metadata 2>/dev/null || which pw-metadata
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
