# languagetool Plugin
Style and grammar checker for 25+ languages

## Commands
- `languagetool <resource> <action>` — Execute languagetool commands
- `languagetool _ _` — Passthrough to languagetool CLI

## Usage
- `languagetool _ _ <args>` — Run languagetool with any arguments
