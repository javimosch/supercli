# ipscan Plugin

CLI tool: ipscan.

## Commands
- `ipscan <resource> <action>` — Execute ipscan commands
- `ipscan self version` — Print ipscan version
- `ipscan _ _` — Passthrough to ipscan CLI

## Usage Examples
- "ipscan --help"
- "ipscan self version"

## Installation
```bash
apt-get install ipscan 2>/dev/null || which ipscan
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
