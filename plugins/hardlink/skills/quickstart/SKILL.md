# hardlink Plugin

CLI tool: hardlink.

## Commands
- `hardlink <resource> <action>` — Execute hardlink commands
- `hardlink self version` — Print hardlink version
- `hardlink _ _` — Passthrough to hardlink CLI

## Usage Examples
- "hardlink --help"
- "hardlink self version"

## Installation
```bash
apt-get install hardlink 2>/dev/null || which hardlink
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
