# cargo-generate-new Plugin

cargo-generate — cargo extension for generating new Rust projects

## Commands
- `cargo-generate-new <resource> <action>` — Execute cargo-generate-new commands
- `cargo-generate-new self version` — Version

## Installation

```bash
cargo install cargo-generate-new
Verify: cargo-generate-new --version
```

## Commands

### `sc cargo-generate-new self version`

Version


## SuperCLI

```bash
sc cargo-generate-new _ _ --help
sc plugins learn cargo-generate-new
```
