# md2confl Plugin
Convert Markdown to Confluence wiki markup

## Commands
- `md2confl <resource> <action>` — Execute md2confl commands
- `md2confl _ _` — Passthrough to md2confl CLI

## Usage
- `md2confl _ _ <args>` — Run md2confl with any arguments
