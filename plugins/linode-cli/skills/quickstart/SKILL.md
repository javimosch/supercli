# linode-cli

Linode CLI — command-line tool for Linode cloud

## Install

```bash
pip install linode-cli
brew install linode-cli
```

Verify installation:

```bash
which linode-cli
```

## Commands

- `linode-cli self version` — print linode-cli version
- `linode-cli cli run ...` — pass any arguments straight through to `linode-cli`
