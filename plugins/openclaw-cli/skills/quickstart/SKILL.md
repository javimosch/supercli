# openclaw-cli Plugin
System diagnostic CLI with JSON reporting.
## Commands

## Installation
```bash
npm install -g openclaw
```
## Key Features
- **System diagnostics** — Check tool health
- **JSON reporting** — Structured output
- **Pipeline-ready** — Automation support
