# ossgofragel Plugin

Open source security vulnerability scanner for Go projects

## Commands
- `ossgofragel self version` — Print ossgofragel version
- `ossgofragel _ _` — Passthrough to ossgofragel CLI

## Usage Examples
- `ossgofragel self version` — Check installed version
- `ossgofragel _ _ --help` — Show ossgofragel help
- `ossgofragel _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/ossgofragel/ossgofragel@latest
```

## Key Features
- security, golang, vulnerability, scanner
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
