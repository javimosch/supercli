# Voicebox Plugin

The open-source AI voice studio — clone, dictate, create

## Commands
- `voicebox _ _` — Passthrough to voicebox CLI

## Installation

```bash
npm install -g voicebox
```

## Examples
```bash
voicebox --help
voicebox --version
```
