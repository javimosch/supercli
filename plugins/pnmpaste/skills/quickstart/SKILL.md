# pnmpaste Plugin

CLI tool: pnmpaste.

## Commands
- `pnmpaste <resource> <action>` — Execute pnmpaste commands
- `pnmpaste self version` — Print pnmpaste version
- `pnmpaste _ _` — Passthrough to pnmpaste CLI

## Usage Examples
- "pnmpaste --help"
- "pnmpaste self version"

## Installation
```bash
apt-get install pnmpaste 2>/dev/null || which pnmpaste
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
