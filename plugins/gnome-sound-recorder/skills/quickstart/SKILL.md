# gnome-sound-recorder Plugin

CLI tool: gnome-sound-recorder.

## Commands
- `gnome-sound-recorder <resource> <action>` — Execute gnome-sound-recorder commands
- `gnome-sound-recorder self version` — Print gnome-sound-recorder version
- `gnome-sound-recorder _ _` — Passthrough to gnome-sound-recorder CLI

## Usage Examples
- "gnome-sound-recorder --help"
- "gnome-sound-recorder self version"

## Installation
```bash
apt-get install gnome-sound-recorder 2>/dev/null || which gnome-sound-recorder
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
