# wovp2ovf Plugin

CLI tool: wovp2ovf.

## Commands
- `wovp2ovf <resource> <action>` — Execute wovp2ovf commands
- `wovp2ovf self version` — Print wovp2ovf version
- `wovp2ovf _ _` — Passthrough to wovp2ovf CLI

## Usage Examples
- "wovp2ovf --help"
- "wovp2ovf self version"

## Installation
```bash
apt-get install wovp2ovf 2>/dev/null || which wovp2ovf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
