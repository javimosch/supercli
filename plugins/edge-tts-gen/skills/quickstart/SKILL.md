# edge-tts-gen Plugin
Generate speech audio using Microsoft Edge TTS API

## Commands
- `edge-tts-gen <resource> <action>` — Execute edge-tts-gen commands
- `edge-tts-gen _ _` — Passthrough to edge-tts-gen CLI

## Usage
- `edge-tts-gen _ _ <args>` — Run edge-tts-gen with any arguments
