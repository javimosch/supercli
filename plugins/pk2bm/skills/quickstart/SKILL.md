# pk2bm Plugin

CLI tool: pk2bm.

## Commands
- `pk2bm <resource> <action>` — Execute pk2bm commands
- `pk2bm self version` — Print pk2bm version
- `pk2bm _ _` — Passthrough to pk2bm CLI

## Usage Examples
- "pk2bm --help"
- "pk2bm self version"

## Installation
```bash
apt-get install pk2bm 2>/dev/null || which pk2bm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
