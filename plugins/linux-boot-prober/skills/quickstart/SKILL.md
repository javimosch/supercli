# linux-boot-prober Plugin

CLI tool: linux-boot-prober.

## Commands
- `linux-boot-prober <resource> <action>` — Execute linux-boot-prober commands
- `linux-boot-prober self version` — Print linux-boot-prober version
- `linux-boot-prober _ _` — Passthrough to linux-boot-prober CLI

- "linux-boot-prober self version"
