# ProxyBridge Plugin

Proxifier Alternative to redirect any Windows/MacOS/Linux TCP and UDP traffic to HTTP/Socks5 proxy

## Commands

### General
- `ProxyBridge self version` — Print ProxyBridge version
- `ProxyBridge _ _` — Passthrough to proxybridge CLI

## Usage Examples
- "Run ProxyBridge"
- "Use proxybridge to Proxifier Alternative to redirect any Windows/MacOS/Linux TC"

## Installation

```bash
pip install proxybridge
```

## Key Features
- Proxifier Alternative to redirect any Windows/MacOS/Linux TCP and UDP traffic to HTTP/Socks5 proxy
- CLI tool, headless and scriptable
