# bytefield-cli Plugin
Generate bytefield and register diagrams from text specs

## Commands
- `bytefield-cli <resource> <action>` — Execute bytefield-cli commands
- `bytefield-cli _ _` — Passthrough to bytefield-cli CLI

## Usage
- `bytefield-cli _ _ <args>` — Run bytefield-cli with any arguments
