# sparrow-wifi Plugin
Spectral awareness tool for WiFi and BLE analysis

## Commands
- `sparrow-wifi <resource> <action>` — Execute sparrow-wifi commands
- `sparrow-wifi _ _` — Passthrough to sparrow-wifi CLI

## Usage
- `sparrow-wifi _ _ <args>` — Run sparrow-wifi with any arguments
