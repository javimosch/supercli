# gnome-screenshot Plugin

CLI tool: gnome-screenshot.

## Commands
- `gnome-screenshot <resource> <action>` — Execute gnome-screenshot commands
- `gnome-screenshot self version` — Print gnome-screenshot version
- `gnome-screenshot _ _` — Passthrough to gnome-screenshot CLI

## Usage Examples
- "gnome-screenshot --help"
- "gnome-screenshot self version"

## Installation
```bash
apt-get install gnome-screenshot 2>/dev/null || which gnome-screenshot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
