# pyhtmlizer3 Plugin

CLI tool: pyhtmlizer3.

## Commands
- `pyhtmlizer3 <resource> <action>` — Execute pyhtmlizer3 commands
- `pyhtmlizer3 self version` — Print pyhtmlizer3 version
- `pyhtmlizer3 _ _` — Passthrough to pyhtmlizer3 CLI

## Usage Examples
- "pyhtmlizer3 --help"
- "pyhtmlizer3 self version"

## Installation
```bash
apt-get install pyhtmlizer3 2>/dev/null || which pyhtmlizer3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
