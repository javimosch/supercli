# drawio-cli Plugin
Export and convert draw.io diagrams from command line

## Commands
- `drawio-cli <resource> <action>` — Execute drawio-cli commands
- `drawio-cli _ _` — Passthrough to drawio-cli CLI

## Usage
- `drawio-cli _ _ <args>` — Run drawio-cli with any arguments
