# nss-pp Plugin

CLI tool: nss-pp.

## Commands
- `nss-pp <resource> <action>` — Execute nss-pp commands
- `nss-pp self version` — Print nss-pp version
- `nss-pp _ _` — Passthrough to nss-pp CLI

## Usage Examples
- "nss-pp --help"
- "nss-pp self version"

## Installation
```bash
apt-get install nss-pp 2>/dev/null || which nss-pp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
