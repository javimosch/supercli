# explodeview Plugin
Tool chain for converting STEP/CAD files to JSON/3D browser views

## Commands
- `explodeview <resource> <action>` — Execute explodeview commands
- `explodeview _ _` — Passthrough to explodeview CLI

## Usage
- `explodeview _ _ <args>` — Run explodeview with any arguments
