# select Plugin

CLI tool: select.

## Commands
- `select <resource> <action>` — Execute select commands
- `select self version` — Print select version
- `select _ _` — Passthrough to select CLI

## Usage Examples
- "select --help"
- "select self version"

## Installation
```bash
apt-get install select 2>/dev/null || which select
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
