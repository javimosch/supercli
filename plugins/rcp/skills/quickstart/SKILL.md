# rcp Plugin

CLI tool: rcp.

## Commands
- `rcp <resource> <action>` — Execute rcp commands
- `rcp self version` — Print rcp version
- `rcp _ _` — Passthrough to rcp CLI

## Usage Examples
- "rcp --help"
- "rcp self version"

## Installation
```bash
apt-get install rcp 2>/dev/null || which rcp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
