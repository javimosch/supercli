# gistify Plugin

Convert YAML/TOML/CSV/Excel to JSON in Go

## Commands
- `gistify self version` — Print version
- `gistify _ _` — Passthrough to gistify

## Installation
```bash
go install github.com/gistify/gistify@latest
```
