# mquickjs Plugin

Public repository of the Micro QuickJS Javascript Engine

## Commands

### General
- `mquickjs self version` — Print mquickjs version
- `mquickjs _ _` — Passthrough to mquickjs CLI

## Usage Examples
- "Run mquickjs"
- "Use mquickjs to Public repository of the Micro QuickJS Javascript Engine"

## Installation

```bash
pip install mquickjs
```

## Key Features
- Public repository of the Micro QuickJS Javascript Engine
- CLI tool, headless and scriptable
