# msgfilter Plugin

CLI tool: msgfilter.

## Commands
- `msgfilter <resource> <action>` — Execute msgfilter commands
- `msgfilter self version` — Print msgfilter version
- `msgfilter _ _` — Passthrough to msgfilter CLI

## Usage Examples
- "msgfilter --help"
- "msgfilter self version"

## Installation
```bash
apt-get install msgfilter 2>/dev/null || which msgfilter
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
