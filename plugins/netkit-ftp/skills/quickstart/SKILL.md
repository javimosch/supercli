# netkit-ftp Plugin

CLI tool: netkit-ftp.

## Commands
- `netkit-ftp <resource> <action>` — Execute netkit-ftp commands
- `netkit-ftp self version` — Print netkit-ftp version
- `netkit-ftp _ _` — Passthrough to netkit-ftp CLI

## Usage Examples
- "netkit-ftp --help"
- "netkit-ftp self version"

## Installation
```bash
apt-get install netkit-ftp 2>/dev/null || which netkit-ftp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
