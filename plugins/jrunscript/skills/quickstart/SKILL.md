# jrunscript Plugin

CLI tool: jrunscript.

## Commands
- `jrunscript <resource> <action>` — Execute jrunscript commands
- `jrunscript self version` — Print jrunscript version
- `jrunscript _ _` — Passthrough to jrunscript CLI

## Usage Examples
- "jrunscript --help"
- "jrunscript self version"

## Installation
```bash
apt-get install jrunscript 2>/dev/null || which jrunscript
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
