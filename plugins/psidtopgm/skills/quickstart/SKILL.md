# psidtopgm Plugin

CLI tool: psidtopgm.

## Commands
- `psidtopgm <resource> <action>` — Execute psidtopgm commands
- `psidtopgm self version` — Print psidtopgm version
- `psidtopgm _ _` — Passthrough to psidtopgm CLI

## Usage Examples
- "psidtopgm --help"
- "psidtopgm self version"

## Installation
```bash
apt-get install psidtopgm 2>/dev/null || which psidtopgm
```
