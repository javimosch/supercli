# kbdrate Plugin

CLI tool: kbdrate.

## Commands
- `kbdrate <resource> <action>` — Execute kbdrate commands
- `kbdrate self version` — Print kbdrate version
- `kbdrate _ _` — Passthrough to kbdrate CLI

## Usage Examples
- "kbdrate --help"
- "kbdrate self version"

## Installation
```bash
apt-get install kbdrate 2>/dev/null || which kbdrate
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
