# zedis Plugin

Redis in Zig

## Commands

### General
- `zedis self version` — Print zedis version
- `zedis _ _` — Passthrough to zedis CLI

## Usage Examples
- "Run zedis"
- "Use zedis to Redis in Zig"

## Installation

```bash
pip install zedis
```

## Key Features
- Redis in Zig
- CLI tool, headless and scriptable
