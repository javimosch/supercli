# lzmainfo Plugin

CLI tool: lzmainfo.

## Commands
- `lzmainfo <resource> <action>` — Execute lzmainfo commands
- `lzmainfo self version` — Print lzmainfo version
- `lzmainfo _ _` — Passthrough to lzmainfo CLI

## Usage Examples
- "lzmainfo --help"
- "lzmainfo self version"

## Installation
```bash
apt-get install lzmainfo 2>/dev/null || which lzmainfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
