# isoinfo Plugin

CLI tool: isoinfo.

## Commands
- `isoinfo <resource> <action>` — Execute isoinfo commands
- `isoinfo self version` — Print isoinfo version
- `isoinfo _ _` — Passthrough to isoinfo CLI

## Usage Examples
- "isoinfo --help"
- "isoinfo self version"

## Installation
```bash
apt-get install isoinfo 2>/dev/null || which isoinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
