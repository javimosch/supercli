# web-quality-skills Plugin

Agent Skills for optimizing web quality based on Lighthouse and Core Web Vitals.

## Commands

### General
- `web-quality-skills self version` — Print web-quality-skills version
- `web-quality-skills _ _` — Passthrough to web-quality-skills CLI

## Usage Examples
- "Run web-quality-skills"
- "Use web-quality-skills to Agent Skills for optimizing web quality based on Lighthouse "

## Installation

```bash
pip install web-quality-skills
```

## Key Features
- Agent Skills for optimizing web quality based on Lighthouse and Core Web Vitals.
- CLI tool, headless and scriptable
