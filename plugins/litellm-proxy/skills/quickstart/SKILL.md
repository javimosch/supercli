# litellm-proxy Plugin

CLI tool: litellm-proxy.

## Commands
- `litellm-proxy <resource> <action>` — Execute litellm-proxy commands
- `litellm-proxy self version` — Print litellm-proxy version
- `litellm-proxy _ _` — Passthrough to litellm-proxy CLI

## Usage Examples
- "litellm-proxy --help"
- "litellm-proxy self version"

## Installation
```bash
apt-get install litellm-proxy 2>/dev/null || which litellm-proxy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
