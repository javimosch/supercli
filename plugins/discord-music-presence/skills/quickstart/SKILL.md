# discord-music-presence Plugin

The Discord music status that works with any media player

## Commands

### General
- `discord-music-presence self version` — Print discord-music-presence version
- `discord-music-presence _ _` — Passthrough to discord-music-presence CLI

## Usage Examples
- "Run discord-music-presence"
- "Use discord-music-presence to The Discord music status that works with any media player"

## Installation

```bash
pip install discord-music-presence
```

## Key Features
- The Discord music status that works with any media player
- CLI tool, headless and scriptable
