# lzcat Plugin

CLI tool: lzcat.

## Commands
- `lzcat <resource> <action>` — Execute lzcat commands
- `lzcat self version` — Print lzcat version
- `lzcat _ _` — Passthrough to lzcat CLI

## Usage Examples
- "lzcat --help"
- "lzcat self version"

## Installation
```bash
apt-get install lzcat 2>/dev/null || which lzcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
