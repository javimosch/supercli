# pnmnoraw Plugin

CLI tool: pnmnoraw.

## Commands
- `pnmnoraw <resource> <action>` — Execute pnmnoraw commands
- `pnmnoraw self version` — Print pnmnoraw version
- `pnmnoraw _ _` — Passthrough to pnmnoraw CLI

## Usage Examples
- "pnmnoraw --help"
- "pnmnoraw self version"

## Installation
```bash
apt-get install pnmnoraw 2>/dev/null || which pnmnoraw
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
