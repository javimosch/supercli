# luajittex Plugin

CLI tool: luajittex.

## Commands
- `luajittex <resource> <action>` — Execute luajittex commands
- `luajittex self version` — Print luajittex version
- `luajittex _ _` — Passthrough to luajittex CLI

## Usage Examples
- "luajittex --help"
- "luajittex self version"

## Installation
```bash
apt-get install luajittex 2>/dev/null || which luajittex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
