# programmer-calculator Plugin

Terminal calculator for programmers

## Commands

### Version
`programmer-calculator self version` — Print programmer-calculator version

### Passthrough
`programmer-calculator _ _` — Passthrough to pcalc CLI with all arguments forwarded.

## Usage Examples

```bash
pcalc --version
pcalc --help
```

## Installation

```bash
cargo install programmer-calculator
```

## Key Features
- Terminal calculator for programmers
