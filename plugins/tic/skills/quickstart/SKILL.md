# tic Plugin

CLI tool: tic.

## Commands
- `tic <resource> <action>` — Execute tic commands
- `tic self version` — Print tic version
- `tic _ _` — Passthrough to tic CLI

## Usage Examples
- "tic --help"
- "tic self version"

## Installation
```bash
apt-get install tic 2>/dev/null || which tic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
