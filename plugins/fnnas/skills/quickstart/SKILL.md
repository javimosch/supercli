# fnnas Plugin

Supports running FnNAS on Amlogic, Allwinner, and Rockchip devices. Support a311d, s922x, s905x3, s905x2, s912, s905d, s905x, s905w, s905, s905l, rk3588, rk3568, rk3399, rk3328, h6, etc.

## Commands

### General
- `fnnas self version` — Print fnnas version
- `fnnas _ _` — Passthrough to fnnas CLI

- "Run fnnas"
- "Use fnnas to Supports running FnNAS on Amlogic, Allwinner, and Rockchip d"

## Installation

```bash
pip install fnnas
```

- Supports running FnNAS on Amlogic, Allwinner, and Rockchip devices. Support a311d, s922x, s905x3, s9
