# pbmtext Plugin

CLI tool: pbmtext.

## Commands
- `pbmtext <resource> <action>` — Execute pbmtext commands
- `pbmtext self version` — Print pbmtext version
- `pbmtext _ _` — Passthrough to pbmtext CLI

## Usage Examples
- "pbmtext --help"
- "pbmtext self version"

## Installation
```bash
apt-get install pbmtext 2>/dev/null || which pbmtext
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
