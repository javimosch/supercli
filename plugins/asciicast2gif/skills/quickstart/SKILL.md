# asciicast2gif Plugin
Convert asciicast v2 files to animated GIFs

## Commands
- `asciicast2gif <resource> <action>` — Execute asciicast2gif commands
- `asciicast2gif _ _` — Passthrough to asciicast2gif CLI

## Usage
- `asciicast2gif _ _ <args>` — Run asciicast2gif with any arguments
