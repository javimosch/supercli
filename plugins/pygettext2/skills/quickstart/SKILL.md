# pygettext2 Plugin

CLI tool: pygettext2.

## Commands
- `pygettext2 <resource> <action>` — Execute pygettext2 commands
- `pygettext2 self version` — Print pygettext2 version
- `pygettext2 _ _` — Passthrough to pygettext2 CLI

## Usage Examples
- "pygettext2 --help"
- "pygettext2 self version"

## Installation
```bash
apt-get install pygettext2 2>/dev/null || which pygettext2
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
