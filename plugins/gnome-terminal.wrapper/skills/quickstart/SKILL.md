# gnome-terminal.wrapper Plugin

CLI tool: gnome-terminal.wrapper.

## Commands
- `gnome-terminal.wrapper <resource> <action>` — Execute gnome-terminal.wrapper commands
- `gnome-terminal.wrapper self version` — Print gnome-terminal.wrapper version
- `gnome-terminal.wrapper _ _` — Passthrough to gnome-terminal.wrapper CLI

## Usage Examples
- "gnome-terminal.wrapper --help"
- "gnome-terminal.wrapper self version"

## Installation
```bash
apt-get install gnome-terminal.wrapper 2>/dev/null || which gnome-terminal.wrapper
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
