# surrealdb Plugin
SurrealDB is a multi-model database combining document, graph, relational, and vector capabilities into a single engine with a powerful CLI.

## Commands
- `surrealdb <resource> <action>` — Execute surrealdb commands
- `surrealdb _ _` — Passthrough to surreal CLI
