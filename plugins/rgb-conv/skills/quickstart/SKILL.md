# rgb-conv Plugin
Convert between RGB and other color formats via CLI

## Commands
- `rgb-conv <resource> <action>` — Execute rgb-conv commands
- `rgb-conv _ _` — Passthrough to rgb-conv CLI

## Usage
- `rgb-conv _ _ <args>` — Run rgb-conv with any arguments
