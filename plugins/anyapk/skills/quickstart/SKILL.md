# anyapk Plugin

Install any apk on the device you own. 

## Commands

### General
- `anyapk self version` — Print anyapk version
- `anyapk _ _` — Passthrough to anyapk CLI

## Installation

```bash
pip install anyapk
```

- Install any apk on the device you own.
