# teams-notify Plugin

CLI tool: teams-notify.

## Commands
- `teams-notify <resource> <action>` — Execute teams-notify commands
- `teams-notify self version` — Print teams-notify version
- `teams-notify _ _` — Passthrough to teams-notify CLI

## Usage Examples
- "teams-notify --help"
- "teams-notify self version"

## Installation
```bash
apt-get install teams-notify 2>/dev/null || which teams-notify
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
