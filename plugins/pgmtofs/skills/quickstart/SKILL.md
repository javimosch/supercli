# pgmtofs Plugin

CLI tool: pgmtofs.

## Commands
- `pgmtofs <resource> <action>` — Execute pgmtofs commands
- `pgmtofs self version` — Print pgmtofs version
- `pgmtofs _ _` — Passthrough to pgmtofs CLI

## Usage Examples
- "pgmtofs --help"
- "pgmtofs self version"

## Installation
```bash
apt-get install pgmtofs 2>/dev/null || which pgmtofs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
