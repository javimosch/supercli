# pathod Plugin

CLI tool: pathod.

## Commands
- `pathod <resource> <action>` — Execute pathod commands
- `pathod self version` — Print pathod version
- `pathod _ _` — Passthrough to pathod CLI

## Usage Examples
- "pathod --help"
- "pathod self version"

## Installation
```bash
apt-get install pathod 2>/dev/null || which pathod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
