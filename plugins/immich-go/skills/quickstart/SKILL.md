# immich-go Plugin

An alternative to the immich-CLI command that doesn't depend on nodejs installation. It tries its best for importing google photos takeout archives.

## Commands
- `immich-go <resource> <action>` — Execute immich-go commands
- `immich-go self version` — Print immich-go version
- `immich-go _ _` — Passthrough to immich-go CLI

## Installation

```bash
pip install immich-go
```
