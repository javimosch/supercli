# update-fmtutil Plugin

CLI tool: update-fmtutil.

## Commands
- `update-fmtutil <resource> <action>` — Execute update-fmtutil commands
- `update-fmtutil self version` — Print update-fmtutil version
- `update-fmtutil _ _` — Passthrough to update-fmtutil CLI

## Usage Examples
- "update-fmtutil --help"
- "update-fmtutil self version"

## Installation
```bash
apt-get install update-fmtutil 2>/dev/null || which update-fmtutil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
