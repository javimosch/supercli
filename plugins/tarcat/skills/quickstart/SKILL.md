# tarcat Plugin

CLI tool: tarcat.

## Commands
- `tarcat <resource> <action>` — Execute tarcat commands
- `tarcat self version` — Print tarcat version
- `tarcat _ _` — Passthrough to tarcat CLI

## Usage Examples
- "tarcat --help"
- "tarcat self version"

## Installation
```bash
apt-get install tarcat 2>/dev/null || which tarcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
