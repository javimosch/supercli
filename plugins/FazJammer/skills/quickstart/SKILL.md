# FazJammer Plugin

A minimal, simple and effective jammer that jams Wi-Fi, BLE and 2.4 GHz band.

## Commands

### General
- `FazJammer self version` — Print FazJammer version
- `FazJammer _ _` — Passthrough to fazjammer CLI

