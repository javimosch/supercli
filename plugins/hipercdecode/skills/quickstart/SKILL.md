# hipercdecode Plugin

CLI tool: hipercdecode.

## Commands
- `hipercdecode <resource> <action>` — Execute hipercdecode commands
- `hipercdecode self version` — Print hipercdecode version
- `hipercdecode _ _` — Passthrough to hipercdecode CLI

## Usage Examples
- "hipercdecode --help"
- "hipercdecode self version"

## Installation
```bash
apt-get install hipercdecode 2>/dev/null || which hipercdecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
