# GameNative Plugin

Native PC gaming with Steam, Epic, GOG and Amazon integrations on Android

## Commands

### General
- `GameNative self version` — Print GameNative version
- `GameNative _ _` — Passthrough to gamenative CLI

## Usage Examples
- "Run GameNative"
- "Use gamenative to Native PC gaming with Steam, Epic, GOG and Amazon integratio"

## Installation

```bash
pip install gamenative
```

## Key Features
- Native PC gaming with Steam, Epic, GOG and Amazon integrations on Android
- CLI tool, headless and scriptable
