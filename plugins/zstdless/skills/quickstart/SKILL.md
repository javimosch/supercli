# zstdless Plugin

CLI tool: zstdless.

## Commands
- `zstdless <resource> <action>` — Execute zstdless commands
- `zstdless self version` — Print zstdless version
- `zstdless _ _` — Passthrough to zstdless CLI

## Usage Examples
- "zstdless --help"
- "zstdless self version"

## Installation
```bash
apt-get install zstdless 2>/dev/null || which zstdless
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
