# x11perf Plugin

CLI tool: x11perf.

## Commands
- `x11perf <resource> <action>` — Execute x11perf commands
- `x11perf self version` — Print x11perf version
- `x11perf _ _` — Passthrough to x11perf CLI

## Usage Examples
- "x11perf --help"
- "x11perf self version"

## Installation
```bash
apt-get install x11perf 2>/dev/null || which x11perf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
