# VBoxSDL Plugin

CLI tool: VBoxSDL.

## Commands
- `VBoxSDL <resource> <action>` — Execute VBoxSDL commands
- `VBoxSDL self version` — Print VBoxSDL version
- `VBoxSDL _ _` — Passthrough to VBoxSDL CLI

## Usage Examples
- "VBoxSDL --help"
- "VBoxSDL self version"

## Installation
```bash
apt-get install VBoxSDL 2>/dev/null || which VBoxSDL
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
