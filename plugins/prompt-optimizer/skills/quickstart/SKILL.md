# Prompt-Optimizer Plugin

An AI prompt optimizer for writing better prompts and getting better AI results

## Commands
- `prompt-optimizer _ _` — Passthrough to prompt-optimizer CLI

## Installation

```bash
npm install -g prompt-optimizer
```

## Examples
```bash
prompt-optimizer --help
prompt-optimizer --version
```
