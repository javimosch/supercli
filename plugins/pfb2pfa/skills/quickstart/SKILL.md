# pfb2pfa Plugin

CLI tool: pfb2pfa.

## Commands
- `pfb2pfa <resource> <action>` — Execute pfb2pfa commands
- `pfb2pfa self version` — Print pfb2pfa version
- `pfb2pfa _ _` — Passthrough to pfb2pfa CLI

## Usage Examples
- "pfb2pfa --help"
- "pfb2pfa self version"

## Installation
```bash
apt-get install pfb2pfa 2>/dev/null || which pfb2pfa
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
