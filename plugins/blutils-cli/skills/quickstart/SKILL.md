# blutils-cli Plugin
CLI tool for blutils-cli.

## Commands
- `blutils-cli <resource> <action>` — Execute blutils-cli commands
- `blutils-cli _ _` — Passthrough to blutils-cli CLI

## Installation
```bash
cargo install blutils-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
