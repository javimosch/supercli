# pyi-makespec Plugin

CLI tool: pyi-makespec.

## Commands
- `pyi-makespec <resource> <action>` — Execute pyi-makespec commands
- `pyi-makespec self version` — Print pyi-makespec version
- `pyi-makespec _ _` — Passthrough to pyi-makespec CLI

## Usage Examples
- "pyi-makespec --help"
- "pyi-makespec self version"

## Installation
```bash
apt-get install pyi-makespec 2>/dev/null || which pyi-makespec
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
