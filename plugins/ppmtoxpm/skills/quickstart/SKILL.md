# ppmtoxpm Plugin

CLI tool: ppmtoxpm.

## Commands
- `ppmtoxpm <resource> <action>` — Execute ppmtoxpm commands
- `ppmtoxpm self version` — Print ppmtoxpm version
- `ppmtoxpm _ _` — Passthrough to ppmtoxpm CLI

## Usage Examples
- "ppmtoxpm --help"
- "ppmtoxpm self version"

## Installation
```bash
apt-get install ppmtoxpm 2>/dev/null || which ppmtoxpm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
