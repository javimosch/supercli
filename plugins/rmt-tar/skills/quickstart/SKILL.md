# rmt-tar Plugin

CLI tool: rmt-tar.

## Commands
- `rmt-tar <resource> <action>` — Execute rmt-tar commands
- `rmt-tar self version` — Print rmt-tar version
- `rmt-tar _ _` — Passthrough to rmt-tar CLI

## Usage Examples
- "rmt-tar --help"
- "rmt-tar self version"

## Installation
```bash
apt-get install rmt-tar 2>/dev/null || which rmt-tar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
