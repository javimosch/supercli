# cups.lprm Plugin

CLI tool: cups.lprm.

## Commands
- `cups.lprm <resource> <action>` — Execute cups.lprm commands
- `cups.lprm self version` — Print cups.lprm version
- `cups.lprm _ _` — Passthrough to cups.lprm CLI

## Usage Examples
- "cups.lprm --help"
- "cups.lprm self version"

## Installation
```bash
apt-get install cups.lprm 2>/dev/null || which cups.lprm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
