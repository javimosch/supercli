# release-plz Plugin
CLI tool for release-plz.

## Commands
- `release-plz <resource> <action>` — Execute release-plz commands
- `release-plz _ _` — Passthrough to release-plz CLI

## Installation
```bash
cargo install release-plz
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
