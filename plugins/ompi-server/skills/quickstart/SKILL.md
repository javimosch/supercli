# ompi-server Plugin

CLI tool: ompi-server.

## Commands
- `ompi-server <resource> <action>` — Execute ompi-server commands
- `ompi-server self version` — Print ompi-server version
- `ompi-server _ _` — Passthrough to ompi-server CLI

## Usage Examples
- "ompi-server --help"
- "ompi-server self version"

## Installation
```bash
apt-get install ompi-server 2>/dev/null || which ompi-server
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
