# komari Plugin

A simple server monitor tool.

## Commands

### General
- `komari self version` — Print komari version
- `komari _ _` — Passthrough to komari CLI

## Usage Examples
- "Run komari"
- "Use komari to A simple server monitor tool."

## Installation

```bash
pip install komari
```

## Key Features
- A simple server monitor tool.
- CLI tool, headless and scriptable
