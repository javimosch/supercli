# mq Plugin
jq for markdown processing.
## Commands
- `mq _ _` — Passthrough to mq CLI
## Installation
```bash
go install github.com/fiatjaf/mq@latest
```
## Key Features
- **Markdown query** — jq-like syntax
- **JSON output** — Structured data
- **Pipeline-ready** — stdin/stdout
