# thin_trim Plugin

CLI tool: thin_trim.

## Commands
- `thin_trim <resource> <action>` — Execute thin_trim commands
- `thin_trim self version` — Print thin_trim version
- `thin_trim _ _` — Passthrough to thin_trim CLI

## Usage Examples
- "thin_trim --help"
- "thin_trim self version"

## Installation
```bash
apt-get install thin_trim 2>/dev/null || which thin_trim
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
