# dgraph-live
dgraph-live — Dgraph graph database live loader. Bulk import RDF/JSON data into Dgraph clusters.

## Commands
- `dgraph-live <resource> <action>` — Execute dgraph-live commands
- `dgraph live run` — dgraph-live — Dgraph graph database live loader. Bulk import RDF/JSON data into Dgraph clusters.
