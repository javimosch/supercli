# pngfix Plugin

CLI tool: pngfix.

## Commands
- `pngfix <resource> <action>` — Execute pngfix commands
- `pngfix self version` — Print pngfix version
- `pngfix _ _` — Passthrough to pngfix CLI

## Usage Examples
- "pngfix --help"
- "pngfix self version"

## Installation
```bash
apt-get install pngfix 2>/dev/null || which pngfix
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
