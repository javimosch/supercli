# kmodsign Plugin

CLI tool: kmodsign.

## Commands
- `kmodsign <resource> <action>` — Execute kmodsign commands
- `kmodsign self version` — Print kmodsign version
- `kmodsign _ _` — Passthrough to kmodsign CLI

## Usage Examples
- "kmodsign --help"
- "kmodsign self version"

## Installation
```bash
apt-get install kmodsign 2>/dev/null || which kmodsign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
