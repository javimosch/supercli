# speak-ng Plugin

CLI tool: speak-ng.

## Commands
- `speak-ng <resource> <action>` — Execute speak-ng commands
- `speak-ng self version` — Print speak-ng version
- `speak-ng _ _` — Passthrough to speak-ng CLI

## Usage Examples
- "speak-ng --help"
- "speak-ng self version"

## Installation
```bash
apt-get install speak-ng 2>/dev/null || which speak-ng
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
