# pnmflip Plugin

CLI tool: pnmflip.

## Commands
- `pnmflip <resource> <action>` — Execute pnmflip commands
- `pnmflip self version` — Print pnmflip version
- `pnmflip _ _` — Passthrough to pnmflip CLI

## Usage Examples
- "pnmflip --help"
- "pnmflip self version"

## Installation
```bash
apt-get install pnmflip 2>/dev/null || which pnmflip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
