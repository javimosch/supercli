# printenv Plugin
Print all or part of environment

## Commands
- `printenv <resource> <action>` — Execute printenv commands
- `printenv self version` — Print printenv version
- `printenv _ _` — Passthrough to printenv CLI

## Usage
- `printenv _ _ <args>` — Run printenv with any arguments
