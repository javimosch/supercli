# mcheck Plugin

CLI tool: mcheck.

## Commands
- `mcheck <resource> <action>` — Execute mcheck commands
- `mcheck self version` — Print mcheck version
- `mcheck _ _` — Passthrough to mcheck CLI

## Usage Examples
- "mcheck --help"
- "mcheck self version"

## Installation
```bash
apt-get install mcheck 2>/dev/null || which mcheck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
