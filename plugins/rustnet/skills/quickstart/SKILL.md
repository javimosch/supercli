# Rustnet Plugin

Per-process network monitoring for your terminal with deep packet inspection

## Commands
- `rustnet _ _` — Passthrough to rustnet CLI

## Installation

```bash
cargo install rustnet
```

## Examples
```bash
rustnet --help
rustnet --version
```
