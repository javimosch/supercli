# pdf2dsc Plugin

CLI tool: pdf2dsc.

## Commands
- `pdf2dsc <resource> <action>` — Execute pdf2dsc commands
- `pdf2dsc self version` — Print pdf2dsc version
- `pdf2dsc _ _` — Passthrough to pdf2dsc CLI

## Usage Examples
- "pdf2dsc --help"
- "pdf2dsc self version"

## Installation
```bash
apt-get install pdf2dsc 2>/dev/null || which pdf2dsc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
