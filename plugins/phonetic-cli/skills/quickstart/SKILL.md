# phonetic-cli Plugin
Convert text to NATO phonetic alphabet spelling

## Commands
- `phonetic-cli <resource> <action>` — Execute phonetic-cli commands
- `phonetic-cli _ _` — Passthrough to phonetic-cli CLI

## Usage
- `phonetic-cli _ _ <args>` — Run phonetic-cli with any arguments
