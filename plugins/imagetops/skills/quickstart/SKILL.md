# imagetops Plugin

CLI tool: imagetops.

## Commands
- `imagetops <resource> <action>` — Execute imagetops commands
- `imagetops self version` — Print imagetops version
- `imagetops _ _` — Passthrough to imagetops CLI

## Usage Examples
- "imagetops --help"
- "imagetops self version"

## Installation
```bash
apt-get install imagetops 2>/dev/null || which imagetops
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
