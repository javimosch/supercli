# namei Plugin

CLI tool: namei.

## Commands
- `namei <resource> <action>` — Execute namei commands
- `namei self version` — Print namei version
- `namei _ _` — Passthrough to namei CLI

## Usage Examples
- "namei --help"
- "namei self version"

```bash
apt-get install namei 2>/dev/null || which namei
```
