# Nobook Plugin

Ad-free facebook lite for Android.

## Commands

### General
- `Nobook self version` — Print Nobook version
- `Nobook _ _` — Passthrough to nobook CLI

## Usage Examples
- "Run Nobook"
- "Use nobook to Ad-free facebook lite for Android."

## Installation

```bash
pip install nobook
```

## Key Features
- Ad-free facebook lite for Android.
- CLI tool, headless and scriptable
