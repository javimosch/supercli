# xkbwatch Plugin

CLI tool: xkbwatch.

## Commands
- `xkbwatch <resource> <action>` — Execute xkbwatch commands
- `xkbwatch self version` — Print xkbwatch version
- `xkbwatch _ _` — Passthrough to xkbwatch CLI

## Usage Examples
- "xkbwatch --help"
- "xkbwatch self version"

## Installation
```bash
apt-get install xkbwatch 2>/dev/null || which xkbwatch
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
