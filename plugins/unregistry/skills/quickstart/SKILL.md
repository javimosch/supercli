# unregistry Plugin

Push docker images directly to remote servers without an external registry

## Commands

### General
- `unregistry self version` — Print unregistry version
- `unregistry _ _` — Passthrough to unregistry CLI

## Usage Examples
- "Run unregistry"
- "Use unregistry to Push docker images directly to remote servers without an ext"

## Installation

```bash
pip install unregistry
```

## Key Features
- Push docker images directly to remote servers without an external registry
- CLI tool, headless and scriptable
