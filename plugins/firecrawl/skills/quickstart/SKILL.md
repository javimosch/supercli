# firecrawl Plugin

The API to search, scrape, and interact with the web at scale. 🔥

## Commands

### General
- `firecrawl self version` — Print firecrawl version
- `firecrawl _ _` — Passthrough to firecrawl CLI

- "Run firecrawl"

pip install firecrawl
