# todo.txt-cli Plugin

Simple extensible shell script for todo.txt

## Commands

### Version
`todo.txt-cli self version` — Print todo.txt-cli version

### Passthrough
`todo.txt-cli _ _` — Passthrough to todo CLI with all arguments forwarded.

## Usage Examples

```bash
todo --version
todo --help
```

## Installation

```bash
brew install todo-txt
```

## Key Features
- Simple extensible shell script for todo.txt
