# quran-cli Plugin
Read the Quran directly in your terminal

## Commands
- `quran-cli <resource> <action>` — Execute quran-cli commands
- `quran-cli _ _` — Passthrough to quran-cli CLI

## Usage
- `quran-cli _ _ <args>` — Run quran-cli with any arguments
