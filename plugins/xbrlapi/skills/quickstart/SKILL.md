# xbrlapi Plugin

CLI tool: xbrlapi.

## Commands
- `xbrlapi <resource> <action>` — Execute xbrlapi commands
- `xbrlapi self version` — Print xbrlapi version
- `xbrlapi _ _` — Passthrough to xbrlapi CLI

## Usage Examples
- "xbrlapi --help"
- "xbrlapi self version"

## Installation
```bash
apt-get install xbrlapi 2>/dev/null || which xbrlapi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
