# ximtoppm Plugin

CLI tool: ximtoppm.

## Commands
- `ximtoppm <resource> <action>` — Execute ximtoppm commands
- `ximtoppm self version` — Print ximtoppm version
- `ximtoppm _ _` — Passthrough to ximtoppm CLI

## Usage Examples
- "ximtoppm --help"
- "ximtoppm self version"

## Installation
```bash
apt-get install ximtoppm 2>/dev/null || which ximtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
