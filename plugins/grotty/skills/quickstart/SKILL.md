# grotty Plugin

CLI tool: grotty.

## Commands
- `grotty <resource> <action>` — Execute grotty commands
- `grotty self version` — Print grotty version
- `grotty _ _` — Passthrough to grotty CLI

## Usage Examples
- "grotty --help"
- "grotty self version"

## Installation
```bash
apt-get install grotty 2>/dev/null || which grotty
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
