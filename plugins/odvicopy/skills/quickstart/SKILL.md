# odvicopy Plugin

CLI tool: odvicopy.

## Commands
- `odvicopy <resource> <action>` — Execute odvicopy commands
- `odvicopy self version` — Print odvicopy version
- `odvicopy _ _` — Passthrough to odvicopy CLI

## Usage Examples
- "odvicopy --help"
- "odvicopy self version"

## Installation
```bash
apt-get install odvicopy 2>/dev/null || which odvicopy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
