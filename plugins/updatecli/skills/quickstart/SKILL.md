# updatecli Plugin
Declarative dependency management and update tool

## Commands
- `updatecli <resource> <action>` — Execute updatecli commands
- `updatecli _ _` — Passthrough to updatecli CLI

## Usage
- `updatecli _ _ <args>` — Run updatecli with any arguments
