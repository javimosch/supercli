# pgmoil Plugin

CLI tool: pgmoil.

## Commands
- `pgmoil <resource> <action>` — Execute pgmoil commands
- `pgmoil self version` — Print pgmoil version
- `pgmoil _ _` — Passthrough to pgmoil CLI

## Usage Examples
- "pgmoil --help"
- "pgmoil self version"

## Installation
```bash
apt-get install pgmoil 2>/dev/null || which pgmoil
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
