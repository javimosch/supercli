# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `websocat <resource> <action>` — Execute websocat commands
- `websocat self version` — Print websocat version
- `websocat client connect` — Connect to WebSocket server
- `websocat _ _` — Passthrough to websocat CLI
