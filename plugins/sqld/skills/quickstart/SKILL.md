# sqld Plugin

CLI tool: sqld.

## Commands
- `sqld <resource> <action>` — Execute sqld commands
- `sqld self version` — Print sqld version
- `sqld _ _` — Passthrough to sqld CLI

## Usage Examples
- "sqld --help"
- "sqld self version"

## Installation
```bash
apt-get install sqld 2>/dev/null || which sqld
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
