# kbd_mode Plugin

CLI tool: kbd_mode.

## Commands
- `kbd_mode <resource> <action>` — Execute kbd_mode commands
- `kbd_mode self version` — Print kbd_mode version
- `kbd_mode _ _` — Passthrough to kbd_mode CLI

## Usage Examples
- "kbd_mode --help"
- "kbd_mode self version"

## Installation
```bash
apt-get install kbd_mode 2>/dev/null || which kbd_mode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
