# grap2graph Plugin

CLI tool: grap2graph.

## Commands
- `grap2graph <resource> <action>` — Execute grap2graph commands
- `grap2graph self version` — Print grap2graph version
- `grap2graph _ _` — Passthrough to grap2graph CLI

## Usage Examples
- "grap2graph --help"
- "grap2graph self version"

## Installation
```bash
apt-get install grap2graph 2>/dev/null || which grap2graph
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
