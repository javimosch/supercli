# pamstack Plugin

CLI tool: pamstack.

## Commands
- `pamstack <resource> <action>` — Execute pamstack commands
- `pamstack self version` — Print pamstack version
- `pamstack _ _` — Passthrough to pamstack CLI

## Usage Examples
- "pamstack --help"
- "pamstack self version"

## Installation
```bash
apt-get install pamstack 2>/dev/null || which pamstack
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
