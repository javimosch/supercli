# mpif77 Plugin

CLI tool: mpif77.

## Commands
- `mpif77 <resource> <action>` — Execute mpif77 commands
- `mpif77 self version` — Print mpif77 version
- `mpif77 _ _` — Passthrough to mpif77 CLI

## Usage Examples
- "mpif77 --help"
- "mpif77 self version"

## Installation
```bash
apt-get install mpif77 2>/dev/null || which mpif77
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
