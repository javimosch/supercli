# tree-sitter

Tree-sitter — incremental parsing system for programming languages

## Install

```bash
brew install tree-sitter
cargo install tree-sitter-cli
```

Verify installation:

```bash
which tree-sitter
```

## Commands

- `tree-sitter self version` — print tree-sitter version
- `tree-sitter cli run ...` — pass any arguments straight through to `tree-sitter`
