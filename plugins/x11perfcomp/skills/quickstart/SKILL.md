# x11perfcomp Plugin

CLI tool: x11perfcomp.

## Commands
- `x11perfcomp <resource> <action>` — Execute x11perfcomp commands
- `x11perfcomp self version` — Print x11perfcomp version
- `x11perfcomp _ _` — Passthrough to x11perfcomp CLI

## Usage Examples
- "x11perfcomp --help"
- "x11perfcomp self version"

## Installation
```bash
apt-get install x11perfcomp 2>/dev/null || which x11perfcomp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
