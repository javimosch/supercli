# vgmerge Plugin

CLI tool: vgmerge.

## Commands
- `vgmerge <resource> <action>` — Execute vgmerge commands
- `vgmerge self version` — Print vgmerge version
- `vgmerge _ _` — Passthrough to vgmerge CLI

## Usage Examples
- "vgmerge --help"
- "vgmerge self version"

## Installation
```bash
apt-get install vgmerge 2>/dev/null || which vgmerge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
