# texluajitc Plugin

CLI tool: texluajitc.

## Commands
- `texluajitc <resource> <action>` — Execute texluajitc commands
- `texluajitc self version` — Print texluajitc version
- `texluajitc _ _` — Passthrough to texluajitc CLI

## Usage Examples
- "texluajitc --help"
- "texluajitc self version"

## Installation
```bash
apt-get install texluajitc 2>/dev/null || which texluajitc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
