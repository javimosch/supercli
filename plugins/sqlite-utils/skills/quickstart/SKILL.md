# sqlite-utils
sqlite-utils — CLI utility for manipulating SQLite databases. Create, query, insert JSON/CSV, build full-text search indexes.

## Commands
- `sqlite-utils <resource> <action>` — Execute sqlite-utils commands
- `sqlite utils run` — sqlite-utils — CLI utility for manipulating SQLite databases. Create, query, insert JSON/CSV, build full-text search indexes.
