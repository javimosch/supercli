# img-resize Plugin
Batch resize images to specified dimensions from CLI

## Commands
- `img-resize <resource> <action>` — Execute img-resize commands
- `img-resize _ _` — Passthrough to img-resize CLI

## Usage
- `img-resize _ _ <args>` — Run img-resize with any arguments
