# apkeep Plugin
CLI tool for apkeep.

## Commands
- `apkeep <resource> <action>` — Execute apkeep commands
- `apkeep _ _` — Passthrough to apkeep CLI

## Installation
```bash
cargo install apkeep
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
