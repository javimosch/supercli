# curlylint Plugin
Experimental HTML templates linting for Jinja/Nunjucks

## Commands
- `curlylint <resource> <action>` — Execute curlylint commands
- `curlylint _ _` — Passthrough to curlylint CLI

## Usage
- `curlylint _ _ <args>` — Run curlylint with any arguments
