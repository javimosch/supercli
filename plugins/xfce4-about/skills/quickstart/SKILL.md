# xfce4-about Plugin

CLI tool: xfce4-about.

## Commands
- `xfce4-about <resource> <action>` — Execute xfce4-about commands
- `xfce4-about self version` — Print xfce4-about version
- `xfce4-about _ _` — Passthrough to xfce4-about CLI

## Usage Examples
- "xfce4-about --help"
- "xfce4-about self version"

## Installation
```bash
apt-get install xfce4-about 2>/dev/null || which xfce4-about
```
