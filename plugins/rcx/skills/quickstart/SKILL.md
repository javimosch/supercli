# rcx Plugin

CLI tool: rcx.

## Commands
- `rcx <resource> <action>` — Execute rcx commands
- `rcx self version` — Print rcx version
- `rcx _ _` — Passthrough to rcx CLI

## Usage Examples
- "rcx --help"
- "rcx self version"

## Installation
```bash
apt-get install rcx 2>/dev/null || which rcx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
