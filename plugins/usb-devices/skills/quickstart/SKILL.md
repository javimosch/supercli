# usb-devices Plugin

CLI tool: usb-devices.

## Commands
- `usb-devices <resource> <action>` — Execute usb-devices commands
- `usb-devices self version` — Print usb-devices version
- `usb-devices _ _` — Passthrough to usb-devices CLI

## Usage Examples
- "usb-devices --help"
- "usb-devices self version"

## Installation
```bash
apt-get install usb-devices 2>/dev/null || which usb-devices
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
