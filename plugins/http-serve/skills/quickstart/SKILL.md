# http-serve
http-serve — quick HTTP static file server. Serve a directory on a specified port. Great for sharing files.

## Commands
- `http-serve <resource> <action>` — Execute http-serve commands
- `http serve run` — http-serve — quick HTTP static file server. Serve a directory on a specified port. Great for sharing files.
