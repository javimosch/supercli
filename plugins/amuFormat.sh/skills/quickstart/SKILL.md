# amuFormat.sh Plugin

amuFormat.sh — Tools for manipulating MSDOS files.

## Commands
- `amuFormat.sh <resource> <action>` — Execute amuFormat.sh commands
- `amuFormat.sh self version` — Print amuFormat.sh version
- `amuFormat.sh _ _` — Passthrough to amuFormat.sh CLI

## Usage Examples
- "amuFormat.sh --help"
- "amuFormat.sh self version"

## Installation
```bash
apt-get install mtools 2>/dev/null || which amuFormat.sh
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
