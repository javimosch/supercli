# amuFormat.sh Plugin

CLI tool: amuFormat.sh.

- `amuFormat.sh <resource> <action>` — Execute amuFormat.sh commands
- `amuFormat.sh self version` — Print amuFormat.sh version
- `amuFormat.sh _ _` — Passthrough to amuFormat.sh CLI

## Usage Examples
- "amuFormat.sh --help"
- "amuFormat.sh self version"

