# gzexe Plugin

CLI tool: gzexe.

## Commands
- `gzexe <resource> <action>` — Execute gzexe commands
- `gzexe self version` — Print gzexe version
- `gzexe _ _` — Passthrough to gzexe CLI

## Usage Examples
- "gzexe --help"
- "gzexe self version"

## Installation
```bash
apt-get install gzexe 2>/dev/null || which gzexe
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
