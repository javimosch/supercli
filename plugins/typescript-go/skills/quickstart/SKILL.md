# typescript-go Plugin

Staging repo for development of native port of TypeScript

## Commands

### General
- `typescript-go self version` — Print typescript-go version
- `typescript-go _ _` — Passthrough to typescript-go CLI

## Usage Examples
- "Run typescript-go"
- "Use typescript-go to Staging repo for development of native port of TypeScript"

## Installation

```bash
pip install typescript-go
```

## Key Features
- Staging repo for development of native port of TypeScript
- CLI tool, headless and scriptable
