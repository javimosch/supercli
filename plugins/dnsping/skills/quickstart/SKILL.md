# dnsping Plugin
Check packet loss and latency of DNS servers with detailed statistics

## Commands
- `dnsping <resource> <action>` — Execute dnsping commands
- `dnsping _ _` — Passthrough to dnsping CLI

## Usage
- `dnsping _ _ <args>` — Run dnsping with any arguments
