# mclasserase Plugin

CLI tool: mclasserase.

## Commands
- `mclasserase <resource> <action>` — Execute mclasserase commands
- `mclasserase self version` — Print mclasserase version
- `mclasserase _ _` — Passthrough to mclasserase CLI

## Usage Examples
- "mclasserase --help"
- "mclasserase self version"

## Installation
```bash
apt-get install mclasserase 2>/dev/null || which mclasserase
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
