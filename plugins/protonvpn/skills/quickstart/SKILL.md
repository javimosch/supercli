# protonvpn Plugin

CLI tool: protonvpn.

## Commands
- `protonvpn <resource> <action>` — Execute protonvpn commands
- `protonvpn self version` — Print protonvpn version
- `protonvpn _ _` — Passthrough to protonvpn CLI

## Usage Examples
- "protonvpn --help"
- "protonvpn self version"

## Installation
```bash
apt-get install protonvpn 2>/dev/null || which protonvpn
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
