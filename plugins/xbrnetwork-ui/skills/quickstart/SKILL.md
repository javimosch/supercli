# xbrnetwork-ui Plugin

CLI tool: xbrnetwork-ui.

## Commands
- `xbrnetwork-ui <resource> <action>` — Execute xbrnetwork-ui commands
- `xbrnetwork-ui self version` — Print xbrnetwork-ui version
- `xbrnetwork-ui _ _` — Passthrough to xbrnetwork-ui CLI

## Usage Examples
- "xbrnetwork-ui --help"
- "xbrnetwork-ui self version"

## Installation
```bash
apt-get install xbrnetwork-ui 2>/dev/null || which xbrnetwork-ui
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
