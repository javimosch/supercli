# Helium-Db Plugin

Open-source graph-vector database built from scratch in Rust

## Commands
- `helium-db _ _` — Passthrough to helixdb CLI

## Installation

```bash
cargo install helixdb
```

## Examples
```bash
helixdb --help
helixdb --version
```
