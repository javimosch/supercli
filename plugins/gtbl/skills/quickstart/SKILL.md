# gtbl Plugin

CLI tool: gtbl.

## Commands
- `gtbl <resource> <action>` — Execute gtbl commands
- `gtbl self version` — Print gtbl version
- `gtbl _ _` — Passthrough to gtbl CLI

## Usage Examples
- "gtbl --help"
- "gtbl self version"

## Installation
```bash
apt-get install gtbl 2>/dev/null || which gtbl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
