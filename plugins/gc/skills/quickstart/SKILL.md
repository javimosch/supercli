# gc Plugin

CLI tool: gc.

## Commands
- `gc <resource> <action>` — Execute gc commands
- `gc self version` — Print gc version
- `gc _ _` — Passthrough to gc CLI

## Usage Examples
- "gc --help"
- "gc self version"

## Installation
```bash
apt-get install gc 2>/dev/null || which gc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
