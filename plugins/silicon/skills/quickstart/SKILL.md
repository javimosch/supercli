# silicon Plugin

silicon — create beautiful images of your source code..

## Commands

### `sc silicon code render`
Render source code to image.

### `sc silicon self version`
Print version.

## Installation

```bash
cargo install silicon
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
