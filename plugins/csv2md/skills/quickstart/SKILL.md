# csv2md Plugin
csv2md — convert CSV to Markdown tables. Reads CSV from stdin, outputs formatted Markdown.

## Commands
- `csv2md <resource> <action>` — Execute csv2md commands
- `csv2md csv2md run` — csv2md — convert CSV to Markdown tables. Reads CSV from stdin, outputs formatted Markdown.
