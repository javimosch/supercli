# zlist Plugin
Lightweight colorful ls alternative.
## Commands
- `zlist _ _` — Passthrough to zlist CLI
## Installation
```bash
git clone <repo> && cd zlist && zig build
```
## Key Features
- **Colorful** — Syntax-highlighted output
- **Fast** — Zig performance
- **Lightweight** — Minimal binary
