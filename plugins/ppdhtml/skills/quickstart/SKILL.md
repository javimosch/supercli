# ppdhtml Plugin

CLI tool: ppdhtml.

## Commands
- `ppdhtml <resource> <action>` — Execute ppdhtml commands
- `ppdhtml self version` — Print ppdhtml version
- `ppdhtml _ _` — Passthrough to ppdhtml CLI

## Usage Examples
- "ppdhtml --help"
- "ppdhtml self version"

## Installation
```bash
apt-get install ppdhtml 2>/dev/null || which ppdhtml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
