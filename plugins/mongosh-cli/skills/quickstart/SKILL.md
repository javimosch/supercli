# mongosh-cli Plugin
MongoDB shell CLI for database administration and queries

## Commands
- `mongosh-cli <resource> <action>` — Execute mongosh-cli commands
- `mongosh-cli _ _` — Passthrough to mongosh-cli CLI

## Usage
- `mongosh-cli _ _ <args>` — Run mongosh-cli with any arguments
