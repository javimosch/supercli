# opal_wrapper Plugin

CLI tool: opal_wrapper.

## Commands
- `opal_wrapper <resource> <action>` — Execute opal_wrapper commands
- `opal_wrapper self version` — Print opal_wrapper version
- `opal_wrapper _ _` — Passthrough to opal_wrapper CLI

## Usage Examples
- "opal_wrapper --help"
- "opal_wrapper self version"

## Installation
```bash
apt-get install opal_wrapper 2>/dev/null || which opal_wrapper
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
