# Donutbrowser Plugin

Simple yet powerful anti-detect browser

## Commands
- `donutbrowser _ _` — Passthrough to donutbrowser CLI

## Installation

```bash
cargo install donutbrowser
```

## Examples
```bash
donutbrowser --help
donutbrowser --version
```
