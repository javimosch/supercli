# certstrap Plugin

certstrap creates and manages SSL/TLS certificates.

## Usage Examples

- "create a new certificate authority"
- "generate a signed certificate for a domain"
- "create a certificate signing request"
- "build a certificate chain"

## Installation

```bash
brew install certstrap
```

## Key Features
- Certificate authority (CA) creation
- Certificate signing request (CSR) generation
- Certificate signing and chain building
- Passphrase-protected private keys
- CRL distribution point support
- PKI infrastructure management
