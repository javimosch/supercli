# daft Plugin

High-performance data engine

## Commands

### Version
`daft self version` — Print daft version

### Passthrough
`daft _ _` — Passthrough to daft CLI with all arguments forwarded.

## Usage Examples

```bash
daft --version
daft --help
```

## Installation

```bash
pip install daft
```

## Key Features
- High-performance data engine
