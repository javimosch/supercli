# seahorse Plugin

CLI tool: seahorse.

## Commands
- `seahorse <resource> <action>` — Execute seahorse commands
- `seahorse self version` — Print seahorse version
- `seahorse _ _` — Passthrough to seahorse CLI

## Usage Examples
- "seahorse --help"
- "seahorse self version"

## Installation
```bash
apt-get install seahorse 2>/dev/null || which seahorse
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
