# r-mpost Plugin

MetaPost tool for TeX documents.

## Commands
- `r-mpost <resource> <action>` — Execute r-mpost commands
- `r-mpost _ _` — Passthrough to r-mpost CLI

## Usage Examples
- "r-mpost --help"

## Installation
```bash
apt-get install texlive-metapost
```

## Key Features
- CLI-based system tool
- Scriptable and automatable
