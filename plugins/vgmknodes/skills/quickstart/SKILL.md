# vgmknodes Plugin

CLI tool: vgmknodes.

## Commands
- `vgmknodes <resource> <action>` — Execute vgmknodes commands
- `vgmknodes self version` — Print vgmknodes version
- `vgmknodes _ _` — Passthrough to vgmknodes CLI

## Usage Examples
- "vgmknodes --help"
- "vgmknodes self version"

## Installation
```bash
apt-get install vgmknodes 2>/dev/null || which vgmknodes
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
