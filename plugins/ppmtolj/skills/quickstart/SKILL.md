# ppmtolj Plugin

CLI tool: ppmtolj.

## Commands
- `ppmtolj <resource> <action>` — Execute ppmtolj commands
- `ppmtolj self version` — Print ppmtolj version
- `ppmtolj _ _` — Passthrough to ppmtolj CLI

## Usage Examples
- "ppmtolj --help"
- "ppmtolj self version"

## Installation
```bash
apt-get install ppmtolj 2>/dev/null || which ppmtolj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
