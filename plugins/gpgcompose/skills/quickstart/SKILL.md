# gpgcompose Plugin

CLI tool: gpgcompose.

## Commands
- `gpgcompose <resource> <action>` — Execute gpgcompose commands
- `gpgcompose self version` — Print gpgcompose version
- `gpgcompose _ _` — Passthrough to gpgcompose CLI

## Usage Examples
- "gpgcompose --help"
- "gpgcompose self version"

## Installation
```bash
apt-get install gpgcompose 2>/dev/null || which gpgcompose
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
