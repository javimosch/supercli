# pbmtogem Plugin

CLI tool: pbmtogem.

## Commands
- `pbmtogem <resource> <action>` — Execute pbmtogem commands
- `pbmtogem self version` — Print pbmtogem version
- `pbmtogem _ _` — Passthrough to pbmtogem CLI

## Usage Examples
- "pbmtogem --help"
- "pbmtogem self version"

## Installation
```bash
apt-get install pbmtogem 2>/dev/null || which pbmtogem
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
