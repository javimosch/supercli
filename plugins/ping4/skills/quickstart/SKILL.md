# ping4 Plugin

CLI tool: ping4.

## Commands
- `ping4 <resource> <action>` — Execute ping4 commands
- `ping4 self version` — Print ping4 version
- `ping4 _ _` — Passthrough to ping4 CLI

## Usage Examples
- "ping4 --help"
- "ping4 self version"

## Installation
```bash
apt-get install ping4 2>/dev/null || which ping4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
