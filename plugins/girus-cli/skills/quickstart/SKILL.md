# Girus-Cli Plugin

Interactive CLI tool for DevOps labs and practice

## Commands
- `girus-cli _ _` — Passthrough to girus CLI

## Installation

```bash
go install github.com/badtuxx/girus-cli@latest
```

## Examples
```bash
girus --help
girus --version
```
