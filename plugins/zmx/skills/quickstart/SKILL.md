# zmx Plugin

Session persistence for terminal processes

## Commands

### General
- `zmx self version` — Print zmx version
- `zmx _ _` — Passthrough to zmx CLI

## Usage Examples
- "Run zmx"
- "Use zmx to Session persistence for terminal processes"

## Installation

```bash
pip install zmx
```

## Key Features
- Session persistence for terminal processes
- CLI tool, headless and scriptable
