# zmx Plugin

Session persistence for terminal processes

## Commands

### Version
`zmx self version` — Print zmx version

### Passthrough
`zmx _ _` — Passthrough to zmx CLI with all arguments forwarded.

## Usage Examples

```bash
zmx --version
zmx --help
```

## Installation

```bash
cargo install zmx
```

## Key Features
- Session persistence for terminal processes
