# magic-new Plugin

CLI tool: magic-new.

## Commands
- `magic-new <resource> <action>` — Execute magic-new commands
- `magic-new self version` — Print magic-new version
- `magic-new _ _` — Passthrough to magic-new CLI

## Usage Examples
- "magic-new --help"
- "magic-new self version"

## Installation
```bash
apt-get install magic-new 2>/dev/null || which magic-new
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
