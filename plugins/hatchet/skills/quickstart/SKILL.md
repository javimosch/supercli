# hatchet Plugin

🪓 An orchestration engine for background tasks, AI agents, and durable workflows

## Commands
- `hatchet <resource> <action>` — Execute hatchet commands
- `hatchet self version` — Print hatchet version
- `hatchet _ _` — Passthrough to hatchet CLI

## Installation

```bash
pip install hatchet
```
