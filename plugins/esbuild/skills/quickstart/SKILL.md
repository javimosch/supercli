# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `esbuild <resource> <action>` — Execute esbuild commands
- `esbuild self version` — Print esbuild version
- `esbuild build bundle` — Bundle JavaScript/TypeScript
- `esbuild _ _` — Passthrough to esbuild CLI
