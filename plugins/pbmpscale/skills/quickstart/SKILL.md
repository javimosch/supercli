# pbmpscale Plugin

CLI tool: pbmpscale.

## Commands
- `pbmpscale <resource> <action>` — Execute pbmpscale commands
- `pbmpscale self version` — Print pbmpscale version
- `pbmpscale _ _` — Passthrough to pbmpscale CLI

## Usage Examples
- "pbmpscale --help"
- "pbmpscale self version"

## Installation
```bash
apt-get install pbmpscale 2>/dev/null || which pbmpscale
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
