# scor2prt Plugin

CLI tool: scor2prt.

## Commands
- `scor2prt <resource> <action>` — Execute scor2prt commands
- `scor2prt self version` — Print scor2prt version
- `scor2prt _ _` — Passthrough to scor2prt CLI

## Usage Examples
- "scor2prt --help"
- "scor2prt self version"

```bash
apt-get install scor2prt 2>/dev/null || which scor2prt
```
