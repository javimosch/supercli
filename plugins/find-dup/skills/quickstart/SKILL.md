# find-dup
find-dup — find duplicate lines in text. Reads stdin, outputs JSON with duplicate counts and line numbers, sorted by frequency.

## Commands
- `find-dup <resource> <action>` — Execute find-dup commands
- `find dup run` — find-dup — find duplicate lines in text. Reads stdin, outputs JSON with duplicate counts and line numbers, sorted by frequency.
