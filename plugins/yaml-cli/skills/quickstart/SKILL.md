# yaml-cli Plugin

yaml-cli — YAML CLI processor, like jq but for YAML..

## Commands

### `sc yaml-cli yaml process`
Process YAML from stdin or file.

### `sc yaml-cli self version`
Print version.

## Installation

```bash
npm install -g yaml-cli
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
