# gnome-characters Plugin

CLI tool: gnome-characters.

## Commands
- `gnome-characters <resource> <action>` — Execute gnome-characters commands
- `gnome-characters self version` — Print gnome-characters version
- `gnome-characters _ _` — Passthrough to gnome-characters CLI

## Usage Examples
- "gnome-characters --help"
- "gnome-characters self version"

## Installation
```bash
apt-get install gnome-characters 2>/dev/null || which gnome-characters
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
