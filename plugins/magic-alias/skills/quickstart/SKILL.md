# magic-alias Plugin

CLI tool: magic-alias.

## Commands
- `magic-alias <resource> <action>` — Execute magic-alias commands
- `magic-alias self version` — Print magic-alias version
- `magic-alias _ _` — Passthrough to magic-alias CLI

## Usage Examples
- "magic-alias --help"
- "magic-alias self version"

## Installation
```bash
apt-get install magic-alias 2>/dev/null || which magic-alias
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
