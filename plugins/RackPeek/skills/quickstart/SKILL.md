# RackPeek Plugin

CLI tool to discover, manage, and document your IT infrastructure

## Commands
- `RackPeek <resource> <action>` — Execute RackPeek commands
- `RackPeek self version` — Print RackPeek version
- `RackPeek _ _` — Passthrough to rackpeek CLI

## Installation

```bash
go install github.com/RackPeek/RackPeek@latest
```
