# xdg-icon-resource Plugin

CLI tool: xdg-icon-resource.

## Commands
- `xdg-icon-resource <resource> <action>` — Execute xdg-icon-resource commands
- `xdg-icon-resource self version` — Print xdg-icon-resource version
- `xdg-icon-resource _ _` — Passthrough to xdg-icon-resource CLI

## Usage Examples
- "xdg-icon-resource --help"
- "xdg-icon-resource self version"

## Installation
```bash
apt-get install xdg-icon-resource 2>/dev/null || which xdg-icon-resource
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
