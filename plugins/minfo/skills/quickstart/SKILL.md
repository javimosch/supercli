# minfo Plugin

CLI tool: minfo.

## Commands
- `minfo <resource> <action>` — Execute minfo commands
- `minfo self version` — Print minfo version
- `minfo _ _` — Passthrough to minfo CLI

## Usage Examples
- "minfo --help"
- "minfo self version"

## Installation
```bash
apt-get install minfo 2>/dev/null || which minfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
