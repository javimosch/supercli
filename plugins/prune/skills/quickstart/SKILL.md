# prune Plugin

CLI tool: prune.

## Commands
- `prune <resource> <action>` — Execute prune commands
- `prune self version` — Print prune version
- `prune _ _` — Passthrough to prune CLI

## Usage Examples
- "prune --help"
- "prune self version"

## Installation
```bash
apt-get install prune 2>/dev/null || which prune
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
