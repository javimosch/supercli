# telnet.netkit Plugin

CLI tool: telnet.netkit.

## Commands
- `telnet.netkit <resource> <action>` — Execute telnet.netkit commands
- `telnet.netkit self version` — Print telnet.netkit version
- `telnet.netkit _ _` — Passthrough to telnet.netkit CLI

## Usage Examples
- "telnet.netkit --help"
- "telnet.netkit self version"

## Installation
```bash
apt-get install telnet.netkit 2>/dev/null || which telnet.netkit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
