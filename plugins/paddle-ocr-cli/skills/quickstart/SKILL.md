# paddle-ocr-cli Plugin
CLI wrapper for high-performance PaddleOCR text recognition

## Commands
- `paddle-ocr-cli <resource> <action>` — Execute paddle-ocr-cli commands
- `paddle-ocr-cli _ _` — Passthrough to paddle-ocr-cli CLI

## Usage
- `paddle-ocr-cli _ _ <args>` — Run paddle-ocr-cli with any arguments
