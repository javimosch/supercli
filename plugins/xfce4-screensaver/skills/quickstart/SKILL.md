# xfce4-screensaver Plugin

CLI tool: xfce4-screensaver.

## Commands
- `xfce4-screensaver <resource> <action>` — Execute xfce4-screensaver commands
- `xfce4-screensaver self version` — Print xfce4-screensaver version
- `xfce4-screensaver _ _` — Passthrough to xfce4-screensaver CLI

## Usage Examples
- "xfce4-screensaver --help"
- "xfce4-screensaver self version"

## Installation
```bash
apt-get install xfce4-screensaver 2>/dev/null || which xfce4-screensaver
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
