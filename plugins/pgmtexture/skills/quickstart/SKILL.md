# pgmtexture Plugin

CLI tool: pgmtexture.

## Commands
- `pgmtexture <resource> <action>` — Execute pgmtexture commands
- `pgmtexture self version` — Print pgmtexture version
- `pgmtexture _ _` — Passthrough to pgmtexture CLI

## Usage Examples
- "pgmtexture --help"
- "pgmtexture self version"

## Installation
```bash
apt-get install pgmtexture 2>/dev/null || which pgmtexture
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
