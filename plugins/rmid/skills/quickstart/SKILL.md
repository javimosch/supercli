# rmid Plugin

CLI tool: rmid.

## Commands
- `rmid <resource> <action>` — Execute rmid commands
- `rmid self version` — Print rmid version
- `rmid _ _` — Passthrough to rmid CLI

## Usage Examples
- "rmid --help"
- "rmid self version"

## Installation
```bash
apt-get install rmid 2>/dev/null || which rmid
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
