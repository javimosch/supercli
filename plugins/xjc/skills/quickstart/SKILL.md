# xjc Plugin

CLI tool: xjc.

## Commands
- `xjc <resource> <action>` — Execute xjc commands
- `xjc self version` — Print xjc version
- `xjc _ _` — Passthrough to xjc CLI

## Usage Examples
- "xjc --help"
- "xjc self version"

## Installation
```bash
apt-get install xjc 2>/dev/null || which xjc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
