# pwgen-cli Plugin
Memorable password generator with multiple modes

## Commands
- `pwgen-cli <resource> <action>` — Execute pwgen-cli commands
- `pwgen-cli _ _` — Passthrough to pwgen-cli CLI

## Usage
- `pwgen-cli _ _ <args>` — Run pwgen-cli with any arguments
