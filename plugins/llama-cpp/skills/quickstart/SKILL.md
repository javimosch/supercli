# llama-cpp Plugin
Inference of LLM models in pure C++ with CLI

## Commands
- `llama-cpp <resource> <action>` — Execute llama-cpp commands
- `llama-cpp _ _` — Passthrough to llama-cpp CLI

## Usage
- `llama-cpp _ _ <args>` — Run llama-cpp with any arguments
