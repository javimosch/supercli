# rmiregistry Plugin

CLI tool: rmiregistry.

## Commands
- `rmiregistry <resource> <action>` — Execute rmiregistry commands
- `rmiregistry self version` — Print rmiregistry version
- `rmiregistry _ _` — Passthrough to rmiregistry CLI

## Usage Examples
- "rmiregistry --help"
- "rmiregistry self version"

## Installation
```bash
apt-get install rmiregistry 2>/dev/null || which rmiregistry
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
