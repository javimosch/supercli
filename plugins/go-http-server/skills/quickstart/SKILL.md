# go-http-server Plugin
Simple production-ready static file HTTP server

## Commands
- `go-http-server <resource> <action>` — Execute go-http-server commands
- `go-http-server _ _` — Passthrough to go-http-server CLI

## Usage
- `go-http-server _ _ <args>` — Run go-http-server with any arguments
