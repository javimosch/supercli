# psfxtable Plugin

CLI tool: psfxtable.

## Commands
- `psfxtable <resource> <action>` — Execute psfxtable commands
- `psfxtable self version` — Print psfxtable version
- `psfxtable _ _` — Passthrough to psfxtable CLI

## Usage Examples
- "psfxtable --help"
- "psfxtable self version"

## Installation
```bash
apt-get install psfxtable 2>/dev/null || which psfxtable
```
