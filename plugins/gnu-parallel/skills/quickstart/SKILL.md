# gnu-parallel
GNU parallel — shell tool for executing jobs in parallel. Run commands across multiple CPU cores or machines.

## Commands
- `gnu-parallel <resource> <action>` — Execute gnu-parallel commands
- `gnu parallel run` — GNU parallel — shell tool for executing jobs in parallel. Run commands across multiple CPU cores or machines.
