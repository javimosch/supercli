# ppmmake Plugin

CLI tool: ppmmake.

## Commands
- `ppmmake <resource> <action>` — Execute ppmmake commands
- `ppmmake self version` — Print ppmmake version
- `ppmmake _ _` — Passthrough to ppmmake CLI

## Usage Examples
- "ppmmake --help"
- "ppmmake self version"

## Installation
```bash
apt-get install ppmmake 2>/dev/null || which ppmmake
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
