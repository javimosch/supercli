# critical Plugin

critical extracts and inlines critical CSS.

## Usage Examples

- "extract critical CSS from a webpage"
- "inline critical CSS for performance"
- "generate critical CSS for mobile and desktop"

## Installation

```bash
npm install -g critical
```

## Key Features
- Above-the-fold CSS extraction
- Critical CSS inlining
- Responsive viewport support
- HTML/CSS optimization
- Page load performance improvement
- Multiple page batch processing
