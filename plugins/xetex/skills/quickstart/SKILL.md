# xetex Plugin

CLI tool: xetex.

## Commands
- `xetex <resource> <action>` — Execute xetex commands
- `xetex self version` — Print xetex version
- `xetex _ _` — Passthrough to xetex CLI

## Usage Examples
- "xetex --help"
- "xetex self version"

## Installation
```bash
apt-get install xetex 2>/dev/null || which xetex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
