# deepagents Plugin

The batteries-included agent harness.

## Commands
- `deepagents <resource> <action>` — Execute deepagents commands
- `deepagents self version` — Print deepagents version
- `deepagents _ _` — Passthrough to deepagents CLI

## Installation

```bash
pip install deepagents
```
