# hetzner-cli Plugin

Hetzner Cloud CLI for managing cloud resources

## Commands
- `hetzner-cli self version` — Print version
- `hetzner-cli _ _` — Passthrough to hcloud

## Installation
```bash
brew install hcloud
```
