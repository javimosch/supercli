# isutf8 Plugin

CLI tool: isutf8.

## Commands
- `isutf8 <resource> <action>` — Execute isutf8 commands
- `isutf8 self version` — Print isutf8 version
- `isutf8 _ _` — Passthrough to isutf8 CLI

## Usage Examples
- "isutf8 --help"
- "isutf8 self version"

## Installation
```bash
apt-get install isutf8 2>/dev/null || which isutf8
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
