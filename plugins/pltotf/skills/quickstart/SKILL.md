# pltotf Plugin

CLI tool: pltotf.

## Commands
- `pltotf <resource> <action>` — Execute pltotf commands
- `pltotf self version` — Print pltotf version
- `pltotf _ _` — Passthrough to pltotf CLI

## Usage Examples
- "pltotf --help"
- "pltotf self version"

## Installation
```bash
apt-get install pltotf 2>/dev/null || which pltotf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
