# gtk4-launch Plugin

CLI tool: gtk4-launch.

## Commands
- `gtk4-launch <resource> <action>` — Execute gtk4-launch commands
- `gtk4-launch self version` — Print gtk4-launch version
- `gtk4-launch _ _` — Passthrough to gtk4-launch CLI

## Usage Examples
- "gtk4-launch --help"
- "gtk4-launch self version"

## Installation
```bash
apt-get install gtk4-launch 2>/dev/null || which gtk4-launch
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
