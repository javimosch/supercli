# ppmflash Plugin

CLI tool: ppmflash.

## Commands
- `ppmflash <resource> <action>` — Execute ppmflash commands
- `ppmflash self version` — Print ppmflash version
- `ppmflash _ _` — Passthrough to ppmflash CLI

## Usage Examples
- "ppmflash --help"
- "ppmflash self version"

## Installation
```bash
apt-get install ppmflash 2>/dev/null || which ppmflash
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
