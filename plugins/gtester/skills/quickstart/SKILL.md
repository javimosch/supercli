# gtester Plugin

CLI tool: gtester.

## Commands
- `gtester <resource> <action>` — Execute gtester commands
- `gtester self version` — Print gtester version
- `gtester _ _` — Passthrough to gtester CLI

## Usage Examples
- "gtester --help"
- "gtester self version"

## Installation
```bash
apt-get install gtester 2>/dev/null || which gtester
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
