# google-chrome-stable Plugin

CLI tool: google-chrome-stable.

## Commands
- `google-chrome-stable <resource> <action>` — Execute google-chrome-stable commands
- `google-chrome-stable self version` — Print google-chrome-stable version
- `google-chrome-stable _ _` — Passthrough to google-chrome-stable CLI

## Usage Examples
- "google-chrome-stable --help"
- "google-chrome-stable self version"

## Installation
```bash
apt-get install google-chrome-stable 2>/dev/null || which google-chrome-stable
```
