# pyrsa-encrypt Plugin

CLI tool: pyrsa-encrypt.

## Commands
- `pyrsa-encrypt <resource> <action>` — Execute pyrsa-encrypt commands
- `pyrsa-encrypt self version` — Print pyrsa-encrypt version
- `pyrsa-encrypt _ _` — Passthrough to pyrsa-encrypt CLI

## Usage Examples
- "pyrsa-encrypt --help"
- "pyrsa-encrypt self version"

```bash
apt-get install pyrsa-encrypt 2>/dev/null || which pyrsa-encrypt
```
