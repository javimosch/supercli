# unpack200 Plugin

CLI tool: unpack200.

## Commands
- `unpack200 <resource> <action>` — Execute unpack200 commands
- `unpack200 self version` — Print unpack200 version
- `unpack200 _ _` — Passthrough to unpack200 CLI

## Usage Examples
- "unpack200 --help"
- "unpack200 self version"

## Installation
```bash
apt-get install unpack200 2>/dev/null || which unpack200
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
