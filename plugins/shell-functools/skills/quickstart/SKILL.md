# shell-functools Plugin
Functional programming tools for shell pipelines

## Commands
- `shell-functools <resource> <action>` — Execute shell-functools commands
- `shell-functools _ _` — Passthrough to shell-functools CLI

## Usage
- `shell-functools _ _ <args>` — Run shell-functools with any arguments
