# skillhub Plugin

Self-hosted, open-source agent skill registry for enterprises. Publish & version skill packages, govern with RBAC and audit logs, deploy   on-premise with Docker or Kubernetes.

## Commands

### General
- `skillhub self version` — Print skillhub version
- `skillhub _ _` — Passthrough to skillhub CLI

## Usage Examples
- "Run skillhub"
- "Use skillhub to Self-hosted, open-source agent skill registry for enterprise"

## Installation

```bash
pip install skillhub
```

## Key Features
- Self-hosted, open-source agent skill registry for enterprises. Publish & version skill packages, gov
- CLI tool, headless and scriptable
