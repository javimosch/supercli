# mem Plugin

CLI tool: mem.

## Commands
- `mem <resource> <action>` — Execute mem commands
- `mem self version` — Print mem version
- `mem _ _` — Passthrough to mem CLI

## Usage Examples
- "mem --help"
- "mem self version"

## Installation
```bash
apt-get install mem 2>/dev/null || which mem
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
