# pictor Plugin

Image processing CLI — resize, convert, and optimize images in batch with JSON output

## Commands
- `pictor self version` — Print pictor version
- `pictor _ _` — Passthrough to pictor CLI

## Usage Examples
- `pictor self version` — Check installed version
- `pictor _ _ --help` — Show pictor help
- `pictor _ _ --json` — JSON output mode

## Installation
```bash
cargo install pictor
```

## Key Features
- image, processor, rust, cli
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
