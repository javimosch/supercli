# lvreduce Plugin

CLI tool: lvreduce.

## Commands
- `lvreduce <resource> <action>` — Execute lvreduce commands
- `lvreduce self version` — Print lvreduce version
- `lvreduce _ _` — Passthrough to lvreduce CLI

## Usage Examples
- "lvreduce --help"
- "lvreduce self version"

## Installation
```bash
apt-get install lvreduce 2>/dev/null || which lvreduce
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
