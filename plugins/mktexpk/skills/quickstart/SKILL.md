# mktexpk Plugin

CLI tool: mktexpk.

## Commands
- `mktexpk <resource> <action>` — Execute mktexpk commands
- `mktexpk self version` — Print mktexpk version
- `mktexpk _ _` — Passthrough to mktexpk CLI

## Usage Examples
- "mktexpk --help"
- "mktexpk self version"

## Installation
```bash
apt-get install mktexpk 2>/dev/null || which mktexpk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
