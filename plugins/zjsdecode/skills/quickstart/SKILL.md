# zjsdecode Plugin

zjsdecode — printer driver for ZjStream-based printers.

## Commands
- `zjsdecode <resource> <action>` — Execute zjsdecode commands
- `zjsdecode self version` — Print zjsdecode version
- `zjsdecode _ _` — Passthrough to zjsdecode CLI

## Usage Examples
- "zjsdecode --help"
- "zjsdecode self version"

## Installation
```bash
apt-get install printer-driver-foo2zjs 2>/dev/null || which zjsdecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
