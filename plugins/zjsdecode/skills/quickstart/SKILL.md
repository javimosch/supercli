# zjsdecode Plugin

CLI tool: zjsdecode.

## Commands
- `zjsdecode <resource> <action>` — Execute zjsdecode commands
- `zjsdecode self version` — Print zjsdecode version
- `zjsdecode _ _` — Passthrough to zjsdecode CLI

## Usage Examples
- "zjsdecode --help"
- "zjsdecode self version"

## Installation
```bash
apt-get install zjsdecode 2>/dev/null || which zjsdecode
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
