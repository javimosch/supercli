# Ruview Plugin

Turns commodity WiFi signals into real-time spatial intelligence and presence detection

## Commands
- `ruview _ _` — Passthrough to ruview CLI

## Installation

```bash
cargo install ruview
```

## Examples
```bash
ruview --help
ruview --version
```
