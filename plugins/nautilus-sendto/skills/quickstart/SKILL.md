# nautilus-sendto Plugin

CLI tool: nautilus-sendto.

## Commands
- `nautilus-sendto <resource> <action>` — Execute nautilus-sendto commands
- `nautilus-sendto self version` — Print nautilus-sendto version
- `nautilus-sendto _ _` — Passthrough to nautilus-sendto CLI

## Usage Examples
- "nautilus-sendto --help"
- "nautilus-sendto self version"

## Installation
```bash
apt-get install nautilus-sendto 2>/dev/null || which nautilus-sendto
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
