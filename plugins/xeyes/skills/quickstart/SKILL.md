# xeyes Plugin

CLI tool: xeyes.

## Commands
- `xeyes <resource> <action>` — Execute xeyes commands
- `xeyes self version` — Print xeyes version
- `xeyes _ _` — Passthrough to xeyes CLI

## Usage Examples
- "xeyes --help"
- "xeyes self version"

## Installation
```bash
apt-get install xeyes 2>/dev/null || which xeyes
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
