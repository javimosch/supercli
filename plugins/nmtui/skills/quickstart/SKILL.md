# nmtui Plugin

CLI tool: nmtui.

## Commands
- `nmtui <resource> <action>` — Execute nmtui commands
- `nmtui self version` — Print nmtui version
- `nmtui _ _` — Passthrough to nmtui CLI

## Usage Examples
- "nmtui --help"
- "nmtui self version"

## Installation
```bash
apt-get install nmtui 2>/dev/null || which nmtui
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
