# CLI-Anything Plugin

"CLI-Anything: Making ALL Software Agent-Native" -- CLI-Hub: https://clianything.cc/

## Commands
- `CLI-Anything <resource> <action>` — Execute CLI-Anything commands
- `CLI-Anything self version` — Print CLI-Anything version
- `CLI-Anything _ _` — Passthrough to cli-anything CLI

## Installation

```bash
pip install cli-anything
```
