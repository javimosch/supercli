# hciattach Plugin

CLI tool: hciattach.

## Commands
- `hciattach <resource> <action>` — Execute hciattach commands
- `hciattach self version` — Print hciattach version
- `hciattach _ _` — Passthrough to hciattach CLI

## Usage Examples
- "hciattach --help"
- "hciattach self version"

## Installation
```bash
apt-get install hciattach 2>/dev/null || which hciattach
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
