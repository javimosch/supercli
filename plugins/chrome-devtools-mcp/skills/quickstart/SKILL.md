# chrome-devtools-mcp Plugin

Chrome DevTools for coding agents

## Commands

### General
- `chrome-devtools-mcp self version` — Print chrome-devtools-mcp version
- `chrome-devtools-mcp _ _` — Passthrough to chrome-devtools-mcp CLI
