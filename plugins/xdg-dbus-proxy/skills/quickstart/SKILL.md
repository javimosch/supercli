# xdg-dbus-proxy Plugin

CLI tool: xdg-dbus-proxy.

## Commands
- `xdg-dbus-proxy <resource> <action>` — Execute xdg-dbus-proxy commands
- `xdg-dbus-proxy self version` — Print xdg-dbus-proxy version
- `xdg-dbus-proxy _ _` — Passthrough to xdg-dbus-proxy CLI

## Usage Examples
- "xdg-dbus-proxy --help"
- "xdg-dbus-proxy self version"

## Installation
```bash
apt-get install xdg-dbus-proxy 2>/dev/null || which xdg-dbus-proxy
```
