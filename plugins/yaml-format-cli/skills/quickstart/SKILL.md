# yaml-format-cli Plugin
CLI tool for yaml-format-cli.

## Commands
- `yaml-format-cli <resource> <action>` — Execute yaml-format-cli commands
- `yaml-format-cli _ _` — Passthrough to yaml-format-cli CLI

## Installation
```bash
cargo install yaml-format-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
