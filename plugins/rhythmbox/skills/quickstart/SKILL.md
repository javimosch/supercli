# rhythmbox Plugin

CLI tool: rhythmbox.

## Commands
- `rhythmbox <resource> <action>` — Execute rhythmbox commands
- `rhythmbox self version` — Print rhythmbox version
- `rhythmbox _ _` — Passthrough to rhythmbox CLI

## Usage Examples
- "rhythmbox --help"
- "rhythmbox self version"

## Installation
```bash
apt-get install rhythmbox 2>/dev/null || which rhythmbox
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
