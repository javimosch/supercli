# sbvarsign Plugin

CLI tool: sbvarsign.

## Commands
- `sbvarsign <resource> <action>` — Execute sbvarsign commands
- `sbvarsign self version` — Print sbvarsign version
- `sbvarsign _ _` — Passthrough to sbvarsign CLI

## Usage Examples
- "sbvarsign --help"
- "sbvarsign self version"

## Installation
```bash
apt-get install sbvarsign 2>/dev/null || which sbvarsign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
