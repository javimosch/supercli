# slugify Plugin

CLI tool: slugify.

## Commands
- `slugify <resource> <action>` — Execute slugify commands
- `slugify self version` — Print slugify version
- `slugify _ _` — Passthrough to slugify CLI

## Usage Examples
- "slugify --help"
- "slugify self version"

## Installation
```bash
apt-get install slugify 2>/dev/null || which slugify
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
