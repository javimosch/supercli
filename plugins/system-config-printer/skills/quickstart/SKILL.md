# system-config-printer Plugin

CLI tool: system-config-printer.

## Commands
- `system-config-printer <resource> <action>` — Execute system-config-printer commands
- `system-config-printer self version` — Print system-config-printer version
- `system-config-printer _ _` — Passthrough to system-config-printer CLI

## Usage Examples
- "system-config-printer --help"
- "system-config-printer self version"

## Installation
```bash
apt-get install system-config-printer 2>/dev/null || which system-config-printer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
