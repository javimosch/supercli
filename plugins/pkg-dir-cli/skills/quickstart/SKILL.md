# pkg-dir-cli Plugin
Find the root directory of a Node.js project

## Commands
- `pkg-dir-cli <resource> <action>` — Execute pkg-dir-cli commands
- `pkg-dir-cli _ _` — Passthrough to pkg-dir-cli CLI

## Usage
- `pkg-dir-cli _ _ <args>` — Run pkg-dir-cli with any arguments
