# texdoctk Plugin

CLI tool: texdoctk.

## Commands
- `texdoctk <resource> <action>` — Execute texdoctk commands
- `texdoctk self version` — Print texdoctk version
- `texdoctk _ _` — Passthrough to texdoctk CLI

## Usage Examples
- "texdoctk --help"
- "texdoctk self version"

## Installation
```bash
apt-get install texdoctk 2>/dev/null || which texdoctk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
