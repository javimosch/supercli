# pytest-benchmark Plugin

CLI tool: pytest-benchmark.

## Commands
- `pytest-benchmark <resource> <action>` — Execute pytest-benchmark commands
- `pytest-benchmark self version` — Print pytest-benchmark version
- `pytest-benchmark _ _` — Passthrough to pytest-benchmark CLI

## Usage Examples
- "pytest-benchmark --help"
- "pytest-benchmark self version"

## Installation
```bash
apt-get install pytest-benchmark 2>/dev/null || which pytest-benchmark
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
