# lorder Plugin

CLI tool: lorder.

## Commands
- `lorder <resource> <action>` — Execute lorder commands
- `lorder self version` — Print lorder version
- `lorder _ _` — Passthrough to lorder CLI

## Usage Examples
- "lorder --help"
- "lorder self version"

## Installation
```bash
apt-get install lorder 2>/dev/null || which lorder
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
