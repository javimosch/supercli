# texdoc Plugin

CLI tool: texdoc.

## Commands
- `texdoc <resource> <action>` — Execute texdoc commands
- `texdoc self version` — Print texdoc version
- `texdoc _ _` — Passthrough to texdoc CLI

## Usage Examples
- "texdoc --help"
- "texdoc self version"

## Installation
```bash
apt-get install texdoc 2>/dev/null || which texdoc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
