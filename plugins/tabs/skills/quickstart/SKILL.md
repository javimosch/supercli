# tabs Plugin

CLI tool: tabs.

## Commands
- `tabs <resource> <action>` — Execute tabs commands
- `tabs self version` — Print tabs version
- `tabs _ _` — Passthrough to tabs CLI

## Usage Examples
- "tabs --help"
- "tabs self version"

## Installation
```bash
apt-get install tabs 2>/dev/null || which tabs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
