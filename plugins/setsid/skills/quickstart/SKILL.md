# setsid Plugin

CLI tool: setsid.

## Commands
- `setsid <resource> <action>` — Execute setsid commands
- `setsid self version` — Print setsid version
- `setsid _ _` — Passthrough to setsid CLI

## Usage Examples
- "setsid --help"
- "setsid self version"

## Installation
```bash
apt-get install setsid 2>/dev/null || which setsid
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
