# yeetgif Plugin

GIF effects CLI in Go

## Commands
- `yeetgif self version` — Print version
- `yeetgif _ _` — Passthrough to yeetgif

## Installation
```bash
go install github.com/bitcrwr/yeetgif@latest
```
