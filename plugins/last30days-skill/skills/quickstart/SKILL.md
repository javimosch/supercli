# last30days-skill Plugin

AI agent skill that researches any topic across Reddit, X, YouTube, HN, Polymarket, and the web - then synthesizes a grounded summary

## Commands

### General
- `last30days-skill self version` — Print last30days-skill version
- `last30days-skill _ _` — Passthrough to last30days-skill CLI

## Usage Examples
- "Run last30days-skill"
- "Use last30days-skill to AI agent skill that researches any topic across Reddit, X, Y"

## Installation

```bash
pip install last30days-skill
```
