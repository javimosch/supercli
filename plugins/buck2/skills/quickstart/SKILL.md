# buck2 Plugin
Fast multi-language build system from Meta in Rust

## Commands
- `buck2 <resource> <action>` — Execute buck2 commands
- `buck2 _ _` — Passthrough to buck2 CLI

## Usage
- `buck2 _ _ <args>` — Run buck2 with any arguments
