# lm-sensors Plugin

lm-sensors reads hardware monitoring data.

## Usage Examples

- "show all sensor readings"
- "display CPU temperature only"
- "monitor fan speeds"
- "detect and configure sensor chips"

## Installation

```bash
brew install lm-sensors
```

## Key Features
- CPU temperature monitoring
- Fan speed readings
- Voltage measurements
- Hardware health checking
- Sensor chip detection
