# uuid-gen-cli Plugin
Quick UUID v4 generator for the terminal

## Commands
- `uuid-gen-cli <resource> <action>` — Execute uuid-gen-cli commands
- `uuid-gen-cli _ _` — Passthrough to uuid-gen-cli CLI

## Usage
- `uuid-gen-cli _ _ <args>` — Run uuid-gen-cli with any arguments
