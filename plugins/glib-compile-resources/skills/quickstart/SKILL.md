# glib-compile-resources Plugin

CLI tool: glib-compile-resources.

## Commands
- `glib-compile-resources <resource> <action>` — Execute glib-compile-resources commands
- `glib-compile-resources self version` — Print glib-compile-resources version
- `glib-compile-resources _ _` — Passthrough to glib-compile-resources CLI

## Usage Examples
- "glib-compile-resources --help"
- "glib-compile-resources self version"

## Installation
```bash
apt-get install glib-compile-resources 2>/dev/null || which glib-compile-resources
```
