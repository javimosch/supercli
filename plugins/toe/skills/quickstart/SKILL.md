# toe Plugin

CLI tool: toe.

## Commands
- `toe <resource> <action>` — Execute toe commands
- `toe self version` — Print toe version
- `toe _ _` — Passthrough to toe CLI

## Usage Examples
- "toe --help"
- "toe self version"

## Installation
```bash
apt-get install toe 2>/dev/null || which toe
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
