# App-Store-Connect-CLI Plugin

Fast, scriptable CLI for the App Store Connect API. Automate TestFlight, builds, submissions, signing, analytics, screenshots, subscriptions, and more. JSON-first, no interactive prompts

## Commands
- `App-Store-Connect-CLI <resource> <action>` — Execute App-Store-Connect-CLI commands
- `App-Store-Connect-CLI self version` — Print App-Store-Connect-CLI version
- `App-Store-Connect-CLI _ _` — Passthrough to app-store-connect-cli CLI

## Installation

```bash
pip install app-store-connect-cli
```
