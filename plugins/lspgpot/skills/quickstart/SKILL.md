# lspgpot Plugin

CLI tool: lspgpot.

## Commands
- `lspgpot <resource> <action>` — Execute lspgpot commands
- `lspgpot self version` — Print lspgpot version
- `lspgpot _ _` — Passthrough to lspgpot CLI

## Usage Examples
- "lspgpot --help"
- "lspgpot self version"

## Installation
```bash
apt-get install lspgpot 2>/dev/null || which lspgpot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
