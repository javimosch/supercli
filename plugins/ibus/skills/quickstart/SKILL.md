# ibus Plugin

CLI tool: ibus.

## Commands
- `ibus <resource> <action>` — Execute ibus commands
- `ibus self version` — Print ibus version
- `ibus _ _` — Passthrough to ibus CLI

## Usage Examples
- "ibus --help"
- "ibus self version"

## Installation
```bash
apt-get install ibus 2>/dev/null || which ibus
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
