# pkttyagent Plugin

CLI tool: pkttyagent.

## Commands
- `pkttyagent <resource> <action>` — Execute pkttyagent commands
- `pkttyagent self version` — Print pkttyagent version
- `pkttyagent _ _` — Passthrough to pkttyagent CLI

## Usage Examples
- "pkttyagent --help"
- "pkttyagent self version"

## Installation
```bash
apt-get install pkttyagent 2>/dev/null || which pkttyagent
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
