# xerox Plugin

CLI tool: xerox.

## Commands
- `xerox <resource> <action>` — Execute xerox commands
- `xerox self version` — Print xerox version
- `xerox _ _` — Passthrough to xerox CLI

## Usage Examples
- "xerox --help"
- "xerox self version"

## Installation
```bash
apt-get install xerox 2>/dev/null || which xerox
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
