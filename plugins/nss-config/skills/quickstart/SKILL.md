# nss-config Plugin

CLI tool: nss-config.

## Commands
- `nss-config <resource> <action>` — Execute nss-config commands
- `nss-config self version` — Print nss-config version
- `nss-config _ _` — Passthrough to nss-config CLI

## Usage Examples
- "nss-config --help"
- "nss-config self version"

## Installation
```bash
apt-get install nss-config 2>/dev/null || which nss-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
