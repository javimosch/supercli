# epub-convert Plugin
Convert documents between EPUB and other ebook formats

## Commands
- `epub-convert <resource> <action>` — Execute epub-convert commands
- `epub-convert _ _` — Passthrough to epub-convert CLI

## Usage
- `epub-convert _ _ <args>` — Run epub-convert with any arguments
