# aws-cli

AWS CLI — command-line interface for Amazon Web Services

## Install

```bash
brew install awscli
pipx install awscli
```

Verify installation:

```bash
which aws
```

## Commands

- `aws-cli self version` — print aws version
- `aws-cli cli run ...` — pass any arguments straight through to `aws`
