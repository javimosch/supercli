# gnome-shell-extension-prefs Plugin

CLI tool: gnome-shell-extension-prefs.

## Commands
- `gnome-shell-extension-prefs <resource> <action>` — Execute gnome-shell-extension-prefs commands
- `gnome-shell-extension-prefs self version` — Print gnome-shell-extension-prefs version
- `gnome-shell-extension-prefs _ _` — Passthrough to gnome-shell-extension-prefs CLI

## Usage Examples
- "gnome-shell-extension-prefs --help"
- "gnome-shell-extension-prefs self version"

## Installation
```bash
apt-get install gnome-shell-extension-prefs 2>/dev/null || which gnome-shell-extension-prefs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
