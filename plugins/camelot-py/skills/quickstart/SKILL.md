# camelot-py Plugin
Extract tables from PDFs with high accuracy CLI

## Commands
- `camelot-py <resource> <action>` — Execute camelot-py commands
- `camelot-py _ _` — Passthrough to camelot-py CLI

## Usage
- `camelot-py _ _ <args>` — Run camelot-py with any arguments
