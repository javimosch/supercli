# e4defrag Plugin

CLI tool: e4defrag.

## Commands
- `e4defrag <resource> <action>` — Execute e4defrag commands
- `e4defrag self version` — Print e4defrag version
- `e4defrag _ _` — Passthrough to e4defrag CLI

## Usage Examples
- "e4defrag --help"
- "e4defrag self version"

## Installation
```bash
apt-get install e4defrag 2>/dev/null || which e4defrag
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
