# zcat Plugin

CLI tool: zcat.

## Commands
- `zcat <resource> <action>` — Execute zcat commands
- `zcat self version` — Print zcat version
- `zcat _ _` — Passthrough to zcat CLI

## Usage Examples
- "zcat --help"
- "zcat self version"

## Installation
```bash
apt-get install zcat 2>/dev/null || which zcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
