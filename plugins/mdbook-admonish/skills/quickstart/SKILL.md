# mdbook-admonish Plugin
Callout and admonition support for mdBook documentation

## Commands
- `mdbook-admonish <resource> <action>` — Execute mdbook-admonish commands
- `mdbook-admonish _ _` — Passthrough to mdbook-admonish CLI

## Usage
- `mdbook-admonish _ _ <args>` — Run mdbook-admonish with any arguments
