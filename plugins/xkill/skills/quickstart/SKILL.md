# xkill Plugin

CLI tool: xkill.

## Commands
- `xkill <resource> <action>` — Execute xkill commands
- `xkill self version` — Print xkill version
- `xkill _ _` — Passthrough to xkill CLI

## Usage Examples
- "xkill --help"
- "xkill self version"

## Installation
```bash
apt-get install xkill 2>/dev/null || which xkill
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
