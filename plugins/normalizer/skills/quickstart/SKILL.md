# normalizer Plugin

CLI tool: normalizer.

## Commands
- `normalizer <resource> <action>` — Execute normalizer commands
- `normalizer self version` — Print normalizer version
- `normalizer _ _` — Passthrough to normalizer CLI

## Usage Examples
- "normalizer --help"
- "normalizer self version"

## Installation
```bash
apt-get install normalizer 2>/dev/null || which normalizer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
