# kanata Plugin
CLI tool for kanata.

## Commands
- `kanata <resource> <action>` — Execute kanata commands
- `kanata _ _` — Passthrough to kanata CLI

## Installation
```bash
cargo install kanata
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
