# nawk Plugin

CLI tool: nawk.

## Commands
- `nawk <resource> <action>` — Execute nawk commands
- `nawk self version` — Print nawk version
- `nawk _ _` — Passthrough to nawk CLI

## Usage Examples
- "nawk --help"
- "nawk self version"

## Installation
```bash
apt-get install nawk 2>/dev/null || which nawk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
