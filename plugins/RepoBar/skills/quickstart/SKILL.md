# RepoBar Plugin

Show status of GitHub Repos right in your menu bar and terminal: CI, Issues, Pull Requests, Latest Release.

## Commands

### General
- `RepoBar self version` — Print RepoBar version
- `RepoBar _ _` — Passthrough to repobar CLI

## Usage Examples
- "Run RepoBar"
- "Use repobar to Show status of GitHub Repos right in your menu bar and termi"

## Installation

```bash
pip install repobar
```

## Key Features
- Show status of GitHub Repos right in your menu bar and terminal: CI, Issues, Pull Requests, Latest R
- CLI tool, headless and scriptable
