# ttysvr Plugin
Terminal screensaver collection in Rust

## Commands
- `ttysvr <resource> <action>` — Execute ttysvr commands
- `ttysvr _ _` — Passthrough to ttysvr CLI

## Usage
- `ttysvr _ _ <args>` — Run ttysvr with any arguments
