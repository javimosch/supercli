# zramctl Plugin

CLI tool: zramctl.

## Commands
- `zramctl <resource> <action>` — Execute zramctl commands
- `zramctl self version` — Print zramctl version
- `zramctl _ _` — Passthrough to zramctl CLI

## Usage Examples
- "zramctl --help"
- "zramctl self version"

## Installation
```bash
apt-get install zramctl 2>/dev/null || which zramctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
