# freeflow Plugin

Free & fast alternative to Wispr Flow

## Commands

### General
- `freeflow self version` — Print freeflow version
- `freeflow _ _` — Passthrough to freeflow CLI

## Usage Examples
- "Run freeflow"
- "Use freeflow to Free & fast alternative to Wispr Flow"

## Installation

```bash
pip install freeflow
```

## Key Features
- Free & fast alternative to Wispr Flow
- CLI tool, headless and scriptable
