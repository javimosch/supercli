# gnome-session Plugin

CLI tool: gnome-session.

## Commands
- `gnome-session <resource> <action>` — Execute gnome-session commands
- `gnome-session self version` — Print gnome-session version
- `gnome-session _ _` — Passthrough to gnome-session CLI

## Usage Examples
- "gnome-session --help"
- "gnome-session self version"

## Installation
```bash
apt-get install gnome-session 2>/dev/null || which gnome-session
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
