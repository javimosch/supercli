# unar Plugin

unar — universal archive extractor supporting RAR, 7z, tar, gzip, bzip2, ZIP, ISO, CAB and 60+ formats

## Installation

```bash
brew install unar
Verify: unar --version
```

## Passthrough

```bash
sc unar _ _ <args...>
```

## SuperCLI

```bash
sc unar _ _ --help
sc plugins learn unar
```
