# raddebugger Plugin

A native, user-mode, multi-process, graphical debugger.

## Commands

### General
- `raddebugger self version` — Print raddebugger version
- `raddebugger _ _` — Passthrough to raddebugger CLI

## Usage Examples
- "Run raddebugger"
- "Use raddebugger to A native, user-mode, multi-process, graphical debugger."

## Installation

```bash
pip install raddebugger
```

## Key Features
- A native, user-mode, multi-process, graphical debugger.
- CLI tool, headless and scriptable
