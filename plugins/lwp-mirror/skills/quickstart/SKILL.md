# lwp-mirror Plugin

CLI tool: lwp-mirror.

## Commands
- `lwp-mirror <resource> <action>` — Execute lwp-mirror commands
- `lwp-mirror self version` — Print lwp-mirror version
- `lwp-mirror _ _` — Passthrough to lwp-mirror CLI

## Usage Examples
- "lwp-mirror --help"
- "lwp-mirror self version"

## Installation
```bash
apt-get install lwp-mirror 2>/dev/null || which lwp-mirror
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
