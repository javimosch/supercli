# mf Plugin

CLI tool: mf.

## Commands
- `mf <resource> <action>` — Execute mf commands
- `mf self version` — Print mf version
- `mf _ _` — Passthrough to mf CLI

## Usage Examples
- "mf --help"
- "mf self version"

## Installation
```bash
apt-get install mf 2>/dev/null || which mf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
