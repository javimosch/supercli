# python-audio-separator Plugin

Stem separation for audio files in Python

## Commands

### Operations
- `python-audio-separator self version` — Print python-audio-separator version
- `python-audio-separator _ _` — Passthrough to python-audio-separator CLI

## Usage Examples
- `python-audio-separator --help`
- `python-audio-separator <args>`

## Installation

```bash
pip install audio-separator
```

## Examples

```bash
python-audio-separator --version
python-audio-separator --help
```
