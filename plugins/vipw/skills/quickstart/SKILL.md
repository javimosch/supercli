# vipw Plugin

CLI tool: vipw.

## Commands
- `vipw <resource> <action>` — Execute vipw commands
- `vipw self version` — Print vipw version
- `vipw _ _` — Passthrough to vipw CLI

## Usage Examples
- "vipw --help"
- "vipw self version"

## Installation
```bash
apt-get install vipw 2>/dev/null || which vipw
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
