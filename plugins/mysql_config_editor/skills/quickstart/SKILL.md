# mysql_config_editor Plugin

CLI tool: mysql_config_editor.

## Commands
- `mysql_config_editor <resource> <action>` — Execute mysql_config_editor commands
- `mysql_config_editor self version` — Print mysql_config_editor version
- `mysql_config_editor _ _` — Passthrough to mysql_config_editor CLI

## Usage Examples
- "mysql_config_editor --help"
- "mysql_config_editor self version"

## Installation
```bash
apt-get install mysql_config_editor 2>/dev/null || which mysql_config_editor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
