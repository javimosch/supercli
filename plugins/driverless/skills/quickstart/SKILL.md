# driverless Plugin

CLI tool: driverless.

## Commands
- `driverless <resource> <action>` — Execute driverless commands
- `driverless self version` — Print driverless version
- `driverless _ _` — Passthrough to driverless CLI

## Usage Examples
- "driverless --help"
- "driverless self version"

## Installation
```bash
apt-get install driverless 2>/dev/null || which driverless
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
