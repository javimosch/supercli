# z2d Plugin

Pure Zig 2D graphics library

## Commands

### General
- `z2d self version` — Print z2d version
- `z2d _ _` — Passthrough to z2d CLI

## Usage Examples
- "Run z2d"
- "Use z2d to Pure Zig 2D graphics library"

## Installation

```bash
pip install z2d
```

## Key Features
- Pure Zig 2D graphics library
- CLI tool, headless and scriptable
