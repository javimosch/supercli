# peekfd Plugin

CLI tool: peekfd.

## Commands
- `peekfd <resource> <action>` — Execute peekfd commands
- `peekfd self version` — Print peekfd version
- `peekfd _ _` — Passthrough to peekfd CLI

## Usage Examples
- "peekfd --help"
- "peekfd self version"

## Installation
```bash
apt-get install peekfd 2>/dev/null || which peekfd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
