# pvmove Plugin

CLI tool: pvmove.

## Commands
- `pvmove <resource> <action>` — Execute pvmove commands
- `pvmove self version` — Print pvmove version
- `pvmove _ _` — Passthrough to pvmove CLI

## Usage Examples
- "pvmove --help"
- "pvmove self version"

## Installation
```bash
apt-get install pvmove 2>/dev/null || which pvmove
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
