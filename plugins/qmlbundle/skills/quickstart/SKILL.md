# qmlbundle Plugin

CLI tool: qmlbundle.

## Commands
- `qmlbundle <resource> <action>` — Execute qmlbundle commands
- `qmlbundle self version` — Print qmlbundle version
- `qmlbundle _ _` — Passthrough to qmlbundle CLI

## Usage Examples
- "qmlbundle --help"
- "qmlbundle self version"

## Installation
```bash
apt-get install qmlbundle 2>/dev/null || which qmlbundle
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
