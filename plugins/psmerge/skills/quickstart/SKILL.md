# psmerge Plugin

CLI tool: psmerge.

## Commands
- `psmerge <resource> <action>` — Execute psmerge commands
- `psmerge self version` — Print psmerge version
- `psmerge _ _` — Passthrough to psmerge CLI

## Usage Examples
- "psmerge --help"
- "psmerge self version"

## Installation
```bash
apt-get install psmerge 2>/dev/null || which psmerge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
