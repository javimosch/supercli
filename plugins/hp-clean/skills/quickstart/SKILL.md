# hp-clean Plugin

CLI tool: hp-clean.

## Commands
- `hp-clean <resource> <action>` — Execute hp-clean commands
- `hp-clean self version` — Print hp-clean version
- `hp-clean _ _` — Passthrough to hp-clean CLI

## Usage Examples
- "hp-clean --help"
- "hp-clean self version"

## Installation
```bash
apt-get install hp-clean 2>/dev/null || which hp-clean
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
