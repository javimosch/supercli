# packetdiag Plugin
Generate packet header diagrams from text specifications

## Commands
- `packetdiag <resource> <action>` — Execute packetdiag commands
- `packetdiag _ _` — Passthrough to packetdiag CLI

## Usage
- `packetdiag _ _ <args>` — Run packetdiag with any arguments
