# mimiclaw Plugin

MimiClaw: Run OpenClaw on a $5 chip. No OS(Linux). No Node.js. No Mac mini. No Raspberry Pi. No VPS. Hardware agents OS.

## Commands

### General
- `mimiclaw self version` — Print mimiclaw version
- `mimiclaw _ _` — Passthrough to mimiclaw CLI

## Usage Examples
- "Run mimiclaw"
- "Use mimiclaw to MimiClaw: Run OpenClaw on a $5 chip. No OS(Linux). No Node.j"

## Installation

```bash
pip install mimiclaw
```
