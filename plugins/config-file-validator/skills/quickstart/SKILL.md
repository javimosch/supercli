# config-file-validator Plugin

config-file-validator — cross-platform CLI tool to validate configuration files..

## Commands

### `sc config-file-validator config validate`
Validate configuration files.

### `sc config-file-validator self version`
Print version.

## Installation

```bash
go install github.com/Boeing/config-file-validator@latest
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
