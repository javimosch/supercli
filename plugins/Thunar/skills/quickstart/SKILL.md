# Thunar Plugin

CLI tool: Thunar.

## Commands
- `Thunar <resource> <action>` — Execute Thunar commands
- `Thunar self version` — Print Thunar version
- `Thunar _ _` — Passthrough to Thunar CLI

## Usage Examples
- "Thunar --help"
- "Thunar self version"

## Installation
```bash
apt-get install Thunar 2>/dev/null || which Thunar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
