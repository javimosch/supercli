# local-dream Plugin

Run Stable Diffusion on Android Devices with Snapdragon NPU acceleration. Also supports CPU/GPU inference.

## Commands

### General
- `local-dream self version` — Print local-dream version
- `local-dream _ _` — Passthrough to local-dream CLI
