# tzselect Plugin

CLI tool: tzselect.

## Commands
- `tzselect <resource> <action>` — Execute tzselect commands
- `tzselect self version` — Print tzselect version
- `tzselect _ _` — Passthrough to tzselect CLI

## Usage Examples
- "tzselect --help"
- "tzselect self version"

## Installation
```bash
apt-get install tzselect 2>/dev/null || which tzselect
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
