# isaset Plugin

CLI tool: isaset.

## Commands
- `isaset <resource> <action>` — Execute isaset commands
- `isaset self version` — Print isaset version
- `isaset _ _` — Passthrough to isaset CLI

## Usage Examples
- "isaset --help"
- "isaset self version"

## Installation
```bash
apt-get install isaset 2>/dev/null || which isaset
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
