# pw-play Plugin

CLI tool: pw-play.

## Commands
- `pw-play <resource> <action>` — Execute pw-play commands
- `pw-play self version` — Print pw-play version
- `pw-play _ _` — Passthrough to pw-play CLI

## Usage Examples
- "pw-play --help"
- "pw-play self version"

## Installation
```bash
apt-get install pw-play 2>/dev/null || which pw-play
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
