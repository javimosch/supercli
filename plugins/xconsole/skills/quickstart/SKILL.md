# xconsole Plugin

CLI tool: xconsole.

## Commands
- `xconsole <resource> <action>` — Execute xconsole commands
- `xconsole self version` — Print xconsole version
- `xconsole _ _` — Passthrough to xconsole CLI

## Usage Examples
- "xconsole --help"
- "xconsole self version"

## Installation
```bash
apt-get install xconsole 2>/dev/null || which xconsole
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
