# pydoc3 Plugin

CLI tool: pydoc3.

## Commands
- `pydoc3 <resource> <action>` — Execute pydoc3 commands
- `pydoc3 self version` — Print pydoc3 version
- `pydoc3 _ _` — Passthrough to pydoc3 CLI

## Usage Examples
- "pydoc3 --help"
- "pydoc3 self version"

## Installation
```bash
apt-get install pydoc3 2>/dev/null || which pydoc3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
