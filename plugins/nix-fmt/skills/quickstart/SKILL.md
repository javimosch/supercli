# nix-fmt Plugin
Experimental formatter for Nix expression language files

## Commands
- `nix-fmt <resource> <action>` — Execute nix-fmt commands
- `nix-fmt _ _` — Passthrough to nix-fmt CLI

## Usage
- `nix-fmt _ _ <args>` — Run nix-fmt with any arguments
