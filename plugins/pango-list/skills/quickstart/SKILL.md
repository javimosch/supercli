# pango-list Plugin

CLI tool: pango-list.

## Commands
- `pango-list <resource> <action>` — Execute pango-list commands
- `pango-list self version` — Print pango-list version
- `pango-list _ _` — Passthrough to pango-list CLI

## Usage Examples
- "pango-list --help"
- "pango-list self version"

## Installation
```bash
apt-get install pango-list 2>/dev/null || which pango-list
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
