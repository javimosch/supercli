# msgcat Plugin

CLI tool: msgcat.

## Commands
- `msgcat <resource> <action>` — Execute msgcat commands
- `msgcat self version` — Print msgcat version
- `msgcat _ _` — Passthrough to msgcat CLI

## Usage Examples
- "msgcat --help"
- "msgcat self version"

## Installation
```bash
apt-get install msgcat 2>/dev/null || which msgcat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
