# google-chrome Plugin

CLI tool: google-chrome.

## Commands
- `google-chrome <resource> <action>` — Execute google-chrome commands
- `google-chrome self version` — Print google-chrome version
- `google-chrome _ _` — Passthrough to google-chrome CLI

## Usage Examples
- "google-chrome --help"
- "google-chrome self version"

## Installation
```bash
apt-get install google-chrome 2>/dev/null || which google-chrome
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
