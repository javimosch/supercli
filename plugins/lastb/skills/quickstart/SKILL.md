# lastb Plugin

CLI tool: lastb.

## Commands
- `lastb <resource> <action>` — Execute lastb commands
- `lastb self version` — Print lastb version
- `lastb _ _` — Passthrough to lastb CLI

## Usage Examples
- "lastb --help"
- "lastb self version"

## Installation
```bash
apt-get install lastb 2>/dev/null || which lastb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
