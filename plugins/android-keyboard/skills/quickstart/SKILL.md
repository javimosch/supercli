# android-keyboard Plugin

Official FUTO Keyboard Issue Tracker and Source Mirror of https://gitlab.futo.org/keyboard/latinime

## Commands

### General
- `android-keyboard self version` — Print android-keyboard version
- `android-keyboard _ _` — Passthrough to android-keyboard CLI
