# parecord Plugin

CLI tool: parecord.

## Commands
- `parecord <resource> <action>` — Execute parecord commands
- `parecord self version` — Print parecord version
- `parecord _ _` — Passthrough to parecord CLI

## Usage Examples
- "parecord --help"
- "parecord self version"

## Installation
```bash
apt-get install parecord 2>/dev/null || which parecord
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
