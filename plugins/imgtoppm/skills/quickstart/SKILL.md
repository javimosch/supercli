# imgtoppm Plugin

CLI tool: imgtoppm.

## Commands
- `imgtoppm <resource> <action>` — Execute imgtoppm commands
- `imgtoppm self version` — Print imgtoppm version
- `imgtoppm _ _` — Passthrough to imgtoppm CLI

## Usage Examples
- "imgtoppm --help"
- "imgtoppm self version"

## Installation
```bash
apt-get install imgtoppm 2>/dev/null || which imgtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
