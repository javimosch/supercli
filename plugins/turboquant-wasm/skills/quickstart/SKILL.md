# turboquant-wasm Plugin

WASM SIMD vector compression

## Commands

### Version
`turboquant-wasm self version` — Print turboquant-wasm version

### Passthrough
`turboquant-wasm _ _` — Passthrough to turboquant CLI with all arguments forwarded.

## Usage Examples

```bash
turboquant --version
turboquant --help
```

## Installation

```bash
cargo install turboquant-wasm
```

## Key Features
- WASM SIMD vector compression
