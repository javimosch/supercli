# xzcmp Plugin

CLI tool: xzcmp.

## Commands
- `xzcmp <resource> <action>` — Execute xzcmp commands
- `xzcmp self version` — Print xzcmp version
- `xzcmp _ _` — Passthrough to xzcmp CLI

## Usage Examples
- "xzcmp --help"
- "xzcmp self version"

## Installation
```bash
apt-get install xzcmp 2>/dev/null || which xzcmp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
