# usecomputer Plugin

Fast computer automation CLI for AI agents. Control any desktop with screenshots, clicks, typing, scrolling, and more.

## Commands

### General
- `usecomputer self version` — Print usecomputer version
- `usecomputer _ _` — Passthrough to usecomputer CLI

## Usage Examples
- "Run usecomputer"
- "Use usecomputer to Fast computer automation CLI for AI agents. Control any desk"

## Installation

```bash
pip install usecomputer
```
