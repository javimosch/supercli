# groupmems Plugin

CLI tool: groupmems.

## Commands
- `groupmems <resource> <action>` — Execute groupmems commands
- `groupmems self version` — Print groupmems version
- `groupmems _ _` — Passthrough to groupmems CLI

## Usage Examples
- "groupmems --help"
- "groupmems self version"

## Installation
```bash
apt-get install groupmems 2>/dev/null || which groupmems
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
