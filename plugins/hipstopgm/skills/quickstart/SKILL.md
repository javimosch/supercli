# hipstopgm Plugin

CLI tool: hipstopgm.

## Commands
- `hipstopgm <resource> <action>` — Execute hipstopgm commands
- `hipstopgm self version` — Print hipstopgm version
- `hipstopgm _ _` — Passthrough to hipstopgm CLI

## Usage Examples
- "hipstopgm --help"
- "hipstopgm self version"

## Installation
```bash
apt-get install hipstopgm 2>/dev/null || which hipstopgm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
