# InstaEclipse Plugin

An Instagram Xposed module with features like Developer Options, Ghost Mode, Ad-Free browsing, and Distraction-Free Mode.

## Commands

### General
- `InstaEclipse self version` — Print InstaEclipse version
- `InstaEclipse _ _` — Passthrough to instaeclipse CLI
