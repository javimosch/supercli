# kbdinfo Plugin

CLI tool: kbdinfo.

## Commands
- `kbdinfo <resource> <action>` — Execute kbdinfo commands
- `kbdinfo self version` — Print kbdinfo version
- `kbdinfo _ _` — Passthrough to kbdinfo CLI

## Usage Examples
- "kbdinfo --help"
- "kbdinfo self version"

## Installation
```bash
apt-get install kbdinfo 2>/dev/null || which kbdinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
