# x86_64-linux-gnu-as Plugin

x86_64-linux-gnu-as — GNU binary utilities, for x86-64-linux-gnu target.

## Commands
- `x86_64-linux-gnu-as <resource> <action>` — Execute x86_64-linux-gnu-as commands
- `x86_64-linux-gnu-as self version` — Print x86_64-linux-gnu-as version
- `x86_64-linux-gnu-as _ _` — Passthrough to x86_64-linux-gnu-as CLI

## Usage Examples
- "x86_64-linux-gnu-as --help"
- "x86_64-linux-gnu-as self version"

## Installation
```bash
apt-get install binutils-x86-64-linux-gnu 2>/dev/null || which x86_64-linux-gnu-as
```
