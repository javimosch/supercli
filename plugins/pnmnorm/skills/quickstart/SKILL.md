# pnmnorm Plugin

CLI tool: pnmnorm.

## Commands
- `pnmnorm <resource> <action>` — Execute pnmnorm commands
- `pnmnorm self version` — Print pnmnorm version
- `pnmnorm _ _` — Passthrough to pnmnorm CLI

## Usage Examples
- "pnmnorm --help"
- "pnmnorm self version"

## Installation
```bash
apt-get install pnmnorm 2>/dev/null || which pnmnorm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
