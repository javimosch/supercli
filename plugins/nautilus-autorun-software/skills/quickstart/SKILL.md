# nautilus-autorun-software Plugin

CLI tool: nautilus-autorun-software.

## Commands
- `nautilus-autorun-software <resource> <action>` — Execute nautilus-autorun-software commands
- `nautilus-autorun-software self version` — Print nautilus-autorun-software version
- `nautilus-autorun-software _ _` — Passthrough to nautilus-autorun-software CLI

## Usage Examples
- "nautilus-autorun-software --help"
- "nautilus-autorun-software self version"
