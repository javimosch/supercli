# gsnd Plugin

CLI tool: gsnd.

## Commands
- `gsnd <resource> <action>` — Execute gsnd commands
- `gsnd self version` — Print gsnd version
- `gsnd _ _` — Passthrough to gsnd CLI

## Usage Examples
- "gsnd --help"
- "gsnd self version"

## Installation
```bash
apt-get install gsnd 2>/dev/null || which gsnd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
