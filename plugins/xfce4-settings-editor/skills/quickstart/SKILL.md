# xfce4-settings-editor Plugin

CLI tool: xfce4-settings-editor.

## Commands
- `xfce4-settings-editor <resource> <action>` — Execute xfce4-settings-editor commands
- `xfce4-settings-editor self version` — Print xfce4-settings-editor version
- `xfce4-settings-editor _ _` — Passthrough to xfce4-settings-editor CLI

## Usage Examples
- "xfce4-settings-editor --help"
- "xfce4-settings-editor self version"

## Installation
```bash
apt-get install xfce4-settings-editor 2>/dev/null || which xfce4-settings-editor
```
