# otp2ocp Plugin

CLI tool: otp2ocp.

## Commands
- `otp2ocp <resource> <action>` — Execute otp2ocp commands
- `otp2ocp self version` — Print otp2ocp version
- `otp2ocp _ _` — Passthrough to otp2ocp CLI

## Usage Examples
- "otp2ocp --help"
- "otp2ocp self version"

## Installation
```bash
apt-get install otp2ocp 2>/dev/null || which otp2ocp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
