# lodraw Plugin

CLI tool: lodraw.

## Commands
- `lodraw <resource> <action>` — Execute lodraw commands
- `lodraw self version` — Print lodraw version
- `lodraw _ _` — Passthrough to lodraw CLI

## Usage Examples
- "lodraw --help"
- "lodraw self version"

## Installation
```bash
apt-get install lodraw 2>/dev/null || which lodraw
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
