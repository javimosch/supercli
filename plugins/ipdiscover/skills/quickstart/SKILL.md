# ipdiscover Plugin

CLI tool: ipdiscover.

## Commands
- `ipdiscover <resource> <action>` — Execute ipdiscover commands
- `ipdiscover self version` — Print ipdiscover version
- `ipdiscover _ _` — Passthrough to ipdiscover CLI

## Usage Examples
- "ipdiscover --help"
- "ipdiscover self version"

## Installation
```bash
apt-get install ipdiscover 2>/dev/null || which ipdiscover
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
