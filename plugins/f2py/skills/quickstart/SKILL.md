# f2py Plugin

CLI tool: f2py.

## Commands
- `f2py <resource> <action>` — Execute f2py commands
- `f2py self version` — Print f2py version
- `f2py _ _` — Passthrough to f2py CLI

## Usage Examples
- "f2py --help"
- "f2py self version"

## Installation
```bash
apt-get install f2py 2>/dev/null || which f2py
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
