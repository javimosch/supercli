# gnome-session-classic Plugin

CLI tool: gnome-session-classic.

## Commands
- `gnome-session-classic <resource> <action>` — Execute gnome-session-classic commands
- `gnome-session-classic self version` — Print gnome-session-classic version
- `gnome-session-classic _ _` — Passthrough to gnome-session-classic CLI

## Usage Examples
- "gnome-session-classic --help"
- "gnome-session-classic self version"

## Installation
```bash
apt-get install gnome-session-classic 2>/dev/null || which gnome-session-classic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
