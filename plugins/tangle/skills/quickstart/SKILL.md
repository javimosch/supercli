# tangle Plugin

CLI tool: tangle.

## Commands
- `tangle <resource> <action>` — Execute tangle commands
- `tangle self version` — Print tangle version
- `tangle _ _` — Passthrough to tangle CLI

## Usage Examples
- "tangle --help"
- "tangle self version"

## Installation
```bash
apt-get install tangle 2>/dev/null || which tangle
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
