# hgrep Plugin
grep with human-friendly, syntax-highlighted output and surrounding context

## Commands
- `hgrep <resource> <action>` — Execute hgrep commands
- `hgrep self version` — Print hgrep version
- `hgrep _ _` — Passthrough to hgrep CLI
