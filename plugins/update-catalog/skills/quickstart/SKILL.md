# update-catalog Plugin

CLI tool: update-catalog.

## Commands
- `update-catalog <resource> <action>` — Execute update-catalog commands
- `update-catalog self version` — Print update-catalog version
- `update-catalog _ _` — Passthrough to update-catalog CLI

apt-get install update-catalog 2>/dev/null || which update-catalog
