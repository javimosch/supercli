# windows Plugin

Windows inside a Docker container.

## Commands

### General
- `windows self version` — Print windows version
- `windows _ _` — Passthrough to windows CLI

## Usage Examples
- "Run windows"
- "Use windows to Windows inside a Docker container."

## Installation

```bash
pip install windows
```

## Key Features
- Windows inside a Docker container.
- CLI tool, headless and scriptable
