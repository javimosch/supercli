# msgcomm Plugin

CLI tool: msgcomm.

## Commands
- `msgcomm <resource> <action>` — Execute msgcomm commands
- `msgcomm self version` — Print msgcomm version
- `msgcomm _ _` — Passthrough to msgcomm CLI

## Usage Examples
- "msgcomm --help"
- "msgcomm self version"

## Installation
```bash
apt-get install msgcomm 2>/dev/null || which msgcomm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
