# ncursesw5-config Plugin

CLI tool: ncursesw5-config.

## Commands
- `ncursesw5-config <resource> <action>` — Execute ncursesw5-config commands
- `ncursesw5-config self version` — Print ncursesw5-config version
- `ncursesw5-config _ _` — Passthrough to ncursesw5-config CLI

## Usage Examples
- "ncursesw5-config --help"
- "ncursesw5-config self version"

## Installation
```bash
apt-get install ncursesw5-config 2>/dev/null || which ncursesw5-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
