# twopi Plugin

CLI tool: twopi.

## Commands
- `twopi <resource> <action>` — Execute twopi commands
- `twopi self version` — Print twopi version
- `twopi _ _` — Passthrough to twopi CLI

## Usage Examples
- "twopi --help"
- "twopi self version"

## Installation
```bash
apt-get install twopi 2>/dev/null || which twopi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
