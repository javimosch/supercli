# ImmortalWrt-ImageBuilder Plugin

它是一个工作流。可快速构建 可选docker、可选自定义固件大小的 immortalWrt。它相当于一个云端的ImageBuilder,属于构建的范畴,不算是编译。目前也支持第三方插件的按需集成。

## Commands

### General
- `ImmortalWrt-ImageBuilder self version` — Print ImmortalWrt-ImageBuilder version
- `ImmortalWrt-ImageBuilder _ _` — Passthrough to immortalwrt-imagebuilder CLI
