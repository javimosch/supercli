# voxtral.c Plugin

Pure C inference of Mistral Voxtral Realtime 4B speech to text model

## Commands

### General
- `voxtral.c self version` — Print voxtral.c version
- `voxtral.c _ _` — Passthrough to voxtral.c CLI

- "Run voxtral.c"

## Installation

```bash
pip install voxtral.c
```

## Key Features
- Pure C inference of Mistral Voxtral Realtime 4B speech to text model
- CLI tool, headless and scriptable
