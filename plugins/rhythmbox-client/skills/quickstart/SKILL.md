# rhythmbox-client Plugin

CLI tool: rhythmbox-client.

## Commands
- `rhythmbox-client <resource> <action>` — Execute rhythmbox-client commands
- `rhythmbox-client self version` — Print rhythmbox-client version
- `rhythmbox-client _ _` — Passthrough to rhythmbox-client CLI

## Usage Examples
- "rhythmbox-client --help"
- "rhythmbox-client self version"

## Installation
```bash
apt-get install rhythmbox-client 2>/dev/null || which rhythmbox-client
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
