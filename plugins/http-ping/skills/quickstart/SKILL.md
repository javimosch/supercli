# http-ping
http-ping — HTTP endpoint latency checker. Pings a URL N times and reports min/max/avg/p95 latency in ms, plus success/fail counts.

## Commands
- `http-ping <resource> <action>` — Execute http-ping commands
- `http ping run` — http-ping — HTTP endpoint latency checker. Pings a URL N times and reports min/max/avg/p95 latency in ms, plus success/fail counts.
