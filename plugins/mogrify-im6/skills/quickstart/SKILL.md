# mogrify-im6 Plugin

CLI tool: mogrify-im6.

## Commands
- `mogrify-im6 <resource> <action>` — Execute mogrify-im6 commands
- `mogrify-im6 self version` — Print mogrify-im6 version
- `mogrify-im6 _ _` — Passthrough to mogrify-im6 CLI

## Usage Examples
- "mogrify-im6 --help"
- "mogrify-im6 self version"
