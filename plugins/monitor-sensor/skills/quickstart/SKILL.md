# monitor-sensor Plugin

CLI tool: monitor-sensor.

## Commands
- `monitor-sensor <resource> <action>` — Execute monitor-sensor commands
- `monitor-sensor self version` — Print monitor-sensor version
- `monitor-sensor _ _` — Passthrough to monitor-sensor CLI

## Usage Examples
- "monitor-sensor --help"
- "monitor-sensor self version"

## Installation
```bash
apt-get install monitor-sensor 2>/dev/null || which monitor-sensor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
