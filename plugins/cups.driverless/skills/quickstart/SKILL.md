# cups.driverless Plugin

CLI tool: cups.driverless.

## Commands
- `cups.driverless <resource> <action>` — Execute cups.driverless commands
- `cups.driverless self version` — Print cups.driverless version
- `cups.driverless _ _` — Passthrough to cups.driverless CLI

## Usage Examples
- "cups.driverless --help"
- "cups.driverless self version"

## Installation
```bash
apt-get install cups.driverless 2>/dev/null || which cups.driverless
```
