# pw-mididump Plugin

CLI tool: pw-mididump.

## Commands
- `pw-mididump <resource> <action>` — Execute pw-mididump commands
- `pw-mididump self version` — Print pw-mididump version
- `pw-mididump _ _` — Passthrough to pw-mididump CLI

## Usage Examples
- "pw-mididump --help"
- "pw-mididump self version"

## Installation
```bash
apt-get install pw-mididump 2>/dev/null || which pw-mididump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
