# pdftohtml Plugin

CLI tool: pdftohtml.

## Commands
- `pdftohtml <resource> <action>` — Execute pdftohtml commands
- `pdftohtml self version` — Print pdftohtml version
- `pdftohtml _ _` — Passthrough to pdftohtml CLI

## Usage Examples
- "pdftohtml --help"
- "pdftohtml self version"

## Installation
```bash
apt-get install pdftohtml 2>/dev/null || which pdftohtml
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
