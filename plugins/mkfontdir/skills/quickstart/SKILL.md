# mkfontdir Plugin

CLI tool: mkfontdir.

## Commands
- `mkfontdir <resource> <action>` — Execute mkfontdir commands
- `mkfontdir self version` — Print mkfontdir version
- `mkfontdir _ _` — Passthrough to mkfontdir CLI

## Usage Examples
- "mkfontdir --help"
- "mkfontdir self version"

## Installation
```bash
apt-get install mkfontdir 2>/dev/null || which mkfontdir
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
