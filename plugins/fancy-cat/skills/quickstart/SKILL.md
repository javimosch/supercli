# fancy-cat Plugin

PDF reader for terminal emulators using the Kitty image protocol

## Commands

### General
- `fancy-cat self version` — Print fancy-cat version
- `fancy-cat _ _` — Passthrough to fancy-cat CLI

## Usage Examples
- "Run fancy-cat"
- "Use fancy-cat to PDF reader for terminal emulators using the Kitty image prot"

## Installation

```bash
pip install fancy-cat
```

## Key Features
- PDF reader for terminal emulators using the Kitty image protocol
- CLI tool, headless and scriptable
