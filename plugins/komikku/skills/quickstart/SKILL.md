# komikku Plugin

Free and open source manga reader for Android

## Commands

### General
- `komikku self version` — Print komikku version
- `komikku _ _` — Passthrough to komikku CLI

## Usage Examples
- "Run komikku"
- "Use komikku to Free and open source manga reader for Android"

## Installation

```bash
pip install komikku
```

## Key Features
- Free and open source manga reader for Android
- CLI tool, headless and scriptable
