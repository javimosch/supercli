# virtualboxvm Plugin

virtualboxvm — x86 virtualization solution - Qt based user interface.

## Commands
- `virtualboxvm <resource> <action>` — Execute virtualboxvm commands
- `virtualboxvm self version` — Print virtualboxvm version
- `virtualboxvm _ _` — Passthrough to virtualboxvm CLI

## Usage Examples
- "virtualboxvm --help"
- "virtualboxvm self version"

## Installation
```bash
apt-get install virtualbox-qt 2>/dev/null || which virtualboxvm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
