# rc Plugin

CLI tool: rc.

## Commands
- `rc <resource> <action>` — Execute rc commands
- `rc self version` — Print rc version
- `rc _ _` — Passthrough to rc CLI

## Usage Examples
- "rc --help"
- "rc self version"

## Installation
```bash
apt-get install rc 2>/dev/null || which rc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
