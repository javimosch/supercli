# pipewire Plugin

CLI tool: pipewire.

## Commands
- `pipewire <resource> <action>` — Execute pipewire commands
- `pipewire self version` — Print pipewire version
- `pipewire _ _` — Passthrough to pipewire CLI

## Usage Examples
- "pipewire --help"
- "pipewire self version"

## Installation
```bash
apt-get install pipewire 2>/dev/null || which pipewire
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
