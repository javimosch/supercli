# pdvitype Plugin

CLI tool: pdvitype.

## Commands
- `pdvitype <resource> <action>` — Execute pdvitype commands
- `pdvitype self version` — Print pdvitype version
- `pdvitype _ _` — Passthrough to pdvitype CLI

## Usage Examples
- "pdvitype --help"
- "pdvitype self version"

## Installation
```bash
apt-get install pdvitype 2>/dev/null || which pdvitype
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
