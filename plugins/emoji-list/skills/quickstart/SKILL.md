# emoji-list Plugin
List directory contents using folder and file emojis

## Commands
- `emoji-list <resource> <action>` — Execute emoji-list commands
- `emoji-list _ _` — Passthrough to emoji-list CLI

## Usage
- `emoji-list _ _ <args>` — Run emoji-list with any arguments
