# gemtopbm Plugin

CLI tool: gemtopbm.

## Commands
- `gemtopbm <resource> <action>` — Execute gemtopbm commands
- `gemtopbm self version` — Print gemtopbm version
- `gemtopbm _ _` — Passthrough to gemtopbm CLI

## Usage Examples
- "gemtopbm --help"
- "gemtopbm self version"

## Installation
```bash
apt-get install gemtopbm 2>/dev/null || which gemtopbm
```
