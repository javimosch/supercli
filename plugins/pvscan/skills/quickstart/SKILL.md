# pvscan Plugin

CLI tool: pvscan.

## Commands
- `pvscan <resource> <action>` — Execute pvscan commands
- `pvscan self version` — Print pvscan version
- `pvscan _ _` — Passthrough to pvscan CLI

## Usage Examples
- "pvscan --help"
- "pvscan self version"

## Installation
```bash
apt-get install pvscan 2>/dev/null || which pvscan
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
