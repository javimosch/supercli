# gimp-console Plugin

CLI tool: gimp-console.

## Commands
- `gimp-console <resource> <action>` — Execute gimp-console commands
- `gimp-console self version` — Print gimp-console version
- `gimp-console _ _` — Passthrough to gimp-console CLI

## Usage Examples
- "gimp-console --help"
- "gimp-console self version"

## Installation
```bash
apt-get install gimp-console 2>/dev/null || which gimp-console
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
