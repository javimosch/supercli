# terrastruct-cli Plugin
Declarative diagram engine for technical documentation

## Commands
- `terrastruct-cli <resource> <action>` — Execute terrastruct-cli commands
- `terrastruct-cli _ _` — Passthrough to terrastruct-cli CLI

## Usage
- `terrastruct-cli _ _ <args>` — Run terrastruct-cli with any arguments
