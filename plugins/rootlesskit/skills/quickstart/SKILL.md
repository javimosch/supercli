# rootlesskit Plugin

CLI tool: rootlesskit.

## Commands
- `rootlesskit <resource> <action>` — Execute rootlesskit commands
- `rootlesskit self version` — Print rootlesskit version
- `rootlesskit _ _` — Passthrough to rootlesskit CLI

## Usage Examples
- "rootlesskit --help"
- "rootlesskit self version"

## Installation
```bash
apt-get install rootlesskit 2>/dev/null || which rootlesskit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
