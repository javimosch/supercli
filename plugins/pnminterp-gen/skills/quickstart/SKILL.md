# pnminterp-gen Plugin

CLI tool: pnminterp-gen.

## Commands
- `pnminterp-gen <resource> <action>` — Execute pnminterp-gen commands
- `pnminterp-gen self version` — Print pnminterp-gen version
- `pnminterp-gen _ _` — Passthrough to pnminterp-gen CLI

## Usage Examples
- "pnminterp-gen --help"
- "pnminterp-gen self version"

## Installation
```bash
apt-get install pnminterp-gen 2>/dev/null || which pnminterp-gen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
