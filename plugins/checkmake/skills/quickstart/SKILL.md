# checkmake
checkmake — Makefile linter. Analyzes Makefiles for common errors, antipatterns, and style issues.

## Commands
- `checkmake <resource> <action>` — Execute checkmake commands
- `checkmake self version` — Print checkmake version
- `checkmake _ _` — Passthrough to checkmake CLI
