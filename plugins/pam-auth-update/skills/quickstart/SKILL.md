# pam-auth-update Plugin

CLI tool: pam-auth-update.

## Commands
- `pam-auth-update <resource> <action>` — Execute pam-auth-update commands
- `pam-auth-update self version` — Print pam-auth-update version
- `pam-auth-update _ _` — Passthrough to pam-auth-update CLI

## Usage Examples
- "pam-auth-update --help"
- "pam-auth-update self version"

## Installation
```bash
apt-get install pam-auth-update 2>/dev/null || which pam-auth-update
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
