# rawtopgm Plugin

CLI tool: rawtopgm.

## Commands
- `rawtopgm <resource> <action>` — Execute rawtopgm commands
- `rawtopgm self version` — Print rawtopgm version
- `rawtopgm _ _` — Passthrough to rawtopgm CLI

## Usage Examples
- "rawtopgm --help"
- "rawtopgm self version"

## Installation
```bash
apt-get install rawtopgm 2>/dev/null || which rawtopgm
```

- Scriptable and automatable
- Pipeline-ready output
