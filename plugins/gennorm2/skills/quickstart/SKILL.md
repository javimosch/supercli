# gennorm2 Plugin

CLI tool: gennorm2.

## Commands
- `gennorm2 <resource> <action>` — Execute gennorm2 commands
- `gennorm2 self version` — Print gennorm2 version
- `gennorm2 _ _` — Passthrough to gennorm2 CLI

## Usage Examples
- "gennorm2 --help"
- "gennorm2 self version"

## Installation
```bash
apt-get install gennorm2 2>/dev/null || which gennorm2
```
