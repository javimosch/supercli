# gts2oogl Plugin

CLI tool: gts2oogl.

## Commands
- `gts2oogl <resource> <action>` — Execute gts2oogl commands
- `gts2oogl self version` — Print gts2oogl version
- `gts2oogl _ _` — Passthrough to gts2oogl CLI

## Usage Examples
- "gts2oogl --help"
- "gts2oogl self version"

## Installation
```bash
apt-get install gts2oogl 2>/dev/null || which gts2oogl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
