# json-flatten
json-flatten — flatten nested JSON to dot-notation keys (e.g., {'user.name':'Alice'}). Handles arrays with index notation.

## Commands
- `json-flatten <resource> <action>` — Execute json-flatten commands
- `json flatten run` — json-flatten — flatten nested JSON to dot-notation keys (e.g., {'user.name':'Alice'}). Handles arrays with index notation.
