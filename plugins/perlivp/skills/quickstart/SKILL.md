# perlivp Plugin

CLI tool: perlivp.

## Commands
- `perlivp <resource> <action>` — Execute perlivp commands
- `perlivp self version` — Print perlivp version
- `perlivp _ _` — Passthrough to perlivp CLI

## Usage Examples
- "perlivp --help"
- "perlivp self version"

## Installation
```bash
apt-get install perlivp 2>/dev/null || which perlivp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
