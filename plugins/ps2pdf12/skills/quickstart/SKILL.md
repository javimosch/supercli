# ps2pdf12 Plugin

CLI tool: ps2pdf12.

## Commands
- `ps2pdf12 <resource> <action>` — Execute ps2pdf12 commands
- `ps2pdf12 self version` — Print ps2pdf12 version
- `ps2pdf12 _ _` — Passthrough to ps2pdf12 CLI

## Usage Examples
- "ps2pdf12 --help"
- "ps2pdf12 self version"

## Installation
```bash
apt-get install ps2pdf12 2>/dev/null || which ps2pdf12
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
