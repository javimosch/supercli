# xbrnetwork Plugin

CLI tool: xbrnetwork.

## Commands
- `xbrnetwork <resource> <action>` — Execute xbrnetwork commands
- `xbrnetwork self version` — Print xbrnetwork version
- `xbrnetwork _ _` — Passthrough to xbrnetwork CLI

## Usage Examples
- "xbrnetwork --help"
- "xbrnetwork self version"

## Installation
```bash
apt-get install xbrnetwork 2>/dev/null || which xbrnetwork
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
