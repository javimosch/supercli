# rscreen Plugin

CLI tool: rscreen.

## Commands
- `rscreen <resource> <action>` — Execute rscreen commands
- `rscreen self version` — Print rscreen version
- `rscreen _ _` — Passthrough to rscreen CLI

## Usage Examples
- "rscreen --help"
- "rscreen self version"

## Installation
```bash
apt-get install rscreen 2>/dev/null || which rscreen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
