# Xorg Plugin

CLI tool: Xorg.

## Commands
- `Xorg <resource> <action>` — Execute Xorg commands
- `Xorg self version` — Print Xorg version
- `Xorg _ _` — Passthrough to Xorg CLI

## Usage Examples
- "Xorg --help"
- "Xorg self version"

## Installation
```bash
apt-get install Xorg 2>/dev/null || which Xorg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
