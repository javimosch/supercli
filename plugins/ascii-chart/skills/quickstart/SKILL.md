# ascii-chart Plugin
Generate line charts from data in the terminal

## Commands
- `ascii-chart <resource> <action>` — Execute ascii-chart commands
- `ascii-chart _ _` — Passthrough to ascii-chart CLI

## Usage
- `ascii-chart _ _ <args>` — Run ascii-chart with any arguments
