# servertool Plugin

CLI tool: servertool.

## Commands
- `servertool <resource> <action>` — Execute servertool commands
- `servertool self version` — Print servertool version
- `servertool _ _` — Passthrough to servertool CLI

## Usage Examples
- "servertool --help"
- "servertool self version"

## Installation
```bash
apt-get install servertool 2>/dev/null || which servertool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
