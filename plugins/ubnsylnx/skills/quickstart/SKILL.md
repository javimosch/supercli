# ubnsylnx Plugin

CLI tool: ubnsylnx.

## Commands
- `ubnsylnx <resource> <action>` — Execute ubnsylnx commands
- `ubnsylnx self version` — Print ubnsylnx version
- `ubnsylnx _ _` — Passthrough to ubnsylnx CLI

## Usage Examples
- "ubnsylnx --help"
- "ubnsylnx self version"

## Installation
```bash
apt-get install ubnsylnx 2>/dev/null || which ubnsylnx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
