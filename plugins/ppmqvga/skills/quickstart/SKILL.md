# ppmqvga Plugin

CLI tool: ppmqvga.

## Commands
- `ppmqvga <resource> <action>` — Execute ppmqvga commands
- `ppmqvga self version` — Print ppmqvga version
- `ppmqvga _ _` — Passthrough to ppmqvga CLI

## Usage Examples
- "ppmqvga --help"
- "ppmqvga self version"

## Installation
```bash
apt-get install ppmqvga 2>/dev/null || which ppmqvga
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
