# idle3 Plugin

CLI tool: idle3.

## Commands
- `idle3 <resource> <action>` — Execute idle3 commands
- `idle3 self version` — Print idle3 version
- `idle3 _ _` — Passthrough to idle3 CLI

## Usage Examples
- "idle3 --help"
- "idle3 self version"

## Installation
```bash
apt-get install idle3 2>/dev/null || which idle3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
