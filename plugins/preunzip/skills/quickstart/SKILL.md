# preunzip Plugin

CLI tool: preunzip.

## Commands
- `preunzip <resource> <action>` — Execute preunzip commands
- `preunzip self version` — Print preunzip version
- `preunzip _ _` — Passthrough to preunzip CLI

## Usage Examples
- "preunzip --help"
- "preunzip self version"

## Installation
```bash
apt-get install preunzip 2>/dev/null || which preunzip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
