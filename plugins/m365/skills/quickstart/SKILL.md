# m365 Plugin

CLI tool: m365.

## Commands
- `m365 <resource> <action>` — Execute m365 commands
- `m365 self version` — Print m365 version
- `m365 _ _` — Passthrough to m365 CLI

## Usage Examples
- "m365 --help"
- "m365 self version"

## Installation
```bash
apt-get install m365 2>/dev/null || which m365
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
