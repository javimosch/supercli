# intel-virtual-output Plugin

CLI tool: intel-virtual-output.

## Commands
- `intel-virtual-output <resource> <action>` — Execute intel-virtual-output commands
- `intel-virtual-output self version` — Print intel-virtual-output version
- `intel-virtual-output _ _` — Passthrough to intel-virtual-output CLI

## Usage Examples
- "intel-virtual-output --help"
- "intel-virtual-output self version"

## Installation
```bash
apt-get install intel-virtual-output 2>/dev/null || which intel-virtual-output
```
