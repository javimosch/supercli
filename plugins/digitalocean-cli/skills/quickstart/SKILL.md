# digitalocean-cli

DigitalOcean CLI — cloud infrastructure management command-line tool

## Install

```bash
brew install doctl
```

Verify installation:

```bash
which doctl
```

## Commands

- `digitalocean-cli self version` — print doctl version
- `digitalocean-cli cli run ...` — pass any arguments straight through to `doctl`
