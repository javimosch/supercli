# zipnote Plugin

CLI tool: zipnote.

## Commands
- `zipnote <resource> <action>` — Execute zipnote commands
- `zipnote self version` — Print zipnote version
- `zipnote _ _` — Passthrough to zipnote CLI

## Usage Examples
- "zipnote --help"
- "zipnote self version"

## Installation
```bash
apt-get install zipnote 2>/dev/null || which zipnote
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
