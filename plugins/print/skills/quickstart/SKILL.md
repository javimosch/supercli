# print Plugin

CLI tool: print.

## Commands
- `print <resource> <action>` — Execute print commands
- `print self version` — Print print version
- `print _ _` — Passthrough to print CLI

## Usage Examples
- "print --help"
- "print self version"

## Installation
```bash
apt-get install print 2>/dev/null || which print
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
