# json-diff-cli Plugin
Small tool for visual structural diffing of JSON objects

## Commands
- `json-diff-cli <resource> <action>` — Execute json-diff-cli commands
- `json-diff-cli _ _` — Passthrough to json-diff-cli CLI

## Usage
- `json-diff-cli _ _ <args>` — Run json-diff-cli with any arguments
