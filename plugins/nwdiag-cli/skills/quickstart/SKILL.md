# nwdiag-cli Plugin
Network topology diagram generator from text descriptions

## Commands
- `nwdiag-cli <resource> <action>` — Execute nwdiag-cli commands
- `nwdiag-cli _ _` — Passthrough to nwdiag-cli CLI

## Usage
- `nwdiag-cli _ _ <args>` — Run nwdiag-cli with any arguments
