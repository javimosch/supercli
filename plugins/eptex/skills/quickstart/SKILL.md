# eptex Plugin

CLI tool: eptex.

## Commands
- `eptex <resource> <action>` — Execute eptex commands
- `eptex self version` — Print eptex version
- `eptex _ _` — Passthrough to eptex CLI

## Usage Examples
- "eptex --help"
- "eptex self version"

## Installation
```bash
apt-get install eptex 2>/dev/null || which eptex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
