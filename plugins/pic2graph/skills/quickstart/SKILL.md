# pic2graph Plugin

CLI tool: pic2graph.

## Commands
- `pic2graph <resource> <action>` — Execute pic2graph commands
- `pic2graph self version` — Print pic2graph version
- `pic2graph _ _` — Passthrough to pic2graph CLI

## Usage Examples
- "pic2graph --help"
- "pic2graph self version"

## Installation
```bash
apt-get install pic2graph 2>/dev/null || which pic2graph
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
