# orte-server Plugin

CLI tool: orte-server.

## Commands
- `orte-server <resource> <action>` — Execute orte-server commands
- `orte-server self version` — Print orte-server version
- `orte-server _ _` — Passthrough to orte-server CLI

## Usage Examples
- "orte-server --help"
- "orte-server self version"

## Installation
```bash
apt-get install orte-server 2>/dev/null || which orte-server
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
