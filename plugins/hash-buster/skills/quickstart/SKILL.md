# hash-buster Plugin
Simple hash identification and cracking utility

## Commands
- `hash-buster <resource> <action>` — Execute hash-buster commands
- `hash-buster _ _` — Passthrough to hash-buster CLI

## Usage
- `hash-buster _ _ <args>` — Run hash-buster with any arguments
