# pid1 Plugin
CLI tool for pid1.

## Commands
- `pid1 <resource> <action>` — Execute pid1 commands
- `pid1 _ _` — Passthrough to pid1 CLI

## Installation
```bash
cargo install pid1
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
