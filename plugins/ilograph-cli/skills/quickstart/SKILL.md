# ilograph-cli Plugin
Interactive system architecture diagram CLI renderer

## Commands
- `ilograph-cli <resource> <action>` — Execute ilograph-cli commands
- `ilograph-cli _ _` — Passthrough to ilograph-cli CLI

## Usage
- `ilograph-cli _ _ <args>` — Run ilograph-cli with any arguments
