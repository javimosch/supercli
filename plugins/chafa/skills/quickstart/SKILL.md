# chafa Plugin

chafa converts and displays images in the terminal.

## Usage Examples

- "display an image in terminal"
- "preview a GIF animation"
- "convert image to ANSI art"
- "render SVG in the terminal"

## Installation

```bash
brew install chafa
```

## Key Features
- Terminal image rendering (ANSI, Unicode, sixel)
- Multiple input formats (JPEG, PNG, GIF, WebP, SVG)
- Image resizing and cropping
- Dithering and color reduction
- Transparency and alpha handling
- Animation support (GIF)
