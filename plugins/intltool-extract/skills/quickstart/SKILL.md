# intltool-extract Plugin

CLI tool: intltool-extract.

## Commands
- `intltool-extract <resource> <action>` — Execute intltool-extract commands
- `intltool-extract self version` — Print intltool-extract version
- `intltool-extract _ _` — Passthrough to intltool-extract CLI

## Usage Examples
- "intltool-extract --help"
- "intltool-extract self version"

## Installation
```bash
apt-get install intltool-extract 2>/dev/null || which intltool-extract
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
