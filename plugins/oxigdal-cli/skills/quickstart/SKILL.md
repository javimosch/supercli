# oxigdal-cli Plugin
Pure Rust CLI for GDAL-like geospatial format conversion

## Commands
- `oxigdal-cli <resource> <action>` — Execute oxigdal-cli commands
- `oxigdal-cli _ _` — Passthrough to oxigdal-cli CLI

## Usage
- `oxigdal-cli _ _ <args>` — Run oxigdal-cli with any arguments
