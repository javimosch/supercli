# yacc Plugin

CLI tool: yacc.

## Commands
- `yacc <resource> <action>` — Execute yacc commands
- `yacc self version` — Print yacc version
- `yacc _ _` — Passthrough to yacc CLI

## Usage Examples
- "yacc --help"
- "yacc self version"

## Installation
```bash
apt-get install yacc 2>/dev/null || which yacc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
