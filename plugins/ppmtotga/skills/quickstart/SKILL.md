# ppmtotga Plugin

CLI tool: ppmtotga.

## Commands
- `ppmtotga <resource> <action>` — Execute ppmtotga commands
- `ppmtotga self version` — Print ppmtotga version
- `ppmtotga _ _` — Passthrough to ppmtotga CLI

## Usage Examples
- "ppmtotga --help"
- "ppmtotga self version"

## Installation
```bash
apt-get install ppmtotga 2>/dev/null || which ppmtotga
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
