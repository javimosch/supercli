# sulogin Plugin

CLI tool: sulogin.

## Commands
- `sulogin <resource> <action>` — Execute sulogin commands
- `sulogin self version` — Print sulogin version
- `sulogin _ _` — Passthrough to sulogin CLI

## Usage Examples
- "sulogin --help"
- "sulogin self version"

## Installation
```bash
apt-get install sulogin 2>/dev/null || which sulogin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
