# xstdcmap Plugin

CLI tool: xstdcmap.

## Commands
- `xstdcmap <resource> <action>` — Execute xstdcmap commands
- `xstdcmap self version` — Print xstdcmap version
- `xstdcmap _ _` — Passthrough to xstdcmap CLI

## Usage Examples
- "xstdcmap --help"
- "xstdcmap self version"

## Installation
```bash
apt-get install xstdcmap 2>/dev/null || which xstdcmap
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
