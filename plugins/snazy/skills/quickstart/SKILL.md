# snazy Plugin
CLI tool for snazy.

## Commands
- `snazy <resource> <action>` — Execute snazy commands
- `snazy _ _` — Passthrough to snazy CLI

## Installation
```bash
cargo install snazy
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
