# x-www-browser Plugin

CLI tool: x-www-browser.

## Commands
- `x-www-browser <resource> <action>` — Execute x-www-browser commands
- `x-www-browser self version` — Print x-www-browser version
- `x-www-browser _ _` — Passthrough to x-www-browser CLI

## Usage Examples
- "x-www-browser --help"
- "x-www-browser self version"

## Installation
```bash
apt-get install x-www-browser 2>/dev/null || which x-www-browser
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
