# perf-map
perf-map — create /tmp/perf-*.map files for JIT code. Enables perf profiling of JIT-compiled code like Node.js.

## Commands
- `perf-map <resource> <action>` — Execute perf-map commands
- `perf map run` — perf-map — create /tmp/perf-*.map files for JIT code. Enables perf profiling of JIT-compiled code like Node.js.
