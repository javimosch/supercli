# uptex Plugin

CLI tool: uptex.

## Commands
- `uptex <resource> <action>` — Execute uptex commands
- `uptex self version` — Print uptex version
- `uptex _ _` — Passthrough to uptex CLI

## Usage Examples
- "uptex --help"
- "uptex self version"

## Installation
```bash
apt-get install uptex 2>/dev/null || which uptex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
