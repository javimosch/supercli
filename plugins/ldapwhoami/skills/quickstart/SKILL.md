# ldapwhoami Plugin

CLI tool: ldapwhoami.

## Commands
- `ldapwhoami <resource> <action>` — Execute ldapwhoami commands
- `ldapwhoami self version` — Print ldapwhoami version
- `ldapwhoami _ _` — Passthrough to ldapwhoami CLI

## Usage Examples
- "ldapwhoami --help"
- "ldapwhoami self version"

## Installation
```bash
apt-get install ldapwhoami 2>/dev/null || which ldapwhoami
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
