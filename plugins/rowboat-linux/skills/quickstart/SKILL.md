# rowboat-linux Plugin

CLI tool: rowboat-linux.

## Commands
- `rowboat-linux <resource> <action>` — Execute rowboat-linux commands
- `rowboat-linux self version` — Print rowboat-linux version
- `rowboat-linux _ _` — Passthrough to rowboat-linux CLI

## Usage Examples
- "rowboat-linux --help"
- "rowboat-linux self version"

## Installation
```bash
apt-get install rowboat-linux 2>/dev/null || which rowboat-linux
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
