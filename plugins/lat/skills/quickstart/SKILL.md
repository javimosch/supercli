# lat Plugin

CLI tool: lat.

## Commands
- `lat <resource> <action>` — Execute lat commands
- `lat self version` — Print lat version
- `lat _ _` — Passthrough to lat CLI

## Usage Examples
- "lat --help"
- "lat self version"

## Installation
```bash
apt-get install lat 2>/dev/null || which lat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
