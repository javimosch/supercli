# nushell Plugin

Nushell — a new type of shell using structured data

## Commands
- `nushell <resource> <action>` — Execute nushell commands
- `nushell self version` — Version

## Installation

```bash
brew install nushell
Verify: nushell --version
```

## Commands

### `sc nushell self version`

Version


## SuperCLI

```bash
sc nushell _ _ --help
sc plugins learn nushell
```
