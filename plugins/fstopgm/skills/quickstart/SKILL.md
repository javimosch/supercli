# fstopgm Plugin

CLI tool: fstopgm.

## Commands
- `fstopgm <resource> <action>` — Execute fstopgm commands
- `fstopgm self version` — Print fstopgm version
- `fstopgm _ _` — Passthrough to fstopgm CLI

## Usage Examples
- "fstopgm --help"
- "fstopgm self version"

## Installation
```bash
apt-get install fstopgm 2>/dev/null || which fstopgm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
