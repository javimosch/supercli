# validlocale Plugin

CLI tool: validlocale.

## Commands
- `validlocale <resource> <action>` — Execute validlocale commands
- `validlocale self version` — Print validlocale version
- `validlocale _ _` — Passthrough to validlocale CLI

## Usage Examples
- "validlocale --help"
- "validlocale self version"

## Installation
```bash
apt-get install validlocale 2>/dev/null || which validlocale
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
