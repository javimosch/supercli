# slurp Plugin

Select a region in Wayland compositor in C

## Commands

### Operations
- `slurp self version` — Print slurp version
- `slurp _ _` — Passthrough to slurp CLI

## Usage Examples
- `slurp --help`
- `slurp <args>`

## Installation

```bash
brew install slurp
```

## Examples

```bash
slurp --version
slurp --help
```
