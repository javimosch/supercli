# lxc-update-config Plugin

CLI tool: lxc-update-config.

## Commands
- `lxc-update-config <resource> <action>` — Execute lxc-update-config commands
- `lxc-update-config self version` — Print lxc-update-config version
- `lxc-update-config _ _` — Passthrough to lxc-update-config CLI

## Usage Examples
- "lxc-update-config --help"
- "lxc-update-config self version"

## Installation
```bash
apt-get install lxc-update-config 2>/dev/null || which lxc-update-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
