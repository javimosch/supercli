# scspell Plugin
Source code spell checker with custom dictionaries

## Commands
- `scspell <resource> <action>` — Execute scspell commands
- `scspell _ _` — Passthrough to scspell CLI

## Usage
- `scspell _ _ <args>` — Run scspell with any arguments
