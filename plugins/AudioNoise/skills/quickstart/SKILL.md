# AudioNoise Plugin

Random digital audio effects

## Commands

### General
- `AudioNoise self version` — Print AudioNoise version
- `AudioNoise _ _` — Passthrough to audionoise CLI

## Usage Examples
- "Run AudioNoise"

```bash
pip install audionoise
```

## Key Features
- Random digital audio effects
- CLI tool, headless and scriptable
