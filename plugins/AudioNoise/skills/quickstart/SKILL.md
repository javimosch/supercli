# AudioNoise Plugin

Random digital audio effects generator

## Commands

### Version
`AudioNoise self version` — Print AudioNoise version

### Passthrough
`AudioNoise _ _` — Passthrough to audionoise CLI with all arguments forwarded.

## Usage Examples

```bash
audionoise --version
audionoise --help
```

## Installation

```bash
cargo install audionoise
```

## Key Features
- Random digital audio effects generator
