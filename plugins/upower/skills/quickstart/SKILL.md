# upower Plugin

CLI tool: upower.

## Commands
- `upower <resource> <action>` — Execute upower commands
- `upower self version` — Print upower version
- `upower _ _` — Passthrough to upower CLI

## Usage Examples
- "upower --help"
- "upower self version"

## Installation
```bash
apt-get install upower 2>/dev/null || which upower
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
