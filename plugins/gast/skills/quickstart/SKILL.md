# gast Plugin

CLI tool: gast.

## Commands
- `gast <resource> <action>` — Execute gast commands
- `gast self version` — Print gast version
- `gast _ _` — Passthrough to gast CLI

## Usage Examples
- "gast --help"
- "gast self version"

## Installation
```bash
apt-get install gast 2>/dev/null || which gast
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
