# unzstd Plugin

CLI tool: unzstd.

## Commands
- `unzstd <resource> <action>` — Execute unzstd commands
- `unzstd self version` — Print unzstd version
- `unzstd _ _` — Passthrough to unzstd CLI

## Usage Examples
- "unzstd --help"
- "unzstd self version"

## Installation
```bash
apt-get install unzstd 2>/dev/null || which unzstd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
