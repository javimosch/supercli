# ppmmix Plugin

CLI tool: ppmmix.

## Commands
- `ppmmix <resource> <action>` — Execute ppmmix commands
- `ppmmix self version` — Print ppmmix version
- `ppmmix _ _` — Passthrough to ppmmix CLI

## Usage Examples
- "ppmmix --help"
- "ppmmix self version"

## Installation
```bash
apt-get install ppmmix 2>/dev/null || which ppmmix
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
