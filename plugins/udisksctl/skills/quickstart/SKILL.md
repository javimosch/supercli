# udisksctl Plugin

CLI tool: udisksctl.

## Commands
- `udisksctl <resource> <action>` — Execute udisksctl commands
- `udisksctl self version` — Print udisksctl version
- `udisksctl _ _` — Passthrough to udisksctl CLI

## Usage Examples
- "udisksctl --help"
- "udisksctl self version"

## Installation
```bash
apt-get install udisksctl 2>/dev/null || which udisksctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
