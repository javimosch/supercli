# bump-my-version Plugin
Modern Python version bumper with rich configuration

## Commands
- `bump-my-version <resource> <action>` — Execute bump-my-version commands
- `bump-my-version _ _` — Passthrough to bump-my-version CLI

## Usage
- `bump-my-version _ _ <args>` — Run bump-my-version with any arguments
