# yt-dlp Plugin

Feature-rich video downloader supporting 1000+ sites

## Commands
- `yt-dlp self version` — Print version
- `yt-dlp _ _` — Passthrough to yt-dlp

## Installation
```bash
brew install yt-dlp
```
