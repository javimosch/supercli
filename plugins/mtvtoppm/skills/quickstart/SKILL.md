# mtvtoppm Plugin

CLI tool: mtvtoppm.

## Commands
- `mtvtoppm <resource> <action>` — Execute mtvtoppm commands
- `mtvtoppm self version` — Print mtvtoppm version
- `mtvtoppm _ _` — Passthrough to mtvtoppm CLI

## Usage Examples
- "mtvtoppm --help"
- "mtvtoppm self version"

## Installation
```bash
apt-get install mtvtoppm 2>/dev/null || which mtvtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
