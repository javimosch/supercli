# pytube Plugin

Lightweight YouTube downloader in Python

## Commands

### Operations
- `pytube self version` — Print pytube version
- `pytube _ _` — Passthrough to pytube CLI

## Usage Examples
- `pytube --help`
- `pytube <args>`

## Installation

```bash
pip install pytube
```

## Examples

```bash
pytube --version
pytube --help
```
