# pasuspender Plugin

CLI tool: pasuspender.

## Commands
- `pasuspender <resource> <action>` — Execute pasuspender commands
- `pasuspender self version` — Print pasuspender version
- `pasuspender _ _` — Passthrough to pasuspender CLI

## Usage Examples
- "pasuspender --help"
- "pasuspender self version"

## Installation
```bash
apt-get install pasuspender 2>/dev/null || which pasuspender
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
