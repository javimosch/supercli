# hprof-slurp Plugin
CLI tool for hprof-slurp.

## Commands
- `hprof-slurp <resource> <action>` — Execute hprof-slurp commands
- `hprof-slurp _ _` — Passthrough to hprof-slurp CLI

## Installation
```bash
cargo install hprof-slurp
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
