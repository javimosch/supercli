# patchwork Plugin

CLI tool: patchwork.

## Commands
- `patchwork <resource> <action>` — Execute patchwork commands
- `patchwork self version` — Print patchwork version
- `patchwork _ _` — Passthrough to patchwork CLI

## Usage Examples
- "patchwork --help"
- "patchwork self version"

## Installation
```bash
apt-get install patchwork 2>/dev/null || which patchwork
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
