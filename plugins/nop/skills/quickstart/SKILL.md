# nop Plugin

CLI tool: nop.

## Commands
- `nop <resource> <action>` — Execute nop commands
- `nop self version` — Print nop version
- `nop _ _` — Passthrough to nop CLI

## Usage Examples
- "nop --help"
- "nop self version"

## Installation
```bash
apt-get install nop 2>/dev/null || which nop
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
