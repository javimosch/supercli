# yokai Plugin

Free and open source manga reader for Android

## Commands

### General
- `yokai self version` — Print yokai version
- `yokai _ _` — Passthrough to yokai CLI

## Usage Examples
- "Run yokai"
- "Use yokai to Free and open source manga reader for Android"

## Installation

```bash
pip install yokai
```

## Key Features
- Free and open source manga reader for Android
- CLI tool, headless and scriptable
