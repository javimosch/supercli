# ntptrace Plugin

CLI tool: ntptrace.

## Commands
- `ntptrace <resource> <action>` — Execute ntptrace commands
- `ntptrace self version` — Print ntptrace version
- `ntptrace _ _` — Passthrough to ntptrace CLI

## Usage Examples
- "ntptrace --help"
- "ntptrace self version"

## Installation
```bash
apt-get install ntptrace 2>/dev/null || which ntptrace
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
