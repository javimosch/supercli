# humanfriendly Plugin

CLI tool: humanfriendly.

## Commands
- `humanfriendly <resource> <action>` — Execute humanfriendly commands
- `humanfriendly self version` — Print humanfriendly version
- `humanfriendly _ _` — Passthrough to humanfriendly CLI

## Usage Examples
- "humanfriendly --help"
- "humanfriendly self version"

## Installation
```bash
apt-get install humanfriendly 2>/dev/null || which humanfriendly
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
