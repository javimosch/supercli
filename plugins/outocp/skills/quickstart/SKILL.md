# outocp Plugin

CLI tool: outocp.

## Commands
- `outocp <resource> <action>` — Execute outocp commands
- `outocp self version` — Print outocp version
- `outocp _ _` — Passthrough to outocp CLI

## Usage Examples
- "outocp --help"
- "outocp self version"

## Installation
```bash
apt-get install outocp 2>/dev/null || which outocp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
