# pw-dsdplay Plugin

CLI tool: pw-dsdplay.

## Commands
- `pw-dsdplay <resource> <action>` — Execute pw-dsdplay commands
- `pw-dsdplay self version` — Print pw-dsdplay version
- `pw-dsdplay _ _` — Passthrough to pw-dsdplay CLI

## Usage Examples
- "pw-dsdplay --help"
- "pw-dsdplay self version"

## Installation
```bash
apt-get install pw-dsdplay 2>/dev/null || which pw-dsdplay
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
