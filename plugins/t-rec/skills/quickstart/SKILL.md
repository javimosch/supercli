# t-rec Plugin
Blazingly fast terminal window recorder to GIF and MP4

## Commands
- `t-rec <resource> <action>` — Execute t-rec commands
- `t-rec _ _` — Passthrough to t-rec CLI

## Usage
- `t-rec _ _ <args>` — Run t-rec with any arguments
