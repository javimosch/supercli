# diagrams-cli Plugin
Render Python Diagrams-as-Code to images via CLI

## Commands
- `diagrams-cli <resource> <action>` — Execute diagrams-cli commands
- `diagrams-cli _ _` — Passthrough to diagrams-cli CLI

## Usage
- `diagrams-cli _ _ <args>` — Run diagrams-cli with any arguments
