# ld.gold Plugin

CLI tool: ld.gold.

## Commands
- `ld.gold <resource> <action>` — Execute ld.gold commands
- `ld.gold self version` — Print ld.gold version
- `ld.gold _ _` — Passthrough to ld.gold CLI

## Usage Examples
- "ld.gold --help"
- "ld.gold self version"

## Installation
```bash
apt-get install ld.gold 2>/dev/null || which ld.gold
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
