# ppmshadow Plugin

CLI tool: ppmshadow.

## Commands
- `ppmshadow <resource> <action>` — Execute ppmshadow commands
- `ppmshadow self version` — Print ppmshadow version
- `ppmshadow _ _` — Passthrough to ppmshadow CLI

## Usage Examples
- "ppmshadow --help"
- "ppmshadow self version"

## Installation
```bash
apt-get install ppmshadow 2>/dev/null || which ppmshadow
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
