# n8n-skills Plugin

n8n skillset for Claude Code to build flawless n8n workflows

## Commands

### General
- `n8n-skills self version` — Print n8n-skills version
- `n8n-skills _ _` — Passthrough to n8n-skills CLI

```bash
pip install n8n-skills
```
