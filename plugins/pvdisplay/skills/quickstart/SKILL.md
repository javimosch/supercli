# pvdisplay Plugin

CLI tool: pvdisplay.

## Commands
- `pvdisplay <resource> <action>` — Execute pvdisplay commands
- `pvdisplay self version` — Print pvdisplay version
- `pvdisplay _ _` — Passthrough to pvdisplay CLI

## Usage Examples
- "pvdisplay --help"
- "pvdisplay self version"

## Installation
```bash
apt-get install pvdisplay 2>/dev/null || which pvdisplay
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
