# fincore Plugin

CLI tool: fincore.

## Commands
- `fincore <resource> <action>` — Execute fincore commands
- `fincore self version` — Print fincore version
- `fincore _ _` — Passthrough to fincore CLI

## Usage Examples
- "fincore --help"
- "fincore self version"

## Installation
```bash
apt-get install fincore 2>/dev/null || which fincore
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
