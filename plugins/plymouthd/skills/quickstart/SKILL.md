# plymouthd Plugin

CLI tool: plymouthd.

## Commands
- `plymouthd <resource> <action>` — Execute plymouthd commands
- `plymouthd self version` — Print plymouthd version
- `plymouthd _ _` — Passthrough to plymouthd CLI

## Usage Examples
- "plymouthd --help"
- "plymouthd self version"

## Installation
```bash
apt-get install plymouthd 2>/dev/null || which plymouthd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
