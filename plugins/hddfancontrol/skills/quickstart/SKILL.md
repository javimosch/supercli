# hddfancontrol Plugin
CLI tool for hddfancontrol.

## Commands
- `hddfancontrol <resource> <action>` — Execute hddfancontrol commands
- `hddfancontrol _ _` — Passthrough to hddfancontrol CLI

## Installation
```bash
cargo install hddfancontrol
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
