# xsubpp Plugin

CLI tool: xsubpp.

## Commands
- `xsubpp <resource> <action>` — Execute xsubpp commands
- `xsubpp self version` — Print xsubpp version
- `xsubpp _ _` — Passthrough to xsubpp CLI

## Usage Examples
- "xsubpp --help"
- "xsubpp self version"

## Installation
```bash
apt-get install xsubpp 2>/dev/null || which xsubpp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
