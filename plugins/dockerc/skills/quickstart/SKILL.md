# dockerc Plugin

container image to single executable compiler

## Commands

### General
- `dockerc self version` — Print dockerc version
- `dockerc _ _` — Passthrough to dockerc CLI

## Usage Examples
- "Run dockerc"
- "Use dockerc to container image to single executable compiler"

## Installation

```bash
pip install dockerc
```

## Key Features
- container image to single executable compiler
- CLI tool, headless and scriptable
