# rst2s5 Plugin

CLI tool: rst2s5.

## Commands
- `rst2s5 <resource> <action>` — Execute rst2s5 commands
- `rst2s5 self version` — Print rst2s5 version
- `rst2s5 _ _` — Passthrough to rst2s5 CLI

## Usage Examples
- "rst2s5 --help"
- "rst2s5 self version"

## Installation
```bash
apt-get install rst2s5 2>/dev/null || which rst2s5
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
