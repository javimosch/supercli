# gpg-wks-server Plugin

CLI tool: gpg-wks-server.

## Commands
- `gpg-wks-server <resource> <action>` — Execute gpg-wks-server commands
- `gpg-wks-server self version` — Print gpg-wks-server version
- `gpg-wks-server _ _` — Passthrough to gpg-wks-server CLI

## Usage Examples
- "gpg-wks-server --help"
- "gpg-wks-server self version"

## Installation
```bash
apt-get install gpg-wks-server 2>/dev/null || which gpg-wks-server
```

- Scriptable and automatable
