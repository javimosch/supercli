# gjs-console Plugin

CLI tool: gjs-console.

## Commands
- `gjs-console <resource> <action>` — Execute gjs-console commands
- `gjs-console self version` — Print gjs-console version
- `gjs-console _ _` — Passthrough to gjs-console CLI

## Usage Examples
- "gjs-console --help"
- "gjs-console self version"

## Installation
```bash
apt-get install gjs-console 2>/dev/null || which gjs-console
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
