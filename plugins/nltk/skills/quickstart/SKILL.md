# nltk Plugin

CLI tool: nltk.

## Commands
- `nltk <resource> <action>` — Execute nltk commands
- `nltk self version` — Print nltk version
- `nltk _ _` — Passthrough to nltk CLI

## Usage Examples
- "nltk --help"
- "nltk self version"

## Installation
```bash
apt-get install nltk 2>/dev/null || which nltk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
