# resizecons Plugin

CLI tool: resizecons.

## Commands
- `resizecons <resource> <action>` — Execute resizecons commands
- `resizecons self version` — Print resizecons version
- `resizecons _ _` — Passthrough to resizecons CLI

## Usage Examples
- "resizecons --help"
- "resizecons self version"

## Installation
```bash
apt-get install resizecons 2>/dev/null || which resizecons
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
