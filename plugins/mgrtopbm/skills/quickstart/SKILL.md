# mgrtopbm Plugin

CLI tool: mgrtopbm.

## Commands
- `mgrtopbm <resource> <action>` — Execute mgrtopbm commands
- `mgrtopbm self version` — Print mgrtopbm version
- `mgrtopbm _ _` — Passthrough to mgrtopbm CLI

## Usage Examples
- "mgrtopbm --help"
- "mgrtopbm self version"

## Installation
```bash
apt-get install mgrtopbm 2>/dev/null || which mgrtopbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
