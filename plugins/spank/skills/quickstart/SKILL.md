# spank Plugin

Slap your MacBook, it yells back. Uses Apple Silicon accelerometer via IOKit HID.

## Commands
- `spank <resource> <action>` — Execute spank commands
- `spank self version` — Print spank version
- `spank _ _` — Passthrough to spank CLI

## Installation

```bash
pip install spank
```
