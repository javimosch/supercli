# qr-decode-cli Plugin
Decode QR codes from image files via command line

## Commands
- `qr-decode-cli <resource> <action>` — Execute qr-decode-cli commands
- `qr-decode-cli _ _` — Passthrough to qr-decode-cli CLI

## Usage
- `qr-decode-cli _ _ <args>` — Run qr-decode-cli with any arguments
