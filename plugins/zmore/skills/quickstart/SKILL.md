# zmore Plugin

CLI tool: zmore.

## Commands
- `zmore <resource> <action>` — Execute zmore commands
- `zmore self version` — Print zmore version
- `zmore _ _` — Passthrough to zmore CLI

## Usage Examples
- "zmore --help"
- "zmore self version"

## Installation
```bash
apt-get install zmore 2>/dev/null || which zmore
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
