# eqn2graph Plugin

CLI tool: eqn2graph.

## Commands
- `eqn2graph <resource> <action>` — Execute eqn2graph commands
- `eqn2graph self version` — Print eqn2graph version
- `eqn2graph _ _` — Passthrough to eqn2graph CLI

## Usage Examples
- "eqn2graph --help"
- "eqn2graph self version"

## Installation
```bash
apt-get install eqn2graph 2>/dev/null || which eqn2graph
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
