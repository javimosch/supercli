# jupytext Plugin
Jupyter notebooks as Markdown or scripts

## Commands
- `jupytext <resource> <action>` — Execute jupytext commands
- `jupytext _ _` — Passthrough to jupytext CLI

## Usage
- `jupytext _ _ <args>` — Run jupytext with any arguments
