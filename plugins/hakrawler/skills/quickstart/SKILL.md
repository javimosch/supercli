# hakrawler Plugin

Simple fast web crawler for gathering URLs — designed for recon pipelines

## Commands
- `hakrawler self version` — Print hakrawler version
- `hakrawler _ _` — Passthrough to hakrawler CLI

## Usage Examples
- `hakrawler self version` — Check installed version
- `hakrawler _ _ --help` — Show hakrawler help
- `hakrawler _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/hakrawler/hakrawler@latest
```

## Key Features
- security, crawler, golang, recon
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
