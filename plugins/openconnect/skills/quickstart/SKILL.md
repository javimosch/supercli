# openconnect Plugin

CLI tool: openconnect.

## Commands
- `openconnect <resource> <action>` — Execute openconnect commands
- `openconnect self version` — Print openconnect version
- `openconnect _ _` — Passthrough to openconnect CLI

## Usage Examples
- "openconnect --help"
- "openconnect self version"

## Installation
```bash
apt-get install openconnect 2>/dev/null || which openconnect
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
