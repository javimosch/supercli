# wkhtmltoimage Plugin

CLI tool: wkhtmltoimage.

## Commands
- `wkhtmltoimage <resource> <action>` — Execute wkhtmltoimage commands
- `wkhtmltoimage self version` — Print wkhtmltoimage version
- `wkhtmltoimage _ _` — Passthrough to wkhtmltoimage CLI

## Usage Examples
- "wkhtmltoimage --help"
- "wkhtmltoimage self version"

## Installation
```bash
apt-get install wkhtmltoimage 2>/dev/null || which wkhtmltoimage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
