# react-scan Plugin

Scan and fix React performance issues

## Commands

### General
- `react-scan self version` — Print react-scan version
- `react-scan _ _` — Passthrough to react-scan CLI

## Usage Examples
- "Run react-scan"
- "Use react-scan to Scan and fix React performance issues"

## Installation

```bash
pip install react-scan
```

## Key Features
- Scan and fix React performance issues
- CLI tool, headless and scriptable
