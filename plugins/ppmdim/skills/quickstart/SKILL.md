# ppmdim Plugin

CLI tool: ppmdim.

## Commands
- `ppmdim <resource> <action>` — Execute ppmdim commands
- `ppmdim self version` — Print ppmdim version
- `ppmdim _ _` — Passthrough to ppmdim CLI

## Usage Examples
- "ppmdim --help"
- "ppmdim self version"

## Installation
```bash
apt-get install ppmdim 2>/dev/null || which ppmdim
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
