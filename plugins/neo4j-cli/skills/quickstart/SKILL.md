# neo4j-cli
neo4j-cli — Neo4j graph database CLI. Run Cypher queries, manage database, import/export graph data.

## Commands
- `neo4j-cli <resource> <action>` — Execute neo4j-cli commands
- `neo4j cli run` — neo4j-cli — Neo4j graph database CLI. Run Cypher queries, manage database, import/export graph data.
