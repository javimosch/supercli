# eutp Plugin

CLI tool: eutp.

## Commands
- `eutp <resource> <action>` — Execute eutp commands
- `eutp self version` — Print eutp version
- `eutp _ _` — Passthrough to eutp CLI

## Usage Examples
- "eutp --help"
- "eutp self version"

## Installation
```bash
apt-get install eutp 2>/dev/null || which eutp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
