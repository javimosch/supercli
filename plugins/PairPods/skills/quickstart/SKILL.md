# PairPods Plugin
Share and manage audio pairing between Bluetooth devices

## Commands
- `PairPods <resource> <action>` — Execute PairPods commands
- `PairPods _ _` — Passthrough to PairPods CLI

## Usage
- `PairPods _ _ <args>` — Run PairPods with any arguments
