# xfwm4 Plugin

CLI tool: xfwm4.

## Commands
- `xfwm4 <resource> <action>` — Execute xfwm4 commands
- `xfwm4 self version` — Print xfwm4 version
- `xfwm4 _ _` — Passthrough to xfwm4 CLI

## Usage Examples
- "xfwm4 --help"
- "xfwm4 self version"

## Installation
```bash
apt-get install xfwm4 2>/dev/null || which xfwm4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
