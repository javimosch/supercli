# ui Plugin

A set of beautifully-designed, accessible components and a code distribution platform. Works with your favorite frameworks. Open Source. Open Code.

## Commands
- `ui <resource> <action>` — Execute ui commands
- `ui self version` — Print ui version
- `ui _ _` — Passthrough to ui CLI

## Installation

```bash
pip install ui
```
