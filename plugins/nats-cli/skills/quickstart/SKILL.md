# nats-cli
nats-cli — NATS messaging CLI. Publish, subscribe, request-reply to NATS subjects. JSON output with --json flag. Non-interactive, headless.

## Install
```bash
curl -LO https://github.com/nats-io/natscli/releases/download/v0.1.5/nats-0.1.5-linux-amd64.zip && unzip nats-0.1.5-linux-amd64.zip && sudo mv nats-0.1.5-linux-amd64/nats /usr/local/bin/ && rm -rf nats-0.1.5-linux-amd64 nats-0.1.5-linux-amd64.zip
```
