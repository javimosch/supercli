# spa-monitor Plugin

CLI tool: spa-monitor.

## Commands
- `spa-monitor <resource> <action>` — Execute spa-monitor commands
- `spa-monitor self version` — Print spa-monitor version
- `spa-monitor _ _` — Passthrough to spa-monitor CLI

## Usage Examples
- "spa-monitor --help"
- "spa-monitor self version"

## Installation
```bash
apt-get install spa-monitor 2>/dev/null || which spa-monitor
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
