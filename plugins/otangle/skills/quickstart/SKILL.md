# otangle Plugin

CLI tool: otangle.

## Commands
- `otangle <resource> <action>` — Execute otangle commands
- `otangle self version` — Print otangle version
- `otangle _ _` — Passthrough to otangle CLI

## Usage Examples
- "otangle --help"
- "otangle self version"

## Installation
```bash
apt-get install otangle 2>/dev/null || which otangle
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
