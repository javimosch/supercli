# troff Plugin

CLI tool: troff.

## Commands
- `troff <resource> <action>` — Execute troff commands
- `troff self version` — Print troff version
- `troff _ _` — Passthrough to troff CLI

## Usage Examples
- "troff --help"
- "troff self version"

## Installation
```bash
apt-get install troff 2>/dev/null || which troff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
