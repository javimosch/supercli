# toc2cue Plugin

CLI tool: toc2cue.

## Commands
- `toc2cue <resource> <action>` — Execute toc2cue commands
- `toc2cue self version` — Print toc2cue version
- `toc2cue _ _` — Passthrough to toc2cue CLI

## Usage Examples
- "toc2cue --help"
- "toc2cue self version"

## Installation
```bash
apt-get install toc2cue 2>/dev/null || which toc2cue
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
