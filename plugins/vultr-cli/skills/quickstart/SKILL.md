# vultr-cli

Vultr CLI — command-line interface for Vultr cloud

## Install

```bash
brew install vultr-cli
```

Verify installation:

```bash
which vultr-cli
```

## Commands

- `vultr-cli self version` — print vultr-cli version
- `vultr-cli cli run ...` — pass any arguments straight through to `vultr-cli`
