# pdfopen Plugin

CLI tool: pdfopen.

## Commands
- `pdfopen <resource> <action>` — Execute pdfopen commands
- `pdfopen self version` — Print pdfopen version
- `pdfopen _ _` — Passthrough to pdfopen CLI

## Usage Examples
- "pdfopen --help"
- "pdfopen self version"

## Installation
```bash
apt-get install pdfopen 2>/dev/null || which pdfopen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
