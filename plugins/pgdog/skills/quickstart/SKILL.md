# pgdog Plugin

PostgreSQL connection pooler, load balancer and database sharder.

## Commands
- `pgdog <resource> <action>` — Execute pgdog commands
- `pgdog self version` — Print pgdog version
- `pgdog _ _` — Passthrough to pgdog CLI

## Installation

```bash
pip install pgdog
```
