# xquad Plugin

A rust implementation of the Quip Network's quantum virtual machine.

## Commands
- `xquad <resource> <action>` — Execute xquad commands
- `xquad self version` — Print xquad version
- `xquad _ _` — Passthrough to xquad CLI

## Installation

```bash
pip install xquad
```
