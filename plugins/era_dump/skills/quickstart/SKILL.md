# era_dump Plugin

CLI tool: era_dump.

## Commands
- `era_dump <resource> <action>` — Execute era_dump commands
- `era_dump self version` — Print era_dump version
- `era_dump _ _` — Passthrough to era_dump CLI

## Usage Examples
- "era_dump --help"
- "era_dump self version"

## Installation
```bash
apt-get install era_dump 2>/dev/null || which era_dump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
