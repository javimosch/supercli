# agent-skills Plugin

Production-grade engineering skills for AI coding agents.

## Commands

### General
- `agent-skills self version` — Print agent-skills version
- `agent-skills _ _` — Passthrough to agent-skills CLI

## Usage Examples
- "Run agent-skills"
- "Use agent-skills to Production-grade engineering skills for AI coding agents."

## Installation

```bash
pip install agent-skills
```

## Key Features
- Production-grade engineering skills for AI coding agents.
- CLI tool, headless and scriptable
