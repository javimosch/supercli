# img-meta Plugin
Display EXIF metadata from image files via command line

## Commands
- `img-meta <resource> <action>` — Execute img-meta commands
- `img-meta _ _` — Passthrough to img-meta CLI

## Usage
- `img-meta _ _ <args>` — Run img-meta with any arguments
