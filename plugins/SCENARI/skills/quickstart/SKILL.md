# SCENARI Plugin

CLI tool: SCENARI.

## Commands
- `SCENARI <resource> <action>` — Execute SCENARI commands
- `SCENARI self version` — Print SCENARI version
- `SCENARI _ _` — Passthrough to SCENARI CLI

## Usage Examples
- "SCENARI --help"
- "SCENARI self version"

## Installation
```bash
apt-get install SCENARI 2>/dev/null || which SCENARI
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
