# libpng-config Plugin

CLI tool: libpng-config.

## Commands
- `libpng-config <resource> <action>` — Execute libpng-config commands
- `libpng-config self version` — Print libpng-config version
- `libpng-config _ _` — Passthrough to libpng-config CLI

## Usage Examples
- "libpng-config --help"
- "libpng-config self version"

## Installation
```bash
apt-get install libpng-config 2>/dev/null || which libpng-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
