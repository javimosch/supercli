# cc-switch Plugin

A cross-platform desktop All-in-One assistant for Claude Code, Codex, OpenCode, OpenClaw, Gemini CLI & Hermes Agent. Only official website: ccswitch.io

## Commands

### General
- `cc-switch self version` — Print cc-switch version
- `cc-switch _ _` — Passthrough to cc-switch CLI

## Usage Examples
- "Run cc-switch"
- "Use cc-switch to A cross-platform desktop All-in-One assistant for Claude Cod"

## Installation

```bash
pip install cc-switch
```

## Key Features
- A cross-platform desktop All-in-One assistant for Claude Code, Codex, OpenCode, OpenClaw, Gemini CLI
- CLI tool, headless and scriptable
