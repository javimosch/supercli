# NodeQuality Plugin

在沙箱环境中运行vps测试脚本，并排版测试结果

## Commands

### General
- `NodeQuality self version` — Print NodeQuality version
- `NodeQuality _ _` — Passthrough to nodequality CLI

## Usage Examples
- "Run NodeQuality"
- "Use nodequality to 在沙箱环境中运行vps测试脚本，并排版测试结果"

## Installation

```bash
pip install nodequality
```

## Key Features
- 在沙箱环境中运行vps测试脚本，并排版测试结果
- CLI tool, headless and scriptable
