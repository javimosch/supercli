# qsvlite Plugin

CLI tool: qsvlite.

## Commands
- `qsvlite <resource> <action>` — Execute qsvlite commands
- `qsvlite self version` — Print qsvlite version
- `qsvlite _ _` — Passthrough to qsvlite CLI

## Usage Examples
- "qsvlite --help"
- "qsvlite self version"

## Installation
```bash
apt-get install qsvlite 2>/dev/null || which qsvlite
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
