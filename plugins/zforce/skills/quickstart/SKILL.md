# zforce Plugin

CLI tool: zforce.

## Commands
- `zforce <resource> <action>` — Execute zforce commands
- `zforce self version` — Print zforce version
- `zforce _ _` — Passthrough to zforce CLI

## Usage Examples
- "zforce --help"
- "zforce self version"

## Installation
```bash
apt-get install zforce 2>/dev/null || which zforce
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
