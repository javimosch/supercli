# Json-Render Plugin

The Generative UI framework — AI outputs JSON, renders as components

## Commands
- `json-render _ _` — Passthrough to json-render CLI

## Installation

```bash
npm install -g json-render
```

## Examples
```bash
json-render --help
json-render --version
```
