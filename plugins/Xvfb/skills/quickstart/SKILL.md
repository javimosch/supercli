# Xvfb Plugin

CLI tool: Xvfb.

## Commands
- `Xvfb <resource> <action>` — Execute Xvfb commands
- `Xvfb self version` — Print Xvfb version
- `Xvfb _ _` — Passthrough to Xvfb CLI

## Usage Examples
- "Xvfb --help"
- "Xvfb self version"

## Installation
```bash
apt-get install Xvfb 2>/dev/null || which Xvfb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
