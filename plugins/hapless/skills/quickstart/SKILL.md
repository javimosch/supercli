# hapless Plugin
Lightweight background process manager.
## Commands
- `hapless _ _` — Passthrough to hapless CLI
## Installation
```bash
cargo install hapless
```
## Key Features
- **Background processes** — Run and manage
- **Lightweight** — Minimal overhead
- **Pipeline-ready** — Automation support
