# mysqlreport Plugin

CLI tool: mysqlreport.

## Commands
- `mysqlreport <resource> <action>` — Execute mysqlreport commands
- `mysqlreport self version` — Print mysqlreport version
- `mysqlreport _ _` — Passthrough to mysqlreport CLI

## Usage Examples
- "mysqlreport --help"
- "mysqlreport self version"

## Installation
```bash
apt-get install mysqlreport 2>/dev/null || which mysqlreport
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
