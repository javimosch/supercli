# ppmtobmp Plugin

CLI tool: ppmtobmp.

## Commands
- `ppmtobmp <resource> <action>` — Execute ppmtobmp commands
- `ppmtobmp self version` — Print ppmtobmp version
- `ppmtobmp _ _` — Passthrough to ppmtobmp CLI

## Usage Examples
- "ppmtobmp --help"
- "ppmtobmp self version"

## Installation
```bash
apt-get install ppmtobmp 2>/dev/null || which ppmtobmp
```
