# tuptime Plugin

tuptime — report historical and statistical system uptime..

## Commands

### `sc tuptime report show`
Show system uptime history.

### `sc tuptime self version`
Print version.

## Installation

```bash
sudo apt-get install tuptime
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
