# ippfind Plugin

CLI tool: ippfind.

## Commands
- `ippfind <resource> <action>` — Execute ippfind commands
- `ippfind self version` — Print ippfind version
- `ippfind _ _` — Passthrough to ippfind CLI

## Usage Examples
- "ippfind --help"
- "ippfind self version"

## Installation
```bash
apt-get install ippfind 2>/dev/null || which ippfind
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
