# qsvp Plugin

CLI tool: qsvp.

## Commands
- `qsvp <resource> <action>` — Execute qsvp commands
- `qsvp self version` — Print qsvp version
- `qsvp _ _` — Passthrough to qsvp CLI

## Usage Examples
- "qsvp --help"
- "qsvp self version"

## Installation
```bash
apt-get install qsvp 2>/dev/null || which qsvp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
