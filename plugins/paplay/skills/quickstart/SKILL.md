# paplay Plugin

CLI tool: paplay.

## Commands
- `paplay <resource> <action>` — Execute paplay commands
- `paplay self version` — Print paplay version
- `paplay _ _` — Passthrough to paplay CLI

## Usage Examples
- "paplay --help"
- "paplay self version"

## Installation
```bash
apt-get install paplay 2>/dev/null || which paplay
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
