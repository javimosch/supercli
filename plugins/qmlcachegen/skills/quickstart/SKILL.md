# qmlcachegen Plugin

CLI tool: qmlcachegen.

## Commands
- `qmlcachegen <resource> <action>` — Execute qmlcachegen commands
- `qmlcachegen self version` — Print qmlcachegen version
- `qmlcachegen _ _` — Passthrough to qmlcachegen CLI

## Usage Examples
- "qmlcachegen --help"
- "qmlcachegen self version"

## Installation
```bash
apt-get install qmlcachegen 2>/dev/null || which qmlcachegen
```
