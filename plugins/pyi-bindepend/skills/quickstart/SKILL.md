# pyi-bindepend Plugin

CLI tool: pyi-bindepend.

## Commands
- `pyi-bindepend <resource> <action>` — Execute pyi-bindepend commands
- `pyi-bindepend self version` — Print pyi-bindepend version
- `pyi-bindepend _ _` — Passthrough to pyi-bindepend CLI

## Usage Examples
- "pyi-bindepend --help"
- "pyi-bindepend self version"

## Installation
```bash
apt-get install pyi-bindepend 2>/dev/null || which pyi-bindepend
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
