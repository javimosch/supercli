# epub-to-pdf-cli Plugin
Node.js wrapper to convert ebooks to PDF via Calibre

## Commands
- `epub-to-pdf-cli <resource> <action>` — Execute epub-to-pdf-cli commands
- `epub-to-pdf-cli _ _` — Passthrough to epub-to-pdf-cli CLI

## Usage
- `epub-to-pdf-cli _ _ <args>` — Run epub-to-pdf-cli with any arguments
