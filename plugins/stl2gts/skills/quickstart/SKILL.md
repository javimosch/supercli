# stl2gts Plugin

CLI tool: stl2gts.

## Commands
- `stl2gts <resource> <action>` — Execute stl2gts commands
- `stl2gts self version` — Print stl2gts version
- `stl2gts _ _` — Passthrough to stl2gts CLI

## Usage Examples
- "stl2gts --help"
- "stl2gts self version"

## Installation
```bash
apt-get install stl2gts 2>/dev/null || which stl2gts
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
