# mpicalc Plugin

CLI tool: mpicalc.

## Commands
- `mpicalc <resource> <action>` — Execute mpicalc commands
- `mpicalc self version` — Print mpicalc version
- `mpicalc _ _` — Passthrough to mpicalc CLI

## Usage Examples
- "mpicalc --help"
- "mpicalc self version"

## Installation
```bash
apt-get install mpicalc 2>/dev/null || which mpicalc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
