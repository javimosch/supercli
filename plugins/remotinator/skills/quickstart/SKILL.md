# remotinator Plugin

CLI tool: remotinator.

## Commands
- `remotinator <resource> <action>` — Execute remotinator commands
- `remotinator self version` — Print remotinator version
- `remotinator _ _` — Passthrough to remotinator CLI

## Usage Examples
- "remotinator --help"
- "remotinator self version"

## Installation
```bash
apt-get install remotinator 2>/dev/null || which remotinator
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
