# qhelpgenerator Plugin

CLI tool: qhelpgenerator.

## Commands
- `qhelpgenerator <resource> <action>` — Execute qhelpgenerator commands
- `qhelpgenerator self version` — Print qhelpgenerator version
- `qhelpgenerator _ _` — Passthrough to qhelpgenerator CLI

## Usage Examples
- "qhelpgenerator --help"
- "qhelpgenerator self version"

## Installation
```bash
apt-get install qhelpgenerator 2>/dev/null || which qhelpgenerator
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
