# exfatlabel Plugin

CLI tool: exfatlabel.

## Commands
- `exfatlabel <resource> <action>` — Execute exfatlabel commands
- `exfatlabel self version` — Print exfatlabel version
- `exfatlabel _ _` — Passthrough to exfatlabel CLI

## Usage Examples
- "exfatlabel --help"
- "exfatlabel self version"

## Installation
```bash
apt-get install exfatlabel 2>/dev/null || which exfatlabel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
