# l2ping Plugin

CLI tool: l2ping.

## Commands
- `l2ping <resource> <action>` — Execute l2ping commands
- `l2ping self version` — Print l2ping version
- `l2ping _ _` — Passthrough to l2ping CLI

## Usage Examples
- "l2ping --help"
- "l2ping self version"

## Installation
```bash
apt-get install l2ping 2>/dev/null || which l2ping
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
