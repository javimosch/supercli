# pbmtomgr Plugin

CLI tool: pbmtomgr.

## Commands
- `pbmtomgr <resource> <action>` — Execute pbmtomgr commands
- `pbmtomgr self version` — Print pbmtomgr version
- `pbmtomgr _ _` — Passthrough to pbmtomgr CLI

## Usage Examples
- "pbmtomgr --help"
- "pbmtomgr self version"

## Installation
```bash
apt-get install pbmtomgr 2>/dev/null || which pbmtomgr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
