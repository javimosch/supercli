# pdfroff Plugin

CLI tool: pdfroff.

## Commands
- `pdfroff <resource> <action>` — Execute pdfroff commands
- `pdfroff self version` — Print pdfroff version
- `pdfroff _ _` — Passthrough to pdfroff CLI

## Usage Examples
- "pdfroff --help"
- "pdfroff self version"

## Installation
```bash
apt-get install pdfroff 2>/dev/null || which pdfroff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
