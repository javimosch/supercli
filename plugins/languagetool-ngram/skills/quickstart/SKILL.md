# languagetool-ngram Plugin
N-gram based language detection and checking

## Commands
- `languagetool-ngram <resource> <action>` — Execute languagetool-ngram commands
- `languagetool-ngram _ _` — Passthrough to languagetool-ngram CLI

## Usage
- `languagetool-ngram _ _ <args>` — Run languagetool-ngram with any arguments
