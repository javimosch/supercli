# opalcc Plugin

CLI tool: opalcc.

## Commands
- `opalcc <resource> <action>` — Execute opalcc commands
- `opalcc self version` — Print opalcc version
- `opalcc _ _` — Passthrough to opalcc CLI

## Usage Examples
- "opalcc --help"
- "opalcc self version"

## Installation
```bash
apt-get install opalcc 2>/dev/null || which opalcc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
