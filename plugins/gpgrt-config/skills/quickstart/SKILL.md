# gpgrt-config Plugin

CLI tool: gpgrt-config.

## Commands
- `gpgrt-config <resource> <action>` — Execute gpgrt-config commands
- `gpgrt-config self version` — Print gpgrt-config version
- `gpgrt-config _ _` — Passthrough to gpgrt-config CLI

## Usage Examples
- "gpgrt-config --help"
- "gpgrt-config self version"

## Installation
```bash
apt-get install gpgrt-config 2>/dev/null || which gpgrt-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
