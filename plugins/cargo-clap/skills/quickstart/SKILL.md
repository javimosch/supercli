# cargo-clap

cargo-clap — cargo extension for generating CLI argument parsers

## Install

```bash
cargo install cargo-clap
```

Verify installation:

```bash
which cargo-clap
```

## Commands

- `cargo-clap self version` — print cargo-clap version
