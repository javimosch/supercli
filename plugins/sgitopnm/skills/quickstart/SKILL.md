# sgitopnm Plugin

CLI tool: sgitopnm.

## Commands
- `sgitopnm <resource> <action>` — Execute sgitopnm commands
- `sgitopnm self version` — Print sgitopnm version
- `sgitopnm _ _` — Passthrough to sgitopnm CLI

## Usage Examples
- "sgitopnm --help"
- "sgitopnm self version"

## Installation
```bash
apt-get install sgitopnm 2>/dev/null || which sgitopnm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
