# ifdata Plugin

CLI tool: ifdata.

## Commands
- `ifdata <resource> <action>` — Execute ifdata commands
- `ifdata self version` — Print ifdata version
- `ifdata _ _` — Passthrough to ifdata CLI

## Usage Examples
- "ifdata --help"
- "ifdata self version"

## Installation
```bash
apt-get install ifdata 2>/dev/null || which ifdata
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
