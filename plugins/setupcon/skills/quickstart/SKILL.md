# setupcon Plugin

CLI tool: setupcon.

## Commands
- `setupcon <resource> <action>` — Execute setupcon commands
- `setupcon self version` — Print setupcon version
- `setupcon _ _` — Passthrough to setupcon CLI

## Usage Examples
- "setupcon --help"
- "setupcon self version"

## Installation
```bash
apt-get install setupcon 2>/dev/null || which setupcon
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
