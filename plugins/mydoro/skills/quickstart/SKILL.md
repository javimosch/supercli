# mydoro Plugin
Modern Pomodoro timer for the terminal in Rust

## Commands
- `mydoro <resource> <action>` — Execute mydoro commands
- `mydoro _ _` — Passthrough to mydoro CLI

## Usage
- `mydoro _ _ <args>` — Run mydoro with any arguments
