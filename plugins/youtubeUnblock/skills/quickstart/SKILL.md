# youtubeUnblock Plugin

Bypasses YouTube detection systems that rely on SNI.

## Commands

### General
- `youtubeUnblock self version` — Print youtubeUnblock version
- `youtubeUnblock _ _` — Passthrough to youtubeunblock CLI

```bash
pip install youtubeunblock
```

- Bypasses YouTube detection systems that rely on SNI.
- CLI tool, headless and scriptable
