# Quickstart

Comprehensive documentation available in the repository.

## Commands
- `fluent-bit <resource> <action>` — Execute fluent-bit commands
- `fluent-bit self version` — Print fluent-bit version
- `fluent-bit process logs` — Process logs with fluent-bit
- `fluent-bit _ _` — Passthrough to fluent-bit CLI
