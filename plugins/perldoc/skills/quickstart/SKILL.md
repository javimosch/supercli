# perldoc Plugin

CLI tool: perldoc.

## Commands
- `perldoc <resource> <action>` — Execute perldoc commands
- `perldoc self version` — Print perldoc version
- `perldoc _ _` — Passthrough to perldoc CLI

## Usage Examples
- "perldoc --help"
- "perldoc self version"

## Installation
```bash
apt-get install perldoc 2>/dev/null || which perldoc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
