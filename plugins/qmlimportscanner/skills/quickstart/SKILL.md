# qmlimportscanner Plugin

CLI tool: qmlimportscanner.

## Commands
- `qmlimportscanner <resource> <action>` — Execute qmlimportscanner commands
- `qmlimportscanner self version` — Print qmlimportscanner version
- `qmlimportscanner _ _` — Passthrough to qmlimportscanner CLI

## Usage Examples
- "qmlimportscanner --help"
- "qmlimportscanner self version"

## Installation
```bash
apt-get install qmlimportscanner 2>/dev/null || which qmlimportscanner
```
