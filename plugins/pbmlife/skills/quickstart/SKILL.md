# pbmlife Plugin

CLI tool: pbmlife.

## Commands
- `pbmlife <resource> <action>` — Execute pbmlife commands
- `pbmlife self version` — Print pbmlife version
- `pbmlife _ _` — Passthrough to pbmlife CLI

## Usage Examples
- "pbmlife --help"
- "pbmlife self version"

## Installation
```bash
apt-get install pbmlife 2>/dev/null || which pbmlife
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
