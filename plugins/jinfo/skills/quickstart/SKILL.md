# jinfo Plugin

CLI tool: jinfo.

## Commands
- `jinfo <resource> <action>` — Execute jinfo commands
- `jinfo self version` — Print jinfo version
- `jinfo _ _` — Passthrough to jinfo CLI

## Usage Examples
- "jinfo --help"
- "jinfo self version"

## Installation
```bash
apt-get install jinfo 2>/dev/null || which jinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
