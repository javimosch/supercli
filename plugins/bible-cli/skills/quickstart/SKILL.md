# bible-cli Plugin
Minimalist Bible verse reader for the terminal

## Commands
- `bible-cli <resource> <action>` — Execute bible-cli commands
- `bible-cli _ _` — Passthrough to bible-cli CLI

## Usage
- `bible-cli _ _ <args>` — Run bible-cli with any arguments
