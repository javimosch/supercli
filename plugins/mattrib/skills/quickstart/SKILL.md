# mattrib Plugin

CLI tool: mattrib.

## Commands
- `mattrib <resource> <action>` — Execute mattrib commands
- `mattrib self version` — Print mattrib version
- `mattrib _ _` — Passthrough to mattrib CLI

## Usage Examples
- "mattrib --help"
- "mattrib self version"

## Installation
```bash
apt-get install mattrib 2>/dev/null || which mattrib
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
