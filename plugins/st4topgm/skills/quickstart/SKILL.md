# st4topgm Plugin

CLI tool: st4topgm.

## Commands
- `st4topgm <resource> <action>` — Execute st4topgm commands
- `st4topgm self version` — Print st4topgm version
- `st4topgm _ _` — Passthrough to st4topgm CLI

## Usage Examples
- "st4topgm --help"
- "st4topgm self version"

```bash
apt-get install st4topgm 2>/dev/null || which st4topgm
```
