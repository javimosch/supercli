# tl-paper Plugin

CLI tool: tl-paper.

## Commands
- `tl-paper <resource> <action>` — Execute tl-paper commands
- `tl-paper self version` — Print tl-paper version
- `tl-paper _ _` — Passthrough to tl-paper CLI

## Usage Examples
- "tl-paper --help"
- "tl-paper self version"

## Installation
```bash
apt-get install tl-paper 2>/dev/null || which tl-paper
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
