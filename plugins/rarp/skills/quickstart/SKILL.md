# rarp Plugin

CLI tool: rarp.

## Commands
- `rarp <resource> <action>` — Execute rarp commands
- `rarp self version` — Print rarp version
- `rarp _ _` — Passthrough to rarp CLI

## Usage Examples
- "rarp --help"
- "rarp self version"

## Installation
```bash
apt-get install rarp 2>/dev/null || which rarp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
