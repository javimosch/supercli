# setxkbmap Plugin

CLI tool: setxkbmap.

## Commands
- `setxkbmap <resource> <action>` — Execute setxkbmap commands
- `setxkbmap self version` — Print setxkbmap version
- `setxkbmap _ _` — Passthrough to setxkbmap CLI

## Usage Examples
- "setxkbmap --help"
- "setxkbmap self version"

## Installation
```bash
apt-get install setxkbmap 2>/dev/null || which setxkbmap
```
