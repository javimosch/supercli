# mdel Plugin

CLI tool: mdel.

## Commands
- `mdel <resource> <action>` — Execute mdel commands
- `mdel self version` — Print mdel version
- `mdel _ _` — Passthrough to mdel CLI

## Usage Examples
- "mdel --help"
- "mdel self version"

## Installation
```bash
apt-get install mdel 2>/dev/null || which mdel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
