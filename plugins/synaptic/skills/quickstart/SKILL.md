# synaptic Plugin

CLI tool: synaptic.

## Commands
- `synaptic <resource> <action>` — Execute synaptic commands
- `synaptic self version` — Print synaptic version
- `synaptic _ _` — Passthrough to synaptic CLI

## Usage Examples
- "synaptic --help"
- "synaptic self version"

## Installation
```bash
apt-get install synaptic 2>/dev/null || which synaptic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
