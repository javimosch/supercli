# cargo-release
cargo-release — release automation for Rust projects. Bump version, tag, publish to crates.io from CLI. Non-interactive with --yes flag.

## Install
```bash
curl -LO https://github.com/crate-ci/cargo-release/releases/download/v0.25.17/cargo-release-v0.25.17-x86_64-unknown-linux-gnu.tar.gz && tar xzf cargo-release-v0.25.17-x86_64-unknown-linux-gnu.tar.gz && sudo mv cargo-release /usr/local/bin/ && rm cargo-release-v0.25.17-x86_64-unknown-linux-gnu.tar.gz
```
