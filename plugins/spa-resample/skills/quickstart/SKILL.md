# spa-resample Plugin

CLI tool: spa-resample.

## Commands
- `spa-resample <resource> <action>` — Execute spa-resample commands
- `spa-resample self version` — Print spa-resample version
- `spa-resample _ _` — Passthrough to spa-resample CLI

## Usage Examples
- "spa-resample --help"
- "spa-resample self version"

## Installation
```bash
apt-get install spa-resample 2>/dev/null || which spa-resample
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
