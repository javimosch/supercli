# xfce4-display-settings Plugin

CLI tool: xfce4-display-settings.

## Commands
- `xfce4-display-settings <resource> <action>` — Execute xfce4-display-settings commands
- `xfce4-display-settings self version` — Print xfce4-display-settings version
- `xfce4-display-settings _ _` — Passthrough to xfce4-display-settings CLI

## Usage Examples
- "xfce4-display-settings --help"
- "xfce4-display-settings self version"

```bash
apt-get install xfce4-display-settings 2>/dev/null || which xfce4-display-settings
```
