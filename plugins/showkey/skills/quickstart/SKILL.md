# showkey Plugin

CLI tool: showkey.

## Commands
- `showkey <resource> <action>` — Execute showkey commands
- `showkey self version` — Print showkey version
- `showkey _ _` — Passthrough to showkey CLI

## Usage Examples
- "showkey --help"
- "showkey self version"

## Installation
```bash
apt-get install showkey 2>/dev/null || which showkey
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
