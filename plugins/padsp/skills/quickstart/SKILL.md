# padsp Plugin

CLI tool: padsp.

## Commands
- `padsp <resource> <action>` — Execute padsp commands
- `padsp self version` — Print padsp version
- `padsp _ _` — Passthrough to padsp CLI

## Usage Examples
- "padsp --help"
- "padsp self version"

## Installation
```bash
apt-get install padsp 2>/dev/null || which padsp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
