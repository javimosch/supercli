# signver Plugin

CLI tool: signver.

## Commands
- `signver <resource> <action>` — Execute signver commands
- `signver self version` — Print signver version
- `signver _ _` — Passthrough to signver CLI

## Usage Examples
- "signver --help"
- "signver self version"

## Installation
```bash
apt-get install signver 2>/dev/null || which signver
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
