# sg Plugin

CLI tool: sg.

## Commands
- `sg <resource> <action>` — Execute sg commands
- `sg self version` — Print sg version
- `sg _ _` — Passthrough to sg CLI

## Usage Examples
- "sg --help"
- "sg self version"

## Installation
```bash
apt-get install sg 2>/dev/null || which sg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
