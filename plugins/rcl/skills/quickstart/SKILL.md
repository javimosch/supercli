# rcl Plugin

CLI tool: rcl.

## Commands
- `rcl <resource> <action>` — Execute rcl commands
- `rcl self version` — Print rcl version
- `rcl _ _` — Passthrough to rcl CLI

## Usage Examples
- "rcl --help"
- "rcl self version"

## Installation
```bash
apt-get install rcl 2>/dev/null || which rcl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
