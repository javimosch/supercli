# unxz Plugin

CLI tool: unxz.

## Commands
- `unxz <resource> <action>` — Execute unxz commands
- `unxz self version` — Print unxz version
- `unxz _ _` — Passthrough to unxz CLI

## Usage Examples
- "unxz --help"
- "unxz self version"

## Installation
```bash
apt-get install unxz 2>/dev/null || which unxz
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
