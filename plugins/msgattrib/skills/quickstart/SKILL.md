# msgattrib Plugin

CLI tool: msgattrib.

## Commands
- `msgattrib <resource> <action>` — Execute msgattrib commands
- `msgattrib self version` — Print msgattrib version
- `msgattrib _ _` — Passthrough to msgattrib CLI

## Usage Examples
- "msgattrib --help"
- "msgattrib self version"

## Installation
```bash
apt-get install msgattrib 2>/dev/null || which msgattrib
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
