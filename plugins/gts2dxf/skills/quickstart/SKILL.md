# gts2dxf Plugin

CLI tool: gts2dxf.

## Commands
- `gts2dxf <resource> <action>` — Execute gts2dxf commands
- `gts2dxf self version` — Print gts2dxf version
- `gts2dxf _ _` — Passthrough to gts2dxf CLI

## Usage Examples
- "gts2dxf --help"
- "gts2dxf self version"

## Installation
```bash
apt-get install gts2dxf 2>/dev/null || which gts2dxf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
