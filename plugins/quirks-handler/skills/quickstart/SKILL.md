# quirks-handler Plugin

CLI tool: quirks-handler.

## Commands
- `quirks-handler <resource> <action>` — Execute quirks-handler commands
- `quirks-handler self version` — Print quirks-handler version
- `quirks-handler _ _` — Passthrough to quirks-handler CLI

## Usage Examples
- "quirks-handler --help"
- "quirks-handler self version"

## Installation
```bash
apt-get install quirks-handler 2>/dev/null || which quirks-handler
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
