# pnmalias Plugin

CLI tool: pnmalias.

## Commands
- `pnmalias <resource> <action>` — Execute pnmalias commands
- `pnmalias self version` — Print pnmalias version
- `pnmalias _ _` — Passthrough to pnmalias CLI

## Usage Examples
- "pnmalias --help"
- "pnmalias self version"

## Installation
```bash
apt-get install pnmalias 2>/dev/null || which pnmalias
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
