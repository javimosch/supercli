# gvpack Plugin

CLI tool: gvpack.

## Commands
- `gvpack <resource> <action>` — Execute gvpack commands
- `gvpack self version` — Print gvpack version
- `gvpack _ _` — Passthrough to gvpack CLI

## Usage Examples
- "gvpack --help"
- "gvpack self version"

## Installation
```bash
apt-get install gvpack 2>/dev/null || which gvpack
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
