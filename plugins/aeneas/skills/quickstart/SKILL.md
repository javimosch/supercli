# aeneas Plugin

Align text to audio automatically in Python

## Commands

### Operations
- `aeneas self version` — Print aeneas version
- `aeneas _ _` — Passthrough to aeneas CLI

## Usage Examples
- `aeneas --help`
- `aeneas <args>`

## Installation

```bash
pip install aeneas
```

## Examples

```bash
aeneas --version
aeneas --help
```
