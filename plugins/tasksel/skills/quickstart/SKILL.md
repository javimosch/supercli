# tasksel Plugin

CLI tool: tasksel.

## Commands
- `tasksel <resource> <action>` — Execute tasksel commands
- `tasksel self version` — Print tasksel version
- `tasksel _ _` — Passthrough to tasksel CLI

## Usage Examples
- "tasksel --help"
- "tasksel self version"

## Installation
```bash
apt-get install tasksel 2>/dev/null || which tasksel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
