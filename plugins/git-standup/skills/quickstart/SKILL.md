# git-standup Plugin
Recall what you did on the last working day

## Commands
- `git-standup <resource> <action>` — Execute git-standup commands
- `git-standup _ _` — Passthrough to git-standup CLI

## Usage
- `git-standup _ _ <args>` — Run git-standup with any arguments
