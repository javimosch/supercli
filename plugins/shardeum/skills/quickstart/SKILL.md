# shardeum Plugin

Shardeum is an EVM based autoscaling blockchain

## Commands
- `shardeum <resource> <action>` — Execute shardeum commands
- `shardeum self version` — Print shardeum version
- `shardeum _ _` — Passthrough to shardeum CLI

## Installation

```bash
pip install shardeum
```
