# chatgpt-scraper Plugin

Easily collect responses from ChatGPT scraper by providing a prompt along with valid Web Scraper API credentials.

## Commands

### General
- `chatgpt-scraper self version` — Print chatgpt-scraper version
- `chatgpt-scraper _ _` — Passthrough to chatgpt-scraper CLI
