# blitz-mac Plugin

Native macOS App Store Connect tool with MCP. Submit iOS apps to App Store with AI agents 

## Commands

### General
- `blitz-mac self version` — Print blitz-mac version
- `blitz-mac _ _` — Passthrough to blitz-mac CLI

## Usage Examples
- "Run blitz-mac"
- "Use blitz-mac to Native macOS App Store Connect tool with MCP. Submit iOS app"

## Installation

```bash
pip install blitz-mac
```

## Key Features
- Native macOS App Store Connect tool with MCP. Submit iOS apps to App Store with AI agents 
- CLI tool, headless and scriptable
