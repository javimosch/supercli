# ovf2ovp Plugin

CLI tool: ovf2ovp.

## Commands
- `ovf2ovp <resource> <action>` — Execute ovf2ovp commands
- `ovf2ovp self version` — Print ovf2ovp version
- `ovf2ovp _ _` — Passthrough to ovf2ovp CLI

## Usage Examples
- "ovf2ovp --help"
- "ovf2ovp self version"

## Installation
```bash
apt-get install ovf2ovp 2>/dev/null || which ovf2ovp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
