# pgmedge Plugin

CLI tool: pgmedge.

## Commands
- `pgmedge <resource> <action>` — Execute pgmedge commands
- `pgmedge self version` — Print pgmedge version
- `pgmedge _ _` — Passthrough to pgmedge CLI

## Usage Examples
- "pgmedge --help"
- "pgmedge self version"

## Installation
```bash
apt-get install pgmedge 2>/dev/null || which pgmedge
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
