# zoxide Plugin

Zoxide — smart directory jumper with frecency tracking

## Commands
- `zoxide <resource> <action>` — Execute zoxide commands
- `zoxide self version` — Version

## Installation

```bash
cargo install zoxide
Verify: zoxide --version
```

## Commands

### `sc zoxide self version`

Version


## SuperCLI

```bash
sc zoxide _ _ --help
sc plugins learn zoxide
```
