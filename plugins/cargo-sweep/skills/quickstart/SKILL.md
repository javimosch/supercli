# cargo-sweep Plugin
Clean up old cargo build artifacts to free disk space

## Commands
- `cargo-sweep <resource> <action>` — Execute cargo-sweep commands
- `cargo-sweep _ _` — Passthrough to cargo-sweep CLI

## Usage
- `cargo-sweep _ _ <args>` — Run cargo-sweep with any arguments
