# xauth Plugin

CLI tool: xauth.

## Commands
- `xauth <resource> <action>` — Execute xauth commands
- `xauth self version` — Print xauth version
- `xauth _ _` — Passthrough to xauth CLI

## Usage Examples
- "xauth --help"
- "xauth self version"

## Installation
```bash
apt-get install xauth 2>/dev/null || which xauth
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
