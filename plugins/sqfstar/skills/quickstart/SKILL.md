# sqfstar Plugin

CLI tool: sqfstar.

## Commands
- `sqfstar <resource> <action>` — Execute sqfstar commands
- `sqfstar self version` — Print sqfstar version
- `sqfstar _ _` — Passthrough to sqfstar CLI

## Usage Examples
- "sqfstar --help"
- "sqfstar self version"

## Installation
```bash
apt-get install sqfstar 2>/dev/null || which sqfstar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
