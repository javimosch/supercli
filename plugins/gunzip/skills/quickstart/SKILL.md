# gunzip Plugin

CLI tool: gunzip.

## Commands
- `gunzip <resource> <action>` — Execute gunzip commands
- `gunzip self version` — Print gunzip version
- `gunzip _ _` — Passthrough to gunzip CLI

## Usage Examples
- "gunzip --help"
- "gunzip self version"

## Installation
```bash
apt-get install gunzip 2>/dev/null || which gunzip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
