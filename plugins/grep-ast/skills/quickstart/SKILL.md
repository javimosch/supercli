# grep-ast Plugin

CLI tool: grep-ast.

## Commands
- `grep-ast <resource> <action>` — Execute grep-ast commands
- `grep-ast self version` — Print grep-ast version
- `grep-ast _ _` — Passthrough to grep-ast CLI

## Usage Examples
- "grep-ast --help"
- "grep-ast self version"

## Installation
```bash
apt-get install grep-ast 2>/dev/null || which grep-ast
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
