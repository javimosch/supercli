# trmnl-firmware Plugin

TRMNL ePaper device firmware

## Commands

### General
- `trmnl-firmware self version` — Print trmnl-firmware version
- `trmnl-firmware _ _` — Passthrough to trmnl-firmware CLI

## Usage Examples
- "Run trmnl-firmware"
- "Use trmnl-firmware to TRMNL ePaper device firmware"

## Installation

```bash
pip install trmnl-firmware
```

## Key Features
- TRMNL ePaper device firmware
- CLI tool, headless and scriptable
