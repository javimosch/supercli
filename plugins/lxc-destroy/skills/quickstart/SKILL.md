# lxc-destroy Plugin

CLI tool: lxc-destroy.

## Commands
- `lxc-destroy <resource> <action>` — Execute lxc-destroy commands
- `lxc-destroy self version` — Print lxc-destroy version
- `lxc-destroy _ _` — Passthrough to lxc-destroy CLI

## Usage Examples
- "lxc-destroy --help"
- "lxc-destroy self version"

## Installation
```bash
apt-get install lxc-destroy 2>/dev/null || which lxc-destroy
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
