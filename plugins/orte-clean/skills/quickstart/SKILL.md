# orte-clean Plugin

CLI tool: orte-clean.

## Commands
- `orte-clean <resource> <action>` — Execute orte-clean commands
- `orte-clean self version` — Print orte-clean version
- `orte-clean _ _` — Passthrough to orte-clean CLI

## Usage Examples
- "orte-clean --help"
- "orte-clean self version"

## Installation
```bash
apt-get install orte-clean 2>/dev/null || which orte-clean
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
