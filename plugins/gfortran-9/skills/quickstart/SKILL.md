# gfortran-9 Plugin

CLI tool: gfortran-9.

## Commands
- `gfortran-9 <resource> <action>` — Execute gfortran-9 commands
- `gfortran-9 self version` — Print gfortran-9 version
- `gfortran-9 _ _` — Passthrough to gfortran-9 CLI

## Usage Examples
- "gfortran-9 --help"
- "gfortran-9 self version"

## Installation
```bash
apt-get install gfortran-9 2>/dev/null || which gfortran-9
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
