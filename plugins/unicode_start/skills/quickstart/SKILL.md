# unicode_start Plugin

CLI tool: unicode_start.

## Commands
- `unicode_start <resource> <action>` — Execute unicode_start commands
- `unicode_start self version` — Print unicode_start version
- `unicode_start _ _` — Passthrough to unicode_start CLI

## Usage Examples
- "unicode_start --help"
- "unicode_start self version"

## Installation
```bash
apt-get install unicode_start 2>/dev/null || which unicode_start
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
