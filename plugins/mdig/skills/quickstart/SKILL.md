# mdig Plugin

CLI tool: mdig.

## Commands
- `mdig <resource> <action>` — Execute mdig commands
- `mdig self version` — Print mdig version
- `mdig _ _` — Passthrough to mdig CLI

## Usage Examples
- "mdig --help"
- "mdig self version"

## Installation
```bash
apt-get install mdig 2>/dev/null || which mdig
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
