# ncurses5-config Plugin

CLI tool: ncurses5-config.

## Commands
- `ncurses5-config <resource> <action>` — Execute ncurses5-config commands
- `ncurses5-config self version` — Print ncurses5-config version
- `ncurses5-config _ _` — Passthrough to ncurses5-config CLI

## Usage Examples
- "ncurses5-config --help"
- "ncurses5-config self version"

## Installation
```bash
apt-get install ncurses5-config 2>/dev/null || which ncurses5-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
