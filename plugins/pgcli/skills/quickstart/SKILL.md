# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `pgcli <resource> <action>` — Execute pgcli commands
- `pgcli self version` — Print pgcli version
- `pgcli database connect` — Connect to PostgreSQL database
- `pgcli _ _` — Passthrough to pgcli CLI
