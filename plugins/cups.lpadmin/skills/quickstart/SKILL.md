# cups.lpadmin Plugin

CLI tool: cups.lpadmin.

## Commands
- `cups.lpadmin <resource> <action>` — Execute cups.lpadmin commands
- `cups.lpadmin self version` — Print cups.lpadmin version
- `cups.lpadmin _ _` — Passthrough to cups.lpadmin CLI

## Usage Examples
- "cups.lpadmin --help"
- "cups.lpadmin self version"

## Installation
```bash
apt-get install cups.lpadmin 2>/dev/null || which cups.lpadmin
```
