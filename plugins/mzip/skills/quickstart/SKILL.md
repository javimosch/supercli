# mzip Plugin

CLI tool: mzip.

## Commands
- `mzip <resource> <action>` — Execute mzip commands
- `mzip self version` — Print mzip version
- `mzip _ _` — Passthrough to mzip CLI

## Usage Examples
- "mzip --help"
- "mzip self version"

## Installation
```bash
apt-get install mzip 2>/dev/null || which mzip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
