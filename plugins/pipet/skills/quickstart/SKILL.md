# pipet Plugin

Swiss-army tool for scraping and extracting data from online assets, made for hackers 

## Commands

### General
- `pipet self version` — Print pipet version
- `pipet _ _` — Passthrough to pipet CLI

## Usage Examples
- "Run pipet"
- "Use pipet to Swiss-army tool for scraping and extracting data from online"

## Installation

```bash
pip install pipet
```

## Key Features
- Swiss-army tool for scraping and extracting data from online assets, made for hackers 
- CLI tool, headless and scriptable
