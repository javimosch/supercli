# mysqloptimize Plugin

CLI tool: mysqloptimize.

## Commands
- `mysqloptimize <resource> <action>` — Execute mysqloptimize commands
- `mysqloptimize self version` — Print mysqloptimize version
- `mysqloptimize _ _` — Passthrough to mysqloptimize CLI

## Usage Examples
- "mysqloptimize --help"
- "mysqloptimize self version"

## Installation
```bash
apt-get install mysqloptimize 2>/dev/null || which mysqloptimize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
