# fixwpps Plugin

CLI tool: fixwpps.

## Commands
- `fixwpps <resource> <action>` — Execute fixwpps commands
- `fixwpps self version` — Print fixwpps version
- `fixwpps _ _` — Passthrough to fixwpps CLI

- "fixwpps self version"
