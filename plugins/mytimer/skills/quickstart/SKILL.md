# mytimer Plugin

Geeky timer for terminal enthusiasts in Python

## Commands

### Operations
- `mytimer self version` — Print mytimer version
- `mytimer _ _` — Passthrough to mytimer CLI

## Usage Examples
- `mytimer --help`
- `mytimer <args>`

## Installation

```bash
pip install mytimer
```

## Examples

```bash
mytimer --version
mytimer --help
```
