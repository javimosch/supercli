# mempalace Plugin

The best-benchmarked open-source AI memory system. And it's free.

## Commands
- `mempalace <resource> <action>` — Execute mempalace commands
- `mempalace self version` — Print mempalace version
- `mempalace _ _` — Passthrough to mempalace CLI

## Installation

```bash
pip install mempalace
```
