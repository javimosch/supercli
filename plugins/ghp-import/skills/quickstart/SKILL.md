# ghp-import Plugin

CLI tool: ghp-import.

## Commands
- `ghp-import <resource> <action>` — Execute ghp-import commands
- `ghp-import self version` — Print ghp-import version
- `ghp-import _ _` — Passthrough to ghp-import CLI

## Usage Examples
- "ghp-import --help"
- "ghp-import self version"

## Installation
```bash
apt-get install ghp-import 2>/dev/null || which ghp-import
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
