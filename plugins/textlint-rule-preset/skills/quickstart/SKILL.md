# textlint-rule-preset Plugin
Preset of textlint rules for technical writing

## Commands
- `textlint-rule-preset <resource> <action>` — Execute textlint-rule-preset commands
- `textlint-rule-preset _ _` — Passthrough to textlint-rule-preset CLI

## Usage
- `textlint-rule-preset _ _ <args>` — Run textlint-rule-preset with any arguments
