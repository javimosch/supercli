# e-q-c Plugin
Simple CLI calculator for scientific and engineering unit conversions

## Commands
- `e-q-c <resource> <action>` — Execute e-q-c commands
- `e-q-c _ _` — Passthrough to e-q-c CLI

## Usage
- `e-q-c _ _ <args>` — Run e-q-c with any arguments
