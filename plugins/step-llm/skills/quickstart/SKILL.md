# step-llm Plugin
CLI for generating parametric CAD/STEP models from natural language

## Commands
- `step-llm <resource> <action>` — Execute step-llm commands
- `step-llm _ _` — Passthrough to step-llm CLI

## Usage
- `step-llm _ _ <args>` — Run step-llm with any arguments
