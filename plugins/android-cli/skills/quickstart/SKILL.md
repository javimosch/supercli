# android-cli Plugin
Build and release Android apps without full Android Studio

## Commands
- `android-cli <resource> <action>` — Execute android-cli commands
- `android-cli _ _` — Passthrough to android-cli CLI

## Usage
- `android-cli _ _ <args>` — Run android-cli with any arguments
