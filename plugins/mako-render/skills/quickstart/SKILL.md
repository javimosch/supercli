# mako-render Plugin

CLI tool: mako-render.

## Commands
- `mako-render <resource> <action>` — Execute mako-render commands
- `mako-render self version` — Print mako-render version
- `mako-render _ _` — Passthrough to mako-render CLI

## Usage Examples
- "mako-render --help"
- "mako-render self version"

## Installation
```bash
apt-get install mako-render 2>/dev/null || which mako-render
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
