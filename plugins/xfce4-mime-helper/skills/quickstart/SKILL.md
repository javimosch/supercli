# xfce4-mime-helper Plugin

CLI tool: xfce4-mime-helper.

## Commands
- `xfce4-mime-helper <resource> <action>` — Execute xfce4-mime-helper commands
- `xfce4-mime-helper self version` — Print xfce4-mime-helper version
- `xfce4-mime-helper _ _` — Passthrough to xfce4-mime-helper CLI

## Usage Examples
- "xfce4-mime-helper --help"
- "xfce4-mime-helper self version"

## Installation
```bash
apt-get install xfce4-mime-helper 2>/dev/null || which xfce4-mime-helper
```
