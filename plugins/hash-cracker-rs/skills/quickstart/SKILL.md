# hash-cracker-rs Plugin
Simple dictionary-based hash cracker in Rust

## Commands
- `hash-cracker-rs <resource> <action>` — Execute hash-cracker-rs commands
- `hash-cracker-rs _ _` — Passthrough to hash-cracker-rs CLI

## Usage
- `hash-cracker-rs _ _ <args>` — Run hash-cracker-rs with any arguments
