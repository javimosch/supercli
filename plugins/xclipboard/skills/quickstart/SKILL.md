# xclipboard Plugin

CLI tool: xclipboard.

## Commands
- `xclipboard <resource> <action>` — Execute xclipboard commands
- `xclipboard self version` — Print xclipboard version
- `xclipboard _ _` — Passthrough to xclipboard CLI

## Usage Examples
- "xclipboard --help"
- "xclipboard self version"

## Installation
```bash
apt-get install xclipboard 2>/dev/null || which xclipboard
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
