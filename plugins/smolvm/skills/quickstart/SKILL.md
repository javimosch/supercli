# smolvm Plugin

Tool to build & run portable, lightweight, self-contained virtual machines.

## Commands

### General
- `smolvm self version` — Print smolvm version
- `smolvm _ _` — Passthrough to smolvm CLI

## Usage Examples
- "Run smolvm"
- "Use smolvm to Tool to build & run portable, lightweight, self-contained vi"

## Installation

```bash
pip install smolvm
```

## Key Features
- Tool to build & run portable, lightweight, self-contained virtual machines.
- CLI tool, headless and scriptable
