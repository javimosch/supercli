# bookstack-cli Plugin
BookStack documentation CLI.
## Commands
- `bookstack-cli _ _` — Passthrough to bookstack-cli CLI
## Installation
```bash
npm install -g @junovy/bookstack-cli
```
## Key Features
- **Docs automation** — Manage BookStack via CLI
- **JSON output** — Structured data
- **CI/CD ready** — Pipeline integration
