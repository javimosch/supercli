# gpic Plugin

CLI tool: gpic.

## Commands
- `gpic <resource> <action>` — Execute gpic commands
- `gpic self version` — Print gpic version
- `gpic _ _` — Passthrough to gpic CLI

## Usage Examples
- "gpic --help"
- "gpic self version"

## Installation
```bash
apt-get install gpic 2>/dev/null || which gpic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
