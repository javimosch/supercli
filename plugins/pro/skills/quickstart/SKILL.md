# pro Plugin

CLI tool: pro.

## Commands
- `pro <resource> <action>` — Execute pro commands
- `pro self version` — Print pro version
- `pro _ _` — Passthrough to pro CLI

## Usage Examples
- "pro --help"
- "pro self version"

## Installation
```bash
apt-get install pro 2>/dev/null || which pro
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
