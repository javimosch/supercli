# grpconv Plugin

CLI tool: grpconv.

## Commands
- `grpconv <resource> <action>` — Execute grpconv commands
- `grpconv self version` — Print grpconv version
- `grpconv _ _` — Passthrough to grpconv CLI

## Usage Examples
- "grpconv --help"
- "grpconv self version"

## Installation
```bash
apt-get install grpconv 2>/dev/null || which grpconv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
