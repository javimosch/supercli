# lcf Plugin

CLI tool: lcf.

## Commands
- `lcf <resource> <action>` — Execute lcf commands
- `lcf self version` — Print lcf version
- `lcf _ _` — Passthrough to lcf CLI

## Usage Examples
- "lcf --help"
- "lcf self version"

## Installation
```bash
apt-get install lcf 2>/dev/null || which lcf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
