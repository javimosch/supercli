# rcssmin Plugin
Fast CSS minifier with C-coded backend

## Commands
- `rcssmin <resource> <action>` — Execute rcssmin commands
- `rcssmin _ _` — Passthrough to rcssmin CLI

## Usage
- `rcssmin _ _ <args>` — Run rcssmin with any arguments
