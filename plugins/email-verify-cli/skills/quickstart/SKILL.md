# email-verify-cli Plugin
Simple CLI check for email address syntax validation

## Commands
- `email-verify-cli <resource> <action>` — Execute email-verify-cli commands
- `email-verify-cli _ _` — Passthrough to email-verify-cli CLI

## Usage
- `email-verify-cli _ _ <args>` — Run email-verify-cli with any arguments
