# incus Plugin

Powerful system container and virtual machine manager 

## Commands
- `incus <resource> <action>` — Execute incus commands
- `incus self version` — Print incus version
- `incus _ _` — Passthrough to incus CLI

## Installation

```bash
pip install incus
```
