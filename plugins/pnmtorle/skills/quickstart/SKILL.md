# pnmtorle Plugin

CLI tool: pnmtorle.

## Commands
- `pnmtorle <resource> <action>` — Execute pnmtorle commands
- `pnmtorle self version` — Print pnmtorle version
- `pnmtorle _ _` — Passthrough to pnmtorle CLI

## Usage Examples
- "pnmtorle --help"
- "pnmtorle self version"

## Installation
```bash
apt-get install pnmtorle 2>/dev/null || which pnmtorle
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
