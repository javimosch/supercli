# ppmtopj Plugin

CLI tool: ppmtopj.

## Commands
- `ppmtopj <resource> <action>` — Execute ppmtopj commands
- `ppmtopj self version` — Print ppmtopj version
- `ppmtopj _ _` — Passthrough to ppmtopj CLI

## Usage Examples
- "ppmtopj --help"
- "ppmtopj self version"

## Installation
```bash
apt-get install ppmtopj 2>/dev/null || which ppmtopj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
