# prr Plugin

AI-powered pull request reviewer in your terminal — headless JSON review mode for CI

## Commands
- `prr self version` — Print prr version
- `prr _ _` — Passthrough to prr CLI

## Usage Examples
- `prr self version` — Check installed version
- `prr _ _ --help` — Show prr help
- `prr _ _ --json` — JSON output mode

## Installation
```bash
go install github.com/andreujuanc/prr@latest
```

## Key Features
- code-review, pull-request, ai, golang
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
