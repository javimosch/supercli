# piper Plugin
Fast local neural text-to-speech engine with CLI interface

## Commands
- `piper <resource> <action>` — Execute piper commands
- `piper _ _` — Passthrough to piper CLI

## Usage
- `piper _ _ <args>` — Run piper with any arguments
