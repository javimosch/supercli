# cups.cupsfilter Plugin

CLI tool: cups.cupsfilter.

## Commands
- `cups.cupsfilter <resource> <action>` — Execute cups.cupsfilter commands
- `cups.cupsfilter self version` — Print cups.cupsfilter version
- `cups.cupsfilter _ _` — Passthrough to cups.cupsfilter CLI

## Usage Examples
- "cups.cupsfilter --help"
- "cups.cupsfilter self version"

## Installation
```bash
apt-get install cups.cupsfilter 2>/dev/null || which cups.cupsfilter
```
