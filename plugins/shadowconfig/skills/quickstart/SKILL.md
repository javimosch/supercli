# shadowconfig Plugin

CLI tool: shadowconfig.

## Commands
- `shadowconfig <resource> <action>` — Execute shadowconfig commands
- `shadowconfig self version` — Print shadowconfig version
- `shadowconfig _ _` — Passthrough to shadowconfig CLI

## Usage Examples
- "shadowconfig --help"
- "shadowconfig self version"

## Installation
```bash
apt-get install shadowconfig 2>/dev/null || which shadowconfig
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
