# llama-swap Plugin

Reliable model swapping for any local OpenAI/Anthropic compatible server - llama.cpp, vllm, etc

## Commands

### General
- `llama-swap self version` — Print llama-swap version
- `llama-swap _ _` — Passthrough to llama-swap CLI
