# oxc Plugin

⚓ A collection of high-performance JavaScript tools.

## Commands
- `oxc <resource> <action>` — Execute oxc commands
- `oxc self version` — Print oxc version
- `oxc _ _` — Passthrough to oxc CLI

## Installation

```bash
pip install oxc
```
