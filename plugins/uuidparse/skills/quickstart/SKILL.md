# uuidparse Plugin

CLI tool: uuidparse.

## Commands
- `uuidparse <resource> <action>` — Execute uuidparse commands
- `uuidparse self version` — Print uuidparse version
- `uuidparse _ _` — Passthrough to uuidparse CLI

## Usage Examples
- "uuidparse --help"
- "uuidparse self version"

## Installation
```bash
apt-get install uuidparse 2>/dev/null || which uuidparse
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
