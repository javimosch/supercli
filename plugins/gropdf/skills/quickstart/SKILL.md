# gropdf Plugin

CLI tool: gropdf.

## Commands
- `gropdf <resource> <action>` — Execute gropdf commands
- `gropdf self version` — Print gropdf version
- `gropdf _ _` — Passthrough to gropdf CLI

## Usage Examples
- "gropdf --help"
- "gropdf self version"

## Installation
```bash
apt-get install gropdf 2>/dev/null || which gropdf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
