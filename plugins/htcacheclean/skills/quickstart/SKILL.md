# htcacheclean Plugin

CLI tool: htcacheclean.

## Commands
- `htcacheclean <resource> <action>` — Execute htcacheclean commands
- `htcacheclean self version` — Print htcacheclean version
- `htcacheclean _ _` — Passthrough to htcacheclean CLI
