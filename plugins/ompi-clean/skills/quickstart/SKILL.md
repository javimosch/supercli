# ompi-clean Plugin

CLI tool: ompi-clean.

## Commands
- `ompi-clean <resource> <action>` — Execute ompi-clean commands
- `ompi-clean self version` — Print ompi-clean version
- `ompi-clean _ _` — Passthrough to ompi-clean CLI

## Usage Examples
- "ompi-clean --help"
- "ompi-clean self version"

## Installation
```bash
apt-get install ompi-clean 2>/dev/null || which ompi-clean
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
