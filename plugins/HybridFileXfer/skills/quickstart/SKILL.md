# HybridFileXfer Plugin

多轨快传，同时使用USB和5G与2.4GWIFI等通道传输文件到电脑，榨干手机IO！

## Commands

### General
- `HybridFileXfer self version` — Print HybridFileXfer version
- `HybridFileXfer _ _` — Passthrough to hybridfilexfer CLI

## Usage Examples
- "Run HybridFileXfer"
- "Use hybridfilexfer to 多轨快传，同时使用USB和5G与2.4GWIFI等通道传输文件到电脑，榨干手机IO！"

## Installation

```bash
pip install hybridfilexfer
```

## Key Features
- 多轨快传，同时使用USB和5G与2.4GWIFI等通道传输文件到电脑，榨干手机IO！
