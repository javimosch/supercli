# genrb Plugin

CLI tool: genrb.

## Commands
- `genrb <resource> <action>` — Execute genrb commands
- `genrb self version` — Print genrb version
- `genrb _ _` — Passthrough to genrb CLI

## Usage Examples
- "genrb --help"
- "genrb self version"

## Installation
```bash
apt-get install genrb 2>/dev/null || which genrb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
