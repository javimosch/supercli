# pgmnorm Plugin

CLI tool: pgmnorm.

## Commands
- `pgmnorm <resource> <action>` — Execute pgmnorm commands
- `pgmnorm self version` — Print pgmnorm version
- `pgmnorm _ _` — Passthrough to pgmnorm CLI

## Usage Examples
- "pgmnorm --help"
- "pgmnorm self version"

## Installation
```bash
apt-get install pgmnorm 2>/dev/null || which pgmnorm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
