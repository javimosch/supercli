# Rust-stakeholder Plugin

generate impressive fake terminal output for demos

## Commands
- `rust-stakeholder self version` — Print rust-stakeholder version
- `rust-stakeholder _ _` — Passthrough to rust-stakeholder CLI

## Usage Examples
- "Generate impressive terminal demo output"
- "Create a fake build output"
- "Simulate a deployment process"

## Installation

```bash
cargo install rust-stakeholder
```

## Examples
```bash
rust-stakeholder demo --type build
rust-stakeholder fake --scenario deploy
```

## Key Features
- Realistic-looking terminal output
- Multiple demo scenarios
- Customizable output
- Great for presentations
