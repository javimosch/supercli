# dvilj4 Plugin

CLI tool: dvilj4.

## Commands
- `dvilj4 <resource> <action>` — Execute dvilj4 commands
- `dvilj4 self version` — Print dvilj4 version
- `dvilj4 _ _` — Passthrough to dvilj4 CLI

## Usage Examples
- "dvilj4 --help"
- "dvilj4 self version"

## Installation
```bash
apt-get install dvilj4 2>/dev/null || which dvilj4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
