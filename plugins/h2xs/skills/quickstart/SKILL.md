# h2xs Plugin

CLI tool: h2xs.

## Commands
- `h2xs <resource> <action>` — Execute h2xs commands
- `h2xs self version` — Print h2xs version
- `h2xs _ _` — Passthrough to h2xs CLI

## Usage Examples
- "h2xs --help"
- "h2xs self version"

## Installation
```bash
apt-get install h2xs 2>/dev/null || which h2xs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
