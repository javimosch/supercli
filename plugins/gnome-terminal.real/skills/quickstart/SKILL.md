# gnome-terminal.real Plugin

CLI tool: gnome-terminal.real.

## Commands
- `gnome-terminal.real <resource> <action>` — Execute gnome-terminal.real commands
- `gnome-terminal.real self version` — Print gnome-terminal.real version
- `gnome-terminal.real _ _` — Passthrough to gnome-terminal.real CLI

## Usage Examples
- "gnome-terminal.real --help"
- "gnome-terminal.real self version"

## Installation
```bash
apt-get install gnome-terminal.real 2>/dev/null || which gnome-terminal.real
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
