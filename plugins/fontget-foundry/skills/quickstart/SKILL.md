# fontget-foundry Plugin
Discover and manage font collections from multiple sources

## Commands
- `fontget-foundry <resource> <action>` — Execute fontget-foundry commands
- `fontget-foundry _ _` — Passthrough to fontget-foundry CLI

## Usage
- `fontget-foundry _ _ <args>` — Run fontget-foundry with any arguments
