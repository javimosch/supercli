# pathoc Plugin

CLI tool: pathoc.

## Commands
- `pathoc <resource> <action>` — Execute pathoc commands
- `pathoc self version` — Print pathoc version
- `pathoc _ _` — Passthrough to pathoc CLI

## Usage Examples
- "pathoc --help"
- "pathoc self version"

## Installation
```bash
apt-get install pathoc 2>/dev/null || which pathoc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
