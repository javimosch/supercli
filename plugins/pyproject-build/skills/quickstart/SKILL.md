# pyproject-build Plugin

CLI tool: pyproject-build.

## Commands
- `pyproject-build <resource> <action>` — Execute pyproject-build commands
- `pyproject-build self version` — Print pyproject-build version
- `pyproject-build _ _` — Passthrough to pyproject-build CLI

## Usage Examples
- "pyproject-build --help"
- "pyproject-build self version"

## Installation
```bash
apt-get install pyproject-build 2>/dev/null || which pyproject-build
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
