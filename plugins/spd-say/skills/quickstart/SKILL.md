# spd-say Plugin

CLI tool: spd-say.

## Commands
- `spd-say <resource> <action>` — Execute spd-say commands
- `spd-say self version` — Print spd-say version
- `spd-say _ _` — Passthrough to spd-say CLI

## Usage Examples
- "spd-say --help"
- "spd-say self version"

## Installation
```bash
apt-get install spd-say 2>/dev/null || which spd-say
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
