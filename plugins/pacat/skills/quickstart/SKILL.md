# pacat Plugin

CLI tool: pacat.

## Commands
- `pacat <resource> <action>` — Execute pacat commands
- `pacat self version` — Print pacat version
- `pacat _ _` — Passthrough to pacat CLI

## Usage Examples
- "pacat --help"
- "pacat self version"

## Installation
```bash
apt-get install pacat 2>/dev/null || which pacat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
