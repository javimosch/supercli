# nomnoml-cli Plugin
Render UML diagrams from plain text descriptions

## Commands
- `nomnoml-cli <resource> <action>` — Execute nomnoml-cli commands
- `nomnoml-cli _ _` — Passthrough to nomnoml-cli CLI

## Usage
- `nomnoml-cli _ _ <args>` — Run nomnoml-cli with any arguments
