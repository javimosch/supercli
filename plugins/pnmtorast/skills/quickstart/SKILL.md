# pnmtorast Plugin

CLI tool: pnmtorast.

## Commands
- `pnmtorast <resource> <action>` — Execute pnmtorast commands
- `pnmtorast self version` — Print pnmtorast version
- `pnmtorast _ _` — Passthrough to pnmtorast CLI

## Usage Examples
- "pnmtorast --help"
- "pnmtorast self version"

## Installation
```bash
apt-get install pnmtorast 2>/dev/null || which pnmtorast
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
