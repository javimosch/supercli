# gnupg-pinentry
pinentry — PIN entry dialog for GnuPG. Enter passphrases and PINs for GPG/SSH keys from CLI.

## Commands
- `gnupg-pinentry <resource> <action>` — Execute gnupg-pinentry commands
- `gnupg pinentry run` — pinentry — PIN entry dialog for GnuPG. Enter passphrases and PINs for GPG/SSH keys from CLI.
