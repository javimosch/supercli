# datahaven Plugin

An EVM compatible Substrate chain, powered by StorageHub and secured by EigenLayer

## Commands
- `datahaven <resource> <action>` — Execute datahaven commands
- `datahaven self version` — Print datahaven version
- `datahaven _ _` — Passthrough to datahaven CLI

## Installation

```bash
pip install datahaven
```
