# OK-Skills — Curated AI Coding Agent Skills

Curated SKILL.md files and AGENTS.md playbooks for Codex, Claude Code, Cursor, OpenClaw, and other SKILL.md-compatible tools.

## Installation
```bash
git clone https://github.com/mxyhi/ok-skills.git
sc skills teach ok-skills:quickstart
```

## What's Included
- **SKILL.md files** — Reusable skills for common development tasks
- **AGENTS.md playbooks** — Workflow configurations for different agent tools
- Coverage: code generation, testing, refactoring, project setup, and more

## Usage
Browse the collection to find skills matching your development needs. Each skill is self-contained and platform-agnostic.
