# mobi-convert Plugin
Convert files to Kindle MOBI ebook format from CLI

## Commands
- `mobi-convert <resource> <action>` — Execute mobi-convert commands
- `mobi-convert _ _` — Passthrough to mobi-convert CLI

## Usage
- `mobi-convert _ _ <args>` — Run mobi-convert with any arguments
