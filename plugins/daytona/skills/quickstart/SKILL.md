# daytona Plugin

Daytona is a Secure and Elastic Infrastructure for Running AI-Generated Code

## Commands
- `daytona <resource> <action>` — Execute daytona commands
- `daytona self version` — Print daytona version
- `daytona _ _` — Passthrough to daytona CLI

## Installation

```bash
pip install daytona
```
