# OpenGlass Plugin

Turn any glasses into AI-powered smart glasses

## Commands

### General
- `OpenGlass self version` — Print OpenGlass version
- `OpenGlass _ _` — Passthrough to openglass CLI

## Usage Examples
- "Run OpenGlass"
- "Use openglass to Turn any glasses into AI-powered smart glasses"

## Installation

```bash
pip install openglass
```

## Key Features
- Turn any glasses into AI-powered smart glasses
- CLI tool, headless and scriptable
