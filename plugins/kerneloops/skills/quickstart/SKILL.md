# kerneloops Plugin

CLI tool: kerneloops.

## Commands
- `kerneloops <resource> <action>` — Execute kerneloops commands
- `kerneloops self version` — Print kerneloops version
- `kerneloops _ _` — Passthrough to kerneloops CLI

## Usage Examples
- "kerneloops --help"
- "kerneloops self version"

## Installation
```bash
apt-get install kerneloops 2>/dev/null || which kerneloops
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
