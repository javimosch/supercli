# git-interactive-rebase-tool Plugin
Full-featured terminal rebase replacement

## Commands
- `git-interactive-rebase-tool <resource> <action>` — Execute git-interactive-rebase-tool commands
- `git-interactive-rebase-tool _ _` — Passthrough to git-interactive-rebase-tool CLI

## Usage
- `git-interactive-rebase-tool _ _ <args>` — Run git-interactive-rebase-tool with any arguments
