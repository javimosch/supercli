# teamviewer Plugin

CLI tool: teamviewer.

## Commands
- `teamviewer <resource> <action>` — Execute teamviewer commands
- `teamviewer self version` — Print teamviewer version
- `teamviewer _ _` — Passthrough to teamviewer CLI

## Usage Examples
- "teamviewer --help"
- "teamviewer self version"

## Installation
```bash
apt-get install teamviewer 2>/dev/null || which teamviewer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
