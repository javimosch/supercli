# gitattributes Plugin
Generate .gitattributes files from templates

## Commands
- `gitattributes <resource> <action>` — Execute gitattributes commands
- `gitattributes _ _` — Passthrough to gitattributes CLI

## Usage
- `gitattributes _ _ <args>` — Run gitattributes with any arguments
