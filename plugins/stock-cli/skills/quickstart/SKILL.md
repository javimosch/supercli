# stock-cli Plugin
Simple terminal tool for basic stock price lookups

## Commands
- `stock-cli <resource> <action>` — Execute stock-cli commands
- `stock-cli _ _` — Passthrough to stock-cli CLI

## Usage
- `stock-cli _ _ <args>` — Run stock-cli with any arguments
