# dokploy Plugin

Open Source Alternative to Vercel, Netlify and Heroku.

## Commands

### General
- `dokploy self version` — Print dokploy version
- `dokploy _ _` — Passthrough to dokploy CLI

## Usage Examples
- "Run dokploy"
- "Use dokploy to Open Source Alternative to Vercel, Netlify and Heroku."

## Installation

```bash
pip install dokploy
```

## Key Features
- Open Source Alternative to Vercel, Netlify and Heroku.
- CLI tool, headless and scriptable
