# dokploy Plugin

Open Source Alternative to Vercel, Netlify and Heroku.

## Commands
- `dokploy <resource> <action>` — Execute dokploy commands
- `dokploy self version` — Print dokploy version
- `dokploy _ _` — Passthrough to dokploy CLI

## Installation

```bash
pip install dokploy
```
