# sbsiglist Plugin

CLI tool: sbsiglist.

## Commands
- `sbsiglist <resource> <action>` — Execute sbsiglist commands
- `sbsiglist self version` — Print sbsiglist version
- `sbsiglist _ _` — Passthrough to sbsiglist CLI

## Usage Examples
- "sbsiglist --help"
- "sbsiglist self version"

## Installation
```bash
apt-get install sbsiglist 2>/dev/null || which sbsiglist
```
