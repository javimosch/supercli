# ldapurl Plugin

CLI tool: ldapurl.

## Commands
- `ldapurl <resource> <action>` — Execute ldapurl commands
- `ldapurl self version` — Print ldapurl version
- `ldapurl _ _` — Passthrough to ldapurl CLI

## Usage Examples
- "ldapurl --help"
- "ldapurl self version"

## Installation
```bash
apt-get install ldapurl 2>/dev/null || which ldapurl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
