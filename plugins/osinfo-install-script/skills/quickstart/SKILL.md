# osinfo-install-script Plugin

CLI tool: osinfo-install-script.

## Commands
- `osinfo-install-script <resource> <action>` — Execute osinfo-install-script commands
- `osinfo-install-script self version` — Print osinfo-install-script version
- `osinfo-install-script _ _` — Passthrough to osinfo-install-script CLI

## Usage Examples
- "osinfo-install-script --help"
- "osinfo-install-script self version"

## Installation
```bash
apt-get install osinfo-install-script 2>/dev/null || which osinfo-install-script
```

- Scriptable and automatable
