# zoom Plugin

zoom — player for Z-Code stories or games.

## Commands
- `zoom <resource> <action>` — Execute zoom commands
- `zoom self version` — Print zoom version
- `zoom _ _` — Passthrough to zoom CLI

## Usage Examples
- "zoom --help"
- "zoom self version"

## Installation
```bash
apt-get install zoom-player 2>/dev/null || which zoom
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
