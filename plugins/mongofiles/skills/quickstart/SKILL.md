# mongofiles Plugin

CLI tool: mongofiles.

## Commands
- `mongofiles <resource> <action>` — Execute mongofiles commands
- `mongofiles self version` — Print mongofiles version
- `mongofiles _ _` — Passthrough to mongofiles CLI

## Usage Examples
- "mongofiles --help"
- "mongofiles self version"

## Installation
```bash
apt-get install mongofiles 2>/dev/null || which mongofiles
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
