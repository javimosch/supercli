# tkconch3 Plugin

CLI tool: tkconch3.

## Commands
- `tkconch3 <resource> <action>` — Execute tkconch3 commands
- `tkconch3 self version` — Print tkconch3 version
- `tkconch3 _ _` — Passthrough to tkconch3 CLI

## Usage Examples
- "tkconch3 --help"
- "tkconch3 self version"

## Installation
```bash
apt-get install tkconch3 2>/dev/null || which tkconch3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
