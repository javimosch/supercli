# a2a-spawn Plugin

CLI tool: a2a-spawn.

## Commands
- `a2a-spawn <resource> <action>` — Execute a2a-spawn commands
- `a2a-spawn self version` — Print a2a-spawn version
- `a2a-spawn _ _` — Passthrough to a2a-spawn CLI

## Usage Examples
- "a2a-spawn --help"
- "a2a-spawn self version"

## Installation
```bash
apt-get install a2a-spawn 2>/dev/null || which a2a-spawn
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
