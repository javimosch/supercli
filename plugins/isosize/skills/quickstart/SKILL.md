# isosize Plugin

CLI tool: isosize.

## Commands
- `isosize <resource> <action>` — Execute isosize commands
- `isosize self version` — Print isosize version
- `isosize _ _` — Passthrough to isosize CLI

## Usage Examples
- "isosize --help"
- "isosize self version"

## Installation
```bash
apt-get install isosize 2>/dev/null || which isosize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
