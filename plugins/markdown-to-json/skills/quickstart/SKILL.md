# markdown-to-json Plugin
Convert markdown to structured JSON data

## Commands
- `markdown-to-json <resource> <action>` — Execute markdown-to-json commands
- `markdown-to-json _ _` — Passthrough to markdown-to-json CLI

## Usage
- `markdown-to-json _ _ <args>` — Run markdown-to-json with any arguments
