# docling Plugin

Get documents ready for generative AI

## Commands

### Version
`docling self version` — Print docling version

### Passthrough
`docling _ _` — Passthrough to docling CLI with all arguments forwarded.

## Usage Examples

```bash
docling --version
docling --help
```

## Installation

```bash
pip install docling
```

## Key Features
- Get documents ready for generative AI
