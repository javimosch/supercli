# linguist Plugin

CLI tool: linguist.

## Commands
- `linguist <resource> <action>` — Execute linguist commands
- `linguist self version` — Print linguist version
- `linguist _ _` — Passthrough to linguist CLI

## Usage Examples
- "linguist --help"
- "linguist self version"

## Installation
```bash
apt-get install linguist 2>/dev/null || which linguist
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
