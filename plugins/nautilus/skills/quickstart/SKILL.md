# nautilus Plugin

CLI tool: nautilus.

## Commands
- `nautilus <resource> <action>` — Execute nautilus commands
- `nautilus self version` — Print nautilus version
- `nautilus _ _` — Passthrough to nautilus CLI

## Usage Examples
- "nautilus --help"
- "nautilus self version"

## Installation
```bash
apt-get install nautilus 2>/dev/null || which nautilus
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
