# vcstime Plugin

CLI tool: vcstime.

## Commands
- `vcstime <resource> <action>` — Execute vcstime commands
- `vcstime self version` — Print vcstime version
- `vcstime _ _` — Passthrough to vcstime CLI

## Usage Examples
- "vcstime --help"
- "vcstime self version"

## Installation
```bash
apt-get install vcstime 2>/dev/null || which vcstime
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
