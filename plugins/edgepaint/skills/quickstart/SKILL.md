# edgepaint Plugin

CLI tool: edgepaint.

## Commands
- `edgepaint <resource> <action>` — Execute edgepaint commands
- `edgepaint self version` — Print edgepaint version
- `edgepaint _ _` — Passthrough to edgepaint CLI

## Usage Examples
- "edgepaint --help"
- "edgepaint self version"

## Installation
```bash
apt-get install edgepaint 2>/dev/null || which edgepaint
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
