# libtoolize Plugin

CLI tool: libtoolize.

## Commands
- `libtoolize <resource> <action>` — Execute libtoolize commands
- `libtoolize self version` — Print libtoolize version
- `libtoolize _ _` — Passthrough to libtoolize CLI

## Usage Examples
- "libtoolize --help"
- "libtoolize self version"

## Installation
```bash
apt-get install libtoolize 2>/dev/null || which libtoolize
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
