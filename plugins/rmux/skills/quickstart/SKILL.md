# rmux Plugin
Native terminal multiplexer in Rust with programmable SDK

## Commands
- `rmux <resource> <action>` — Execute rmux commands
- `rmux _ _` — Passthrough to rmux CLI

## Usage
- `rmux _ _ <args>` — Run rmux with any arguments
