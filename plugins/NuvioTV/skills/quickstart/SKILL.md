# NuvioTV Plugin

Official Nuvio Android TV Repository

## Commands

### General
- `NuvioTV self version` — Print NuvioTV version
- `NuvioTV _ _` — Passthrough to nuviotv CLI

## Usage Examples
- "Run NuvioTV"

```bash
pip install nuviotv
```
