# thin_delta Plugin

CLI tool: thin_delta.

## Commands
- `thin_delta <resource> <action>` — Execute thin_delta commands
- `thin_delta self version` — Print thin_delta version
- `thin_delta _ _` — Passthrough to thin_delta CLI

## Usage Examples
- "thin_delta --help"
- "thin_delta self version"

```bash
apt-get install thin_delta 2>/dev/null || which thin_delta
```
