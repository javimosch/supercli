# thunar Plugin

CLI tool: thunar.

## Commands
- `thunar <resource> <action>` — Execute thunar commands
- `thunar self version` — Print thunar version
- `thunar _ _` — Passthrough to thunar CLI

## Usage Examples
- "thunar --help"
- "thunar self version"

## Installation
```bash
apt-get install thunar 2>/dev/null || which thunar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
