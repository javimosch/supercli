# prepmx Plugin

CLI tool: prepmx.

## Commands
- `prepmx <resource> <action>` — Execute prepmx commands
- `prepmx self version` — Print prepmx version
- `prepmx _ _` — Passthrough to prepmx CLI

## Usage Examples
- "prepmx --help"
- "prepmx self version"

## Installation
```bash
apt-get install prepmx 2>/dev/null || which prepmx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
