# nbt-dump Plugin
Inspect and edit Minecraft NBT data format files

## Commands
- `nbt-dump <resource> <action>` — Execute nbt-dump commands
- `nbt-dump _ _` — Passthrough to nbt-dump CLI

## Usage
- `nbt-dump _ _ <args>` — Run nbt-dump with any arguments
