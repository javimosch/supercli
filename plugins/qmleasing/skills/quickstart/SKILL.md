# qmleasing Plugin

CLI tool: qmleasing.

## Commands
- `qmleasing <resource> <action>` — Execute qmleasing commands
- `qmleasing self version` — Print qmleasing version
- `qmleasing _ _` — Passthrough to qmleasing CLI

## Usage Examples
- "qmleasing --help"
- "qmleasing self version"

## Installation
```bash
apt-get install qmleasing 2>/dev/null || which qmleasing
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
