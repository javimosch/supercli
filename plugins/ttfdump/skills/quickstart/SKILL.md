# ttfdump Plugin

CLI tool: ttfdump.

## Commands
- `ttfdump <resource> <action>` — Execute ttfdump commands
- `ttfdump self version` — Print ttfdump version
- `ttfdump _ _` — Passthrough to ttfdump CLI

## Usage Examples
- "ttfdump --help"
- "ttfdump self version"

## Installation
```bash
apt-get install ttfdump 2>/dev/null || which ttfdump
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
