# aa-enabled Plugin

CLI tool: aa-enabled.

## Commands
- `aa-enabled <resource> <action>` — Execute aa-enabled commands
- `aa-enabled self version` — Print aa-enabled version
- `aa-enabled _ _` — Passthrough to aa-enabled CLI

## Usage Examples
- "aa-enabled --help"
- "aa-enabled self version"

## Installation
```bash
apt-get install aa-enabled 2>/dev/null || which aa-enabled
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
