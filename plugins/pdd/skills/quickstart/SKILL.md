# pdd Plugin

Tiny date/time diff calculator in Python

## Commands

### Operations
- `pdd self version` — Print pdd version
- `pdd _ _` — Passthrough to pdd CLI

## Usage Examples
- `pdd --help`
- `pdd <args>`

## Installation

```bash
pip install pdd
```

## Examples

```bash
pdd --version
pdd --help
```
