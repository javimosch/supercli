# userdel Plugin

CLI tool: userdel.

## Commands
- `userdel <resource> <action>` — Execute userdel commands
- `userdel self version` — Print userdel version
- `userdel _ _` — Passthrough to userdel CLI

## Usage Examples
- "userdel --help"
- "userdel self version"

## Installation
```bash
apt-get install userdel 2>/dev/null || which userdel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
