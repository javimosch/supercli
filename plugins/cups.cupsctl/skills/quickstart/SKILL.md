# cups.cupsctl Plugin

CLI tool: cups.cupsctl.

## Commands
- `cups.cupsctl <resource> <action>` — Execute cups.cupsctl commands
- `cups.cupsctl self version` — Print cups.cupsctl version
- `cups.cupsctl _ _` — Passthrough to cups.cupsctl CLI

## Usage Examples
- "cups.cupsctl --help"
- "cups.cupsctl self version"

## Installation
```bash
apt-get install cups.cupsctl 2>/dev/null || which cups.cupsctl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
