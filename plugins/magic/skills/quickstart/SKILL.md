# magic Plugin

CLI tool: magic.

## Commands
- `magic <resource> <action>` — Execute magic commands
- `magic self version` — Print magic version
- `magic _ _` — Passthrough to magic CLI

## Usage Examples
- "magic --help"
- "magic self version"

## Installation
```bash
apt-get install magic 2>/dev/null || which magic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
