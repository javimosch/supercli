# microsandbox Plugin

🧱 local-first and microVM-backed programmable sandboxes for AI agents

## Commands
- `microsandbox <resource> <action>` — Execute microsandbox commands
- `microsandbox self version` — Print microsandbox version
- `microsandbox _ _` — Passthrough to microsandbox CLI

## Installation

```bash
pip install microsandbox
```
