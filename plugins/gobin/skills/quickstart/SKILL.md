# gobin Plugin
Self-hosted hastebin-compatible pastebin server with CLI client

## Commands
- `gobin <resource> <action>` — Execute gobin commands
- `gobin _ _` — Passthrough to gobin CLI

## Usage
- `gobin _ _ <args>` — Run gobin with any arguments
