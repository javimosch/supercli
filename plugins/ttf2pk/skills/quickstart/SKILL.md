# ttf2pk Plugin

CLI tool: ttf2pk.

## Commands
- `ttf2pk <resource> <action>` — Execute ttf2pk commands
- `ttf2pk self version` — Print ttf2pk version
- `ttf2pk _ _` — Passthrough to ttf2pk CLI

## Usage Examples
- "ttf2pk --help"
- "ttf2pk self version"

## Installation
```bash
apt-get install ttf2pk 2>/dev/null || which ttf2pk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
