# octocode Plugin

Semantic code searcher and codebase utility. Search codebases by meaning, understand code structure without reading every file.

## Commands
- `octocode self version` — Print version
- `octocode _ _ <args>` — Passthrough to octocode

## Usage Examples
- "Code Search"

## Installation
```bash
cargo install octocode
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
