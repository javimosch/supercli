# odbc2parquet Plugin
CLI tool for odbc2parquet.

## Commands
- `odbc2parquet <resource> <action>` — Execute odbc2parquet commands
- `odbc2parquet _ _` — Passthrough to odbc2parquet CLI

## Installation
```bash
cargo install odbc2parquet
```
## Key Features
- **Pipeline-ready** — stdin/stdout
- **CLI-native** — Command line tool
