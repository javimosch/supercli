# readlink Plugin
Display value of a symbolic link

## Commands
- `readlink <resource> <action>` — Execute readlink commands
- `readlink self version` — Print readlink version
- `readlink _ _` — Passthrough to readlink CLI

## Usage
- `readlink _ _ <args>` — Run readlink with any arguments
