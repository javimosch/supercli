# wsimport Plugin

CLI tool: wsimport.

## Commands
- `wsimport <resource> <action>` — Execute wsimport commands
- `wsimport self version` — Print wsimport version
- `wsimport _ _` — Passthrough to wsimport CLI

## Usage Examples
- "wsimport --help"
- "wsimport self version"

## Installation
```bash
apt-get install wsimport 2>/dev/null || which wsimport
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
