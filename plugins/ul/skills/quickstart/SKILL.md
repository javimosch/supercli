# ul Plugin

CLI tool: ul.

## Commands
- `ul <resource> <action>` — Execute ul commands
- `ul self version` — Print ul version
- `ul _ _` — Passthrough to ul CLI

## Usage Examples
- "ul --help"
- "ul self version"

## Installation
```bash
apt-get install ul 2>/dev/null || which ul
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
