# lrelease Plugin

CLI tool: lrelease.

## Commands
- `lrelease <resource> <action>` — Execute lrelease commands
- `lrelease self version` — Print lrelease version
- `lrelease _ _` — Passthrough to lrelease CLI

## Usage Examples
- "lrelease --help"
- "lrelease self version"

## Installation
```bash
apt-get install lrelease 2>/dev/null || which lrelease
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
