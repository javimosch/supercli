# openspec Plugin

CLI tool: openspec.

## Commands
- `openspec <resource> <action>` — Execute openspec commands
- `openspec self version` — Print openspec version
- `openspec _ _` — Passthrough to openspec CLI

## Usage Examples
- "openspec --help"
- "openspec self version"

## Installation
```bash
apt-get install openspec 2>/dev/null || which openspec
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
