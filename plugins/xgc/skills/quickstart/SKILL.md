# xgc Plugin

CLI tool: xgc.

## Commands
- `xgc <resource> <action>` — Execute xgc commands
- `xgc self version` — Print xgc version
- `xgc _ _` — Passthrough to xgc CLI

## Usage Examples
- "xgc --help"
- "xgc self version"

## Installation
```bash
apt-get install xgc 2>/dev/null || which xgc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
