# sensible-browser Plugin

CLI tool: sensible-browser.

## Commands
- `sensible-browser <resource> <action>` — Execute sensible-browser commands
- `sensible-browser self version` — Print sensible-browser version
- `sensible-browser _ _` — Passthrough to sensible-browser CLI

## Usage Examples
- "sensible-browser --help"
- "sensible-browser self version"

## Installation
```bash
apt-get install sensible-browser 2>/dev/null || which sensible-browser
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
