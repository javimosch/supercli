# lesskey Plugin

CLI tool: lesskey.

## Commands
- `lesskey <resource> <action>` — Execute lesskey commands
- `lesskey self version` — Print lesskey version
- `lesskey _ _` — Passthrough to lesskey CLI

## Usage Examples
- "lesskey --help"
- "lesskey self version"

## Installation
```bash
apt-get install lesskey 2>/dev/null || which lesskey
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
