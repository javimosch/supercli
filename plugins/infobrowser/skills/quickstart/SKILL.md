# infobrowser Plugin

CLI tool: infobrowser.

## Commands
- `infobrowser <resource> <action>` — Execute infobrowser commands
- `infobrowser self version` — Print infobrowser version
- `infobrowser _ _` — Passthrough to infobrowser CLI

## Usage Examples
- "infobrowser --help"
- "infobrowser self version"

## Installation
```bash
apt-get install infobrowser 2>/dev/null || which infobrowser
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
