# sparklespray Plugin
Batch job submission tool.
## Commands
- `sparklespray _ _` — Passthrough to sparklespray CLI
## Installation
```bash
cargo install sparklespray
```
## Key Features
- **Batch jobs** — Submit and track tasks
- **JSON output** — Detailed reporting
- **Pipeline-ready** — Automation support
