# pipenv-setup Plugin
Sync setup.py dependencies with Pipfile

## Commands
- `pipenv-setup <resource> <action>` — Execute pipenv-setup commands
- `pipenv-setup _ _` — Passthrough to pipenv-setup CLI

## Usage
- `pipenv-setup _ _ <args>` — Run pipenv-setup with any arguments
