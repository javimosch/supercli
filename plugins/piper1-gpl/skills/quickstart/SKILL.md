# piper1-gpl Plugin

Fast and local neural text-to-speech engine

## Commands

### General
- `piper1-gpl self version` — Print piper1-gpl version
- `piper1-gpl _ _` — Passthrough to piper1-gpl CLI

## Usage Examples
- "Run piper1-gpl"
- "Use piper1-gpl to Fast and local neural text-to-speech engine"

## Installation

```bash
pip install piper1-gpl
```

## Key Features
- Fast and local neural text-to-speech engine
- CLI tool, headless and scriptable
