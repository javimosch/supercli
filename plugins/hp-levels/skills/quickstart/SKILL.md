# hp-levels Plugin

CLI tool: hp-levels.

## Commands
- `hp-levels <resource> <action>` — Execute hp-levels commands
- `hp-levels self version` — Print hp-levels version
- `hp-levels _ _` — Passthrough to hp-levels CLI

## Usage Examples
- "hp-levels --help"
- "hp-levels self version"

## Installation
```bash
apt-get install hp-levels 2>/dev/null || which hp-levels
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
