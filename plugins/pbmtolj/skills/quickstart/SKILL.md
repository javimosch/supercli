# pbmtolj Plugin

CLI tool: pbmtolj.

## Commands
- `pbmtolj <resource> <action>` — Execute pbmtolj commands
- `pbmtolj self version` — Print pbmtolj version
- `pbmtolj _ _` — Passthrough to pbmtolj CLI

## Usage Examples
- "pbmtolj --help"
- "pbmtolj self version"

## Installation
```bash
apt-get install pbmtolj 2>/dev/null || which pbmtolj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
