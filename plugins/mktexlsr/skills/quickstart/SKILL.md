# mktexlsr Plugin

CLI tool: mktexlsr.

## Commands
- `mktexlsr <resource> <action>` — Execute mktexlsr commands
- `mktexlsr self version` — Print mktexlsr version
- `mktexlsr _ _` — Passthrough to mktexlsr CLI

## Usage Examples
- "mktexlsr --help"
- "mktexlsr self version"

## Installation
```bash
apt-get install mktexlsr 2>/dev/null || which mktexlsr
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
