# ncursesw6-config Plugin

CLI tool: ncursesw6-config.

## Commands
- `ncursesw6-config <resource> <action>` — Execute ncursesw6-config commands
- `ncursesw6-config self version` — Print ncursesw6-config version
- `ncursesw6-config _ _` — Passthrough to ncursesw6-config CLI

## Usage Examples
- "ncursesw6-config --help"
- "ncursesw6-config self version"

## Installation
```bash
apt-get install ncursesw6-config 2>/dev/null || which ncursesw6-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
