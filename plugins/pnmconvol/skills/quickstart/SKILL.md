# pnmconvol Plugin

CLI tool: pnmconvol.

## Commands
- `pnmconvol <resource> <action>` — Execute pnmconvol commands
- `pnmconvol self version` — Print pnmconvol version
- `pnmconvol _ _` — Passthrough to pnmconvol CLI

## Usage Examples
- "pnmconvol --help"
- "pnmconvol self version"

## Installation
```bash
apt-get install pnmconvol 2>/dev/null || which pnmconvol
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
