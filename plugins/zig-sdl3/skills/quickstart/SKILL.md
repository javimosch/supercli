# zig-sdl3 Plugin

Zig wrapper for SDL3.

## Commands

### General
- `zig-sdl3 self version` — Print zig-sdl3 version
- `zig-sdl3 _ _` — Passthrough to zig-sdl3 CLI

## Usage Examples
- "Run zig-sdl3"
- "Use zig-sdl3 to Zig wrapper for SDL3."

## Installation

```bash
pip install zig-sdl3
```

## Key Features
- Zig wrapper for SDL3.
- CLI tool, headless and scriptable
