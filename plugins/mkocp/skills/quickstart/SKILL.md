# mkocp Plugin

CLI tool: mkocp.

## Commands
- `mkocp <resource> <action>` — Execute mkocp commands
- `mkocp self version` — Print mkocp version
- `mkocp _ _` — Passthrough to mkocp CLI

## Usage Examples
- "mkocp --help"
- "mkocp self version"

## Installation
```bash
apt-get install mkocp 2>/dev/null || which mkocp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
