# gencmn Plugin

CLI tool: gencmn.

## Commands
- `gencmn <resource> <action>` — Execute gencmn commands
- `gencmn self version` — Print gencmn version
- `gencmn _ _` — Passthrough to gencmn CLI

## Usage Examples
- "gencmn --help"
- "gencmn self version"

## Installation
```bash
apt-get install gencmn 2>/dev/null || which gencmn
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
