# mtr-packet Plugin

CLI tool: mtr-packet.

## Commands
- `mtr-packet <resource> <action>` — Execute mtr-packet commands
- `mtr-packet self version` — Print mtr-packet version
- `mtr-packet _ _` — Passthrough to mtr-packet CLI

## Usage Examples
- "mtr-packet --help"
- "mtr-packet self version"

## Installation
```bash
apt-get install mtr-packet 2>/dev/null || which mtr-packet
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
