# speech-dispatcher Plugin

CLI tool: speech-dispatcher.

## Commands
- `speech-dispatcher <resource> <action>` — Execute speech-dispatcher commands
- `speech-dispatcher self version` — Print speech-dispatcher version
- `speech-dispatcher _ _` — Passthrough to speech-dispatcher CLI

## Usage Examples
- "speech-dispatcher --help"
- "speech-dispatcher self version"

## Installation
```bash
apt-get install speech-dispatcher 2>/dev/null || which speech-dispatcher
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
