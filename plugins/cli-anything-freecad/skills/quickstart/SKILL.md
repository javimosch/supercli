# cli-anything-freecad Plugin
Headless CAD automation harness for FreeCAD with 250+ commands

## Commands
- `cli-anything-freecad <resource> <action>` — Execute cli-anything-freecad commands
- `cli-anything-freecad _ _` — Passthrough to cli-anything-freecad CLI

## Usage
- `cli-anything-freecad _ _ <args>` — Run cli-anything-freecad with any arguments
