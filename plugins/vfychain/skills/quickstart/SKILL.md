# vfychain Plugin

vfychain — Network Security Service tools.

## Commands
- `vfychain <resource> <action>` — Execute vfychain commands
- `vfychain self version` — Print vfychain version
- `vfychain _ _` — Passthrough to vfychain CLI

## Usage Examples
- "vfychain --help"
- "vfychain self version"

## Installation
```bash
apt-get install libnss3-tools 2>/dev/null || which vfychain
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
