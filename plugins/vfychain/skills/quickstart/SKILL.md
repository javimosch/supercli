# vfychain Plugin

CLI tool: vfychain.

## Commands
- `vfychain <resource> <action>` — Execute vfychain commands
- `vfychain self version` — Print vfychain version
- `vfychain _ _` — Passthrough to vfychain CLI

## Usage Examples
- "vfychain --help"
- "vfychain self version"

## Installation
```bash
apt-get install vfychain 2>/dev/null || which vfychain
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
