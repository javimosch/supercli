# py3rsa-verify Plugin

CLI tool: py3rsa-verify.

## Commands
- `py3rsa-verify <resource> <action>` — Execute py3rsa-verify commands
- `py3rsa-verify self version` — Print py3rsa-verify version
- `py3rsa-verify _ _` — Passthrough to py3rsa-verify CLI

## Usage Examples
- "py3rsa-verify --help"
- "py3rsa-verify self version"

## Installation
```bash
apt-get install py3rsa-verify 2>/dev/null || which py3rsa-verify
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
