# system-config-printer-applet Plugin

CLI tool: system-config-printer-applet.

## Commands
- `system-config-printer-applet <resource> <action>` — Execute system-config-printer-applet commands
- `system-config-printer-applet self version` — Print system-config-printer-applet version
- `system-config-printer-applet _ _` — Passthrough to system-config-printer-applet CLI

## Usage Examples
- "system-config-printer-applet --help"
- "system-config-printer-applet self version"

## Installation
```bash
apt-get install system-config-printer-applet 2>/dev/null || which system-config-printer-applet
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
