# jsonxf Plugin
Fast JSON pretty-printer and minifier

## Commands
- `jsonxf <resource> <action>` — Execute jsonxf commands
- `jsonxf _ _` — Passthrough to jsonxf CLI

## Usage
- `jsonxf _ _ <args>` — Run jsonxf with any arguments
