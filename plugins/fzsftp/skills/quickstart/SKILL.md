# fzsftp Plugin

CLI tool: fzsftp.

## Commands
- `fzsftp <resource> <action>` — Execute fzsftp commands
- `fzsftp self version` — Print fzsftp version
- `fzsftp _ _` — Passthrough to fzsftp CLI

## Usage Examples
- "fzsftp --help"
- "fzsftp self version"

## Installation
```bash
apt-get install fzsftp 2>/dev/null || which fzsftp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
