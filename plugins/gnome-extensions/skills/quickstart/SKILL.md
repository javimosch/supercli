# gnome-extensions Plugin

CLI tool: gnome-extensions.

## Commands
- `gnome-extensions <resource> <action>` — Execute gnome-extensions commands
- `gnome-extensions self version` — Print gnome-extensions version
- `gnome-extensions _ _` — Passthrough to gnome-extensions CLI

## Usage Examples
- "gnome-extensions --help"
- "gnome-extensions self version"

## Installation
```bash
apt-get install gnome-extensions 2>/dev/null || which gnome-extensions
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
