# xmag Plugin

CLI tool: xmag.

## Commands
- `xmag <resource> <action>` — Execute xmag commands
- `xmag self version` — Print xmag version
- `xmag _ _` — Passthrough to xmag CLI

## Usage Examples
- "xmag --help"
- "xmag self version"

## Installation
```bash
apt-get install xmag 2>/dev/null || which xmag
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
