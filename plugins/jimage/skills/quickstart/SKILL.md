# jimage Plugin

CLI tool: jimage.

## Commands
- `jimage <resource> <action>` — Execute jimage commands
- `jimage self version` — Print jimage version
- `jimage _ _` — Passthrough to jimage CLI

## Usage Examples
- "jimage --help"
- "jimage self version"

## Installation
```bash
apt-get install jimage 2>/dev/null || which jimage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
