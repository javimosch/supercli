# Topit Plugin

Pin any window to the top of your screen / 在Mac上将你的任何窗口强制置顶

## Commands

### General
- `Topit self version` — Print Topit version
- `Topit _ _` — Passthrough to topit CLI

## Usage Examples
- "Run Topit"
- "Use topit to Pin any window to the top of your screen / 在Mac上将你的任何窗口强制置顶"

## Installation

```bash
pip install topit
```

## Key Features
- Pin any window to the top of your screen / 在Mac上将你的任何窗口强制置顶
- CLI tool, headless and scriptable
