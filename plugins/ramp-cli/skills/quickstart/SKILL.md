# Ramp CLI

Agent-ready spend and finance service provisioning from the terminal.

## Commands

- `ramp-cli _ _` — Passthrough to ramp CLI

## Installation

```bash
npm i -g @ramp/cli
```

## Authentication

Set `RAMP_API_KEY` environment variable.

## Usage Examples

- "Provision a new corporate card"
- "Manage spend limits"
- "Get transaction reports"

## Key Features
- **Agent-Ready** - Built for AI agents
- **Finance** - Spend management
- **Provisioning** - Service setup
- **Non-Interactive** - Scriptable
