# pnmscale Plugin

CLI tool: pnmscale.

## Commands
- `pnmscale <resource> <action>` — Execute pnmscale commands
- `pnmscale self version` — Print pnmscale version
- `pnmscale _ _` — Passthrough to pnmscale CLI

## Usage Examples
- "pnmscale --help"
- "pnmscale self version"

## Installation
```bash
apt-get install pnmscale 2>/dev/null || which pnmscale
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
