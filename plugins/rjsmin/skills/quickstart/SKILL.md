# rjsmin Plugin
Fast JavaScript minifier with C backend

## Commands
- `rjsmin <resource> <action>` — Execute rjsmin commands
- `rjsmin _ _` — Passthrough to rjsmin CLI

## Usage
- `rjsmin _ _ <args>` — Run rjsmin with any arguments
