# remark-lint Plugin
Lint markdown files with pluggable rules

## Commands
- `remark-lint <resource> <action>` — Execute remark-lint commands
- `remark-lint _ _` — Passthrough to remark-lint CLI

## Usage
- `remark-lint _ _ <args>` — Run remark-lint with any arguments
