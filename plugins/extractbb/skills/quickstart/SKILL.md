# extractbb Plugin

CLI tool: extractbb.

## Commands
- `extractbb <resource> <action>` — Execute extractbb commands
- `extractbb self version` — Print extractbb version
- `extractbb _ _` — Passthrough to extractbb CLI

## Usage Examples
- "extractbb --help"
- "extractbb self version"

## Installation
```bash
apt-get install extractbb 2>/dev/null || which extractbb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
