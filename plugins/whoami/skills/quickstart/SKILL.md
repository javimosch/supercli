# whoami Plugin

CLI tool: whoami.

## Commands
- `whoami <resource> <action>` — Execute whoami commands
- `whoami self version` — Print whoami version
- `whoami _ _` — Passthrough to whoami CLI

## Usage Examples
- "whoami --help"
- "whoami self version"

## Installation
```bash
apt-get install whoami 2>/dev/null || which whoami
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
