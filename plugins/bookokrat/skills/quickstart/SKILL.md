# bookokrat Plugin
Terminal EPUB/PDF ebook reader.
## Commands
- `bookokrat _ _` — Passthrough to bookokrat CLI
## Installation
```bash
cargo install bookokrat
```
## Key Features
- **EPUB/PDF** — Multiple ebook formats
- **Terminal-native** — No GUI needed
- **Pipeline-ready** — Document processing
