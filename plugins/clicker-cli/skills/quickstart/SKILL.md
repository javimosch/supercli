# clicker-cli Plugin
Terminal-based cookie clicker game for developers

## Commands
- `clicker-cli <resource> <action>` — Execute clicker-cli commands
- `clicker-cli _ _` — Passthrough to clicker-cli CLI

## Usage
- `clicker-cli _ _ <args>` — Run clicker-cli with any arguments
