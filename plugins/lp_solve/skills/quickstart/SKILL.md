# lp_solve Plugin

CLI tool: lp_solve.

## Commands
- `lp_solve <resource> <action>` — Execute lp_solve commands
- `lp_solve self version` — Print lp_solve version
- `lp_solve _ _` — Passthrough to lp_solve CLI

## Usage Examples
- "lp_solve --help"
- "lp_solve self version"

## Installation
```bash
apt-get install lp_solve 2>/dev/null || which lp_solve
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
