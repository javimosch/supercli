# batt-stat Plugin
Display detailed battery status and health information

## Commands
- `batt-stat <resource> <action>` — Execute batt-stat commands
- `batt-stat _ _` — Passthrough to batt-stat CLI

## Usage
- `batt-stat _ _ <args>` — Run batt-stat with any arguments
