# vc Plugin

CLI tool: vc.

## Commands
- `vc <resource> <action>` — Execute vc commands
- `vc self version` — Print vc version
- `vc _ _` — Passthrough to vc CLI

## Usage Examples
- "vc --help"
- "vc self version"

## Installation
```bash
apt-get install vc 2>/dev/null || which vc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
