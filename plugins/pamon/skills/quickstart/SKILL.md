# pamon Plugin

CLI tool: pamon.

## Commands
- `pamon <resource> <action>` — Execute pamon commands
- `pamon self version` — Print pamon version
- `pamon _ _` — Passthrough to pamon CLI

## Usage Examples
- "pamon --help"
- "pamon self version"

## Installation
```bash
apt-get install pamon 2>/dev/null || which pamon
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
