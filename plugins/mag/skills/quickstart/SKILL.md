# mag Plugin

CLI tool: mag.

## Commands
- `mag <resource> <action>` — Execute mag commands
- `mag self version` — Print mag version
- `mag _ _` — Passthrough to mag CLI

## Usage Examples
- "mag --help"
- "mag self version"

## Installation
```bash
apt-get install mag 2>/dev/null || which mag
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
