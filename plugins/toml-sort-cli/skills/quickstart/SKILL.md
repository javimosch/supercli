# toml-sort-cli Plugin
CLI tool for toml-sort-cli.

## Commands
- `toml-sort-cli <resource> <action>` — Execute toml-sort-cli commands
- `toml-sort-cli _ _` — Passthrough to toml-sort-cli CLI

## Installation
```bash
cargo install toml-sort-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
