# ppdi Plugin

CLI tool: ppdi.

## Commands
- `ppdi <resource> <action>` — Execute ppdi commands
- `ppdi self version` — Print ppdi version
- `ppdi _ _` — Passthrough to ppdi CLI

## Usage Examples
- "ppdi --help"
- "ppdi self version"

## Installation
```bash
apt-get install ppdi 2>/dev/null || which ppdi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
