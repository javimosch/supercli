# kubectl-ai Plugin

AI powered Kubernetes Assistant

## Commands

### General
- `kubectl-ai self version` — Print kubectl-ai version
- `kubectl-ai _ _` — Passthrough to kubectl-ai CLI

## Usage Examples
- "Run kubectl-ai"
- "Use kubectl-ai to AI powered Kubernetes Assistant"

## Installation

```bash
pip install kubectl-ai
```

## Key Features
- AI powered Kubernetes Assistant
- CLI tool, headless and scriptable
