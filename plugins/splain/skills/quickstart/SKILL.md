# splain Plugin

CLI tool: splain.

## Commands
- `splain <resource> <action>` — Execute splain commands
- `splain self version` — Print splain version
- `splain _ _` — Passthrough to splain CLI

## Usage Examples
- "splain --help"
- "splain self version"

## Installation
```bash
apt-get install splain 2>/dev/null || which splain
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
