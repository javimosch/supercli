# qmllint Plugin

CLI tool: qmllint.

## Commands
- `qmllint <resource> <action>` — Execute qmllint commands
- `qmllint self version` — Print qmllint version
- `qmllint _ _` — Passthrough to qmllint CLI

## Usage Examples
- "qmllint --help"
- "qmllint self version"

## Installation
```bash
apt-get install qmllint 2>/dev/null || which qmllint
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
