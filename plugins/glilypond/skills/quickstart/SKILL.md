# glilypond Plugin

CLI tool: glilypond.

## Commands
- `glilypond <resource> <action>` — Execute glilypond commands
- `glilypond self version` — Print glilypond version
- `glilypond _ _` — Passthrough to glilypond CLI

## Usage Examples
- "glilypond --help"
- "glilypond self version"

## Installation
```bash
apt-get install glilypond 2>/dev/null || which glilypond
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
