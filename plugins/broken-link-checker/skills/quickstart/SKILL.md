# broken-link-checker Plugin
Find broken links in websites and HTML files

## Commands
- `broken-link-checker <resource> <action>` — Execute broken-link-checker commands
- `broken-link-checker _ _` — Passthrough to broken-link-checker CLI

## Usage
- `broken-link-checker _ _ <args>` — Run broken-link-checker with any arguments
