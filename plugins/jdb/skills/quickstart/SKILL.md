# jdb Plugin

CLI tool: jdb.

## Commands
- `jdb <resource> <action>` — Execute jdb commands
- `jdb self version` — Print jdb version
- `jdb _ _` — Passthrough to jdb CLI

## Usage Examples
- "jdb --help"
- "jdb self version"

## Installation
```bash
apt-get install jdb 2>/dev/null || which jdb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
