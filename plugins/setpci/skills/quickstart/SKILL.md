# setpci Plugin

CLI tool: setpci.

## Commands
- `setpci <resource> <action>` — Execute setpci commands
- `setpci self version` — Print setpci version
- `setpci _ _` — Passthrough to setpci CLI

## Usage Examples
- "setpci --help"
- "setpci self version"

## Installation
```bash
apt-get install setpci 2>/dev/null || which setpci
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
