# piconv Plugin

CLI tool: piconv.

## Commands
- `piconv <resource> <action>` — Execute piconv commands
- `piconv self version` — Print piconv version
- `piconv _ _` — Passthrough to piconv CLI

## Usage Examples
- "piconv --help"
- "piconv self version"

## Installation
```bash
apt-get install piconv 2>/dev/null || which piconv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
