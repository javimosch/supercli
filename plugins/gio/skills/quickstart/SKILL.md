# gio Plugin

CLI tool: gio.

## Commands
- `gio <resource> <action>` — Execute gio commands
- `gio self version` — Print gio version
- `gio _ _` — Passthrough to gio CLI

## Usage Examples
- "gio --help"
- "gio self version"

## Installation
```bash
apt-get install gio 2>/dev/null || which gio
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
