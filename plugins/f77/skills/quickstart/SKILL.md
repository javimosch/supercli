# f77 Plugin

CLI tool: f77.

## Commands
- `f77 <resource> <action>` — Execute f77 commands
- `f77 self version` — Print f77 version
- `f77 _ _` — Passthrough to f77 CLI

## Usage Examples
- "f77 --help"
- "f77 self version"

## Installation
```bash
apt-get install f77 2>/dev/null || which f77
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
