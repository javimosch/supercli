# ds4 Plugin

DeepSeek 4 Flash local inference engine for Metal and CUDA

## Commands

### General
- `ds4 self version` — Print ds4 version
- `ds4 _ _` — Passthrough to ds4 CLI

## Usage Examples
- "Run ds4"
- "Use ds4 to DeepSeek 4 Flash local inference engine for Metal and CUDA"

## Installation

```bash
pip install ds4
```

## Key Features
- DeepSeek 4 Flash local inference engine for Metal and CUDA
- CLI tool, headless and scriptable
