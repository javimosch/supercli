# ppmtopict Plugin

CLI tool: ppmtopict.

## Commands
- `ppmtopict <resource> <action>` — Execute ppmtopict commands
- `ppmtopict self version` — Print ppmtopict version
- `ppmtopict _ _` — Passthrough to ppmtopict CLI

## Usage Examples
- "ppmtopict --help"
- "ppmtopict self version"

## Installation
```bash
apt-get install ppmtopict 2>/dev/null || which ppmtopict
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
