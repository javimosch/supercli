# pico-os Plugin

A minimal RISC-V 32-bit OS written in Zig.

## Commands

### General
- `pico-os self version` — Print pico-os version
- `pico-os _ _` — Passthrough to pico-os CLI

- "Run pico-os"

## Installation

```bash
pip install pico-os
```

## Key Features
- A minimal RISC-V 32-bit OS written in Zig.
