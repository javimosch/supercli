# sqfscat Plugin

CLI tool: sqfscat.

## Commands
- `sqfscat <resource> <action>` — Execute sqfscat commands
- `sqfscat self version` — Print sqfscat version
- `sqfscat _ _` — Passthrough to sqfscat CLI

## Usage Examples
- "sqfscat --help"
- "sqfscat self version"

## Installation
```bash
apt-get install sqfscat 2>/dev/null || which sqfscat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
