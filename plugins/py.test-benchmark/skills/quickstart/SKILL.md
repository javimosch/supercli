# py.test-benchmark Plugin

CLI tool: py.test-benchmark.

## Commands
- `py.test-benchmark <resource> <action>` — Execute py.test-benchmark commands
- `py.test-benchmark self version` — Print py.test-benchmark version
- `py.test-benchmark _ _` — Passthrough to py.test-benchmark CLI

## Usage Examples
- "py.test-benchmark --help"
- "py.test-benchmark self version"

## Installation
```bash
apt-get install py.test-benchmark 2>/dev/null || which py.test-benchmark
```

- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
