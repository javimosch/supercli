# lwp-download Plugin

CLI tool: lwp-download.

## Commands
- `lwp-download <resource> <action>` — Execute lwp-download commands
- `lwp-download self version` — Print lwp-download version
- `lwp-download _ _` — Passthrough to lwp-download CLI

## Usage Examples
- "lwp-download --help"
- "lwp-download self version"

## Installation
```bash
apt-get install lwp-download 2>/dev/null || which lwp-download
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
