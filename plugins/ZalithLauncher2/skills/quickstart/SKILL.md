# ZalithLauncher2 Plugin

A Minecraft: Java Edition Launcher for Android

## Commands

### General
- `ZalithLauncher2 self version` — Print ZalithLauncher2 version
- `ZalithLauncher2 _ _` — Passthrough to zalithlauncher2 CLI

## Usage Examples
- "Run ZalithLauncher2"
- "Use zalithlauncher2 to A Minecraft: Java Edition Launcher for Android"

## Installation

```bash
pip install zalithlauncher2
```

## Key Features
- A Minecraft: Java Edition Launcher for Android
- CLI tool, headless and scriptable
