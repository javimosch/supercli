# xiaozhi-esp32-server-java Plugin

小智ESP32的Java企业级管理平台，提供设备监控、音色定制、角色切换和对话记录管理的前后端及服务端一体化解决方案

## Commands

### General
- `xiaozhi-esp32-server-java self version` — Print xiaozhi-esp32-server-java version
- `xiaozhi-esp32-server-java _ _` — Passthrough to xiaozhi-esp32-server-java CLI
