# disk-clean-cli Plugin
CLI tool for disk-clean-cli.

- `disk-clean-cli _ _` — Passthrough to disk-clean-cli CLI

## Installation
```bash
cargo install disk-clean-cli
```
## Key Features
- **Pipeline-ready** — stdin/stdout
