# uic Plugin

CLI tool: uic.

## Commands
- `uic <resource> <action>` — Execute uic commands
- `uic self version` — Print uic version
- `uic _ _` — Passthrough to uic CLI

## Usage Examples
- "uic --help"
- "uic self version"

## Installation
```bash
apt-get install uic 2>/dev/null || which uic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
