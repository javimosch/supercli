# kmer-db Plugin
Fast memory-efficient k-mer counting and querying for bioinformatics

## Commands
- `kmer-db <resource> <action>` — Execute kmer-db commands
- `kmer-db _ _` — Passthrough to kmer-db CLI

## Usage
- `kmer-db _ _ <args>` — Run kmer-db with any arguments
