# union Plugin

The trust-minimized, zero-knowledge bridging protocol, designed for censorship resistance, extremely high security, and usage in decentralized finance.

## Commands
- `union <resource> <action>` — Execute union commands
- `union self version` — Print union version
- `union _ _` — Passthrough to union CLI

## Installation

```bash
pip install union
```
