# gslj Plugin

CLI tool: gslj.

## Commands
- `gslj <resource> <action>` — Execute gslj commands
- `gslj self version` — Print gslj version
- `gslj _ _` — Passthrough to gslj CLI

## Usage Examples
- "gslj --help"
- "gslj self version"

## Installation
```bash
apt-get install gslj 2>/dev/null || which gslj
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
