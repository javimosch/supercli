# ppmhist Plugin

CLI tool: ppmhist.

## Commands
- `ppmhist <resource> <action>` — Execute ppmhist commands
- `ppmhist self version` — Print ppmhist version
- `ppmhist _ _` — Passthrough to ppmhist CLI

## Usage Examples
- "ppmhist --help"
- "ppmhist self version"

## Installation
```bash
apt-get install ppmhist 2>/dev/null || which ppmhist
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
