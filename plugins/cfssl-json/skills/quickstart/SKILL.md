# cfssl-json Plugin
CloudFlare SSL toolkit with JSON output support

## Commands
- `cfssl-json <resource> <action>` — Execute cfssl-json commands
- `cfssl-json _ _` — Passthrough to cfssl-json CLI

## Usage
- `cfssl-json _ _ <args>` — Run cfssl-json with any arguments
