# compilet Plugin
Server/CLI that compiles C/C++/Rust code into WebAssembly

## Commands
- `compilet <resource> <action>` — Execute compilet commands
- `compilet _ _` — Passthrough to compilet CLI

## Usage
- `compilet _ _ <args>` — Run compilet with any arguments
