# chemcli Plugin
Command-line molecular weight calculator for chemistry

## Commands
- `chemcli <resource> <action>` — Execute chemcli commands
- `chemcli _ _` — Passthrough to chemcli CLI

## Usage
- `chemcli _ _ <args>` — Run chemcli with any arguments
