# a2dissite Plugin

CLI tool: a2dissite.

## Commands
- `a2dissite <resource> <action>` — Execute a2dissite commands
- `a2dissite self version` — Print a2dissite version
- `a2dissite _ _` — Passthrough to a2dissite CLI

## Usage Examples
- "a2dissite --help"
- "a2dissite self version"

## Installation
```bash
apt-get install a2dissite 2>/dev/null || which a2dissite
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
