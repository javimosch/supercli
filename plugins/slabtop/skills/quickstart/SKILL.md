# slabtop Plugin

CLI tool: slabtop.

## Commands
- `slabtop <resource> <action>` — Execute slabtop commands
- `slabtop self version` — Print slabtop version
- `slabtop _ _` — Passthrough to slabtop CLI

## Usage Examples
- "slabtop --help"
- "slabtop self version"

## Installation
```bash
apt-get install slabtop 2>/dev/null || which slabtop
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
