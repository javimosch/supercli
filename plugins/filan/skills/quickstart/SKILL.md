# filan Plugin

CLI tool: filan.

## Commands
- `filan <resource> <action>` — Execute filan commands
- `filan self version` — Print filan version
- `filan _ _` — Passthrough to filan CLI

## Usage Examples
- "filan --help"
- "filan self version"

## Installation
```bash
apt-get install filan 2>/dev/null || which filan
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
