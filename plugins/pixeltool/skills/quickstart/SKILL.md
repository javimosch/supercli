# pixeltool Plugin

CLI tool: pixeltool.

## Commands
- `pixeltool <resource> <action>` — Execute pixeltool commands
- `pixeltool self version` — Print pixeltool version
- `pixeltool _ _` — Passthrough to pixeltool CLI

## Usage Examples
- "pixeltool --help"
- "pixeltool self version"

## Installation
```bash
apt-get install pixeltool 2>/dev/null || which pixeltool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
