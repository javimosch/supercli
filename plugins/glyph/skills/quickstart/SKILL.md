# glyph Plugin

convert images, video to ascii!

## Commands

### General
- `glyph self version` — Print glyph version
- `glyph _ _` — Passthrough to glyph CLI

## Usage Examples
- "Run glyph"
- "Use glyph to convert images, video to ascii!"

## Installation

```bash
pip install glyph
```

## Key Features
- convert images, video to ascii!
- CLI tool, headless and scriptable
