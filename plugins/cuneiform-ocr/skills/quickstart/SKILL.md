# cuneiform-ocr Plugin
Open-source OCR system with command-line interface

## Commands
- `cuneiform-ocr <resource> <action>` — Execute cuneiform-ocr commands
- `cuneiform-ocr _ _` — Passthrough to cuneiform-ocr CLI

## Usage
- `cuneiform-ocr _ _ <args>` — Run cuneiform-ocr with any arguments
