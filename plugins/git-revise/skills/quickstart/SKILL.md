# git-revise Plugin
Rebase alternative for amending and splitting commits

## Commands
- `git-revise <resource> <action>` — Execute git-revise commands
- `git-revise _ _` — Passthrough to git-revise CLI

## Usage
- `git-revise _ _ <args>` — Run git-revise with any arguments
