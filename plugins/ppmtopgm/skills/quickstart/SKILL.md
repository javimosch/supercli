# ppmtopgm Plugin

CLI tool: ppmtopgm.

## Commands
- `ppmtopgm <resource> <action>` — Execute ppmtopgm commands
- `ppmtopgm self version` — Print ppmtopgm version
- `ppmtopgm _ _` — Passthrough to ppmtopgm CLI

## Usage Examples
- "ppmtopgm --help"
- "ppmtopgm self version"

## Installation
```bash
apt-get install ppmtopgm 2>/dev/null || which ppmtopgm
```
