# tex2aspc Plugin

CLI tool: tex2aspc.

## Commands
- `tex2aspc <resource> <action>` — Execute tex2aspc commands
- `tex2aspc self version` — Print tex2aspc version
- `tex2aspc _ _` — Passthrough to tex2aspc CLI

## Usage Examples
- "tex2aspc --help"
- "tex2aspc self version"

## Installation
```bash
apt-get install tex2aspc 2>/dev/null || which tex2aspc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
