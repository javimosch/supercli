# xfreerdp Plugin

CLI tool: xfreerdp.

## Commands
- `xfreerdp <resource> <action>` — Execute xfreerdp commands
- `xfreerdp self version` — Print xfreerdp version
- `xfreerdp _ _` — Passthrough to xfreerdp CLI

## Usage Examples
- "xfreerdp --help"
- "xfreerdp self version"

## Installation
```bash
apt-get install xfreerdp 2>/dev/null || which xfreerdp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
