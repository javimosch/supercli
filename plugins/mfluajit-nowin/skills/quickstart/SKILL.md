# mfluajit-nowin Plugin

CLI tool: mfluajit-nowin.

## Commands
- `mfluajit-nowin <resource> <action>` — Execute mfluajit-nowin commands
- `mfluajit-nowin self version` — Print mfluajit-nowin version
- `mfluajit-nowin _ _` — Passthrough to mfluajit-nowin CLI

## Usage Examples
- "mfluajit-nowin --help"
- "mfluajit-nowin self version"

## Installation
```bash
apt-get install mfluajit-nowin 2>/dev/null || which mfluajit-nowin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
