# kpseaccess Plugin

CLI tool: kpseaccess.

## Commands
- `kpseaccess <resource> <action>` — Execute kpseaccess commands
- `kpseaccess self version` — Print kpseaccess version
- `kpseaccess _ _` — Passthrough to kpseaccess CLI

## Usage Examples
- "kpseaccess --help"
- "kpseaccess self version"

## Installation
```bash
apt-get install kpseaccess 2>/dev/null || which kpseaccess
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
