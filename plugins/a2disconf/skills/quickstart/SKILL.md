# a2disconf Plugin

CLI tool: a2disconf.

## Commands
- `a2disconf <resource> <action>` — Execute a2disconf commands
- `a2disconf self version` — Print a2disconf version
- `a2disconf _ _` — Passthrough to a2disconf CLI

## Usage Examples
- "a2disconf --help"
- "a2disconf self version"

## Installation
```bash
apt-get install a2disconf 2>/dev/null || which a2disconf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
