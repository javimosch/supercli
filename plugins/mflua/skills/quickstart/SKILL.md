# mflua Plugin

CLI tool: mflua.

## Commands
- `mflua <resource> <action>` — Execute mflua commands
- `mflua self version` — Print mflua version
- `mflua _ _` — Passthrough to mflua CLI

## Usage Examples
- "mflua --help"
- "mflua self version"

## Installation
```bash
apt-get install mflua 2>/dev/null || which mflua
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
