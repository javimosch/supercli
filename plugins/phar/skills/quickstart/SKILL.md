# phar Plugin

CLI tool: phar.

## Commands
- `phar <resource> <action>` — Execute phar commands
- `phar self version` — Print phar version
- `phar _ _` — Passthrough to phar CLI

## Usage Examples
- "phar --help"
- "phar self version"

## Installation
```bash
apt-get install phar 2>/dev/null || which phar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
