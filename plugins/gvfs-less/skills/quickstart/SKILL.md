# gvfs-less Plugin

CLI tool: gvfs-less.

## Commands
- `gvfs-less <resource> <action>` — Execute gvfs-less commands
- `gvfs-less self version` — Print gvfs-less version
- `gvfs-less _ _` — Passthrough to gvfs-less CLI

## Usage Examples
- "gvfs-less --help"
- "gvfs-less self version"

## Installation
```bash
apt-get install gvfs-less 2>/dev/null || which gvfs-less
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
