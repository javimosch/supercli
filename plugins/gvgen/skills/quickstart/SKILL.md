# gvgen Plugin

CLI tool: gvgen.

## Commands
- `gvgen <resource> <action>` — Execute gvgen commands
- `gvgen self version` — Print gvgen version
- `gvgen _ _` — Passthrough to gvgen CLI

## Usage Examples
- "gvgen --help"
- "gvgen self version"

## Installation
```bash
apt-get install gvgen 2>/dev/null || which gvgen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
