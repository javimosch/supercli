# write-good Plugin

write-good suggests simpler alternatives for English prose.

## Usage Examples

- "check README.md for weasel words"
- "lint documentation for passive voice"
- "find redundant phrases in blog post"

## Installation

```bash
npm install -g write-good
```

## Key Features
- Weasel word detection
- Passive voice identification
- Lexical illusion detection
- Redundant phrase spotting
- Cliche identification
- No dictionary dependency
- Plain text and Markdown support
