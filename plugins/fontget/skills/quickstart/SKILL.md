# fontget Plugin
Tiny CLI manager to discover and install fonts on Linux/macOS

## Commands
- `fontget <resource> <action>` — Execute fontget commands
- `fontget _ _` — Passthrough to fontget CLI

## Usage
- `fontget _ _ <args>` — Run fontget with any arguments
