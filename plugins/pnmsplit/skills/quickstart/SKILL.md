# pnmsplit Plugin

CLI tool: pnmsplit.

## Commands
- `pnmsplit <resource> <action>` — Execute pnmsplit commands
- `pnmsplit self version` — Print pnmsplit version
- `pnmsplit _ _` — Passthrough to pnmsplit CLI

## Usage Examples
- "pnmsplit --help"
- "pnmsplit self version"

## Installation
```bash
apt-get install pnmsplit 2>/dev/null || which pnmsplit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
