# pass-strength-cli Plugin
Validate password entropy and strength in the shell

## Commands
- `pass-strength-cli <resource> <action>` — Execute pass-strength-cli commands
- `pass-strength-cli _ _` — Passthrough to pass-strength-cli CLI

## Usage
- `pass-strength-cli _ _ <args>` — Run pass-strength-cli with any arguments
