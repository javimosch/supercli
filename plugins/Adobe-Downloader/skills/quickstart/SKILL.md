# Adobe-Downloader Plugin

macOS Adobe apps download & installer

## Commands

### General
- `Adobe-Downloader self version` — Print Adobe-Downloader version
- `Adobe-Downloader _ _` — Passthrough to adobe-downloader CLI

## Usage Examples
- "Run Adobe-Downloader"
- "Use adobe-downloader to macOS Adobe apps download & installer"

## Installation

```bash
pip install adobe-downloader
```

## Key Features
- macOS Adobe apps download & installer
- CLI tool, headless and scriptable
