# mpicxx Plugin

CLI tool: mpicxx.

## Commands
- `mpicxx <resource> <action>` — Execute mpicxx commands
- `mpicxx self version` — Print mpicxx version
- `mpicxx _ _` — Passthrough to mpicxx CLI

## Usage Examples
- "mpicxx --help"
- "mpicxx self version"

## Installation
```bash
apt-get install mpicxx 2>/dev/null || which mpicxx
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
