# gml2gv Plugin

CLI tool: gml2gv.

## Commands
- `gml2gv <resource> <action>` — Execute gml2gv commands
- `gml2gv self version` — Print gml2gv version
- `gml2gv _ _` — Passthrough to gml2gv CLI

## Usage Examples
- "gml2gv --help"
- "gml2gv self version"

## Installation
```bash
apt-get install gml2gv 2>/dev/null || which gml2gv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
