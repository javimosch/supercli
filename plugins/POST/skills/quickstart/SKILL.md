# POST Plugin

POST — simple and consistent interface to the world-wide web.

## Commands
- `POST <resource> <action>` — Execute POST commands
- `POST self version` — Print POST version
- `POST _ _` — Passthrough to POST CLI

## Usage Examples
- "POST --help"
- "POST self version"

## Installation
```bash
apt-get install libwww-perl 2>/dev/null || which POST
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
