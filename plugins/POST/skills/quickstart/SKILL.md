# POST Plugin

CLI tool: POST.

## Commands
- `POST <resource> <action>` — Execute POST commands
- `POST self version` — Print POST version
- `POST _ _` — Passthrough to POST CLI

## Usage Examples
- "POST --help"
- "POST self version"

## Installation
```bash
apt-get install POST 2>/dev/null || which POST
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
