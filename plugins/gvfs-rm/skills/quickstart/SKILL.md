# gvfs-rm Plugin

CLI tool: gvfs-rm.

## Commands
- `gvfs-rm <resource> <action>` — Execute gvfs-rm commands
- `gvfs-rm self version` — Print gvfs-rm version
- `gvfs-rm _ _` — Passthrough to gvfs-rm CLI

## Usage Examples
- "gvfs-rm --help"
- "gvfs-rm self version"

## Installation
```bash
apt-get install gvfs-rm 2>/dev/null || which gvfs-rm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
