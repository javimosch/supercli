# rackdiag Plugin
Generate rack layout diagrams from simple text input

## Commands
- `rackdiag <resource> <action>` — Execute rackdiag commands
- `rackdiag _ _` — Passthrough to rackdiag CLI

## Usage
- `rackdiag _ _ <args>` — Run rackdiag with any arguments
