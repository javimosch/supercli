# pnmrotate Plugin

CLI tool: pnmrotate.

## Commands
- `pnmrotate <resource> <action>` — Execute pnmrotate commands
- `pnmrotate self version` — Print pnmrotate version
- `pnmrotate _ _` — Passthrough to pnmrotate CLI

## Usage Examples
- "pnmrotate --help"
- "pnmrotate self version"

## Installation
```bash
apt-get install pnmrotate 2>/dev/null || which pnmrotate
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
