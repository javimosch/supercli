# iecset Plugin

CLI tool: iecset.

## Commands
- `iecset <resource> <action>` — Execute iecset commands
- `iecset self version` — Print iecset version
- `iecset _ _` — Passthrough to iecset CLI

## Usage Examples
- "iecset --help"
- "iecset self version"

## Installation
```bash
apt-get install iecset 2>/dev/null || which iecset
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
