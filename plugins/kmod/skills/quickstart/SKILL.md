# kmod Plugin

CLI tool: kmod.

## Commands
- `kmod <resource> <action>` — Execute kmod commands
- `kmod self version` — Print kmod version
- `kmod _ _` — Passthrough to kmod CLI

## Usage Examples
- "kmod --help"
- "kmod self version"

## Installation
```bash
apt-get install kmod 2>/dev/null || which kmod
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
