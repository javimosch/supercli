# zagi Plugin

Better git CLI for AI agents with --json and --compat output modes. 3 output formats, git-pass-through for unimplemented commands.

## Commands
- `zagi self version` — Print version
- `zagi _ _ <args>` — Passthrough to zagi

## Usage Examples
- "Better Git CLI"

## Installation
```bash
curl -fsSL zagi.sh/install | sh
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
