# snice Plugin

CLI tool: snice.

## Commands
- `snice <resource> <action>` — Execute snice commands
- `snice self version` — Print snice version
- `snice _ _` — Passthrough to snice CLI

## Usage Examples
- "snice --help"
- "snice self version"

## Installation
```bash
apt-get install snice 2>/dev/null || which snice
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
