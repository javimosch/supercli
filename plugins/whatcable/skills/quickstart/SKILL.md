# whatcable Plugin

macOS menu bar app that tells you, in plain English, what each USB-C cable plugged into your Mac can actually do

## Commands

### General
- `whatcable self version` — Print whatcable version
- `whatcable _ _` — Passthrough to whatcable CLI
