# xmlcatalog Plugin

CLI tool: xmlcatalog.

## Commands
- `xmlcatalog <resource> <action>` — Execute xmlcatalog commands
- `xmlcatalog self version` — Print xmlcatalog version
- `xmlcatalog _ _` — Passthrough to xmlcatalog CLI

## Usage Examples
- "xmlcatalog --help"
- "xmlcatalog self version"

## Installation
```bash
apt-get install xmlcatalog 2>/dev/null || which xmlcatalog
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
