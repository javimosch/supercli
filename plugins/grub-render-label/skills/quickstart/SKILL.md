# grub-render-label Plugin

CLI tool: grub-render-label.

## Commands
- `grub-render-label <resource> <action>` — Execute grub-render-label commands
- `grub-render-label self version` — Print grub-render-label version
- `grub-render-label _ _` — Passthrough to grub-render-label CLI

## Usage Examples
- "grub-render-label --help"
- "grub-render-label self version"

## Installation
```bash
apt-get install grub-render-label 2>/dev/null || which grub-render-label
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
