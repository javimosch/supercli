# pageres-cli Plugin

Capture website screenshots from CLI in JavaScript

## Commands

### Operations
- `pageres-cli self version` — Print pageres-cli version
- `pageres-cli _ _` — Passthrough to pageres-cli CLI

## Usage Examples
- `pageres-cli --help`
- `pageres-cli <args>`

## Installation

```bash
npm install -g pageres-cli
```

## Examples

```bash
pageres-cli --version
pageres-cli --help
```
