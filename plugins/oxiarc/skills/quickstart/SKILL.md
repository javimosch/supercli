# oxiarc Plugin
Pure Rust implementation for archiving and compression

## Commands
- `oxiarc <resource> <action>` — Execute oxiarc commands
- `oxiarc _ _` — Passthrough to oxiarc CLI

## Usage
- `oxiarc _ _ <args>` — Run oxiarc with any arguments
