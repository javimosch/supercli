# temp-mail-cli Plugin
Create disposable email addresses and monitor inboxes

## Commands
- `temp-mail-cli <resource> <action>` — Execute temp-mail-cli commands
- `temp-mail-cli _ _` — Passthrough to temp-mail-cli CLI

## Usage
- `temp-mail-cli _ _ <args>` — Run temp-mail-cli with any arguments
