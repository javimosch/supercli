# rustowl Plugin

Visualize Ownership and Lifetimes in Rust

## Commands

### General
- `rustowl self version` — Print rustowl version
- `rustowl _ _` — Passthrough to rustowl CLI

## Usage Examples
- "Run rustowl"
- "Use rustowl to Visualize Ownership and Lifetimes in Rust"

## Installation

```bash
pip install rustowl
```

## Key Features
- Visualize Ownership and Lifetimes in Rust
- CLI tool, headless and scriptable
