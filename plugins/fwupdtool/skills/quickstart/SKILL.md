# fwupdtool Plugin

CLI tool: fwupdtool.

## Commands
- `fwupdtool <resource> <action>` — Execute fwupdtool commands
- `fwupdtool self version` — Print fwupdtool version
- `fwupdtool _ _` — Passthrough to fwupdtool CLI

## Usage Examples
- "fwupdtool --help"
- "fwupdtool self version"

## Installation
```bash
apt-get install fwupdtool 2>/dev/null || which fwupdtool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
