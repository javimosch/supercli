# gitignore-cli Plugin
Gitignore.io CLI for creating gitignore files

## Commands
- `gitignore-cli <resource> <action>` — Execute gitignore-cli commands
- `gitignore-cli _ _` — Passthrough to gitignore-cli CLI

## Usage
- `gitignore-cli _ _ <args>` — Run gitignore-cli with any arguments
