# sensible-pager Plugin

CLI tool: sensible-pager.

## Commands
- `sensible-pager <resource> <action>` — Execute sensible-pager commands
- `sensible-pager self version` — Print sensible-pager version
- `sensible-pager _ _` — Passthrough to sensible-pager CLI

## Usage Examples
- "sensible-pager --help"
- "sensible-pager self version"

## Installation
```bash
apt-get install sensible-pager 2>/dev/null || which sensible-pager
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
