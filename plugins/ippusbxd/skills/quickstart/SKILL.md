# ippusbxd Plugin

CLI tool: ippusbxd.

## Commands
- `ippusbxd <resource> <action>` — Execute ippusbxd commands
- `ippusbxd self version` — Print ippusbxd version
- `ippusbxd _ _` — Passthrough to ippusbxd CLI

## Usage Examples
- "ippusbxd --help"
- "ippusbxd self version"

## Installation
```bash
apt-get install ippusbxd 2>/dev/null || which ippusbxd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
