# gpgtar Plugin

CLI tool: gpgtar.

## Commands
- `gpgtar <resource> <action>` — Execute gpgtar commands
- `gpgtar self version` — Print gpgtar version
- `gpgtar _ _` — Passthrough to gpgtar CLI

## Usage Examples
- "gpgtar --help"
- "gpgtar self version"

## Installation
```bash
apt-get install gpgtar 2>/dev/null || which gpgtar
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
