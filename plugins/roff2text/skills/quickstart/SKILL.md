# roff2text Plugin

CLI tool: roff2text.

## Commands
- `roff2text <resource> <action>` — Execute roff2text commands
- `roff2text self version` — Print roff2text version
- `roff2text _ _` — Passthrough to roff2text CLI

## Usage Examples
- "roff2text --help"
- "roff2text self version"

## Installation
```bash
apt-get install roff2text 2>/dev/null || which roff2text
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
