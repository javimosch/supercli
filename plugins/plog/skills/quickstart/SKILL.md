# plog Plugin

CLI tool: plog.

## Commands
- `plog <resource> <action>` — Execute plog commands
- `plog self version` — Print plog version
- `plog _ _` — Passthrough to plog CLI

## Usage Examples
- "plog --help"
- "plog self version"

## Installation
```bash
apt-get install plog 2>/dev/null || which plog
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
