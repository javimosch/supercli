# pybabel-python3 Plugin

CLI tool: pybabel-python3.

## Commands
- `pybabel-python3 <resource> <action>` — Execute pybabel-python3 commands
- `pybabel-python3 self version` — Print pybabel-python3 version
- `pybabel-python3 _ _` — Passthrough to pybabel-python3 CLI

## Usage Examples
- "pybabel-python3 --help"
- "pybabel-python3 self version"

## Installation
```bash
apt-get install pybabel-python3 2>/dev/null || which pybabel-python3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
