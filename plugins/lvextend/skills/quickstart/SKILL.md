# lvextend Plugin

CLI tool: lvextend.

## Commands
- `lvextend <resource> <action>` — Execute lvextend commands
- `lvextend self version` — Print lvextend version
- `lvextend _ _` — Passthrough to lvextend CLI

## Usage Examples
- "lvextend --help"
- "lvextend self version"

## Installation
```bash
apt-get install lvextend 2>/dev/null || which lvextend
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
