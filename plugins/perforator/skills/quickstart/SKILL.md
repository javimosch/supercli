# perforator Plugin

Cluster-wide continuous profiling tool

## Commands

### Version
`perforator self version` — Print perforator version

### Passthrough
`perforator _ _` — Passthrough to perforator CLI with all arguments forwarded.

## Usage Examples

```bash
perforator --version
perforator --help
```

## Installation

```bash
cargo install perforator
```

## Key Features
- Cluster-wide continuous profiling tool
