# logresolve Plugin

CLI tool: logresolve.

## Commands
- `logresolve <resource> <action>` — Execute logresolve commands
- `logresolve self version` — Print logresolve version
- `logresolve _ _` — Passthrough to logresolve CLI

## Usage Examples
- "logresolve --help"
- "logresolve self version"

## Installation
```bash
apt-get install logresolve 2>/dev/null || which logresolve
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
