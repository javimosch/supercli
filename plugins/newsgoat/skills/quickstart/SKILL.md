# newsgoat Plugin
TUI RSS reader in Go with vi-like keybindings

## Commands
- `newsgoat <resource> <action>` — Execute newsgoat commands
- `newsgoat _ _` — Passthrough to newsgoat CLI

## Usage
- `newsgoat _ _ <args>` — Run newsgoat with any arguments
