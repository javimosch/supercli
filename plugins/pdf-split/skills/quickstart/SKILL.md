# pdf-split Plugin
Split multi-page PDFs into individual pages from CLI

## Commands
- `pdf-split <resource> <action>` — Execute pdf-split commands
- `pdf-split _ _` — Passthrough to pdf-split CLI

## Usage
- `pdf-split _ _ <args>` — Run pdf-split with any arguments
