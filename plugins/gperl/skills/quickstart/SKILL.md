# gperl Plugin

CLI tool: gperl.

## Commands
- `gperl <resource> <action>` — Execute gperl commands
- `gperl self version` — Print gperl version
- `gperl _ _` — Passthrough to gperl CLI

## Usage Examples
- "gperl --help"
- "gperl self version"

## Installation
```bash
apt-get install gperl 2>/dev/null || which gperl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
