# pw-reserve Plugin

CLI tool: pw-reserve.

## Commands
- `pw-reserve <resource> <action>` — Execute pw-reserve commands
- `pw-reserve self version` — Print pw-reserve version
- `pw-reserve _ _` — Passthrough to pw-reserve CLI

## Usage Examples
- "pw-reserve --help"
- "pw-reserve self version"

## Installation
```bash
apt-get install pw-reserve 2>/dev/null || which pw-reserve
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
