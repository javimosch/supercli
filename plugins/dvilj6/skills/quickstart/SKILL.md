# dvilj6 Plugin

CLI tool: dvilj6.

## Commands
- `dvilj6 <resource> <action>` — Execute dvilj6 commands
- `dvilj6 self version` — Print dvilj6 version
- `dvilj6 _ _` — Passthrough to dvilj6 CLI

## Usage Examples
- "dvilj6 --help"
- "dvilj6 self version"

## Installation
```bash
apt-get install dvilj6 2>/dev/null || which dvilj6
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
