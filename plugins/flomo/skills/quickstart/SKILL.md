# flomo Plugin

Flowmodoro timer CLI for productivity in Python

## Commands

### Operations
- `flomo self version` — Print flomo version
- `flomo _ _` — Passthrough to flomo CLI

## Usage Examples
- `flomo --help`
- `flomo <args>`

## Installation

```bash
pip install flomo
```

## Examples

```bash
flomo --version
flomo --help
```
