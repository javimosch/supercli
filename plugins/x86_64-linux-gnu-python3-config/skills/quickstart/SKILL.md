# x86_64-linux-gnu-python3-config Plugin

x86_64-linux-gnu-python3-config — header files and a static library for Python (default).

## Commands
- `x86_64-linux-gnu-python3-config <resource> <action>` — Execute x86_64-linux-gnu-python3-config commands
- `x86_64-linux-gnu-python3-config self version` — Print x86_64-linux-gnu-python3-config version
- `x86_64-linux-gnu-python3-config _ _` — Passthrough to x86_64-linux-gnu-python3-config CLI

## Usage Examples
- "x86_64-linux-gnu-python3-config --help"
- "x86_64-linux-gnu-python3-config self version"

## Installation
```bash
apt-get install libpython3-dev 2>/dev/null || which x86_64-linux-gnu-python3-config
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
