# scanimage Plugin

CLI tool: scanimage.

## Commands
- `scanimage <resource> <action>` — Execute scanimage commands
- `scanimage self version` — Print scanimage version
- `scanimage _ _` — Passthrough to scanimage CLI

## Usage Examples
- "scanimage --help"
- "scanimage self version"

## Installation
```bash
apt-get install scanimage 2>/dev/null || which scanimage
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
