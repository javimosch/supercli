# ppdc Plugin

CLI tool: ppdc.

## Commands
- `ppdc <resource> <action>` — Execute ppdc commands
- `ppdc self version` — Print ppdc version
- `ppdc _ _` — Passthrough to ppdc CLI

## Usage Examples
- "ppdc --help"
- "ppdc self version"

## Installation
```bash
apt-get install ppdc 2>/dev/null || which ppdc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
