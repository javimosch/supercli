# ispell-autobuildhash Plugin

CLI tool: ispell-autobuildhash.

## Commands
- `ispell-autobuildhash <resource> <action>` — Execute ispell-autobuildhash commands
- `ispell-autobuildhash self version` — Print ispell-autobuildhash version
- `ispell-autobuildhash _ _` — Passthrough to ispell-autobuildhash CLI

## Usage Examples
- "ispell-autobuildhash --help"
- "ispell-autobuildhash self version"

## Installation

```bash
apt-get install ispell-autobuildhash 2>/dev/null || which ispell-autobuildhash
```
