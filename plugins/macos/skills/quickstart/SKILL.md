# macos Plugin

MacOS inside a Docker container.

## Commands

### General
- `macos self version` — Print macos version
- `macos _ _` — Passthrough to macos CLI

## Usage Examples
- "Run macos"
- "Use macos to MacOS inside a Docker container."

## Installation

```bash
pip install macos
```

## Key Features
- MacOS inside a Docker container.
- CLI tool, headless and scriptable
