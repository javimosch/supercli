# qdbusxml2cpp Plugin

CLI tool: qdbusxml2cpp.

## Commands
- `qdbusxml2cpp <resource> <action>` — Execute qdbusxml2cpp commands
- `qdbusxml2cpp self version` — Print qdbusxml2cpp version
- `qdbusxml2cpp _ _` — Passthrough to qdbusxml2cpp CLI

## Usage Examples
- "qdbusxml2cpp --help"
- "qdbusxml2cpp self version"

## Installation
```bash
apt-get install qdbusxml2cpp 2>/dev/null || which qdbusxml2cpp
```

- CLI-based tool
