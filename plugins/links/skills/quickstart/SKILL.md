# links Plugin

links is a text and graphics mode web browser.

## Usage Examples

- "open a URL in text mode"
- "browse the web in graphics mode"
- "download a file from a URL"

## Installation

```bash
brew install links
```

## Key Features
- Text and graphics mode browsing
- JavaScript and CSS rendering
- SSL/TLS support
- Framebuffer and sixel graphics
- Download manager
