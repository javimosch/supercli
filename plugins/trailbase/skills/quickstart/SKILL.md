# trailbase Plugin

An open, sub-millisecond, single-executable Firebase alternative with type-safe APIs, built-in WebAssembly runtime, realtime subscriptions, auth, and admin UI built on Rust, SQLite & Wasmtime.

## Commands
- `trailbase <resource> <action>` — Execute trailbase commands
- `trailbase self version` — Print trailbase version
- `trailbase _ _` — Passthrough to trailbase CLI

## Installation

```bash
pip install trailbase
```
