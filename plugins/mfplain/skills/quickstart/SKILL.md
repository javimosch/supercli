# mfplain Plugin

CLI tool: mfplain.

## Commands
- `mfplain <resource> <action>` — Execute mfplain commands
- `mfplain self version` — Print mfplain version
- `mfplain _ _` — Passthrough to mfplain CLI

## Usage Examples
- "mfplain --help"
- "mfplain self version"

## Installation
```bash
apt-get install mfplain 2>/dev/null || which mfplain
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
