# opl2ofm Plugin

CLI tool: opl2ofm.

## Commands
- `opl2ofm <resource> <action>` — Execute opl2ofm commands
- `opl2ofm self version` — Print opl2ofm version
- `opl2ofm _ _` — Passthrough to opl2ofm CLI

## Usage Examples
- "opl2ofm --help"
- "opl2ofm self version"

## Installation
```bash
apt-get install opl2ofm 2>/dev/null || which opl2ofm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
