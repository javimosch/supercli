# pnmsmooth Plugin

CLI tool: pnmsmooth.

## Commands
- `pnmsmooth <resource> <action>` — Execute pnmsmooth commands
- `pnmsmooth self version` — Print pnmsmooth version
- `pnmsmooth _ _` — Passthrough to pnmsmooth CLI

## Usage Examples
- "pnmsmooth --help"
- "pnmsmooth self version"

## Installation
```bash
apt-get install pnmsmooth 2>/dev/null || which pnmsmooth
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
