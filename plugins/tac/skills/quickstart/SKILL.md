# tac Plugin
Reverse cat — display files in reverse

## Commands
- `tac <resource> <action>` — Execute tac commands
- `tac self version` — Print tac version
- `tac _ _` — Passthrough to tac CLI

## Usage
- `tac _ _ <args>` — Run tac with any arguments
