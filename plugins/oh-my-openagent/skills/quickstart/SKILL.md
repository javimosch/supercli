# oh-my-openagent Plugin

omo; the one and only agent harness for complex codebases. the pickaxe for complex software engineering. For your Codex, for your OpenCode

## Commands
- `oh-my-openagent <resource> <action>` — Execute oh-my-openagent commands
- `oh-my-openagent self version` — Print oh-my-openagent version
- `oh-my-openagent _ _` — Passthrough to oh-my-openagent CLI

## Installation

```bash
pip install oh-my-openagent
```
