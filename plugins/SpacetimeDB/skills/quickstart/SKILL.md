# SpacetimeDB Plugin

Development at the speed of light

## Commands
- `SpacetimeDB <resource> <action>` — Execute SpacetimeDB commands
- `SpacetimeDB self version` — Print SpacetimeDB version
- `SpacetimeDB _ _` — Passthrough to spacetimedb CLI

## Installation

```bash
pip install spacetimedb
```
