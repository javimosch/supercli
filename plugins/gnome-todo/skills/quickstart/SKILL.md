# gnome-todo Plugin

CLI tool: gnome-todo.

## Commands
- `gnome-todo <resource> <action>` — Execute gnome-todo commands
- `gnome-todo self version` — Print gnome-todo version
- `gnome-todo _ _` — Passthrough to gnome-todo CLI

## Usage Examples
- "gnome-todo --help"
- "gnome-todo self version"

## Installation
```bash
apt-get install gnome-todo 2>/dev/null || which gnome-todo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
