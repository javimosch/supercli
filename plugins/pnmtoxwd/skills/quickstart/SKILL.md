# pnmtoxwd Plugin

CLI tool: pnmtoxwd.

## Commands
- `pnmtoxwd <resource> <action>` — Execute pnmtoxwd commands
- `pnmtoxwd self version` — Print pnmtoxwd version
- `pnmtoxwd _ _` — Passthrough to pnmtoxwd CLI

## Usage Examples
- "pnmtoxwd --help"
- "pnmtoxwd self version"

## Installation
```bash
apt-get install pnmtoxwd 2>/dev/null || which pnmtoxwd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
