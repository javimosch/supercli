# SpamBlocker Plugin

Android Call/SMS blocker.

## Commands

### General
- `SpamBlocker self version` — Print SpamBlocker version
- `SpamBlocker _ _` — Passthrough to spamblocker CLI

## Usage Examples
- "Run SpamBlocker"
- "Use spamblocker to Android Call/SMS blocker."

## Installation

```bash
pip install spamblocker
```

## Key Features
- Android Call/SMS blocker.
- CLI tool, headless and scriptable
