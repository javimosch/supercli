# pianobar Plugin

pianobar — console Pandora radio client

## Commands
- `pianobar <resource> <action>` — Execute pianobar commands
- `pianobar _ _` — Passthrough

## Installation

```bash
macOS: brew install pianobar
Ubuntu/Debian: sudo apt install pianobar
```


## Passthrough

```bash
sc pianobar _ _ <args...>
```

## SuperCLI

```bash
sc pianobar _ _ --help
sc plugins learn pianobar
```
