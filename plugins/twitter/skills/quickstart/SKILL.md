# twitter Plugin

CLI tool: twitter.

## Commands
- `twitter <resource> <action>` — Execute twitter commands
- `twitter self version` — Print twitter version
- `twitter _ _` — Passthrough to twitter CLI

## Usage Examples
- "twitter --help"
- "twitter self version"

## Installation
```bash
apt-get install twitter 2>/dev/null || which twitter
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
