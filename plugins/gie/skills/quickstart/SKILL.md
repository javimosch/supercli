# gie Plugin

CLI tool: gie.

## Commands
- `gie <resource> <action>` — Execute gie commands
- `gie self version` — Print gie version
- `gie _ _` — Passthrough to gie CLI

## Usage Examples
- "gie --help"
- "gie self version"

## Installation
```bash
apt-get install gie 2>/dev/null || which gie
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
