# czkawka Plugin

czkawka — duplicate file finder, empty folders, similar images, and more..

## Commands

### `sc czkawka dup find`
Find duplicate files in directory.

### `sc czkawka empty find`
Find empty folders.

### `sc czkawka image similar`
Find similar images.

### `sc czkawka self version`
Print version.

## Installation

```bash
cargo install czkawka
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
