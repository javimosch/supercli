# neotoppm Plugin

CLI tool: neotoppm.

## Commands
- `neotoppm <resource> <action>` — Execute neotoppm commands
- `neotoppm self version` — Print neotoppm version
- `neotoppm _ _` — Passthrough to neotoppm CLI

## Usage Examples
- "neotoppm --help"
- "neotoppm self version"

## Installation
```bash
apt-get install neotoppm 2>/dev/null || which neotoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
