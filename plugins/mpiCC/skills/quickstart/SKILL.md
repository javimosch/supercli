# mpiCC Plugin

CLI tool: mpiCC.

## Commands
- `mpiCC <resource> <action>` — Execute mpiCC commands
- `mpiCC self version` — Print mpiCC version
- `mpiCC _ _` — Passthrough to mpiCC CLI

## Usage Examples
- "mpiCC --help"
- "mpiCC self version"

## Installation
```bash
apt-get install mpiCC 2>/dev/null || which mpiCC
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
