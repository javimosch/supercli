# move.zig Plugin
Zig-based mv with conflict resolution.
## Commands
- `move.zig _ _` — Passthrough to move.zig CLI
## Installation
```bash
git clone https://github.com/gauravnumber/move.zig && cd move.zig && zig build
```
## Key Features
- **Fast** — Zig-powered
- **Conflict resolution** — Smart name collision handling
- **Pipeline-ready** — Automation support
