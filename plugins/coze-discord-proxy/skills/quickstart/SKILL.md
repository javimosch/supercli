# coze-discord-proxy Plugin

代理Discord对话Coze-Bot，实现以API形式请求GPT4模型，提供对话、文生图、图生文、知识库检索等功能。

## Commands

### General
- `coze-discord-proxy self version` — Print coze-discord-proxy version
- `coze-discord-proxy _ _` — Passthrough to coze-discord-proxy CLI

- "Run coze-discord-proxy"

## Installation

```bash
pip install coze-discord-proxy
```
