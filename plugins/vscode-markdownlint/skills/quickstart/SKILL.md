# vscode-markdownlint Plugin
Markdown linting rules for VS Code via CLI

## Commands
- `vscode-markdownlint <resource> <action>` — Execute vscode-markdownlint commands
- `vscode-markdownlint _ _` — Passthrough to vscode-markdownlint CLI

## Usage
- `vscode-markdownlint _ _ <args>` — Run vscode-markdownlint with any arguments
