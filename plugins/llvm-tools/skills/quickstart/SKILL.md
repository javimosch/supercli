# llvm-tools
llvm-tools — LLVM binary utilities. llvm-objdump, llvm-nm, llvm-size, llvm-strings for binary analysis.

## Commands
- `llvm-tools <resource> <action>` — Execute llvm-tools commands
- `llvm tools run` — llvm-tools — LLVM binary utilities. llvm-objdump, llvm-nm, llvm-size, llvm-strings for binary analysis.
