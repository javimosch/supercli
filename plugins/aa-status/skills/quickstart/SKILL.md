# aa-status Plugin

CLI tool: aa-status.

## Commands
- `aa-status <resource> <action>` — Execute aa-status commands
- `aa-status self version` — Print aa-status version
- `aa-status _ _` — Passthrough to aa-status CLI

## Usage Examples
- "aa-status --help"
- "aa-status self version"

## Installation
```bash
apt-get install aa-status 2>/dev/null || which aa-status
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
