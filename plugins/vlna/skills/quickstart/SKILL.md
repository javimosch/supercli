# vlna Plugin

CLI tool: vlna.

## Commands
- `vlna <resource> <action>` — Execute vlna commands
- `vlna self version` — Print vlna version
- `vlna _ _` — Passthrough to vlna CLI

## Usage Examples
- "vlna --help"
- "vlna self version"

## Installation
```bash
apt-get install vlna 2>/dev/null || which vlna
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
