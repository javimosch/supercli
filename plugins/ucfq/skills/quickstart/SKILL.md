# ucfq Plugin

CLI tool: ucfq.

## Commands
- `ucfq <resource> <action>` — Execute ucfq commands
- `ucfq self version` — Print ucfq version
- `ucfq _ _` — Passthrough to ucfq CLI

## Usage Examples
- "ucfq --help"
- "ucfq self version"

## Installation
```bash
apt-get install ucfq 2>/dev/null || which ucfq
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
