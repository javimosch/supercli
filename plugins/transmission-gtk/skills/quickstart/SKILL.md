# transmission-gtk Plugin

CLI tool: transmission-gtk.

## Commands
- `transmission-gtk <resource> <action>` — Execute transmission-gtk commands
- `transmission-gtk self version` — Print transmission-gtk version
- `transmission-gtk _ _` — Passthrough to transmission-gtk CLI

## Usage Examples
- "transmission-gtk --help"
- "transmission-gtk self version"

## Installation
```bash
apt-get install transmission-gtk 2>/dev/null || which transmission-gtk
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
