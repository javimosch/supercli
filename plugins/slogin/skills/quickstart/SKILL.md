# slogin Plugin

CLI tool: slogin.

## Commands
- `slogin <resource> <action>` — Execute slogin commands
- `slogin self version` — Print slogin version
- `slogin _ _` — Passthrough to slogin CLI

## Usage Examples
- "slogin --help"
- "slogin self version"

## Installation
```bash
apt-get install slogin 2>/dev/null || which slogin
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
