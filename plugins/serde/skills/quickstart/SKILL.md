# serde Plugin

Serde — serialization framework for Rust

## Commands
- `serde <resource> <action>` — Execute serde commands
- `serde self version` — Version

## Installation

```bash
cargo install serde
Verify: serde --version
```

## Commands

### `sc serde self version`

Version


## SuperCLI

```bash
sc serde _ _ --help
sc plugins learn serde
```
