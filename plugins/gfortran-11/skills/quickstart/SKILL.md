# gfortran-11 Plugin

CLI tool: gfortran-11.

## Commands
- `gfortran-11 <resource> <action>` — Execute gfortran-11 commands
- `gfortran-11 self version` — Print gfortran-11 version
- `gfortran-11 _ _` — Passthrough to gfortran-11 CLI

## Usage Examples
- "gfortran-11 --help"
- "gfortran-11 self version"

## Installation
```bash
apt-get install gfortran-11 2>/dev/null || which gfortran-11
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
