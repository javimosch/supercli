# markdown_py Plugin

CLI tool: markdown_py.

## Commands
- `markdown_py <resource> <action>` — Execute markdown_py commands
- `markdown_py self version` — Print markdown_py version
- `markdown_py _ _` — Passthrough to markdown_py CLI

## Usage Examples
- "markdown_py --help"
- "markdown_py self version"

## Installation
```bash
apt-get install markdown_py 2>/dev/null || which markdown_py
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
