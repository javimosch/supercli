# terminator Plugin

CLI tool: terminator.

## Commands
- `terminator <resource> <action>` — Execute terminator commands
- `terminator self version` — Print terminator version
- `terminator _ _` — Passthrough to terminator CLI

## Usage Examples
- "terminator --help"
- "terminator self version"

## Installation
```bash
apt-get install terminator 2>/dev/null || which terminator
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
