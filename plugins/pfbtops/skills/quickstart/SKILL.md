# pfbtops Plugin

CLI tool: pfbtops.

## Commands
- `pfbtops <resource> <action>` — Execute pfbtops commands
- `pfbtops self version` — Print pfbtops version
- `pfbtops _ _` — Passthrough to pfbtops CLI

## Usage Examples
- "pfbtops --help"
- "pfbtops self version"

## Installation
```bash
apt-get install pfbtops 2>/dev/null || which pfbtops
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
