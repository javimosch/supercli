# sim Plugin

Build, deploy, and orchestrate AI agents. Sim is the central intelligence layer for your AI workforce.

## Commands
- `sim <resource> <action>` — Execute sim commands
- `sim self version` — Print sim version
- `sim _ _` — Passthrough to sim CLI

## Installation

```bash
pip install sim
```
