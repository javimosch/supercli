# dvitomp Plugin

CLI tool: dvitomp.

## Commands
- `dvitomp <resource> <action>` — Execute dvitomp commands
- `dvitomp self version` — Print dvitomp version
- `dvitomp _ _` — Passthrough to dvitomp CLI

## Usage Examples
- "dvitomp --help"
- "dvitomp self version"

## Installation
```bash
apt-get install dvitomp 2>/dev/null || which dvitomp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
