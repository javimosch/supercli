# hello-bash-shell Plugin

Curso para aprender a trabajar con Bash (Bourne-again shell), línea de comandos, terminal y scripting desde cero utilizando Warp (la terminal y entorno de desarrollo con IA).

## Commands

### General
- `hello-bash-shell self version` — Print hello-bash-shell version
- `hello-bash-shell _ _` — Passthrough to hello-bash-shell CLI
