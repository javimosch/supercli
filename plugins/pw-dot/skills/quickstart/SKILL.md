# pw-dot Plugin

CLI tool: pw-dot.

## Commands
- `pw-dot <resource> <action>` — Execute pw-dot commands
- `pw-dot self version` — Print pw-dot version
- `pw-dot _ _` — Passthrough to pw-dot CLI

## Usage Examples
- "pw-dot --help"
- "pw-dot self version"

## Installation
```bash
apt-get install pw-dot 2>/dev/null || which pw-dot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
