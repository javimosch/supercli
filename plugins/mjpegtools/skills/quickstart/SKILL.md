# mjpegtools Plugin

mjpegtools — MJPEG video processing tools for capture, playback, editing, and compression. Supports hardware MJPEG codec, AVI file operations, audio/video synchronization, and format conversion between MJPEG and other video formats.

## Installation

```bash
brew install mjpegtools
Verify: mjpegtools --version
```

## Commands

### `sc mjpegtools self version`

Print mjpegtools version

## Passthrough

```bash
sc mjpegtools _ _ <args...>
```

## SuperCLI

```bash
sc mjpegtools _ _ --help
sc plugins learn mjpegtools
```
