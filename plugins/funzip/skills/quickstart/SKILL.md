# funzip Plugin

CLI tool: funzip.

## Commands
- `funzip <resource> <action>` — Execute funzip commands
- `funzip self version` — Print funzip version
- `funzip _ _` — Passthrough to funzip CLI

## Usage Examples
- "funzip --help"
- "funzip self version"

## Installation
```bash
apt-get install funzip 2>/dev/null || which funzip
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
