# Studio-3T Plugin

CLI tool: Studio-3T.

## Commands
- `Studio-3T <resource> <action>` — Execute Studio-3T commands
- `Studio-3T self version` — Print Studio-3T version
- `Studio-3T _ _` — Passthrough to Studio-3T CLI

## Usage Examples
- "Studio-3T --help"
- "Studio-3T self version"

## Installation
```bash
apt-get install Studio-3T 2>/dev/null || which Studio-3T
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
