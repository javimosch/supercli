# app-manifest-cli Plugin
Manipulate Android and iOS app manifest files via CLI

## Commands
- `app-manifest-cli <resource> <action>` — Execute app-manifest-cli commands
- `app-manifest-cli _ _` — Passthrough to app-manifest-cli CLI

## Usage
- `app-manifest-cli _ _ <args>` — Run app-manifest-cli with any arguments
