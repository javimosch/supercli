# lowfat Plugin

CLI tool: lowfat.

## Commands
- `lowfat <resource> <action>` — Execute lowfat commands
- `lowfat self version` — Print lowfat version
- `lowfat _ _` — Passthrough to lowfat CLI

## Usage Examples
- "lowfat --help"
- "lowfat self version"

## Installation
```bash
apt-get install lowfat 2>/dev/null || which lowfat
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
