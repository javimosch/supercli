# mandb Plugin

CLI tool: mandb.

## Commands
- `mandb <resource> <action>` — Execute mandb commands
- `mandb self version` — Print mandb version
- `mandb _ _` — Passthrough to mandb CLI

## Usage Examples
- "mandb --help"
- "mandb self version"

## Installation
```bash
apt-get install mandb 2>/dev/null || which mandb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
