# yuvtoppm Plugin

CLI tool: yuvtoppm.

## Commands
- `yuvtoppm <resource> <action>` — Execute yuvtoppm commands
- `yuvtoppm self version` — Print yuvtoppm version
- `yuvtoppm _ _` — Passthrough to yuvtoppm CLI

## Usage Examples
- "yuvtoppm --help"
- "yuvtoppm self version"

## Installation
```bash
apt-get install yuvtoppm 2>/dev/null || which yuvtoppm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
