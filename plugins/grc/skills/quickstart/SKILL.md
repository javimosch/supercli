# grc Plugin
Generic colorizer for any command output. Pipe command stdout through grc for configurable colorization. Supports log files, configs, and custom patterns.
## Commands
- `grc self version` — Print version
- `grc _ _` — Passthrough to grc
## Installation
```bash
brew install grc
```
