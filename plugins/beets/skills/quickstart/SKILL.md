# beets Plugin

beets — music library manager and tagger

## Commands
- `beets <resource> <action>` — Execute beets commands
- `beets _ _` — Passthrough

## Installation

```bash
pip install beets
```


## Passthrough

```bash
sc beets _ _ <args...>
```

## SuperCLI

```bash
sc beets _ _ --help
sc plugins learn beets
```
