# shotwell Plugin

CLI tool: shotwell.

## Commands
- `shotwell <resource> <action>` — Execute shotwell commands
- `shotwell self version` — Print shotwell version
- `shotwell _ _` — Passthrough to shotwell CLI

## Usage Examples
- "shotwell --help"
- "shotwell self version"

## Installation
```bash
apt-get install shotwell 2>/dev/null || which shotwell
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
