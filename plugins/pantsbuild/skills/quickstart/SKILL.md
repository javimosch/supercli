# pantsbuild Plugin
Scalable build system for Python Java Go and more

## Commands
- `pantsbuild <resource> <action>` — Execute pantsbuild commands
- `pantsbuild _ _` — Passthrough to pantsbuild CLI

## Usage
- `pantsbuild _ _ <args>` — Run pantsbuild with any arguments
