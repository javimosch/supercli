# morphe-manager Plugin

Morphe app patcher for Android

## Commands

### General
- `morphe-manager self version` — Print morphe-manager version
- `morphe-manager _ _` — Passthrough to morphe-manager CLI

## Usage Examples
- "Run morphe-manager"
- "Use morphe-manager to Morphe app patcher for Android"

## Installation

```bash
pip install morphe-manager
```

## Key Features
- Morphe app patcher for Android
- CLI tool, headless and scriptable
