# color-palette
color-palette — generate color schemes from a base hex color. Outputs monochromatic, complementary, triadic, analogous palettes as JSON.

## Commands
- `color-palette <resource> <action>` — Execute color-palette commands
- `color palette run` — color-palette — generate color schemes from a base hex color. Outputs monochromatic, complementary, triadic, analogous palettes as JSON.
