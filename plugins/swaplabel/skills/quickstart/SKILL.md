# swaplabel Plugin

CLI tool: swaplabel.

## Commands
- `swaplabel <resource> <action>` — Execute swaplabel commands
- `swaplabel self version` — Print swaplabel version
- `swaplabel _ _` — Passthrough to swaplabel CLI

## Usage Examples
- "swaplabel --help"
- "swaplabel self version"

## Installation
```bash
apt-get install swaplabel 2>/dev/null || which swaplabel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
