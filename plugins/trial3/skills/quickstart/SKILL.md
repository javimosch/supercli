# trial3 Plugin

CLI tool: trial3.

## Commands
- `trial3 <resource> <action>` — Execute trial3 commands
- `trial3 self version` — Print trial3 version
- `trial3 _ _` — Passthrough to trial3 CLI

## Usage Examples
- "trial3 --help"
- "trial3 self version"

## Installation
```bash
apt-get install trial3 2>/dev/null || which trial3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
