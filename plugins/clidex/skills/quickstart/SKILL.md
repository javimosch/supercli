# clidex Plugin

CLI tool discovery for AI agents — search, compare, and install 440+ tools

## Commands
- `clidex self version` — Print clidex version
- `clidex _ _` — Passthrough to clidex CLI

## Usage Examples
- `clidex self version` — Check installed version
- `clidex _ _ --help` — Show clidex help
- `clidex _ _ --json` — JSON output mode

## Installation
```bash
cargo install clidex
```

## Key Features
- cli, discovery, ai-agents
- Non-interactive CLI with JSON output support
- Pipeline-ready for automation
