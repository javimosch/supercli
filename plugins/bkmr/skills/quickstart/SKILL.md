# bkmr Plugin
Fast bookmark manager with fuzzy search in Rust

## Commands
- `bkmr <resource> <action>` — Execute bkmr commands
- `bkmr _ _` — Passthrough to bkmr CLI

## Usage
- `bkmr _ _ <args>` — Run bkmr with any arguments
