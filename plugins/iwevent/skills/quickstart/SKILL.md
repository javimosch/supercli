# iwevent Plugin

CLI tool: iwevent.

## Commands
- `iwevent <resource> <action>` — Execute iwevent commands
- `iwevent self version` — Print iwevent version
- `iwevent _ _` — Passthrough to iwevent CLI

## Usage Examples
- "iwevent --help"
- "iwevent self version"

## Installation
```bash
apt-get install iwevent 2>/dev/null || which iwevent
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
