# pnmhisteq Plugin

CLI tool: pnmhisteq.

## Commands
- `pnmhisteq <resource> <action>` — Execute pnmhisteq commands
- `pnmhisteq self version` — Print pnmhisteq version
- `pnmhisteq _ _` — Passthrough to pnmhisteq CLI

## Usage Examples
- "pnmhisteq --help"
- "pnmhisteq self version"

## Installation
```bash
apt-get install pnmhisteq 2>/dev/null || which pnmhisteq
```

- Pipeline-ready output
