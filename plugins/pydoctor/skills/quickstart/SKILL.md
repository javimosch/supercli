# pydoctor Plugin
Python-focused API documentation generator

## Commands
- `pydoctor <resource> <action>` — Execute pydoctor commands
- `pydoctor _ _` — Passthrough to pydoctor CLI

## Usage
- `pydoctor _ _ <args>` — Run pydoctor with any arguments
