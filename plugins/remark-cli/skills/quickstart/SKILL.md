# remark-cli Plugin
Command line interface for remark markdown processor

## Commands
- `remark-cli <resource> <action>` — Execute remark-cli commands
- `remark-cli _ _` — Passthrough to remark-cli CLI

## Usage
- `remark-cli _ _ <args>` — Run remark-cli with any arguments
