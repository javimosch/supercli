# thunar-volman Plugin

CLI tool: thunar-volman.

## Commands
- `thunar-volman <resource> <action>` — Execute thunar-volman commands
- `thunar-volman self version` — Print thunar-volman version
- `thunar-volman _ _` — Passthrough to thunar-volman CLI

## Usage Examples
- "thunar-volman --help"
- "thunar-volman self version"

## Installation
```bash
apt-get install thunar-volman 2>/dev/null || which thunar-volman
```
