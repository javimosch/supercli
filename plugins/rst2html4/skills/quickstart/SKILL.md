# rst2html4 Plugin

CLI tool: rst2html4.

## Commands
- `rst2html4 <resource> <action>` — Execute rst2html4 commands
- `rst2html4 self version` — Print rst2html4 version
- `rst2html4 _ _` — Passthrough to rst2html4 CLI

## Usage Examples
- "rst2html4 --help"
- "rst2html4 self version"

## Installation
```bash
apt-get install rst2html4 2>/dev/null || which rst2html4
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
