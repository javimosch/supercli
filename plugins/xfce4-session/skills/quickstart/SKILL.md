# xfce4-session Plugin

CLI tool: xfce4-session.

## Commands
- `xfce4-session <resource> <action>` — Execute xfce4-session commands
- `xfce4-session self version` — Print xfce4-session version
- `xfce4-session _ _` — Passthrough to xfce4-session CLI

## Usage Examples
- "xfce4-session --help"
- "xfce4-session self version"

## Installation
```bash
apt-get install xfce4-session 2>/dev/null || which xfce4-session
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
