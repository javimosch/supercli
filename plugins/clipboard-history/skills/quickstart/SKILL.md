# clipboard-history Plugin
Track and recall clipboard history in the terminal

## Commands
- `clipboard-history <resource> <action>` — Execute clipboard-history commands
- `clipboard-history _ _` — Passthrough to clipboard-history CLI

## Usage
- `clipboard-history _ _ <args>` — Run clipboard-history with any arguments
