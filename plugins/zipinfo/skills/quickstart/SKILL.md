# zipinfo Plugin

CLI tool: zipinfo.

## Commands
- `zipinfo <resource> <action>` — Execute zipinfo commands
- `zipinfo self version` — Print zipinfo version
- `zipinfo _ _` — Passthrough to zipinfo CLI

## Usage Examples
- "zipinfo --help"
- "zipinfo self version"

## Installation
```bash
apt-get install zipinfo 2>/dev/null || which zipinfo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
