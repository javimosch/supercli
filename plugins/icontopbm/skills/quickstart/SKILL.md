# icontopbm Plugin

CLI tool: icontopbm.

## Commands
- `icontopbm <resource> <action>` — Execute icontopbm commands
- `icontopbm self version` — Print icontopbm version
- `icontopbm _ _` — Passthrough to icontopbm CLI

## Usage Examples
- "icontopbm --help"
- "icontopbm self version"

## Installation
```bash
apt-get install icontopbm 2>/dev/null || which icontopbm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
