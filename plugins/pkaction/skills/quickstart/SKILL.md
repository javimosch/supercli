# pkaction Plugin

CLI tool: pkaction.

## Commands
- `pkaction <resource> <action>` — Execute pkaction commands
- `pkaction self version` — Print pkaction version
- `pkaction _ _` — Passthrough to pkaction CLI

## Usage Examples
- "pkaction --help"
- "pkaction self version"

## Installation
```bash
apt-get install pkaction 2>/dev/null || which pkaction
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
