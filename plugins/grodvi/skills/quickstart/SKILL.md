# grodvi Plugin

CLI tool: grodvi.

## Commands
- `grodvi <resource> <action>` — Execute grodvi commands
- `grodvi self version` — Print grodvi version
- `grodvi _ _` — Passthrough to grodvi CLI

## Usage Examples
- "grodvi --help"
- "grodvi self version"

## Installation
```bash
apt-get install grodvi 2>/dev/null || which grodvi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
