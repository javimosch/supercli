# pybabel Plugin

CLI tool: pybabel.

## Commands
- `pybabel <resource> <action>` — Execute pybabel commands
- `pybabel self version` — Print pybabel version
- `pybabel _ _` — Passthrough to pybabel CLI

## Usage Examples
- "pybabel --help"
- "pybabel self version"

## Installation
```bash
apt-get install pybabel 2>/dev/null || which pybabel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
