# dv2dt Plugin

CLI tool: dv2dt.

## Commands
- `dv2dt <resource> <action>` — Execute dv2dt commands
- `dv2dt self version` — Print dv2dt version
- `dv2dt _ _` — Passthrough to dv2dt CLI

## Usage Examples
- "dv2dt --help"
- "dv2dt self version"

## Installation
```bash
apt-get install dv2dt 2>/dev/null || which dv2dt
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
