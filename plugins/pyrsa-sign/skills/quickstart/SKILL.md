# pyrsa-sign Plugin

CLI tool: pyrsa-sign.

## Commands
- `pyrsa-sign <resource> <action>` — Execute pyrsa-sign commands
- `pyrsa-sign self version` — Print pyrsa-sign version
- `pyrsa-sign _ _` — Passthrough to pyrsa-sign CLI

## Usage Examples
- "pyrsa-sign --help"
- "pyrsa-sign self version"

## Installation
```bash
apt-get install pyrsa-sign 2>/dev/null || which pyrsa-sign
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
