# pick Plugin

pick — a fuzzy picker for the terminal..

## Commands

### `sc pick filter run`
Fuzzy filter stdin lines.

### `sc pick self version`
Print version.

## Installation

```bash
brew install pick
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
