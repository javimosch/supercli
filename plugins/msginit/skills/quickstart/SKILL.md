# msginit Plugin

CLI tool: msginit.

## Commands
- `msginit <resource> <action>` — Execute msginit commands
- `msginit self version` — Print msginit version
- `msginit _ _` — Passthrough to msginit CLI

## Usage Examples
- "msginit --help"
- "msginit self version"

## Installation
```bash
apt-get install msginit 2>/dev/null || which msginit
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
