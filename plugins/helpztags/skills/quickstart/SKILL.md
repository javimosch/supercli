# helpztags Plugin

CLI tool: helpztags.

## Commands
- `helpztags <resource> <action>` — Execute helpztags commands
- `helpztags self version` — Print helpztags version
- `helpztags _ _` — Passthrough to helpztags CLI

## Usage Examples
- "helpztags --help"
- "helpztags self version"

## Installation
```bash
apt-get install helpztags 2>/dev/null || which helpztags
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
