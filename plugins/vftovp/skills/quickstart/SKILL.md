# vftovp Plugin

CLI tool: vftovp.

## Commands
- `vftovp <resource> <action>` — Execute vftovp commands
- `vftovp self version` — Print vftovp version
- `vftovp _ _` — Passthrough to vftovp CLI

## Usage Examples
- "vftovp --help"
- "vftovp self version"

## Installation
```bash
apt-get install vftovp 2>/dev/null || which vftovp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
