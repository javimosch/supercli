# mt-gnu Plugin

CLI tool: mt-gnu.

## Commands
- `mt-gnu <resource> <action>` — Execute mt-gnu commands
- `mt-gnu self version` — Print mt-gnu version
- `mt-gnu _ _` — Passthrough to mt-gnu CLI

## Usage Examples
- "mt-gnu --help"
- "mt-gnu self version"

## Installation
```bash
apt-get install mt-gnu 2>/dev/null || which mt-gnu
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
