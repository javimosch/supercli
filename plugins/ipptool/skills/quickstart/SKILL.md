# ipptool Plugin

CLI tool: ipptool.

## Commands
- `ipptool <resource> <action>` — Execute ipptool commands
- `ipptool self version` — Print ipptool version
- `ipptool _ _` — Passthrough to ipptool CLI

## Usage Examples
- "ipptool --help"
- "ipptool self version"

## Installation
```bash
apt-get install ipptool 2>/dev/null || which ipptool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
