# mdeltree Plugin

CLI tool: mdeltree.

## Commands
- `mdeltree <resource> <action>` — Execute mdeltree commands
- `mdeltree self version` — Print mdeltree version
- `mdeltree _ _` — Passthrough to mdeltree CLI

## Usage Examples
- "mdeltree --help"
- "mdeltree self version"

## Installation
```bash
apt-get install mdeltree 2>/dev/null || which mdeltree
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
