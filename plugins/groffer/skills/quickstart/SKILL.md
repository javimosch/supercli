# groffer Plugin

CLI tool: groffer.

## Commands
- `groffer <resource> <action>` — Execute groffer commands
- `groffer self version` — Print groffer version
- `groffer _ _` — Passthrough to groffer CLI

## Usage Examples
- "groffer --help"
- "groffer self version"

## Installation
```bash
apt-get install groffer 2>/dev/null || which groffer
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
