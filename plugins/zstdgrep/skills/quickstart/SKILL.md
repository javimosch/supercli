# zstdgrep Plugin

CLI tool: zstdgrep.

## Commands
- `zstdgrep <resource> <action>` — Execute zstdgrep commands
- `zstdgrep self version` — Print zstdgrep version
- `zstdgrep _ _` — Passthrough to zstdgrep CLI

## Usage Examples
- "zstdgrep --help"
- "zstdgrep self version"

## Installation
```bash
apt-get install zstdgrep 2>/dev/null || which zstdgrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
