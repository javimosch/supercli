# rst2latex Plugin

CLI tool: rst2latex.

## Commands
- `rst2latex <resource> <action>` — Execute rst2latex commands
- `rst2latex self version` — Print rst2latex version
- `rst2latex _ _` — Passthrough to rst2latex CLI

## Usage Examples
- "rst2latex --help"
- "rst2latex self version"

## Installation
```bash
apt-get install rst2latex 2>/dev/null || which rst2latex
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
