# Quickstart

See GitHub repository for comprehensive documentation and usage examples.

## Commands
- `lame <resource> <action>` — Execute lame commands
- `lame self version` — Print lame version
- `lame encode mp3` — Encode audio to MP3
- `lame _ _` — Passthrough to lame CLI
