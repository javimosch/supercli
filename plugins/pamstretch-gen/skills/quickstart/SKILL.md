# pamstretch-gen Plugin

CLI tool: pamstretch-gen.

## Commands
- `pamstretch-gen <resource> <action>` — Execute pamstretch-gen commands
- `pamstretch-gen self version` — Print pamstretch-gen version
- `pamstretch-gen _ _` — Passthrough to pamstretch-gen CLI

## Usage Examples
- "pamstretch-gen --help"
- "pamstretch-gen self version"

## Installation
```bash
apt-get install pamstretch-gen 2>/dev/null || which pamstretch-gen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
