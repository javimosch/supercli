# MemShellParty Plugin

一款专注于 Java 主流 Web 中间件的内存马快速生成工具，致力于简化安全研究人员和红队成员的工作流程，提升攻防效率

## Commands

### General
- `MemShellParty self version` — Print MemShellParty version
- `MemShellParty _ _` — Passthrough to memshellparty CLI
