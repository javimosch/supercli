# totp-cli
totp-cli — TOTP/HOTP token generator CLI. Generate time-based one-time passwords for 2FA from command line.

## Commands
- `totp-cli <resource> <action>` — Execute totp-cli commands
- `totp cli run` — totp-cli — TOTP/HOTP token generator CLI. Generate time-based one-time passwords for 2FA from command line.
