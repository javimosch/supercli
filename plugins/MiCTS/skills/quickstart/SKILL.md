# MiCTS Plugin

Trigger Circle to Search on any Android 9–16 device

## Commands

### General
- `MiCTS self version` — Print MiCTS version
- `MiCTS _ _` — Passthrough to micts CLI

## Usage Examples
- "Run MiCTS"
- "Use micts to Trigger Circle to Search on any Android 9–16 device"

## Installation

```bash
pip install micts
```

## Key Features
- Trigger Circle to Search on any Android 9–16 device
- CLI tool, headless and scriptable
