# easter-egg-search Plugin
Search files for hidden developer easter eggs

## Commands
- `easter-egg-search <resource> <action>` — Execute easter-egg-search commands
- `easter-egg-search _ _` — Passthrough to easter-egg-search CLI

## Usage
- `easter-egg-search _ _ <args>` — Run easter-egg-search with any arguments
