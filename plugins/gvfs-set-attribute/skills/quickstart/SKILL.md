# gvfs-set-attribute Plugin

CLI tool: gvfs-set-attribute.

## Commands
- `gvfs-set-attribute <resource> <action>` — Execute gvfs-set-attribute commands
- `gvfs-set-attribute self version` — Print gvfs-set-attribute version
- `gvfs-set-attribute _ _` — Passthrough to gvfs-set-attribute CLI

## Usage Examples
- "gvfs-set-attribute --help"
- "gvfs-set-attribute self version"

## Installation
```bash
apt-get install gvfs-set-attribute 2>/dev/null || which gvfs-set-attribute
```
