# thin_rmap Plugin

CLI tool: thin_rmap.

## Commands
- `thin_rmap <resource> <action>` — Execute thin_rmap commands
- `thin_rmap self version` — Print thin_rmap version
- `thin_rmap _ _` — Passthrough to thin_rmap CLI

## Usage Examples
- "thin_rmap --help"
- "thin_rmap self version"

## Installation
```bash
apt-get install thin_rmap 2>/dev/null || which thin_rmap
```
