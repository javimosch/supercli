# ash Plugin

Ash — lightweight POSIX-compliant shell

## Commands
- `ash <resource> <action>` — Execute ash commands
- `ash self version` — Version

## Installation

```bash
brew install ash
Verify: ash --version
```

## Commands

### `sc ash self version`

Version


## SuperCLI

```bash
sc ash _ _ --help
sc plugins learn ash
```
