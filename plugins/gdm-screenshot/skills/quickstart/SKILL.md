# gdm-screenshot Plugin

CLI tool: gdm-screenshot.

## Commands
- `gdm-screenshot <resource> <action>` — Execute gdm-screenshot commands
- `gdm-screenshot self version` — Print gdm-screenshot version
- `gdm-screenshot _ _` — Passthrough to gdm-screenshot CLI

## Usage Examples
- "gdm-screenshot --help"
- "gdm-screenshot self version"

## Installation
```bash
apt-get install gdm-screenshot 2>/dev/null || which gdm-screenshot
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
