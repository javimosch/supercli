# unity-scope-loader Plugin

CLI tool: unity-scope-loader.

## Commands
- `unity-scope-loader <resource> <action>` — Execute unity-scope-loader commands
- `unity-scope-loader self version` — Print unity-scope-loader version
- `unity-scope-loader _ _` — Passthrough to unity-scope-loader CLI

## Usage Examples
- "unity-scope-loader --help"
- "unity-scope-loader self version"

## Installation
```bash
apt-get install unity-scope-loader 2>/dev/null || which unity-scope-loader
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
