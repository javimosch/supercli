# PocketMage_PDA Plugin

An E-Ink PDA device using the ESP32 S3.

## Commands

### General
- `PocketMage_PDA self version` — Print PocketMage_PDA version
- `PocketMage_PDA _ _` — Passthrough to pocketmage-pda CLI

## Usage Examples
- "Run PocketMage_PDA"
- "Use pocketmage-pda to An E-Ink PDA device using the ESP32 S3."

## Installation

```bash
pip install pocketmage-pda
```

## Key Features
- An E-Ink PDA device using the ESP32 S3.
- CLI tool, headless and scriptable
