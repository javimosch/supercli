# psicc Plugin

CLI tool: psicc.

## Commands
- `psicc <resource> <action>` — Execute psicc commands
- `psicc self version` — Print psicc version
- `psicc _ _` — Passthrough to psicc CLI

## Usage Examples
- "psicc --help"
- "psicc self version"

## Installation
```bash
apt-get install psicc 2>/dev/null || which psicc
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
