# ruscreen Plugin

CLI tool: ruscreen.

## Commands
- `ruscreen <resource> <action>` — Execute ruscreen commands
- `ruscreen self version` — Print ruscreen version
- `ruscreen _ _` — Passthrough to ruscreen CLI

## Usage Examples
- "ruscreen --help"
- "ruscreen self version"

## Installation
```bash
apt-get install ruscreen 2>/dev/null || which ruscreen
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
