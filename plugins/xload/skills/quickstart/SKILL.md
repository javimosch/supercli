# xload Plugin

CLI tool: xload.

## Commands
- `xload <resource> <action>` — Execute xload commands
- `xload self version` — Print xload version
- `xload _ _` — Passthrough to xload CLI

## Usage Examples
- "xload --help"
- "xload self version"

## Installation
```bash
apt-get install xload 2>/dev/null || which xload
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
