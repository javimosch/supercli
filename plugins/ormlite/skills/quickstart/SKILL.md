# ormlite Plugin
Rust ORM CLI that auto-generates migrations from structs

## Commands
- `ormlite <resource> <action>` — Execute ormlite commands
- `ormlite _ _` — Passthrough to ormlite CLI

## Usage
- `ormlite _ _ <args>` — Run ormlite with any arguments
