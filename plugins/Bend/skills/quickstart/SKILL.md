# Bend Plugin

A massively parallel, high-level programming language

## Commands
- `Bend <resource> <action>` — Execute Bend commands
- `Bend self version` — Print Bend version
- `Bend _ _` — Passthrough to bend CLI

## Installation

```bash
pip install bend
```
