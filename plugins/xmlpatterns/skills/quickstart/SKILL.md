# xmlpatterns Plugin

CLI tool: xmlpatterns.

## Commands
- `xmlpatterns <resource> <action>` — Execute xmlpatterns commands
- `xmlpatterns self version` — Print xmlpatterns version
- `xmlpatterns _ _` — Passthrough to xmlpatterns CLI

## Usage Examples
- "xmlpatterns --help"
- "xmlpatterns self version"

## Installation
```bash
apt-get install xmlpatterns 2>/dev/null || which xmlpatterns
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
