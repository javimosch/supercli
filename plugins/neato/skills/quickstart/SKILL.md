# neato Plugin

CLI tool: neato.

## Commands
- `neato <resource> <action>` — Execute neato commands
- `neato self version` — Print neato version
- `neato _ _` — Passthrough to neato CLI

## Usage Examples
- "neato --help"
- "neato self version"

## Installation
```bash
apt-get install neato 2>/dev/null || which neato
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
