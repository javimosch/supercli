# gifview Plugin

CLI tool: gifview.

## Commands
- `gifview <resource> <action>` — Execute gifview commands
- `gifview self version` — Print gifview version
- `gifview _ _` — Passthrough to gifview CLI

## Usage Examples
- "gifview --help"
- "gifview self version"

## Installation
```bash
apt-get install gifview 2>/dev/null || which gifview
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
