# qgltf Plugin

CLI tool: qgltf.

## Commands
- `qgltf <resource> <action>` — Execute qgltf commands
- `qgltf self version` — Print qgltf version
- `qgltf _ _` — Passthrough to qgltf CLI

## Usage Examples
- "qgltf --help"
- "qgltf self version"

## Installation
```bash
apt-get install qgltf 2>/dev/null || which qgltf
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
