# favicon-emoji Plugin

Generate emoji-favicon in terminal in JavaScript

## Commands

### Operations
- `favicon-emoji self version` — Print favicon-emoji version
- `favicon-emoji _ _` — Passthrough to favicon-emoji CLI

## Usage Examples
- `favicon-emoji --help`
- `favicon-emoji <args>`

## Installation

```bash
npm install -g favicon-emoji
```

## Examples

```bash
favicon-emoji --version
favicon-emoji --help
```
