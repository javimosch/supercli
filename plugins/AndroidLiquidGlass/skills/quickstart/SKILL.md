# AndroidLiquidGlass Plugin

Compose Multiplatform Liquid Glass effect

## Commands

### General
- `AndroidLiquidGlass self version` — Print AndroidLiquidGlass version
- `AndroidLiquidGlass _ _` — Passthrough to androidliquidglass CLI

## Usage Examples
- "Run AndroidLiquidGlass"
- "Use androidliquidglass to Compose Multiplatform Liquid Glass effect"

## Installation

```bash
pip install androidliquidglass
```

## Key Features
- Compose Multiplatform Liquid Glass effect
- CLI tool, headless and scriptable
