# datamash
datamash — GNU data transformation tool. Perform numeric, textual, and statistical operations on tabular data.

## Commands
- `datamash <resource> <action>` — Execute datamash commands
- `datamash datamash run` — datamash — GNU data transformation tool. Perform numeric, textual, and statistical operations on tabular data.
