# mapscrn Plugin

CLI tool: mapscrn.

## Commands
- `mapscrn <resource> <action>` — Execute mapscrn commands
- `mapscrn self version` — Print mapscrn version
- `mapscrn _ _` — Passthrough to mapscrn CLI

## Usage Examples
- "mapscrn --help"
- "mapscrn self version"

## Installation
```bash
apt-get install mapscrn 2>/dev/null || which mapscrn
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
