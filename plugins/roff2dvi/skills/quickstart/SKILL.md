# roff2dvi Plugin

CLI tool: roff2dvi.

## Commands
- `roff2dvi <resource> <action>` — Execute roff2dvi commands
- `roff2dvi self version` — Print roff2dvi version
- `roff2dvi _ _` — Passthrough to roff2dvi CLI

## Usage Examples
- "roff2dvi --help"
- "roff2dvi self version"

## Installation
```bash
apt-get install roff2dvi 2>/dev/null || which roff2dvi
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
