# im-server Plugin

A high-performance IM server.

## Commands

### General
- `im-server self version` — Print im-server version
- `im-server _ _` — Passthrough to im-server CLI

## Usage Examples
- "Run im-server"
- "Use im-server to A high-performance IM server."

## Installation

```bash
pip install im-server
```

## Key Features
- A high-performance IM server.
- CLI tool, headless and scriptable
