# mkofm Plugin

CLI tool: mkofm.

## Commands
- `mkofm <resource> <action>` — Execute mkofm commands
- `mkofm self version` — Print mkofm version
- `mkofm _ _` — Passthrough to mkofm CLI

## Usage Examples
- "mkofm --help"
- "mkofm self version"

apt-get install mkofm 2>/dev/null || which mkofm
