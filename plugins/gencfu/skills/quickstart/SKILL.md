# gencfu Plugin

CLI tool: gencfu.

## Commands
- `gencfu <resource> <action>` — Execute gencfu commands
- `gencfu self version` — Print gencfu version
- `gencfu _ _` — Passthrough to gencfu CLI

## Usage Examples
- "gencfu --help"
- "gencfu self version"

## Installation
```bash
apt-get install gencfu 2>/dev/null || which gencfu
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
