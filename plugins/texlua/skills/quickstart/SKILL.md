# texlua Plugin

CLI tool: texlua.

## Commands
- `texlua <resource> <action>` — Execute texlua commands
- `texlua self version` — Print texlua version
- `texlua _ _` — Passthrough to texlua CLI

## Usage Examples
- "texlua --help"
- "texlua self version"

## Installation
```bash
apt-get install texlua 2>/dev/null || which texlua
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
