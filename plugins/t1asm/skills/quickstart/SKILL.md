# t1asm Plugin

CLI tool: t1asm.

## Commands
- `t1asm <resource> <action>` — Execute t1asm commands
- `t1asm self version` — Print t1asm version
- `t1asm _ _` — Passthrough to t1asm CLI

## Usage Examples
- "t1asm --help"
- "t1asm self version"

## Installation
```bash
apt-get install t1asm 2>/dev/null || which t1asm
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
