# sql-studio Plugin

SQL Database Explorer [SQLite, libSQL, PostgreSQL, MySQL/MariaDB, ClickHouse, DuckDB, Microsoft SQL Server]

## Commands
- `sql-studio <resource> <action>` — Execute sql-studio commands
- `sql-studio _ _` — Passthrough to sql-studio CLI

## Installation

```bash
pip install sql-studio
```
