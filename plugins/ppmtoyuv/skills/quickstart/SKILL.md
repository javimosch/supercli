# ppmtoyuv Plugin

CLI tool: ppmtoyuv.

## Commands
- `ppmtoyuv <resource> <action>` — Execute ppmtoyuv commands
- `ppmtoyuv self version` — Print ppmtoyuv version
- `ppmtoyuv _ _` — Passthrough to ppmtoyuv CLI

## Usage Examples
- "ppmtoyuv --help"
- "ppmtoyuv self version"

## Installation
```bash
apt-get install ppmtoyuv 2>/dev/null || which ppmtoyuv
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
