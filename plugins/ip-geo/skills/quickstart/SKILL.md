# ip-geo Plugin
IP geolocation lookup via ip-api.com. Shows country, city, ISP, coordinates.

## Commands
- `ip-geo <resource> <action>` — Execute ip-geo commands
- `ip geo run` — ip-geo utility

## Usage
- `ip geo run 8.8.8.8`
