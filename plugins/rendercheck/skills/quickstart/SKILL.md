# rendercheck Plugin

CLI tool: rendercheck.

## Commands
- `rendercheck <resource> <action>` — Execute rendercheck commands
- `rendercheck self version` — Print rendercheck version
- `rendercheck _ _` — Passthrough to rendercheck CLI

## Usage Examples
- "rendercheck --help"
- "rendercheck self version"

## Installation
```bash
apt-get install rendercheck 2>/dev/null || which rendercheck
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
