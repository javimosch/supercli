# etc1tool Plugin

CLI tool: etc1tool.

## Commands
- `etc1tool <resource> <action>` — Execute etc1tool commands
- `etc1tool self version` — Print etc1tool version
- `etc1tool _ _` — Passthrough to etc1tool CLI

## Usage Examples
- "etc1tool --help"
- "etc1tool self version"

## Installation
```bash
apt-get install etc1tool 2>/dev/null || which etc1tool
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
