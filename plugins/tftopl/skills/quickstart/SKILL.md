# tftopl Plugin

CLI tool: tftopl.

## Commands
- `tftopl <resource> <action>` — Execute tftopl commands
- `tftopl self version` — Print tftopl version
- `tftopl _ _` — Passthrough to tftopl CLI

## Usage Examples
- "tftopl --help"
- "tftopl self version"

## Installation
```bash
apt-get install tftopl 2>/dev/null || which tftopl
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
