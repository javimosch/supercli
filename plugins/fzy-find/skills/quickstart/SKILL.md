# fzy-find Plugin
Lightweight and fast fuzzy finder alternative for the terminal

## Commands
- `fzy-find <resource> <action>` — Execute fzy-find commands
- `fzy-find _ _` — Passthrough to fzy-find CLI

## Usage
- `fzy-find _ _ <args>` — Run fzy-find with any arguments
