# showrgb Plugin

CLI tool: showrgb.

## Commands
- `showrgb <resource> <action>` — Execute showrgb commands
- `showrgb self version` — Print showrgb version
- `showrgb _ _` — Passthrough to showrgb CLI

## Usage Examples
- "showrgb --help"
- "showrgb self version"

## Installation
```bash
apt-get install showrgb 2>/dev/null || which showrgb
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
