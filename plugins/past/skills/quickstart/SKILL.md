# past Plugin

past — a pastebin CLI tool..

## Commands

### `sc past paste send`
Upload text to pastebin.

### `sc past self version`
Print version.

## Installation

```bash
cargo install past
```

## Key Features
- CLI-only, headless operation
- No authentication required
- JSON output support
