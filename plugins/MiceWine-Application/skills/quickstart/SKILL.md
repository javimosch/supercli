# MiceWine-Application Plugin

MiceWine is a project that aims to run Windows applications and games on Android smartphones.

## Commands

### General
- `MiceWine-Application self version` — Print MiceWine-Application version
- `MiceWine-Application _ _` — Passthrough to micewine-application CLI
