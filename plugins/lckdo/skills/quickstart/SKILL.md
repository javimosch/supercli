# lckdo Plugin

CLI tool: lckdo.

## Commands
- `lckdo <resource> <action>` — Execute lckdo commands
- `lckdo self version` — Print lckdo version
- `lckdo _ _` — Passthrough to lckdo CLI

## Usage Examples
- "lckdo --help"
- "lckdo self version"

## Installation
```bash
apt-get install lckdo 2>/dev/null || which lckdo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
