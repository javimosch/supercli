# ppdpo Plugin

CLI tool: ppdpo.

## Commands
- `ppdpo <resource> <action>` — Execute ppdpo commands
- `ppdpo self version` — Print ppdpo version
- `ppdpo _ _` — Passthrough to ppdpo CLI

## Usage Examples
- "ppdpo --help"
- "ppdpo self version"

## Installation
```bash
apt-get install ppdpo 2>/dev/null || which ppdpo
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
