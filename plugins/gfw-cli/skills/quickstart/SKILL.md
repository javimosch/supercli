# gfw-cli Plugin
Global Fishing Watch data CLI.
## Commands
- `gfw-cli _ _` — Passthrough to gfw-cli CLI
## Installation
```bash
npm install -g @globalfishingwatch/gfw-cli
```
## Key Features
- **Marine data** — Spatial fishing activity
- **Machine-readable** — Structured output
- **Pipeline-ready** — Scriptable CLI
