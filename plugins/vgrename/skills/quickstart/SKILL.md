# vgrename Plugin

CLI tool: vgrename.

## Commands
- `vgrename <resource> <action>` — Execute vgrename commands
- `vgrename self version` — Print vgrename version
- `vgrename _ _` — Passthrough to vgrename CLI

## Usage Examples
- "vgrename --help"
- "vgrename self version"

## Installation
```bash
apt-get install vgrename 2>/dev/null || which vgrename
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
