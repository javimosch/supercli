# rmic Plugin

CLI tool: rmic.

## Commands
- `rmic <resource> <action>` — Execute rmic commands
- `rmic self version` — Print rmic version
- `rmic _ _` — Passthrough to rmic CLI

## Usage Examples
- "rmic --help"
- "rmic self version"

## Installation
```bash
apt-get install rmic 2>/dev/null || which rmic
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
