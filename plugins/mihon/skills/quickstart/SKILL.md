# mihon Plugin

Free and open source manga reader for Android

## Commands

### General
- `mihon self version` — Print mihon version
- `mihon _ _` — Passthrough to mihon CLI

## Usage Examples
- "Run mihon"
- "Use mihon to Free and open source manga reader for Android"

## Installation

```bash
pip install mihon
```

## Key Features
- Free and open source manga reader for Android
- CLI tool, headless and scriptable
