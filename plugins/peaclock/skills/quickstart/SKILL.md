# peaclock Plugin

Responsive customizable clock timer and stopwatch

## Commands

### Version
`peaclock self version` — Print peaclock version

### Passthrough
`peaclock _ _` — Passthrough to peaclock CLI with all arguments forwarded.

## Usage Examples

```bash
peaclock --version
peaclock --help
```

## Installation

```bash
cargo install peaclock
```

## Key Features
- Responsive customizable clock timer and stopwatch
