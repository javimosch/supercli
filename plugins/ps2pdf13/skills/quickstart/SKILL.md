# ps2pdf13 Plugin

CLI tool: ps2pdf13.

## Commands
- `ps2pdf13 <resource> <action>` — Execute ps2pdf13 commands
- `ps2pdf13 self version` — Print ps2pdf13 version
- `ps2pdf13 _ _` — Passthrough to ps2pdf13 CLI

## Usage Examples
- "ps2pdf13 --help"
- "ps2pdf13 self version"

## Installation
```bash
apt-get install ps2pdf13 2>/dev/null || which ps2pdf13
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
