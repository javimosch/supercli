# mmd Plugin

CLI tool: mmd.

## Commands
- `mmd <resource> <action>` — Execute mmd commands
- `mmd self version` — Print mmd version
- `mmd _ _` — Passthrough to mmd CLI

## Usage Examples
- "mmd --help"
- "mmd self version"

## Installation
```bash
apt-get install mmd 2>/dev/null || which mmd
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
