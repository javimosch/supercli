# twarc2 Plugin

CLI tool: twarc2.

## Commands
- `twarc2 <resource> <action>` — Execute twarc2 commands
- `twarc2 self version` — Print twarc2 version
- `twarc2 _ _` — Passthrough to twarc2 CLI

## Usage Examples
- "twarc2 --help"
- "twarc2 self version"

## Installation
```bash
apt-get install twarc2 2>/dev/null || which twarc2
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
