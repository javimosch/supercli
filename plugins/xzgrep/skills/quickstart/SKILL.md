# xzgrep Plugin

CLI tool: xzgrep.

## Commands
- `xzgrep <resource> <action>` — Execute xzgrep commands
- `xzgrep self version` — Print xzgrep version
- `xzgrep _ _` — Passthrough to xzgrep CLI

## Usage Examples
- "xzgrep --help"
- "xzgrep self version"

## Installation
```bash
apt-get install xzgrep 2>/dev/null || which xzgrep
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
