# jp2a Plugin
Convert JPEG images to ASCII art in the terminal

## Commands
- `jp2a <resource> <action>` — Execute jp2a commands
- `jp2a _ _` — Passthrough to jp2a CLI

## Usage
- `jp2a _ _ <args>` — Run jp2a with any arguments
