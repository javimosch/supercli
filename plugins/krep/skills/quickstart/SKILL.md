# krep Plugin

Fast text search tool with SIMD acceleration, multi-threading, and regex. Supports gitignore, stdin pipeline, brew install.

## Commands
- `krep self version` — Print version
- `krep _ _ <args>` — Passthrough to krep

## Usage Examples
- "Fast Text Search"

## Installation
```bash
brew install krep
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
