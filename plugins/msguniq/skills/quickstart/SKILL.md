# msguniq Plugin

CLI tool: msguniq.

## Commands
- `msguniq <resource> <action>` — Execute msguniq commands
- `msguniq self version` — Print msguniq version
- `msguniq _ _` — Passthrough to msguniq CLI

## Usage Examples
- "msguniq --help"
- "msguniq self version"

## Installation
```bash
apt-get install msguniq 2>/dev/null || which msguniq
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
