# groupdel Plugin

CLI tool: groupdel.

## Commands
- `groupdel <resource> <action>` — Execute groupdel commands
- `groupdel self version` — Print groupdel version
- `groupdel _ _` — Passthrough to groupdel CLI

## Usage Examples
- "groupdel --help"
- "groupdel self version"

## Installation
```bash
apt-get install groupdel 2>/dev/null || which groupdel
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
