# schemagen Plugin

CLI tool: schemagen.

## Commands
- `schemagen <resource> <action>` — Execute schemagen commands
- `schemagen self version` — Print schemagen version
- `schemagen _ _` — Passthrough to schemagen CLI

## Usage Examples
- "schemagen --help"
- "schemagen self version"

## Installation
```bash
apt-get install schemagen 2>/dev/null || which schemagen
```
