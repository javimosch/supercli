# gltfpack Plugin

CLI tool: gltfpack.

## Commands
- `gltfpack <resource> <action>` — Execute gltfpack commands
- `gltfpack self version` — Print gltfpack version
- `gltfpack _ _` — Passthrough to gltfpack CLI

## Usage Examples
- "gltfpack --help"
- "gltfpack self version"

## Installation
```bash
apt-get install gltfpack 2>/dev/null || which gltfpack
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
