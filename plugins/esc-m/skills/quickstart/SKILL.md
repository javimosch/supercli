# esc-m Plugin

CLI tool: esc-m.

## Commands
- `esc-m <resource> <action>` — Execute esc-m commands
- `esc-m self version` — Print esc-m version
- `esc-m _ _` — Passthrough to esc-m CLI

## Usage Examples
- "esc-m --help"
- "esc-m self version"

## Installation
```bash
apt-get install esc-m 2>/dev/null || which esc-m
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
