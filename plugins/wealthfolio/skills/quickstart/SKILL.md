# wealthfolio Plugin

A beautiful, private, local-first personal finance tracker. Investments, net worth, spending, and simulations.

## Commands

### General
- `wealthfolio self version` — Print wealthfolio version
- `wealthfolio _ _` — Passthrough to wealthfolio CLI
