# ATAC Plugin

A simple API client (postman like) in your terminal

## Commands

### General
- `ATAC self version` — Print ATAC version
- `ATAC _ _` — Passthrough to atac CLI

## Usage Examples
- "Run ATAC"
- "Use atac to A simple API client (postman like) in your terminal"

## Installation

```bash
pip install atac
```

## Key Features
- A simple API client (postman like) in your terminal
- CLI tool, headless and scriptable
