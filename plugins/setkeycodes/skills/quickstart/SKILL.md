# setkeycodes Plugin

CLI tool: setkeycodes.

## Commands
- `setkeycodes <resource> <action>` — Execute setkeycodes commands
- `setkeycodes self version` — Print setkeycodes version
- `setkeycodes _ _` — Passthrough to setkeycodes CLI

## Usage Examples
- "setkeycodes --help"
- "setkeycodes self version"

## Installation
```bash
apt-get install setkeycodes 2>/dev/null || which setkeycodes
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
