# vibeproxy Plugin

Native macOS menu bar app to use your Claude Code & ChatGPT subscriptions with AI coding tools - no API keys needed

## Commands

### General
- `vibeproxy self version` — Print vibeproxy version
- `vibeproxy _ _` — Passthrough to vibeproxy CLI

## Usage Examples
- "Run vibeproxy"
- "Use vibeproxy to Native macOS menu bar app to use your Claude Code & ChatGPT "

## Installation

```bash
pip install vibeproxy
```
