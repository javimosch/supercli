# gnome-logs Plugin

CLI tool: gnome-logs.

## Commands
- `gnome-logs <resource> <action>` — Execute gnome-logs commands
- `gnome-logs self version` — Print gnome-logs version
- `gnome-logs _ _` — Passthrough to gnome-logs CLI

## Usage Examples
- "gnome-logs --help"
- "gnome-logs self version"

## Installation
```bash
apt-get install gnome-logs 2>/dev/null || which gnome-logs
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
