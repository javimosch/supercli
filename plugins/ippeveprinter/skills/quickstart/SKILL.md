# ippeveprinter Plugin

CLI tool: ippeveprinter.

## Commands
- `ippeveprinter <resource> <action>` — Execute ippeveprinter commands
- `ippeveprinter self version` — Print ippeveprinter version
- `ippeveprinter _ _` — Passthrough to ippeveprinter CLI

## Usage Examples
- "ippeveprinter --help"
- "ippeveprinter self version"

## Installation
```bash
apt-get install ippeveprinter 2>/dev/null || which ippeveprinter
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
