# watchgnupg Plugin

CLI tool: watchgnupg.

## Commands
- `watchgnupg <resource> <action>` — Execute watchgnupg commands
- `watchgnupg self version` — Print watchgnupg version
- `watchgnupg _ _` — Passthrough to watchgnupg CLI

## Usage Examples
- "watchgnupg --help"
- "watchgnupg self version"

## Installation
```bash
apt-get install watchgnupg 2>/dev/null || which watchgnupg
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
