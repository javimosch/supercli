# codex-auth Plugin

A CLI tool to switch and manage Codex accounts

## Commands

### General
- `codex-auth self version` — Print codex-auth version
- `codex-auth _ _` — Passthrough to codex-auth CLI

## Usage Examples
- "Run codex-auth"
- "Use codex-auth to A CLI tool to switch and manage Codex accounts"

## Installation

```bash
pip install codex-auth
```

## Key Features
- A CLI tool to switch and manage Codex accounts
- CLI tool, headless and scriptable
