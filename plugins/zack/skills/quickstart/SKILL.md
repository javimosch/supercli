# zack Plugin

Backtesting engine in Zig

## Commands

### General
- `zack self version` — Print zack version
- `zack _ _` — Passthrough to zack CLI

## Usage Examples
- "Run zack"
- "Use zack to Backtesting engine in Zig"

## Installation

```bash
pip install zack
```

## Key Features
- Backtesting engine in Zig
- CLI tool, headless and scriptable
