# nuwa-skill Plugin

你想蒸馏的下一个员工，何必是同事。蒸馏任何人的思维方式——心智模型、决策启发式、表达DNA。Distill how anyone thinks.

## Commands
- `nuwa-skill <resource> <action>` — Execute nuwa-skill commands
- `nuwa-skill self version` — Print nuwa-skill version
- `nuwa-skill _ _` — Passthrough to nuwa-skill CLI

## Installation

```bash
pip install nuwa-skill
```
