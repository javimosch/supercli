# oxvg Plugin

Fastest SVG toolchain for optimisation, minification, linting, and actions. Usable via CLI, Node, Wasm, or Rust.

## Commands
- `oxvg self version` — Print version
- `oxvg _ _ <args>` — Passthrough to oxvg

## Usage Examples
- "SVG Optimizer"

## Installation
```bash
cargo install oxvg
```

## Key Features
- CLI-only, no interactive prompts
- No API keys or authentication required
- Pipeline-ready output format
