# gamemoderun Plugin

CLI tool: gamemoderun.

- `gamemoderun <resource> <action>` — Execute gamemoderun commands
- `gamemoderun self version` — Print gamemoderun version
- `gamemoderun _ _` — Passthrough to gamemoderun CLI
