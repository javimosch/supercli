# trust Plugin

CLI tool: trust.

## Commands
- `trust <resource> <action>` — Execute trust commands
- `trust self version` — Print trust version
- `trust _ _` — Passthrough to trust CLI

## Usage Examples
- "trust --help"
- "trust self version"

## Installation
```bash
apt-get install trust 2>/dev/null || which trust
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
