# lxc-unshare Plugin

CLI tool: lxc-unshare.

## Commands
- `lxc-unshare <resource> <action>` — Execute lxc-unshare commands
- `lxc-unshare self version` — Print lxc-unshare version
- `lxc-unshare _ _` — Passthrough to lxc-unshare CLI

## Usage Examples
- "lxc-unshare --help"
- "lxc-unshare self version"

## Installation
```bash
apt-get install lxc-unshare 2>/dev/null || which lxc-unshare
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
