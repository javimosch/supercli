# ron Plugin

RON — Rusty Object Notation serialization format

## Commands
- `ron <resource> <action>` — Execute ron commands
- `ron self version` — Version

## Installation

```bash
cargo install ron
Verify: ron --version
```

## Commands

### `sc ron self version`

Version


## SuperCLI

```bash
sc ron _ _ --help
sc plugins learn ron
```
