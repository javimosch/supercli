# react-native-executorch Plugin

Declarative way to run AI models in React Native on device, powered by ExecuTorch.

## Commands

### General
- `react-native-executorch self version` — Print react-native-executorch version
- `react-native-executorch _ _` — Passthrough to react-native-executorch CLI

```bash
pip install react-native-executorch
```
