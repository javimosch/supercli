# tempfile Plugin

CLI tool: tempfile.

## Commands
- `tempfile <resource> <action>` — Execute tempfile commands
- `tempfile self version` — Print tempfile version
- `tempfile _ _` — Passthrough to tempfile CLI

## Usage Examples
- "tempfile --help"
- "tempfile self version"

## Installation
```bash
apt-get install tempfile 2>/dev/null || which tempfile
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
