# mailmail3 Plugin

CLI tool: mailmail3.

## Commands
- `mailmail3 <resource> <action>` — Execute mailmail3 commands
- `mailmail3 self version` — Print mailmail3 version
- `mailmail3 _ _` — Passthrough to mailmail3 CLI

## Usage Examples
- "mailmail3 --help"
- "mailmail3 self version"

## Installation
```bash
apt-get install mailmail3 2>/dev/null || which mailmail3
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
