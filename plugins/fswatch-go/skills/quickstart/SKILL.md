# fswatch-go Plugin
Go-based file change notification and monitoring tool

## Commands
- `fswatch-go <resource> <action>` — Execute fswatch-go commands
- `fswatch-go _ _` — Passthrough to fswatch-go CLI

## Usage
- `fswatch-go _ _ <args>` — Run fswatch-go with any arguments
