# hwe-support-status Plugin

CLI tool: hwe-support-status.

## Commands
- `hwe-support-status <resource> <action>` — Execute hwe-support-status commands
- `hwe-support-status self version` — Print hwe-support-status version
- `hwe-support-status _ _` — Passthrough to hwe-support-status CLI

## Usage Examples
- "hwe-support-status --help"
- "hwe-support-status self version"

## Installation
```bash
apt-get install hwe-support-status 2>/dev/null || which hwe-support-status
```

- CLI-based tool
- Scriptable and automatable
