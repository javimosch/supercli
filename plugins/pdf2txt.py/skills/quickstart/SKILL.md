# pdf2txt.py Plugin

CLI tool: pdf2txt.py.

- `pdf2txt.py <resource> <action>` — Execute pdf2txt.py commands
- `pdf2txt.py self version` — Print pdf2txt.py version
- `pdf2txt.py _ _` — Passthrough to pdf2txt.py CLI

## Usage Examples
