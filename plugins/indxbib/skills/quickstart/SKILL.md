# indxbib Plugin

CLI tool: indxbib.

## Commands
- `indxbib <resource> <action>` — Execute indxbib commands
- `indxbib self version` — Print indxbib version
- `indxbib _ _` — Passthrough to indxbib CLI

## Usage Examples
- "indxbib --help"
- "indxbib self version"

## Installation
```bash
apt-get install indxbib 2>/dev/null || which indxbib
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
