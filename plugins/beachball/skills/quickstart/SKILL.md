# beachball Plugin
Semantic versioning and changelog tool for monorepos

## Commands
- `beachball <resource> <action>` — Execute beachball commands
- `beachball _ _` — Passthrough to beachball CLI

## Usage
- `beachball _ _ <args>` — Run beachball with any arguments
