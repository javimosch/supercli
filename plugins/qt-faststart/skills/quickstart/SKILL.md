# qt-faststart Plugin

CLI tool: qt-faststart.

## Commands
- `qt-faststart <resource> <action>` — Execute qt-faststart commands
- `qt-faststart self version` — Print qt-faststart version
- `qt-faststart _ _` — Passthrough to qt-faststart CLI

## Usage Examples
- "qt-faststart --help"
- "qt-faststart self version"

## Installation
```bash
apt-get install qt-faststart 2>/dev/null || which qt-faststart
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
