# 7za Plugin

CLI tool: 7za.

## Commands
- `7za <resource> <action>` — Execute 7za commands
- `7za self version` — Print 7za version
- `7za _ _` — Passthrough to 7za CLI

## Usage Examples
- "7za --help"
- "7za self version"

## Installation
```bash
apt-get install 7za 2>/dev/null || which 7za
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
