# xbiff Plugin

CLI tool: xbiff.

## Commands
- `xbiff <resource> <action>` — Execute xbiff commands
- `xbiff self version` — Print xbiff version
- `xbiff _ _` — Passthrough to xbiff CLI

## Usage Examples
- "xbiff --help"
- "xbiff self version"

## Installation
```bash
apt-get install xbiff 2>/dev/null || which xbiff
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
