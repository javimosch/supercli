# qsvdp Plugin

CLI tool: qsvdp.

## Commands
- `qsvdp <resource> <action>` — Execute qsvdp commands
- `qsvdp self version` — Print qsvdp version
- `qsvdp _ _` — Passthrough to qsvdp CLI

## Usage Examples
- "qsvdp --help"
- "qsvdp self version"

## Installation
```bash
apt-get install qsvdp 2>/dev/null || which qsvdp
```

## Key Features
- CLI-based tool
- Scriptable and automatable
- Pipeline-ready output
- system based
